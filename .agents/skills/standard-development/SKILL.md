# 标准开发

将用户开发任务作为原命令的 `$ARGUMENTS`。在执行任何操作前，完整读取 `.opencode/commands/standardDev.md`，并逐条执行其全部要求。

该文件是唯一流程基准。不得省略、合并、重排或改写其中的开发规范、提案确认、验证和交付要求。`.opencode/` 只读，不得修改。
