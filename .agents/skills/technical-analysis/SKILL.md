# 技术面统计快照 (Technical Analysis Snapshot)

本 skill 用于为深度研报模块七（技术面分析）生成标准化统计快照，消除手写 SQL 的口径错误。

## 使用方式

```bash
PYTHONPATH=. uv run python .agents/skills/technical-analysis/scripts/technical_snapshot.py <symbol> --output <快照输出路径>
```

- `<symbol>`：6 位股票代码
- `--output`：快照 Markdown 文件路径，按项目规范存放于 `workspace/research/<公司名称>/tmp_data/`，文件名含日期，如 `technical_snapshot_20260731.md`

## 统计项与口径铁律

1. **趋势指标（MA、RSI、MACD、布林带）一律使用后复权价**（`v_daily_valuation.close_hfq`），严禁使用不复权价计算，防止除权失真。
2. **不复权价（`daily_kline.close`）仅用于：** 目标价定价、支撑阻力位的市价标注、市值计算。
3. **折算标注**：提及后复权点位时必须同步折算并标注"当前对应不复权市价约 XX 元"，折算基准为快照生成日的复权因子。
4. **RSI 采用 Wilder 平滑**，14 日周期。
5. 所有日期字段为交易日期，成交量单位为手，成交额单位为元。

## 输出快照包含

| 区块 | 内容 |
|:---|:---|
| 基础信息 | 当前不复权收盘价、后复权收盘价、复权因子、总股本、总市值 |
| 均线系统 | MA20/60/120/250（后复权）+ 折算不复权价，标注价格相对位置 |
| 历史极值 | ATH（后复权）、52周高低（后复权+不复权） |
| 年度表现 | 各年度开盘/收盘/涨跌幅（不复权，标注除权年度） |
| 动能指标 | RSI14、MACD（DIF/DEA/柱）、布林带（中轨/上下轨） |
| 量价特征 | 近20日成交量/成交额、区间最大值、地量日期、放量倍数 |
| 支撑阻力 | 近期显著高低点、整数关口（不复权，标注性质） |
| 其他 | 近10个交易日行情明细 |

## 产出与汇报

1. 统计快照落盘到 `--output` 指定路径。
2. 返回给主 agent 的消息只含：快照文件路径、当前价（不复权）、复权因子、均线排列状态（多头/空头/纠缠）、RSI 值、以及任何数据异常（如历史数据缺失、复权因子异常）。

## 边界

- 本 skill 只产出统计数字，**不做趋势解读与投资判断**——解读由主 agent 基于快照完成。
- 禁止修改任何投资文档，只允许写入 `--output` 指定的快照文件。
