# Equity Research Workflow

本 workflow 用于个股深度研究、重新生成标准研报、独立复核研报，以及围绕个股开展深度讨论。

## 入口判断

当用户提出以下任务时，使用本 workflow：

- 按标准流程分析某家公司。
- 重新研究或重写某家公司研报。
- 独立审查已有个股研报，防止过度乐观或悲观。
- 与用户讨论某家公司投资价值、估值、基本面或风险。

## 必读材料

1. `investigation/equities/deep_investment_analysis_framework.md`
2. `docs/data_catalog.md`
3. `docs/data_schema.md`
4. `docs/view_architecture.md`
5. `docs/usage.md`
6. 目标公司在 `investigation/equities/<公司名>/` 下的全部既有研究材料。
7. `investigation/equities/note.md` 中与目标公司或相关投研结论有关的汇总信息。

如果目标公司已有 `reports/` 章节报告，必须完整阅读所有章节，禁止选择性阅读。

## 数据准备

1. 精准识别公司名称与 6 位股票代码。
2. 必要时执行：

```bash
uv run main.py sync-all --symbol <股票代码>
```

3. 检查 `workspace/research/<公司名>/` 中是否已有可复用材料，包括财报 PDF、脚本、中间数据和历史实验。
4. 量化分析必须通过视图完成，常用视图包括：
   - `v_daily_valuation`
   - `daily_kline`
   - `fin_ttm`
   - `fin_income_statement`
   - `fin_balance_sheet`
   - `fin_cashflow_statement`
   - `fin_indicator`

## 标准深度研究

严格遵循 `deep_investment_analysis_framework.md` 的章节结构与方法论。输出前应完成：

1. 公司微观经营与财务质量审计。
2. 产业周期、供需结构与终端需求判断。
3. 竞争格局、份额、成本曲线与护城河分析。
4. 宏观、政策、汇率、利率和地缘变量审计。
5. 盈利预测与核心变量建模。
6. 估值、风险对冲和目标价推导。
7. 技术面与市场定价行为分析。
8. 投资摘要、逻辑证伪点和跟踪计划。

## 研报重写

重写已有公司研报时，先判断旧报告与最新研究框架的差距，再决定对旧内容进行更新、替换或合并。不得为了重写而简化已有有效内容。

## 独立复核

复核时先脱离原结论独立收集多空证据，再回到原研报检查：

1. 利好是否成立，是否被夸大。
2. 利空是否遗漏，是否被低估。
3. 市场当前更可能如何定价这些信息。

如需修改研报，先输出修改建议并等待用户确认；确认后再手术式修改相关章节、汇总研报和跟踪手册。

## 汇总信息维护

当个股深度研究、研报重写、独立复核或深度讨论导致以下任一内容发生实质变化时，必须同步维护 `investigation/equities/note.md`：

1. 核心投资结论。
2. 评级、仓位建议、目标价或估值区间。
3. 盈利预测、核心变量或逻辑证伪点。
4. 跟踪状态、优先级或后续观察事项。

若研究后确认没有重要增量，应在最终回复中说明 `note.md` 无需更新。

## 深度讨论

讨论型任务应先完成研究资产加载和关键数据透视，再向用户汇报：

1. 当前数据事实。
2. 既有研报共识。
3. 逻辑证伪点的最新状态。
4. 值得继续讨论的 3 个核心博弈变量。

然后询问用户希望从哪个变量切入。
