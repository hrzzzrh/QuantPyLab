# 日线行情表 (daily_kline)

存储股票的每日原始价格与成交数据，以 Parquet 格式存储在数据湖中。

## 1. 字段定义

| 序号 | 字段名 | 类型 | 说明 | 样例值 |
| :--- | :--- | :--- | :--- | :--- |
| 1 | `symbol` | VARCHAR | 股票代码 (纯数字，分区键) | 600519 |
| 2 | `date` | DATE | 交易日期 | 2024-01-02 |
| 3 | `open` | DOUBLE | **不复权**开盘价 | 1715.00 |
| 4 | `high` | DOUBLE | **不复权**最高价 | 1718.19 |
| 5 | `low` | DOUBLE | **不复权**最低价 | 1678.10 |
| 6 | `close` | DOUBLE | **不复权**收盘价 | 1685.01 |
| 7 | `volume` | DOUBLE | 成交量 (手) | 32156 |
| 8 | `amount` | DOUBLE | 成交额 (元) | 5440082944.0 |
| 9 | `adj_factor` | DOUBLE | **后复权因子** (用于计算后复权价) | 5.577083 |

## 2. 数据来源
- 当前生产同步实现: 在市股票默认使用新浪 KLC raw + `hfq.js` 原始复权因子；当前退市股票重建优先使用新浪 KLC，新浪返回空数据、请求/解析失败或质量校验失败时，整只股票切换到腾讯 `newfqkline` raw + hfq 重建。单只股票不混用两个来源的复权序列，staging manifest 通过 `source_used` 记录实际来源。股票 K 线新增/重建的最低起始日为 `2010-01-01`，显式传入更早日期时归一化到该日期；最后交易日在最低日期前的退市股票在 staging 中排除，日常同步记录为无行情；已有更早 canonical 数据不主动清理。canonical 晋级完成并通过灰度验收前，调度仍保持暂停。
- 目标全量重建路径: 在市股票使用新浪 KLC；退市股票使用新浪 KLC，必要时使用腾讯整段 fallback。本地旧 Parquet 不参与新数据质量验收，单只股票内不混用其他数据源复权序列。腾讯返回的成交额字段以万元计，转换为元后写入 `amount`。
- KLC/腾讯 staging 质量校验: 必须存在完整字段，日期有效、无重复、按升序排列且不含周末；数值有限、价格/成交量/成交额非负、复权因子大于 0；同时验证 OHLC 关系和 `close_hfq ≈ close × adj_factor`。腾讯 `newfqkline` raw + hfq 在合并前剔除周末行，并在 manifest 的 `weekend_rows_filtered` 中记录数量；对已确认的供应商坏数据行（`688089/688143/688173` 的 `2024-11-06`）在来源适配层剔除，并在 `known_bad_rows_filtered` 中记录数量；在市股票的既有 AkShare 增量路径不使用这套 staging 公共质量门禁，仍保留其现有行为，但同样执行上述已知坏行过滤。明确无复权记录时才允许 `adj_factor=1.0`。无行情响应使用独立的 `sync_status` 冷却状态，不记录为行情落盘成功。
