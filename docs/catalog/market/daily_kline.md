# 日线行情表 (daily_kline)

存储股票的每日原始价格与成交数据，以 Parquet 格式存储在数据湖中。

## 1. 字段定义

| 序号 | 字段名 | 类型 | 说明 | 样例值 |
| :--- | :--- | :--- | :--- | :--- |
| 1 | `symbol` | VARCHAR | 股票代码 (纯数字，分区键) | 600519 |
| 2 | `date` | DATE | 交易日期 | 2024-01-02 |
| 3 | `open` | DOUBLE | **不复权**开盘价 | 1715.00 |
| 4 | `high` | DOUBLE | **不复权**最高价 | 1718.19 |
| 5 | `low` | DOUBLE | **不复权**最低价 | 1678.10 |
| 6 | `close` | DOUBLE | **不复权**收盘价 | 1685.01 |
| 7 | `volume` | DOUBLE | 成交量 (手) | 32156 |
| 8 | `amount` | DOUBLE | 成交额 (元) | 5440082944.0 |
| 9 | `adj_factor` | DOUBLE | **后复权因子** (用于计算后复权价) | 5.577083 |

## 2. 数据来源
- 接口: `ak.stock_zh_a_hist` (新浪) / `ak.stock_zh_a_daily` (备用)
- 逻辑: 每天增量同步，同时获取 Raw 和 HFQ 价格以计算复权因子。
- **退市股专项**: 已退市股票 (stocks.is_active=0) 新浪/东财源均无数据，改用腾讯 `fqkline` 接口全量重建该股整个 K线 (不复权 day + 后复权 hfq → adj_factor)，整体覆盖本地，保证单一复权口径自洽。重建后写入 `metadata.db` 的 `sync_status` (dataset='kline')，后续同步自动跳过。腾讯不提供成交额，退市股重建的 `amount` 为估算值 (volume×100×收盘价)。
- **腾讯复权异常兜底**: 腾讯 hfq 对退市整理期首日暴跌股可能溢出为负 (实测 000004: 2026-06-23 无涨跌幅限制单日 -89% 被误判为除权)。处理规则: hfq 负值段之前数据有效, 该股正常段因子保留, 负值尾段 (退市整理期, 无除权先验) 按接缝日因子延续并记 warning; 仅当 hfq 全为负时放弃重建该股。
