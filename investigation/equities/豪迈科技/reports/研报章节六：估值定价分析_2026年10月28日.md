### 1.2 基准PE选择（2027E下调至21x）

**为什么2027E由23x下调至21x？**

- 旧2026E基准PE 23x基于当时ROE 18.7%+零增长；Q3后2026E ROE降至16.0%、净利-14.3%，故2027E基准PE下调至21x
- 2027E ROE修复至18.4%（+2.4pp vs 2026E 16.0%）、增速+15.1%，理论应给予溢价
- **但审慎考量**：1) 毛利率30.0%远低于2025年33.56%，修复幅度有限；2) Q3毛利率26.85%击穿F3，盈利可预测性下降；3) 2027H1仍承压，修复集中在下半年；4) 综合确定性2.6/5偏低；5) 汇率6.67+套保仅30%
- **21x**：较P50 19.90x溢价5.5%，溢价来自ROE 18.4%+燃机超级周期期权，扣除毛利率修复不确定+汇率风险；较旧23x下调2x（-8.7%）

### 1.3 PB-ROE校验（2027E）

| 参数 | 数值 |
|:---|:---|
| 2027E ROE（新） | 23.6÷128.5 ≈ **18.4%**（vs 2026E 16.0%） |
| 当前PB（37.62×11.6÷128.47） | **3.40x** |
| 隐含回报率 | 18.4÷3.40 = **5.41%** |
| 5年PB/ROE历史中位数比率 | 0.175 |
| → 合理PB | 0.175×18.4 = **3.22x** |
| → 合理市值 | 3.22×128.47 = **413.7亿** |
| → 合理股价（除权后） | **35.66元** |

PB-ROE模型显示：2027E ROE修复至18.4%（旧22.0%），合理PB由3.85x降至3.22x，合理价由40.99元降至**35.66元**（-13.1%）。**当前37.62元高于PB-ROE合理价35.66元（+5.5%），已无安全边际**。PB-ROE较PE法（41.44元）更保守，因PB-ROE基于当前净资产128.47亿，而PE基于2027E盈利23.6亿，两者差异反映市场对2027H2盈利修复的怀疑——**这正是当前估值的核心矛盾：PE法看还有10.2%空间，PB-ROE看已高估5.5%**。

## 二、估值全变量对冲审计矩阵（2027E重审，Σ下调至-3%）

### 2.1 审慎调节

| 审计维度 | 核心因子 | 审慎思考 | 调节 | 深度理由 |
|:---|:---|:---|:---:|:---|
| **内部：企业DNA** | 全球轮胎模具龙头(32.75%)+ROIC>20%+低杠杆+内生孵化(CNC从自用到外销) | **稀缺性仍存但毛利率弱化**。2027E模具毛利率37.0%仍低于2025年40.0%，Q3综合26.85%显示龙头定价权弱化 | **+1%** | 稀缺性溢价边际弱化，维持+1% |
| **内部：扩产执行力** | 燃机超级周期验证（GE 122GW/西门子95GW）但风电/模具毛利率证伪 | 执行力在燃机订单端验证，但收入/利润转化滞后，**净效应中性** | **0%** | 已在23.6亿净利中体现 |
| **内部：盈利确定性** | 2027E确定性评分2.6/5（较旧3.2下调0.6） | **盈利可预测性下降**。Q3毛利率击穿F3、人工成本超预期、汇率加速升值，2027H1仍承压 | **-2%** | 确定性折价由-1%扩大至-2% |
| **宏观：机床国产替代** | 五轴国产化率68%，但科德Q3 -38.7%、豪迈外部-24.5% | 5-10年长逻辑仍成立，但2027E外部仅+10%，**短期不构成估值溢价** | **0%** | 由+1%下调至0% |
| **宏观：汇率风险** | 2027E假设人民币6.70+20亿套保部分生效 | **不调整PE**。汇率已体现在E的财务费用1.60亿 | **0%** | 严格遵循"可计算进E，不可计算进PE" |
| **宏观：中美关税** | 综合关税33-57%，USTR提议CNC额外12.5% + 轮胎欧盟反倾销45.3%（7-8生效） | 海外产能(泰/墨/美)已对冲机械，但**轮胎反倾销加剧外销价格压力**，尾部风险维持 | **-2%** | 维持-2% |
| **市场：流动性与风格** | 11.6亿股，自由流通~436亿，业绩确定性下降 | 流动性仍可，但**业绩下修使风格溢价消失** | **0%** | 维持0% |

**综合调节（修正）**：+1%+0%-2%+0%+0%-2%+0% = **-3%**。**修正目标市值 = 495.6亿×(1-3%)=480.7亿**（较旧-1%下调2pp：确定性-1→-2、机床+1→0）。

> 逻辑：Q3毛利率击穿、人工成本超预期、汇率加速升值使确定性由3.2降至2.6，确定性折价扩大至-2%；机床外部走弱使国产替代溢价暂时归零；关税折价维持-2%。
