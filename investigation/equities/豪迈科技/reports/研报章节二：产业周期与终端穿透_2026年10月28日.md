**研究日期：2026年10月28日**
**目标年份：2027年（Q4切换期，锚定次年EPS）**
**承接模块一核心发现**：豪迈科技2025年营收110.78亿元，三大业务（轮胎模具53.7%、大型零部件35.8%、数控机床8.7%）均处于上行期，但2026年利润逐季失速。**Q3 2026审计更新**：Q3营收32.54亿（+15.74%）、归母4.79亿（-19.05%）、单季毛利率26.85%（Q2 31.03%→Q3 26.85%），9M归母16.12亿（-9.84%），F1/F3/F5三项证伪触发。**关键产业变化**：①风电1-9月新增60.66GW（-0.7%）、Q3单季22.04GW（+128%），量已修复但铸件价格仍低；②GE Vernova Q3燃机backlog 116→122GW、总backlog 1,970亿美元（Q4指引超2,000亿），燃机超级周期再强化，但豪迈大件H1仅+3.42%、Q3毛利率反降，订单→利润转化滞后；③科德数控Q3 -38.70%、净利-126.6%，公司归因出口政策性因素；国内金属切削机床1-8月+18.6%，行业性走弱证据不足；④9月橡胶轮胎出口85万吨+8.4%、金额143.36亿元+6.3%，量增价减（另有82万吨/137.78亿元口径（+8.1%/+5.9%））。本章对"供需边际与压力传导"的判断需从"需求断层"修正为"量修复、价与成本双压"。

## 一、轮胎模具：终需稳健增长，EV驱动结构性升级

### 1.1 产业链位置与周期定位

轮胎模具是轮胎硫化成型的关键工装，处于"钢材/铸件→模具制造→轮胎生产→汽车OEM/替换市场"链条的中上游。需求驱动因素按重要性排序：**轮胎花纹迭代频率 > 轮胎产能扩张 > 汽车保有量增长**。

**生命周期判断**：轮胎模具处于**成熟期后半段的结构性增长阶段**。全球市场CAGR约3-6%，属于非爆发式增长赛道。但两大结构性因素正在扩大有效市场空间：1) EV轮胎对模具精度的要求大幅提升，推动模具更换周期缩短；2) 轮胎花纹更新频率加快（从过去3-5年一次变为1-2年一次），增加了模具的替换性需求。

### 1.2 终端需求穿透：全球轮胎市场

| 指标 | 数据 |
|:---|:---|
| 2025年全球轮胎市场规模 | ~2,500亿美元 |
| 2025-2035年CAGR | 5.4% |
| 2025年全球轮胎模具市场 | ~16-19亿美元 |
| 2025-2031年模具CAGR | 3.1%-6.3% |
| EV轮胎增速 | 10-22% CAGR（远超整体） |
| 替换市场占比 | 70%+ |

**终端景气度审计**：全球轮胎市场维持5%+增速，核心驱动力为：
1. **发展中国家汽车保有量增长**：亚太地区CAGR 6.0%，中国、印度、东盟贡献增量
2. **EV轮胎需求爆发**：EV轮胎增速22% CAGR，且EV轮胎对低滚阻、低噪音、高载荷的要求迫使轮胎企业不断开发新花纹，直接带动模具需求
3. **替换市场稳定性**：替换需求占比70%+，具有消费品的抗周期属性，不直接受新车销量波动影响

### 1.3 动能溯源与透支审计

**增长动能来源**：主要由内生力量驱动（EV技术更迭、轮胎花纹迭代加速），**未发现显著的政策刺激透支风险**。轮胎模具作为消耗性工装，其需求有轮胎花纹更新这个"硬约束"支撑——只要轮胎企业持续推出新花纹，模具需求就不会断档。而当下正是EV轮胎设计的集中研发期，对模具的测试、小批量、量产需求是真实的终端拉动。

**跨期断层风险评估**：**低风险**。EV渗透率仍在持续提升（中国2025年新能源乘用车渗透率超50%），全球范围内EV轮胎的标准化设计远未完成，未来3-5年模具需求有坚实的技术迭代支撑。

### 1.4 库存动力学

轮胎模具为"以销定产"的订单式生产，不存在渠道库存的概念。轮胎企业自身的模具库存管理较为精益（模具单价高、占地面积大），因此该环节不存在显著的牛鞭效应风险。

## 二、大型零部件：风电稳健，燃气轮机爆发

### 2.1 风电铸件：高基数下的增速换挡（Q3 2026实测修正）

**2025年回顾**：中国风电新增装机120GW（+51% YoY），创历史新高。受政策抢装潮驱动，其中陆风110GW、海风6.6GW。整机招标量143.82GW，核准项目160GW，储备充足。

**2026年展望（引入Q3实测）**：
| 预测来源 | 2026年新增装机 | 增速 | 备注 |
|:---|:---|:---|:---|
| 国家能源局 | **1-9月60.66GW（-0.7% YoY）；Q3单季22.04GW（+128%）** | 累计微降、Q3放量 | 9月底累计7.0亿千瓦（+20.4%）；9月单月7.4GW |
| 国能能源研究院 | 118GW（110-125） | -2% | 10-17行业研报维持，Q4需约57.3GW（同比约-4%） |
| 中金公司 | 118-125GW | -2%~+4% |  |
| 国金证券/华泰 | 118-120GW | -2%~0% | 华泰9月后维持118GW中枢 |

**核心判断（Q3修正）**：1-9月60.66GW（同比-0.7%）**已基本追平2025年同期61.09GW**，Q3单季22.04GW（+128%）显著放量，**"H1断层"已被Q3赶工修复**；但全年118GW仍需Q4完成约57.3GW（2025Q4约59.5GW，同比约-4%），Q4传统赶工+冬季窗口收窄并存，**"可达但需接近去年同期的赶工强度（57.3GW vs 59.5GW）"，不再是此前的"极度后置高风险"，但兑现难度高于此前估计**。价格端仍是核心矛盾：9月风机中标价1,533元/kW跌破1,550预警线，铸件环节价格未随量修复，**量的复苏并未转化为铸件盈利**。"十五五"陆风110-120GW/海风15GW中长期逻辑不变。

**2027年展望（Q4切换期修正）**：1-9月定标143.85GW创历史同期新高、在手管线192GW（定标/框采口径，与公开招标口径不同），2027年陆风交付基础扎实；但2026年H1公开招标51.80GW（-28%）提示2027年远期增速放缓，交付依赖框采转化。管理层称"明年不一定乐观"，行业加速集中（"谁都能干"→供应商集中化）利好龙头。**2027E风电营收约-8.7%至21亿**（原-9%至20亿，Q3量修复小幅上修），毛利率仍仅约18-19%，价格战未止。日月股份H1营收-20.79%/净利-42.79%、Q3待披露，印证行业盈利压力。

**对豪迈科技的影响（Q3验证）**：大型零部件H1营收+3.42%、毛利率19.94%（-4.36pp）；Q3风电装机+128%带动大件收入提速（推算约+25%），但**毛利率进一步降至约16.5%**，说明**量增价减+低毛利风电/关联铸件占比提升+人工成本**三重挤压，价格压力正向铸件环节充分传导。整机商"反内卷"后的毛利率修复**未传导至铸件**，6-12个月滞后假设再次推迟至2027年。08-29交流的日照25万吨"高端零部件超市"（海风超大件+船用）为2027H2后的结构增量，短期难救毛利率。

**需求前置/透支审计（维持中等）**：2025年抢装前置导致2026H1同比-24.9%，Q3赶工修复；"沙戈荒"500GW与深远海100GW规划提供中长期保障，但**2026年公开招标-28%意味着2027年新增装机可能回落至110-120GW**，跨期断层风险由"2026年"后移至"2027年"，评级维持"中等"。

### 2.2 燃气轮机零部件：AI驱动的超级周期（Q3 2026强化验证）

这是豪迈科技三个业务中最具预期差的增长极，**Q3 2026再获创纪录验证**：

| 指标 | 数据（更新至2026Q3） |
|:---|:---|
| 2025年全球燃气轮机市场 | ~202.5亿美元 |
| 2025-2031年CAGR | 6.44% |
| **2026Q2全球燃机新签订单** | **38GW（+71% YoY, +29% QoQ，创历史新高，JP Morgan/McCoy口径）** |
| **2026Q3 GE Vernova订单/backlog** | **订单290亿美元（+96%有机）、总backlog 1,970亿美元（环比+200亿）、燃机backlog 116→122GW、年底指引≥130GW、营收126亿美元+27%** |
| 分厂商Q2新签 | 西门子能源12.5GW / GE Vernova 11.3GW / 三菱电力5.3GW |
| 全球年产能 | 仅60-70GW（年化产能口径）；GE 2026Q3年化20GW、2028年24GW |
| **GE Vernova backlog** | **122GW（Q3末，vs Q2 116GW，年底≥130GW，交付排至2031）；总backlog 1,970亿美元、Q4预计超2,000亿** |
| **西门子能源backlog** | **69GW firm + 26GW SRA（Q3 FY26末95GW，年底目标100GW）** |
| 西门子能源FY26交付 | Q3交付6GW（环比翻倍），已追加中小燃机产能30台至80台、2028年再增至100台 |
| 三菱重工 | 宣布至2030年产能较2024财年翻倍（此前仅+30%），GE亦上调至2030年30GW |
| **全球燃机供需** | **2026年需求117GW vs 供应50-60GW，缺口60GW+，单台2031年交付价格已达2025年3倍** |
| AI数据中心驱动力 | 2025-2028年美国数据中心总功耗从8.9GW升至111.3GW；美国占全球Q2新增约50%（18GW） |

**供需缺口巨大且加剧**：全球燃机Q2新签38GW已超过全球年产能的一半，**年化需求117GW vs 供应50-60GW的缺口从"持续扩大"升级为"极度紧缺"**。GE燃机backlog 116→122GW（Q3末）、总backlog 1,970亿美元、年底指引≥130GW，西门子95GW，交付排期已至2030-2031，**超额预订锁定未来5年需求**。三大OEM扩产至30GW（GE 2030）、产能翻倍（MHI）仍远不足以弥合缺口，**对上游铸件/精加工的溢出需求可见度提升至"极高"，且价格传导（3倍价）开始显现**。

**终端景气度审计**：**超强→更强**。AI数据中心Time-to-Power与离网自备电源（PJM预警2027年6月后新增数据中心优先断电、德州暂停并网申请催生SOFC/燃气+储能离网需求）进一步强化，且中东（沙特/阿联酋AI中心愿景）、亚洲（10.5GW，同增167%）新增贡献亮眼。**但豪迈的转化明显滞后**：H1大型零部件仅+3.42%、Q3毛利率进一步降至约16.5%，说明**OEM backlog并不等于上游铸件立即放量，产能切换、认证节奏、价格谈判与人工成本共同压制了利润兑现**。**2027E燃机营收+26%至24亿**（backlog排至2031+新签38GW创纪录+产能释放）仍为2027E盈利修复的核心驱动，但确定性由5/5下调至4.5/5（订单强、转化慢）。

## 三、数控机床：国产替代加速，五轴机床爆发

### 3.1 市场空间与增速

| 指标 | 2025年 | 2026年E | 2030年E | CAGR |
|:---|:---|:---|:---|:---|
| 中国数控机床市场规模 | 1,224亿元 | 1,304亿元 | 1,597亿元 | 5.3% |
| 其中五轴机床 | 129亿元 | 157亿元 | 352亿元 | 22.2% |
| 五轴机床国产化率 | 59.5% | — | 78%+ | — |

### 3.2 周期定位与驱动力

**生命周期**：五轴数控机床处于**成长期中段**（渗透率约10.5%→22%的加速阶段）。核心驱动力：
1. **航空航天下游**（占比33.7%）：国产大飞机、军用航空发动机对高端加工设备需求刚性
2. **新能源汽车一体化压铸模具**：超大吨位压铸机配套的大型五轴机床需求爆发
3. **设备更新政策**：贷款贴息+《机械行业稳增长工作方案》持续落地
4. **国产替代**：从2020年的18%提升至2025年的59.5%，自主可控战略持续推进

### 3.3 豪迈科技的独特优势

豪迈科技的机床业务并非"从零开始"。公司自成立之初便自制电火花机床及三/四/五轴机床用于轮胎模具生产，积累了20+年的机床自用经验。当前推向市场的产品（立式五轴加工中心、卧式车铣复合、五轴激光加工中心等）是在大规模内部使用验证后的外溢，**可靠性经过了工业级考验，这是与纯初创型机床企业最本质的区别**。

2025年数控机床营收9.68亿元（+142.59%），虽然体量尚小，但增速远超行业均值，正在经历从"内部工具"到"外部产品"的质变。**08-29交流**：外部订单同比仍增长、下滑主因内部扩产优先保障自用（合并10.28亿、自用62.7%），产能可满足20-30%增长、流程改善已释放效率、新厂尚未启用；母机除磨床外近100%自制，实验室约4亿元投入、第五工业园厂房已建成可随时扩展。**但Q3数据要求修正归因**：科德数控Q3营收0.65亿（-38.70%）、归母-395万（-126.6%）、9M -30.4%/-51.65%，其季报明确归因"受国内外政策性因素影响，出口业务收入减少"；同期国内金属切削机床1-8月营收+18.6%、新增订单+15.7%，行业总量景气。**因此豪迈外部下滑主因内部优先+客户基数小，科德主因出口政策性因素，"高端五轴国内需求行业性走弱"证据不足**。2027E外部营收增速由+15%下修至+10%（8.0亿）。

### 3.4 供需边际预判

**供给端**：科德数控、海天精工、纽威数控等国产龙头在加速扩产，供给竞争加剧。但豪迈科技的差异化在于：1) 自研自用20+年的机床制造经验；2) 全产业链布局（铸造→热处理→加工→装配→检测）；3) 与轮胎模具业务的协同效应。短期竞争压力有限，但长期需关注专业化机床企业的规模效应。**Q3更新**：机床工具行业1-8月营收+7.5%、其中金属切削机床+18.6%、新增订单+15.7%、在手订单+19.3%，总量与切削机床细分均景气；科德Q3 -38.70%主因出口政策性因素，豪迈外部-24.46%主因内部优先+客户基数小，**"国内高端五轴需求行业性走弱"证据不足**；2027E外部+10%，较旧+15%下修但仍为正增长。

## 四、强制复核项确认（Q3 2026重检+10-28三季报）

1. **终端产品景气度预测**：已穿透三大业务的终端市场——轮胎市场（9月橡胶轮胎出口85万吨+8.4%、金额143.36亿元+6.3%，量增价减；另有82万吨/137.78亿元口径（+8.1%/+5.9%），方向一致，具体以海关月报为准）、风电装机（**1-9月60.66GW/-0.7%、Q3单季22.04GW/+128%；全年118GW需Q4约57.3GW（同比约-4%），可达但需赶工；2027年公开招标-28%提示增速回落**）、燃气轮机（**GE Q3燃机backlog 122GW、总backlog 1970亿美元、年底≥130GW；西门子95GW；供需缺口60GW+，2027E燃机营收+26%至24亿**）、五轴机床（切削机床1-8月+18.6%、订单+15.7%；科德Q3 -38.7%主因出口政策性，豪迈主因内部优先），均有明确景气度数据支撑但**风电"量修复、价仍弱"、机床"总量景气、高端分化"是关键修正**。

2. **跨期需求移位审计**：轮胎模具无显著透支风险（EV驱动真实，9月橡胶轮胎出口量+8.4%）；**风电"H1断层"已被Q3 22.04GW修复，但2026年公开招标-28%意味着2027年装机可能回落至110-120GW，跨期断层风险由2026年后移至2027年**；燃气轮机是长期结构性趋势（AI数据中心），GE backlog 122GW再验证；机床受设备更新政策推动，国内切削机床1-8月+18.6%，国产替代逻辑仍在；豪迈外部下滑主因内部优先，需更长周期验证外部放量。

3. **供需边际与压力传导（Q3后）**：
