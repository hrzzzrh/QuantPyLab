### 1.2 基准PE选择（2027E维持23x）

**为什么2027E维持23x而非上调？**

- 2026E基准PE 23x基于ROE 18.7%+零增长，给予P50 21.66x + 6.2%溢价
- 2027E ROE修复至22.0%（+3.3pp）、增速恢复至+18%，理论上应给予更高溢价
- **但审慎考量**：1) 毛利率32.7%仍低于2025年33.56%，修复有限；2) 风电"明年不一定乐观"（管理层）；3) 新项目2027H1试产二次冲击；4) 综合确定性3.2/5仍中等
- **23x维持**：P50 21.66x + 6.2%溢价，溢价来自ROE 22%+燃机超级周期期权价值，扣除毛利率修复有限+风电不确定性

### 1.3 PB-ROE校验（2027E）

| 参数 | 数值 |
|:---|:---|
| 2027E ROE（新） | 28.2÷128.0 ≈ **22.0%**（vs 2026E 18.7%） |
| 当前PB（39.25×11.6÷123.61） | **3.68x** |
| 隐含回报率 | 22.0÷3.68 = **5.98%** |
| 5年PB/ROE历史中位数比率 | 0.175 |
| → 合理PB | 0.175×22.0 = **3.85x** |
| → 合理市值 | 3.85×123.61 = **475.9亿** |
| → 合理股价（除权后） | **40.99元** |

PB-ROE模型显示：2027E ROE修复至22.0%使合理PB由3.27x升至3.85x，合理价由36.09元升至40.99元（+13.6%）。**当前39.25元略低于PB-ROE合理价40.99元，处于合理偏低区间**。PB-ROE较PE法（55.36元）更保守，因PB-ROE基于当前净资产（123.61亿），而PE基于盈利预测（28.2亿），两者差异反映市场对2027E盈利恢复的怀疑程度。

## 二、估值全变量对冲审计矩阵（2027E重审，Σ维持-1%）

### 2.1 审慎调节

### 3.2 锚点回测（2027E，-1%调节）

修正后中性PE = 55.36÷2.43 = **22.8x**。该PE：

- 隐含PEG = 22.8÷18.0（2027E正常化增速）= **1.27**（vs 2026E 1.93，PEG改善反映增速恢复）
