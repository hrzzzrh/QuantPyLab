# 研报章节六：估值定价分析（定稿修订）

**研究日期：2026年07月28日**
**当前股价（不复权）**：48.22元（2026年7月28日收盘）
**当前市值**：559.35亿元（11.6亿股）
**目标年份**：2026年（Q3，锚定当年EPS）

**逻辑继承**：
- 模块五定稿预测：2026E EPS **2.28元**，净利润**26.5亿**（+10.7%）
- 三态EPS：保守1.97 / 中性2.28 / 乐观2.57
- ROE维持~20%水平

## 一、价值锚定：适配性方法选择

| 方法 | 权重 | 选择理由 |
|:---|:---|:---|
| **PE（市盈率）** | 60% | 盈利稳定正值，A股制造业最常用定价锚。为主方法 |
| **PB-ROE** | 25% | ROE长期>20%，重资产属性，适合交叉验证 |
| **PEG** | 15% | 正常化利润增速~15%，辅助判断估值透支程度 |

### 1.1 历史分位审计

| PE TTM分位 | 数值 | 当前(23.41x)位置 |
|:---|:---|:---|
| P10（低估） | 16.49x | — |
| P25 | 18.41x | — |
| **P50（中位）** | **20.10x** | — |
| P75 | 21.85x | — |
| P90（高估） | 23.77x | — |
| **当前** | **23.41x** | 接近P90，高于P75 |
| **2026E PE (48.22÷2.28)** | **21.15x** | 位于P50-P75上半区，低于P75 21.85x |

**2026年7月28日复核观察**：股价从46.49元上行至48.22元后，PE TTM已接近2019年以来P90，"极端低估"表述不再成立；但以2026E EPS 2.28元计算，Forward PE约21.15x，仍低于2019年以来P75 21.85x。市场已部分修复7月初的折价，但尚未充分定价燃机超级周期、毛利率修复和扩产项目2026年不进营业成本的组合。

### 1.2 基准PE选择

**为什么是24x而非旧版的26.5x或初版的23x？**

- 旧版26.5x（PEG 1.56）隐含了对28亿净利润的乐观预期配合，利润基数虚高导致PE被摊薄
- 初版23x过度保守，忽视了一个ROE 20%+的全球制造业龙头的估值溢价应高于平庸企业
- **24x**：在2019年以来历史中位数20.10x基础上给予约19%的合理溢价。溢价来自：ROE从17%→22%的结构性提升、三个增长引擎（vs 过去仅模具单一驱动）、数控机床期权价值

| 计算步骤 | 数值 |
|:---|:---|
| 2026E归母净利润（定稿） | 26.5亿 |
| 基准PE | **24.0x** |
| **基准市值** | **636.0亿** |
| 除权后股数 | 11.6亿股 |
| **基准目标价** | **54.83元** |
| 当前价 | 48.22元 |
| 基准上行空间 | +13.7% |

### 1.3 PB-ROE校验

| 参数 | 数值 |
|:---|:---|
| 2026E ROE | 26.5÷128.0 ≈ 20.7% |
| 当前PB | 4.46x |
| 隐含回报率 | 20.7%÷4.46 = 4.6% |
| 5年PB/ROE历史中位数比率 | 0.175 |
| → 合理PB | 0.175×20.7 = **3.62x** |
| → 合理市值 | 3.62×128.0 = **463亿** |
| → 合理股价（除权后） | **39.91元** |

PB-ROE模型提示当前估值偏高（隐含回报仅4.6%）。但需注意：1) 历史中位PB/ROE比率对应的时期（2021-2023年）公司尚未展现当前的增长引擎组合；2) 2026E ROE因扩产稀释暂时回调，2027-2028年有望回升至22%+。PB-ROE更多反映"当前ROE的静态定价"，而非"成长性溢价"。此处取其警示含义（不宜给予过度PE溢价），但不过度依赖。

## 二、估值全变量对冲审计矩阵

### 2.1 审慎调节

| 审计维度 | 核心因子 | 审慎思考 | 调节 | 深度理由 |
|:---|:---|:---|:---:|:---|
| **内部：企业DNA** | 全球轮胎模具龙头(32.75%)+ROIC>20%+无杠杆+内生孵化(CNC从自用到外销) | **稀缺性溢价成立**。大部分稀缺性已通过基准PE（24x，高于2019年以来中位数20.10x约19%）体现，此处仅对剩余未定价部分（全球份额继续提升+ROE维持22%+）保留小幅溢价 | **+2%** | 较旧版+5%收窄，将部分溢价转入基准PE(24x) |
| **内部：扩产执行力** | 日照Q1净利4.6倍增长，实证了跨过盈亏平衡点的非对称利润弹性 | 这是**已实现的利润弹性**，属于E的范畴，不额外进PE | **0%** | 已在26.5亿净利中体现 |
| **宏观：机床国产替代** | 五轴机床国产化率59.5%→78%，国家战略级长逻辑 | 5-10年级别结构性趋势，非短期主题。豪迈"自用外溢"模式独特 | **+2%** | 政策长逻辑改善远期天花板，给予小幅估值溢价 |
| **宏观：汇率风险** | 人民币升值趋势确定 | **不调整PE**。汇率是具体可计算的钱，已体现在E的财务费用预测(+1.0亿) | **0%** | 严格遵循"可计算进E，不可计算进PE"原则 |
| **宏观：中美关税** | 综合关税33-57%，USTR提议CNC额外12.5% | 海外产能(泰/墨/美)已大幅对冲。但关税若扩展至模具品类+收紧转口审查，风险不可忽视 | **-2%** | 较旧版-3%收窄。USMCA R2确认机械/模具非攻击目标，关税焦虑已部分消退 |
| **市场：流动性与风格** | 11.6亿股(送转后)，自由流通市值~530亿 | 送转后流动性改善利于机构配置。当前A股偏好"业绩确定性+制造业龙头" | **+1%** | 小幅溢价 |

**综合调节**：+2%+0%+2%+0%-2%+1% = **+3%**

**调节幅度较旧版（+15%）、新版（+6%）均大幅收窄**。核心理由：旧版+15%过于慷慨（将多种非稀缺因素折算为估值溢价），新版+6%也偏多。在PB-ROE已提示估值偏高的背景下，估值矩阵的调节应保持审慎。**真正改变估值中枢的只有"机床国产替代"这一个政策长逻辑（+2%）和"寡头垄断稀缺性"（+2%）——合计+4%，被关税尾部折价-2%和已部分计入基准PE的溢价稀释后，仅剩+3%。**

### 2.2 修正目标市值

修正目标市值 = 636.0亿 × (1+3%) = **655.1亿**

## 三、三态目标价合成

| 情景 | EPS(元) | PE | 修正后目标价(元) | 概率 |
|:---|:---|:---|:---|:---|
| 保守(Bear) | 1.97 | 21x | **42.7** | 20% |
| 中性(Base) | 2.28 | 24x | **56.5** | 55% |
| 乐观(Bull) | 2.57 | 27x | **71.7** | 25% |

> 注：目标价 = EPS × 标称PE × (1+3%修正系数)，故隐含PE分别为21.7x/24.8x/27.9x（高于标称PE约0.7-0.9x，对应+3%估值调节）。

- **概率加权目标价**：42.7×0.2 + 56.5×0.55 + 71.7×0.25 = 8.54 + 31.08 + 17.93 = **57.5元**

### 3.1 盈亏比计算

| 参数 | 数值 |
|:---|:---|
| 加权目标价 | 57.5元 |
| 当前价 | 48.22元 |
| 保守目标价 | 42.7元 |
| 上涨空间 | +19.2% |
| 下行风险 | -11.4% |
| **盈亏比** | **1.68:1** |

### 3.2 锚点回测

修正后中性PE = 56.5÷2.28 = **24.8x**。该PE：
- 高于2019年以来P75（21.85x）约13.5%、高于P90（23.77x）约4.3%、高于中位数（20.10x）约23%
- 隐含PEG = 24.8÷15.0（正常化增速）= **1.65**
- **已越过2019年以来90分位**，处于历史估值区间上方。维持24.8x需要ROE>20%+零有息负债+三个增长引擎（燃机超级周期、模具垄断、机床放量）持续兑现作为支撑；中性目标价的倍数扩张空间有限，估值弹性主要依赖盈利兑现（26.5亿）而非进一步提估值。若半年报后盈利兑现不及预期，PE存在向P90（23.77x）乃至P75（21.85x）回归的压力——这是当前估值中枢的最大下修风险。

## 四、与历史两版估值的关键差异

| 指标 | 旧版6/26 | 初版7/1 | **定稿7/1** | 差异归因 |
|:---|:---|:---|:---|:---|
| EPS | 2.41 | 2.19 | **2.28** | 财务费用+1.0亿(vs →0.2,+1.5)取中 |
| 基准PE | 25x | 23x | **24x** | 中等溢价，历史中位+11% |
| 综合调节 | +15% | +6% | **+3%** | 严格过滤，仅保留稀缺性+政策长逻辑 |
| 目标价(加权) | 62.30 | 54.50 | **57.5** | — |
| 上涨空间 | +33.3% | +17.2% | **+23.7%** | — |
| 盈亏比 | 6.23x | 1.87x | **2.90x** | — |

> 注：定稿列上涨空间+23.7%/盈亏比2.90x按7月初价格46.49元口径计算；按7月28日收盘48.22元口径，对应+19.2%/盈亏比1.68x（见正文3.1）。

**定稿的核心修正**：
1. **旧版高估了利润**（28→26.5亿）和估值溢价（+15%→+3%），目标价虚高
2. **初版低估了毛利率修复**（25.4→26.5亿），且PE选择过于保守（23x）
3. 定稿取两者之长：利润取旧版会计洞察+初版数据审慎的折中（26.5亿）、PE取有据可依的合理溢价（24x）、估值调节严格过滤（+3%）

**结论**：当前48.22元对应2026E PE 21.15x，已从7月初的低估区向合理区修复，但仍未超过2019年以来P75 21.85x。目标价57.5元保持不变，盈亏比从2.90:1收窄至1.68:1，评级维持买入但操作从"44-47元分批建仓"调整为"48元上方不追高、45-47元回落加仓、已持有仓位继续持有"。旧版62.30元利润假设偏乐观，初版54.50元对毛利率修复力度估计不足。**26.5亿利润+24x PE+3%调节=57.5元**仍是当前最优估计，下一次重估锚点为8月29日半年报。
