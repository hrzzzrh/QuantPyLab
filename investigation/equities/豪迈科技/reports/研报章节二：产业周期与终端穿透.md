# 研报章节二：产业周期与终端穿透

**研究日期：2026年08月29日**
**承接模块一核心发现**：豪迈科技2025年营收110.78亿元，三大业务（轮胎模具53.7%、大型零部件35.8%、数控机床8.7%）均处于上行期，但Q1 2026利润增长失速（营收+17%，净利-0.83%），需判断是产业周期拐点还是阶段性扰动。**H1 2026审计更新**：H1营收60.16亿（+14.27%）但净利11.34亿（-5.28%）、Q2单季-8.69%，毛利率2.11pp塌方与大型零部件19.94%（-4.36pp）、模具36.49%（-3.72pp）证实压力已从费用端传导至核心盈利，本章对"供需边际与压力传导"的判断需联动下修。**08-29业绩交流增量**：模具人工扰动明确为1-2年培训期（影响延至27H1，27H2成熟）、奎文折旧尚未计入；机床外销下滑系内部优先与订单波动而非竞争力缺失；大型零部件焊接件及多行业大件为新增边际（详见三章）。

## 一、轮胎模具：终需稳健增长，EV驱动结构性升级

### 1.1 产业链位置与周期定位

轮胎模具是轮胎硫化成型的关键工装，处于"钢材/铸件→模具制造→轮胎生产→汽车OEM/替换市场"链条的中上游。需求驱动因素按重要性排序：**轮胎花纹迭代频率 > 轮胎产能扩张 > 汽车保有量增长**。

**生命周期判断**：轮胎模具处于**成熟期后半段的结构性增长阶段**。全球市场CAGR约3-6%，属于非爆发式增长赛道。但两大结构性因素正在扩大有效市场空间：1) EV轮胎对模具精度的要求大幅提升，推动模具更换周期缩短；2) 轮胎花纹更新频率加快（从过去3-5年一次变为1-2年一次），增加了模具的替换性需求。

### 1.2 终端需求穿透：全球轮胎市场

| 指标 | 数据 |
|:---|:---|
| 2025年全球轮胎市场规模 | ~2,500亿美元 |
| 2025-2035年CAGR | 5.4% |
| 2025年全球轮胎模具市场 | ~16-19亿美元 |
| 2025-2031年模具CAGR | 3.1%-6.3% |
| EV轮胎增速 | 10-22% CAGR（远超整体） |
| 替换市场占比 | 70%+ |

**终端景气度审计**：全球轮胎市场维持5%+增速，核心驱动力为：
1. **发展中国家汽车保有量增长**：亚太地区CAGR 6.0%，中国、印度、东盟贡献增量
2. **EV轮胎需求爆发**：EV轮胎增速22% CAGR，且EV轮胎对低滚阻、低噪音、高载荷的要求迫使轮胎企业不断开发新花纹，直接带动模具需求
3. **替换市场稳定性**：替换需求占比70%+，具有消费品的抗周期属性，不直接受新车销量波动影响

### 1.3 动能溯源与透支审计

**增长动能来源**：主要由内生力量驱动（EV技术更迭、轮胎花纹迭代加速），**未发现显著的政策刺激透支风险**。轮胎模具作为消耗性工装，其需求有轮胎花纹更新这个"硬约束"支撑——只要轮胎企业持续推出新花纹，模具需求就不会断档。而当下正是EV轮胎设计的集中研发期，对模具的测试、小批量、量产需求是真实的终端拉动。

**跨期断层风险评估**：**低风险**。EV渗透率仍在持续提升（中国2025年新能源乘用车渗透率超50%），全球范围内EV轮胎的标准化设计远未完成，未来3-5年模具需求有坚实的技术迭代支撑。

### 1.4 库存动力学

轮胎模具为"以销定产"的订单式生产，不存在渠道库存的概念。轮胎企业自身的模具库存管理较为精益（模具单价高、占地面积大），因此该环节不存在显著的牛鞭效应风险。

## 二、大型零部件：风电稳健，燃气轮机爆发

### 2.1 风电铸件：高基数下的增速换挡（H1 2026实测修正）

**2025年回顾**：中国风电新增装机120GW（+51% YoY），创历史新高。受政策抢装潮驱动，其中陆风110GW、海风6.6GW。整机招标量143.82GW，核准项目160GW，储备充足。

**2026年展望（引入H1实测）**：
| 预测来源 | 2026年新增装机 | 增速 | 备注 |
|:---|:---|:---|:---|
| 国家能源局 | **38.62GW（H1实测，-24.9% YoY）** | H1已现负增长 | 陆上37.78GW、海上0.84GW；累计装机6.79亿千瓦（+18.5%） |
| 国能能源研究院 | 130GW | +8% | 全年预测不变 |
| 中金公司 | 130-140GW | +8-17% |  |
| 国金证券/华泰 | 130GW（陆风120+海风10）/132GW | +8~+10% | 华泰H1后仍维持130GW（陆风120、海风10），认为9GW海风储备可支撑 |

**核心判断（修正）**：H1 38.62GW（同比-24.9%）显著低于全年130GW线性进度（59%应完成76.7GW，实际仅完成29.7%），**意味着H2需完成91.4GW（月均15.2GW）才能达成全年目标，供需节奏极度后置、执行风险骤升**。若H2无法放量，全年实际或滑落至105-120GW区间（YoY -12%至持平），**此前"维持在120-140GW高位"的乐观假设被H1实测证伪，节奏判断由"稳"转为"前低后高、后高不确定"**。"十五五"陆风110-120GW/海风15GW（东吴）/20GW（乐观）中长期逻辑不变，但**2026年内压力传导已显**：上半年光伏新增"十五五"规划的年均1.92亿千瓦缺口（上半年仅1.17亿千瓦，73.9%中可再生1.17亿中风电仅38.62GW）与136号文电价全面入市后收益率下行，导致运营商观望。

**对豪迈科技的影响（H1验证+08-29交流）**：大型零部件风电铸件业务H1营收仅+3.42%（vs 2025年+32.94%），远低于行业装机预期，且**H1毛利率19.94%较2025H1 24.30%骤降4.36pp，较2025全年21.58%再降1.64pp**，表明**竞争加剧已超越上游议价权改善，价格压力正向铸件环节传导且叠加人工成本上升**。整机商"反内卷"后风机毛利率修复的传导效应**未在H1兑现**，6-12个月滞后假设面临时间考验——若全年装机不及预期，传导窗口将进一步推迟至2027年。**08-29交流新增**：管理层判断风电“明年不一定乐观”、行业将加速集中（“谁都能干”→供应商集中化），豪迈因综合竞争力可在集中化中获主动；日照基地投后将突破尺寸/重量限制，可承接海风超大件及船用等高端零部件“超市”逻辑，单一风电依赖度有望降低。

**需求前置/透支审计（下修）**：2025年抢装前置已导致2026H1同比-24.9%的"断层"初现，但"沙戈荒"500GW与深远海100GW规划仍提供中长期制度保障，**跨期断层风险由"可控"上调至"中等"——2026年内存在阶段性库存去化与订单节奏扰动**。

### 2.2 燃气轮机零部件：AI驱动的超级周期（H1 2026强化验证）

这是豪迈科技三个业务中最具预期差的增长极，**H1 2026再获创纪录验证**：

| 指标 | 数据（更新至2026Q2/H1） |
|:---|:---|
| 2025年全球燃气轮机市场 | ~202.5亿美元 |
| 2025-2031年CAGR | 6.44% |
| **2026Q2全球燃机新签订单** | **38GW（+71% YoY, +29% QoQ，创历史新高，JP Morgan/McCoy口径）** |
| 分厂商Q2新签 | 西门子能源12.5GW / GE Vernova 11.3GW / 三菱电力5.3GW |
| 全球年产能 | 仅60-70GW（年化产能口径） |
| **GE Vernova backlog** | **116GW（Q2末，vs Q1 100GW，年底指引≥125GW，交付已排至2031）** |
| **西门子能源backlog** | **69GW firm + 26GW SRA（Q3 FY26末95GW，年底目标100GW）** |
| 西门子能源FY26交付 | Q3交付6GW（环比翻倍），已追加中小燃机产能30台至80台、2028年再增至100台 |

**供需缺口巨大且加剧**：全球燃机订单38GW（Q2单季）已超过全球年产能的一半，**年化需求117GW vs 供应50-60GW的缺口从"持续扩大"升级为"极度紧缺"**。GE 116GW（vs 83GW at 2025年末）、西门子95GW的backlog均创纪录且交付排期已至2030-2031，**超额预订锁定未来5年需求**。三大OEM扩产至30GW（GE 2030）、产能翻倍（MHI）仍远不足以弥合缺口，**对上游铸件/精加工的溢出需求可见度提升至"极高"，且价格传导（3倍价）开始显现**。

**终端景气度审计**：**超强→更强**。AI数据中心Time-to-Power与离网自备电源（PJM预警2027年6月后新增数据中心优先断电、德州暂停并网申请催生SOFC/燃气+储能离网需求）进一步强化，且中东（沙特/阿联酋AI中心愿景）、亚洲（10.5GW，同增167%）新增贡献亮眼。**豪迈作为GE/西门子/三菱核心铸件供应商，订单满负荷表述与燃机超级周期形成强共振，但H1大型零部件仅+3.42%显示产能瓶颈或风电拖累对冲了燃机增量，H2兑现取决于产能切换与交付节奏**。

## 三、数控机床：国产替代加速，五轴机床爆发

### 3.1 市场空间与增速

| 指标 | 2025年 | 2026年E | 2030年E | CAGR |
|:---|:---|:---|:---|:---|
| 中国数控机床市场规模 | 1,224亿元 | 1,304亿元 | 1,597亿元 | 5.3% |
| 其中五轴机床 | 129亿元 | 157亿元 | 352亿元 | 22.2% |
| 五轴机床国产化率 | 59.5% | — | 78%+ | — |

### 3.2 周期定位与驱动力

**生命周期**：五轴数控机床处于**成长期中段**（渗透率约10.5%→22%的加速阶段）。核心驱动力：
1. **航空航天下游**（占比33.7%）：国产大飞机、军用航空发动机对高端加工设备需求刚性
2. **新能源汽车一体化压铸模具**：超大吨位压铸机配套的大型五轴机床需求爆发
3. **设备更新政策**：贷款贴息+《机械行业稳增长工作方案》持续落地
4. **国产替代**：从2020年的18%提升至2025年的59.5%，自主可控战略持续推进

### 3.3 豪迈科技的独特优势

豪迈科技的机床业务并非"从零开始"。公司自成立之初便自制电火花机床及三/四/五轴机床用于轮胎模具生产，积累了20+年的机床自用经验。当前推向市场的产品（立式五轴加工中心、卧式车铣复合、五轴激光加工中心等）是在大规模内部使用验证后的外溢，**可靠性经过了工业级考验，这是与纯初创型机床企业最本质的区别**。

2025年数控机床营收9.68亿元（+142.59%），虽然体量尚小，但增速远超行业均值，正在经历从"内部工具"到"外部产品"的质变。**08-29交流验证**：外部订单同比仍增长（非需求失速），下滑主因内部扩产优先保障自用（合并10.28亿、自用62.7%），且产能可满足20-30%增长、通过流程改善已释放效率、新厂尚未启用；母机除磨床外近100%自制，实验室约4亿元投入、第五工业园厂房已建成可随时扩展，规划产值远超当前20亿量级，转台占比极小。

### 3.4 供需边际预判

**供给端**：科德数控、海天精工、纽威数控等国产龙头在加速扩产，供给竞争加剧。但豪迈科技的差异化在于：1) 自研自用20+年的机床制造经验；2) 全产业链布局（铸造→热处理→加工→装配→检测）；3) 与轮胎模具业务的协同效应。短期竞争压力有限，但长期需关注专业化机床企业的规模效应。**08-29补充**：行业新增订单+20.5%与豪迈外部-24.46%的分化，主因内部挤出而非外部竞争力缺失，波动性系客户基数小所致，随成熟将收敛。

## 四、强制复核项确认（H1 2026重检）

1. **终端产品景气度预测**：已穿透三大业务的终端市场——轮胎市场（5.4% CAGR、H1出口+4.9%量增价减分化）、风电装机（**H1 38.62GW同比-24.9%后，全年130GW由"稳健"转为"后置高风险"**）、燃气轮机（**38GW创纪录新签、供需缺口60GW+、backlog排至2031，结构性短缺由"至2030年"强化为"至少至2031年"**）、五轴机床（22% CAGR、国产化率68%再获验证），均有明确景气度数据支撑但**风电短期预测需下修为"完成130GW需H2月均15GW，存在不达预期风险"**。

2. **跨期需求移位审计**：轮胎模具无显著透支风险（EV驱动真实，出口6月单月+11.7%显示韧性）；**风电"断层"已现（H1-24.9%）但"十五五"110-120GW+深远海100GW规划仍提供中长期顶板，短期风险由"低"上调至"中等"**；燃气轮机是长期结构性趋势（AI数据中心需求）；机床受设备更新政策推动但长期由国产替代驱动（H1金属切削机床+20.5%新增订单超预期背离"悲观"担忧）。

3. **供需边际与压力传导（08-29交流后）**：
   - 轮胎模具：需求稳健增长（H1+19.66%营收验证，08-29交流：内外1:1、TT关闭等份额加速，电加热与蒸汽订单各半、未来电加热更受认可），但**毛利率-3.72pp显示压力已传导至模具环节**，龙头议价权**边际弱化**（原"可控"→"轻度承压"）；**人工培训期1-2年（影响延至27H1、27H2成熟）为阶段性因子，奎文折旧尚未计入，H2快速修复预期需下修**
   - 大型零部件：风电铸件竞争加剧，毛利率再下探4.36pp至19.94%（**压力传导加剧，验证阈值F3"毛利率连续两季低于31%"的综合毛利率已触及32.38%边缘**）；燃气轮机零部件需求旺盛、**价格端3倍价已现，议价权提升但受风电拖累与产能瓶颈影响，H1+3.42%未充分体现**；**日照投后多行业大件“超市”逻辑（海风超大件+船用等）将降低单一风电依赖**
   - 数控机床：行业高增长（新增订单+20.5%）+国产替代（68%国产化率）窗口持续，**豪迈外部-24.46%系内部优先与客户基数小波动所致（订单仍增长、产能可满足20-30%增长），非外部竞争力验证失败**；供给扩张尚未过剩，波动将随客户面扩大而收敛
