# 研报章节二：产业周期与终端穿透

**研究日期**：2026年10月27日
**标的**：恒瑞医药（600276.SH / 1276.HK）
**目标年份**：2027年（Q4切换期，锚定2027E EPS；2026E保留为对照口径）

**前序核心结论回顾（模块一，2026Q3更新）**：
恒瑞9M已披露：创新药占比64.59%再创新高、Q3单季创新药+18.24%（Q2仅+7.9%）、抗肿瘤Q3转正+4.10%（Q2 -6.0%）、非肿瘤加速至+77.8%、扣非Q3 +90.93%、OCF/NP修复至1.13x。这些财务特征对模块二"供需边际向选择性过剩滑落"的预判构成**部分修正**：赛道拥挤仍然成立（仿制药-16.41%、成熟肿瘤品种增速仅+3.13%），但"存量品种失速向全赛道扩散"的H1担忧被Q3证伪——抗肿瘤在Q3重回正增长，说明供给过剩的冲击集中于少数老品种而非整个治疗领域。

## 一、产业生命周期与库存节奏

### 1.1 行业周期定位：创新药处于成长期，全行业处于调整期

中国医药行业正经历"总量调整 + 结构升级"的双重变局：

| 维度 | 整体医药行业 | 创新药细分 |
| :--- | :--- | :--- |
| **周期阶段** | 成熟期（存量博弈）| **成长期（渗透率驱动）** |
| **关键信号** | 2025年全终端市场约20033亿元，同比**下降1.4%**（罕见总量收缩）；规模以上医药制造业利润下降2.8% | 2025年创新药市场约1.22万亿，增速仍在双位数；获批创新药76个（同比+58%），创历史新高 |
| **增长动能** | 人口老龄化驱动的刚性需求 vs 集采降价导致的"量增价减" | 创新药审评加速（纳入ICH、优先审评）、医保"以价换量"、商保补充支付 |

**核心判断**：医药行业整体正处于"以价换量"的存量洗牌期，但创新药是当前唯一具备高确定性的成长板块。恒瑞身处创新药赛道，受益于结构性增长，但其仿制药业务（9M 76.05亿、全年约100亿）承受着集采降价的持续压力。**2026Q3实证进一步强化这一分野：创新药+18.24% vs 仿制药-17.1%，两者剪刀差达35pp，创历史最宽**。

### 1.2 库存动力学：仿制药被动去库延续，创新药主动补库进入收获期

- **仿制药/原料药环节**：处于**被动去库阶段**。集采常态化导致医疗机构减少仿制药库存，"以量换价"模式下企业按约定量精准供应，传统的渠道压货模式被彻底打破。2025年集采31个项目，省级联盟占87%，覆盖面持续扩大。**恒瑞自身库存从H1的29.94亿微升至Q3的30.43亿（+1.64%），在营收环比+22.39%的背景下存货几乎未增，说明库存周转加快、无积压风险**。
- **创新药环节**：处于**主动补库后的收获期**。创新药获批放量驱动企业扩充产能。恒瑞Q3末固定资产62.14亿、在建工程24.91亿、无形资产38.98亿，9M资本支出26.71亿（+55.8%），**产能与产能性资产同步扩张，对应的是已获批产品的商业化放量而非押注未验证管线**。

**牛鞭效应辨析**：当前创新药的上量源于真实临床需求释放，而非渠道压货。Q3新增证据：
1. **回款率102.2%**（9M），剔除BD现金后产品端回款95.9%，说明终端真实销售而非渠道囤货
2. **应收账款增速（+8.31% vs H1）远低于Q3营收环比增速（+22.39%）**，收入增长未依赖放宽信用政策
3. **存货几乎持平而营收大增**，进一步印证"卖得出去"而非"压得进去"

## 二、终端需求穿透与跨期断层审计

### 2.1 最终产品画像：两大核心终端

恒瑞的创新药最终负载于以下终端形态（按9M实际结构）：

| 产品线 | 最终终端 | 9M收入（亿）| 占创新药比重 | 核心场景 |
| :--- | :--- | :--- | :--- | :--- |
| 抗肿瘤产品 | 癌症患者治疗 | 98.65 | 71.12% | 三甲医院肿瘤科、DTP药房 |
| 非肿瘤产品（代谢/自免/神经）| 慢性病患者管理 | 40.06 | 28.88% | 内分泌科、风湿免疫科、零售 |

> 对比2026Q1的抗肿瘤占创新药73.2%、非肿瘤26.8%，**非肿瘤占比在三个季度内提升2.1pp**，第二曲线的结构权重持续上升。

### 2.2 抗肿瘤终端景气度审计

**市场规模与增长**：
- 2025年中国抗肿瘤药物市场规模约3187亿元（5年CAGR约11.4%）
- 从2020年的1858亿元净增1329亿元，5年累计涨幅71.5%
- 预计2026年突破3500亿元

**增长动能源头审计**：

| 动能来源 | 性质 | 持续性评估 |
| :--- | :--- | :--- |
| 人口老龄化（65岁以上人口2.24亿，占15.9%）| **内生** | 确定、持续、不可逆。老年癌症发病率是中年人的5-10倍 |
| 诊疗可及性提升（总诊疗人次101.1亿，+20.07%）| **半内生** | 分级诊疗+医保覆盖扩大，具有政策惯性 |
| 治疗范式升级（化疗占比从78%降至43.8%，靶向/免疫疗法占比47.1%）| **内生** | 技术替代驱动，不可逆 |
| 医保"以价换量"（国家医保已纳入199种创新药，累计支出5048亿元）| **外生/政策** | 持续但边际减弱（2025新增36种抗癌药，平均降价63%）|
| 商保补充支付（商业险在抗癌药支付中占比预计从12%升至18-20%）| **外生/政策** | 中期增量 |

**恒瑞抗肿瘤板块的三季度实证**：

| 期间 | 抗肿瘤创新药收入 | YoY | 归因 |
| :--- | :--- | :--- | :--- |
| 2026Q1 | 33.13亿（推算）| +11.63% | 医保品种放量 |
| 2026Q2 | 29.52亿（推算）| **-6.0%** | 吡咯替尼/阿帕替尼下滑 + 瑞康ADC准入慢 |
| **2026Q3** | **36.01亿** | **+4.10%（环比+21.99%）** | **瑞康CRC三线（8月获批）+ 法米替尼宫颈癌一线（7月获批）+ 海曲泊帕新适应症（9月11日）三重贡献** |
| 2026 9M | 98.65亿 | +3.13% | — |

**关键修正**：Q2的-6.0%曾被解读为"PD-1红海化、基石品种增长见顶"的趋势性信号（黄灯6）。Q3的+4.10%表明**该判断过度外推**——抗肿瘤板块的问题是新适应症的商业化转化滞后（医院准入周期6-9个月），而非终端需求萎缩。Q3三项新适应症获批后的即时放量（环比+21.99%）验证了"管线兑现→准入→放量"的传导链在3个月量级内即可生效。**但9M累计仅+3.13%仍远低于行业11.4%的CAGR，恒瑞在抗肿瘤赛道的份额是被侵蚀的**，这一点未改变。

**跨期断层审计——需求前置风险评估**：

- **PD-1抑制剂市场**：存在一定程度的**需求前置**。国产PD-1年治疗费用已从进口药30万+降至5万以内，医保纳入后短期内需求被提前释放。恒瑞卡瑞利珠单抗面临的挑战是：PD-1市场已趋于饱和，新增适应症（联用方案的推进）将是维持增长的唯一路径。Q3法米替尼+卡瑞利珠单抗宫颈癌一线获批即属此路径。
- **HER2 ADC（瑞康曲妥珠单抗）**：需求前置风险较低。该品类国内渗透率尚处早期，Q3新增第3项适应症（HER2阳性结直肠癌）扩大适用人群，11项BTD为后续适应症铺路。
- **HER3 ADC（瑞康芦泽妥塔单抗）**：Q3新获BTD（联合贝伐一线EGFR突变NSCLC）并递交NDA，是恒瑞ADC平台向HER3靶点延伸的信号，属增量而非存量转移。
- **整体评估**：恒瑞抗癌管线丰富（超30款肿瘤创新药），单产品需求前置风险可被管线迭代所消化。不存在"一锤子买卖"式的系统性透支。

### 2.3 代谢/GLP-1终端景气度审计

**市场规模与结构性需求**：
- 中国成人超重/肥胖率：50.7%（2018年，预计2030年升至61.3%），相当于约7亿肥胖/超重人群
- 2026年中国减重药物市场从"野蛮生长"进入"合规化2.0阶段"
- 全球GLP-1市场正处爆发期，2025年全球GLP-1市场超500亿美元

**恒瑞GLP-1管线的终端定位（Q3重大进展）**：
1. **瑞普泊肽（HRS9531，GLP-1/GIP双靶点）**：**减重NDA已受理（2025年9月）；Q3新增T2DM适应症NDA获CDE受理——糖尿病与减重双适应症并行申报，扩大了可及患者池**。口服版中国II期减重数据：26周平均体重下降最高12.1%（优于司美格鲁肽的约10%），且未观察到平台期。
2. **HRS-7535（口服小分子GLP-1）**：T2DM与减重双NDA已于9月02-03日受理，III期44周减重10.9%、50周11.1%无平台期。国内口服小分子GLP-1稀缺（全球仅礼来Orforglipron于2026年4月获FDA批准）。
3. **HRS-1596（每周一次口服GLP-1/GIP双受体激动剂）**：9月29日授权诺和诺德（大中华区外全球权益），3亿美元首付+26亿美元潜在总额+销售提成。**这是恒瑞代谢管线首次被全球GLP-1龙头（诺和）以首付形式背书**，验证了分子设计的国际竞争力。
4. **HRS-4729（GIP/GLP-1/GCG三靶点）**：8月获批II期，对标礼来retatrutide。
5. **Kailera全球平台**：恒瑞以"NewCo"模式将GLP-1海外权益授予Kailera（纳斯达克上市，代码KLRA），总里程碑高达60亿美元。

**非肿瘤板块的三季度实证**：

| 期间 | 非肿瘤创新药收入 | YoY | 归因 |
| :--- | :--- | :--- | :--- |
| 2026Q1 | 12.13亿 | +92.13% | 恒格列净/瑞卡西单抗/艾玛昔替尼新进医保 |
| 2026Q2 | 13.32亿（推算）| +60.2% | 基数抬升、增速自然回落 |
| **2026Q3** | **14.61亿** | **+77.8%（环比+9.68%）** | **舒地胰岛素8月26日首批发货 + 艾玛昔替尼第5项适应症（8月）+ 卓托奇拜单抗AD递交** |
| 2026 9M | 40.06亿 | +75.36% | — |

**关键发现**：非肿瘤增速从Q2的+60.2%重新加速至Q3的+77.8%，**打破了"增速单边衰减"的线性预期**。驱动来自新分子接力（舒地胰岛素首批发货）而非单一品种的自然增长，说明**恒瑞的代谢/自免管线具备"接续上市、平滑增长"的矩阵特性**。这一特性对GLP-1上市后的放量节奏构成正面预期——恒瑞不需要依赖单一爆款。

**竞争烈度评估（跨期断层风险的核心来源，10月27日更新）**：

| 风险因子 | 评估 |
| :--- | :--- |
| 司美格鲁肽专利已到期，中瑞FTA数据保护触发 | 专利已到期，但因中瑞FTA数据保护（6年），仿制药审批暂停，最早2027年4月才可能大规模涌入。窗口期较此前预期延长6-12个月。风险等级：中高 |
| 礼来替尔泊肽已进医保 | 疗效最强之一，月治疗费已降至300+元，对恒瑞定价形成锚定 |
| **礼来retatrutide（三靶点）ADA 2026数据** | **6月6日ADA年会公布Phase 3 TRIUMPH-1和TRANSCEND-T2D-1结果：12mg 80周减重28.3%（70.3磅），9mg 25.9%，同时显著改善膝骨关节炎疼痛和阻塞性睡眠呼吸暂停。这是GLP-1赛道迄今最强的疗效数据，将行业标杆大幅提升。但retatrutide尚未在中国提交上市申请，且三靶点安全性需更长随访验证。风险等级：中——远期竞争压力，短期不直接冲击恒瑞中国市场** |
| 信达玛仕度肽已上市 | 国产先发优势 + 渠道覆盖。信达H1产品收入82.01亿（+56.7%），玛仕度肽为综合产品线重要增长驱动（交银国际预测2026年约18亿、2027年40-50亿）；信达中期报告不按单品披露收入 |
| 辉瑞埃诺格鲁肽进口 | 2026年入华，新竞争者 |
| **诺和诺德成为恒瑞BD合作方（Q3新增）** | 9月29日HRS-1596授权诺和，3亿美元首付。**竞争与合作的边界被重新定义**：诺和既是恒瑞未来减重市场的最强竞争者（司美格鲁肽），又是其早期分子的买单方。这说明恒瑞在GLP-1分子的设计能力已获全球龙头认可，但同时也意味着恒瑞最优质的下一代分子被授权出去、国内商业化仍需与诺和正面竞争 |

**retatrutide三靶点数据对行业格局的影响（延续判断）**：
礼来retatrutide（GIP/GLP-1/Glucagon三靶点）将行业"Best-in-class"标杆从替尔泊肽的~22%提升至~28%。对恒瑞的影响需分层看待：
- **短期（2026-2027）**：retatrutide尚未在中国提交IND/NDA，中国GLP-1市场短期竞争焦点仍是司美格鲁肽仿制药（2027年4月涌入）和信达玛仕度肽。
- **中期（2028+）**：若retatrutide成功在中国获批，将重新定义减重药的疗效预期基准——届时恒瑞的双靶点瑞普泊肽（注射剂36周23.6%、口服26周12.1%）在疗效维度将处于劣势。恒瑞的差异化优势在于口服便利性+渠道+价格，而非纯疗效竞争。
- **战略含意**：恒瑞HRS-4729（GIP/GLP-1/GCG三靶点）II期进度是对冲retatrutide的关键，但时间上落后礼来3-4年。

**司美格鲁肽仿制药审批延迟**：2026年3月20日司美格鲁肽核心专利到期后，由于中瑞FTA药品试验数据保护条款（6年），瑞士子公司Novo Nordisk Pharma AG持有的司美格鲁肽在中国触发数据保护，多家仿制药企业（九源基因、丽珠集团、联邦制药等）的上市申请审批状态显示为"暂停"。仿制药最早可能要到2027年4月才能获批，**显著延长了恒瑞GLP-1创新药的竞争窗口期**。走2.4类改良型生物制品路径的企业（如齐鲁、石药）可能不受此影响，但其临床数据需独立验证。

**跨期断层审计结论**：
- **存在显著的"竞争前置"风险，但不存在"需求前置"风险**。7亿超重人群的临床需求真实且几乎未被满足（当前GLP-1药物覆盖率极低），但供给端的竞品洪峰（预计2027-2028年）将在仿制药获批后将市场从"蓝海"压入"红海"。
- 恒瑞的差异化在于：（1）双靶点（GLP-1/GIP）提供更优减重数据；（2）口服+注射双剂型布局；（3）Kailera全球化变现；（4）**Q3新增：T2DM与减重双适应症并行申报，患者池从减重扩展至糖尿病（中国糖尿病患者约1.4亿）**。
- **Q3新增风险维度**：HRS-1596授权诺和意味着恒瑞把"每周一次口服"这一最优质的给药便利性资产让渡给了最强竞争者。恒瑞国内GLP-1的商业化窗口依赖瑞普泊肽（注射，双靶点）与HRS-7535（口服小分子），**与诺和的合作关系可能在未来转化为国内市场的直接竞争**。

## 三、供需边际与压力传导

### 3.1 行业整体供需平衡

| 供给端 | 需求端 | 供需边际 |
| :--- | :--- | :--- |
| 2025年NMPA批准76个创新药（+58%），管线加速释放 | 创新药市场年增长约8-10% | **供给增速 > 需求增速**，竞争加剧不可避免 |
| CDMO产能CAGR>20%扩张，但结构分化（ADC/大分子缺、小分子过）| 研发支出持续增加（恒瑞9M 71.46亿、百济141亿）| 高端产能（ADC、CGT）仍紧缺，低端产能过剩 |
| GLP-1赛道：20+仿制药+5+创新药涌入 | 7亿超重人群，但自费为主 | **短期供过于求风险显著** |

### 3.2 价格压力传导特征

**波动放大效应分析**：
- 集采价格降幅（平均70%）对仿制药利润的冲击是**即时且不可逆的**。恒瑞的仿制药业务（9M 76.05亿、全年约100亿）每一轮集采都将面临新一轮降价。**Q3仿制药-17.1%与Q2推算-22%相比略有收窄，但仍无见底信号**。
- 恒瑞的"对冲机制"在Q3被强力验证——创新药收入（9M 138.71亿）增速（+17.05%）远超仿制药减量（-16.41%），9M扣非净利率从23.44%（2025）升至25.58%。**但这种对冲的"质量"需打折：Q3的利润对冲主要来自BD而非产品端**。

**传导时滞与弹性**：
- 医保谈判降价的**传导时滞约为3-6个月**（协议签署→医院进药→处方放量），期间存在"以价换量"的验证窗口。
- **Q3提供了传导时滞的实证校准**：瑞康CRC三线（8月6日获批）、法米替尼宫颈癌一线（7月23日获批）、海曲泊帕新适应症（9月11日获批）三项在Q3内即贡献抗肿瘤环比+21.99%，说明**新适应症从获批到放量的最短时滞可压缩至1-2个月**（若已具备医院准入基础）。这修正了此前"准入周期6-9个月"的保守假设，对2027E GLP-1放量预测构成正面依据。
- 恒瑞的博弈筹码包括：（1）**品种数量优势**（27款1类创新药），单一品种集采冲击可被管线宽度分散；（2）**学术推广壁垒**（全国医院覆盖网络），并非单纯价格竞争；（3）**销售费用率的规模弹性**（Q3 23.84%证明收入回升时费用率可快速回落）。

### 3.3 供需边际预判

**核心预判（10月27日修正）**：2026-2027年创新药供需边际将从"紧平衡"向"选择性过剩"滑落，但**"选择性"的含义在Q3被重新界定**——过剩集中在成熟靶点（PD-1/L1类10+产品）与同质化品种，而差异化靶点（ADC、双抗、口服小分子GLP-1）仍处供不应求。

- **抗肿瘤赛道**：拥挤程度高（PD-1/L1类已有10+产品），但恒瑞的优势在于管线深度（ADC、双抗、PARP等差异化靶点）而非单品依赖。**Q3 +4.10%的转正说明恒瑞在拥挤赛道中仍能通过新适应症获得增量，但增速天花板明显低于行业**。
- **代谢/减重赛道**：2026年下半年至2027年是"供给洪峰期"（司美仿制药+多款创新药集中上市），短期供给冲击猛烈。但长期看，7亿肥胖/超重人口的渗透率（当前<1%）决定了天花板极高，**优胜劣汰后的幸存者将享受巨大市场**。
- **恒瑞的相对优势**：恒瑞GLP-1双靶点（GIP/GLP-1）是目前国产进度最快的之一（减重+T2DM双NDA），口服小分子HRS-7535国内领先，且借Kailera与诺和打开全球化变现。但**时间窗口紧张**——必须在2027-2028年窗口期内建立品牌心智和处方习惯。

## 五、产业周期结论

恒瑞所处的创新药行业正处于**"总量收缩中的结构性牛市"**——整体医药市场萎缩（-1.4%），但创新药市场以双位数增速逆势扩张。这一"剪刀差"构成恒瑞的alpha来源，且Q3数据强化了这一判断：创新药+18.24% vs 仿制药-17.1%，剪刀差35pp。

**本次最重要的产业周期修正**：H1曾判定"供需边际向选择性过剩滑落已传导至龙头收入端"（抗肿瘤Q2 -6.0%）。Q3的+4.10%证明**该传导是"品种级"而非"板块级"的**——过剩冲击集中在吡咯替尼、阿帕替尼等上市较早的成熟品种，而新适应症（瑞康CRC、法米替尼宫颈癌、海曲泊帕ITP/CTIT）仍能获得增量。这意味着**恒瑞的产业周期风险本质上是"管线迭代速度能否跑赢存量品种衰退速度"的赛跑**，而非需求端的系统性萎缩。

**Q3给出的赛跑证据是正面的**：7项获批+7项NDA受理+35个临床批件+2项BTD，管线迭代速度未放缓；抗肿瘤环比+21.99%、非肿瘤环比+9.68%，迭代已转化为收入。

然而，最大的外部不确定性仍来自**GLP-1赛道的供给洪峰**。司美格鲁肽专利到期、20+仿制药涌入、替尔泊肽降价、信达已占先机、礼来retatrutide将疗效标杆推至28.3%，恒瑞必须在窗口期（2027-2028年）内完成品牌建设和处方引流。**Q3新增的隐忧是：恒瑞把最具差异化潜力的HRS-1596（每周一次口服）授权给了诺和——这既是能力背书，也意味着国内市场竞争格局的复杂度上升。**

**产业周期评级**：创新药成长期，细分赛道竞争烈度快速攀升但呈"选择性"分布。恒瑞的管线纵深是最大护城河——不依赖单一爆款，而是凭借27款已上市创新药的矩阵叠加效应。**评级从"承压"边际上调至"承压但具韧性"**。
