## 一、投资摘要

### 1.1 公司画像

中顺洁柔是中国生活用纸行业四大龙头之一（洁柔品牌），2025年营收87.80亿元（+7.7%），归母净利3.19亿元（+312.8%）；2026H1营收44.10亿（+1.85%，Q2仅~1%）、归母2.25亿（+50.13%，落预告2.20-2.30亿中值，其中湿厕纸+130%/棉柔巾+68%高端品占比35.31%），拥有洁柔、太阳、朵蕾蜜等品牌，渠道覆盖全国（电商/新零售占比61%），建有七大生产基地+达州一期10万吨（TM3 2026-04-22投产）全面建成。

### 1.2 投资逻辑的核心矛盾

**"好行业，中公司，差结构"** 三字概括：

- **好行业**：生活用纸是高频刚需消费品，中国人均消费（~10kg）仅为美国的38%，行业CAGR 5-6%，天花板远未触及。消费升级（高端化/细分化）+渠道下沉（县域渗透率提升）是长期结构性驱动力。

- **中公司**：洁柔品牌认知度全国前三，过去十年份额从3.6%提升至~14%（行业最快），电商/新零售渠道先发优势明显，渠道执行力在四大龙头中首屈一指。管理层（职业经理人+员工持股）进取心强。

- **差结构**：公司存在**三个致命的结构性软肋**：
  1. **上游"裸奔"**：四大龙头中唯一没有浆纸一体化的企业，利润完全被动暴露于国际木浆价格波动（2024年当周期逆转时，NP从9.06亿→0.77亿崩塌91.5%）
  2. **品类极度单一**：99%营收来自纸巾，没有恒安式的卫生巾/纸尿裤业务对冲风险，也没有维达/RGE式的上游浆厂安全垫
  3. **ROIC仅4.9%**：资本回报率已跌破合理门槛，意味着公司正在摧毁而非创造股东价值

## 二、风险因素（按冲击烈度排序）

### R1：木浆价格大幅上行（冲击烈度 ★★★★★，概率 15-20%）

**触因**：巴西干旱/物流中断/全球浆厂检修集中→阔叶浆供应收紧→浆价从4,383元/吨（7月现货）飙升至6,000元+/吨（7月针叶已现挺价+55美元/吨信号）

**冲击**：吨成本上升约1,600元，按90万吨销量计算→成本增量约14.4亿。即使ASP提升5%对冲→归母净利仍将从5.07亿（2027E Base）骤降至约0-1亿。**股价可能跌至2.5-3.5元（Bear Case 2.48元）。**

**对冲**：加速竹浆替代（达州基地）；建立更高的木浆安全库存；布局浆价期货对冲工具（公司目前未使用）

### R2：竞争格局恶化——维达/RGE整合发力（冲击烈度 ★★★★☆，概率 25-35%）

**触因**：维达在被金鹰集团（RGE）收购后，借助Bracell 150万吨阔叶浆产线的成本优势，在中高端市场发起价格战

**冲击**：中顺洁柔被迫跟进促销→ASP下降2-3%→毛利率压缩→净利压缩至3-4亿区间。更为严重的是，这可能造成洁柔品牌在高端市场的长期份额流失，削弱品牌溢价能力。**H1双向解读**：恒安H1 -6.1%（需求侧行业性利空，但洁柔+1.85%跑赢显示相对韧性）+毛利率+3pct、经营利润+12.6%→竞争强度利好（头部均承压，但恒安汇兑损失2.13亿致净利-8.7%，财务扰动非经营性，不构成份额冲击）

**监测指标**：维达/得宝终端促销、京东/天猫排名、洁柔市占率季度变化；新增达州一期10万吨全面投产对份额支撑

### R3：消费持续疲软+通缩压力（冲击烈度 ★★★☆☆，概率 15-20%）

**触因**：中国经济复苏乏力，消费者信心低迷，消费降级趋势强化

**冲击**：高端产品（乳霜纸巾/国风联名/湿厕纸等）推广受阻→产品结构降级→ASP承受下行压力。但生活用纸刚需总量不会大幅萎缩，预计对营收影响-2-5%，对利润影响-10-20%。**H1已现**：营收+1.85%（Q2~1%）显著低于行业5-6%预期，消费疲软超预期已部分兑现，需关注Q3金九银十旺季能否回升至3%+

### R4：人民币显著贬值（冲击烈度 ★★★☆☆，概率 10-15%）

**触因**：中美利差扩大、资本外流→人民币兑美元贬值至7.5+

**冲击**：进口木浆的美元计价成本上升。以公司年进口约50万吨木浆、均价650美元/吨估算，人民币从6.79贬至7.5→人民币成本增加约1.6亿元→吞噬约34%的新Base净利4.70亿。**H1对冲**：人民币升至6.74（在岸6.7442创2023年2月以来新高，海关汇率6.791）已兑现大部分红利（H1财务费用-72.68%），后续贬值风险仍存但短期升值趋势对冲供应链风险

### R5：公司治理风险——家族企业路径依赖（冲击烈度 ★★★☆☆，概率 10%）

**触因**：实际控制人邓颖忠家族持股比例较高（广东中顺纸业集团持股约25%，中顺公司持股约20%）。若家族决策与职业经理人团队产生分歧（如过度保守的资本配置、管理层动荡），可能损害公司运营效率。

**冲击**：管理层不稳定→战略执行受阻→业务增长失速。参考同行业恒安国际在阿米巴改革期间的阵痛和维达在被收购前后的管理层动荡。

**对冲**：目前职业经理人团队（总裁杨裕钊，曾任财务总监）表现积极，员工持股计划激励机制有效，短期内治理风险可控。

## 三、研究结论象限图

基于**"确定性"与"预期收益空间"**两个维度：

```
                    预期收益空间 高
                          ↑
      第二象限              │              第一象限
   (Speculative Growth)    │        (High-Conviction Buy)
   低确定性+高预期收益      │        高确定性+高预期收益
                            │
    ←  │ ← 中顺洁柔 ×      │
                            │     × 心脉医疗
                            │
  ——————————————————————————————————→ 确定性 高
                            │
      第四象限              │              第三象限
       (Avoid/Wait)        │         (Defensive Value)
   低确定性+低预期收益      │        高确定性+低预期收益
                            │
                      预期收益空间 低
```

**中顺洁柔当前定位：第四象限（Avoid/Wait，2027E切换后赔率微修复但仍不及阈值）**

- **确定性**：3.0/5——费用拐点与达州投产上调确定性，但销量增速1.85%大幅下调对冲，综合维持
- **预期收益空间**：概率加权目标价8.88元（+25.6% vs 7.04），盈亏比0.40（仍<1.0）
- **下调至理想买入区间（5.50-6.50元）后**，可进入**第三象限（Defensive Value）**：高确定性（估值已显著低于P5+达州产能兑现+股息）+中等预期收益（30-60%）
- 公司**不具备第一象限（High-Conviction Buy）资质**：上游裸奔+品类单一+ROIC 8%仍低是长期硬伤，非周期性波动可解决；H1研发腰斩更削弱长期护城河

**一句话总结（2027E-Based，10-09重算）**：**中顺洁柔H1呈现"营收失速但利润与现金流质量逆势改善"的割裂：销售费用拐点20.77%与达州一期全面投产验证管理层降本能力，但1.85%增速与研发腰斩暴露需求疲软与长期投入矛盾。10-09价7.04元已进入修正中枢7.92元下方-11.3%，估值安全垫随价格企稳增厚（PE 22.90x已显著低于P5处于极端低估），但H1营收失速+研发腰斩令成长性折价，仍无安全边际，等待回调至5.50-6.50元或Q3营收/毛利率双验证后再评估。**
