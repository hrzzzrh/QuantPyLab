# 研报章节八：投资摘要与风险因素

**研究日期：** 2026年08月25日

## 一、投资摘要 (Investment Summary)

### 核心投资逻辑

金风科技是全球风电整机制造领域的绝对龙头——国内新增装机连续十五年第一（21%份额），全球连续四年第一（17.3%份额），2025年首次包揽陆上、海上、出口"三冠王"。公司正处于盈利修复通道：2026H1风机毛利率11.62%（+3.65pct）验证涨价订单交付逻辑，扣非归母净利润+47.79%。2026年全年归母净利润（中性情景）预计达**44亿元（同比+59%）**，与机构一致预期均值（44.7亿）基本持平。

**自上次研报（7月24日）以来的核心变化**：

1. **半年报落地（公告编号2026-084）**：H1营收337.39亿（+18.23%）、归母净利18.55亿（+24.67%）、扣非20.22亿（+47.79%）；风机毛利率11.62%（+3.65pct）验证修复方向但低于12-14%的预期路径
2. **最大预期差：国际销售毛利率17.79%（同比-0.95pct）**，远低于2025年报与Q1口径的24.29%——海外收入占比升至32.27%的同时盈利质量边际恶化
3. **2026E归母净利从50亿下调至44亿（EPS 1.18→1.04元），收入基数从960亿下修至805亿（与分业务模型勾稽，中性净利率5.5%与H1精确一致）**：H1进度37%偏慢+海外毛利率回落+铜价历史新高三重压制
4. **股价"过山车"**：从17.62元反弹至8/19盘中24.21元（天量94.64亿元长上影），随后三日暴跌24.4%，8/24收于18.30元（较锚点仅+3.9%）——超跌修复的第一波已经兑现
5. **《可再生能源发展"十五五"规划》正式落地（发改能源〔2026〕1067号，7月6日印发、7月23日公布）**：2030风光>28亿千瓦约束性目标、海风新增开工约1亿千瓦，政策框架以部委文件锁定
6. **海风景气缺口**：1H海风并网仅0.84GW、招标-57%，海风贡献推迟至2027年
7. **竞对分化加剧**：Vestas Q2上调指引（EBIT margin 7-9%、股价+18%）确认全球盈利修复；明阳智能H1预告净利暴跌75-84%（官方归因为电站出售进展受阻——对金风风电场转让业务构成同业预警）
8. **EU FSR程序性挫折**：7/20欧盟普通法院驳回暂停调查的临时措施申请（非终局判决，实体审理继续；公司5月29日提起司法审查、6月3日发布声明）
9. **份额回升**：1-7月央国企中标份额14.01%（第三），全口径第一；但7月央国企中标价（不含塔筒1,402元/kW）为主要整机商最低

**五维核心结论：**

1. **行业端**：陆风"量稳价稳"（1-7月招标57.94GW/+3.7%，价格稳定1,600元/kW），海风景气缺口是主要矛盾。"十五五"规划锁定长期需求框架。BNEF预测中国2026年陆风90GW、2027-2030年均92GW。

2. **公司端**：H1销量12,364MW（+16.19%），在手订单54,142MW创新高，海外订单9,489MW（+28.93%，较Q1末小幅回落78MW）。风机毛利率11.62%验证修复；国际毛利率回落是核心瑕疵。绿色甲醇一期Q4交付（马士基50万吨/年+赫伯罗特25万吨/年长协）、储能国际出货+200%构成第二曲线增量。

3. **财务端**：H1综合毛利率16.76%（+1.41pct），减值温和（2.23亿），利息费用-12.7%，经营现金流改善46.5%；合同负债较年初-10.2%需跟踪Q3回补。

4. **估值端**：当前股价**18.30元**（不复权），市值773亿，PE TTM 24.83x（约P65-P70分位），**前向PE 17.6x回到近5年P25上方**。基准目标价19.7元（19x 2026E PE），概率加权目标价20.2元，盈亏比0.30——估值从"极端低估"回归"合理偏低但赔率单薄"。

5. **风险端**：国际毛利率持续下滑、Q4减值黑箱、海风景气缺口、EU FSR实体审理、铜价历史新高。

## 三、研究结论象限图 (Final Evaluation Matrix)

基于**确定性**与**预期收益空间**两个维度，将金风科技定位于以下象限：

```
                    高确定性
                        |
      第三象限          |          第一象限
    (Defensive Value)   |   (High-Conviction Buy)
                        |
       金风科技 ● ------+--------
                        |
                        |
      第四象限          |          第二象限
    (Avoid/Wait)        |   (Speculative Growth)
                        |
                    低确定性
```

### 定位：**第三象限边界——"高确定性、赔率收窄后的防御配置"**（自第一象限边界下调）

**定位理由：**

1. **确定性仍高**：在手订单54,142MW锁定未来约2年收入；十五五规划部委文件落地；全球龙头地位稳固且竞对分化（明阳暴跌/Vestas复苏）强化头部逻辑；H1扣非+47.79%验证经营性改善。

2. **预期收益空间显著收窄**：8月反弹兑现超跌修复第一波（期间最高+37%），EPS累计下调12%，当前+7.7%的中性上行空间与0.30的盈亏比均不足以支撑进攻性仓位——这是自研究启动以来评级首次下调的核心原因。

3. **关键矛盾切换**：7月的矛盾是"市场何时重新定价极端低估"，当前的矛盾是"海外盈利质量与Q4减值黑箱能否证伪中性预测"。前者是时间问题，后者是需要逐季验证的基本面问题。

4. **最优策略建议**：
   - **当前价位（18.30元，前向PE 17.6x）**：防御性底仓持有，不加仓
   - **理想加仓区一**：回踩15-16.5元（前向PE 14.4-15.9x，接近保守情景与历史强支撑区）分批布局
   - **右侧确认加仓**：放量收复MA20（约20.1元）并站稳，叠加Q3数据验证（海风招标恢复+国际毛利率企稳）
   - **止损参考**：跌破12.0元（保守情景价）重新评估全部逻辑
   - **催化事件**：半年报披露（8/26）后的解读、Q3月度装机数据、绿色甲醇Q4交付、海外大订单

### 最终评级：**中性（自"偏正面"下调一级）**

半年报完成了它作为"最关键验证点"的使命：方向上确认了毛利率修复（11.62%），结构上暴露了海外盈利质量恶化（17.79%）与进度偏慢（H1完成原预测37%）。配合股价8月的脉冲式反弹，"高确定性基本面遭遇极端低估"的错配已经收敛——我们据此下调评级至中性。金风科技仍是风电行业中确定性最高的资产，但当下的赔率不支持进攻性配置：等待更好的价格（15-16.5元）或更强的基本面信号（海风恢复+国际毛利率企稳）再行提升仓位。
