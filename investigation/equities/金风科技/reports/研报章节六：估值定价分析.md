# 研报章节六：估值定价分析

**研究日期：** 2026年07月24日

---

## 【逻辑继承：盈利预测引导定价】

模块五中性预测（本轮下调后）：2026E EPS = 1.18 元（原1.37元，因1H装机-24.9%超出预期下调），2027E EPS = 1.50 元。本章基于此进行多维估值定价。

**本轮审计的核心背景**：自6月13日上次审计以来，股价从21.43元暴跌至17.62元（-17.8%），主因为：(1) 1H2026全国风电新增装机38.62GW（同比-24.9%），大幅低于市场预期；(2) 风电板块系统性杀跌（出口+35.6%但板块不涨反跌）；(3) 市场风险偏好下降。但6月单月新增装机13.57GW（同比+166%）已出现强劲恢复信号，全年120GW目标仍有可能。

## 二、适配性估值方法选择

### 2.1 PE估值（权重：40%）

**选择理由**：金风科技盈利波动大但已恢复正向增长，PE仍是最直观的定价工具。

**可比公司PE**（基于2026年一致预期）：

| 可比公司 | 2025PE | 2026PE | 备注 |
| :--- | :---: | :---: | :--- |
| 金风科技 | 23.9x | 14.9x | 全球龙头，前向PE处于历史P10以下 |
| 明阳智能 | ~50x | ~25x | 利润基数极低，PE失真 |
| 运达股份 | ~50x | ~20x | 国内第二 |
| 三一重能 | ~30x | ~18x | 利润下滑中 |
| 维斯塔斯 | ~18x | ~15x | 成熟市场低增长 |
| **可比均值（国内）** | **~43x** | **~21x** | |

**PE估值区间**（基于2026E EPS=1.18元，当前股价17.62元）：
- 悲观(13x)：1.18 * 13 = **15.3元**（-13.2%，低于P10分位15.3x）
- 保守(15x)：1.18 * 15 = **17.7元**（+0.5%，接近历史P10-P25区间）
- **中性(18x)：1.18 * 18 = 21.2元**（+20.3%，接近历史P25-P50区间）
- 乐观(22x)：1.18 * 22 = **26.0元**（+47.6%，接近历史P50-P75区间）
- 激进(25x)：1.18 * 25 = **29.5元**（+67.4%，市场情绪修复）

**中性18x PE的逻辑（较原20x下调2x）**：(1) EPS下调至1.18元（原1.37元），利润基数下降压制估值倍数；(2) 1H装机-24.9%增大了全年业绩不确定性，应给予盈利可预见性折价；(3) 但6月单月+166%的恢复信号表明Q2可能是全年低谷，H2恢复趋势若被验证，估值倍数有望修复。以18x PE计算，目标价21.2元（+20.3% vs现价），较原目标价27.4元下调22.6%。

### 2.2 PB-ROE模型（权重：30%）

**选择理由**：金风科技为重资产制造业，PB-ROE框架天然适配。

- 2025A：ROE = 7.08%，PB = 2.32x
- 2026E：ROE ≈ 10-11%，合理PB ≈ 1.5-2.0x
- 2026Q1末BVPS = 447.08亿 / 42.24亿 = **10.58元**
- 2026E BVPS ≈ 10.58 + 1.00 - 0.20(分红) = **11.38元**
- PB 1.5x → 目标价17.1元；PB 1.8x → 20.5元；PB 2.0x → 22.8元
- **当前PB 1.66x**，处于PB-ROE框架的中性偏低区间

**PB-ROE交叉验证：中性目标价20-21元**。

## 五、逻辑证伪与极限压力测试

### 5.1 "一击毙命"的黑天鹅场景

**定义**：欧洲市场对中国风电企业**全面关闭**，叠加国内装机断崖式下降。

**假设**：
- 海外业务收入从180亿萎缩至50亿（仅保留中东/非洲/南美非敏感市场）
- 国内风机销量降至20GW/年（仅维持存量替换）
- 风电场因电价下跌需计提大规模减值（减值50亿/年）
- 净利润降至亏损边缘（约5-10亿/年）

**地狱价格**（基于清算价值）：
- 净资产（2026Q1末BVPS）≈ 10.58元
- 扣除商誉和无形资产后的有形净资产 ≈ 9.8元
- **极端支撑位：8-10元（后复权约67-84元）**
- 相当于PB 0.8-1.0x，已接近2024-2025年低点（7.92-9.27元）

## 六、最终定价结论

**基准目标价**：**21.2元（不复权）**（对应18x 2026E PE，EPS 1.18元）
**修正目标价**：**21.9元（不复权）**（全变量审计矩阵修正0%）
**保守情景价**：**11.7元（不复权）**（熊市PE收缩+利润不达预期）

**当前价格17.62元，距修正目标价+24.3%上行空间。**

**投资评级**：本轮审计的核心发现是**"高确定性基本面"与"恐慌性抛售"之间的极端背离**。金风科技Q1净利+60%、毛利率>10%、海外在手订单9.57GW创新高、6月国内装机+166%强劲恢复——这些数据指向一个正在兑现的盈利修复故事。但股价在六周内暴跌17.8%（距年内高点-49.8%），已将几乎所有利空（1H装机-24.9%、铜价上行、FSR调查）提前定价甚至过度定价。前向PE 14.9x已进入近5年最低区间，盈亏比0.72为研究启动以来最优。风险在于：(1) H1业绩能否验证毛利率持续修复（8月下旬半年报是关键验证点）；(2) 1H装机数据的全年影响——若H2月均装机超15GW，全年120GW仍可实现；(3) 板块资金流出的负反馈何时结束；(4) Q4减值黑箱规模。当前风险收益比已显著向多头倾斜。
