## 一、产业生命周期与库存节奏

### 1.1 周期定位：AI驱动的成长期爆发

光模块行业正处于**AI算力驱动的高速成长期**，传统的电信/企业网周期叠加了AI数据中心这一全新的结构性增量引擎。

全球AI光模块市场规模（来源：TrendForce/LightCounting）：
- 2025年：165亿美元（Cignal AI报告数据通信光组件收入单独超190亿美元）
- 2026年（预测）：LightCounting 2026年7月已将以太网光模块销售额增速预测上调至**+73%**，并预计2031年市场规模达800亿美元
- 高盛（2026年8月）：2026/2027/2028年全球光模块市场510亿/730亿/690亿美元，其中800G及以上市场CAGR 31%

以太网光模块市场增速：
- 2024年：+93%（历史性爆发）
- 2025年：+82%（持续高增）
- 2026年（预测）：+65%→+73%（LightCounting连续上调）

**周期判定的关键指标**：
- Jefferies（2026年7月专家电话会）：800G缺货约10%、1.6T缺货约30%；2026年800G出货约4,000-4,200万只、1.6T约1,800万只；2027年800G出货冲8,000万只、1.6T约5,500万只——2027年市场规模约为2025年的三倍
- 中报确认公司H1销量1,899万只（同比+109.8%），在手订单覆盖2026全年、部分下到2027年

结论：**行业处于AI算力驱动的高成长期**，且2026年的供给瓶颈比年初预判更持久；但2027年增速换挡是主流机构共识。

### 1.2 库存动力学：供需失衡延续与牛鞭效应倒计时

**当前供需状态**：

InP EML激光芯片短缺不仅未如年初预期"2026年中缓解"，反而在加剧：
- Lumentum公开表示InP交付缺口已扩大至30%以上、"紧缺程度超过同期存储芯片"；其高功率泵浦激光器无限期售罄
- Coherent在FQ4业绩会明确：InP供需失衡"至少将持续整个2026和2027年"，内部InP产能在提前一个季度翻倍后，计划2027年底前再翻倍以上；产能已被合同锁定至2028年、部分至2030年
- 英伟达向Lumentum与Coherent各注资20亿美元锁定扩产，并要求供应链2025-2030年间将InP激光器产能提升约20倍，而上游仅同意规划约12倍（Rosenblatt口径）；2英寸光通信级InP衬底价格2025年初至2026年4月上涨近2倍
- 新增产能（诺基亚收购恩智浦亚利桑那晶圆厂改产InP、JX金属衬底扩产7-10倍等）的释放节点普遍在2027-2030年

**"牛鞭效应"辨析（核心审计）**：

这是一个必须高度重视的结构性风险：

1. **短缺期的过量订购仍在进行时**：LightCounting 2026年8月简报明确指出——"许多供应商报告收入增长加速和创纪录订单，零部件短缺限制增长的同时，double ordering正在推高bookings和对未来的预测"。历史规律表明：当供应商增加产能、短缺缓解后，重复订单消失、价格下降加速。
2. **信号验证**：
   - 中际旭创存货198.26亿元（较上年末+56.3%，较Q1再增26.5%）——公司主动囤料锁定稀缺芯片产能
   - 公司在手订单覆盖2026全年、部分下到2027年，交付计划细化到月度，重点客户已给出2028年新产品指引
   - 但LightCounting同时预警："我们无法预知这种情况（重复订单消失）何时发生"
3. **预判修正**：年初判断的"2026年下半年出现1-2个季度增长停滞期"窗口正在后移——InP产能释放节点普遍指向2027-2030年，意味着短缺溢价和高定价权的持续时间将长于此前预期；真正的牛鞭效应风险窗口更可能出现在2027年下半年至2028年（高盛预测2028年市场规模首次回落：730亿→690亿美元）。届时，当前因短缺而维持的高定价和高毛利率才会面临实质压力。

**结论**：当前订单波动中终端真实需求仍占主导（订单能见度到2027年为佐证），但渠道端double ordering的放大成分正在累积。2027年是检验真实需求强度与消化超额订购的关键窗口期。

## 二、终端需求穿透与跨期断层审计

### 2.1 最终产品画像

中际旭创的光模块产品最终负载于**AI数据中心集群**，具体终端形态包括：
- **云服务提供商（CSP）的AI训练/推理集群**：Amazon AWS、Google Cloud、Microsoft Azure、Meta AI、Oracle Cloud
- **AI模型公司的GPU集群**：OpenAI、Anthropic、xAI等
- **企业级私有AI部署**（远期增量）

光模块在AI数据中心中的角色：实现GPU服务器之间、交换机之间的高速数据传输（Scale-out网络），以及跨数据中心互联（Scale-across网络，使用相干模块）。

### 2.2 终端景气度审计（2026-2028）

**超级CAPEX周期**——四大云厂商2026年资本开支指引（2026Q2财报后最新）：

| 云厂商 | 2025年CAPEX | 2026年CAPEX（最新指引） | 较此前变化 |
|:---|:---|:---|:---|
| Amazon | ~$1250亿 | **~$2200亿**（原$2000亿上调） | +10% |
| Alphabet/Google | ~$950亿 | **$1950-2050亿**（原$1800-1900亿上调） | 上限上调 |
| Microsoft | ~$1000亿 | ~$1750亿（自然年口径，租赁会计调整） | 口径调整 |
| Meta | ~$722亿 | $1300-1450亿（下限上调） | 下限+50亿 |
| **合计** | **~$3810亿** | **~$7200-7450亿** | 持续上修 |

资料来源：各公司2026Q2财报、中信建投/光大证券整理（2026年8月）

**2026Q2实际执行**：四大云厂合计CAPEX达1,712亿美元（同比+94%），其中AWS 542亿、Google 449亿、Microsoft 410亿、Meta 311亿。云业务收入集体加速：Google Cloud +81.8%、Azure +43%、AWS +36.8%（创18个季度新高），AI收入兑现模式日渐清晰。

**2027年前瞻**：摩根士丹利（2026年7月）将五大超大规模云厂商2027/2028年CAPEX预测整体上调至约1.2万亿/1.4万亿美元，可用算力从2025年约30GW增至2028年约120GW（近4倍）。管理层定性信号一致：亚马逊称2026年产能仍不足、2027年同样、2028年订单需求显著；谷歌表示"供给受限"、2027年CAPEX继续大幅增长；谷歌积压订单（RPO）达5,140亿美元。中性情境下2027年CAPEX约8,200亿美元（+12%）——增速显著放缓但绝对值仍增长。

**关键结构性信号**：

1. **需求是合同锁定（Contracted Demand）而非投机**：Google RPO 5,140亿美元，供给紧张延续至2027年的表态来自多家云厂。
2. **推理需求正在成为新引擎**：Dell'Oro指出，2026年以后"推理"将取代"训练"成为更大的CAPEX驱动力。"Token-hungry"推理模型的普及推动长期光互连需求的结构性增长。
3. **光模块在CAPEX中的占比持续提升**：从2025年的2.7%升至2026年的3.1%，预计2031年达4.1%（LightCounting）。即便CAPEX总量增速放缓，光模块仍可通过结构性占比提升维持增长。
4. **国内算力建设接力**：半年报披露2026Q2腾讯资本开支527.8亿元（同比+176%、环比+65%）、阿里巴巴676.78亿元（同比+75%）；公司依托成都智禾的量产能力承接国内400G/800G需求，国内收入稳步增长。

### 2.3 动能溯源与透支审计

**增长动能溯源**：

| 驱动力 | 性质 | 可持续性评估 |
|:---|:---|:---|
| AI大模型训练和推理对算力的需求 | **内生技术驱动力** | 高（token消耗量呈近指数级增长） |
| CSP厂商的GPU军备竞赛 | **内生竞争驱动** | 中高（2027年增速换挡是共识，但绝对值仍在增长） |
| 800G→1.6T代际升级 | **内生技术迭代** | 高（1.6T缺口30%，2027年出货预计翻三倍至5,500万只） |
| 政府补贴/产业政策 | **外生干预** | 低（中国政策有扶持，但核心需求来自北美） |

**跨期需求透支审计（Mandatory）**：

存在以下**需求前置/透支风险**：

1. **GPU供给约束下的"伪需求前置"**：GPU供给不足导致光模块采购被放大。一旦GPU产能释放（预计2027年起加速），光模块需求可能短暂回调。LightCounting提醒："即便是GPU供应链中的一个小故障，都会减少AI集群中其他产品（包括光模块）的需求"——反之GPU超预期交付也会延长光模块短缺。
2. **电力基础设施是隐形天花板**：美国PJM电网容量定价从2023年的$34/MW-day飙升至2026年的$329/MW-day，数据中心建设周期因此拉长（大摩称已拉长至最长3年）。有CAPEX承诺不等于有实际交付能力。
3. **"光模块提前下单"是确定性的透支**：历史数据（LightCounting）证明，短缺期产业链的过量订购会在供需平衡后被消化。当前double ordering仍在进行（LightCounting 8月简报确认），但InP新产能释放集中在2027-2030年，透支消化窗口相应后移至2027H2-2028。
4. **Free Cash Flow恶化与折旧悬崖**：2026Q2 Google/Meta自由现金流转负（-59亿/-76亿美元）；光大证券测算2026年新增算力资产将在2027年起集中抬升折旧摊销（Amazon/Google/Microsoft/Meta年均新增折旧400/325-342/317/227-264亿美元），北美云厂商报表压力自2027年开始显现——这是2027年CAPEX增速换挡的核心财务约束。
5. **光模块销售额领先CAPEX拐点约6个月**（LightCounting历史规律）：需从2027年下半年起严密监测北美云厂CAPEX指引的边际变化。

**结论**：当前增长中真实结构性需求仍占主导（订单能见度到2027年、1.6T缺口30%），但周期性透支正在累积且消化窗口后移至2027H2-2028。2027年是验证"真需求"vs"伪需求"的关键时间窗。

## 三、供需边际与压力传导

### 3.1 供需平衡审计

**供给侧**（光模块行业整体）：

- InP EML激光芯片产能：**仍是最大瓶颈且缓解时点后移**——Lumentum交付缺口>30%，Coherent称失衡至少贯穿2026-2027年，新产能（6英寸InP产线、诺基亚/JX金属跨界扩产）释放节点普遍在2027-2030年；中国200G EML国产替代（长光华芯计划2026Q4量产、源杰科技推进量产准备）尚处验证期
- 光模块组装产能：公司2026H1产能2,215万只（同比+90.8%）、在建工程37.07亿元（+161%），苏州/铜陵/成都/台湾/泰国基地同步扩建；H股募资30%用于全球产能扩充
- 泰国等海外产能：海外产能占比约七成（2025年约1,991万只 vs 中国约815万只），2026Q1海外产能利用率87.3%
- **CPO进入全面量产阶段**：英伟达于2026年8月14日宣布Spectrum-X以太网硅光CPO交换机全面量产（全球首款200G/lane CPO交换机，首批部署CoreWeave/Lambda/甲骨文），博通51.2T Bailly持续出货——机柜内最短距互连层开始被CPO替代；但光引擎良率、先进封装产能与外置光源（ELS）供给仍限制其放量斜率

**需求侧**：

- 2026年四大云厂CAPEX指引合计7,200-7,450亿美元（同比+~90%），大摩预测2027年五大云厂约1.2万亿美元
- LightCounting 2026年预测增速上调至+73%；Jefferies测算800G缺货10%、1.6T缺货30%
- 公司订单能见度：在手订单覆盖2026全年、部分下到2027年，重点客户给出2028年新产品指引

**供需预判**：

| 时间段 | 供需状态 | 对毛利/定价的影响 |
|:---|:---|:---|
| 2026H1 | **严重供不应求**（InP缺口>30%） | 已验证：光模块毛利率46.59%创新高 |
| 2026H2 | **短缺延续**（InP失衡至少贯穿2026全年），CPO开始上量但良率受限 | 定价权维持，毛利率高位有支撑 |
| 2027 | **供给渐进释放**（6英寸InP产能翻倍落地），需求增速换挡（CAPEX +12%~30%） | 价格年降恢复常态（10-15%/年），毛利率温和回落 |
| 2028+ | **再平衡风险窗口**（高盛预测市场规模首次回落）+ CPO规模放量 | 牛鞭效应消化+技术路线重构双重考验 |

### 3.2 压力传导特征分析

中际旭创处于产业链中游（光模块组装/设计），压力传导呈现以下特征：

**上游压力传导**（光芯片、电芯片供应商）：
- InP EML芯片供应商集中度高（美日三强主导200G EML），议价能力强（年报显示第一供应商占比35.76%）
- 芯片短缺+衬底涨价（2英寸InP衬底2025年初至2026年4月涨近2倍）→成本上行压力真实存在
- 但公司通过硅光路线降低对EML的依赖（硅光仅需2-4颗CW激光器 vs EML方案8颗），半年报确认"通过提供硅光方案、EML方案等多元化解决方案……提前锁定供应链产能"——这是对冲手段，也是46.59%毛利率的重要来源

**下游压力传导**（CSP客户）：
- **定价权向上游厂商倾斜（当前周期）**：供不应求下光模块供应商享有强定价权，光模块毛利率从39.96%（2025H1）升至46.59%（2026H1）
- **定价权向客户回归（供需平衡后，预计2027年起）**：CSP集中度极高（前5大客户占收入75.98%），当供给充裕后客户议价能力会快速回升
- **量增可对冲价降**：800G→1.6T代际切换时，新一代产品可维持更高ASP；1.6T硅光模块出货量逐季攀升

**波动放大效应**：

光模块在中游面临**双重放大**：
1. **上游短缺放大**：光芯片短缺→提前囤货（存货198亿元）→短缺缓解后消化库存→需求"断崖"
2. **下游CAPEX调整放大**：CSP削减10%CAPEX → 光模块订单可能削减20-30%（因去除重复订单部分）

**传导时滞**：约1-2个季度。LightCounting历史规律显示光模块销售额领先CAPEX拐点约6个月转负。

## 五、模块二核心结论

1. **行业处于AI驱动的超级成长期且强度超预期**：LightCounting将2026年增速预测连续上调至+73%，Jefferies预计2027年市场规模为2025年的三倍；但2027年增速换挡（CAPEX从+70%放缓至+12%~30%）是主流共识。
2. **2026H2短缺溢价延续**：InP/EML失衡至少贯穿2026-2027（Coherent原话），新产能集中在2027-2030年释放——年初"2026年中缓解"的假设已被证伪，高定价权的持续时间长于此前预判。
3. **牛鞭效应倒计时后移而非消失**：double ordering正在推高bookings，透支消化窗口指向2027H2-2028；届时存货198亿元的库存结构与当前高毛利率将同步承压。
4. **终端CAPEX增速与云厂FCF的矛盾在积累**：Google/Meta自由现金流已转负，2027年折旧集中抬升构成CAPEX财务约束——这是2027年需求端最大的下行变量。
5. **光模块在CAPEX中的结构性占比提升（2.7%→4.1%）**是抵御CAPEX总量放缓的缓冲垫；国内算力建设（腾讯/阿里Q2 CAPEX翻倍级增长）提供第二增长极。
6. **"电力瓶颈"比"芯片瓶颈"更值得关注**——它决定CAPEX承诺能有多少真正转化为实物需求。

---

*此结论直接影响模块五的盈利预测——Base场景中2026H2毛利率维持45-46%高位（短缺溢价延续），2027年起纳入价格年降恢复与牛鞭效应消化；Bear场景考虑2027年CAPEX减速与去库共振的可能性。*
