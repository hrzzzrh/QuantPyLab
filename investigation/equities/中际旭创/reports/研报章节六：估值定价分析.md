## 一、价值锚定：适配性方法选择

### 1.1 方法论工具箱评估

| 方法 | 适用性 | 选择理由 |
|:---|:---:|:---|
| **PE（市盈率）** | ★★★★★ | 公司盈利稳定且持续增长，PE是最直观和广泛使用的锚 |
| **PEG（成长性估值）** | ★★★★ | 适用于高成长阶段，补充PE的静态缺陷 |
| **PB-ROE** | ★★★ | 公司资产较轻，PB参考价值有限 |
| **DCF（现金流折现）** | ★★ | 光模块行业周期性极强，远期自由现金流预测误差极大 |
| **EV/EBITDA** | ★★★ | 公司债务极少，EV与市值接近，增量信息有限 |
| **SOTP（分部估值）** | ★ | 公司99%收入来自光模块，无需分部 |

**选择结论**：以 **PE（前瞻）** 为主要锚定方法，辅以 **PEG** 交叉验证，以 **历史分位** 为背景校验。

### 4.2 盈亏比计算

**公式**：盈亏比 = (概率加权目标价 - 现价) / (现价 - 保守场景价)

- 概率加权目标价：**857元**（09-11前为853元按旧股本口径513/848/1,137推导，差异系股本口径统一至11.779亿股）
- 现价：**808.44元**（2026-09-30，视图实测；节后10-08为783元）
- 保守场景价：**510元**（20.38×25）

**盈亏比（09-30锚）** = (857 - 808.44) / (808.44 - 510) = 48.56 / 298.44 = **0.16**；**09-11前为-0.14（902.37元锚），本次由负转正主因：①股价-10.4%回调（902.37→808.44，分母收窄、分子转正）+②FCC窄口径使地缘折价-11%→-8%、综合调节-3%→0%、中性目标838→859元上修**

**盈亏比（10-08节后锚，补充）** = (857 - 783) / (783 - 510) = 74 / 273 = **0.27**；**节后回调使赔率从0.16→0.27进一步改善**

**解读**：盈亏比首次转正（09-30为0.16，10-08为0.27），主因股价回调与FCC窄口径共同驱动；但**0.16-0.27仍处于"安全垫偏薄"区间（远低于1.0重仓阈值与1.5理想阈值）**，利好（英伟达Q2 96.22B/Vera Rubin全面量产、新易盛终局209.1亿/75.29亿、TrendForce 8300亿、FCC窄口径）已被Base 316亿/26.84元假设充分隐含，不构成对EPS的机械上修。评级无法上调至"买入"的核心原因仍是：①修正目标859元较09-30仅+6.3%上行、加权857元较09-30仅+6.0%上行，安全垫约49-51元；②经营现金流/净利润0.13（Q2单季转负）与新易盛0.22的对比显示质量瑕疵需Q3验证；③CPO价值链重构（供应链排除可插拔厂）的折价未解除。**若Q3现金流回正+存货去化验证，且股价维持750-850元区间（Forward PE 27.9-31.7x），赔率将随业绩兑现而增厚；技术面09-30已跌破全部均线（见第七章），应等待企稳信号再决策**。

### 5.1 黑天鹅场景模拟

### 5.2 压力情景一：毛利率回归历史均值

若2027年毛利率从46%滑落至35%（类似2024年水平），其他条件不变：
- 2027E净利润从350亿降至约250亿以下，EPS从29.72降至约21.4元
- 对应25x PE的股价：535元（较现价约-43%）

1. **估值实现"股价回调+FCC窄口径"双重消化与修复**：PE(TTM)从52.0倍（09-08）收敛至46.56倍（09-30，PB 23.89倍）、Forward PE从33.6倍收敛至30.1倍——09-30较09-08再回调-10.4%（808.44 vs 902.37）叠加TTM分母稳定于204.53亿；节后10-08进一步至45.09倍/ Forward 29.2倍（783/26.84），**由"偏高"向"合理偏高"靠拢**。
