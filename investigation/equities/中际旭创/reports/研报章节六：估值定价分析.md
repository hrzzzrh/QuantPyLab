## 一、价值锚定：适配性方法选择

### 1.1 方法论工具箱评估

| 方法 | 适用性 | 选择理由 |
|:---|:---:|:---|
| **PE（市盈率）** | ★★★★★ | 公司盈利稳定且持续增长，PE是最直观和广泛使用的锚 |
| **PEG（成长性估值）** | ★★★★ | 适用于高成长阶段，补充PE的静态缺陷 |
| **PB-ROE** | ★★★ | 公司资产较轻，PB参考价值有限 |
| **DCF（现金流折现）** | ★★ | 光模块行业周期性极强，远期自由现金流预测误差极大 |
| **EV/EBITDA** | ★★★ | 公司债务极少，EV与市值接近，增量信息有限 |
| **SOTP（分部估值）** | ★ | 公司97.95%收入来自光模块，无需分部 |

**选择结论**：以 **PE（前瞻）** 为主要锚定方法，辅以 **PEG** 交叉验证，以 **历史分位** 为背景校验。

### 2.3 三态市值计算

采用**PE法 + PEG法交叉验证**：

**方法一：PE法**
- 2026E EPS：27.01元（Base场景，按H股发行后11.6973亿股计算）
- 合理PE倍数讨论：
  - 保守（行业回归成熟期）：25x → 675元
  - 中性（成长期龙头合理估值）：**30-35x** → 810-945元
  - 乐观（AI超级周期延续+EML短缺溢价）：35x → 945元
- **中性情景PE取32x**（反映龙头溢价+高增长+中等不确定性，维持不变）
- **中性情景未调节目标价：864元，未调节市值：10,112亿元**

**方法二：PEG法**
- 2025→2026E净利润增速：+193%（上调）
- 2026→2027E净利润增速：+13%
- 两年复合增速：~82%
- PEG=1.0对应PE=82x（按两年CAGR）
- PEG=0.5对应PE=41x（按两年CAGR）
- **取PEG=0.40-0.45**（光模块行业的周期风险+2026H2不确定性要求折价）：PE=33-37x
- **中性情景交叉验证目标价：937-1,050元**

**中性情景交叉验证**（PE法为主、PEG为交叉验证）：PE 32-35x × EPS 27.01 = **864-945元**。

| **概率加权目标价** | — | — | **862.2元** |

### 4.2 盈亏比计算

**公式**：盈亏比 = (概率加权目标价 - 现价) / (现价 - 保守场景价)

- 概率加权目标价：862.2元
- 现价：902.01元
- 保守场景价：455元

**盈亏比** = (862.2 - 902.01) / (902.01 - 455) = -39.81 / 447.01 = **-0.09**

**解读**：当前价格下，概率加权目标价仍低于现价，盈亏比为负。相较5月，股价回调改善了安全边际，但H股发行的确定性摊薄同步下调每股估值；在正式半年报披露前，尚不足以将评级转为买入。

## 五、逻辑证伪与极限压力测试

### 5.1 黑天鹅场景模拟

**定义"一击毙命"事件**：美国将DSP芯片列入对华出口管制清单，Broadcom/Marvell被禁止向中际旭创供应DSP。

**后果推演**：
- DSP芯片短期无替代方案（Credo仅覆盖部分LPO短距场景）
- 800G/1.6T模块中DSP是不可或缺的核心芯片
- 公司可能在6-12个月内耗尽库存DSP，营收将断崖式下跌
- 尽管可加速硅光+LPO路线转型，但客户认证和产能切换需要18-24个月

**极限支撑位（清算价值法）**：
- 2026Q1归母净资产：355.87亿元
- 每股净资产（BVPS）：30.42元（355.87亿/11.6973亿股；未计H股募资到账后的净资产增加）
- 扣除商誉19.39亿后的有形净资产：336.48亿元，**有形BVPS：28.77元**（同一股本口径）
- **极限"地狱价格"：30-50元**（假设纯清算价值——事实上公司作为全球龙头，即使遭遇芯片管制也极大概率被收购或获得应急许可，真实破产概率极低）

### 5.2 压力情景一：毛利率回归历史均值

若毛利率从43.5%滑落至35%（类似2024年水平），其他条件不变：
- 2026E净利润从316亿降至约260亿，EPS从27.01降至约22.23
- 对应20x PE的股价：445元（较现价约-51%）

**这揭示了当前估值最大的脆弱性——对毛利率假设高度敏感。**

## 六、模块六核心结论

1. **当前定价（902.01元/PE TTM 70.6倍）已较5月回落，但修正Base目标价847元仍低于现价**。H股发行将总股本增至11.6973亿股，令2026E Base EPS由28.38元调整为27.01元；股价回调与每股摊薄共同决定当前估值位置。
2. **盈亏比仍为负（-0.09）**。相较5月的-0.21已有改善，但尚不构成足以支持建仓的安全边际；保守场景价455元对应较现价约49.6%的下行风险。
3. **估值最大的脆弱点仍是毛利率假设**。当前43.5%的全年毛利率假设包含大量"短缺溢价"成分，而EML短缺虽比此前预判更持久，但终将消退。
4. **最大的尾部风险仍是芯片管制**——虽然概率仅~15%，但一旦发生，股价可能跌至30-50元区间。
5. **估值分位仍偏高**：TTM PE 70.6倍处于近五年80.6%分位、PB 29.6倍处于95.3%分位。Forward PE 33.4倍虽接近长期中枢，但市场仍充分定价了2026年的增长与高毛利率。
6. **建仓区间维持750-850元（Forward PE约27.8-31.5x）**，以防范2026H2需求、ASP与毛利率验证风险。当前价已接近而非显著高于该区间上沿，仍应等待半年报或更明确的安全边际，避免以“价格回落”替代基本面验证。
