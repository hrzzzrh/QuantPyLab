# 研报章节六：估值定价与全变量风险对冲

**研究日期**：2026年8月25日
**研究标的**：立讯精密（002475.SZ）
**现价基准**：53.72 元（不复权收盘价，2026-08-24）；总市值 4,156.76 亿元；总股本 77.38 亿股（A+H，含2026年7月H股发行及部分行使超配）

---

## 1. 价值锚定：适配性方法选择

### 1.1 方法论选择理由

| 方法 | 适用性判定 |
| :--- | :--- |
| **PE（主方法）** | 公司盈利为正且连续十年增长、盈利虽含非经成分但可常态化校正；制造业可比公司均以PE定价。分母采用第五章三态归母EPS（已用发行后总股本77.38亿股统一口径） |
| **PB-ROE（交叉验证）** | ROE 连续四年站稳21%（H股募资后前瞻ROE将被稀释至约16%，见1.3节），资产重（固定资产659亿+有息负债1,371亿），PB-ROE能检验PE结论是否脱离资产回报现实 |
| SOTP（辅助） | 三大业务属性差异大（组装/汽车/AI互联），用于检验整体倍数隐含的板块结构 |

DCF不作为主方法：公司自由现金流近年波动剧烈（OCF-TTM自2025Q3高点连续三期回落至165亿）且处于高资本开支周期，远期现金流预测置信区间过宽，强行折现只会制造虚假精度。

### 1.2 历史分位审计（系统视图实测）

- 当前 PE-TTM 24.14x，处2016年以来**21.7%分位**（中位数33.51x，Q1分位24.98x）；当前 PB 4.68x，处**6.2%分位**（中位数7.27x，P10为4.96x）。口径注记：系统pe_ttm分母为含少数股东损益的净利润TTM（实测对应归母口径约23.4x），本章三态倍数基于归母EPS，两者存在约3%的口径差，不影响分位结论；
- 关键历史坐标：2025年4月9日极端底部市值2,079亿元（PE 16.43x/PB 3.95x），同年6月初进一步探至 **PB 3.72x**（历史最低）；2026年5月13日高点5,840亿（PE 33.92x）；
- **审慎使用声明**：历史中位数33.51x形成于"iPhone单极驱动+移动互联网渗透红利"时代，与当前"低毛利组装占比更高+增速降档+盈利质量下滑"的基本面不可比；而2018年（贸易战底23.85x）、2022年（底部23.04x）的危机估值更具参照性——两轮极端压力下市场给到约16-24x。**本报告将中性倍数锚定在22x（低于Q1分位24.98x），而非机械套用历史中位数。**

### 1.3 H 股发行后的 PB-ROE 口径重建（2026年7月新增变量）

公司2026年7月9日H股上市净筹约240.39亿港元（约合人民币223亿元），对PB-ROE验证产生双重影响，必须显性处理：

- **BVPS 重估**：2026年末归母净资产 ≈ 936.08（2026H1末实测）+ H2归母利润117.6 + 募资净额≈223 − 年内已付分红26 ≈ **1,251亿元，BVPS ≈ 16.2元**（发行前口径仅约12.9元）；
- **ROE 稀释**：2027E前瞻ROE ≈ 220 ÷ 平均净资产约1,357亿 ≈ **16.2%**（募资前为21%）；
- 含义：H股募资是"以回报率换弹药"的资本运作，若募投项目边际资本回报率低于16%，则摊薄不可逆；若高于（AI/汽车产能爬坡情景），则为下一轮ROE回升蓄力。该变量使PB维度的"低分位"部分失真——PB 4.68x的分母尚未包含募资增厚，动态PB实际更低，但这属于杠杆结构变化而非经营改善，**不应据此上调估值**。

## 2. 三态情景市值（盈利 × 倍数，向下取整至十亿位）

估值锚点规则：当前为Q3，锚定**2026年当年EPS**（第五章三态输出）。

| 情景 | 2026E归母净利 | EPS(元) | 情景PE | 倍数取值理由 | **情景市值（亿元）** | 对应股价（元） |
| :--- | ---: | ---: | ---: | :--- | ---: | ---: |
| 保守 | 145亿 | 1.87 | 17x | 盈利下修周期的危机估值带（2025极端底15.77-16.43x上方留缓冲，低于2018/2022危机底）：砍单+价格战+汇率三击定价 | 145×17=2,465→**2,460** | **31.80** |
| 中性 | 196亿 | 2.53 | 22x | 低于十年Q1分位24.98x：反映增速降档与盈利质量折价后的"新常态中枢" | 196×22=4,312→**4,310** | 55.70 |
| 乐观 | 228亿 | 2.95 | 26x | 接近2020-21高增长中枢下沿但留安全边际（乐观盈利已高，倍数不给满28x） | 228×26=5,928→**5,920** | **76.50** |

**PB-ROE交叉验证（中性）**：中性PE 22x × 前瞻ROE 16.2% = 合理PB约3.56x × BVPS 16.2元 ≈ **57.7元**，与PE法55.70元（调节前）偏差<5%，两法互证通过。（若错误地沿用募资前旧BVPS 12.9元与旧ROE 21%，将得出PB法66元与PE法55元的假性背离——这正是H股事件必须纳入模型的理由。）

**SOTP辅助验证（中性）**：消费电子91.4亿×18x + 汽车28.3亿×25x + 通讯27.6亿×30x + 其他7.6亿×10x + 非经营净贡献50亿×5x ≈ **3,510亿元**。SOTP较整体法（4,310亿）低约18.6%，缺口即市场给予的整体平台溢价与多元化协同定价——它提示：若AI板块获得更激进的独立定价（通讯板块30x→40x），SOTP可上移至4,200亿量级与整体法收敛；反之若平台叙事退潮，SOTP就是更诚实的下限参照。

## 3. 估值全变量对冲审计矩阵（仅作用于中性档）

| 审计维度 | 核心审计因子 | 审慎思考（估值影响力过滤） | 调节 | 深度理由（PE贴现维度） |
| :--- | :--- | :--- | :---: | :--- |
| **内部：企业底层特质** | 平台化并购整合执行力（Leoni提前达标[证据E7]、闻泰ODM承接、H股融资通道打通）；41.6万员工四线作战的组织能力 | 辨析：执行力已体现在收入结构升级(E)中，但"持续获得链主授权+持续获得低成本资本"的双重组织稀缺性未被单独定价——A股万亿以下制造平台中仅此一家同时深度嵌入Apple+NVIDIA生态并完成AH双平台布局。剔除平庸的优秀后，保留稀缺性溢价 | **+2%** | 提高长期现金流的实现确定性，等效降低股权风险溢价 |
| **宏观：政策与战略对齐** | AI算力国家战略、中国制造出海标杆叙事 | 辨析：立讯AI收入几乎全部来自北美客户，国内产业政策不构成其定价权来源；"出海标杆"是媒体叙事而非现金流因子。**典型"平庸的关联"，调节为零** | **0%** | 无实质影响 |
| **宏观：地缘与外部约束** | ①中美科技脱钩尾部风险（AI业务理论清零场景）；②关税摇摆的经营摩擦；③印度iPhone分流的结构性挤压；④美伊冲突/霍尔木兹局势对航运成本与油价的传导 | 辨析：①②属不可量化但真实的尾部约束——第二章已论证光模块销售领先capex拐点6个月转负的行业规律叠加地缘变量，使公司远期现金流的方差显著大于表观波动；③已在E的消费电子收入上限中体现，不重复扣除；④经评估对消费电子供应链的影响以成本加成形式滞后传导，幅度有限且已在存储涨价传导中覆盖，不单独计价。合计给予温和折价而非恐慌性折价 | **-5%** | 将不可量化的地缘焦虑显性化为约0.5x PE的风险扣除 |
| **市场：流动性与风格** | AI硬件行情的风格契合；AH两地上市后的指数纳入与期权工具（港交所已推立讯期权）；果链白马的机构持仓基础 | 辨析：风格契合真实存在（公司是AI算力硬件直接受益标的）但本质是贝塔而非阿尔法——一旦AI资本开支预期降档，风格资金撤离速度与其进入速度对称；AH上市带来南向资金增量与衍生品流动性，属结构性小幅正面。给予克制的净溢价 | **+2%** | 阶段性流动性溢价，计入但不外推 |
| **综合调节系数** | —— | —— | **Σ=-1%** | —— |

**修正目标市值（仅中性档）= 4,310 × (1 − 1%) = 4,266.9 → 向下取整 4,270 亿元，对应股价 55.18 → 55.20 元。**
（保守/乐观情景市值不叠加调节：2,460亿元/31.80元 与 5,920亿元/76.50元 维持原值。取整规则声明：全部情景市值一律向下取整至十亿位，避免人为抬高锚点。）

## 4. 逻辑纯净性校验（Consistency Guardrails）

| 因子 | 归属 | 校验说明 |
| :--- | :---: | :--- |
| 汇兑损失25亿假设 | E | 具体可计算的金额，进利润预测 ✅ |
| 存储涨价压价对毛利率影响 | E | 可量化至毛利率0.x pct级别 ✅ |
| Leoni改善 | E | 已体现在汽车板块毛利率14.5%假设中 ✅ |
| H股募资的利息收入 | E | 已计入财务费用假设（利息净额11亿）✅ |
| 地缘脱钩尾部 | PE | 不可计算概率的事件，进倍数折价 ✅ |
| 杠杆率上升 | PE | 利息已进E，但杠杆带来的不确定性进PE折价（含于-5%地缘项与22x低倍数中，不重复）✅ |
| ROE稀释 | PE | H股募资摊薄已通过前瞻ROE进入PB-ROE验证，不再作为独立扣减项 ✅ |
| AI增长动能 | E+PE各一次 | 收入端只计2026当年增量；22x/30x倍数是对持续增长能力的定价——属于"当期业绩×长期能力"的标准框架，非重复计算 ✅ |

**锚点回测**：修正后隐含综合PE = 4,270亿 ÷ 196亿 ≈ 21.8x。该值显著低于十年中位数33.51x，需给出商业逻辑支撑：①公司净利率约4.75%（vs 中位数时代的6%+），单位收入创造利润的能力下降；②ROIC五连降至10.93%，增量资本的回报质量恶化；③第一大客户集中度56.68%在AI多元化叙事下仍未实质改变。三个结构性事实支持估值中枢系统性下移，21.8x不是情绪折价而是质量重定价。反之，若2027年出现"汇兑正常化+扣非增速回到15%+"的组合，估值向24.98x（Q1分位）修复即对应约14%的额外上行，该期权价值已隐含在乐观情景中。

## 5. 确定性与胜率矩阵

### 5.1 三态概率赋值

| 情景 | 发生概率 | 赋值依据 |
| :--- | :---: | :--- |
| 保守 | 15% | 需要"砍单兑现+汇率再恶化+集中减值"三要素叠加，历史上仅2018H2级别冲击可比 |
| 中性 | 60% | 终端景气与订单可见性支持基准路径；H1实绩已锁定全年近四成 |
| 乐观 | 25% | 折叠屏/CPC/Leoni三选二超预期即可触发 |

### 5.2 目标价合成与盈亏比

- **三态目标价**：保守 **31.80 元** ／ 中性 **55.20 元**（审计修正后）／ 乐观 **76.50 元**
- **加权目标价** = 15%×31.80 + 60%×55.20 + 25%×76.50 = 4.77 + 33.12 + 19.13 = **57.02 → 57.00 元**
- 现价 53.72 元（不复权，2026-08-24）
- **期望收益空间** = 57.00 ÷ 53.72 − 1 = **+6.1%**
- **盈亏比** = (加权目标价 − 现价) ÷ (现价 − 保守目标价) = (57.00 − 53.72) ÷ (53.72 − 31.80) = 3.28 ÷ 21.92 ≈ **0.15**

**盈亏比的诚实解读**：分子（期望收益）薄、分母（下行距离）厚，当前价位的风险报酬结构明显不利。这不是看空基本面的信号——中性情景仍有静态空间且基本面引擎评分高——而是"好公司≠好价格"的定量表达：市场当前定价已经贴近甚至略超我们的中性锚，超额收益必须依赖乐观情景兑现或以更低价格积累筹码。

## 6. 逻辑证伪与极限压力测试

### 6.1 黑天鹅场景定义（一击毙命事件）

**"链主双重背弃"情景**：Apple 因印度产能成熟+成本谈判将立讯 iPhone 组装份额从~27%压缩至15%以下，同时 NVIDIA 平台切换互连方案（CPO 全面替代铜连接/CPC）导致电连接价值量断崖——两大核心授权同时失效。此情景下消费电子收入-20%、通讯板块收入-40%，2027E归母净利润降至约110亿元量级。

### 6.2 极限支撑位审计（地狱价格）

- 清算/重置视角：2026H1末归母净资产936亿元（BVPS约12.1元，未含7月H股募资）；含募资后年末BVPS约16.2元。极端情景下市场对重资产代工商的定价下限参考2025年实际触及的3.72x PB（2025年6月历史最低）——但那是正常经营年份的恐慌底，黑天鹅情景应按更严口径；
- 盈利视角：黑天鹅情景净利110亿 × 危机估值14x ≈ 1,540亿元；
- 净资产视角：1.5x PB × 16.2元 ≈ 24.3元/股 ≈ 1,880亿元（此为含弹药口径，偏宽）；
- **地狱价格区间：1,500-1,550亿元市值，对应股价约 19.4-20.0 元（取整表述约19-20元，较现价约-63%）**。
- 极端情形提示：该价格仅在"双重背弃+系统性危机"共振时可见，其功能是风险管理的终极锚点而非可等待的目标买点；常规熊市的历史极限参考为2025年4月的2,079亿元市值（26.9元，彼时PB 3.95x）与6月的PB 3.72x极值。

---

*本章结论一句话版：中性修正目标市值4,270亿元（55.20元/股），三态31.80/55.20/76.50元，概率加权目标价57.00元，较现价+6.1%，盈亏比0.15——定价已贴近合理中枢且下行距离深厚，风险报酬比不支持激进建仓，属于典型的"优质但不便宜"；H股募资重塑了净资产与ROE坐标，任何沿用旧BVPS的估值讨论均已失效。*
