## 1. 预测方法论声明

严禁基于机构一致预期倒推。本章采用"双轨互证"架构：

- **主轨（半年度锚定法）**：以2026H1已审计实绩为硬约束，对H2做分业务驱动的净利率推演；
- **辅轨（利润表桥法）**：自营业收入向下逐科目构建全年利润表桥，确保每个数字可复现、可证伪；
- 两轨结果偏差须<3%方可采信，最终以SOTP分部算法做结构透视。

所有核心假设标注证据来源编号（索引见第8节）。**基期实测数据（系统视图+财报原文）**：

## 5. SOTP 分部模拟净利（勾稽校验，参数全部可复现）

采用框架公式 `板块模拟净利_i = 板块营收_i × [板块毛利率_i − 总期间费用率 × K_i] × (1 − 有效税率)`：

**统一参数**：总期间费用率 = 312/4,125 = **7.56%**；有效税率 **9%**（留存系数0.91）；少数股东损益在汇总后单列说明。

| 板块 | 2026E营收 | 板块毛利率 | K值 | K依据 | 模拟净利（亿元） |
| :--- | ---: | ---: | :---: | :--- | ---: |
| 消费电子 | 3,050 | 10.85% | 1.0 | 成熟标准化制造 | 91.4 |
| 汽车电子 | 667 | 14.50% | 1.3 | 高整合难度成长期业务（Leoni重组中） | 28.3 |
| 通讯及数据中心 | 360 | 17.50% | 1.2 | 高研发强度成长业务 | 27.6 |
| 其他 | 48 | 25.00% | 1.0 | 混合制造 | 7.6 |
| **经营性板块小计** | | | | | **154.9** |
| 非经营性净贡献 | | | | 投资收益及其他81+营业外1−减值18−税金及附加14 | **+50.0** |
| **净利润总额合计** | | | | | **≈204.9** |

**勾稽校验**：SOTP合计204.9亿 vs 利润表桥净利润总额212亿（233×0.91），**偏差3.3%**——源于汽车（K=1.3）与通讯（K=1.2）板块的费用超额分摊设计（合计多摊约21.5亿费用），方向与幅度均可解释，**勾稽视为通过**。扣除约8%少数股东损益后，SOMP隐含归母约188亿，与主轨196亿的差距即为K值分摊的保守余量。

## 7. H 股发行对盈利模型的渗透影响（2026年7月新增变量）

公司于2026年7月9日完成H股上市（代号2475.HK），全球发售净筹约240.39亿港元（约合人民币223亿元，按0.93汇率估算）。对本章模型的传导：

1. **财务费用对冲**：募资现金入账后，按2%存款利率估算年增利息收入约4.5亿元，已体现在财务费用假设中（利息净额11亿而非15亿）；
2. **净资产增厚**：2026年末BVPS预计升至约16.2元（详见章节六PB-ROE验证），ROE将被被动稀释约3-4pct——这是"以回报率换弹药"的标准并购前置动作，其成败取决于募投项目（AI产能与汽车电子）的边际资本回报率能否高于16%的被稀释前水平；
3. **EPS 口径**：本章EPS一律使用发行后总股本77.38亿股，不存在新旧股本混用问题。
