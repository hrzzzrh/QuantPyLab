## 一、投资摘要

### 1.1 核心投资逻辑（2026年11月）

伯特利是国内汽车线控制动自主龙头，具备"传统制动→One-Box EHB→EMB→全域智能底盘（XYZ+ADAS）→机器人零部件"完整路径。2026前三季度营收105.47亿（+26.20%）、归母10.30亿（+15.51%），但Q3单季营收+33.86% vs 归母+5.17%，呈现"增收不增利"。**核心矛盾从"增长能否验证"切换为"利润率能否止跌"**：

| 事件 | 方向 | 重要性 | 最新评估 |
| :--- | :--- | :--- | :--- |
| 2026三季报（10-29） | **收入强/利润弱** | ★★★★★ | 营收+26.2%/Q3+33.9%，归母+15.5%/Q3+5.2%，归母净利率9.76%/Q3 9.08% |
| 新定点年化104.99亿（+44.79%） | **强利好** | ★★★★★ | 在研934项/+74.25%、WCBS新增量产60项/+106.9%，2027-2028收入可见度高 |
| EMB 1+4整车厂定点（9-30） | 积极 | ★★★★ | 理想量产后新增4家，Q3出货明显增长；但ASP受3488元/套压制 |
| 铝价10月回落（23,690元/吨，-2.33%） | 积极 | ★★★ | Q4成本压力缓解，毛利率20.33%（Q3）已部分体现 |
| 豫北并表（6月起） | 中性偏负 | ★★★★ | 营收+18.7亿（2026E），但前三季度少数股东损益仅0.09亿，利润贡献薄于预期 |
| 人民币偏强/汇兑损失 | 负面 | ★★★ | 前三季度财务费用0.92亿（去年-0.14亿），汇兑损失约0.4-0.5亿 |
| 9月零售-28.0%/10月-26% | 负面 | ★★★★ | 终端趋势性下台阶，2026年零售约-22%~-24% |
| USMCA年度审查延续 | 负面但未新增 | ★★★★ | ITC报告2027-07-01前提交；墨西哥组装件临时免关税仅边际缓和 |
| H股聆讯停滞 | 负面 | ★★★ | 截至10-31无聆讯/回复公告，稀释与合规压力未解 |

**净影响**：收入与订单逻辑仍强（新定点104.99亿），但利润率下台阶（归母净利率9.76%→2027E 8.89%）使2027E盈利下修11.5%。**估值已跌至PE 15.57x（历史最低附近），市场定价接近"零增长"，而基准仍是+13.0%——这是"降速"与"极低估值"的错配，而非"逻辑破坏"。**

### 1.3 多空力量对弈（2026年11月）

**多头逻辑（估值底+订单强）**：
1. **估值处于历史绝对底部**：PE 15.57x距全量最低15.52x仅0.3%，PB 2.61x显著低于P10 4.25x；2027E Forward PE 13.7x
2. **订单储备创历史新高**：新定点年化104.99亿元（+44.79%项数），在研934项（+74.25%），WCBS新增量产60项（+106.9%）
3. **收入端份额逻辑仍强**：Q3营收+33.86%（剔除豫北并表后内生约+8.8%），在零售-28%的环境下仍跑赢；智能电控销量+42.7%、机械转向+62.9%
4. **毛利率企稳向上**：19.80%（+0.48pp）、Q3 20.33%为2026年内单季新高（同比-0.22pp）；铝价10月回落
5. **EMB多点定点**：理想量产后新增4个整车厂定点，获理想"技术创新奖"，从"单一客户"走向"平台化"

**空头逻辑（利润率下台阶）**：
1. **增收不增利**：Q3归母+5.17% vs 营收+33.86%，归母净利率9.08%（同比-2.48pp）；扣非+10.93%低于归母+15.51%
2. **费用刚性**：研发+27.2%（Q3+46.2%）、财务费用0.92亿（汇兑损失0.4-0.5亿）、补助退坡0.40亿、减值多计提0.85亿
3. **单季现金流弱**：Q3 OCF仅0.16亿（H1为7.52亿），OCF/NP从117%降至74%
4. **豫北利润贡献薄**：前三季度少数股东损益仅0.09亿（Q3单季0.159亿），归母贡献下修至0.66亿/年
5. **终端趋势性下滑**：9月零售-28.0%、10月1-25日-26%，2026年零售约-22%~-24%
6. **USMCA+H股**：年度审查延续、聆讯停滞，地缘与稀释压力未解

### 1.4 关键结论

> **三季报后，伯特利的投资逻辑从"2027E盈利拐点+估值极厚安全垫"切换为"收入与订单仍强、利润率下台阶、估值处历史极值"**。2027E基准EPS 1.84元（+13.0%）、加权目标价35.38元（+40.9%）、中性审计目标32.08元（+27.8%）；现价25.11元低于保守价25.36元（-1.0%），盈亏比仍记∞+，但**安全垫已经很薄——保守价距现价仅1.0%，若2027E盈利再下修约1%，保守价将跌破现价**。**操作上维持增持但暂缓加仓：现价不追跌，放量收复MA10 26.20或2026年报确认Q4净利率≥9%再加仓；放量跌破25.0减仓，跌破24.77（10月低点）止损。** 下一验证：11-04权益分派实施（10转4.2除权）→11-17临时股东会→H股聆讯→2027-03~04年报。

## 三、研究结论象限图

```
预期收益空间
       ▲
   高   │  第二象限                    │  第一象限
        │  Speculative Growth          │  High-Conviction Buy
        │  (黑马/期权仓位)              │  (核心重仓)
        │                              │
        │  2027E EMB/悬架超预期+       │  ★ 伯特利当前定位（第一/第二交界，按第二象限纪律）
        │  终端企稳回升                │  收入+订单强、利润率下台阶
        │  (概率25%, 上行+111%)        │  确定性3.5/5、上行+40.9%/下行-1.0%
        ├──────────────────────────────┤  = 增持（持有观望、暂缓加仓）
        │  第四象限                    │
        │  Avoid/Wait                  │
        │  (回避/观望)                  │
   低   │                              │
        └──────────────────────────────┘
         低 ←──────────────────────→ 高
                     确定性
```

> **最终定位：第一/第二象限交界（确定性3.5/5、上行+40.9%），操作上按第二象限纪律——不追高、等确认。→ 增持（持有观望、暂缓加仓）。**  
> 核心原因：收入与订单确定性高（新定点104.99亿），但利润率下台阶使确定性由4.5/5降至3.5/5；上行+40.9% vs 下行-1.0%（为负）赔率仍为正，但安全垫仅1.0%——**这是"估值底+盈利降速"的组合，不是"高确定性成长股"的买点，必须等Q4净利率或技术面确认。**
