### 1.3 多空力量对弈（重估）

**多头逻辑（增强）**：
1. **H1超预期反转**：Q2+42.4%/+48.0%+全年上修至+6.9%（前次-6.8%），增速转正
2. **技术壁垒兑现**：全球首家全干式EMB量产+ASIL-D+WCBS全国产化平台，在研912项/年化63.1亿历史新高
3. **豫北并表超预期**：H1贡献15-16亿，毛利率19.45%企稳（未被拖累），协同初现
4. **回购+筹码改善**：1-2亿回购+工行1.8亿贷款+股东户数73,208（-8.5%）修复治理信任
5. **出口+87.8%对冲总量**：7月出口占比41%，获全球某头部车企233.5万辆海外定点，墨西哥虽亏但摩洛哥分散

**空头逻辑（收敛）**：
1. **有息负债激增**：短借+3965%/长借+1702%，财务费用0.46亿转正，资产负债率56.76%需跟踪
2. **USMCA年度审查仍存**：美提92%区域价值含量+50%美国含量提案（8月17日），9月第四轮谈判分歧仍大
3. **估值仍击穿历史最低**：PE 17.64x <19.88x，虽修复但仍处底部，显示市场仍谨慎
4. **盈亏比0.47未达1.0**：现价28.07上行7.9% vs 下行16.6%，赔率未达重仓线
5. **存货/应收仍高**：43.59亿应收/22.83亿存货增速略高于营收

### 1.4 关键结论

> **伯特利从“被错杀的成长股”回归“业绩验证的价值成长股”。**49天内股价+21.1%已反映H1超预期大部分，但PE 17.64x仍处历史绝对底部，且2027E增速32.9%（EPS 2.07）提供PEG 0.55支撑。概率加权目标30.28元（+7.9%）、审计修正28.2元（+0.5%）显示当前位置为“合理偏低”而非“便宜”。**不追高，等待回踩25-26元（MA20附近，盈亏比>1）或Q3验证后再加仓。**

## 三、研究结论象限图

```
预期收益空间
      ▲
  高   │  第二象限                    │  第一象限
       │  Speculative Growth          │  High-Conviction Buy
       │  (黑马/期权仓位)              │  (核心重仓)
       │                              │
       │  EMB放量超预期+               │
       │  2027E 32.9%高增速             │
       │  (概率25%, 上行+37%)          │
       ├──────────────────────────────┤
       │  第四象限                    │  第三象限
       │  Avoid/Wait                  │  Defensive Value
       │  (回避/观望)                  │  (防御/底仓)
       │                              │
  低   │                              │  ★ 伯特利当前定位
       │                              │  中等确定性(增速+6.9%)
       │                              │  +中等收益(+7.9%~37%)
       │                              │  = 中性持有（偏谨慎）
       └──────────────────────────────┘
        低 ←──────────────────────→ 高
                    确定性
```

> **最终定位：第三象限边缘（Defensive Value偏第二象限），中性持有。**  
> 核心原因：H1超预期使确定性从3.0/5→4.0/5，增速转正+7.9%~37%收益区间，但盈亏比0.47未达1.0。**28元以上不追高，回踩25-26元或Q3验证后加仓。**
