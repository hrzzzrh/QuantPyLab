# 研报章节二：产业周期与终端穿透

**研究日期**：2026年07月13日  
**逻辑继承**：模块一发现PE 15.91x击穿5年历史最低19.88x，Q1营收近乎零增长且Q2恶化风险极高，豫北转向6月18日完成交割。本章节将向下穿透至终端汽车市场，结合2026年6月最新数据审计增长动能真伪与供需边际演变。

---

## 一、产业生命周期与库存节奏定位

### 1.1 行业三维坐标定位

| 维度 | 定位 | 证据（更新至2026年6月） |
| :--- | :--- | :--- |
| **汽车整体市场** | **成熟期（存量博弈，需求深度承压）** | 6月乘用车零售160.2万辆，同比-23.2%；1-6月累计870.1万辆，同比-20.2%。全年预期下修至约2,700-2,800万辆（约-7%~-10%） |
| **新能源汽车** | **成长期后半段（增速放缓，渗透率被动创新高）** | 6月NEV渗透率62.8%（历史新高）。但NEV零售100.7万辆同比仍-9.4%，绝对销量承压。渗透率飙升主因燃油车崩塌 |
| **线控制动（EHB）** | **成长期中段（规模化放量）** | 2025年渗透率突破50%，One-Box占比86.6%。2026年预计达60%+，市场规模预计180.84亿元，CAGR 16.45% |
| **电子机械制动（EMB）** | **导入期→早期量产（产业化元年确认）** | 2026年为首个量产年。**坐标系全球首款EMB量产乘用车（奇瑞EX7）已交付，博世宣布2026年内量产**。预计2026-2030年CAGR超70% |

**核心定位**：伯特利横跨三个生命周期阶段——成熟期（盘式制动器/轻量化零部件）、成长期（EHB线控制动/EPB）、导入期（EMB/线控转向/悬架/机器人零部件）。公司的整体成长性取决于成长期和导入期业务能否接续成熟期业务的增长放缓。当前核心矛盾在于——当终端市场陷入深度负增长时，成长期业务（EHB/EPB）的渗透率提升能否完全对冲总量萎缩？

### 1.2 库存周期动力学——牛鞭效应从预警变为现实

**产业链库存状态判断（更新至2026年6月）**：

| 环节 | 信号 | 方向判断 |
| :--- | :--- | :--- |
| **终端零售** | 6月零售160.2万辆，同比-23.2%（4月-21.5%→5月-23%→6月-23.2%：连续三月恶化） | **需求持续恶化，且速度加快** |
| **主机厂批发** | 6月批发235.8万辆，同比-5.7%。零售-批发剪刀差仍大（国内零售低于批发） | **批发与零售仍严重背离** |
| **经销商库存** | 1-6月厂商端库存去化48万辆，生产极其谨慎（生产233.8万<批发235.8万） | **去库存进行中，但绝对库存仍高** |
| **Tier1供应商（伯特利）** | 存货18.07亿元（+27.3%），增速远超营收增速20.9%。叠加6月零增长预期 | **被动累库压力加重** |

**牛鞭效应辨析（强化版）**：

2025年主机厂在"两新"补贴刺激下大幅扩产（批发+8.8%），带动Tier1供应商大量备货。2026年终端需求印证了最坏的预期——4月-21.5%、5月-23%、6月-23.2%，需求侧不仅没有企稳，反而在持续恶化。而供给侧的批发仅-5.7%，**增速剪刀差高达17.5个百分点**。

行业整体在主动去库存（1-6月去化48万辆），但传导向Tier1的订单削减存在2-3个月的滞后期。伯特利Q1营收仅+1.38%，**Q2很可能由正转负**，正是这一传导滞后的体现。

> **核心辨析**：终端需求-23.2%的背景下，Q2营收转负几乎是一个"确定性事件"。2025年新增定点605项/年化95亿元是领先指标，但其兑现高度依赖下游主机厂实际产销。**终端需求若持续承压，新增定点的兑现率将显著下降。** 这是本轮更新将2026E营收大幅下修的核心依据。

## 二、终端需求穿透与跨期断层审计（MANDATORY）

### 2.1 最终产品画像

伯特利的产品最终负载于**乘用车**（占比近100%），具体为：
- 盘式制动器/EPB/WCBS/EMB → 乘用车制动系统
- 轻量化铸铝转向节/控制臂 → 乘用车底盘
- 机械转向/EPS → 乘用车转向系统
- ADAS → 乘用车智能驾驶

**终端景气度直接影响因子** = 中国乘用车产量 + 新能源汽车产量 + 出口量

### 2.2 终端景气度审计（2026-2028年）——更新至6月完整数据

#### 2.2.1 中国乘用车内需：承压深度超出所有预期

| 年度/时段 | 乘用车销量 | YoY | 驱动力 |
| :--- | :--- | :--- | :--- |
| 2025全年 | 3010万辆 | +9.2% | 补贴加码+报废更新放量 |
| 2026 Q1 | 零售同比-17.4% | — | 补贴退坡+高基数 |
| 2026年4月 | 零售138.4万辆 | -21.5% | 三重压力叠加 |
| 2026年5月 | 零售152.8万辆 | -23% | 恶化加深 |
| **2026年6月** | **零售160.2万辆** | **-23.2%** | **恶化继续，连续三月超-20%** |
| **2026H1累计** | **零售870.1万辆** | **-20.2%** | **上半年降幅两成** |
| **2026E全年** | **下调至约2,700-2,800万辆** | **约-7%~-10%** | 此前预测-4%~-7%已失效，全年大概率负增长8-10% |

**需求下滑的结构性特征（6月数据）**：
- **燃油车崩塌是绝对主因**：6月常规燃油乘用车零售60万辆，同比-39%。燃油车占H1下滑的约80%
- **NEV韧性偏强但绝对量也开始萎缩**：6月NEV零售100.7万辆同比-9.4%（此前NEV零售增速尚能持平或微正，6月开始显著转负），但渗透率仍创新高62.8%
- **出口是唯一亮点**：6月出口87.7万辆（+82.3%），其中NEV出口49.9万辆（+152.7%），占出口56.9%
- **批发端相对稳健**：6月批发235.8万辆仅-5.7%，得益于出口暴增缓冲

#### 2.2.2 新能源汽车：渗透率创新高但绝对量承压

| 时段 | 新能源零售 | YoY | 渗透率 |
| :--- | :--- | :--- | :--- |
| 2026年4月 | 零售84.9万辆 | -6.8% | 61.4% |
| 2026年5月 | 零售95万辆 | — | 62.5% |
| **2026年6月** | **零售100.7万辆** | **-9.4%** | **62.8%（历史新高）** |
| **2026E全年** | **下调至约1,650-1,750万辆** | **约+2~7%** | 此前预测+5-10% |

新能源仍是增长动力，但增速显著不及预期。渗透率飙升主要源于燃油车基数的坍塌性下滑（"被动渗透率提升"），而非新能源绝对增速的强劲。6月NEV零售同比转负（-9.4%）是一个危险信号——连新能源也撑不住了。

#### 2.2.3 出口：结构性增量仍在但面临全新风险

1-6月乘用车出口约390万辆（+82%+）。出口仍是伯特利海外业务（轻量化+EPB）的确定性增长点，但**USMCA拒绝续期（7月1日）是对这一增长逻辑的结构性打击**。详见章节四。

### 2.3 动能溯源与跨期透支审计（强制）——更新

#### 增长动能分类

| 驱动力 | 类型 | 持续性判断 |
| :--- | :--- | :--- |
| 新能源汽车渗透率提升 | **内生** | 持续但以"被动提升"为主——渗透率升但绝对量降（6月NEV零售-9.4%） |
| "两新"以旧换新政策 | **外生（政策）** | **边际效应显著递减**——2026年从"定额制"改为"比例制"，低价车补贴大幅缩水 |
| 购置税减免 | **外生（政策）** | **2026年减半**，购车成本上升 |
| 智能化升级（线控制动渗透） | **内生** | 确定性较高——EHB渗透率持续提升（50%→60%→70%） |
| 国产品牌替代外资 | **内生** | 确定性较高——但外资反攻（博世2026年EMB量产）削弱差异化 |
| 出口扩张 | **内生+外生** | ★ 高增长（+82%）但**USMCA非续期构成全新结构性风险** |

#### 跨期断层审计：风险已全面升级

**需求透支证据链（升级版）**：

| 证据 | 来源 | 最新数据 |
| :--- | :--- | :--- |
| 2025年以旧换新超1150万辆 | 商务部 | 透支效应正在释放 |
| 2026年Q1零售-17.4% | 乘联分会 | 一季度深跌 |
| 2026年4月零售-21.5% | 乘联分会 | 二季度首月恶化 |
| 2026年5月零售-23% | 乘联分会 | 持续恶化 |
| **2026年6月零售-23.2%** | 乘联分会 | **恶化加速——连续三个月超-20%** |
| **1-6月累计零售-20.2%** | 乘联分会 | **上半年整体崩塌两成** |
| NEV渗透率62.8%（6月） | 中汽协 | 历史新高但燃油车加速退出是主因 |
| 行业利润率Q1仅3.2% | 中汽协 | 逼近盈亏线 |

**"跨期断层"判断（升级为"确定性事件"）**：2024-2025年两轮"两新"刺激实质上已**提前透支了2026-2027年的置换需求**。1-6月连续6个月的数据（-17.4%→-21.5%→-23%→-23.2%）已不仅证实了透支效应的存在，更表明其严重程度超出此前所有预期。

**对伯特利的业务含义（升级）**：
1. **2026年乘用车市场将深度负增长（-8%~-10%）**，而非此前的温和负增长（-4%~-7%）
2. **Q2营收大概率由正转负**，Q1的+1.38%是"暴风雨前的平静"
3. **2025年新增定点的大规模兑现将被大幅推迟**至2027年，甚至部分项目可能被取消
4. **出口（+82%）是少有的增量**，但USMCA风险使其不确定性骤升

## 三、供需边际与压力传导——关键更新

### 3.1 行业价格战状态：戛然而止后维持

5月价格战戛然而止后，6月未出现新的降价潮。叠加库存去化（1-6月行业去化48万辆），产业链利润底可能已过。对伯特利而言，年降压力的边际缓解是少有的积极信号。

### 3.2 EMB竞争格局——量产窗口的"卡位战"全面升级（重大更新）

2026年被业界公认为EMB产业化元年。本次更新的关键变化：

| 竞争者 | EMB最新进度 | 竞争态势 |
| :--- | :--- | :--- |
| **伯特利** | 3月小批量交付，4月批量生产，5月8日第1万件下线，60万套产能规划 | 量产进度依然领先但优势在缩窄 |
| **坐标系** | ★ 奇瑞星途EX7已于3月实现量产交付——**全球首款搭载EMB的量产乘用车**；80万件/年产线建成；3488元/套（极低定价） | **最直接竞争者，已抢走"全球首款"名号，伯特利vs坐标系专利诉讼进行中** |
| **博世** | ★ **2026年北京车展宣布EMB年内量产**，与地平线合作J6E/J6M方案，BWA+ESP双线方案 | ★ 最危险的竞争者——外资巨头的品牌+技术+客户优势 |
| 理想汽车 | 自研EMB，计划2026年大规模量产 | 主机厂自研威胁 |
| 比亚迪/弗迪科技 | 自研EMB推进中 | 体系内替代风险 |
| 采埃孚 | 已获500万辆级EMB订单 | 外资巨头参与 |
| 15+家其他竞争者 | 2026年内量产 | 供给端拥挤 |

> ★ **关键评估变化**（来源：36氪2026年7月12日深度分析）：博世2026年宣布量产意味着本土供应商的先发优势从1-2年缩短到数月。**真正的竞争维度从"谁先量产"转向"谁的成本更低、客户响应更快"。** 这意味着伯特利的EMB先发溢价逻辑被大幅削弱。同时，芯片（车规MCU英飞凌36%份额、国产合计仅11%）是整个底盘国产替代的天花板，不是2-3年能突破的。

## 四、强制复核项确认（Mandatory Audit Checks）

> ✅ **复核1**：已穿透并引用终端产品最新景气度——6月乘用车零售-23.2%，1-6月累计-20.2%。全年预期从此前-4%~-7%大幅下调至-8%~-10%。

> ✅ **复核2**：已审计跨期需求透支风险——1-6月数据全线段证实透支效应。2025年超1150万辆以旧换新实质性地前置了置换需求。H1零售-20.2%的深度远超预期。

> ✅ **复核3**：已分析供需边际演变方向——EHB从"供不应求"转向"供需平衡"，EMB竞争白热化升级（博世年内量产+坐标系首发+15+竞争者）。EMB先发窗口从1-2年收窄至数月，这是本轮更新的重大变量。

## 五、模块二核心结论

1. **终端需求恶化从"超预期"升级为"深度崩塌"**：6月零售-23.2%是连续第三个月超-20%，1-6月累计-20.2%。全年乘用车销量预期下调至约2,700-2,800万辆（-8%~-10%）。

2. **Q2营收转负是大概率事件**：Q1营收仅+1.38%，而6月终端需求-23.2%，牛鞭效应的传导正在发生。这意味着年初的所有营收预测都已严重失效。

3. **EMB竞争格局发生质变**：博世宣布2026年量产+坐标系奇瑞EX7首发交付，两起重磅事件叠加，将EMB从"伯特利有望独享红利"的故事改写为"先发窗口数月、核心比拼成本与响应"的新现实。

4. **"跨期需求透支"已从预警升级为确定性事实**：2025年超1150万辆以旧换新透支了2026-2027年需求。H1-20.2%的正反馈已不容置疑。

5. **出口仍是唯一亮点但蒙上USMCA阴影**：1-6月出口+82%，但美国拒绝续期USMCA（7月1日）从根本上动摇了北美出口逻辑。
