# 研报章节二：产业周期与终端穿透

**研究日期**：2026年11月1日  
**关联研报复用**：已盘点 `investigation/industry/` 与 `investigation/macro/`，与本轮相关的是《新能源汽车与商用车电动化行业深度研究报告_2026年10月17日》（数据截至10-17，含9月中汽协/乘联会数据）、《中国电解铝行业深度研究报告_2026年10月17日》、《中国人形机器人产业深度研究报告_2026年10月17日》（第二曲线，2027-2028商业化验证期）与《宏观指标跟踪手册_2026年10月19日》。复用结论：①乘用车已进入"高渗透率下的存量竞争、出口对冲内需"阶段，与本轮9月零售-28.0%/出口+73.7%一致；②电解铝报告对成本/供给的判断与本轮10月铝价回落（23,690元/吨）一致；③机器人报告认为大规模量产最早2027年后，支持将机器人列入Bull情景而非基准；④宏观手册PPI+5.0%、LPR持稳，支持"上游成本压力+折现率稳定"的假设。**未发现与本轮最新可信信息相悖的行业级结论，故不触发行业研报更新；行业报告仅作为背景基准，具体数据以本轮公告/乘联会/铝价一手来源为准。**  
**逻辑继承**：模块一三季报呈现"营收+26.2%/Q3+33.9%、归母+15.5%/Q3+5.2%"的增收不增利结构，毛利率19.80%企稳（Q3 20.33%）。本章基于乘联分会**9月正式数161.8万辆/-28.0%**（大幅差于9-17预估169万/-24.6%）、1-9月累计1333.4万辆/-21.7%、**10月1-25日零售114.5万辆/-26%**（10月全月预计约160万辆）、9月NEV零售108.4万辆/-16.7%渗透率67.0%再创新高、9月出口91.7万辆/+73.7%、9月燃油车-43%（纯燃油-49%）及三季报实证，重估终端动能。目标年份维持2027E，本章同步下修2027年终端基准与公司份额对冲斜率。

## 二、终端需求穿透与跨期断层审计（MANDATORY）

### 2.1 最终产品画像

伯特利产品最终负载于**乘用车**（近100%），终端景气度=中国乘用车产量+新能源产量+出口量。2026H1中国汽车产销约1,499/1,501万辆，同比-4%/-4.1%（国内992万辆-21.1%，出口509.6万辆+65.3%）——总量-4%+结构分化。

### 2.2 终端景气度审计（2026-2028年）——更新至9月正式数与10月周度

#### 2.2.2 新能源汽车：渗透率67.0%再创历史新高，但绝对量连续三个月负增长

9月NEV零售108.4万辆/-16.7%（8月-10.1%→9月-16.7%），渗透率67.0%（同比+9.1pp）再创新高；自主NEV渗透率更高，合资仅13.4%。NEV批发166.6万辆/+11.3%、生产165.5万辆/+9.8%，纯电仍为主体；10月1-25日NEV零售75.3万辆/-13%、渗透率65.7%，批发渗透率72.9%。**高渗透率对总量的边际支撑已明显递减**：当NEV零售本身连续负增长时，"油电替代"不再是增量逻辑，而是存量结构切换；对伯特利而言，增量来自新能源车单车价值量（WCBS/EMB/ADAS）而非NEV总量。

#### 2.2.3 出口：高增延续，是内需下滑的唯一强对冲

9月乘用车出口91.7万辆/+73.7%环比+3.2%，占厂商销量36%；NEV出口占60.8%（+21pp），自主出口81.2万辆/+75%。海关口径1-9月汽车出口863万辆/+51.9%（其中电动车470.8万辆/+77.3%）。奇瑞1-9月出口149.91万辆/+66.3%、9月单月超20万辆，是伯特利海外配套的直接载体。USMCA年度审查仍是中期变量，但短期出口高增为伯特利轻量化（+6.68%）与智能电控提供订单缓冲。

### 2.3 动能溯源与跨期透支审计——"金九银十"双双失守，透支压力仍在释放

**增长动能分类**：
- **内生**：NEV渗透率67.0%（+9.1pp）、EHB渗透率62%+、油电替代（燃油-43%/纯燃油-49%）——结构切换持续，但NEV零售自身-16.7%，内生增量已不足以托举总量
- **外生**：以旧换新比例制（前低后高）、购置税减半（压制）、高油价（汽油年内+1,720元/吨）——政策托底力度弱于退坡幅度
- **出口**：9月+73.7%、奇瑞+66.3%——短期最强动能，但受USMCA/欧盟贸易政策约束

**跨期断层判断**：1-9月-21.7%→10月1-25日-26%，说明透支压力尚未见底；9月正式数161.8万较预估169万低7.2万辆，意味着"金九"的旺季补库并未发生，10月"银十"亦仅约160万辆。按乘联分会口径，2026年零售全年约1,780-1,820万辆（-22%~-24%），较2025年减少约500-550万辆。**对伯特利的影响路径**：①总量下滑→主机厂年降压力加大（2027年降幅可能从3-5%扩大至5-8%）；②但伯特利新定点年化104.99亿元、智能电控销量+42.7%，份额提升可对冲量的下滑；③真正需要警惕的是"以价换量"——Q3毛利率20.33%尚稳，但净利率9.08%已说明价格与费用压力正在利润端体现。**结论：2027年"量"的可见度高于"价"，收入双位数增长可期，利润率修复需依赖产品结构（EMB/悬架/线控转向）而非行业回暖。**

## 三、供需边际与压力传导

### 3.1 行业价格战状态：显性降价缓和，隐性年降与账期压力上升

5月后显性降价潮缓和（8月仅10款降价、同比-13款），但9-10月总量-28%/-26%使主机厂将压力转向"年度降价+拉长账期+压低新品定价"。伯特利Q3毛利率20.33%（环比+0.87pp）说明其产品结构（智能电控/高毛利开发费）暂时抵消了年降，但净利率9.08%（同比-2.48pp）与应收账款同比+31.8%说明**压力已从毛利率转移至费用与营运资金**。2027年若行业零售零增长，年降幅度可能扩大至5-8%，是2027E毛利率假设（19.7%）的主要风险。

### 3.2 EMB竞争格局——从“卡位战”到“量产兑现”

| 竞争者 | 最新进度（截至2026-10-31） | 竞争态势 |
| :--- | :--- | :--- |
| **伯特利** | **全球首家全干式EMB量产+ASIL-D认证；理想项目量产后新增4个整车厂量产定点，Q3出货量明显增长；现有约30万套EMB产能（120万件专用线），60万套募投项目2027-06-30达可使用状态** | **量产+多点定点领先，ASP承压** |
| 坐标系 | 奇瑞星途EX7全球首发交付，产能40万套（此前口径80万件/年），3488元/套；与伯特利专利诉讼进行中 | 价格竞争者，核心客户正面争夺 |
| 博世 | 2026年内中国量产（BWA+ESP双线，智己/小鹏线控转向同步落地）；H1 Mobility营收278亿欧/-0.5%（有机+2.3%）、EBIT率4.7%（含2.7亿欧减值） | 外资最大威胁，但中国EMB放量晚于伯特利 |
| 采埃孚 | 500万辆级EMB订单；1-9月营收289亿欧（有机+1.4%）、调整后EBIT率4.9%（+1.3pp）、FCF约11亿欧、杠杆率2.61x；EMB量产排期未来1-2年 | 规模+盈利改善，但中国EMB节奏偏慢 |
| 同驭/利氪/格陆博/京西/比博斯特 | 同驭年底量产（规划16万套）、利氪/格陆博/京西/比博斯特2026年内量产 | 供给拥挤，价格战延续 |

**行业空间口径校准**：高工智能汽车研究院预测2026-2028年中国乘用车前装标配EMB（含干湿混合）累计300-350万辆，2029年新车配置率突破50%；东方财富/东吴口径2030年国内EMB市场规模超115亿元；另有观点（舒强）认为2030年EMB份额约15%、EHB仍占85%。此前引用的"久谦资本：EMB渗透率突破30%、中国市场280亿元"属更长期/更乐观口径，**未经交叉验证，仅作方向性参考，不作为2027E基准**。按高工口径，2027年行业EMB前装约80-120万辆，伯特利若占15-20%份额对应12-24万套，与章节五2027E 18-20万套的基准假设基本匹配。

**评估变化**：EMB已从"卡位战"进入"量产+多点定点"阶段——伯特利9-30说明会披露新增4个整车厂量产定点，10-23获理想"技术创新奖"，说明其EMB并非单一客户项目；但坐标系3488元/套、博世年内量产、同驭16万套规划使ASP与份额同时承压。**2027E EMB收入基准由5.0亿微调至4.8亿（量增价减），不再假设"独家红利"。**

## 五、模块二核心结论（2026年11月）

1. **9月正式数161.8万辆/-28.0%大幅差于预估（-24.6%），10月1-25日再-26%，"金九银十"双双失守**；1-9月累计-21.7%，2026年零售全年约1,780-1,820万辆（-22%~-24%）。总量下行不是"弱修复"，而是高油价+购置税减半+补贴退坡共振下的趋势性下台阶。
2. **伯特利"总量下行、份额上行"的收入逻辑仍成立但利润逻辑弱化**：Q3营收+33.86%（豫北并表+智能电控销量+42.7%+机械转向+62.94%），但归母仅+5.17%，净利率9.08%（同比-2.48pp）。**份额对冲可以保收入，无法保利润率**——这是2026Q3最重要的新事实。
3. **订单储备是2027年最大确定性**：前三季度新定点598项/+44.79%、年化收益104.99亿元（H1为63.1亿），在研934项/+74.25%；即使2027年行业零售零增长，公司收入仍有望实现15-20%增长。
4. **EMB从"卡位战"进入"量产+多点定点"**：理想项目量产后新增4个整车厂定点，Q3出货明显增长；但坐标系3488元/套、博世2026年内量产、同驭16万套规划使ASP承压，2027E EMB收入基准由5.0亿微调至4.8亿。
5. **2027E终端基准**：零售低基数下-2%~+3%（约1,760-1,850万辆），总销量含出口约2,650-2,750万辆（出口1,100万辆对冲）；公司增长主要来自份额（WCBS 14%→15%）、豫北全年并表与EMB/悬架放量，而非行业回暖。
