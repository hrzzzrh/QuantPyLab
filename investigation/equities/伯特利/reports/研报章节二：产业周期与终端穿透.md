# 研报章节二：产业周期与终端穿透

**研究日期**：2026年09月09日  
**逻辑继承**：模块一2026H1业绩超预期反转（营收+21.46%/Q2+42.4%），本章基于2026年8月乘用车零售正式数（154.1万辆同比-23.6%环比+5.5%差于预估158万-21.7%/+8.1%）、1-8月累计1171.6万辆-20.8%、批发235.3万-5.3%、燃油-40%腰斩、NEV 100.5万-10.1%渗透率65.2%新高及半年报实证，重估增长动能。关注点“弱修复证伪”在8月正式数中兑现——环比修复+5.5%弱于预估+8.1%，同比跌幅较7月-20.9%再扩大2.7pp，底部企稳预期被削弱，但出口+77.8%占比38%托底逻辑未变。前次担忧的“Q2营收转负”已被智能电控+39%及豫北并表证伪。

## 一、产业生命周期与库存节奏定位

### 1.1 行业三维坐标定位

| 维度 | 定位 | 证据（更新至2026年9月8日正式数） |
| :--- | :--- | :--- |
| **汽车整体市场** | **成熟期（存量博弈，弱修复证伪、需求承压未缓解）** | 8月正式零售154.1万辆同比-23.6%环比+5.5%（差于8月21日预估158万-21.7%/+8.1%）；1-8月累计1171.6万辆同比-20.8%；7月146.1万辆-20.9%→8月跌幅再扩大2.7pp，弱修复证伪 |
| **新能源汽车** | **成长期后半段（渗透率65.2%新高但绝对量-10.1%承压）** | 8月NEV零售100.5万辆同比-10.1%（较7月-3.9%扩大），渗透率65.2%（+9.9pp YoY，环比+0.1pp）再创历史新高；批发151.0万辆+16.4%（占批售64.2%），生产152.8万辆+19.2% |
| **线控制动（EHB）** | **成长期中段（规模化放量）** | 2025年渗透率突破50%，2026年预计62%+，市场规模持续扩张；伯特利WCBS新增量产+146.67%验证 |
| **电子机械制动（EMB）** | **导入期→早期量产（2026量产元年兑现）** | **伯特利全球首家全干式EMB量产+ASIL-D认证**；博世/采埃孚等外资亦加速，但伯特利已量产落地 |

**核心定位**：伯特利虽处成熟期总量承压，但成长期（EHB）与导入期（EMB）业务通过份额提升（在研912项/+87.65%）实现了对总量下行的对冲，2026H1超预期是最佳例证。

### 1.2 库存周期动力学——去库延续+出口托底但弱修复证伪

**产业链库存状态判断（更新至2026年8月正式数）**：

| 环节 | 信号 | 方向判断 |
| :--- | :--- | :--- |
| **终端零售** | 8月154.1万辆同比-23.6%环比+5.5%（预估158万-21.7%/+8.1%，差3.9万辆/1.9pp/2.6pp）；7月146.1万辆-20.9%→8月跌幅扩大2.7pp | **弱修复证伪，环比修复弱于预期，底部企稳证伪** |
| **批发** | 8月235.3万辆同比-5.3%环比+4.5%（7月225.2万辆-0.2%）；批零剪刀差18.3pp | **批强零弱延续，出口是核心支撑** |
| **生产** | 8月234.8万辆同比-4.5%环比+5.7%（7月222.2万辆-1.6%） | 去库延续，1-8月行业累计去库存73万辆（厂商生产谨慎） |
| **Tier1（伯特利）** | 存货22.83亿（+26.32%）略高于营收+21.46%，但缺口收窄至4.86pp | **备货合理，非被动累库** |
| **出口** | 8月88.8万辆同比+77.8%环比-4.2%占比38%（7月91.8万辆+87.8%占比41%）；自主78万辆+82% | **高增延续但环比回落，结构性增量仍强** |

**牛鞭效应辨析（修正：8月弱修复证伪）**：
前次担忧的“终端-23.2%→Q2营收转负”传导并未发生（伯特利H1+21.46%已证伪脱钩），原因：①公司客户结构（奇瑞/吉利+比亚迪等）出海增速远高于行业（8月行业出口+77.8%占比38%，伯特利轻量化+11.59%且获全球某头部车企233.5万辆海外定点），②智能电控等高附加值产品渗透率65.2%提升独立于总量（燃油-40%腰斩反向加速油电替代），③豫北并表增量。但8月正式数环比+5.5%弱于预估+8.1%、同比-23.6%差于预估-21.7%，且较7月-20.9%跌幅再扩大，**底部企稳预期被证伪为“弱修复”**。库存去化（1-8月累计-73万辆，厂商以销定产）延续，但总量压力未缓解，伯特利“份额上行对冲总量下行”逻辑需更强份额提升来维持。

## 二、终端需求穿透与跨期断层审计（MANDATORY）

### 2.1 最终产品画像

伯特利产品最终负载于**乘用车**（近100%），终端景气度=中国乘用车产量+新能源产量+出口量。2026H1中国汽车产销约1,499/1,501万辆，同比-4%/-4.1%（国内992万辆-21.1%，出口509.6万辆+65.3%）——总量-4%+结构分化。

**结构性特征（8月正式）**：燃油车54万辆同比-40%腰斩（纯燃油-45%），NEV 100.5万辆同比-10.1%（跌幅较7月-3.9%扩大，批发151.0万+16.4%但零售仅环比+5.7%），出口88.8万辆+77.8%占比38%仍高但环比-4.2%回落。自主零售108万辆-19%（份额69.9%+4.1pp），合资31万辆-35%、德/日/美份额全降。

#### 2.2.2 新能源汽车：渗透率65.2%再创历史新高但绝对量转弱

8月NEV渗透率65.2%（同比+9.9pp，环比+0.1pp）再创新高，自主NEV渗透率83.9%、豪华38.9%、合资仅13.4%，纯电批发103.2万辆+25.9%占NEV批发68.3%（插混3.1%/增程-10.9%分化）。但8月NEV零售100.5万辆同比-10.1%（较7月-3.9%扩大6.2pp），批强零弱（批发+16.4% vs 零售-10.1%）显示终端需求亦承压，65%+高渗透率对总量支撑边际递减。

#### 2.2.3 出口：高增延续但环比回落，USMCA为变量

1-8月出口累计高增，8月88.8万辆+77.8%（NEV占58.4%+18pp，自主78万辆+82%/合资10.8万辆+53%）、NEV出口51.8万辆+154.7%，但环比-4.2%（7月+87.8%→8月+77.8%增速回落）。USMCA年度审查仍存（第四轮9月01-15窗口，50%/92%提案，截至09-08未见双源结论，待核验），但短期出口高增为伯特利提供对冲（墨西哥+摩洛哥+全球某头部车企233.5万辆定点）。

### 2.3 动能溯源与跨期透支审计——“弱修复证伪”后透支压力未缓解

**增长动能分类**：
- **内生**：NEV渗透率65.2%（+9.9pp）及EHB渗透率62%+、油电替代加速（燃油-40%腰斩）——持续但绝对量-23.6%下内生亦承压
- **外生**：以旧换新（比例制，前低后高、9月加码预期）、购置税减半（压制）+ 高油价持续催化（汽油年内+1720元/吨，7月底以来+180元）——政策托底但总量未扭转
- **出口**：8月+77.8%高增但环比-4.2%回落，短期最强动能但增速边际放缓

**跨期断层判断（修正：弱修复证伪）**：1-8月-20.8%证实透支存在且8月-23.6%差于预估-21.7%、环比+5.5%弱于+8.1%，显示7月-20.9%收窄仅为弱修复而非拐点，透支压力未边际递减。伯特利H1+21.46%证明“份额提升+出口+新产品”可对冲总量透支，但全年-8%~-12%新假设下对冲所需份额提升斜率更高，H2需更强新定点转化（在研912项/年化63.1亿）来维持。

## 三、供需边际与压力传导

### 3.1 行业价格战状态：持续缓和

5月戛然而止后，6-7月未现新降价潮，7月库存去化+出口托底使年降压力缓解。伯特利毛利率19.45%企稳印证。

### 3.2 EMB竞争格局——从“卡位战”到“量产兑现”

| 竞争者 | 最新进度 | 竞争态势 |
| :--- | :--- | :--- |
| **伯特利** | **全球首家全干式EMB量产+ASIL-D认证，首个项目量产，60万套产能** | **技术兑现领先** |
| 坐标系 | 奇瑞EX7首发交付，80万件/年，3488元/套 | 价格竞争者，诉讼进行中 |
| 博世 | 2026年内量产（已完成冬季测试） | 外资最大威胁，但伯特利已量产缩小窗口焦虑 |
| 采埃孚 | 500万辆级订单 | 规模领先 |
| 其他15+家 | 2026年内量产 | 供给拥挤，但伯特利已卡位 |

**评估变化**：前次担忧“先发窗口缩至数月”在H1后修正为“伯特利已将先发兑现为量产与认证壁垒”，EMB从“故事”进入“订单”阶段。

## 五、模块二核心结论（2026-09-09重估：弱修复证伪方向）

1. **8月正式154.1万辆-23.6%环比+5.5%弱修复证伪，差于预估158万-21.7%/+8.1%，同比跌幅较7月-20.9%再扩大2.7pp，底部企稳预期落空**；1-8月累计1171.6万辆-20.8%显示总量承压未缓解，燃油54万辆-40%腰斩、NEV 100.5万辆-10.1%亦承压，65.2%渗透率新高但绝对量难托总量。
2. **伯特利“总量下行、份额上行”逻辑仍被H1+21.46%验证但H2对冲斜率需提升**，智能电控+39%、WCBS+146%及出口+77.8%高增对冲总量，全年假设回拨至-8%~-12%（前次-5%~-8%）。
3. **EMB从“卡位战”进入“量产兑现”**：伯特利全球首家全干式量产+ASIL-D认证，将先发转化为订单壁垒，批强零弱（批-5.3% vs 零-23.6%）及去库存73万辆显示供给端以销定产。
4. **跨期透支未边际递减**，政策加力（以旧换新前低后高、9月加码预期+高油价年内+1720元/吨催化油电替代）为H2提供边际支撑但总量拐点待“金九银十”验证，出口托底（38%占比）仍是核心支撑。
