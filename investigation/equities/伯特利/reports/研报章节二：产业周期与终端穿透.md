# 研报章节二：产业周期与终端穿透

**研究日期**：2026年08月31日  
**逻辑继承**：模块一2026H1业绩超预期反转（营收+21.46%/Q2+42.4%），本章基于2026年7-8月终端最新数据（7月零售-20.9%/1-7月累计-20.3%/出口+87.8%）及半年报实证，重估增长动能与供需边际。前次担忧的“Q2营收转负”已被智能电控+39%及豫北并表证伪。

---

## 一、产业生命周期与库存节奏定位

### 1.1 行业三维坐标定位

| 维度 | 定位 | 证据（更新至2026年7-8月） |
| :--- | :--- | :--- |
| **汽车整体市场** | **成熟期（存量博弈，需求承压但降幅收窄预期）** | 7月零售146.1万辆，同比-20.9%（较6月-23.2%收窄2.3pp）；1-7月累计1,017.3万辆，同比-20.3%；8月预计158万辆（环比+8.1%，同比-21.7%），8月1-23日同比-22%持平 |
| **新能源汽车** | **成长期后半段（渗透率新高但绝对量承压）** | 7月NEV零售95.1万辆同比-3.9%，渗透率65.1%（1-7月渗透率约55%+）；8月预计渗透率65.8% |
| **线控制动（EHB）** | **成长期中段（规模化放量）** | 2025年渗透率突破50%，2026年预计62%+，市场规模持续扩张；伯特利WCBS新增量产+146.67%验证 |
| **电子机械制动（EMB）** | **导入期→早期量产（2026量产元年兑现）** | **伯特利全球首家全干式EMB量产+ASIL-D认证**；博世/采埃孚等外资亦加速，但伯特利已量产落地 |

**核心定位**：伯特利虽处成熟期总量承压，但成长期（EHB）与导入期（EMB）业务通过份额提升（在研912项/+87.65%）实现了对总量下行的对冲，2026H1超预期是最佳例证。

### 1.2 库存周期动力学——去库延续+出口托底

**产业链库存状态判断（更新至2026年7月）**：

| 环节 | 信号 | 方向判断 |
| :--- | :--- | :--- |
| **终端零售** | 7月146.1万辆，同比-20.9%（4月-21.5%→5月-23%→6月-23.2%→7月-20.9%：收窄） | **降幅收窄，底部企稳信号** |
| **批发** | 7月225.2万辆，同比-0.2%（受出口+87.8%托底） | **批发-零售剪刀差20.7pp，出口是核心支撑** |
| **生产** | 7月222.2万辆，同比-1.6%（谨慎） | 去库延续，1-7月库存去化持续 |
| **Tier1（伯特利）** | 存货22.83亿（+26.32%）略高于营收+21.46%，但缺口收窄至4.86pp | **备货合理，非被动累库** |
| **出口** | 7月91.8万辆，同比+87.8%，占比41% | **结构性增量，且自主品牌出口+87%** |

**牛鞭效应辨析（修正）**：
前次担忧的“终端-23.2%→Q2营收转负”传导并未发生。原因：①公司客户结构（奇瑞/吉利+比亚迪等）出海增速远高于行业（行业出口+87.8%，伯特利轻量化+11.59%且获全球某头部车企233.5万辆海外定点），②智能电控等高附加值产品渗透率提升独立于总量，③豫北并表增量。库存去化（2026年1-7月持续）+8月预计环比+8.1%显示最差时点已过。

## 二、终端需求穿透与跨期断层审计（MANDATORY）

### 2.1 最终产品画像

伯特利产品最终负载于**乘用车**（近100%），终端景气度=中国乘用车产量+新能源产量+出口量。2026H1中国汽车产销约1,499/1,501万辆，同比-4%/-4.1%（国内992万辆-21.1%，出口509.6万辆+65.3%）——总量-4%+结构分化。

### 2.2 终端景气度审计（2026-2028年）——更新至7-8月

#### 2.2.1 中国乘用车内需：降幅收窄至-20.9%，底部企稳

| 2026 Q1 | 零售-17.4% | — | 补贴退坡 |
| 2026年4月 | 138.4万辆 | -21.5% | — |
| 2026年5月 | 152.8万辆 | -23% | — |
| 2026年6月 | 160.2万辆 | -23.2% | 最差 |

**结构性特征**：燃油车7月51万辆同比-41%仍是主因；NEV 95.1万辆同比-3.9%（较6月-9.4%收窄）；出口91.8万辆+87.8%持续高增，占比41%创纪录。

#### 2.2.2 新能源汽车：渗透率65.1%新高，供给向大型化

7月NEV渗透率65.1%（环比+2.1pp），1-7月49.6%。供给端49款5米以上新车占56%（2024年38%），经济型供给收缩。

#### 2.2.3 出口：持续高增但USMCA为变量

1-7月出口约390万辆+82%以上，7月+87.8%（NEV占58.8%）。USMCA年度审查仍存，但短期出口高增为伯特利提供对冲（公司墨西哥工厂+获全球某头部车企233.5万辆定点）。

### 2.3 动能溯源与跨期透支审计——“透支”边际递减

**增长动能分类**：
- **内生**：NEV渗透率（65.1%）、EHB渗透率（62%+）、国产品牌替代——持续
- **外生**：以旧换新（比例制，边际递减）、购置税减半（压制但政策预期加力：7月政治局“加力扩内需、优化供给”、消费品以旧换新配套政策优化）
- **出口**：+87.8%高增，短期最强动能

**跨期断层判断（修正）**：1-7月-20.3%证实透支存在，但7月降幅收窄+8月环比+8.1%+政策加力预期显示透支压力边际递减。伯特利H1+21.46%证明“份额提升+出口+新产品”可对冲总量透支。

## 三、供需边际与压力传导

### 3.1 行业价格战状态：持续缓和

5月戛然而止后，6-7月未现新降价潮，7月库存去化+出口托底使年降压力缓解。伯特利毛利率19.45%企稳印证。

### 3.2 EMB竞争格局——从“卡位战”到“量产兑现”

| 竞争者 | 最新进度 | 竞争态势 |
| :--- | :--- | :--- |
| **伯特利** | **全球首家全干式EMB量产+ASIL-D认证，首个项目量产，60万套产能** | **技术兑现领先** |
| 坐标系 | 奇瑞EX7首发交付，80万件/年，3488元/套 | 价格竞争者，诉讼进行中 |
| 博世 | 2026年内量产（已完成冬季测试） | 外资最大威胁，但伯特利已量产缩小窗口焦虑 |
| 采埃孚 | 500万辆级订单 | 规模领先 |
| 其他15+家 | 2026年内量产 | 供给拥挤，但伯特利已卡位 |

**评估变化**：前次担忧“先发窗口缩至数月”在H1后修正为“伯特利已将先发兑现为量产与认证壁垒”，EMB从“故事”进入“订单”阶段。

> ✅ 复核1：已穿透终端——7月零售-20.9%（收窄）、1-7月-20.3%、出口+87.8%、NEV渗透率65.1%

## 五、模块二核心结论（2026-08-31重估）

1. **终端降幅收窄至-20.9%（7月），8月预计环比+8.1%，底部企稳信号初现**，较6月-23.2%最差时点改善。
2. **伯特利“总量下行、份额上行”逻辑被H1+21.46%验证**，智能电控+39%、WCBS+146%及出口高增对冲总量。
3. **EMB从“卡位战”进入“量产兑现”**：伯特利全球首家全干式量产+ASIL-D认证，将先发转化为订单壁垒。
4. **跨期透支边际递减**，政策加力预期（7月政治局+以旧换新优化）为H2提供支撑，全年预期-5%~-8%（前次-8%~-10%略收窄）。
