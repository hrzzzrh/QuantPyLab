# 研报章节四：外部边界与宏观政策

**研究日期**：2026年11月1日  
**逻辑继承**：模块三确认EMB进入"量产+多点定点"但价格战延续、外资财务改善但中国节奏落后1-2年。模块四在Q3"增收不增利"的新事实下重审外部变量：**铝价10月回落（长江现货月均23,690元/吨，-2.33%）缓解成本压力，但人民币汇率升值带来汇兑损失（前三季度财务费用0.92亿元，其中约0.4-0.5亿为汇兑）成为新的利润扰动**；USMCA年度审查延续（ITC第三份报告2027-07-01前提交），墨西哥10-13对组装件临时免关税仅边际缓和；H股聆讯仍无进展。**目标年份维持2027E。**

## 一、宏观环境变量

### 1.1 折现率与估值环境

| 变量 | 现状 | 对伯特利影响 |
| :--- | :--- | :--- |
| **中国10年期国债** | ~1.7%（历史低位） | 降低折现率，理论上提升成长股估值中枢——但市场正从"成长"切至"价值"定价 |
| **A股市场风格** | 价值/红利优于成长（持续性强化） | 汽车零部件成长股遭遇双重打击：基本面恶化+风格逆风 |
| **流动性环境** | 适度宽松但信用传导偏弱 | 中小企业融资困难，但伯特利作为上市公司有优势 |

### 1.2 汇率影响

| 币种 | 方向 | 对伯特利影响 |
| :--- | :--- | :--- |
| **人民币/美元** | 2026年人民币偏强（前三季度汇兑损失体现于财务费用） | **偏空**：出口收入换算人民币减薄；前三季度财务费用0.92亿元（去年同期-0.14亿），其中利息费用0.63亿、汇兑损失约0.4-0.5亿 |
| **人民币/欧元** | 相对稳定 | 影响中性 |
| **墨西哥比索** | USMCA不确定性→比索承压 | 墨西哥工厂成本端存在波动风险 |

**汇率敏感性**：前三季度财务费用率0.87%（同比+1.03pp），是净利率下行的第二大单项（仅次于研发+减值）。若2027年人民币维持强势，按营收185.2亿、外币敞口约20-25%估算，每1%人民币升值对应约0.15-0.25亿元汇兑损失（非精确，仅作方向性压力测试）；该变量已作为S类情景，不进入2027E基准（基准仅保留0.8%财务费用率）。

### 1.3 通胀与大宗商品传导

| 原材料 | 最新趋势（2026-10） | 对毛利率影响 |
| :--- | :--- | :--- |
| 铝（轻量化主材） | **长江现货月均23,690元/吨（环比-2.33%），月末23,300元/吨；沪铝主力月末23,100元/吨（月-2.8%）；社会库存71.6万吨（月+0.8万吨，7月以来首次月度净累库）** | **边际利好**——较9月的24,260元/吨回落约570-960元，Q4轻量化成本压力缓解；11月预计区间震荡（复产+淡季 vs 低库存） |
| 钢材 | 产能过剩，价格偏弱 | 利好盘式制动器成本端 |
| 铜/芯片 | 铜价高位（LME 1.2-1.4万美元/吨，同比+30%），车规芯片供应偏紧 | 电子电控成本压力仍存 |
| 汇率 | 人民币偏强 | **偏空**（见1.2） |

**综合判断**：原材料成本端从"高位再上行"转为"高位回落"，Q3毛利率20.33%已部分体现；但铜/芯片与汇率形成对冲，**2027E毛利率基准维持19.7%（而非上调），铝价回落作为Bull情景的上行期权（20.3%）**。

## 二、地缘政治风险——USMCA拒绝续期是结构性升级 ★★★★★

### 2.1 ★ 重磅事件：USMCA拒绝16年续期（2026年7月1日）

**事件概要**：2026年7月1日，USMCA三国联合审查会议召开。墨西哥和加拿大均已正式表示愿意将协议延长16年，但**美国贸易代表Greer宣布拒绝续期**，触发协议的年度审查机制。

**关键事实**：
- USMCA没有终止，现有关税优惠、原产地规则、投资保护仍然完全有效
- 协议将存续至2036年，但每年需进行联合审查
- 美国明确表示寻求更严格的汽车原产地规则（如提高区域价值含量要求、增设美国特有含量要求）
- 美国正在与墨西哥进行双边谈判（第三轮7月20日墨西哥城），与加拿大的谈判尚未正式启动
- **核心目标**：堵截中国零部件通过墨西哥转口、打击"非市场经济体"投资、收紧汽车核心部件原产地门槛

**对伯特利的直接冲击链**：
```
USMCA拒绝续期
    ↓
汽车原产地规则进入长达10年的"年度重谈"周期
    ↓
墨西哥工厂的USMCA合规性面临持续升级的门槛
    ↓
① 墨西哥工厂的本地化采购比例要求可能进一步提高
② 中国产零部件通过墨西哥享受USMCA优惠的通道可能被彻底封堵
③ Section 232关税（25%）对非USMCA合规产品的适用范围可能扩大
    ↓
伯特利墨西哥工厂的海外故事面临结构性不确定性
```

## 三、产业政策

### 3.1 利好伯特利的政策

| 政策 | 最新状态 |
| :--- | :--- |
| **GB 21670-2025（新增EMB法规）** | 2026年1月已实施，已为EMB量产扫清法规障碍 |
| **GB 17675-2025（线控转向法规）** | 2026年7月起实施，删除机械连接强制要求 |
| **"十五五"智能底盘标准化** | 工信部推进中 |
| **反"内卷"政策** | 中汽协等机构倡议反对无底线价格战，5月效果初现 |

### 3.2 对伯特利不利的政策

| 政策 | 影响 |
| :--- | :--- |
| **新能源汽车购置税减半（2026年起）** | 增加购车成本，压降终端销量预期 |
| **以旧换新补贴方式调整** | 从"定额制"改"比例制"，低价车补贴缩水 |
| **反补贴调查风险** | 若EMB出口放量，可能引发海外反补贴调查 |

### 3.3 政策影响净评估

政策组合对伯特利的影响呈现"**短期压力+中长期分化**"的格局：
- **短期（2026年）**：购置税减半+补贴退坡压制终端需求、毛利率承压
- **中期（2027-2028年）**：EMB/线控转向法规红利释放，但竞争加剧可能侵蚀红利
- **长期（2028+）**："十五五"智能底盘战略支持，但USMCA规则不确定性将持续10年

## 四、模块四核心结论（2026年11月）

1. **USMCA仍是最大的中期外部风险，但10月无新增恶化**：美国拒绝16年续期→年度审查；USITC第三份原产地规则报告法定截止2027-07-01，10月听证已举行、无结论；墨西哥10-13对整车组装件（9803.00.01）临时免关税，边际缓和SKD/CKD项目成本，但不改变"中国资本+本地化率"审查方向。伯特利墨西哥工厂的USMCA合规门槛仍在抬升，摩洛哥投产是主要对冲。
2. **汇率取代铝价成为Q3最大的外部利润扰动**：人民币偏强使前三季度财务费用达0.92亿元（去年同期-0.14亿），其中汇兑损失约0.4-0.5亿；这是归母净利率从10.90%降至9.76%的重要单项。汇率属不可预测变量，归入S类，不进入2027E基准（基准仅保留0.8%财务费用率）。
3. **铝价10月回落是确定性利好**：长江现货月均23,690元/吨（-2.33%）、月末23,300元/吨、沪铝主力月末23,100元/吨（-2.8%），社会库存71.6万吨（月+0.8万吨，7月以来首次累库）。Q4轻量化成本压力缓解，但铜/芯片与汇率对冲，2027E毛利率基准维持19.7%，铝价回落计入Bull情景（20.3%）。
4. **H股聆讯仍停滞，稀释与合规压力未解**：5月21日递表，9月18日证监会补充五项材料（未决诉讼/境外投资/募集资金境内外金额/奇瑞关联交易/质押担保），截至10-31无聆讯或回复类公告；11月聆讯预期存在不确定性。发行价若低于每股内含价值（或市价）将造成明显摊薄，回购1亿元仅部分对冲。
5. **治理边际改善但未消除**：回购1亿元已执行（371万股/26.33-27.39元），10-29获"金辑奖·中国汽车新供应链百强"；但董秘信披违规历史、奇瑞关联交易（收入占比约四成）仍是H股审核与治理折价的核心来源，审计中维持治理-2%。
6. **新增公司行动**：2026年半年度10转4.2已获股东会通过，10-28公告"伯25转债"11-03起停止转股，**11-04披露权益分派实施公告**；除权后总股本约12.75亿股，股价与每股指标按1.42折算，不改变市值与估值结论。
