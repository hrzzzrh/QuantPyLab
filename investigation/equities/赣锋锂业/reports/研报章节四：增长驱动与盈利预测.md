# 研报章节四：增长驱动与盈利预测
**研究日期**：2026年7月19日

**更新说明**：自2026年6月13日上期研究以来，发生了以下关键变化：(1) 公司于7月14日发布2026年H1业绩预告，归母净利润36.5-46亿元（中值41.25亿），H1 EPS中值1.975元/股，验证了Base情景的盈利修复逻辑；(2) 碳酸锂经历了单边下行（17.46→15.1万元/吨，-13.5%），Q3均价已跌破Base假设的16.5万元/吨；(3) 锂电板块7月6-10日发生系统性踩踏，板块个股普遍暴跌20-40%；(4) 高盛下调公司H股至"沽售"，预测H2锂价9,500美元/吨（约7.8万人民币），但该预测与当前供需基本面严重背离。综合判断：H1业绩验证了公司的盈利能力，但Q3锂价下行压力超出此前预期。Base情景全年均价假设从16.5万元/吨下调至15.5万元/吨，但H1已锁定的均价（约16万元/吨）构成安全垫。

## 1. 分业务 P*Q 模型的证据链锚定 (2026年目标年份)

预测基准：2026年行业供需从"弱平衡"演变为 **"硬缺口"（-5至-10万吨LCE）**，储能爆发填补车端增速放缓的缺口，锂价中枢系统性上移。

### 1.1 销量 (Q) 确定性溯源与预测
*   **核心假设（维持）**：2026年锂盐有效总销量达到 **22.5万吨 LCE**（较2025年的18.48万吨增长约21.7%）。
*   **内生动力证据（强化）**：
    *   非洲马里 Goulamina 锂辉石项目一期（50.6万吨精矿）2025年产出33.66万吨精矿，**2026年目标满产**，且公司已100%控股Mali Lithium。
    *   阿根廷 Cauchari-Olaroz 盐湖稳定爬坡，2026年产量指引3.5-4万吨LCE。
    *   Mariana 项目一期（2万吨氯化锂）已于2025年2月投产，逐步释放产能。
    *   Q1实际锂盐出货约5万吨，验证全年22.5万吨目标的可行性。
*   **确定性评分：4.5分（较高→极高）**。Q1实际出货已验证产能爬坡节奏，Goulamina满产确定性增强。

### 1.2 价格 (P) 趋势推演
*   **核心假设（下调）**：2026年碳酸锂全年含税均价中枢 **15.5万元/吨**（不含税约 13.7万元/吨），较上期16.5万元/吨下调6.1%。
    *   Q1实际：均价约15万元/吨，公司已在该价位实现29.72%毛利率和20.90%净利率。
    *   Q2实际：期货从20.99万跌至15.76万再反弹至17.46万，Q2均价预计16.5-17万元/吨，高于全年预估中枢。
    *   Q3运行中（截至7月17日）：期货LC2609约15.1-15.3万元/吨，现货电池级15.1万元/吨。津巴布韦精矿7月集中到港（7月5-20日核心窗口）叠加澳洲复产预期，Q3均价预计**14.5-15.5万元/吨**。
    *   Q4预判：8月中旬新电池产能集中投产（花旗调研确认），叠加Q4传统储能旺季+动力电池旺季，需求端有望边际改善。但供给增量（津巴布韦持续到港+澳洲复产矿石Q4抵达）与需求增量形成博弈。预计Q4均价**15-17万元/吨**。
*   **成本传导与竞争证据**：8万元/吨为全球高成本矿的现金成本线。当前15.1万元/吨仍显著高于成本支撑。但花旗产业链调研显示一个重要分歧——上游矿商/电池制造商认为当前价格"可接受"，下游储能系统商则在拼命压价。这种产业链内部的定价权博弈意味着锂价在15万元/吨附近存在需求端的边际承接力（下游趁跌价补库），但也意味着上行空间被储能IRR天花板限制（18万元+时中国独立储能项目IRR跌破6%决策红线）。
*   **确定性评分：3.0分（中，从3.5分下调）**。Q1-Q2均价已锁定，但Q3/Q4价格不确定性较上期增加。下行动力来自供给增量超预期释放，上行动力来自8月新电池产能投产+Q4旺季补库。

## 2. 利润矩阵与多态情景推演 (Dynamic Scenario Planning)

基于Q1实际财务数据（营收91.96亿元，归母净利18.37亿元，毛利率29.72%，净利率20.90%）及H1业绩预告中值（归母净利约41.25亿元），我们对2026年全年利润进行情景推演。公司自有矿占比持续提升，H1已确认的盈利修复趋势不可逆，但Q3锂价下行超出此前预期。

### 【情景一：中性 Base】—— 概率55%，最可能发生（较上期下调5个百分点）
*   **参数**：锂盐全年含税均价 15.5万元/吨（不含税13.7万元/吨），单吨净利约 4.0万元（较上期4.7万元下调，因H2均价下行）。电池板块盈利显著改善。
*   **H1已实现**：归母净利约41.25亿元（中值），其中PLS股票出售贡献税前约9.81亿元（税后约7.85亿元）。
*   **H2预估（不含PLS收益）**：锂盐22.5万吨×下半年约11万吨出货量×单吨净利约3.5万元≈38.5亿元 + 电池及其他约8亿元 ≈ 46.5亿元（其中锂盐板块受Q3低价拖累，Q4旺季边际改善）。
*   **公司总净利润**：H1(41.25) + H2(46.5) - 内部抵消 ≈ **78 亿元**（较上期85亿元下调8.2%）。
*   **EPS**：78 / 20.97 ≈ **3.72 元/股**（较上期4.06元下调8.4%）。

### 【情景二：乐观 Bull】—— 概率20%，维持不变
*   **参数**：锂盐全年含税均价 18万元/吨（不含税15.9万元/吨）。8月新电池产能集中投产+Q4旺季补库，锂价强劲反弹至18-20万。锌巴布韦精矿到港量低于预期（受配额及物流瓶颈约束），供给增量释放慢于预期。
*   **锂盐板块净利**：22.5万吨 × 6.0万元 ≈ 135 亿元。
*   **电池及其他板块净利**：约 25 亿元。
*   **公司总净利润**：约 **105 亿元**（较上期120亿元下调，因H2价格兑现度打折）。
*   **EPS**：105 / 20.97 ≈ **5.01 元/股**（较上期5.73元下调12.6%）。

### 【情景三：保守 Bear】—— 概率25%，较上期上调5个百分点
*   **参数**：锂盐全年含税均价 13万元/吨（不含税11.5万元/吨）。Q3/Q4锂价持续低迷（13-14万区间），供给增量全面释放，锌巴布韦+澳洲+智利三线增量形成实质性过剩。下游刚需采购，无大规模补库。
*   **H2预估**：锂盐下半年出货约11万吨×单吨净利约1.8万元≈19.8亿元 + 电池及其他约6亿元 ≈ 25.8亿元。
*   **公司总净利润**：H1(41.25) + H2(25.8) ≈ **67 亿元**（较上期50亿元上调，因H1高安全垫已锁定）。
*   **EPS**：67 / 20.97 ≈ **3.20 元/股**（较上期2.39元上调33.9%，因H1业绩超预期）。

## 3. EPS 预测与逻辑索引
结合总股本 20.97 亿股：
*   **2026年 Base EPS 预测**：**3.72 元/股**（较上期4.06元下调8.4%，主要反映H2锂均价从16万+下移至~15万）。
    *   *证据回溯*：H1业绩预告中值41.25亿元（已验证）；Q3锂价15.1万元/吨（7月17日实时数据）；锂盐全年均价15.5万元/吨的核心假设。
*   **2026年 Bull EPS 预测**：**5.01 元/股**（较上期5.73元下调12.6%，因Bull情景H2价格兑现度打折）。
*   **2026年 Bear EPS 预测**：**3.20 元/股**（较上期2.39元上调33.9%，因H1业绩超预期已锁定较高安全垫）。

**H1业绩预告交叉验证**：
*   H1 EPS中值1.975元 vs 上期Base全年EPS 4.06元，H1达成全年目标的48.6%，处于合理区间（锂企业H1通常占全年45-48%）。
*   H1扣非净利润中值36亿元，非经常性损益（PLS出售+公允价值变动）贡献约5.25亿元。H2扣非盈利能力将是检验Base EPS的关键——若H2锂均价维持15万元/吨，公司凭自有矿成本优势仍可实现每吨3-3.5万元净利（测算约38.5亿元H2扣非+8亿元电池），H2总计约46.5亿元。
