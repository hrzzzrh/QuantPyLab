# 研报章节六：技术面分析
**研究日期**：2026年7月19日

**重大更新说明**：自2026年6月13日上期研究以来，技术面发生了根本性恶化。股价从71.16元持续下跌至48.48元（7月17日收盘），累计跌幅-31.9%。200日均线（长期趋势生命线）被有效击穿且未收复，MA60死叉MA200的趋势正在形成。锂电板块7月6-10日的系统性踩踏（板块个股普遍暴跌20-40%）加速了技术面的全面恶化。当前趋势结构已从"长期上升趋势中的深度回调"蜕变为"中期趋势逆转"，需以全新视角重新评估。

## 1. 趋势架构分析
当前赣锋锂业（002460）处于**中长期上升趋势被实质性破坏→探底寻底**阶段。趋势结构已从"上升趋势中的回调"恶化为"趋势逆转确认"，需以防御性框架重新评估。

*   **均线系统（全面恶化）**：
    *   5日均线：当前位于 **51.68元**（后复权约733元）。股价48.48元处于所有主要均线下方，短期均线呈空头排列。
    *   60日均线（MA60）：当前约 **63.00元**（后复权约891元）。股价已从6月13日的71.16元跌至48.48元，较MA60低约23%。MA60已拐头向下，失去支撑意义。
    *   200日均线（MA200）：当前约 **63.76元**（后复权约901元）。**关键恶化**：6月8日曾短暂击穿MA200（62.76元）但次日收复。本次7月7日以61.44元收盘再次击穿MA200，此后连续8个交易日位于MA200下方运行（7月8-17日），且未出现任何有效的收复尝试。**200日均线的有效跌破（连续多日无法收复）是中长期趋势逆转的技术确认信号。**
    *   均线系统：MA5 < MA10 < MA20 < MA60，短期均线全面空头排列。MA60已开始下行并向MA200靠拢，**MA60死叉MA200（"死亡交叉"）在未来2-3周内形成的概率极高**，这将是对长期多头趋势的终极技术否定。
*   **价格行为（下跌结构回顾）**：
    *   6月13日（上期锚点）：71.16元——当时判断"本轮极端下跌已完成"，MA200提供有效支撑。
    *   6月22-24日：72.05→71.62元——横盘整理，但始终未能突破MA60（77.18元）。
    *   6月25日-7月1日：68.36→65.92元——开启新一轮下跌，锂价从17.46万向15万滑落。
    *   7月2-7日：63.99→61.44元——**加速下跌，7月7日收盘61.44元，再次击穿MA200（63.76元）**。
    *   7月8-10日：锂电板块系统性踩踏，56.17→55.99→53.63元，**三日连续大阴线，与天齐锂业、融捷股份等板块个股同步暴跌**。
    *   7月14-17日：H1业绩预告发布（52.55→51.50→49.97→48.48元），**业绩利好完全无法阻止股价下跌——典型的"买预期、卖事实"及板块系统性减仓信号**。
*   **阶段定性**：本轮下跌已从"技术性回调"演变为"趋势逆转+板块系统性抛售"。6月的MA200支撑逻辑已被彻底证伪。当前处于**非理性的恐慌性杀跌阶段**——H1业绩实证41亿净利润却无法阻止股价跌破50元，说明市场定价机制暂时失灵，由资金面和情绪面主导。

## 2. 关键支撑与阻力位（以不复权市价标注）
*   **历史极值阻力（原目标位，现已遥远）**：**91.45元**（后复权1,293.03元，5月6日52周前高）。当前距此位有+88.6%上行空间，短期内突破概率极低。
*   **MA200阻力（趋势分界线）**：**63.76元**（后复权901.67元）。此位已从"支撑"变为"阻力"。股价若反弹至此位附近将遭遇极强的套牢盘解套抛压。收复此位是趋势重新转多的最低技术条件。
*   **MA60阻力**：**63.00元**（后复权891元）。已拐头向下，与MA200接近交叉。收复MA60的意义已下降——更关键的是看MA60是否与MA200形成死叉。
*   **当前价位**：**48.48元**（后复权687.43元），7月17日收盘。距52周最低价30.60元有约37%下行空间，距52周最高价91.45元有约89%上行空间。
*   **短期支撑（心理关口）**：**45.00元**（整数关口）。若跌破此位，下一支撑为前低密集成交区40元附近。
*   **估值支撑（基本面锚）**：**40.00元**（对应PB约1.80x，2026E PE约10.8x，接近全历史PB分布的极端低位）。
*   **极端支撑（底线）**：**30.60元**（52周最低价，2025年锂价低谷期的市场定价极值。但当前基本面远优于彼时——彼时公司亏损，今日公司H1盈利41亿）。

## 3. 量价行为与未来走势演绎
*   **量价结构分析**：
    *   **下跌放量（危险信号）**：7月8-10日三根大阴线对应成交量分别为69.5万手、71.7万手、56.4万手（日均66万手），显著高于6月下跌阶段的45-55万手。**下跌过程中放量意味着机构性卖盘而非散户恐慌——这是锂电板块系统性减仓的铁证。**
    *   **7月14日H1业绩预告日的异常量价**：当日成交量41.0万手（相对缩量），股价从52.55→51.50（-2.0%）。**业绩利好无法触发反弹，是为"利空式下跌"——市场已完全price-out锂矿板块。**
    *   **7月15-17日**：51.50→49.97→48.48元，连续三日在50元关口附近缩量下行。成交量从39.5万→67.2万→50.3万手，出现初步的量价背离（价格新低但成交量未同步放大），可能是抛压衰竭的早期信号。
    *   **锂价-股价联动关系发生质变**：6月下跌中，锂价与股价高度联动（15.76万vs 61.18元同时见底）。但当前锂价15.1万元/吨（高于6月4日低点15.76万），股价48.48元却远低于6月8日低点61.18元——**锂价-股价联动已断裂，显示市场不再以锂价作为定价锚，而是对整个锂矿板块执行系统性风险折价。**
*   **短期走势（1-3个月）**：
    *   **最可能路径（概率约55%）**：股价在**[40, 55]**区间内震荡寻底。45元（心理关口）和40元（PB约1.8x极端估值）为两个关键支撑。反弹阻力位在55元（7月8日缺口上沿）和63.76元（MA200）。
    *   **核心观察点**：未来2-3周内，(1) 成交量能否持续萎缩至30万手以下（抛压衰竭信号）；(2) 锂价能否在15万关口企稳（基本面锚）；(3) 融资余额是否大幅下降（杠杆出清信号）。
    *   **下行风险**：若锂价跌破14万元/吨且融资盘再次强平，股价可能快速下探至40元甚至35元区间。
*   **长期走势（6-12个月以上）**：
    *   MA200（63.76元）已被有效跌破且未收复，长期上升趋势的技术基础已被破坏。当前的核心问题不是"何时创新高"，而是"何时确认底部"。
    *   估值底（2026E PE 13x → PB 2.19x）提供了基本面支撑。类似的技术面崩溃在A股周期股历史上并不罕见——往往出现在周期反转确认后的"二次探底"阶段（市场对周期持久性的集体质疑）。
    *   中长期目标（需先完成底部确认）：若(1) 锂价在15万以上企稳且Q4旺季带动反弹至17万+、(2) H1正式半年报（8月底）确认经营强劲、(3) MA60死叉MA200后重新金叉——则目标价可看向90元（基于2026E EPS 3.72×24.2x PE）。
*   **交易策略建议**：
    *   **已持有仓位**：当前48.48元已被严重低估（2026E PE仅13x），**不建议在当前位置止损**。但需为可能的进一步下跌做好心理和资金准备。若仓位过重（>70%），建议在反弹至50-55元区间适度减仓至50%以下。
    *   **新建仓位**：当前价位极度低估但趋势仍在恶化。建议采用**分批定投策略**——在45-50元区间每下跌3-5%加仓一次（如48→46→44→42元分四批），总仓位逐步建至目标仓位的70-80%。保留20-30%现金应对极端情况（如跌至35-40元区间）。
    *   **右侧确认信号（更安全的入场点）**：(1) 放量大阳线收复10日均线；(2) 连续3日不再创新低；(3) 锂价反弹+板块情绪回暖共振。
    *   **止损纪律**：基于估值而非技术位——若收盘价连续两日低于**38.00元**（对应PB约1.7x，2026E Forward PE约10x），意味着市场正在定价远超出基本面的悲观预期，需重新评估整个投资逻辑。

## 4. 估值与技术的交叉验证
*   当前动态PE（2026E Base EPS 3.72元）仅 **13.0倍**，处于公司全历史PE分布的极端低位（P25约35x，P50约54x）。当前PE已低于2024年公司亏损期间的PE（彼时PE为负，PB最低触1.5x）——但彼时公司确为亏损，今日H1已盈利41亿。
*   **PB视角的极端性**：当前PB 2.19倍，处于全历史PB分布的约3%分位。公司上市以来PB最低区间为1.5-2.0x（2024年行业深度亏损期）。当前PB已接近该极端区间，但基本面显著优于彼时。
*   技术面全面恶化（MA200有效跌破、MA60死叉MA200即将形成）vs 基本面持续改善（H1净利41亿、Goulamina满产、储能满产满销），形成了该股历史上最极端的**"基本面-技术面剪刀差"**。这种剪刀差无法长期维持——要么基本面随后恶化（锂价崩溃、业绩暴雷），要么技术面通过股价反弹修复。
*   52周价格区间：不复权最低价30.60元 → 最高价91.45元，当前48.48元处于该区间的约33%分位。已回吐本轮上涨（30.60→91.45）的约70.6%，远超技术性回调的黄金分割极限（61.8%）。
