# 研报章节六：估值定价分析

**研究日期**：2026年08月02日

---

## 一、价值锚定：适配性估值方法选择

伊利股份具有稳定盈利、高分红、低增长的成熟消费品龙头特征，适用以下估值路径：

### 方法一：PE估值（主锚，权重50%）

**理由**：盈利稳定且可预测，PE是最直观的消费品估值锚。

| 基准 | PE倍数 | 对应市值（亿元） | 对应股价（元） | 逻辑 |
| :--- | :--- | :--- | :--- | :--- |
| 历史中位（2019-2026） | 23.93x | — | — | 仅作参考，A股估值中枢下移 |
| 全球乳业龙头平均 | 18-22x | — | — | 雀巢~20x，达能~18x |
| **基准PE** | **18x** | **2,196** | **34.73** | 盈利确定性溢价+消费龙头溢价 |
| 保守PE | 15x | 1,830 | 28.93 | 接近当前PE，市场悲观延续 |
| 乐观PE | 22x | 2,684 | 42.44 | 消费复苏+龙头发掘 |

**PE定价的审慎思考**：
- 当前PE仅14.82x（2026年7月31日收盘27.10元对应），处于近5年约15%分位（近5年PE 25分位15.74x），较6月26日的13.27x（约6%分位）已修复约1.6x，但仍显著低于历史中位数23.93x
- 超低PE的原因并非市场"误判"——2024年业绩暴雷（Q4亏损）、液态奶持续萎缩、人口结构担忧均是合理折价因素
- 7月中旬以来股价反弹+11.7%，叠加原奶价格周度同比转正（周期拐点确认）、H1业绩韧性验证（机构预期归母净利77亿/+6.9%），市场开始对"竞争格局改善+周期反转"进行重新定价，PE中枢有望向15-18x修复，但要回到23x+的历史中位仍需要消费信心和人口预期的根本性逆转
- **给予18x PE的基准估值**：对应2026年EPS 1.93元，即35元目标价（不复权市价）

### 方法二：PB-ROE模型（交叉验证，权重25%）

**理由**：ROE稳定在20%+，PB-ROE框架适用。

- 2025年ROE：20.87%，2026E ROE：~19.5%
- 可持续ROE估值：`(ROE - g) / (r - g) = (19.5% - 2%) / (8% - 2%) = 2.92x PB`
- 当前BVPS：9.42元
- 理论合理股价：9.42 × 2.92 = **27.51元**

但PB-ROE模型对ROE假设高度敏感，如果ROE持续维持在20%以上（伊利历史上ROE波动区间15-21%），合理PB可上升至3.0-3.3x。考虑到股本回购注销持续进行，BVPS有上行趋势。

### 方法三：股息贴现（DDM，权重25%）

**理由**：承诺2025-2027年分红比例≥75%，适合DDM估值。

- 2025年每股分红：1.38元（0.90年末+0.48中期）
- 2026E EPS × 75%：1.93 × 0.75 = 1.45元
- 折现率假设8%，永续增长率2%
- 内在价值：1.45 / (8% - 2%) = **24.17元**

DDM得出的价值偏低（24.17元），主要是因为伊利虽然分红慷慨，但股息增长率有限（公司处于成熟期，利润增速仅中个位数）。

### 综合估值锚定

| 估值方法 | 权重 | 对应股价 | 加权贡献 |
| :--- | :--- | :--- | :--- |
| PE估值（18x 2026E EPS） | 50% | 34.73元 | 17.37 |
| PB-ROE模型 | 25% | 27.51元 | 6.88 |
| DDM股息贴现 | 25% | 24.17元 | 6.04 |
| **综合基准市值/股价** | — | **1,915亿 / 30.29元** | — |

## 二、估值全变量对冲审计矩阵

| 审计维度 | 核心审计因子 | 审慎思考（估值影响力过滤） | 调节幅度 | 深度理由 |
| :--- | :--- | :--- | :---: | :--- |
| **内部：企业底层特质** | 战略定力+业务多元化的抗风险能力 | 伊利多元化布局（液态奶→奶粉→冷饮→深加工）在行业低谷期已验证其抗风险价值，这是普通乳企不具备的稀缺能力 → **溢价** | **+5%** | 业务结构多元化降低了盈利波动性，增加了长期现金流的可预见性，可给予确定性溢价 |
| **内部：治理与资本配置** | 75%+分红+回购注销+管理层稳定 | 高分红承诺和回购注销是A股罕见的"股东友好"行为，潘刚团队20年稳定经营→ **溢价** | **+3%** | 高分红相当于为估值提供了一个"股息底"，降低了下行风险 |
| **宏观：政策与战略对齐** | 灭菌乳国标+反补贴税+育儿补贴+消费刺激 | 三大利好同时落地，但多数政策的实际业绩弹性有限（灭菌乳国标行业已基本符合、育儿补贴金额温和）→ **微幅溢价** | **+2%** | 政策利好更偏向"信心催化"而非"实质增量"，给予轻微溢价而非大幅上调 |
| **宏观：地缘与外部约束** | 供应链国际化风险 | 伊利海外营收占比<5%，地缘风险敞口小。但进口关键原料（乳清蛋白等）若受限可能影响成本 → **中性** | **0%** | 风险敞口极小，不足以构成折价因子 |
| **市场：流动性与风格** | 机构持仓集中度+红利风格契合度 | 当前市场风格偏向红利/价值，伊利股息率约5.1%、低PE+稳定现金流高度契合 → **溢价** | **+3%** | 低利率时代红利资产享受流动性溢价，短期可能维持，但中期风格轮动是必然 |
| **综合调节系数** | Σ = +13% | — | | |
| **修正目标市值** | 1,915亿 × (1+13%) = **2,164亿** | | | |
| **修正目标股价** | = **34.21元**（不复权市价） | | | |

**负向因子的审慎论证（防乐观偏差）**：审计矩阵未纳入"出生人口-17%压缩婴配粉天花板"与"液态奶结构性萎缩"两项负向因子，理由如下——(1) 两项压力均已体现于E端：2026E婴配粉增速假设仅+5%-10%（低确定性评分3/5）、液体乳-2%至+2%，盈利预测已充分吸收人口与品类逆风；(2) 估值端的折价已由DDM/PB-ROE方法中的低永续增长假设（g=2%）与历史分位锚定（PE基准18x远低于历史中位23.93x）系统性反映；(3) 若在PE调节中重复扣减，将构成"E与PE双重计算"。故综合调节+13%中不含人口折价，但该风险在保守情景（-9.2%净利）与风险因素章节中显式保留。此处理符合框架"具体的、可计算的钱进E；不可计算、关乎信心的进PE"的纯净性准则。

## 三、逻辑纯净性校验

| 因子 | 已体现于E（利润预测） | 需体现于PE（估值倍数） | 说明 |
| :--- | :--- | :--- | :--- |
| 市场份额提升 | ✅（液态奶、婴配粉营收假设已含份额增长） | — | 量价假设已纳入 |
| 多元化业务结构 | — | ✅（+5%溢价） | 降低波动性→确定性溢价 |
| 高分红政策 | — | ✅（+3%溢价） | 降低下行风险→股息底溢价 |
| 原奶成本红利 | ✅（2026年毛利率假设已含成本假设） | — | 成本假设已量化 |
| 政策利好 | — | ✅（+2%溢价） | 不可量化为具体利润增量 |
| 行业竞争趋缓 | — | ✅（+3%溢价） | 不可量化为具体利润，但降低不确定性 |

**锚点回测**：修正后隐含PE = 34.21 / 1.93 ≈ **17.7x**，接近全球乳业龙头平均水平（18-20x），高于当前14.82x（对应2026E PE约14.0x）但显著低于历史中位23.93x，估值定价合理。

**估值方法敏感性披露**：综合估值锚定30.29元（PE法34.74×50% + PB-ROE 27.51×25% + DDM 24.17×25%）叠加+13%审计调节后得基准34.21元。其中DDM（24.17元）与PB-ROE（27.51元）显著低于基准价——两法分别受制于"成熟期低增长+高分红（股息增长有限）"与"ROE假设敏感性"，而PE法以盈利确定性与全球龙头均值回归为依据。基准价对PE法权重与全正面调节（+13%）存在10-20%的敏感性：若审计调节降至+8%，基准价约33.2元；若PE法权重降至40%，综合锚定约29.2元。投资者应意识到基准目标价隐含的估值弹性和置信区间。

## 四、三态目标价与盈亏比

| 情景 | 概率 | 2026E EPS | 目标PE | 目标股价（元） | 市值（亿元） |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **保守（Bear）** | 25% | 1.66 | 14x | **23.24** | 1,470 |
| **基准（Base）** | 50% | 1.93 | 18x（修正后17.7x） | **34.21** | 2,164 |
| **乐观（Bull）** | 25% | 2.13 | 22x | **46.86** | 2,964 |

**当前价格**：27.10元（不复权市价，2026年7月31日收盘）

> **价格动态说明**：6月5日除权（2025年度分红每股0.90元）后股价一度于7月上旬在24.5-25.0元区域筑底（7月13日盘中低点24.52元），随后受原奶价格周度同比转正（7月第三周起）、H1业绩预期稳健（机构预测归母净利约77亿/+6.9%）、优然牧业股权绑定完成等催化持续上行，7月30日盘中最高27.70元，创52周新高（后复权口径）。7月31日收盘27.10元，较6月26日收盘价24.27元上涨+11.7%，验证了此前"估值错杀"的判断。

**盈亏比计算**：
- **加权目标价** = 0.25×23.24 + 0.50×34.21 + 0.25×46.86 = **34.63元**（三态概率加权，框架强制口径）
- 上行空间（加权目标价）：34.63 - 27.10 = 7.53元（+27.8%）
- 下行风险（保守情景价，未调节）：27.10 - 23.24 = 3.86元（-14.2%）
- **盈亏比** = 7.53 / 3.86 = **1.95 : 1** ✅（框架口径；若以基准目标价34.21计为1.84:1）

盈亏比较6月26日大幅收窄（原9.65:1为基准口径，按加权口径约为10.1:1），主因是股价自极端低位反弹+11.7%后上行空间压缩、下行风险回升。盈亏比仍大于1，且保守情景目标价23.24元仍高于6月低点附近的技术支撑（MA250对应约24.98元），下行保护依然存在，但安全边际较6月极端低估时点明显收窄。

## 五、极限压力测试：逻辑证伪场景

**黑天鹅事件定义**："三重打击同时发生"——(1) 中国爆发重大乳制品食品安全事故（类似于2008年三聚氰胺级别的行业信任危机）；(2) 伊利作为行业龙头首当其冲，营收暴跌50%+；(3) 经销商体系崩溃，大规模退货和坏账。

**极端情景估值**：
- 营收：1,210亿 → 600亿（-50%）
- 净利润：清零或巨亏（品牌重建需3-5年）
- 清算价值：净资产595.88亿 - 商誉21.73亿 - 无形资产46.77亿 ≈ 527亿
- 每股清算价值：527亿 / 63.25亿股 ≈ **8.34元**
- **地狱价格（净资产折价30%）**：8.34 × 0.7 ≈ **5.84元**

*概率评估：发生概率 < 1%。2008年后中国乳制品安全监管体系全面升级，伊利MSCI ESG评级AA级，全产业链溯源体系完善。但此类事件一旦发生，杀伤力是毁灭性的。*

## 六、估值结论

伊利股份当前27.10元的价格，对应2026E PE约14.0x（27.10/1.93），处于历史偏低分位（近5年约15%）。综合PE估值、PB-ROE模型和DDM模型，考虑全变量对冲审计修正后，**基准目标股价34.21元（不复权市价），对应市值约2,164亿元，上行空间约26.2%**。三态盈亏比1.95:1（概率加权口径），风险收益比仍为正。自6月26日研报发布以来股价已反弹+11.7%，印证了"极端低估值错杀"的判断；当前估值修复进入中段，上行空间收窄但逻辑仍在兑现轨道上。
