# 研报章节六：估值定价分析

**研究日期**：2026年08月26日

---

## 一、价值锚定：适配性估值方法选择

伊利股份具有稳定盈利、高分红、低增长的成熟消费品龙头特征，适用以下估值路径：

### 方法一：PE估值（主锚，权重50%）

**理由**：盈利稳定且可预测，PE是最直观的消费品估值锚。

| 基准 | PE倍数 | 对应市值（亿元） | 对应股价（元） | 逻辑 |
| :--- | :--- | :--- | :--- | :--- |
| 历史中位（2019-2026） | 23.93x | — | — | 仅作参考，A股估值中枢下移 |
| 全球乳业龙头平均 | 18-22x | — | — | 雀巢~20x，达能~18x |
| **基准PE** | **18x** | **1,944** | **30.24** | 盈利确定性溢价+消费龙头溢价 |
| 保守PE | 14x | 1,372 | 21.70 | 减值后盈利仍待市场重新信任 |
| 乐观PE | 22x | 2,464 | 38.94 | 消费复苏+龙头发掘 |

**PE定价的审慎思考**：
- 当前PE TTM 13.56x（2026年8月25日收盘25.90元对应；TTM净利尚未纳入H1减值），处于近5年约9%分位；若以含减值的动态TTM净利101.2亿计约16.2x
- 半年报减值冲击后，市场对"账面利润"的信任需要时间修复，基准PE从18x的隐含前提（无大额一次性损失）出发依然成立——商誉出清后未来减值拖累收敛，18x对应的是正常化盈利能力而非被冲击后的报表利润
- **给予18x PE的基准估值**：对应下修后2026年EPS 1.68元，即30.24元目标价（不复权市价）

### 方法二：PB-ROE模型（交叉验证，权重25%）

**理由**：ROE稳定在15-21%区间，PB-ROE框架适用。

- 2025年ROE 20.87%；减值冲击后2026E正常化ROE约17.5%-18%
- 可持续ROE估值：`(ROE - g) / (r - g) = (17.5% - 2%) / (8% - 2%) = 2.58x PB`
- 当前BVPS：约8.49元（2026H1末归母权益537.11亿/63.25亿股）
- 理论合理股价：8.49 × 2.58 = **21.90元**；若ROE维持18%以上则合理PB 2.67x、对应22.7元

考虑到分红回购持续（BVPS增长与股价下行对冲），PB-ROE给出的是保守下限参考。

### 方法三：股息贴现（DDM，权重25%）

**理由**：承诺2025-2027年分红比例≥75%，适合DDM估值。

- 下修后2026E EPS 1.68元 × 75% = 每股股息1.26元
- 折现率假设8%，永续增长率2%
- 内在价值：1.26 / (8% - 2%) = **21.00元**

DDM得出的价值偏低（21.00元），反映的是"利润零增长+高分红"的纯防御定价；当前股价25.90元高于DDM价值，说明市场仍在为盈利恢复与份额集中支付溢价。

### 综合估值锚定

| 估值方法 | 权重 | 对应股价 | 加权贡献 |
| :--- | :--- | :--- | :--- |
| PE估值（18x 2026E EPS 1.68） | 50% | 30.24元 | 15.12 |
| PB-ROE模型 | 25% | 21.90元 | 5.48 |
| DDM股息贴现 | 25% | 21.00元 | 5.25 |
| **综合基准市值/股价** | — | **1,635亿 / 25.85元** | — |

> 注1：三法离散度显著扩大（30.24 vs 21-22元），PE法与PB/DDM法的分歧本质是"减值是否可忽略"——本报告以经营性改善证据（毛销差、现金流、份额）支持PE法主导权重，但需向投资者明示该权重的乐观倾向。
> 注2：综合基准市值=25.85元×63.25亿股=1,635亿元（勾稽口径）。

## 二、估值全变量对冲审计矩阵

| 审计维度 | 核心审计因子 | 审慎思考（估值影响力过滤） | 调节幅度 | 深度理由 |
| :--- | :--- | :--- | :---: | :--- |
| **内部：企业底层特质** | 战略定力+多元化的抗风险能力 | 2026H1收入/毛销差/现金流/份额四大经营变量全面改善验证抗风险能力；**但澳优商誉减值暴露并购整合的远期定价风险，多元化溢价自+5%收窄至+3%** → **溢价（下调）** | **+3%** | 多元化仍降低盈利波动性，但奶粉第二曲线降速削弱了"确定性溢价"的成色 |
| **内部：治理与资本配置** | 75%+分红承诺+管理层稳定+市值管理制度落地 | 高分红承诺未变（2025年75.48%兑现），潘刚团队连任，公司制定《市值管理制度》→ **溢价维持** | **+3%** | 股息底逻辑未被减值动摇，股息率约5.3%（按2025年派息口径）提供下行保护 |
| **宏观：政策与战略对齐** | 灭菌乳国标+反补贴税+育儿补贴+消费刺激 | 政策组合仍在，但育儿补贴未能逆转婴配粉总量收缩（H1奶粉分部仅+1.61%），政策溢价自+2%下调至+1% → **微幅溢价** | **+1%** | 政策托底的边际效力已被H1实证打折 |
| **宏观：地缘与外部约束** | 供应链国际化风险+进口原料涨价 | 海外资产占比13.14%，GLP-1驱动乳清蛋白涨价为新增成本变量但公司D90产线已投产对冲 → **中性偏负** | **0%** | 风险有对冲手段且敞口可控，不足以构成折价因子 |
| **市场：流动性与风格** | 机构持仓集中度+红利风格契合度 | 红利/价值风格仍在但消费板块资金热度降温，股价8月回落-4.4%；自+3%下调至+2% → **溢价（下调）** | **+2%** | 低利率时代高股息资产仍有配置需求，但短期风格贡献收敛 |
| **综合调节系数** | Σ = +9% | — | | |
| **修正目标市值** | 1,635亿 × (1+9%) = **1,782亿** | | | |
| **修正目标股价** | = 1,782亿 ÷ 63.25亿股 = **28.18 ≈ 28.20元**（不复权市价） | | | |

> 注：综合调节系数由上一版的+13%下调至+9%。下调的三处（DNA -2pp、政策 -1pp、流动性 -1pp）均直接对应本次半年报披露的实证信息，符合框架"估值影响力过滤"原则——不是情绪化惩罚，而是把已被证伪或弱化的溢价因子如实撤回。

**负向因子的审慎论证（防乐观偏差）**：审计矩阵未将"澳优商誉减值15.47亿"单独作为PE调节项扣减，理由：(1) 减值属一次性会计出清，已在E端（2026E净利106亿 vs 经营性124亿）完整体现，若再在PE端扣减即构成"E与PE双重计算"，违反框架纯净性准则；(2) 减值的持续性信号（奶粉远期盈利中枢下移）通过"DNA多元化溢价从+5%收窄至+3%"在估值中枢层面体现；(3) 出生人口与液态奶萎缩的结构性压力继续保留于保守情景与风险因素章节。

## 三、逻辑纯净性校验

| 因子 | 已体现于E（利润预测） | 需体现于PE（估值倍数） | 说明 |
| :--- | :--- | :--- | :--- |
| 市场份额提升 | ✅（液体乳、婴配粉营收假设已含份额增长） | — | 量价假设已纳入 |
| 多元化业务结构 | — | ✅（+3%溢价，自+5%下调） | 减值暴露并购整合风险后溢价收窄 |
| 高分红政策 | — | ✅（+3%溢价） | 降低下行风险→股息底溢价 |
| 澳优商誉减值 | ✅（2026E净利106亿已全额吸收） | — | 一次性出清，严禁PE端重复扣减 |
| 政策利好 | — | ✅（+1%溢价，自+2%下调） | 托底有效但增量证伪 |
| 行业竞争趋缓 | ✅（销售费用率17.6%-18.0%假设） | — | 已量化为费用节约 |

**锚点回测**：修正后隐含综合PE = 28.20 / 1.68 ≈ **16.8x**，低于全球乳业龙头平均水平（18-20x），高于当前动态口径的13-16x但显著低于历史中位23.93x。在盈利出清年给予低于全球同业的倍数，其支撑在于经营性盈利能力未受损（还原减值后H1经营性净利约78.1亿、同比正增长），定价合理但置信区间较此前放宽。

**估值方法敏感性披露**：基准价28.20元对PE法权重与审计调节存在敏感性——若PE法权重降至40%（PB/DDM权重各升至30%），综合锚定约24.9元；若审计调节降至+5%，基准价约27.1元。投资者应意识到：在减值冲击后，本报告基准目标价隐含"市场将逐步回归正常化盈利定价"的假设，若三季报再现大额减值则该假设失效，应切换至保守情景定价。

## 四、三态目标价与盈亏比

| 情景 | 概率 | 2026E EPS | 目标PE | 目标股价（元） | 市值（亿元） |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **保守（Bear）** | 20% | 1.55 | 14x | **21.70** | 1,372 |
| **基准（Base）** | 55% | 1.68 | 18x（修正后16.8x） | **28.20** | 1,782 |
| **乐观（Bull）** | 25% | 1.77 | 22x | **38.94** | 2,464 |

**当前价格**：25.90元（不复权市价，2026年8月25日收盘）

> **价格动态说明**：7月31日收盘27.10元创阶段高位后，8月股价随消费板块调整与中报不确定性发酵回落，8月19日盘中最低25.00元，8月11日起收盘跌破MA250年线（后复权2,851.5，折算约26.11元），8月25日收盘25.90元——半年报于8月26日盘后披露，市场对减值冲击的定价尚未完成，当前价格是"业绩披露前"的均衡，存在跳空风险与机会。

**盈亏比计算**：
- **加权目标价** = 0.20×21.70 + 0.55×28.20 + 0.25×38.94 = **29.59 ≈ 29.6元**（三态概率加权，框架强制口径）
- 上行空间（加权目标价）：29.59 - 25.90 = 3.69元（+14.2%）
- 下行风险（保守情景价，未调节）：25.90 - 21.70 = 4.20元（-16.2%）
- **盈亏比** = 3.69 / 4.20 = **0.88 : 1** ❌（框架口径；低于1:1阈值）

盈亏比自8月2日的1.95:1大幅恶化至0.88:1，驱动因素有三：(1) 盈利预测下修压缩目标价中枢（加权34.63→29.6元）；(2) 股价虽回落但幅度（-4.4%）远小于盈利下修幅度；(3) 保守情景价因减值后盈利基数下移而下沉（23.24→21.70元）。**按框架纪律，盈亏比<1意味着期望收益已不能充分补偿下行风险，第一象限定位不再成立。**

## 五、极限压力测试：逻辑证伪场景

**黑天鹅事件定义**："三重打击同时发生"——(1) 中国爆发重大乳制品食品安全事故（类似于2008年三聚氰胺级别的行业信任危机）；(2) 伊利作为行业龙头首当其冲，营收暴跌50%+；(3) 经销商体系崩溃，大规模退货和坏账。

**极端情景估值**：
- 营收：1,240亿 → 620亿（-50%）
- 净利润：清零或巨亏（品牌重建需3-5年）
- 清算价值：净资产537.11亿 - 商誉6.3亿 - 无形资产约46亿 ≈ 485亿
- 每股清算价值：485亿 / 63.25亿股 ≈ **7.67元**
- **地狱价格（净资产折价30%）**：7.67 × 0.7 ≈ **5.37元**

*概率评估：发生概率 < 1%。2008年后中国乳制品安全监管体系全面升级，伊利MSCI ESG评级AA级，全产业链溯源体系完善。但此类事件一旦发生，杀伤力是毁灭性的。*

## 六、估值结论

伊利股份当前25.90元的价格，对应动态口径PE约13-16x、PB 2.75x（近5年约3%分位），处于历史深度低位区间。综合PE估值、PB-ROE模型和DDM模型并叠加下修后的审计调节（+9%），**基准目标股价28.20元（不复权市价），对应市值约1,782亿元，上行空间约8.9%；概率加权目标价29.6元，上行空间约14.2%；盈亏比0.88:1，低于1:1阈值**。本次半年报的减值出清在压低盈利的同时也卸掉了商誉包袱，估值逻辑从"成长修复"切换为"深度价值+出清后弹性"，风险收益比不再支持进攻性定位——评级由第一象限下调至第三象限（Defensive Value），持有/底仓策略，等待右侧信号或更深的赔率。
