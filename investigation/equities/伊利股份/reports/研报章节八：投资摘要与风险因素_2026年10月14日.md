## 一、投资摘要 (Investment Summary)

### 核心逻辑

伊利股份是中国乳业绝对龙头，正处于**"原奶周期反转确认+减值出清完成+盈利口径回归"三重叠加的定价窗口**。本次跟踪将研究目标年份由2026E切换至2027E，核心判断如下：

1. **目标年份切换的本质是"口径回归"，而非经营加速**：2027E 中性归母净利预测130亿元，相对2026E 报表口径（106亿元）+22.6%，但相对2026E **经营性净利（约127亿元）仅+2.4%**；2027E 归母净利率10.24%与2026E 经营性净利率（约10.2%）基本持平。澳优商誉减值15.47亿元已于2026H1全额计提，商誉余额降至约6.3亿元（占净资产1.2%），历史包袱卸下，2027年不再有大额减值拖累。**投资者不应将目标价的上移等同于基本面改善的幅度。**

2. **原奶周期反转已从"预期"变为"确认"，但成本压力的时点提前**：主产省生鲜乳均价由2026年6月的3.03元/公斤升至 **10月第1周的3.10元/公斤（同比+2.0%）**，连续四周环比上行，同比涨幅由+1.0%扩大至+2.0%；散奶价格弹性更大（9月前两周均价3.63元/公斤）。供给端，2026年8月末全国奶牛存栏575.9万头（较2024年2月高点累计去化72.6万头），成母牛占比由2023年的50.8%升至53.8%，进口活牛2026年1-7月同比-31%；**华泰证券预判27-28年原奶供给"更为紧缺"**。需求端，2026年1-7月乳制品产量同比+6%，结束2024-2025年连续负增长。**奶价温和上行对龙头最有利（竞争趋缓→费用率下行），但上行斜率超预期将直接冲击毛利率——这是2027年取代"减值与奶粉降速"的头号风险变量。**

3. **行业总量仍弱，份额逻辑是唯一增长来源**：2026Q2 乳制品线下零售额同比-8.48%（较Q1降幅扩大），常温纯牛奶占比35.57%但同比微降；婴配粉行业截至 MAT 2606 母婴品类-2.3%、普配牛奶粉-2.0%、婴配羊奶粉-12.2%，仅特配牛奶粉+5.2%，CR10 已由2021年62.3%升至2026Q1的76.8%。伊利婴配粉份额18.6%（+0.6pp，第一）、成人粉26.8%（第一），份额逻辑仍在兑现，但**"以份额换增长"的边际效力递减**；成人营养品（中老年奶粉行业2026Q1销售额+27.4%、单罐均价65→73元）与奶酪乳脂2B/深加工（马苏里拉1万吨产线2026年3月投产、欧盟反补贴税5年保护期）是确定性最高的第二曲线。

4. **估值切换后安全边际增厚，赔率显著修复**：2027E 前瞻 PE 仅 **13.69x**（现价28.13元 / 2027E中性EPS 2.06元），当前 PE TTM 17.58x 处近5年约40.9%分位、PB 3.31x 处约34.7%分位。经PE（17x）、PB-ROE（3.0x）、DDM（6%资本化）三法加权并叠加审计调节（Σ=+9%，仅作用中性档），得出 **保守/中性/乐观三态目标价 23.90 / 34.27 / 47.43元**（对应三态市值 1,512 / 2,168 / 3,000亿元），**概率加权目标价 35.49元，中性收益率 +21.8%，盈亏比 1.74:1**（自2026年9月30日的0.41:1修复）。

5. **竞对双向解读已落地并更新**：蒙牛2026H1全业态+7.77%（收入447.95亿元、经营利润36.76亿元创历史新高、鲜奶/奶粉/奶酪均>30%）验证"奶价企稳、消费企稳、结构升级"的行业筑底（需求侧利好共振）；其奶酪平台妙可蓝多2026年前三季度营收48.67亿元（+22.97%）、归母2.12亿元（+20.37%）进一步确认奶酪赛道景气。但竞争侧蒙牛液态奶+5.2%跑赢伊利+1.3%、奶粉+22.8% vs 伊利奶粉分部+1.61%（骤降），竞争强度抬升。飞鹤2026H1营收93.62亿元（+2.3%）、归母8.37亿元（-16.3%）、销售费用率36.6%（+1.9pp），婴配粉80.9亿元（-1.3%）与伊利同向印证总量收缩未逆转。光明乳业2026H1营收118.73亿元（-4.81%）、归母2.51亿元（+15.34%，含资产出售）、扣非2.18亿元（-13.39%），区域龙头仍处调整期。新乳业2026H1营收58.13亿元（+5.2%）、净利4.65亿元（+17.24%），低温赛道结构性机会确认。

6. **股东回报机制强化**：公司承诺2025-2027年分红比例≥75%（2025年实际75.48%），10-20亿元注销式回购方案已生效（期限2026年9月16日至2027年3月15日，回购价上限39.53元/股，**截至2026年9月30日尚未实施**）；2026年10月发行五期超短期融资券合计415亿元、利率仅 **1.29%**，融资成本优势显著，财务费用有望继续贡献净收益。

## 二、风险因素 (Risk Factors)

按对股价潜在影响烈度从高到低排列：

### 🔴 高风险（概率>15%，影响烈度>20%）

**1. 原奶价格上行斜率超预期（2027年新增头号风险，取代"减值与奶粉降速"）**
- 主产省生鲜乳均价10月第1周3.10元/公斤、同比+2.0%，连续四周环比上行；散奶9月前两周均价3.63元/公斤
- 华泰证券预判27-28年原奶供给"更为紧缺"（成母牛集中去化、后备牛补栏有限、进口活牛-31%）；中邮/国金等机构判断2026-2027年成母牛补充或出现断档
- 历史上奶价每变动30%对应伊利毛利率约3.8pp 波动。若2027年奶价升至3.9元/公斤以上（毛利率降至33.0%、压力>2.5pp），2027E 中性归母净利将降至约115亿元（EPS 1.82元），中性目标价降至约32.08元（+14.0% vs 现价），估值修复空间收窄至不足基准情形的2/3，评级应下调至第三象限；**若上述奶价条件与"保利润默契破裂（销售费用率回升至18.5%以上）"同时发生**，2027E 归母净利降至约100-105亿元，按13x PE 计股价约20.6-21.6元（低于保守情景23.90元），需切换至保守情景以下定价并减半仓
- **监测指标**：周度农业农村部生鲜乳价格（重点观察同比涨幅是否突破+5%）、散奶价格、奶牛存栏月度去化

**2. 奶粉第二曲线降速的持续化（2026H1已兑现，2027年仍受总量收缩压制）**
- 奶粉及奶制品2026H1增速骤降至+1.61%（上年同期+14.26%）；尼尔森IQ MAT 2606 口径母婴品类-2.3%、普配牛奶粉-2.0%、婴配羊奶粉-12.2%、婴儿辅食-15.4%
- 2025年出生人口792万（-17%），2028-2029年婴配粉需求面临新一轮冲击；澳优商誉减值隐含管理层下调远期假设（增长率5.05%-7.16%、毛利率上限43.36%）
- 成人营养品（份额26.8%、中老年奶粉行业+27.4%）可部分对冲但体量有限
- **监测指标**：Q3/Q4奶粉分部营收增速、存货跌价计提额、婴配粉份额（跌破15%触发一级证伪）

**3. 终端消费总量收缩超预期**
- 2026Q2 乳制品线下零售额同比-8.48%（较Q1降幅扩大），常温纯牛奶占比35.57%同比微降；纯牛奶、酸奶终端销售额仍在负区间
- 若经济继续下行，乳制品"准刚需"属性可能动摇；2026年9月社零同比+3.2%（增速温和），消费复苏力度不足以支撑乳制品总量反转
- 伊利2027E 营收假设仅+2.4%，若实际转负，中性情景失效

### 🟡 中风险（概率10-20%，影响烈度10-20%）

**4. 存货跌价的后续计提**
- 期末存货跌价准备余额9.35亿元（2026H1末），若原奶上行期大包粉/常温产品价盘承压，不排除零星计提拖累报表利润
- 2026年Q4是传统减值计提季（2024Q4亏损约20亿元、2025Q4仅11.39亿元），三季报/年报计提力度是2027年基数的关键变量

**5. 行业"保利润"默契破裂、价格战重启**
- 若奶价上行未能有效压缩低价竞争空间，或区域性乳企以低价搅局（盒马/超盒算等渠道自有品牌鲜奶950ml仅6.9元），销售费用率可能回升至18.5%以上
- 2027E 销售费用率假设17.5%，每回升1pp 对应约12.7亿元费用、约10亿元税后利润

**6. GLP-1驱动的进口原料涨价**
- WPC80欧洲基准价三年翻两番（近20,000欧元/吨，Vesper指数），D90国内采购价2026年初一度翻倍；中国1-6月乳清粉进口均价+17%、量-8.6%
- 营养品业务成本承压；对冲手段为D90全电渗析产线（3月）、宁夏500吨基地（7月）、现代健康谷奶酪基地

**7. 蒙牛竞争强度抬升**
- 蒙牛2026H1液态奶+5.2%跑赢伊利+1.3%，鲜奶/奶粉/奶酪均>30%；其"一体两翼"战略与世界杯（央视转播钻石合作伙伴）营销投入力度大
- 妙可蓝多2026年前三季度营收+22.97%验证奶酪赛道竞争加剧；若蒙牛动销持续改善，伊利的相对优势叙事弱化

### 🟢 低风险（概率<10%，影响烈度<10%）

**8. 地缘政治影响海外业务拓展**
- 境外资产206.46亿元（占总资产13.14%），东南亚部分市场尚未盈利（公司IR口径），印尼/菲律宾/中东扩张顺利但面临汇率与地缘扰动

**9. 回购注销执行风险**
- 10-20亿元回购方案截至2026年9月30日零实施，若股价持续高于回购价上限39.53元或资金另有安排，注销式回购对EPS的增厚（约0.4%-0.8%）可能不兑现

**10. 食品安全事件**
- 伊利MSCI ESG评级AA级，全产业链品控体系完善，但乳业天然存在食品安全风险（黑天鹅场景下每股清算价值约9.23元、地狱价格约6.46元）

## 三、研究结论象限图 (Final Evaluation Matrix)

```
预期收益空间 ↑
    高     │  第二象限               │  第一象限 ★
            │  Speculative Growth     │  High-Conviction Buy
            │                         │  ┌──────────────┐
    ───────┼─────────────────────────┼──│  伊利股份     │
    低     │  第四象限               │  │  确定性：★★★☆ │
            │  Avoid/Wait             │  │  中性收益：+21.8% │
            │                         │  │  盈亏比：1.74:1 │
            │                         │  └──────────────┘
            │                         │
            │  低                     │  高
```

**伊利股份位于第一象限（High-Conviction Buy 下沿），自第三象限上调**，理由：

- **确定性中等偏高（★★★☆，3.3-3.5/5）**：龙头地位稳固、"一超多强"格局未变、经营性盈利能力经2026H1验证未失速（还原减值后经营性净利约78.1亿元）、原奶周期拐点确认、商誉包袱基本卸下——**但2027年新增"原奶上行斜率"不可控变量，且需求端总量未反转，使盈利路径的确定性低于2026E版本**（核心假设平均确定性评分由3.5/5降至3.3/5）。
- **预期收益空间高（中性+21.8%、加权+26.2%）**：目标年份切换使锚定盈利基数上移22.6%（其中约19个百分点来自减值出清后的口径回归），叠加2027E前瞻PE仅13.69x的低起点，赔率显著修复。
- **盈亏比1.74:1 > 1:1 阈值**：期望收益已充分补偿下行风险，第一象限定位成立。但**赔率改善高度依赖2027年盈利兑现**（剔除切换机械效应后仅0.23:1），且下行风险锚（23.90元）距现价仅-15.0%，安全垫不厚。
- **定位调整的含义**：由"防御/底仓"（第三象限）转向"持有/分批建仓"（第一象限），但执行上仍应遵守"不追高"纪律。**需明示确定性张力**：本次评级上移由**收益端**（目标年份切换使锚定盈利基数上移22.6%）驱动，而确定性评分实际由2026E版本的3.5/5 微降至 **3.3/5（★★★☆，中等偏高）**，且下行风险锚（23.90元）距现价仅-15.0%、安全垫不厚——因此本报告将第一象限定位为 **"High-Conviction Buy 下沿"**，操作上以**分批建仓**而非"核心重仓"为定位；若以更严格的"高确定性+高预期收益"双重标准衡量，本股更接近**第一/第二象限交界**（收益端达标、确定性端仅中等偏高）。**最近的决定性验证节点为2026年三季报（2026年10月30日披露）**：① Q3单季归母需≥33亿元（2025Q3为32.26亿元）方支持2026E 106亿元路径；② 是否再现>3亿元资产减值；③ 奶粉分部增速是否企稳；④ 液体乳Q3增速与合同负债回补。若三季报再现大额减值或奶粉转负，需重检至第三/第四象限。
