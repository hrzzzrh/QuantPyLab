## 三、逻辑证伪警报 (Invalidation Triggers)

以下信号一旦触发，必须承认当前投资逻辑已被动摇，直接启动止损或下调评级：

| 级别 | 证伪信号 | 触发后的行动 |
| :--- | :--- | :--- |
| 🔴 **一级（立即止损）** | 公司爆发重大食品安全事故（类似2008年级别） | 不计成本清仓，基本面逻辑彻底崩溃 |
| 🔴 **一级（立即止损）** | 婴配粉市占率连续两个报告期跌破15% | 第二增长曲线逻辑证伪，下调至第四象限 |
| 🟠 **二级（减半仓+下调评级）** | 液体乳连续三季营收下滑>5% 且 奶粉增速<3% | 双引擎同时熄火，"多元化对冲"逻辑失效 |
| 🟠 **二级（减半仓+下调评级）** | 经营现金流连续两季为负 或 合同负债跌破80亿 | 利润质量严重恶化，经销商体系可能系统性崩溃 |
| 🟡 **三级（下调盈利预测，不加仓）** | 原奶价格暴涨至4.2元/kg以上且竞争格局未改善 | 成本端压力无法通过费用优化对冲 |
| 🟡 **三级（下调盈利预测，不加仓）** | 蒙牛发动全面价格战，伊利被迫跟进（销售费用率>20%） | 行业"保利润"默契破裂，重回低利润率竞争 |
| 🟡 **三级（下调盈利预测，不加仓）** | 2026年全年营收<1,150亿（公司指引1,215亿偏离>5%）| 管理层指引失准，全年盈利预测需大幅下修 |
| 🟡 **三级（下调盈利预测，不加仓）** | 2026H1半年报归母净利增速<2% 或 经营现金流同比继续恶化 | H1验证不及预期，全年122亿预测面临下修 |
