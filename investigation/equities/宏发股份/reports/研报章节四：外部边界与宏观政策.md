# 研报章节四：外部边界与宏观政策

**研究日期**：2026年11月04日  
**研究标的**：宏发股份 (600885.SH)  
**前序核心结论继承**：
- 模块一：2026Q1-3毛利率32.93%、Q3单季33.37%（环比+0.18pp），财务费用1.47亿（同比+536.7%），主要受人民币升值与利息收入下降拖累
- 模块二：NEV国内零售连续10个月负增长、出口+130%；储能2027年目标已完成93%、价格战；电网5万亿投资、特高压招标+49%
- 模块三：宏发全球份额约26.4%（中电元协口径），日美对手战略收缩，护城河宽但原材料与海外敞口大
- **本章核心问题**：在人民币升破6.70、铜价历史高位、关税休战延长的组合下，外部变量对2026-2027年盈利与估值的净影响是什么？

---

## 一、宏观环境变量

### 1.1 利率与折现率环境

**中国货币政策：适度宽松，长端利率进一步下行**

| 指标 | 当前值（2026-11） | 2026年展望 |
|:---|:---|:---|
| 央行政策利率（7天逆回购） | 1.40% | 预计维持或再降10-20bp |
| 1年期LPR | 3.00% | 低位稳定 |
| 5年期LPR | 3.50% | 维持低位 |
| 10年期国债收益率 | **1.62%**（2026-11-03，中国债券信息网） | 低位震荡，机构预测年底1.69% |
| 实际利率 | 约0.7-1.0%（CPI +0.9%） | 通缩压力缓解，实际利率仍偏高 |

**对宏发的影响**：
- **贴现率下行支撑估值**：10年期国债1.62%，低于2026年上半年1.70-1.90%的均值，无风险利率下行理论上支撑PE中枢。按1.62%无风险利率+3.5%风险溢价，股权成本约5.1%，对应25-30x PE的中枢仍成立。
- **融资成本降低**：宏发有息负债仅9.66亿，直接受益有限；但下游客户（车企、家电厂商、电网）融资成本降低有利于资本开支和设备采购，间接利好继电器需求。
- **理财收益率下行**：宏发账面交易性金融资产5.13亿，收益承压。

### 1.2 汇率损益分析（本期最大宏观变化）

**人民币汇率：显著升值，USDCNY 6.66**

| 指标 | 当前值 | 变化 |
|:---|:---|:---|
| USDCNY即期 | **6.6605**（2026-11-04） | 较10-09的6.6925再升0.5%；过去12个月人民币升值约6.37% |
| 2026年初至今 | — | 人民币对美元升值约7% |
| 10年期中美利差 | 中国1.62% vs 美国约4.0% | 利差仍深，但人民币逆势升值，反映出口顺差与结汇需求 |

**当前汇率基准**：USDCNY 6.6605，较2025年同期人民币升值约6.4%；2027年平均汇率P50设为6.70。人民币升值对宏发的影响是**实质性负面**：

| 影响维度 | 方向 | 程度 | 分析 |
|:---|:---|:---|:---|
| 海外收入折算 | 负面 | **中等偏大** | 海外收入占比约30%（2025年29.75%），人民币每升值1%约减少营收0.3%、归母净利0.5-0.8%（含折算与汇兑）；7%升值对应营收-2.1%、归母净利-3.5%至-5.6% |
| 原材料进口 | 正面 | 部分对冲 | 铜、银以美元计价，人民币升值降低进口原料的人民币成本；但公司原材料以国内采购为主，对冲有限 |
| 海外竞争力 | 负面 | 中等 | 竞争对手松下/欧姆龙以日元计价，日元2026年亦升值，相对竞争力变化不大；但欧洲客户以欧元计价，人民币对欧元升值会削弱中国出口报价竞争力 |
| 汇兑损益 | 负面 | 已兑现 | 2026Q1-3财务费用1.47亿（同比+1.24亿），其中利息费用0.40亿、利息收入0.35亿；其他综合收益中的外币报表折算差额-0.43亿 |
| 海外产能 | 正面 | 长期对冲 | 德国、印尼、越南本地化生产可降低美元/欧元结算敞口，但越南工厂2026年内才投产，短期贡献有限 |

**定量测算**：2026Q1-3海外收入约30%×173.40=52.0亿；若按2025年同期汇率（约7.10-7.20）折算，当前6.66对应人民币收入减少约3.1-3.8亿，按海外毛利率34.8%测算，毛利减少约1.1-1.3亿，税后归母减少约0.8-1.3亿（约占2026E归母净利的3.5-5.7%）。这是Q3毛利率同比-1.98pp、归母净利率同比-0.72pp的重要解释之一。

**2027年假设**：F节点设定2027年平均USDCNY **6.70**（80%区间6.45-6.95）。若人民币进一步升至6.45（较6.70升值3.7%），2027E归母净利将下修约2-3%（含海外收入折算与汇兑损失）；若回落至6.95（贬值3.7%），则上修约2-3%。汇率是2027年盈利预测中仅次于铜价的不确定性。

**综合判断**：汇率对宏发整体影响**负面但不致命**。海外收入30%提供了天然对冲（收入端与成本端部分抵消），本地化生产与提价可部分转嫁；但人民币7%的升值已实质侵蚀2026年利润，且2027年若继续升值，将成为估值折价的新增因子。汇率已从背景变量升级为核心变量：2026Q1-3财务费用1.47亿（同比+536.7%）、海外收入折算与毛利率承压。

### 1.3 通胀传导效率

中国2026年9月PPI同比**+5.0%**（前值8月+3.8%），CPI同比+0.9%，PPI连续回升，从"输入性通缩"转向"温和再通胀"。9月出口+36.3%、进口+31.0%，外需强劲；制造业PMI 50.1，重回荣枯线上方。

**对宏发成本端的影响路径**：

```
全球再通胀 → 铜/银/工程塑料涨价 → 继电器原材料成本上升
           → 劳动力成本上升 → 人工成本上升
           → 能源/运输成本上升 → 制造费用上升
```

2025年宏发原材料成本暴涨33.44%已是通胀传导的实证。但**2026年出现分化**：

**银价趋势（利好）**：COMEX白银从2026年1月峰值$121.67/盎司持续回落，8月约$66-69，11月4日现货约**$51.63/盎司**（FXEmpire/COMEX，11-04），较8月再跌22-25%，较峰值跌约58%。50日均线$60.64、200日均线$69.53，价格在均线下方，技术趋势偏弱；主要支撑$48.62、$46.48，阻力$54.63、$55.35。若银价维持$50-60区间，宏发Q4-2027年原材料成本将显著低于2026年上半年。银价每下跌$10/盎司，按年用银量测算约节省成本1.5-2.0亿元，税后归母约+1.0-1.3亿（约占2027E归母净利的4-5%）。

**铜价趋势（利空）**：LME三个月铜10月31日约**$14,154.5/吨**，9月10日历史高点$14,875/吨；COMEX铜约$6.57/磅。UBS预测2026年全球铜缺口21.9万吨、2027年扩大至37.9万吨，并将2027年LME铜价预测上调至$15,500/吨（+9.5% vs 当前）。此前ICSG"2026年盈余9.6万吨"的判断已被UBS的最新缺口预测取代，本报告采信更新、更接近现货的UBS口径，但标注"投行预测，未经官方统计确认"。铜价每上涨$1,000/吨，按年用铜量测算约增加成本1.2-1.5亿元，税后归母约-0.9至-1.1亿（约占2027E归母净利的3-4%）。

**对宏发毛利率的综合判断**：银价下跌是2027年最大的成本利好（约+1.5-2.0pp毛利率），铜价上涨是最大对冲项（约-1.0-1.5pp），两者净影响约+0.5-1.0pp；叠加提价年化与规模效应，2027年毛利率修复至34.0%的假设成立，但上行空间有限。**不能假设回到2024年36%以上的毛利率水平**。

**宏发的对冲能力**：
- 规模采购优势：年采购铜银量极大，议价能力强于中小对手
- 月度议价/联动报价：2026年已将定价机制从半年度/年度改为月度，提价10-20%，自身消化约20%
- 效率提升：自动化率持续提高，制造费用率持平
- **边际改善**：银价从$121.67跌至$51.63，成本传导时滞约3-6个月，Q4起逐步体现在报表中；但人民币升值与铜价高位会吃掉部分红利

## 二、地缘政治风险

### 2.1 中美贸易摩擦：从"极端峰值"到"规则化摩擦+休战延长"

**关税演进路径（2025-2026年）**：

| 时间节点 | 事件 | 对华关税水平 |
|:---|:---|:---|
| 2025年1月 | Trump就职 | ~20% |
| 2025年2-3月 | IEEPA加征20% | ~40% |
| 2025年4月2日 | "解放日"全球关税 | 73%（峰值后164%） |
| 2025年5月 | 中美谈判降级 | 大幅下调 |
| 2025年10月 | Xi-Trump会晤 | 再降10pp |
| 2026年2月 | 最高法院裁决限制总统关税权 | 加权平均22.3%（对中国） |
| 2026年2月24日 | Section 122全球10%关税 | 维持22-36%水平 |
| 2026年7月24日 | Section 122到期，301强劳12.5%接替 | 净+2.5pp，无真空期 |
| **2026年9月23-24日** | **Xi访美，Board of Trade机制落地；休战延长至2027-01-10** | **30-for-30清单推荐、无实施时间表；7.5%产能过剩关税未落地** |
| **2026年11月4日（当前）** | **休战有效，Section 301 12.5%强劳关税维持；178项豁免至11-09** | **加权约20-22%** |

**关键判断**：
1. **7.5%产能过剩关税未落地**：8月24日Bloomberg报道美国拟在9月峰会前对中国商品加征7.5%产能过剩关税（合计上限20%）；9月23-24日华盛顿峰会未宣布该关税，休战延长至2027-01-10。截至11-04，无USTR正式实施通知。**结论：拟议7.5%关税短期搁置，但未正式撤回，仍是2027年1月10日前的观察项**（来源：Bloomberg 2026-08-24、白宫/Reuters 2026-09-26、USTR公告；未经USTR逐字确认撤回）。
2. **Board of Trade 30-for-30清单**：9月28日USTR公布77个美国税目（含小家电、玩具、节庆装饰、儿童安全座椅等）与1,619个中国税目（农产品、医疗设备等）的降税推荐清单，但仅为"建议"，需经美国国内通知-评论程序，**无实施时间表**；USTR 10-01明确"不设时间表"。对宏发的直接关税减免有限（继电器不在清单内），但小家电关税下降有利于下游需求。
3. **休战延长至2027-01-10**：休战到期日已由2026-11-10延至2027-01-10。极端路径（100%+关税）概率进一步下降。
4. **Section 301 12.5%强劳关税维持**：这是当前对华关税的核心构成，继电器HS编码（8536）适用；宏发通过德国/印尼/越南产能与FOB报价部分规避，但短期难以完全消除。

**对宏发的含义**：极端关税路径概率下降，海外订单可见度改善；但利润率不能再计入"关税自然消除"红利，地缘折价只应收窄，不应转为估值溢价。7.5%产能过剩关税未在9月峰会落地，地缘折价从-1.5%收窄至-1.0%，但不取消。

### 2.2 供应链重构 (China+1) 的实质影响

**全球供应链转移趋势**：
- 美国自中国进口占比已从2018年的21.6%降至2025年的约13%
- 中国2025年对美出口下降20%，但总贸易顺差创新高（$1.2万亿）
- 中国出口转向：非洲+25.8%、拉美+7.4%、东南亚+13.4%、欧盟+8.4%

**对宏发的影响——机遇大于威胁**：

1. **宏发已提前布局全球化制造**：
   - 德国工厂2025年投产（高压直流继电器全自动产线），2026年"配合客户项目推进节奏，当前业务体量暂时较小"
   - 印尼宏发：2025年营收+64%，60亩新工业园2025年11月奠基，2026年"稳定运行中"
   - 越南工厂：2026年1月与VinFast合资签约（宏发持股80%），10-30交流"预计今年内逐步投入运行"
   - **"中国+东南亚+欧洲"三极制造体系已初步成型**

2. **竞争对手替代逻辑不成立**：
   - 继电器认证周期2-4年（车规级），短期不可替代
   - 全球仅宏发、松下、泰科具有大批量稳定供货能力
   - 即使客户想"去中国化"，也找不到同等级别的替代供应商

3. **"China+1"反而为宏发提供了海外建厂的商业合理性**：
   - 欧洲客户：德国工厂就近供应，规避关税和物流成本
   - 东南亚客户：印尼/越南工厂辐射东盟市场
   - 美国客户：可通过东南亚基地间接进入（Section 301对东盟国家仍有关税优惠）

**2026年实际验证**：10-30交流确认"中国大陆和欧洲是主要增长来源、增速较快；北美业务同比下滑，但降幅逐季收窄、呈现逐步修复态势"。这说明：①欧洲本地化与客户拓展有效；②北美受关税/需求影响仍在收缩，但最坏时刻已过；③海外增长不完全依赖美国，区域多元化降低单一市场风险。

**唯一实质风险**：若中美关系极端恶化至"全面脱钩"（100%+关税维持），宏发海外收入的30%将直接受到冲击。但考虑到宏发已启动全球产能布局，这一风险正在被主动管理。

### 2.3 出口管制与稀土反制

中国对稀土、关键矿产的出口管制是应对美国关税的核心战略武器。中国控制全球约70%的稀土产量和85%的精炼能力。2026年2月中国宣布对7种稀土元素实施出口管制。

**对宏发的影响**：间接有限。继电器不直接使用稀土元素，但下游客户（电动汽车、风电、工业机器人）受稀土供应影响，可能间接减缓部分终端需求。但这种影响是第二阶的，优先级远低于关税、汇率和原材料价格。

## 三、监管与产业政策

### 3.1 "十五五"规划定位

2026年3月13日正式发布的《十五五规划纲要》与宏发相关度极高：

| 政策要点 | 原文 | 对宏发的含义 |
|:---|:---|:---|
| **元器件国产化** | "推进电子信息、机械装备等全产业链创新，发展高端、短缺产品，加快突破关键零部件、元器件和专用材料" | 宏发作为国产继电器绝对龙头，是政策直接受益者 |
| **新能源汽车** | "智能网联新能源汽车"列入战略性新兴产业 | NEV继续发展，高压直流继电器需求有政策保障；但国内零售负增长，政策边际效果递减 |
| **新型储能** | "扎实推进新型储能等关键技术创新"；2030年新型储能目标300GW | 储能继电器长期空间确认，但2027年180GW目标已完成93%，短期增速下修 |
| **智能制造** | "发展智能制造、绿色制造" | 宏发获评"卓越级智能工厂"，符合政策导向 |
| **科技自立自强** | "全链条推动集成电路...关键核心技术攻关取得决定性突破" | 元器件自主可控上升到国家安全高度 |

### 3.2 电子信息制造业稳增长行动方案（2025-2026）

工信部、发改委、数据局联合发布的行动方案明确提出：
- 规模以上电子信息制造业增加值年均增速约7%
- 加上锂电池、光伏及元器件制造后，年均营收增速达到5%以上
- **电子元器件被明确纳入稳增长重点领域**

宏发作为中国电子元器件百强企业TOP4（2025年），充分受益。

### 3.3 新能源政策的持续性

| 政策领域 | 当前状态 | 对宏发影响 |
|:---|:---|:---|
| NEV购置税减免 | 2026年逐步退坡 | 短期负面（国内零售连续10个月负增长），但出口/商用车对冲 |
| "以旧换新"补贴 | 2026年第二批625亿元已拨付 | 支撑家电/汽车更新需求，但边际效果递减 |
| 光伏管理办法 | 2026年新政落地，1-9月新增-53.9% | 光伏继电器需求短期承压 |
| 储能政策 | 强制配储延续；2030年300GW目标；2027年180GW目标已完成93% | 长期空间确认，2027年增速下修 |
| 智能电网 | 国网十五五4万亿、全国电网5万亿、2026年特高压招标+49% | 电力继电器需求高确定性 |

### 3.4 行业准入与环保约束

继电器行业不存在特殊的行政准入壁垒（非牌照管制行业），但事实上的认证壁垒极高：
- 汽车继电器需通过AEC-Q、IATF 16949
- 出口需UL（美国）、VDE（德国）、TÜV（欧洲）、CQC（中国）认证
- 国网/南网有独立的供应商准入体系

宏发同时拥有UL&CUL、VDE、TÜV、CQC等全部主流认证，且是"国内首家获国网2025版电流互感器资质的制造商"，在认证层面建立了事实上的护城河。

环保约束方面，欧盟RoHS和REACH法规对继电器的有害物质（如镉）使用有严格限制，AgCdO（银氧化镉）触点材料已被AgSnO₂（银氧化锡）替代。宏发已完成技术切换，环保合规成本已经消化。

## 四、宏观变量对估值的传导机制

### 4.1 折现率（无风险利率）路径

```
PBOC宽松 → 10Y国债1.62% → 权益风险溢价稳定 → 
DCF分母下降 → 理论PE中枢抬升 → 支撑当前24-26x PE
```

当前中国10年期国债1.62%对应约5.1-5.3%的股权成本（加3.5%风险溢价），支持25-30x PE的中枢水平。宏发当前PE TTM 24.32x略低于这一区间的下沿，估值压力不大。

### 4.2 汇率路径

人民币升值→海外收入折算减少→EPS下调→PE估值保持不变（分子分母同向调整）→对估值倍数无实质影响，但会降低以人民币计价的盈利与目标价。**汇率是2027年盈利预测的F节点（P50 6.70），不是估值倍数调节项**——这是"可计算风险进E、不可计算风险进PE"的纪律要求。

### 4.3 地缘政治风险溢价

最需要警惕的情景：**中美关系恶化 → 全面关税回归 → 海外收入断崖 → EPS骤降30% → PE杀跌至15-18倍**。

这一情景在2025年4月曾短暂出现（股价最低触及约21.70元，PE约18.8倍），但随后随中美谈判缓和而修复。2026年9月休战延长至2027-01-10，极端路径概率下降；但2027-01-10仍是下一个扰动窗口，且7.5%产能过剩关税未正式撤回。**地缘折价从-1.5%收窄至-1.0%，但不取消**。
