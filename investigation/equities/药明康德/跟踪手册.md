## 五、仓位管理建议框架（8月16日TRO获批后重建）

```
持仓水位                触发条件
──────────────────────────────────────────────
15-20%（重仓）     ← 一审胜诉除名 + OMB未指定 + TIDES维持>40% + 小分子D&M持续>50%。概率约35%
10-15%（标准仓）   ← 【当前建议】TRO获批 + OMB未在12月确认BCC名单（独立指定概率25-35%）。基准情景
5-8%（中性仓）     ← OMB 12月名单确认指定 → 回落至此；或一审败诉
3-5%（观察仓）     ← DoD重新列名/上诉获暂缓 → 回落至此
0-3%（清仓观望）   ← 一审败诉 + OMB指定双杀；客户开始实质转移
```

> 注：8月7日TRO获批后仓位框架从"观察仓(3-5%)"上调至"标准仓(10-15%)"。上调依据：①TRO获批暂停1260H即时效力；②BCC自动纳入路径被司法阻断（Ropes & Gray确认），OMB独立指定概率25-35%；③半年报全面超预期+指引上调+员工持股绑定。但8/4-8/10股价急涨24%（128.50→159.24），现价已高于概率加权目标价151元约5.2%、高于修正公允价值146元约9.1%，**安全边际为负，不追高，回调至146元下方分批加仓**。
