## 一、价值锚定：适配性方法选择

### 1.1 方法论筛选

新强联是**重资产、高周期、政策敏感性制造业**企业。基于其特征：
- **PE（市盈率）——主方法**：维持。当前TTM归母7.25亿（2026前三季TTM，EPS_TTM 1.75元），PE_TTM 14.16x；Forward PE（2027E P50 EPS 1.82元）= **13.63x**（24.80/1.82）。
- **PB-ROE（市净率-ROE模型）——辅助验证**：当前PB 1.38x（24.80/18.00，BVPS 2026Q3）；2027E中性ROE约9.3%（7.54亿/81.5亿期末净资产），PB-ROE隐含合理PB仅0.93x，对应16.7元——**这是当前估值最刺眼的矛盾：PE看便宜、PB-ROE看不便宜。**
- **PEG——不适用**：2027E盈利+6.3%，周期股PEG参考意义弱。
- **DCF——不适用**：OCF虽修复至0.88，但历史波动大、资本开支高，稳定性不足。
- **SOTP——不适用**：风电配套占营收83%、齿轮箱仅5%，各板块共享同一套产能/客户/工艺，不具备独立估值的业务属性；强行分部会制造虚假精度。**（框架模块五§5的SOTP仅适用于"多个不同属性业务板块"，本公司不满足，故不执行。）**

### 1.3 PB-ROE 模型验证

| 指标 | 数值 | 解读 |
| :--- | :--- | :--- |
| 每股净资产（2026Q3） | 18.00元（74.53亿/4.14亿股） | 较H1 +0.39元 |

## 二、三态市值与目标价计算（2027E）

### 2.1 PE方法（主方法）

**合理PE倍数的锚定逻辑**：由20x下调至**18x（中性）/16x（保守）/22x（乐观）**。理由：
1. **成长性下修**：2027E归母增速由+22.1%（上版7.29→8.90）降至+6.3%（7.09→7.54），PEG由0.90升至2.86，20x不再匹配；
2. **竞争格局恶化**：洛轴Q3增速显著优于公司、主轴第一/齿轮箱第二，公司此前的"TRB稀缺性溢价"应压缩；
3. **同业对照（双向）**：金雷/日月/大金2027E平均PE约11.5x（华西7-31旧口径），公司18x对应56%溢价；但洛轴（301699）PE_TTM约38.2x/PB 4.42x（次新股溢价，不可直接比）。**18x是"对传统零部件溢价、对洛轴折价"的中间值，已充分反映TRB技术、12MW海风与齿轮箱小期权；若按同业11.5x，目标价仅17.2元。**
4. **历史中枢**：18x较近3年PE中位25.54x折价30%，较P25 20.18x折价11%，处于"周期底部+成长降速"的合理区间。

| 估值参数 | 保守 | 中性 | 乐观 |
| :--- | :--- | :--- | :--- |
| 2027E EPS（元） | 1.15 | 1.82 | 2.35 |
| 合理PE倍数 | 16x | 18x | 22x |
| **对应股价（元）** | **18.40** | **32.76** | **51.70** |
| 隐含市值（亿） | 76.2 | 135.6 | 214.1 |

**三态市值（取整）**：保守 **76亿** / 中性 **136亿** / 乐观 **214亿**

**三态目标价（未调节）**：保守 **18.40元** / 中性 **32.76元** / 乐观 **51.70元**；中性档经第三节全变量审计（Σ=-18%）后修正为 **26.86元**，保守/乐观不叠加调节（框架强制性规则）。

### 2.2 PB-ROE 交叉验证

若给予PB 1.0倍（匹配ROE 9.3%）：1.0 × 18.00 = **18.00元**；若ROE修复至12%、PB 1.2倍：1.2 × 19.0（2027E BVPS）≈ **22.8元**。**PB-ROE给出的合理区间18.0-22.8元，低于本报告修正目标价26.86元；26.86元需要"ROE修复至12%+PE 18x"同时成立，属于偏乐观的中性假设。**

## 五、确定性与胜率矩阵（2027E）

### 5.1 三态逻辑加权与盈亏比

| 情景 | 概率 | 目标股价（元） | 盈亏计算（vs 现价24.80元） |
| :--- | :--- | :--- | :--- |
| **保守** | 30% | 18.40 | 盈亏 = 18.40 - 24.80 = -6.40元（-25.8%） |
| **中性** | 50% | **26.86** | 盈利 = 26.86 - 24.80 = +2.06元（+8.3%） |
| **乐观** | 20% | 51.70 | 盈利 = 51.70 - 24.80 = +26.90元（+108.5%） |
| **概率加权目标价** | | **29.29元**（+18.1%） | 0.30×18.40 + 0.50×26.86 + 0.20×51.70 = 29.29 |

**概率调整说明**：保守25%→30%（Q3份额流失、齿轮箱产能受限）、中性55%→50%、乐观20%维持（海风下修但海外/齿轮箱扩产期权仍在）。

**盈亏比分析**：

传统公式：(加权目标价 - 现价) / (现价 - 保守价格) = (29.29 - 24.80) / (24.80 - 18.40) = 4.49 / 6.40 = **0.70**

**替代分析——隐含下行空间的概率加权**：
- 保守（30%，18.40）：亏损 (18.40-24.80)/24.80 = -25.8%
- 中性（50%，26.86）：盈利 +8.3%
- 乐观（20%，51.70）：盈利 +108.5%
- 加权期望收益率 = 30%×(-25.8%) + 50%×(+8.3%) + 20%×(+108.5%) = -7.74% + 4.15% + 21.70% = **+18.1%**

**加权期望收益率+18.1%，盈亏比0.70**——较上版0.60小幅改善，但仍<1。**敏感性（必须披露）**：若保守PE由16x降至14x，保守价16.10元，盈亏比降至0.52；若保守EPS降至1.05元，保守价16.80元，盈亏比0.56；若Q4毛利率<26%导致2027E下修至6.8亿（EPS 1.64），加权目标价约27.97元（仅调整中性档），盈亏比降至0.50。**盈亏比0.70对保守档高度敏感，不能作为"上调评级"的充分依据。**
