### 1.1 方法论筛选（维持6.8日结论）

新强联是**重资产、高周期、政策敏感性制造业**企业。基于其特征：
- **PE（市盈率）——主方法**：维持。但需注意当前TTM净利润7.97亿为景气峰值，Forward PE（概率加权EPS 1.80元）= 12.33x
- **PB-ROE（市净率-ROE模型）——辅助验证**：当前PB 1.29x已极其接近每股净资产，意义上升
- **PEG——不适用**：2026E盈利预计下滑，PEG为负
- **DCF——不适用**：经营现金流极度不稳定

**估值压力测试（第四次重大修订）**：

1. **PE_TTM 11.53x已进入"荒谬估值区间"**。这不是相对低估，而是绝对意义上的极端。6月8日PE_TTM 14.71x已创近5年最低——彼时我们认为那是"恐慌错杀"。今日11.53x较彼时再压缩-21.6%。对应当前TTM净利润7.97亿元（仅次于2025年的历史第二高水平），而2024年盈利崩塌期PE最低17.79x时的EPS仅0.18元——**今日的盈利质量是彼时的11.8倍，而PE反而低了35%**。仅从这一比较就可判断：当前定价不是基本面驱动的。

2. **Forward PE 12.33x（概率加权EPS 1.80元）的绝对值分析**：对于一家拥有TRB主轴轴承技术壁垒、年营收46亿、ROE 13.78%的制造业龙头，12.33x的Forward PE在A股历史上找不到任何参照物。风电零部件行业可比公司PE普遍在15-25x，新强联当前已较行业下限折价18%。

3. **"市场是否正确"vs"市场是否失灵"的辨析**：在正常市场中，价格=价值。但在流动性危机中，价格可能大幅偏离价值。当前新强联面临三重非基本面压力——融资盘强制平仓（6月5日5.46亿）、大股东质押螺旋（7月13日补充质押）、定增发行底价预期（约20-22元）——这些力量共同将价格压制到远低于任何基本面模型计算的水平。**这不是市场在"正确"定价，而是市场在"失能"状态下定价。**

4. **PB 1.29x的信号**：距离每股净资产16.91元（PB=1）仅差23.8%。在A股制造业中，PB跌至1倍附近通常意味着市场在为企业"清算"定价——而新强联是一家年营收46亿、盈利8亿的持续经营企业。PB 1.29x已在为"破产概率"定价，而非为"盈利能力"定价。

## 二、基准市值与目标价计算

### 2.1 PE方法（主方法）

**合理PE倍数的锚定逻辑**：新强联当前面临的结构性风险已较6月8日显著增加——控股股东补充质押暗示的质押螺旋风险、定增摊薄风险、流动性危机持续——因此合理PE倍数需进一步下调。

| 估值参数 | 保守 | 中性 | 乐观 |
| :--- | :--- | :--- | :--- |
| 2026E EPS（元） | 1.13 | 1.76 | 2.76 |
| 合理PE倍数 | 20x | 20x | 22x |
| **对应股价（元）** | **22.60** | **35.20** | **60.72** |
| 隐含市值（亿） | 93.6 | 145.8 | 251.5 |

**PE倍数下调说明**（6月8日22x→20x）：
- 下调2倍PE的原因：①大股东质押螺旋风险增加了公司治理不确定性（-1x PE）；②定增发行底价预期（约20-22元）形成了短期价格锚定压力（-1x PE）；③流动性危机持续——买方枯竭意味着短期不存在估值修复的"催化剂资金"
- 但20x PE仍对应：①风电零部件行业可比中位（15-25x）的中低区间；②较近3年PE中位数25.68x折价22%，反映了盈利下滑和风险折价

**基准市值（中性PE×中性EPS）**：**35.20元 × 4.14亿 = 145.8亿**

### 2.2 PB-ROE 交叉验证

若给予PB 1.5倍（匹配ROE恢复至12%的预期）：1.5 × 16.91 = **25.37元**。与PE方法的35.20元存在较大差距，反映PB方法对公司ROE能否持续高于资本成本的怀疑。当价格接近PB 1.0倍（16.91元）时，PB方法提供的底部支撑意义显著增强。

## 五、确定性与胜率矩阵

### 5.1 三态逻辑加权与盈亏比（2026.07.19第四次重大修订）

| 情景 | 概率 | 目标股价（元） | 盈亏计算（vs 现价22.20元） |
| :--- | :--- | :--- | :--- |
| **保守** | 25%（↑5pct） | 22.60 | 盈亏 = 22.60 - 22.20 = +0.40元（+1.8%） |
| **中性** | 55%（持平） | **35.20** | 盈利 = 35.20 - 22.20 = +13.00元（+58.6%） |
| **乐观** | 20%（↓5pct） | 60.72 | 盈利 = 60.72 - 22.20 = +38.52元（+173.5%） |
| **概率加权目标价** | | **37.13元** | 较现价溢价 **+67.3%** |

**概率调整说明**：
- 保守情景概率从20%→25%（↑5pct）：Q1装机仅15.77GW、1-5月累计25.05GW（年化仅60GW），需求弱于预期；质押螺旋+流动性危机增加尾部风险
- 乐观情景概率从25%→20%（↓5pct）：市场已证明对乐观信号完全免疫，定增摊薄削弱上行空间
- 中性情景维持55%：1-6月央国企定标89.31GW提供强劲支撑，中长期需求逻辑未破

**盈亏比分析（重大变化——传统公式失效）**：

传统公式：(目标价 - 现价) / (现价 - 保守价格) = (37.13 - 22.20) / (22.20 - 22.60) = 14.93 / (-0.40) = **负数——公式失效**

**这是本轮研究最重要的估值信号**：当前22.20元已跌破保守情景目标价（22.60元）。传统盈亏比公式失效的原因不是"风险无限大"，而是**"下行风险已充分暴露且定价过度"**。当现价低于最悲观情景的目标价时，意味着市场在"过度恐慌"——连最坏的情况都已被价格所消化。

**替代分析——隐含下行空间的概率加权**：
- 保守情景（25%）：盈利1.8%
- 中性情景（55%）：盈利58.6%
- 乐观情景（20%）：盈利173.5%
- 加权期望收益率 = 25%×1.8% + 55%×58.6% + 20%×173.5% = 0.45% + 32.23% + 34.70% = **+67.4%**

**加权期望收益率+67.4%**，较6月8日+53.6%进一步上升——这是因为价格下跌的速度（-21.6%）远快于目标价下调的速度（概率加权目标价从44.03→37.13，仅-15.7%）。**价格被"过度打压"的程度在加剧。**

## 六、模块六核心结论（2026.07.19连续第四次重大修订）

1. **估值画像已从"极端低估/恐慌定价"进一步演变为"市场失灵定价"**。PE_TTM 11.53x为2020年上市以来最低，Forward PE（概率加权EPS）12.33x远低于近3年任何分位值。这不是相对低估，而是绝对意义上的荒谬——对应当前处于历史高位盈利水平（TTM净利润7.97亿）的制造业龙头，在任何正常市场中都找不到11.75x PE的参照物。

2. **传统盈亏比公式已失效——但失效的原因恰恰佐证了"过度恐慌"**。当前22.20元已跌破保守情景目标价（22.60元），意味着市场连最坏的情况都已充分定价。加权期望收益率从6月8日的+53.6%上升至**+67.4%**——价格下跌的速度远超基本面恶化的速度。

3. **全变量修正目标价从32.54元大幅下调至26.06元（-19.9%）**，新增了三个折价因子：大股东质押螺旋风险（-3pct）、定增摊薄预期（-5pct）、流动性折价（-5pct）。综合折价率从-16%上调至-26%。然而即使计入这10pct新增折价，现价22.20元仍较修正目标价折价-14.8%。

4. **核心风险从"基本面担忧"全面转向"流动性危机担忧"**：
