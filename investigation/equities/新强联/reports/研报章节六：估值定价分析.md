## 一、价值锚定：适配性方法选择

### 1.1 方法论筛选（维持6.8日结论）

新强联是**重资产、高周期、政策敏感性制造业**企业。基于其特征：
- **PE（市盈率）——主方法**：维持。但需注意当前TTM净利润7.97亿为景气峰值，Forward PE（概率加权EPS 1.80元）= 12.33x
- **PB-ROE（市净率-ROE模型）——辅助验证**：当前PB 1.29x已极其接近每股净资产，意义上升
- **PEG——不适用**：2026E盈利预计下滑，PEG为负
- **DCF——不适用**：经营现金流极度不稳定

**估值压力测试（第四次重大修订）**：

1. **PE_TTM 11.53x已进入历史绝对低位**。6月8日PE_TTM 14.71x已创近5年最低——彼时我们认为那是"恐慌错杀"。今日11.53x较彼时再压缩-21.6%。对应当前TTM净利润7.97亿元（仅次于2025年的历史第二高水平）。需要修正此前的一个对比误差：2024年7月10日PE最低17.79x时，彼时对应的TTM净利润为2.79亿元、TTM EPS约0.78元（3.59亿股本口径），而非0.18元（0.18元为2024全年EPS，彼时尚不可知）。今日TTM EPS 1.93元约为彼时的**2.5倍**，PE则较彼时低35%——低估程度依然显著，但"盈利质量是彼时11.8倍"的表述不成立。

2. **Forward PE 12.33x（概率加权EPS 1.80元）的绝对值分析**：对于一家拥有TRB主轴轴承技术壁垒、年营收46亿、ROE 13.78%的制造业龙头，12.33x的Forward PE处于上市以来最低区间。风电零部件行业可比公司PE普遍在15-25x，新强联当前已较行业下限折价18%。

3. **"市场是否正确"vs"市场是否失灵"的辨析**：在正常市场中，价格=价值。但在流动性危机中，价格可能大幅偏离价值。当前新强联面临三重非基本面压力——融资盘强制平仓（6月5日5.46亿）、大股东质押压力（7月13日补充质押，质押比例30.33%）、定增发行底价预期（约20-22元）——这些力量共同将价格压制到低于基本面模型计算的水平。**这不是市场在"正确"定价，而是市场在"失能"状态下定价。**

4. **PB 1.29x的信号**：距离每股净资产17.27元（2026Q1，71.50亿/4.14亿股；2025年末为16.90元）尚差22.2%。在A股制造业中，PB跌至1倍附近通常意味着市场在为企业"清算"定价——而新强联是一家年营收46亿、盈利8亿的持续经营企业。需注意历史参照：2024年7月10日PB曾低至0.985倍（彼时行业底部），其后股价从13.82元一路上行至2026年3月的53.38元——"PB=1绝对硬底"的信念存在反例，PB 1.29x更准确的表述是"逼近历史P10区域"。

## 二、基准市值与目标价计算

### 2.1 PE方法（主方法）

**合理PE倍数的锚定逻辑**：新强联当前面临的结构性风险已较6月8日显著增加——控股股东补充质押暗示的质押压力、定增摊薄风险、流动性危机持续——因此合理PE倍数需进一步下调。

| 估值参数 | 保守 | 中性 | 乐观 |
| :--- | :--- | :--- | :--- |
| 2026E EPS（元） | 1.13 | 1.76 | 2.76 |
| 合理PE倍数 | 20x | 20x | 22x |
| **对应股价（元）** | **22.60** | **35.20** | **60.72** |
| 隐含市值（亿） | 93.6 | 145.8 | 251.5 |

**PE倍数下调说明**（6月8日22x→20x）：
- 下调2倍PE的原因：①大股东质押及治理不确定性（-1x PE，质押比例30.33%但公司声明无平仓风险）；②定增发行底价预期（约20-22元）形成了短期价格锚定压力（-1x PE）；③流动性危机持续——买方枯竭意味着短期不存在估值修复的"催化剂资金"
- 但20x PE仍对应：①风电零部件行业可比中位（15-25x）的中低区间；②较近3年PE中位数25.68x折价22%，反映了盈利下滑和风险折价

**基准市值（中性PE×中性EPS）**：**35.20元 × 4.14亿 = 145.8亿**

### 2.2 PB-ROE 交叉验证

若给予PB 1.5倍（匹配ROE恢复至12%的预期）：1.5 × 17.27 = **25.91元**。与PE方法的35.20元存在较大差距，反映PB方法对公司ROE能否持续高于资本成本的怀疑。当价格接近PB 1.0倍（17.27元）时，PB方法提供的底部支撑意义显著增强。

## 四、逻辑纯净性校验

### 4.1 "E vs PE" 区分（更新）

| 因素 | 归属 | 理由 |
| :--- | :--- | :--- |
| 2026年风电装机回落→营收-11.7%（中性） | **E（利润）** | 具体的、可量化的量价变化 |
| 定增EPS摊薄（约-14.2%） | **PE（估值倍数）** | 模块五核心盈利预测维持未摊薄口径（EPS 1.76），摊薄通过估值折价（-5%）表达，避免与E端重复计算 |
| 大股东质押或有风险 | **PE（估值倍数）** | 不可量化的或有风险，关乎公司治理稳定性（当前质押比例30.33%，公司声明无平仓风险） |

| "136号文"政策不确定性 | **PE（估值倍数）** | 关乎远期信心，不可精确量化为当期利润 |

## 五、确定性与胜率矩阵

### 5.1 三态逻辑加权与盈亏比（2026.07.19第四次重大修订）

| 情景 | 概率 | 目标股价（元） | 盈亏计算（vs 现价22.20元） |
| :--- | :--- | :--- | :--- |
| **保守** | 25%（↑5pct） | 22.60 | 盈亏 = 22.60 - 22.20 = +0.40元（+1.8%） |
| **中性** | 55%（持平） | **35.20** | 盈利 = 35.20 - 22.20 = +13.00元（+58.6%） |
| **乐观** | 20%（↓5pct） | 60.72 | 盈利 = 60.72 - 22.20 = +38.52元（+173.5%） |
| **概率加权目标价** | | 未对冲口径 **37.13元**（+67.3%）；对冲后口径 **28.61元**（+28.9%） | 口径说明见下 |

**概率调整说明**：
- 保守情景概率从20%→25%（↑5pct）：Q1装机仅15.77GW、1-5月累计25.05GW（年化仅60GW），需求弱于预期；流动性危机增加尾部风险
- 乐观情景概率从25%→20%（↓5pct）：市场已证明对乐观信号完全免疫，定增摊薄削弱上行空间
- 中性情景维持55%：1-6月央国企定标89.31GW提供强劲支撑，中长期需求逻辑未破

**目标价口径修正（重要）**：37.13元为**未含全变量对冲折价**的三态纯基本面加权值（0.25×22.60+0.55×35.20+0.20×60.72=37.15，四舍五入37.13）。若将全变量对冲系数-23%同比例应用于三态目标价（22.60×0.77=17.40、35.20×0.77=27.10、60.72×0.77=46.75），则**对冲后概率加权目标价 = 0.25×17.40+0.55×27.10+0.20×46.75 = 28.61元**，对应**对冲口径期望收益率 = 28.61/22.20-1 = +28.9%**。本报告最终以**全变量修正目标价27.12元**（=修正市值112.3亿÷4.14亿股）为操作锚，对冲后概率加权目标价28.61元（+28.9%）为期望收益参考；37.13元（+67.3%）仅为未含对冲的理论值，不作为安全边际依据。

**盈亏比分析（重大变化——传统公式失效）**：

传统公式：(目标价 - 现价) / (现价 - 保守价格)。无论采用未对冲口径（(37.13-22.20)/(22.20-22.60) = 14.93/(-0.40)）还是对冲后口径（(28.61-22.20)/(22.20-22.60) = 6.41/(-0.40)），由于现价22.20元 < 保守情景目标价22.60元，**分母均为负，公式不适用**——按项目框架惯例，记"保守情景下行空间为负"（∞+）。

**这是本轮研究最重要的估值信号**：当前22.20元已跌破保守情景目标价（22.60元）。传统盈亏比公式失效的原因不是"风险无限大"，而是**"下行风险已充分暴露且定价过度"**。当现价低于最悲观情景的目标价时，意味着市场在"过度恐慌"——连最坏的情况都已被价格所消化。

**替代分析——隐含下行空间的概率加权（对冲口径）**：
- 保守情景（25%，修正目标价17.40）：亏损 (17.40-22.20)/22.20 = -21.6%
- 中性情景（55%，修正目标价27.10）：盈利 (27.10-22.20)/22.20 = +22.1%
- 乐观情景（20%，修正目标价46.75）：盈利 (46.75-22.20)/22.20 = +110.6%
- 加权期望收益率 = 25%×(-21.6%) + 55%×(+22.1%) + 20%×(+110.6%) = -5.40% + 12.16% + 22.12% = **+28.9%**

注：对冲口径下保守情景修正目标价17.40元低于现价，故对冲口径下保守情景存在实际下行空间（-21.6%）；该口径仅用于期望收益参考，**盈亏比仍按未对冲三态保守价22.60元判定（公式不适用，记∞+）**，严禁以对冲后保守价代入公式制造数值化盈亏比。

**对冲口径加权期望收益率+28.9%**，较6月8日+53.6%口径回落——修正后的口径更审慎：目标价下调幅度（32.54→27.12，-16.7%）叠加概率两端向保守偏移，对冲后期望收益显著低于此前未对冲口径的+67.4%。**价格被"过度打压"的程度依然存在（现价较修正目标价折价-18.2%），但"历史级安全边际"的表述需相应降调。**

## 六、模块六核心结论（2026.07.19连续第四次重大修订）

1. **估值画像已从"极端低估/恐慌定价"进一步演变为"市场失灵定价"**。PE_TTM 11.53x为2020年上市以来最低，Forward PE（概率加权EPS）12.33x远低于近3年任何分位值。对应当前处于历史高位盈利水平（TTM净利润7.97亿）的制造业龙头，这是上市以来从未出现过的估值坐标。

2. **传统盈亏比公式已失效——但失效的原因恰恰佐证了"过度恐慌"**。当前22.20元已跌破保守情景目标价（22.60元），意味着市场连最坏的情况都已充分定价。对冲口径加权期望收益率为**+28.9%**（未对冲口径为+67.4%，但该口径未计入全变量折价，不作为安全边际依据）。

3. **全变量修正目标价从32.54元下调至27.12元（-16.7%）**，新增定增摊薄预期（-5%）与流动性折价（-5%）两项折价因子，同时因质押比例实测为30.33%且公司声明无平仓风险，治理折价从-8%下调至-5%，综合折价率-23%。现价22.20元仍较修正目标价折价-18.2%。

4. **核心风险从"基本面担忧"全面转向"流动性危机担忧"**：
   - 大股东质押（肖争强30.33%持股已质押，7月13日补充质押300万股；公司声明"不存在平仓或强制过户风险，质押风险在可控范围内"）
   - 定增发行底价预期（约20-22元）形成短期价格天花板
   - 融资盘强制平仓风险（6月5日融资余额5.46亿）
   - 买方彻底枯竭——任何基本面利好都无法转化为价格修复

5. **底部锚点分析**：
   - PB=1（17.27元/股，2026Q1每股净资产）是重要的底部参照——除非公司出现实质性经营危机，否则不应跌破（但需注意2024年7月PB曾低至0.985倍的历史反例，该锚位并非绝对）
   - 保守情景目标价22.60元已被击穿，说明市场定价了比保守情景更悲观的东西
   - 极端悲观情景（质押强平+融资爆仓）目标14.55元——这是流动性危机完全失控的定价

6. **入场建议（连续第四次重大修正）**：
   - **暂停一切加仓，转为"观察等待"模式**。在质押风险、定增发行价格、流动性恢复三个关键不确定性解除之前，盲目在下跌中加仓可能掉入"流动性陷阱"
   - **明确入场信号**（任一出现即可考虑分批介入）：①大股东公告质押风险解除或未触发平仓线；②定增发行价格确定（不低于22元/股，最好>25元）；③出现连续3日缩量且不再创新低；④半年报（8月29日）数据优于预期
   - **若上述信号出现时股价仍在20-22元**，将是历史性的进场机会——因为即使最保守的估值模型（全变量修正目标价27.12元）也意味着+23-36%上行空间
   - **若股价跌破17.27元（PB=1）**，且公司基本面未出现实质性恶化——将是极端低估区域。但需首先确认公司未出现财务造假、大客户流失等致命风险
