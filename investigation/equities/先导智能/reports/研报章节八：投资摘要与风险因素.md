## 一、投资摘要（Investment Summary）

### 1.1 公司定位

先导智能是全球锂电智能装备绝对龙头（全球份额 22.4%、中国份额 28.7-34.1%，全球唯一锂电整线提供商），A+H 双平台上市。主业（锂电池智能装备占收入 65.6%）随下游电池厂第二轮扩产大周期（2025-2027）进入景气上行；固态电池整线（全球市占率 70%+、单 GWh 价值量 2-3 倍）构成 2027-2028 年的第二成长曲线期权。

### 1.2 核心投资逻辑（三条主线）

1. **订单-收入传导的确定性兑现但利润兑现分化**：2026H1合同负债174.03亿（+35.22% vs年初 / +33.29% YoY，创历史新高）+营收81.89亿（+23.88%创同期新高，Q2 44.98亿+28.09%加速）+2025新签240亿（+37.1%）→2026E收入185亿（+28%）路径仍被预收款锁定（确定性5/5），但H1毛利率31.90%（-1.85pp）及Q2 30.59%（-3.0pp QoQ）跌破33.5%阈值，利润弹性（+11.9%）显著弱于订单弹性（+35%）。
2. **盈利质量分化：现金流历史最优 vs 毛利承压**：H1 OCF 40.85亿（+73.57%，Q2单季28.37亿历史最佳，OCF/NP 427%）+净减值0.36亿可控 +信用转回1.05亿，现金流顶级；但财务费用1.316亿（+509%汇兑-1.04亿）与锂电装备32.64%（-2.42pp）/物流17.68%（-4.09pp）/海外33.72%（-6.55pp）全线下滑，抵消部分现金优势。H股募资43.95亿到账后净现金约118亿（货币151亿）仍支撑扩张。
3. **固态电池产业化高杠杆期权仍存但未兑现**：单GWh 4-5亿（2-3倍）+存量替换30%+市占70%+，但H1固态占比仍<5%→10%强信号未触发（仅Q2斩获头部干法/涂布/转印/叠片/等静压订单+重复订单，金额未披），2026中试/2027-2028量产招标仍是目标价上修（39.81元）触发器。

### 1.4 投资建议

**评级：中性/观望（等待回调或Q3毛利率修复验证）；第三象限边缘（高确定性 + 当前收益空间不足且成色分化）**

- 先导智能是"好公司、但价格偏贵且业绩分化"：订单/现金流/护城河/固态期权质地仍优（合同负债174亿+35%新高，OCF 40.85亿历史最佳），但**H1毛利率31.90%（-1.85pp）及Q2 30.59%（-3.0pp QoQ）跌破33.5%阈值，利润弹性（+11.9%）显著弱于订单弹性（+35%），财务费用+509%汇兑共振**，现价33.62对应2026E PE 32.18x高于中性28.86x。
- 中性30.16低于现价10.3%、加权29.50低于12.3%、盈亏比-0.26（原-0.11）进一步为负，不具安全边际，**暂不建议现价建仓**。
- **操作策略（下移）**：等待**22-24元**（盈亏比0.90-1.81，原26元以下核心区上移）分批至60-70%，22元以下核心配置；或右侧信号"Q3毛利率≥32.5%+放量收复36.95元（MA60）"再加仓（原37.5元下修）。技术面支撑31.0（08-25低点32.80抬高）距现价仅2.6元。
- **时间框架**：12-18个月持有期。若Q3毛利率修复或2027固态放量，中性上修至39.81元（2027E 1.40-1.49×28-31x），届时盈亏比转正。

## 三、研究结论象限图（Final Evaluation Matrix）

```
                      高确定性
                          │
        第一象限          │          第二象限
   (High-Conviction Buy)  │    (Speculative Growth)
                          │
   ───────────────────★──┼───────────────────
       （先导智能定位）   │
                          │
        第三象限          │          第四象限
     (Defensive Value)    │      (Avoid/Wait)
                          │
                      低确定性
                      低 ←── 预期收益空间 ──→ 高
```

**象限定位：第三象限边缘（高确定性但成色分化 + 当前收益空间不足且下修）**

- **确定性维度（高但边际下修至3.5/5）**：订单174亿/现金流40.85亿/护城河仍高（5/5），但盈利质量从4/5降至3.5/5（H1毛利率31.90%及Q2 30.59%急跌超预期，汇兑1.04亿系统性），固态期权未兑现。
- **收益空间维度（不足且恶化）**：中性30.16低于现价10.3%、加权29.50低于12.3%、盈亏比-0.26（原-0.11）进一步为负；保守价17.86（-46.8%）下移使安全边际门槛从26元抬升至22元，属"跌不深亦涨不动且下修风险"态。
- **对应策略**：观望等待——**22-24元**（原30元以下）分批至60-70%、22元以下盈亏比1.81转为积极配置；或Q3毛利率≥32.5%+放量收复36.95元双确认后右侧介入。**当前不构成"买入"（-0.26），亦不构成"回避"（174亿储备确定性仍高）。**
