## 一、投资摘要（Investment Summary）

### 1.1 公司定位

先导智能是全球锂电智能装备绝对龙头（全球份额 22.4%、中国份额 28.7-34.1%，全球唯一锂电整线提供商），A+H 双平台上市。主业（锂电池智能装备占收入 65.6%）随下游电池厂第二轮扩产大周期（2025-2027）进入景气上行；固态电池整线（全球市占率 70%+、单 GWh 价值量 2-3 倍）构成 2027-2028 年的第二成长曲线期权。

### 1.2 核心投资逻辑（三条主线）

1. **订单-收入传导的确定性兑现（2027E 收入锁定）**：2026H1合同负债174.03亿（+35.22% vs年初，创历史新高）+营收81.89亿（+23.88%，Q2 44.98亿+28.09%加速）+2026H1新签订单超180亿（+50~60%）+订单能见度至2027年8月→2027E收入240亿（+29.7%）由2026年订单锁定（确定性5/5），但利润兑现取决于毛利率修复（H1 31.90%跌破33.5%阈值）。
2. **盈利质量分化：现金流历史最优 vs 毛利承压**：H1 OCF 40.85亿（+73.57%，Q2单季28.37亿历史最佳，OCF/NP 427%）+净减值0.36亿可控，现金流顶级；但财务费用1.316亿（+509%汇兑-1.04亿，Q4在岸6.69续压）与锂电装备32.64%/物流17.68%/海外33.72%全线下滑，抵消部分现金优势。H股募资43.95亿到账后净现金约118亿（货币151亿）仍支撑扩张。
3. **固态电池产业化高杠杆期权（2027 量产元年）**：单GWh 4-5亿（2-3倍）+存量替换30%+市占70%+；公司固态订单"接近翻倍式增长"（Q3持续获单，占比仍<5%），宁德宜宾中试线8月通线规划2027小批量、比亚迪2027装车、奇瑞10-08集中采购；2027 GWh级量产线招标是目标价上修（50.17元）触发器。

### 1.4 投资建议

**评级：中性偏积极/谨慎增持（2027E锚定切换后预期收益转正，但盈亏比0.34不充分）；第三象限（高确定性 + 中低收益空间，等待三季报验证）**

- 先导智能是"好公司 + 估值回归合理区间"：订单/现金流/护城河/固态期权质地优（合同负债174亿+35%新高，OCF 40.85亿历史最佳，订单能见度至2027-08），2027E 中性归母净利 25.0亿（+42.9% vs 2026E 17.5亿），收入端由订单锁定（确定性5/5），利润端取决于毛利率修复与固态兑现。
- 现价32.35对应2027E PE 21.7x（低于中性25.25x）、2026E PE 30.96x、PE TTM 30.43x/PB 3.01x，估值自偏贵区间回归合理；中性37.71高于现价16.6%、加权36.48高于12.8%、盈亏比0.34转正但**不充分（<1）**。
- **操作策略**：现价32.35处中性偏积极区间，**左侧建仓下移至26-28元分批至60-70%（28元对应盈亏比1.10），30元以下逐步加仓，26元以下核心配置**；右侧信号为"10-29三季报毛利率≥32.5% + 固态GWh级招标落地"。技术面10-15收盘32.35（自10-12高点37.88回落-14.6%，回踩MA60附近）。
- **时间框架**：12-18个月持有期。若三季报毛利率修复或2027固态放量，中性上修至42-45元（2027E EPS 1.55-1.60×26-28x），届时盈亏比转正扩大。

## 三、研究结论象限图（Final Evaluation Matrix）

```
                      高确定性
                          │
        第一象限          │          第二象限
   (High-Conviction Buy)  │    (Speculative Growth)
                          │
   ───────────────────★──┼───────────────────
       （先导智能定位）   │
                          │
        第三象限          │          第四象限
     (Defensive Value)    │      (Avoid/Wait)
                          │
                      低确定性
                      低 ←── 预期收益空间 ──→ 高
```

**象限定位：第三象限（高确定性 + 中低收益空间）**

- **确定性维度（高，3.5/5）**：订单能见度至2027-08/合同负债174亿/现金流40.85亿/护城河5/5，2027E 收入确定性5/5；利润确定性3.5/5（毛利率修复+固态兑现双不确定，H1毛利率31.90%实证）。
- **收益空间维度（中低）**：中性37.71高于现价16.6%、加权36.48高于12.8%、盈亏比0.34转正但不充分；保守价20.31（-37.2%）对应安全边际门槛在26-28元。
- **对应策略**：现价32.35处中性偏积极区间，**26-28元分批至60-70%、30元以下逐步加仓**；右侧信号为10-29三季报毛利率≥32.5%+固态GWh级招标落地。**当前不构成强"买入"（盈亏比0.34不充分），亦不构成"回避"（订单锁定+估值回归合理）。**
