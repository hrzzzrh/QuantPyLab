## 五、分部估值（SOTP）分析

新易盛业务高度集中于光互联产品（占比99.72%），传统分部估值（SOTP）的适用性有限。按照框架要求，仅当存在多个不同属性业务板块时才执行SOTP。新易盛目前不具备此条件，该步骤跳过。

**替代性验证**：通过产品结构拆分验证总利润的合理性——

| 产品线 | 2026E营收（亿） | 毛利率 | 毛利润（亿） | 说明 |
|:---|:---|:---|:---|:---|
| 1.6T光模块 | 276 | 49% | 135 | 高毛利引擎，供给缺口支撑ASP |
| 800G光模块 | 304 | 47% | 143 | 规模主力，全球需求>4500万只 |
| 400G及以下 | 15 | 28% | 4.2 | 持续萎缩 |
| 其他 | 0.7 | 40% | 0.3 | 极小 |
| **合计** | **~596** | **47.4%** | **283** | |
| 减：期间费用 | | | 60 | |
| 减：税费 | | | 29 | |

> **勾稽校验**：P*Q自下而上推演值（~596亿营收）与自上而下校准值（~550亿营收）之间的偏差约8%，主要来自ASP的综合估算误差和产品组合复杂度。采用经校准的550亿/195亿作为正式预测值。

## 七、模块五结论

1. **2026年中性预测（H1预告校准后）**：营收550亿元（+121%），净利润195亿元（+105%），EPS 13.99元（13.94亿股），毛利率47.5%，净利率35.5%。核心驱动力是1.6T放量（从~50万只到350万只）和800G维持量价高位。H1预告净利润70-80亿，Q2环比增长51-87%超预期，全年预测可期。

2. **确定性评分最高的假设**：800G出货1200万只（4/5分，Jefferies确认全球需求超4500万只）；**最低的假设**：2027-2028年持续增长（2/5分，供需拐点和竞争格局存在重大不确定性）。

3. **多情景概率加权结果**：Bull 30% × 230亿 + Base 50% × 195亿 + Bear 20% × 155亿 = 加权净利润约198亿。Bull概率上调5%（因Jefferies确认需求超预期），Base下调5%（H1实际值偏移），Bear维持20%。

4. **核心分歧**：市场共识（花旗目标701元）对2027年EPS极为乐观（隐含EPS>30元），但我们认为尽管Jefferies上调了行业需求，1.6T ASP下行（$1150→$850）和毛利率回落（47.5%→42.5%）将持续到2027年。叠加H股约8%稀释，2027E EPS仅15.06元，几无增长。**本研究仍是市场上对2027年展望最谨慎的声音之一。**

5. **SOTP不适用**：公司业务高度集中，分部估值无意义。改用产品结构拆分验证了总利润的合理性。
