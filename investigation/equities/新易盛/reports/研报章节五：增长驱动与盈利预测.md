## 五、分部估值（SOTP）分析

新易盛业务高度集中于光互联产品（占比99%+），传统分部估值（SOTP）的适用性有限。按照框架要求，仅当存在多个不同属性业务板块时才执行SOTP。新易盛目前不具备此条件，该步骤跳过。

**替代性验证**：通过产品结构拆分验证总利润的合理性（2027E中性）——

|:---|:---:|:---:|:---:|:---|
| 1.6T光模块 | 539 | 44% | 237.2 | 高毛利引擎，量增+200%、价降25% |
| 800G光模块 | 347 | 41% | 142.3 | 规模主力，ASP持平、量增37% |
| NPO/其他 | 4 | 47% | 1.9 | 2027年小批量 |
| **合计** | **~890** | **42.9%** | **381.4** | 与表2B的382.7亿基本一致 |
| 减：期间费用 | | | 44.0 | 含税金1.3亿、汇兑8亿 |
| 减：所得税净额（税率15%−其他收益3亿） | | | 48.0 | 340.7×15%−3.0 |
| **净利润** | | | **~290** | 与表2B一致 |

> **勾稽校验**：P*Q自下而上毛利润381.4亿与表2B的382.7亿差异仅1.3亿（0.3%），产品结构拆分验证了总利润的合理性。

## 七、模块五结论

1. **2026年中性预测（Q3实际校准）**：营收500亿元（+101%），净利179亿元（+88%），EPS 12.83元，毛利率47.3%，净利率35.8%。9M完成度63.7%，隐含Q4收入181.5亿（环比+65.9%）、净利65.3亿——这是全年预测的单点故障，也是最近一个可验证节点。

2. **2027年中性预测（目标年份）**：营收890亿元（+78%），净利290亿元（+62%），EPS 20.79元，毛利率43%，净利率32.6%。核心驱动：①股权激励累计下限（2026-2027≥1,400亿）隐含2027年≥900亿；②1.6T出货1,050万只（+200%）、ASP $750（-25%）；③NPO 2027年小批量（约4亿）、2028年规模化；④汇兑损失收窄至8亿。三态：乐观330亿/23.66元、中性290亿/20.79元、保守180亿/12.91元。

3. **确定性评分**：2026年营收500亿（激励下限+公司信心）4/5；2027年营收≥900亿（累计考核）3/5（执行力折价）；1.6T出货1,050万只 3/5（DSP供给约束）；毛利率43% 3/5（Q3已降至46.27%、2027年降价）；税率15% 4/5（已实证）。

4. **增速换挡但绝对增长显著**：2027E中性净利+62%（vs 2026E +88%），增速换挡反映1.6T降价周期与高基数，但1.6T量增（+200%）+NPO接力+汇兑改善仍驱动绝对利润增长。**较市场共识（天风273亿/2026、部分卖方2027年更高）审慎，较本研究上期（292亿）基本持平。**

5. **SOTP不适用**：公司业务高度集中（光互联占比99%+），分部估值无意义。产品结构拆分继续验证总利润的合理性。

6. **预测的可证伪性**：本预测的三个可观测证伪点——①2026Q4收入<160亿（2027年4月年报）；②2027H1收入<380亿（2027年8月半年报）；③Q4毛利率<45%。任一触发，F4（2027年净利290亿）必须下修，不得只解释。
