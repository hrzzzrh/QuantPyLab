## 1. 投资摘要 (Investment Summary)

### 1.1 核心投资逻辑（半年报后复核，维持但增加现金流瑕疵）

天顺风能正处于**"陆上衰退出清 + 海工爆发爬坡 + 发电稳定支撑"**的三重业务结构切换关键期。**2025年首次年度亏损的"先出清"逻辑在2026年半年报得到首次财务验证——扭亏为盈但现金流未同步修复**：

1. **海工装备（25.51%营收占比，+220%增速→2026H1 Q2止跌回升）**—— 2025年成为核心增长引擎，**2026H1 Q2 13.62亿（+7.8%）+33.67亿在手订单（含税，04-30）验证爬坡**，国内份额前三、与大金重工形成"双寡头"，**但H2需13.5亿交付（约Q2的1倍）方能兑现全年22亿预测**。
2. **零碳发电（24.44%营收占比，毛利率62.87%→H1新增468.4MW至2,251MW）**—— 1.78GW→2.25GW提供稳定现金流，已核准461.6MW+开工251.6MW保障增长，但**风资源偏弱致H1发电量同比下降为新瑕疵**。
3. **陆上风能装备（45.55%营收占比，-15.68%增速→H1营收-7.72%主因）**—— 主动收缩延续，2026年1月停产6家子公司是"战略出清"而非"被动萎缩"。

> **一句话校正**：原"战略定力"标签在半年报后修正为 **"战略定力兑现第一步（扭亏），但现金流与存货为第二步待验证"**。

## 2. 风险因素 (Risk Factors)

按对股价影响的烈度进行优先级排序：

### 2.1 高烈度风险（可能导致股价下跌30%+，半年报后新增"现金流"为首要风险）

#### 风险1：现金流与流动性风险（新增，半年报后首要）

- **触发条件**：H1 OCF -3.49亿（连续两季为负）+ 存货25.55亿（+5.57亿）+ 货币6.44亿（-3.87亿），若Q3 OCF仍为负且存货继续攀升
- **影响**：
  - 经营+投资净流出16.31亿（H1），依赖筹资13.60亿覆盖，**自造血能力阶段性失效**；
  - 若Q3未回款，**全年OCF 2-5亿指引落空**，资产负债率或破65%警戒；
  - 定增19.5亿若审核受阻（问询10项含存货库龄59.87%超1年、关联采购3.27亿），**流动性压力将延续至2027年**。
- **当前状态**：H1已触发"连续两季为负"（Q1 -2.37 + Q2推算-1.13），**合同负债6.61亿（+0.82亿）为唯一积极信号**。
- **跟踪时点**：2026Q3季报（OCF是否转正、货币是否企稳）

#### 风险2：欧盟反倾销税续期或扩大范围

- **触发条件**：2026年12月17日日落复审后，欧盟对塔筒维持14.4%税率，或扩大至单桩/导管架
- **影响**：
  - **维持现状**：海外塔筒出口成本+14.4%，对天顺影响有限（已主动收缩陆上）
  - **扩大范围**：海外业务受损**3-5亿**
- **当前状态**：欧委会已发布即将到期通知（2026年3月20日）
- **跟踪时点**：2026-12-17

#### 风险3：商誉减值风险（问询后升级）

- **触发条件**：海工业务或电站资产现金流不达预期，或**定增问询中江苏长风收购（29.07亿现金/商誉19.05亿）被要求补充计提**
- **影响**：
  - 商誉19.05亿占H1净资产21.6%（88.03亿），若计提5-10亿减值，**单次冲击EPS 0.28-0.56元，且净资产直接缩水5-10亿**；
  - 问询函直指"业绩承诺/变相侵占上市公司利益"，**监管关注使计提概率上行**。
- **当前状态**：2025年及2026H1均未计提，但**问询回复后待审核，仍存隐患**
- **跟踪时点**：2026年报商誉减值测试 + 定增审核进展

#### 风险4：海工H2交付不及预期

- **触发条件**：H1 20.20亿（-7.72%）→ 全年55.2亿需H2完成35.0亿（约Q2的2.6倍），若H2海工交付<13.5亿（全年22亿落空）
- **影响**：
  - 2026E营收下修至50亿（Bear情景），全年净利或仅1.5-2.0亿（EPS 0.08-0.11），**与2.50-2.94亿指引背离**；
  - 德国基地利用率不足，固定成本摊销压力，SOTP估值下调20-25%。
- **当前状态**：阳江已Q2试投产，但**H1存货25.55亿显示"备货未交付"**，Q3交付节奏为关键。
- **跟踪时点**：2026Q3季报（营收是否≥15亿/季、合同负债是否≥7亿）

#### 风险5：欧洲AR7项目落空

- **触发条件**：2026-2027H1供应商锁定中，天顺未获主流订单
- **影响**：
  - 德国基地50万吨产能利用率不足
  - 失去"出海"逻辑
  - 估值修复"看涨期权"（30亿）归零
- **当前状态**：欧洲H1已授出17GW（英国9.74+德国5.89），AR7窗口兑现中，**机会与竞争同步加剧**
- **跟踪时点**：2026-2027H1定标结果

## 4. 风险/收益的不对称性分析（09-19现价7.72元复核）

### 4.1 当前赔率（加权口径，按框架）

| 情景 | 目标价 | 概率 | 期望收益（09-19） | 06-05原值 |
|---|---|---|---|---|

| 中性 | 5.96元 | 50% | 2.98元 | 同 |
| 乐观 | 11.96元 | 25% | 2.99元 | 同 |
| **总期望（加权）** | **6.43元** | - | - | **6.43元** |
| **当前价** | **7.72元** | - | - | 9.77元 |
| **期望收益** | - | - | **-1.29元（-16.7%）** | **-3.34元（-34%）** |

> **口径校正**：原"当前赔率"未区分"乐观价"与"加权价"，现按框架强制以**加权目标价6.43元**为分子，**保守价1.84元**为分母计算盈亏比。

### 4.2 盈亏比计算（按框架强制口径修正）

```
框架盈亏比 = (加权目标价 - 现价) / (现价 - 保守目标价)
06-05： (6.43 - 9.77) / (9.77 - 1.84) = -3.34 / 7.93 = -0.42（期望为负）
09-19： (6.43 - 7.72) / (7.72 - 1.84) = -1.29 / 5.88 = -0.22（期望仍为负但收敛0.20）

参考（乐观口径，非框架）：
乐观盈亏比 = (乐观 - 现价)/(现价 - 保守) = (11.96 - 7.72)/(7.72 - 1.84) = 4.24/5.88 = 0.72（>1需乐观兑现）
```

**盈亏比 -0.22 < 0（期望为负）**：**仍为不利赔率，但较06-05的-0.42显著修复**；若用乐观口径则为0.72（需乐观情景兑现方为正）。

**对比标准（加权口径）**：
- **优秀投资**：盈亏比 ≥ 2.0
- **可接受投资**：盈亏比 1.0-2.0
- **不利投资**：盈亏比 < 1.0
- **期望为负**：盈亏比 < 0 ← **天顺当前位置（加权-0.22），需回调至6.43附近方转正**
