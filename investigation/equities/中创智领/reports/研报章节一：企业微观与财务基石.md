# 研报章节一：企业微观与财务基石

**研究日期**：2026年08月31日

## 一、公司概览与业务内核

中创智领（郑州）工业技术集团股份有限公司（601717.SH / 0564.HK），前身为郑州煤矿机械集团股份有限公司（郑煤机），始建于1958年，2010年A股上市，2025年完成更名，标志着公司从传统煤矿机械制造商向多元化工业技术集团的战略转型。公司实际控制人为河南省国资委。

公司当前形成 **煤矿机械、汽车零部件、工业智能** 三大核心业务板块：

### 1.1 煤矿机械板块（营收 ~188亿，占比 ~46% → 2026H1 72.3亿占比38.5%）

核心产品为煤炭综采液压支架及配套设备。液压支架是井工煤矿综采工作面的核心支护装备，与采煤机、刮板输送机构成综采"三机一架"系统。公司全球领先，国内市场占有率连续十余年保持30%以上。产品以销定产、个性化定制，根据煤矿地质条件进行差异化设计。

2025年煤机板块营收 187.78亿，同比 +10.01%，毛利率 28.94%（同比 -2.92pp）。2026H1煤机板块实现收入**72.3亿元，同比-20.3%**（公司公告披露），受下游煤炭行业周期性调整、能源结构加速转型、煤矿企业资本开支收紧及行业竞争加剧影响，液压支架及配套设备市场需求显著减少，但海外市场中标额>10亿元同比+50%（澳大利亚、哈萨克斯坦、美国）、矿用机器人订货同比+60%且获首批28台履带行走支护机器人订单、掘锚一体机获首台套订单等结构性亮点仍存。公司推出常水支架（零排放液压支架）和全电动支架两大创新产品，以及覆盖采掘、运输、支护等环节的十大矿用辅助作业机器人，向绿色化、智能化方向升级。

### 1.2 汽车零部件板块（营收 ~199亿，占比 ~48% → 2026H1 105.43亿占比56.2%）

通过2016年并购整合建立，旗下包含两大品牌：
- **SEG（索恩格）**：德国品牌，主营乘用车和商用车起动机、发电机、启停电机及轻混能量回收系统（BRM），全球9个生产基地和研发中心，12个国家销售代表处。2025年海外营收 131.49亿，净利润 3.57亿（净利率仅 ~2.7%）；**2026H1 SEG实现营收71.45亿元（714,528.10万元）、净利润2.96亿元（29,566.79万元）、净利率4.14%**，同比营收+11%、净利润+176%（半年报披露），盈利水平显著改善。
- **亚新科集团（ASIMCO）**：国内品牌，包括亚新科山西（铸造）、亚新科NVH（噪声与振动）、亚新科双环（活塞环）、亚新科凸轮轴等，主要面向国内商用车和乘用车市场。

2025年汽车零部件板块营收 198.81亿，同比 +14.03%，毛利率 14.44%（同比 +0.71pp），呈改善趋势。分产品看，底盘系统零部件销量 9.73亿件（+13.85%），动力系统零部件销量 2.35亿件（-9.95%），汽车电机销量 2637万件（-0.22%）。**2026H1汽车零部件板块实现收入105.43亿元，同比+7.2%**，主要由欧洲、印度市场传统电机业务增长及国内新能源电机量产贡献驱动。

### 1.3 工业智能板块（营收 ~22亿，占比 ~5% → 2026H1 15.7亿占比8.4%）

以恒达智控、数耘等品牌，专注于矿山、工厂等全场景的数字化解决方案。2025年营收 21.72亿，同比 +12.56%，毛利率 41.84%（同比 -5.62pp），虽毛利率有所下滑，但依然是各板块中利润率最高的业务。该板块体量尚小，但增长潜力值得关注。**2026H1工业智能板块实现收入15.7亿元，同比-2.1%**，在煤矿企业整体投资需求收紧环境下，传统智能化产品下滑，但智慧矿山/智能供液等新业务及智能产线改造、仓储物流等智能制造业务（收入占比提升至13%、新产品新业务收入同比+112%）快速增长，形成对冲。

## 二、近五年盈利质量透视

### 2.1 营收与利润趋势

**核心趋势（2021-2025）**：
- 营收 CAGR ~9.0%（292.94亿 → 413.85亿）
- 归母净利润 CAGR ~21.9%（19.48亿 → 42.93亿）
- 净利率从 7.07% 提升至 10.54%，盈利质量显著改善
- ROE 从 14.06% 提升至 18.88%，连续四年上行
- ROIC 从 10.30% 提升至 14.45%，资本运用效率持续优化

**2026H1重大拐点（08-30正式披露，需双源交叉已验证）**：
- 营收187.64亿同比-6.04%，归母16.03亿同比-36.25%，扣非12.71亿同比-40.47%，基本EPS 0.918元同比-35.67%，表现大幅低于此前2026E基准37.5亿（H1仅完成42.8%）。
- Q1归母8.92亿、Q2归母7.11亿（16.03-8.92），环比-20.3%，同比Q2约14.26亿腰斩；扣非Q1 6.38亿、Q2 6.33亿环比基本持平，说明Q2非经常性收益（处置/政府补助等）占比下降，经营性盈利已无增长。
- 综合毛利率推算19.82%（营业成本150.46亿/营收187.64亿），较2025H1约23.55%下滑约3.7pp，验证Q1的19.27%非一次性、已呈现趋势性恶化（跟踪手册3.1一级证伪信号“2026H1综合毛利率<19.5%且煤机毛利率<26%”已实质触发）。
- 行业对照：核心竞对天地科技同期营收125.65亿-11.01%、归母7.35亿-64.68%（但需剔除上年同期沁南能源处置25.27亿一次性收益，扣非口径同比仅-38.46%至6.47亿，经营性收缩约四成），印证为行业性需求收缩而非公司个体份额丢失，但公司-20.3%的煤机跌幅亦与行业同步（经营性收缩幅度与扣非-38.46%可比）。

**关键盈利亮点（历史）**：
1. **规模效应释放**：营收增长的同时费用率持续摊薄，净利率提升约3.5个百分点。
2. **毛利率波动**：2024年毛利率跳升至23.99%（受益于原材料价格下行），2025年回落至22.66%，反映材料成本占比高（直接材料占制造成本68.08%）的周期敏感性。
3. **Q4利润骤降**：2025年Q4归母净利润仅6.48亿（Q1 10.89亿、Q2 14.26亿、Q3 11.30亿），Q4净利骤降需关注是否存在集中计提减值或费用前置。

## 三、成本与费用穿透

### 3.1 成本结构（2025年机械制造分部）

| 成本项目 | 金额（亿） | 占总成本比例 |
|:---|:---|:---|
| 直接材料 | 215.24 | 68.08% |
| 直接人工 | 22.70 | 7.18% |
| 制造费用及其他 | ~78.20 | 24.74% |

直接材料占比高达68%，钢材等大宗商品价格波动对毛利率影响显著。2024年毛利率跳升主要受益于钢价下行，2025年毛利率回落也与此相关。**2026H1成本端**：营业成本150.46亿同比仅-1.43%，显著小于营收-6.04%的降幅，印证材料成本刚性与价格竞争导致的毛利挤压；钢材价格截至2026年8月下旬螺纹钢均价约3304元/吨（周环比+2.07%，Mysteel调研），较3月3455元降后有所回升但仍处于相对低位，未能对冲价格战压力；铜价（LME 8月约9000-10000美元高位）对SEG电机成本形成持续压力。

### 3.2 期间费用率趋势

- **研发投入**：2025年研发投入合计 20.57亿（费用化17.79亿 + 资本化2.78亿），占营收 4.97%，资本化率 13.52%。研发人员2311人，占员工总数14.02%，其中硕士及以上664人。2026H1研发费用7.68亿元同比-2.82%，费用化投入边际收缩。
- **期间费用（2026H1）**：销售费用4.33亿+6.26%、管理费用7.17亿+12.45%、财务费用1.70亿+48.69%（汇兑损益波动主因），三项合计较去年同期增加约1.39亿，对利润形成额外侵蚀。
- **费用率**：2026H1营收187.64亿，期间费用（销管财研）合计20.89亿，费用率11.13%，较2025H1约11.0%微升，规模效应未能延续。

## 四、财务亮点与潜在风险点（2026H1更新）

### 财务亮点

1. **盈利质量历史提升但H1出现逆转**：ROE从14%→19%（2021-2025四年上升）后，2026H1加权ROE骤降至7.02%（半年度），ROIC同步承压，盈利拐点确认。
2. **现金流大幅修复**：OCF 20.74亿同比+63.26%、OCF/净利1.29创近年新高，Q2单季OCF 19.13亿显示回款改善，缓解了2025年应收激增的担忧。
3. **杠杆与商誉仍清洁**：资产负债率约52%仍处可控区间，商誉仅0.88亿无减值隐忧。
4. **汽零与智能结构性改善**：汽零营收+7.2%且SEG净利率+1.44pp至4.14%、智能新业务+112%且智能制造占比提升至13%，为煤机下滑提供对冲。

### 潜在风险点（风险等级上调）

1. **综合毛利率趋势性恶化（新增一级证伪触发）**：2026H1综合19.82%已跌破跟踪手册黄灯预警19.5%的临界区间（仅高0.32pp），较2025H1下滑3.7pp，且Q2扣非环比零增长显示企稳未兑现，需高度警惕毛利率进入下行通道。
2. **煤机需求周期性收缩超预期**：H1煤机-20.3%且竞对天地科技-11.01%/-64.68%同步验证，行业性需求收缩已替代此前的“更新替换韧性”假设；煤炭工业“十五五”规划虽强化智能化75%目标，但新增产能“一本账”严格置换意味着总量扩张有限，设备需求更多依赖存量改造，价格竞争加剧。
3. **应收与长期借款双扩张**：2025年末应收激增历史包袱未完全消化，H1长期借款又翻倍至55亿，财务费用+48.69%且受限资产19.43亿，流动性与利息负担需持续监控（跟踪手册OCF/净利<0.4二级证伪虽暂解除，但杠杆回升构成新关注点）。
4. **境外盈利虽改善但绝对值仍薄**：SEG 4.14%净利率较2.7%显著进步，但仍远低于全球龙头Bosch/Denso 5-8%水平，且受人民币汇率波动及汽车零部件232/301关税（约50%综合税率）间接影响，海外盈利稳定性不足。
5. **可转债供给压力与稀释**：可转债修订后41.40亿元（原43.5亿，补流从12亿降至9.90亿）虽略有收缩，但转股稀释11-15%预期及审核不确定性仍构成持续压制；Q2股价已从15.34元回调至14.23元，反映市场对盈利下滑的定价。
6. **贸易业务低效占用资源**：28.35亿营收、毛利率仅2.93%，约等于无利润的流水，消耗营运资金。
