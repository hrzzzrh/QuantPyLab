## 四、PB-ROE辅助参考（更新）

- 2026H1末BPS = 236.87/17.854 = **13.27元**（较2025年末13.55元-2.07%）
- 2026E ROE（基准32亿/236.87）≈ **13.5%**（年化7.02%×2≈14.04% vs 2025年18.88%显著回落）
- Ke = 10%：合理PB = ROE/Ke = 1.35x → 目标价 **17.91元**
- Ke = 12%（保守）：合理PB = 1.125x → 目标价 **14.93元**
- **当前PB 1.07x**：恰处于近5年P10（1.07），较P05（1.04）仅+2.9%，仍处历史底部但较6月25日的1.05x微升（资产缩水+股价回调幅度小于盈利下滑）。

PB-ROE显示，若ROE能维持13.5%，当前1.07x显著低估；但若ROE进一步下滑至10%以下（保守场景27亿对应11.4%），合理PB 10% Ke下仅1.14x，对应15.12元，PB安全边际亦收窄。

### 盈亏比（框架强制口径，分子加权、分母未调节保守价）

盈亏比 = (加权目标价 - 现价) / (现价 - 保守价)  
= (12.7 - 14.23) / (14.23 - 11.50)  
= -1.53 / 2.73 = **-0.56**

**判定**：分子为负（加权目标<现价），加权预期收益-10.8%，已跌破盈亏比1.0阈值；按框架“现价<保守价时记∞+”不适用，此处现价>保守价但加权为负，属**负盈亏比**，投资吸引力丧失。较上期2.08大幅转负。

*若误将-8%作用于保守价至10.58元，则分母2.??会虚增盈亏比，属框架违规；此处严格按“仅中性调节”。

## 十、修正后投资结论（评级下调）

**评级调整：买入（偏谨慎）→ 持有/观望（Hold / Wait）**

一个月内第四次下修目标价（29.80→22.0→17.24→12.35元），审计后基准累计-58.6%，直接原因是**2026H1业绩证伪趋势性恶化**（19.82%毛利率+煤机-20.3%+归母-36.25%）及**行业性收缩**（天地科技-64.68%）的双重验证。此前乐观假设中“Q2企稳回升至21%+”已证伪，盈利预测中枢需永久性下移约15%。

**核心投资逻辑是否已被推翻？**

**部分推翻，逻辑磨损至临界：**

1.  **煤机智能化政策逻辑未被推翻但增量显著弱于预期**：十五五规划75%智能化目标（现65%）仅+10pp增量，且产能“一本账”严格置换使总量扩张有限，智能化需求更多依赖存量改造与价格竞争，3-5年增量逻辑从“年均15-24亿”下修至“年均8-12亿”。
2.  **可转债逻辑边际改善但仍为压制**：41.40亿/补流9.90亿较此前收缩，且3-4亿回购+增持对冲部分供给压力，长期资本配置方向正确但短期稀释与审核不确定性未解除。
3.  **估值不再极端低估**：PE 7.51x（P10-P25）/PB 1.07x（P10）已较6.41x/1.05x回升，安全边际收窄；按新基准12.35元，现价已高出目标13%，估值支撑削弱。
4.  **盈亏比转负**：-0.56且加权预期-10.8%，已跌破1.0重仓线，更远离2.0高赔率区间，风险回报劣化。

**但尚未跌入“清仓”区间的原因：**

- SEG与智能制造的结构性改善（SEG +176%、智能新产品+112%）及OCF 20.74亿（+63%）的现金流修复，提供了盈利对冲与流动性缓冲；
- 7.51x PE仍处历史偏低，PB 1.07x接近地板，对应11.50元保守价仍有-19.2%安全垫，极限下行相对可控（地狱10.5-13.3元）；
- 持有/观望而非卖出，等待Q3毛利率是否企稳20.5%+及十五五规划执行催化（山西等基地大型现代化煤矿建设）。

**维持策略**：**持有/观望**，审计后基准12.35元（-13.2%）、加权12.7元（-10.8%）。**操作**：14.0-14.5元区间不新增仓位；若股价回调至11.5-12.0元（对应保守价+地狱区间上限）可左侧小幅试仓；若放量收复15.0元（MA20/60附近）且Q3毛利率回升至20.5%+再考虑加仓。关键验证节点：**2026Q3业绩（10月底）毛利率与回款持续性、15五规划大型煤矿建设招标、天地科技Q3是否继续恶化**。
