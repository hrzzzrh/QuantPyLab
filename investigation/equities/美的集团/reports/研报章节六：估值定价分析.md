## 一、价值锚定：适配性方法选择（2026年06月26日历史快照）

### 1.1 方法论选择理由

美的集团的商业模式特征决定了估值方法的优先级：

| 估值方法 | 适配度 | 理由 |
| :--- | :---: | :--- |
| **PE（市盈率）** | ★★★★★ | 盈利稳定、现金流充沛，是最合理的主锚 |
| **DCF（现金流折现）** | ★★★★☆ | 自由现金流充沛（2025年FCF 422亿），作为验证锚 |
| PB-ROE | ★★★☆☆ | 适用于ROE下行期评估底部支撑，但PB受权益基数扩张影响 |
| PEG | ★★★☆☆ | 利润增速9-11%（中性），PE约11-14x，PEG<1.5合理 |
| SOTP | ★★★★☆ | 适用于ToC/ToB业务差异化的估值逻辑 |
| PS | ★★☆☆☆ | 不适用于成熟制造企业 |
| EV/EBITDA | ★★★☆☆ | 作为辅助参考，排除折旧摊销影响 |

**选择路径**：以PE为主锚（对标历史分位和同业），SOTP为结构验证，DCF/FCF yield为安全边际验证。

### 2.3 修正市值计算

**基准市值选择**：

> 口径说明：FCF Yield 法使用中性情景预测 FCF 440 亿（含经营改善假设），与章节一 2025 年实际 FCF 422 亿（OCF 533.5 − Capex 111.4）口径不同，属预测值；DCF/FCF 仅作安全边际验证，估值主锚为 PE 法。

| 方法 | 参数 | 基准市值 |
| :--- | :--- | :---: |
| PE法（中性EPS 5.95×合理PE 12.5x） | 12.5x × 452亿 = 5,650亿 | 5,650亿 |
| PE法（中性EPS 5.95×合理PE 14.5x） | 14.5x × 452亿 = 6,554亿 | 6,554亿 |

## 四、逻辑证伪与极限压力测试

### 4.1 黑天鹅情景：三重打击同时发生

**定义**："国内需求断崖 + 海外贸易壁垒全面升级 + 铜价突破15万元/吨"同时发生

在此极端情景下：
- 国内家电零售全年下滑20%+（连续两年国补透支）
- 美国对所有中国产品征100%关税，且东南亚转口被堵死
- 铜价受供应冲击突破15万元/吨

**极限利润测算**：收入下滑30%至3,200亿，毛利率降至21%，归母净利润约100亿。EPS ≈ 1.31元。

### 4.2 极限支撑位（地狱价格）

在"行业生存危机"模式下，市场给予的PE将极度压缩（类似2018年美的PE曾低至9.5x）：

- **PE极限压缩**（9.5x）：100亿 × 9.5x = 950亿市值 → **12.5元/股**
- **PB清算价值**（1.5x归母权益下限）：2,232亿×1.5 = 3,348亿 → **44.0元/股**
- **股息安全垫**（按每股4.3元/年，5%股息率要求）：**86元/股**（当前价格86.18元略高于此线，股息率约5.0%，持有收益由正转平；若按68元建仓线则股息率6.3%）

**综合极限支撑位**：约**40-45元**（接近1.5x PB或净资产清算价值）

**风险判断（2026年08月28日重估）**：当前86.18元距离极限支撑位40-45元约48-49%下行空间，距离新中性目标价79.2元上行-8.1%（已透支，vs旧91.0元+15.9%），距离加权目标80.2元下行-6.9%，风险收益比由6月26日1.32骤降至-0.27，安全垫消失。
