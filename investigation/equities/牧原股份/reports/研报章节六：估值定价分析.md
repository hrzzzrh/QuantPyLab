# 研报章节六：估值定价分析

> **研究日期**：2026年7月29日
> **研究对象**：牧原食品股份有限公司（002714.SZ / 02714.HK）
> **逻辑继承**：模块五更新后，2026E三态EPS为Bear -1.39 / Base -0.43 / Bull +0.52，概率加权EPS约-0.44元；2027E初步框架Bear/Base/Bull EPS仍为3.12/5.72/9.01元。2026年盈利因H1预亏57-67亿元下修，但二季度末全国能繁母猪降至3,780万头使2027年反转确定性上升。本模块选择适配估值方法，通过全变量审计矩阵给出目标市值和股价。

---

## 一、价值锚定：适配性估值方法选择

牧原股份是典型的**强周期+重资产+龙头地位**企业，当前处于猪周期底部（2026E大概率亏损），传统PE估值法完全失效。根据其商业模式特征，选择以下三种方法交叉验证：

| 估值方法 | 适用理由 | 权重 |
|:---|:---|:---|
| **PB-ROE**（主力方法） | 重资产公司（固定资产>1000亿），净资产是利润的载体。当前PB 2.57倍仍处近5年低位约3.2%分位，但已较6月末2.31倍修复 | 40% |
| **头均市值**（行业通行） | 生猪养殖行业特有估值范式，按每头出栏生猪赋予市值来定价猪企 | 35% |
| **PB绝对估值**（底线锚） | 在盈利为负时提供底线锚，评估资产安全垫厚度 | 25% |

> **为什么不用PE？** 2026E EPS为负值，猪周期底部年份PE剧烈跳变（2023年负值→2024年20-25x→2025年8-13x），纯PE法会产生严重误导。
> **为什么不用DCF？** 猪周期利润波动极大，自由现金流极不稳定，DCF对终值假设过度敏感。

当前为Q2，根据框架规则锚定2026年。但因2026E EPS为负，主力采用PB-ROE和头均市值。

## 二、基准市值测算

### 2.1 方法一：PB-ROE模型

公允PB = (ROE - g) / (COE - g)

| 参数 | 取值 | 依据 |
|:---|:---|:---|
| 周期平均ROE | **18%** | 2019-2025年剔除2020（74.43%）和2023（-6.38%）极端值后均值约18% |
| 权益资本成本(COE) | **9.5%** | Rf 1.7%（10年期国债）+ ERP 6.0% × Beta 1.3 |
| 永续增长率(g) | **3.0%** | 猪肉消费稳中有降，但牧原可通过份额提升+屠宰+海外维持低个位数增长 |
| 2026E BVPS | **~14.72元** | 2026Q1 BVPS 14.94元 - Base全年亏损较Q1继续摊薄约0.22元；H1预告中值对应中期BVPS约14.08元 |

计算：公允PB = (18%-3%) / (9.5%-3%) = 15%/6.5% = **2.31倍**
PB-ROE基准市值 = 57.73亿股 × 14.72元 × 2.31 = **1,963亿元**

### 2.2 方法二：头均市值法

| 头均市值(元/头) | 出栏(万头) | 市值(亿) | 股价(元) | 场景 |
|:---|:---|:---|:---|:---|
| 2,500（历史底） | 7,600 | 1,900 | 32.9 | 亏损期底部锚 |
| **2,953（当前）** | **7,600** | **2,245** | **38.88** | **2026.7.29** |
| 3,000（保守） | 7,600 | 2,280 | 39.5 | 底部合理下沿 |
| **3,500（中性）** | **7,600** | **2,660** | **46.1** | **周期中部合理水平** |
| 4,500（乐观） | 8,000 | 3,600 | 62.4 | 周期上行期 |

头均市值基准区间：3,000-3,500元/头，对应2,280-2,660亿，中值**2,470亿**。当前头均市值已从6月末约2,590元/头修复至约2,950元/头，安全边际不再极端。

### 2.3 方法三：PB绝对估值（底线锚）

| 情景 | PB | BVPS(元) | 股价(元) | 市值(亿) |
|:---|:---|:---|:---|:---|
| 当前（Q1 BVPS口径） | 2.57 | 14.94 | 38.88 | 2,245 |
| H1预告后估算 | 2.76 | 14.08 | 38.88 | 2,245 |
| 历史5年低位 | 2.14 | 14.72 | 31.50 | 1,818 |
| 2023年亏损期最低 | ~2.70 | ~10.88 | 29.38 | 1,696 |
| 极端清算 | 1.55 | 14.72 | 22.82 | 1,318 |

### 2.4 基准市值综合

| 方法 | 基准市值(亿) | 股价(元) |
|:---|:---|:---|
| PB-ROE | 1,963 | 34.01 |
| 头均市值(中值) | 2,470 | 42.78 |
| PB绝对底线 | 1,818 | 31.50 |
| **综合基准** | **~2,185** | **~37.8** |

当前股价38.88元（市值2,244.5亿），已略高于综合基准市值——**市场已提前交易二季度能繁去化和7月猪价反弹，赔率较6月末明显压缩**。

## 三、全变量对冲审计矩阵

### 3.1 E vs PE 边界划分

| 因素 | 进入E or PE？ |
|:---|:---|
| H2猪价每+1元/kg约增利39亿 | E（可计算） |
| 成本11.6→11.3元节省约27亿 | E（可计算） |
| 二季度末能繁母猪3780万头 | E（提高2027供给收缩确定性） |
| 育种自主→10年后仍有成本优势 | PE（关乎长期确定性） |
| AI养猪领先→远期竞争力 | PE（关乎护城河宽度） |
| 政策结构红利（环保/碳交易） | PE（降低系统性风险） |
| 零地缘风险 | PE（折价消除） |
| AI牛市致周期股失宠 | PE（暂时性，不纳入永久调整） |

### 3.2 审计矩阵

**公式**：修正目标市值 = 基准市值 × (1 + 调节幅度总和)
**基准市值**：2,185亿元（37.8元/股）

| 审计维度 | 核心审计因子 | 审慎思考 | 调节 | 深度理由 |
|:---|:---|:---|:---:|:---|
| **内部-DNA** | **成本护城河持久性**：全链一体化带来的结构性成本优势（vs温氏0.2元/kg，vs行业>1元/kg） | 成本优势通常是阶段性的，但牧原的成本优势源于不可复制的商业模式结构，具有持久护城河属性。这是能改变估值中枢的稀缺特质 | **+5%** | 持久性成本优势降低了远期利润不确定性，PE应获确定性溢价 |
| | **技术自主与AI赋能**：育种自主+天网工程+养猪大模型，构建从经验到数据驱动的生产力代差 | 技术投入本身不创造溢价，但牧原AI技术正处于投入期→产出期节点（头均降本323/600元过半），未来3-5年红利确定性高 | **+3%** | 技术代差赋予轻度成长性溢价 |
| | **管理层战略定力与资本市场稳定动作**：H股3-5亿港元回购方案、董事高管5亿元A股增持完成、80亿元债务融资工具获准注册 | 回购和增持是信心信号，低息融资说明信用资质仍强；但这些不能替代盈利修复，不能给过高永久溢价 | **+1%** | 对流动性和市场信心有边际支撑 |
| **宏观-政策** | **结构性政策**：能繁母猪目标下调至3750万头且二季度末仅剩30万头缺口，环保趋严+土地收紧+CCER碳交易持续利好龙头 | 能繁去化会进入E端，不应重复给PE；但政策执行力提升降低了“反转一再延后”的不确定性 | **+4%** | 政策可信度上升，远期盈利折现率下降 |
| **宏观-地缘** | **纯内需+零海外资产** | 在一个地缘动荡的世界中，零地缘风险是稀缺的确定性优势 | **+2%** | 确定性本身就值钱，这是相对于其他A股的确定性补偿 |
| **市场-风格** | **AI牛市致周期股失宠** | 市场风格是暂时的，会在猪周期反转时轮动。不应纳入永久调整 | **0%** | 风格折价是逆向投资者的机会 |
| **综合调节** | — | — | **+15%** | — |

### 3.3 修正目标市值

**修正目标市值 = 2,185 × 1.15 = 2,513亿元**
**修正目标股价 = 2,513 / 57.73 = 43.5元/股**

| 估值锚 | 市值(亿) | 股价(元) | 相对当前空间 |
|:---|:---|:---|:---|
| 基准（未调节） | 2,185 | 37.8 | -2.8% |
| **修正目标** | **2,513** | **43.5** | **+11.9%** |

## 五、三态目标价与盈亏比

| 情景 | 概率 | 目标股价(元) | 逻辑 |
|:---|:---|:---|:---|
| **Bear** | 25% | **27.5** | 2026深亏约80亿→BV缩水→PB压缩至2.0倍 |
| **Base** | 50% | **43.5** | 修正目标市值（审计矩阵产出） |
| **Bull** | 25% | **58.0** | 2027猪价反转→EPS 5.72→约10倍PE |

**概率加权目标价** = 27.5×0.25 + 43.5×0.50 + 58.0×0.25 = **43.1元/股**

**盈亏比**（当前38.88元）：
(43.1 - 38.88) / (38.88 - 27.5) = 4.2 / 11.4 = **0.37**

若仅考虑Base情景：盈亏比 = (43.5-38.88) / (38.88-27.5) = 4.6/11.4 = **0.40**

盈亏比从6月末0.87压缩至0.37，核心原因是股价已从34.99元反弹至38.88元，而H1预亏使2026年净资产和利润锚下修。二季度末能繁母猪加速去化提高了2027年胜率，但当前价位已不是最舒服的左侧建仓点，新增仓位应等待回落至35-37元或7月销售简报进一步确认猪价均价上台阶。

## 六、黑天鹅情景与极限压力测试

### 6.1 一击毙命事件：非洲猪瘟新变异株大规模爆发

**定义**：一种致死率>50%、传染性极强的非洲猪瘟新变异株在中国爆发，牧原在某核心养殖大省（如河南）的猪群大面积感染，被迫扑杀数百万头生猪。

**极限情景推演**：
- 扑杀200万头存栏 → 直接损失约40亿元（200万头×2,000元/头重置成本）
- 恐慌性抛售 → 短期猪价暴跌至5元/kg以下
- 消费者恐慌 → 猪肉消费短期断崖式下跌30-50%
- 全年出栏从7,600万头降至5,500万头以下
- 全年亏损扩大至**250-300亿元**（包含扑杀+跌价+减值）
- BVPS从14.72元降至~10元
- 股价可能跌至**15-18元**（PB 1.5-1.8倍，在恐慌中PB可低至1倍以下）

**但需注意**：
1. ASF后牧原已投入大量资源构建防疫体系（空气过滤猪舍全覆盖），相比2018年已大幅提升
2. 大企业防疫能力远强于散户（牧原的生物安全等级行业最高），若新疫情爆发反而加速散户退出+加速猪价反转
3. 政府将采取更激进的收储+补贴措施
4. 牧原历史上应对过多次疫情（2023年冬季非瘟考验），具备成熟的应急预案

### 6.2 极限支撑位：地狱价格

**情景**：恐慌性抛售叠加流动性危机，市场给予重资产清算估值
- 账面净资产打7折（考虑存货贬值+生物资产减值）：BVPS ≈ 10.3元
- 市场极端恐慌下PB压缩至1.5倍
- **地狱价格 ≈ 15.6元/股**（较当前-55%，市值约900亿）

但这一情景**概率极低**（<5%），因为：
1. 公司账上现金138.62亿+H股融资60亿+，流动性充裕
2. 即使全年亏损100亿，净资产仍超800亿
3. 政府收储+产能调控会托底猪价
4. 牧原的产业地位决定了其too big to fail

### 6.3 风险管理框架

| 风险级别 | 股价锚点(元) | 触发条件 | 应对建议 |
|:---|:---|:---|:---|
| 正常波动 | 35-40 | 周期底部反弹后的震荡 | 持有，回调再加 |
| 警示线 | 28-30 | 猪价持续低于9元/kg超3个月 | 审视仓位，暂不加仓 |
| 止损线 | 24-26 | 能繁母猪不降反增+疫情爆发 | 减仓至半仓以下 |
| 地狱线 | 15-18 | 债务违约风险+系统性危机 | 清仓离场 |

## 七、估值定价结论

| 定价锚点 | 市值(亿) | 股价(元，不复权) |
|:---|:---|:---|
| 极限地狱价 | ~900 | ~15.6 |
| 保守情景 | 1,588 | 27.5 |
| 当前市价 | 2,244.5 | 38.88 |
| **概率加权目标价** | **2,488** | **43.1** |
| Base目标价 | 2,513 | 43.5 |
| Bull目标价 | 3,349 | 58.0 |

**核心判断**：当前股价38.88元处于**合理略低估但赔率已压缩**区间。基准价值约37.8元，经全变量审计矩阵修正后公允值约43.5元（+11.9%）。真正的超额收益空间仍来自Bull情景（58.0元，+49.2%），触发条件是猪周期在2027Q1如期反转且幅度超预期；但在H1预亏落地后，38-40元区间不宜追高，35-37元回调区间的风险收益更优。
