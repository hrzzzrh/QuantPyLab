# 研报章节六：估值定价分析

> **研究日期**：2026年8月22日
> **研究对象**：牧原食品股份有限公司（002714.SZ / 02714.HK）
> **逻辑继承**：模块五更新后，2026E三态EPS为Bear -1.39 / Base -0.35 / Bull +0.69，概率加权EPS约-0.36元；2027E初步框架Bear/Base/Bull EPS仍为3.12/5.72/9.01元。2026年H1半年报实际亏损60.78亿（TTM归母净利转负至-11.21亿），H1实际BVPS降至13.89元（归母权益801.87亿/57.73亿股，含永续债口径），全国能繁母猪3,780万头+卓创7月样本-1.48%使2027年反转确定性上升。本模块选择适配估值方法，通过全变量审计矩阵给出目标市值和股价。

---

## 一、价值锚定：适配性估值方法选择

牧原股份是典型的**强周期+重资产+龙头地位**企业，当前处于猪周期底部（2026E大概率亏损），传统PE估值法完全失效。根据其商业模式特征，选择以下三种方法交叉验证：

| 估值方法 | 适用理由 | 权重 |
|:---|:---|:---|
| **PB-ROE**（主力方法） | 重资产公司（固定资产>1000亿），净资产是利润的载体。当前PB 2.81倍（基于H1实际BVPS 13.89元），较8月上半月的2.63倍被动抬升 | 40% |
| **头均市值**（行业通行） | 生猪养殖行业特有估值范式，按每头出栏生猪赋予市值来定价猪企 | 35% |
| **PB绝对估值**（底线锚） | 在盈利为负时提供底线锚，评估资产安全垫厚度 | 25% |

> **为什么不用PE？** 2026E EPS为负值，猪周期底部年份PE剧烈跳变（2023年负值→2024年20-25x→2025年8-13x），纯PE法会产生严重误导。
> **为什么不用DCF？** 猪周期利润波动极大，自由现金流极不稳定，DCF对终值假设过度敏感。

当前为Q2，根据框架规则锚定2026年。但因2026E EPS为负，主力采用PB-ROE和头均市值。

## 二、基准市值测算

### 2.1 方法一：PB-ROE模型

公允PB = (ROE - g) / (COE - g)

| 参数 | 取值 | 依据 |
|:---|:---|:---|
| 周期平均ROE | **18%** | 2019-2025年剔除2020（74.43%）和2023（-6.38%）极端值后均值约18% |
| 权益资本成本(COE) | **9.5%** | Rf 1.7%（10年期国债）+ ERP 6.0% × Beta 1.3 |
| 永续增长率(g) | **3.0%** | 猪肉消费稳中有降，但牧原可通过份额提升+屠宰+海外维持低个位数增长 |
| 2026E BVPS | **~13.90元** | 2026H1半年报实际归母净资产801.87亿/57.73亿股=13.89元（含永续债口径）；全年若Base亏损约20亿，年末BVPS约13.3-13.5元，取13.90为本模型保守基准 |

计算：公允PB = (18%-3%) / (9.5%-3%) = 15%/6.5% = **2.31倍**
PB-ROE基准市值 = 57.73亿股 × 13.90元 × 2.31 = **1,854亿元**

### 2.2 方法二：头均市值法

| 头均市值(元/头) | 出栏(万头) | 市值(亿) | 股价(元) | 场景 |
|:---|:---|:---|:---|:---|
| 2,500（历史底） | 7,600 | 1,900 | 32.9 | 亏损期底部锚 |
| **2,967（当前）** | **7,600** | **2,256** | **39.07** | **2026.8.21** |
| 3,000（保守） | 7,600 | 2,280 | 39.5 | 底部合理下沿 |
| **3,500（中性）** | **7,600** | **2,660** | **46.1** | **周期中部合理水平** |
| 4,500（乐观） | 8,000 | 3,600 | 62.4 | 周期上行期 |

头均市值基准区间：3,000-3,500元/头，对应2,280-2,660亿，中值**2,470亿**。当前头均市值约2,967元/头（市值2,255.51亿/7,600万头），位于底部合理下沿附近，较7月末的约2,950元/头基本持平（股价回落被头均摊薄吸收）。

### 2.3 方法三：PB绝对估值（底线锚）

| 情景 | PB | BVPS(元) | 股价(元) | 市值(亿) |
|:---|:---|:---|:---|:---|
| 当前（2026-08-21，含永续债口径） | 2.81 | 13.89 | 39.07 | 2,256 |
| 2026E年末估算（Base全年亏约20亿，披露口径） | ~2.9 | ~13.4 | 39.07 | 2,256 |
| 历史5年低位 | 2.14 | 13.90 | 29.7 | 1,716 |
| 2023年亏损期最低 | ~2.70 | ~10.88 | 29.38 | 1,696 |
| 极端清算 | 1.55 | 13.90 | 21.5 | 1,245 |

> 注：当前PB采用含永续债口径（39.07/13.89=2.81，与系统估值视图8/21一致）；公司披露口径每股净资产为不含永续债口径。H1亏损+分红后BVPS从Q1的15.12元缩水至13.89元，PB被动抬升——周期底部净资产缩水效应需在估值中显性化。

### 2.4 基准市值综合

| 方法 | 基准市值(亿) | 股价(元) |
|:---|:---|:---|
| PB-ROE | 1,854 | 32.1 |
| 头均市值(中值) | 2,470 | 42.8 |
| PB绝对底线 | 1,716 | 29.7 |
| **综合基准**（40%×PB-ROE + 35%×头均市值 + 25%×PB绝对底线） | **2,010** | **34.8** |

当前股价39.07元（市值2,255.51亿，2026-08-21收盘），已高于综合基准市值约12.2%——**基准价值因H1净资产缩水（BVPS 15.12→13.89）下修，而股价仍在39元上方，赔率较8/5进一步压缩，市场对2027年反转的定价已相当激进**。

## 三、全变量对冲审计矩阵

### 3.1 E vs PE 边界划分

| 因素 | 进入E or PE？ |
|:---|:---|
| H2猪价每+1元/kg约增利34亿 | E（可计算） |
| 成本降至11.35-11.45元（H2）对应利润贡献约9-13亿 | E（可计算） |
| 二季度末能繁母猪3780万头 | E（提高2027供给收缩确定性） |
| 育种自主→10年后仍有成本优势 | PE（关乎长期确定性） |
| AI养猪领先→远期竞争力 | PE（关乎护城河宽度） |
| 政策结构红利（环保/碳交易） | PE（降低系统性风险） |
| 零地缘风险 | PE（折价消除） |
| H1经营现金流转负+负债率回升+短债化 | PE（财务结构折价-2%） |
| AI牛市致周期股失宠 | PE（暂时性，不纳入永久调整） |

### 3.2 审计矩阵

**公式**：修正目标市值 = 基准市值 × (1 + 调节幅度总和)
**基准市值**：2,010亿元（34.8元/股）

| 审计维度 | 核心审计因子 | 审慎思考 | 调节 | 深度理由 |
|:---|:---|:---|:---:|:---|
| **内部-DNA** | **成本护城河持久性**：全链一体化带来的结构性成本优势（7月完全成本11.5元/kg，vs温氏约12+元/kg，vs行业平均更高） | 成本优势通常是阶段性的，但牧原的成本优势源于不可复制的商业模式结构，且2026年7月已兑现11.5元/kg全年目标、优秀场线<10.5——这是能改变估值中枢的稀缺特质 | **+5%** | 持久性成本优势降低了远期利润不确定性，PE应获确定性溢价 |
| | **技术自主与AI赋能**：育种自主（育种中心2026年投产）+天网工程+与阿里云共建养猪大模型 | 技术投入本身不创造溢价，但牧原AI技术正处于投入期→产出期节点（头均降本600元已实现过半），未来3-5年红利确定性高 | **+3%** | 技术代差赋予轻度成长性溢价 |
| | **管理层战略定力与资本市场稳定动作**：H股3-5亿港元回购方案、董事高管5亿元A股增持完成（7/17）、AAAsti主体信用评级、8/18发行10亿1.7%短融 | 回购和增持是信心信号，低息融资说明信用资质仍强（主体评级升AAA）；但这些不能替代盈利修复，不能给过高永久溢价 | **+1%** | 对流动性和市场信心有边际支撑 |
| **宏观-政策** | **结构性政策**：能繁母猪目标下调至3750万头且二季度末已是3,780万头（回到绿色区间）、卓创7月样本环比-1.48%、环保趋严+CCER碳交易持续利好龙头 | 能繁去化会进入E端，不应重复给PE；但政策执行力提升降低了"反转一再延后"的不确定性 | **+4%** | 政策可信度上升，远期盈利折现率下降 |
| **宏观-地缘** | **纯内需+零海外资产**（海外营收占比0.07%，越南为技术输出模式） | 在一个地缘动荡的世界中，零地缘风险是稀缺的确定性优势 | **+2%** | 确定性本身就值钱，这是相对于其他A股的确定性补偿 |
| **财务-结构** | **H1经营现金流转负（-22.24亿）+短债化（短贷472.52亿）+负债率回升至54.18%** | 现金流恶化已计入E端（盈利和BVPS下修），不应重复计入PE；但资产负债率从Q1的50.73%回升3.45pct至54.18%、融资依赖短债，财务结构稳健性较Q1削弱——属于真实的估值折价因子 | **-2%** | 周期底部现金创造力下降+融资结构短期化，中期财务安全垫较Q1低点收窄 |
| **市场-风格** | **AI牛市致周期股失宠** | 市场风格是暂时的，会在猪周期反转时轮动。不应纳入永久调整 | **0%** | 风格折价是逆向投资者的机会 |
| **综合调节** | — | — | **+13%** | — |

### 3.3 修正目标市值

**修正目标市值 = 2,010 × 1.13 = 2,271亿元**
**修正目标股价 = 2,271 / 57.73 = 39.3元/股**

| 估值锚 | 市值(亿) | 股价(元) | 相对当前空间 |
|:---|:---|:---|:---|
| 基准（未调节） | 2,010 | 34.8 | -10.9% |
| **修正目标** | **2,271** | **39.3** | **+0.6%** |

> 本次较8/5模型新增-2%财务结构折价（经营现金流转负+短债化），调节幅度从+15%降至+13%；叠加基准市值从2,104亿下修至2,010亿（净资产缩水），修正目标市值从2,420亿降至2,271亿、目标股价从41.9元降至39.3元。**核心含义：半年报落地后，当前股价对应的已不是"修复初期溢价"，而是周期反转的"提前定价"，上行空间几乎耗尽。**

## 五、三态目标价与盈亏比

| 情景 | 概率 | 目标股价(元) | 逻辑 |
|:---|:---|:---|:---|
| **Bear** | 25% | **27.5** | 2026深亏约80亿→BV缩水→PB压缩至2.0倍 |
| **Base** | 50% | **39.3** | 修正目标市值（审计矩阵产出） |
| **Bull** | 25% | **55.0** | 2027猪价反转→EPS 5.72→约9.6倍PE（原58.0元基于EPS 5.72×10.1x，因2026亏损使反转兑现时间窗口延后，倍数小幅下调） |

**概率加权目标价** = 27.5×0.25 + 39.3×0.50 + 55.0×0.25 = **40.3元/股**

**盈亏比**（当前39.07元，2026-08-21收盘）：
(40.3 - 39.07) / (39.07 - 27.5) = 1.23 / 11.57 = **0.11**

盈亏比从7月末0.30进一步压缩至0.11，核心原因：①半年报落地后净资产缩水（BVPS 15.12→13.89元）压低下行锚与基准价值；②8月猪价站上11元使股价维持39元上方；③经营现金流转负+负债率回升触发-2%财务结构折价。**当前价位赔率几乎归零**——上行仅剩+3%左右（Base），下行却达-29.6%（Bear），新增仓位应等待回落至35-37元或后续月度简报确认销售均价站上11.5元/kg。

## 六、黑天鹅情景与极限压力测试

### 6.1 一击毙命事件：非洲猪瘟新变异株大规模爆发

**定义**：一种致死率>50%、传染性极强的非洲猪瘟新变异株在中国爆发，牧原在某核心养殖大省（如河南）的猪群大面积感染，被迫扑杀数百万头生猪。

**极限情景推演**：
- 扑杀200万头存栏 → 直接损失约40亿元（200万头×2,000元/头重置成本）
- 恐慌性抛售 → 短期猪价暴跌至5元/kg以下
- 消费者恐慌 → 猪肉消费短期断崖式下跌30-50%
- 全年出栏从7,600万头降至5,500万头以下
- 全年亏损扩大至**250-300亿元**（包含扑杀+跌价+减值）
- BVPS从13.89元降至~9-10元
- 股价可能跌至**14-16元**（PB 1.5-1.6倍，在恐慌中PB可低至1倍以下）

**但需注意**：
1. ASF后牧原已投入大量资源构建防疫体系（空气过滤猪舍全覆盖），相比2018年已大幅提升
2. 大企业防疫能力远强于散户（牧原的生物安全等级行业最高），若新疫情爆发反而加速散户退出+加速猪价反转
3. 政府将采取更激进的收储+补贴措施
4. 牧原历史上应对过多次疫情（2023年冬季非瘟考验），具备成熟的应急预案

### 6.2 极限支撑位：地狱价格

**情景**：恐慌性抛售叠加流动性危机，市场给予重资产清算估值
- 账面净资产打7折（考虑存货贬值+生物资产减值）：BVPS ≈ 9.7元（H1实际13.89×0.7）
- 市场极端恐慌下PB压缩至1.5倍
- **地狱价格 ≈ 14.6元/股**（较当前-62.6%，市值约843亿）

但这一情景**概率极低**（<5%），因为：
1. 公司货币资金165.47亿（受限29.17亿）+AAAsti信用+8/18发行10亿1.7%短融，流动性充裕
2. 即使全年亏损100亿，净资产仍超700亿
3. 政府收储+产能调控会托底猪价
4. 牧原的产业地位决定了其too big to fail

## 七、估值定价结论

| 定价锚点 | 市值(亿) | 股价(元，不复权) |
|:---|:---|:---|
| 极限地狱价 | ~843 | ~14.6 |
| 保守情景 | 1,588 | 27.5 |
| 当前市价 | 2,255.5 | 39.07 |
| **概率加权目标价** | **2,327** | **40.3** |
| Base目标价 | 2,271 | 39.3 |
| Bull目标价 | 3,175 | 55.0 |

**核心判断**：当前股价39.07元（2026-08-21收盘）处于**"反转提前定价"状态**——基准价值约34.8元（因H1净资产缩水下修），经全变量审计矩阵（新增财务结构折价-2%后调节+13%）修正后公允值约39.3元（+0.6%），概率加权目标价40.3元（+3.1%）。**半年报落地的"好消息出尽"效应叠加净资产缩水，使当前价位的赔率几乎归零（盈亏比0.11）**。真正的超额收益空间仍来自Bull情景（55.0元，+40.8%），触发条件是猪周期在2027Q1如期反转且幅度超预期；当前39元上方区间不应追高，35-37元回调区间（或9月销售简报确认均价站上11.5元/kg）才是重新考虑加仓的位置。
