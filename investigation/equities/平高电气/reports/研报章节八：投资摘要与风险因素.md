## 一、投资摘要

### 1.1 投资逻辑（核心叙事）

平高电气是**中国特高压GIS（气体绝缘开关设备）领域的绝对龙头**，在1000kV GIS交流市场占有25-30%份额（行业第一）、直流市场占有45-50%份额（半壁江山）。公司正处于由"十五五"全国电网5万亿+投资（较十四五增长超80%）驱动的**新一轮景气扩张周期起点**——2026年国网特高压单批次1000kV GIS招标量（93间隔）已超过2024-2025年总和，公司在手订单126亿元（其中高压板块113亿元）锁定了未来1.5年的营收确定性。

**投资逻辑链**：十五五电网投资加码80%+（全国5万亿+）→年均特高压核准5-7条→GIS招标量翻倍→平高电气市场份额稳固（特高压中标第一）→营收和利润双重增长→估值修复至合理中枢。

### 1.3 核心增长驱动力

1. **订单爆发的确定性与H2交付弹性**（置信度：极高→极高）：2026H1合同负债21.71亿（+25.5%）、存货24.79亿（+40.5%）双高增，H1中标64.6亿已转化为合同负债；但H1营收53.74亿（-5.64%）仅完成全年预测143.5亿的37.4%，H2需完成89-92亿（同比+29-34%）追赶，交付压力与弹性并存。
2. **十五五电网投资的政策刚需（双规划确认）**（置信度：极高）：2026.6.26《新型能源体系十五五规划》+2026.08.03《新型电力系统十五五规划》（发改能源〔2026〕942号，5万亿+、15回直流、西电东送超4.2亿千瓦）双确认，政策确定性进一步强化。2026年上半年国网投资3027亿（+4.0%）/3100亿（+12.6%）、特高压前三批292.61亿超2025全年（220.62亿）、陕豫±800kV直流获核准（192亿），行业景气从政策预期走向实物兑现。
3. **毛利率超预期兑现**（置信度：中→高）：2026H1毛利率29.75%（Q2 30.03%）大超25-26%目标（+4.75ppt），较2025全年23.92%提升5.83ppt，输配电设备毛利率约30.13%验证成本传导有效，铜价高位（沪铜10.6万、LME 14,117美元/吨）已被产品结构优化对冲。
4. **技术护城河的稳固性**（置信度：极高）：800kV/80kA已工程应用+550kV GIL通过错断试验+平芝1100kV GIS通过型式试验，至少2030年前无第六家特高压GIS供应商。思源电气在1000kV GIS领域仍未进入（仅变压器三期产能）。
5. **外资逆向增持但浮亏扩大**（置信度：高→中）：Templeton 7月13日举牌5.42%（加权成本约20元上方），现价19.29元浮亏约3.5%（07-31时1.4%），短期无增持，验证效果边际减弱。
6. **历史估值分位（回调后改善）**（置信度：中）：当前PE TTM 20.58倍（约45%分位）较07-31的22.75倍/54%分位回落，PB 2.21倍仍高于2021年以来中位1.73但已回落（视图2026-08-20实测中位1.73），回调后吸引力回升。

## 二、风险因素（按对股价影响烈度排序）

### 🔴 高危风险

**R1. 特高压建设进度不及预期**

- **烈度**：★★★★★（可能触发营收负增长，目标价下调至15元以下）
- **描述**：特高压项目的核准、开工、设备招标、收入确认周期长（6-18个月），任何一个环节的延迟都将直接影响公司的营收确认。2025年"三交九直"核准延迟已导致公司全年营收仅增0.93%。若2026年再度出现大规模延迟，EPS可能降至0.80元以下。
- **触发条件**：国网/发改委特高压核准进度持续低于预期；在施项目出现重大技术问题。
- **应对**：关注国网每月特高压设备招标公告和季度项目进度报告。

**R2. 铜价持续上涨侵蚀利润**

- **烈度**：★★★★☆（可能压缩毛利率2-4ppt，EPS减少2-3亿）
- **描述**：铜价从2025年初7万元/吨飙升至2026年中的10万元+/吨（+50%），铜占公司产品营业成本约15-20%。若铜价维持当前高位或进一步上行，2026年毛利率可能被压缩至22%以下。
- **触发条件**：LME铜价持续高于13000美元/吨；国内铜加工费TC进一步恶化。
- **应对**：跟踪LME铜价、SHFE铜期货、公司套保比例及铜铝替代进展。

**R3. 竞争格局恶化（思源电气追赶）**

- **烈度**：★★★☆☆（影响中长期份额和毛利率）
- **描述**：思源电气在常规GIS市场份额领先（2026年首批GIS中标8.74亿元占比30.1%，超越平高），750kV GIS快速追赶。但在特高压1000kV GIS领域，思源2026年第二次特高压招标中仅中标常规组合电器（排名第15），仍未进入1000kV核心品类。平高在最高端市场的份额短期内稳固。
- **触发条件**：思源电气1000kV GIS通过型式试验并取得首单业绩。
- **应对**：关注思源电气的特高压技术研发进展和国网认证状态。

### 🟡 中危风险

**R4. 经营现金流持续恶化（已触发观察）**

- **烈度**：★★★★☆（由中危上调至高危，限制分红和估值倍数）
- **描述**：2025年经营CF 8.11亿（-73.05%）→2026H1 -6.89亿（同比-60.5%，OCF/净利润-0.84×跌破0.5×红线），连续两年恶化且H1缺口扩大至-6.89亿，定性已从"一次性主动支付"转为**支付策略常态化/结构性承压**。若全年无法转正至10亿以上，将实质削弱分红（拟10派2.42元约3.28亿）与估值倍数（治理折价-3%）。
- **触发条件**：2026H1经营CF仍为负值或低于5亿（**已触发，-6.89亿**），Q3是否转正为关键验证。

**R5. 国际业务持续失血**

- **烈度**：★★☆☆☆（影响有限但消耗管理资源）
- **描述**：国际业务毛利率-24.39%，2025年亏损约0.63亿元。若单机出口转型不及预期，亏损可能扩大。
- **触发条件**：2026H1国际业务仍亏损超过0.5亿元。

**R6. 配网集采价格战**

- **烈度**：★★☆☆☆（配网仅占营收26%，但持续降价将拖累整体利润）
- **描述**：国网配网集采竞争激烈，价格战已出现（2025年第一批降价）。若2026年价格无法有效回升，配网板块毛利率可能进一步跌至14-15%。
- **触发条件**：国网配电物资第二批招标价格低于第一批。

### 🟢 低危风险

**R7. 宏观经济大幅下行**

- **烈度**：★★☆☆☆（电网投资具有逆周期属性）
- **描述**：电网投资历来具备"托底经济"的功能，历史上经济下行期往往反而加大投资。且公司客户（国网）信用等级极高（等同于主权信用），经济下行期的回款风险低。

**R8. 环保政策风险（SF6替代加速）**

- **烈度**：★☆☆☆☆（长期机会大于威胁）
- **描述**：全球推进SF6替代，公司已提前布局C4环保GIL和真空GIS，环保政策趋严反而将加速淘汰中小竞争对手。

## 三、研究结论象限图

基于"确定性"与"预期收益空间"两个维度，对平高电气进行最终定位：

```
                    高确定性
                        ▲
                        |
        ┌───────────────┼───────────────┐
        │               │               │
        │  第三象限      │  ★ 第一象限   │
        │  Defensive     │  High-Conv    │
        │  Value         │  Buy          │
        │               │               │
低收益 ◄────────────────┼────────────────► 高收益
        │               │               │
        │  第四象限      │  第二象限      │
        │  Avoid/Wait    │  Speculative  │
        │               │  Growth       │
        │               │               │
        └───────────────┼───────────────┘
                        │
                        ▼
                    低确定性
```

**最终定位：第一象限偏边界（High-Conviction Buy 边界）——高确定性、回调后赔率回升，持有/分批加仓**

- **确定性**：高（政策双确认+订单饱满+技术壁垒+毛利率超预期），确定性评分3.4/5（较原3.5微降，现金流与营收增速对冲）。
- **预期收益空间**：中高（12个月概率加权目标价24.21元，+25.5%；Base目标价24.2元+25.5%，框架口径盈亏比1.17），较07-31的0.96回升0.18——8月19-20日回调（19.72→19.29）使赔率从"中性"回到"可加仓"区间。

**定位理由（2026H1更新）**：
- 平高电气2026H1呈现"增利不增收"（营收-5.64% vs净利+22.87%/毛利率30%），第一象限定位维持但内部发生分化：**盈利维度超预期（净利超7.8亿上限、毛利率+5ppt）强化确定性，营收与现金流维度不及预期（-5.64%/-0.84×）增加不确定性**，综合确定性3.4/5微降。
- 估值从07-31的合理中枢（PE TTM 22.75倍/54%分位）回调至偏低（20.58倍/45%分位），目标价24.2元（微降0.2元）对应+25.5%上行，盈亏比1.17倍（>1）重回可加仓区间（算术修正），回调提供买点。
- 7月22日中标64.6亿+特高压前三批292.61亿超2025全年+陕豫直流获核准+双规划确认，行业景气度已从政策预期走向实物兑现，但平高H1增速跑输思源/西电提示份额压力，需Q3修复。
- **核心建议（更新）**：19.29元回调后可分批加仓，第一买点18.87-18.96元（MA60/250共振带），第二买点18.00-18.60元；收复19.87元（MA20）后加仓，放量站稳20.23元（MA120）3日确认二次上攻至24.2元。止损设在有效跌破18.60元（共振带失守）。属于核心-卫星策略中的"核心仓位"类型，单票配置不超过组合15%，Q3交付与现金流转正为最核心风控验证。
