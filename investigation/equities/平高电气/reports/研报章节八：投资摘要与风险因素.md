## 一、投资摘要

### 1.1 投资逻辑（核心叙事）

平高电气是**中国特高压GIS（气体绝缘开关设备）领域的绝对龙头**，在1000kV GIS交流市场占有25-30%份额（行业第一）、直流市场占有45-50%份额（半壁江山）。公司正处于由"十五五"全国电网5万亿+投资（较十四五增长超80%）驱动的**新一轮景气扩张周期起点**——2026年国网特高压单批次1000kV GIS招标量（93间隔）已超过2024-2025年总和，公司在手订单126亿元（其中高压板块113亿元）锁定了未来1.5年的营收确定性。

**投资逻辑链**：十五五电网投资加码80%+（全国5万亿+）→年均特高压核准5-7条→GIS招标量翻倍→平高电气市场份额稳固（特高压中标第一）→营收和利润双重增长→估值修复至合理中枢。

### 1.3 核心增长驱动力

1. **订单爆发的确定性**（置信度：极高）：2026年累计中标64.60亿元（已公告4次，最新一批为7月22日公告的18.18亿元，含特高压第三次设备招标7.5亿元），占2025年营收约51.6%。合同负债18.24亿（Q1末），Q（销量）增长看得见摸得着。
2. **十五五电网投资的政策刚需**（置信度：极高）：2026.6.26国务院批复《新型能源体系建设"十五五"规划》，全国电网固投5万亿+（较十四五增长超80%），十五五投产15项特高压直流，西电东送规模超4.2亿千瓦，2030年非化石能源发电量占比目标50%。**2026年上半年国网固定资产投资已超3100亿元（+12.6%），特高压年内前三批招标累计292.61亿元已超2025年全年（220.62亿元）**，政策确定性与执行节奏双双验证。
3. **毛利率修复的持续性**（置信度：中）：Q1毛利率29.42%，产品结构向高毛利特高压倾斜，铜价维持高位（沪铜~10.47万/吨，TC深度负值-141.6美元/干吨）是主要不确定性因素。
4. **技术护城河的稳固性**（置信度：极高）：800kV/80kA世界纪录断路器+核电GIS市占率>50%，至少2030年前无实质意义的第六家特高压GIS供应商。思源电气在1000kV GIS领域仍未进入（其扩产集中于1000kV变压器产能，常州三期已于6月签约）。
5. **外资逆向增持事实**（置信度：高）：Templeton（富兰克林邓普顿）7月13日举牌持股5.42%。据权益变动报告书，其4月以来买入区间17.32-22.20元、加权成本约20元上方，现价19.72元仍低于其成本——外资在股价下跌过程中持续逆向建仓，但当前仍处浮亏，属"逆向增持"而非"确认后追涨"。
6. **历史估值分位**（置信度：中）：当前PE TTM 22.75倍已回升至2024年以来中位数（22.43倍）附近（约54%分位），PB 2.29倍高于2021年以来中位数（1.65倍）——"显著低估"状态已修复为"合理中枢"，PB维度甚至提示偏贵。

## 二、风险因素（按对股价影响烈度排序）

### 🔴 高危风险

**R1. 特高压建设进度不及预期**

- **烈度**：★★★★★（可能触发营收负增长，目标价下调至15元以下）
- **描述**：特高压项目的核准、开工、设备招标、收入确认周期长（6-18个月），任何一个环节的延迟都将直接影响公司的营收确认。2025年"三交九直"核准延迟已导致公司全年营收仅增0.93%。若2026年再度出现大规模延迟，EPS可能降至0.80元以下。
- **触发条件**：国网/发改委特高压核准进度持续低于预期；在施项目出现重大技术问题。
- **应对**：关注国网每月特高压设备招标公告和季度项目进度报告。

**R2. 铜价持续上涨侵蚀利润**

- **烈度**：★★★★☆（可能压缩毛利率2-4ppt，EPS减少2-3亿）
- **描述**：铜价从2025年初7万元/吨飙升至2026年中的10万元+/吨（+50%），铜占公司产品营业成本约15-20%。若铜价维持当前高位或进一步上行，2026年毛利率可能被压缩至22%以下。
- **触发条件**：LME铜价持续高于13000美元/吨；国内铜加工费TC进一步恶化。
- **应对**：跟踪LME铜价、SHFE铜期货、公司套保比例及铜铝替代进展。

**R3. 竞争格局恶化（思源电气追赶）**

- **烈度**：★★★☆☆（影响中长期份额和毛利率）
- **描述**：思源电气在常规GIS市场份额领先（2026年首批GIS中标8.74亿元占比30.1%，超越平高），750kV GIS快速追赶。但在特高压1000kV GIS领域，思源2026年第二次特高压招标中仅中标常规组合电器（排名第15），仍未进入1000kV核心品类。平高在最高端市场的份额短期内稳固。
- **触发条件**：思源电气1000kV GIS通过型式试验并取得首单业绩。
- **应对**：关注思源电气的特高压技术研发进展和国网认证状态。

### 🟡 中危风险

**R4. 经营现金流持续恶化**

- **烈度**：★★★☆☆（限制分红和估值倍数）
- **描述**：2025年经营CF从30亿骤降至8.1亿（-73.05%），公司解释为缩短付款周期的一次性调整。若2026年经营CF无法恢复至15亿以上，将表明这不是"策略性"而是"结构性"现金流恶化，会削弱公司价值。
- **触发条件**：2026H1经营CF仍为负值或低于5亿。

**R5. 国际业务持续失血**

- **烈度**：★★☆☆☆（影响有限但消耗管理资源）
- **描述**：国际业务毛利率-24.39%，2025年亏损约0.63亿元。若单机出口转型不及预期，亏损可能扩大。
- **触发条件**：2026H1国际业务仍亏损超过0.5亿元。

**R6. 配网集采价格战**

- **烈度**：★★☆☆☆（配网仅占营收26%，但持续降价将拖累整体利润）
- **描述**：国网配网集采竞争激烈，价格战已出现（2025年第一批降价）。若2026年价格无法有效回升，配网板块毛利率可能进一步跌至14-15%。
- **触发条件**：国网配电物资第二批招标价格低于第一批。

### 🟢 低危风险

**R7. 宏观经济大幅下行**

- **烈度**：★★☆☆☆（电网投资具有逆周期属性）
- **描述**：电网投资历来具备"托底经济"的功能，历史上经济下行期往往反而加大投资。且公司客户（国网）信用等级极高（等同于主权信用），经济下行期的回款风险低。

**R8. 环保政策风险（SF6替代加速）**

- **烈度**：★☆☆☆☆（长期机会大于威胁）
- **描述**：全球推进SF6替代，公司已提前布局C4环保GIL和真空GIS，环保政策趋严反而将加速淘汰中小竞争对手。

## 三、研究结论象限图

基于"确定性"与"预期收益空间"两个维度，对平高电气进行最终定位：

```
                    高确定性
                        ▲
                        |
        ┌───────────────┼───────────────┐
        │               │               │
        │  第三象限      │  ★ 第一象限   │
        │  Defensive     │  High-Conv    │
        │  Value         │  Buy          │
        │               │               │
低收益 ◄────────────────┼────────────────► 高收益
        │               │               │
        │  第四象限      │  第二象限      │
        │  Avoid/Wait    │  Speculative  │
        │               │  Growth       │
        │               │               │
        └───────────────┼───────────────┘
                        │
                        ▼
                    低确定性
```

**最终定位：第一象限偏边界（High-Conviction Buy 边界）——高确定性、赔率中性，持有观察**

- **确定性**：高（政策锁定+订单锁定+技术壁垒+外资逆向增持=四重确定），确定性评分3.5/5维持。
- **预期收益空间**：中（12个月概率加权目标价24.14元，+22.4%；Base目标价+23.7%，框架口径盈亏比0.96），较7月17日锚点（加权口径盈亏比1.96）明显收窄——股价两周内上涨8.65%兑现了大部分修复空间，当前价位期望收益与下行风险大致对称。

**定位理由**：
- 平高电气是"高确定性、中等弹性"的投资标的，7月下旬股价从18.15元反弹至19.72元后，估值已从"显著低估"修复至"合理中枢"（PE TTM 22.75倍vs历史中位数22.43倍、PB 2.29倍vs中位数1.65倍），第一象限定位维持但已处边界——0.96倍的框架口径盈亏比（<1）意味着当前价位不再是"核心重仓"的理想买点，而是"确定性资产的持有观察"状态。
- +22.4%的概率加权预期收益仍高于无风险利率（约2.5%）约20个百分点，具备持有价值；但新增买入需等待更好价格或右侧突破确认。
- 7月22日第三批中标18.18亿元（累计64.60亿元）+国网上半年投资3100亿元（+12.6%）+特高压年内前三批招标292.61亿元超2025全年，行业景气度从政策预期走向业绩兑现的路径已验证。
- **核心建议**：19.72元现价维持持有，不加仓不急于卖出；19.0-19.2元（MA60附近）与17.6-18.6元（MA250/回踩低点区间）为新增仓位参考区；8月下旬半年报若验证H1净利≥7亿元且毛利率≥25%，放量突破MA120（20.15元）后可加仓（届时盈亏比将修复至1以上）。止损设在有效跌破18.63元（7月24日回踩低点）。重仓配置不宜超过组合的15%，属于**核心-卫星策略中的"核心仓位"类型**。
