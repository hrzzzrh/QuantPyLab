## 一、投资摘要

### 1.1 投资逻辑（核心叙事）

平高电气是**中国特高压GIS（气体绝缘开关设备）领域的绝对龙头**，在1000kV GIS交流市场占有25-30%份额（行业第一）、直流市场占有45-50%份额（半壁江山）。公司正处于由"十五五"全国电网5万亿+投资（较十四五增长超80%）驱动的**新一轮景气扩张周期起点**——2026年国网特高压单批次1000kV GIS招标量（93间隔）已超过2024-2025年总和，公司在手订单126亿元（其中高压板块113亿元）锁定了未来1.5年的营收确定性。

**投资逻辑链**：十五五电网投资加码80%+（全国5万亿+）→年均特高压核准5-7条→GIS招标量翻倍→平高电气市场份额稳固（特高压中标第一）→营收和利润双重增长→估值修复至合理中枢。

### 1.3 核心增长驱动力

1. **订单爆发的确定性与H2交付弹性**（置信度：极高→极高）：2026H1合同负债21.71亿（+25.5%）、存货24.79亿（+40.5%）双高增，**9月8日新增中标9.36亿（累计73.96亿，占2025营收59.1%）**验证H2订单饱满；但H1营收53.74亿（-5.64%）仅完成全年预测143.5亿的37.4%，H2需完成89-92亿（同比+29-34%）追赶，交付压力与弹性并存。
2. **十五五电网投资的政策刚需（双规划确认）**（置信度：极高）：2026.6.26《新型能源体系十五五规划》+2026.08.03《新型电力系统十五五规划》（发改能源〔2026〕942号，5万亿+、15回直流、西电东送超4.2亿千瓦）双确认，政策确定性进一步强化。**9月4日国网第四次变电设备候选人公示（约174亿/383家）+9月8日中标9.36亿**双验证招标放量，陕北-安徽工程6/30投运等实物兑现加速。
3. **毛利率超预期兑现**（置信度：中→高）：2026H1毛利率29.75%（Q2 30.03%）大超25-26%目标（+4.75ppt），较2025全年23.92%提升5.83ppt，输配电设备毛利率约30.13%验证成本传导有效；但**9月9日LME 14728/沪铜110580创历史新高后9月中旬高位震荡（LME 14400/沪铜109570），成本压力延续但未再新高**需Q3验证传导持续性，铜铝复合替代与套保为对冲手段。
4. **技术护城河的稳固性**（置信度：极高）：800kV/80kA已工程应用+550kV GIL通过错断试验+平芝1100kV GIS通过型式试验（8/27说明会重申），至少2030年前无第六家特高压GIS供应商。思源电气在1000kV GIS领域仍未进入（仅变压器三期产能）。
5. **会计估计变更的"报表-经营"分拆（新增·置信度：高）**：2026H1因关联方迁徙率模型新增计提8110.74万（税后7453.55万，8/20公告/8/27说明会双源核验），报表归母8.17亿（+22.87%）vs还原8.92亿（+34.1%），非实际坏账、可随回款转回。后续关注点转为关联方余额波动对报表利润的"会计噪音"，不影响现金流与经营趋势判断。
6. **外资逆向增持但浮亏小幅扩大**（置信度：高→中）：Templeton 7月13日举牌5.42%（加权成本约20元上方），现价19.49元浮亏约2.6%（09-08时1.9%），缩量整固期浮亏扩大0.7pct，安全边际微降。
7. **历史估值分位（缩量回踩后微降）**（置信度：中）：当前PE TTM 20.79倍（约46%分位）较09-08的20.93倍/47%微降，PB 2.23倍仍高于2021年以来中位1.73（视图2026-09-18实测），仍处合理偏低。

## 二、风险因素（按对股价影响烈度排序）

### 🔴 高危风险

**R1. 特高压建设进度不及预期**

- **烈度**：★★★★★（可能触发营收负增长，目标价下调至15元以下）
- **描述**：特高压项目的核准、开工、设备招标、收入确认周期长（6-18个月），任何一个环节的延迟都将直接影响公司的营收确认。2025年"三交九直"核准延迟已导致公司全年营收仅增0.93%。若2026年再度出现大规模延迟，EPS可能降至0.80元以下。
- **触发条件**：国网/发改委特高压核准进度持续低于预期；在施项目出现重大技术问题。
- **应对**：关注国网每月特高压设备招标公告和季度项目进度报告。

**R2. 铜价持续上涨侵蚀利润**

- **烈度**：★★★★☆（可能压缩毛利率2-4ppt，EPS减少2-3亿）
- **描述**：铜价从2025年初7万元/吨飙升至2026年中的10万元+/吨（+50%），铜占公司产品营业成本约15-20%。若铜价维持当前高位或进一步上行，2026年毛利率可能被压缩至22%以下。
- **触发条件**：LME铜价持续高于13000美元/吨；国内铜加工费TC进一步恶化。
- **应对**：跟踪LME铜价、SHFE铜期货、公司套保比例及铜铝替代进展。

**R3. 竞争格局恶化（思源电气追赶）**

- **烈度**：★★★☆☆（影响中长期份额和毛利率）
- **描述**：思源电气在常规GIS市场份额领先（2026年首批GIS中标8.74亿元占比30.1%，超越平高），750kV GIS快速追赶。但在特高压1000kV GIS领域，思源2026年第二次特高压招标中仅中标常规组合电器（排名第15），仍未进入1000kV核心品类。平高在最高端市场的份额短期内稳固。
- **触发条件**：思源电气1000kV GIS通过型式试验并取得首单业绩。
- **应对**：关注思源电气的特高压技术研发进展和国网认证状态。

### 🟡 中危风险

**R4. 经营现金流持续恶化（已触发观察）+ 关联方坏账会计噪音（新增）**

- **烈度**：★★★★☆（由中危上调至高危，限制分红和估值倍数；新增会计噪音为中等但需分拆）
- **描述**：2025年经营CF 8.11亿（-73.05%）→2026H1 -6.89亿（同比-60.5%，OCF/净利润-0.84×跌破0.5×红线），连续两年恶化且H1缺口扩大至-6.89亿，定性已从"一次性主动支付"转为**支付策略常态化/结构性承压**。若全年无法转正至10亿以上，将实质削弱分红（拟10派2.42元约3.28亿）与估值倍数（治理折价-3%）。**新增：2026H1关联方迁徙率新增计提8110.74万（税后7453万，不影响现金流），报表利润8.17亿还原后8.92亿；后续随关联方余额动态波动，若H2未回款可能再增0.3-0.5亿报表减值，若回款则可冲回，形成"会计噪音"**。
- **触发条件**：2026H1经营CF仍为负值或低于5亿（**已触发，-6.89亿**），Q3是否转正为关键验证；关联方余额及回款节奏为会计噪音观察项。

**R5. 国际业务持续失血**

- **烈度**：★★☆☆☆（影响有限但消耗管理资源）
- **描述**：国际业务毛利率-24.39%，2025年亏损约0.63亿元。若单机出口转型不及预期，亏损可能扩大。
- **触发条件**：2026H1国际业务仍亏损超过0.5亿元。

**R6. 配网集采价格战**

- **烈度**：★★☆☆☆（配网仅占营收26%，但持续降价将拖累整体利润）
- **描述**：国网配网集采竞争激烈，价格战已出现（2025年第一批降价）。若2026年价格无法有效回升，配网板块毛利率可能进一步跌至14-15%。
- **触发条件**：国网配电物资第二批招标价格低于第一批。

### 🟢 低危风险

**R7. 宏观经济大幅下行**

- **烈度**：★★☆☆☆（电网投资具有逆周期属性）
- **描述**：电网投资历来具备"托底经济"的功能，历史上经济下行期往往反而加大投资。且公司客户（国网）信用等级极高（等同于主权信用），经济下行期的回款风险低。

**R8. 环保政策风险（SF6替代加速）**

- **烈度**：★☆☆☆☆（长期机会大于威胁）
- **描述**：全球推进SF6替代，公司已提前布局C4环保GIL和真空GIS，环保政策趋严反而将加速淘汰中小竞争对手。

## 三、研究结论象限图

基于"确定性"与"预期收益空间"两个维度，对平高电气进行最终定位：

```
                    高确定性
                        ▲
                        |
        ┌───────────────┼───────────────┐
        │               │               │
        │  第三象限      │  ★ 第一象限   │
        │  Defensive     │  High-Conv    │
        │  Value         │  Buy          │
        │               │               │
低收益 ◄────────────────┼────────────────► 高收益
        │               │               │
        │  第四象限      │  第二象限      │
        │  Avoid/Wait    │  Speculative  │
        │               │  Growth       │
        │               │               │
        └───────────────┼───────────────┘
                        │
                        ▼
                    低确定性
```

**最终定位：第一象限偏边界（High-Conviction Buy 边界）——高确定性、赔率修复，持有/分批加仓**

- **确定性**：高（政策双确认+订单73.96亿饱满+技术壁垒+毛利率超预期+会计噪音可分拆），确定性评分3.4/5维持（新增会计噪音不降分，现金流与营收增速对冲；09-09~18无新增订单/招标兑现为边际增加的不确定性但不降分）。
- **预期收益空间**：中高（12个月概率加权目标价24.21元报表/24.90元还原，+24.2%/+27.8%；Base目标价24.2/24.9元，框架口径盈亏比1.08报表/1.23还原），较09-08的1.02/1.17小幅修复0.06——9月二度回踩19.62→19.49后赔率+0.06，缩量整固期赔率被动修复但非盈利上修驱动。

**定位理由（2026-09-22更新）**：
- 平高电气2026H1呈现"增利不增收"（营收-5.64% vs净利+22.87%报表/+34.1%还原/毛利率30%），第一象限定位维持但内部发生分化：**盈利维度超预期（还原后8.92亿+34.1%、毛利率+5ppt）强化确定性，营收与现金流维度不及预期（-5.64%/-0.84×）增加不确定性，新增8110万会计噪音需分拆观察**，综合确定性3.4/5维持。
- 估值从09-08的20.93倍/47%分位微降至20.79倍/46%分位，目标价24.2元报表（24.9元还原）对应+24.2%/+27.8%上行，盈亏比1.08倍报表（1.23倍还原）仍>1维持可加仓区间，二度回踩后安全边际小幅修复0.06但非盈利驱动。
- 9月8日累计73.96亿（+9.36亿）+特高压前三批292.61亿超2025全年+第四次候选人公示约174亿/383家+陕豫直流6/30投运+双规划确认，行业景气度从政策预期走向实物兑现，但H1增速跑输思源/西电提示份额压力，需Q3修复。
- **核心建议（09-22更新）**：19.49元处缩量整固期不追高，第一买点19.09-19.30元（MA60/250共振带，上移0.12-0.13元）企稳后分批加仓，第二买点18.00-18.60元；放量（>180k手）收复19.68/19.74元（MA20/120双阻力簇）3日确认二次上攻至24.2元。止损设在有效跌破19.09-19.30共振带或18.60元（共振带失守）。属于核心-卫星策略中的"核心仓位"类型，单票配置不超过组合15%，Q3交付（需89-92亿追赶）与现金流转正+第五/六批招标兑现为最核心风控验证，关联方回款节奏为会计噪音次要观察，二度回踩未破位前长期通道有效但缩量观望期不宜加杠杆。
