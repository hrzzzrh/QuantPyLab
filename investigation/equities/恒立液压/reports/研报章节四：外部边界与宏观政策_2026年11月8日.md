# 研报章节四：外部边界与宏观政策

**研究日期：2026年11月8日**
**标的：恒立液压（601100.SH）｜目标年份：2027年**

---

## 一、宏观环境变量审计

### 1.1 汇率：当前对公司损益表杀伤力最大的单一宏观变量

- **现状**：人民币兑美元中间价**6.7168（2026-11-06，较前一交易日调贬12个基点）**；11-05为6.7156、11-04为6.7180；在岸即期约6.6693、离岸约6.6669，**为2022年6月以来最强区间**。10月人民币中间价累计上调213个基点（6.7351→6.7138），在岸累计升值496个基点；年内人民币对美元升值约4.9%、对欧元升值约10%。**2026-11-03央行宣布自11月15日起将金融机构外汇存款准备金率由4%上调至6%**，为升值"踩刹车"，市场解读为"升值方向不变、斜率放缓"（中信证券）。
- **传导路径（已被三季报证实）**：公司海外收入占比约19%+美国收入2026年约8亿元，持有美元应收账款与美元资产。2026Q1-3财务费用+1.83亿元（上年同期-2.00亿元），其中汇兑损失约3.4-3.5亿元（上年为收益0.69亿元），被1.40亿元利息收入部分对冲；**同时，外汇掉期的公允价值变动收益为-2.53亿元（上年-1.00亿元）**——掉期在"投资收益"端贡献+2.27亿元赎回收益，却在"公允价值变动"端亏损2.53亿元，形成**双通道扰动**，使汇兑对冲的经济效果与会计呈现严重背离。9月末其他综合收益-1.09亿元（外币报表折算损失1.26亿元），确认折算敞口仍基本裸露。
- **前瞻判断**：人民币升值方向未逆转（即期6.67、央行仅"控速"），且2026年12月企业结汇需求集中释放可能推动阶段性走强。**盈利预测处理**：2026E中性情景财务费用2.4亿元（Q4按0.6亿元计提）、2027E中性2.8亿元（不假设回冲，较上期2.5亿元上调0.3亿元以反映即期汇率强于预期）；保守3.6亿元（即期升破6.6）、乐观1.9亿元（回贬至6.9以上）。**汇率仍是2027E方差最大的外生变量之一。**

### 1.2 利率与折现率

国内处于低利率环境。对估值的影响是双重的：①低折现率抬升长久期资产理论价值——这是市场给予恒立丝杠远期期权高估值的宏观温床；②低利率本身对应弱总需求，压制挖机新增需求的复苏高度。**新增变量：公司自身融资成本开始显性化**——Q3短期借款8.49亿元（年初0.14亿元）、2027-2029年债权融资计划≤50亿元，若利率上行50bp，按满额测算年利息支出增加约0.25亿元，对利润影响有限但方向为负。**分母端友好、分子端存疑的格局未变。**

### 1.3 原材料成本：2026年内最友好的区间

- **螺纹钢现货3,100.84元/吨（2026-11-05，较前一日+9.34元/吨）**，较10-15的3,318元/吨下跌6.5%、较8月低点仅高约100元；期货RB2701收3,038元/吨（11-06），上海HRB400E 20mm现货3,180元/吨；Mysteel定性"库存年内低位、供需压力加大、钢价难有趋势性行情"；
- 钢材占公司成本55.17%（2025年），钢价每降10%理论上改善毛利率2-3pct；**当前钢价已低于3400元/吨的"顺风逆转预警线"约9%，是Q4及2027年毛利率修复的第二顺风**；
- 风险：若"反内卷"政策推动供给收缩或钢厂复产不及预期，钢价存在均值回归可能；焦煤/焦炭价格偏弱（11-06焦炭+2.75%、焦煤+1.15%但现货提降预期升温），成本端暂无上行压力；
- 直接人工+制造费用合计占成本44.8%（2025年）且增速快（人工+41.5%），反映新基地投产初期的效率损耗——该部分随爬坡改善，Q3毛利率回升0.31pct是第一个实证。

## 二、地缘政治风险审计：从"规则重写"升级为"产品级贸易救济"

### 2.1 美国对线性液压缸的反倾销/反补贴调查（2026年新增，最高优先级）

| 节点 | 内容 | 时间 |
| :--- | :--- | :--- |
| 申请 | 美国液压缸公平贸易联盟（Hydraulic Cylinders Fair Trade Coalition）及9家本土生产商提交AD/CVD申请 | 2026-07-29 |
| 立案 | 美国商务部对**中国、印度、墨西哥**发起反补贴（CVD）调查，对**加拿大、中国、印度、韩国、墨西哥**发起反倾销（AD）调查 | 2026-09-08（公告09-14） |
| ITC初裁 | **投票认定有合理迹象显示美国产业受到实质损害，全案继续（5国全部肯定）** | **2026-09-30投票**（USITC新闻稿er0930_69296；裁定10-09提交、10-14联邦公报公告91 FR 65258） |
| CVD初裁 | 原定2026-11-12；因申请人申请延期，**推迟至2027-01-19前** | 2026-10-20公告（91 FR 66295） |
| AD初裁 | 按140天法定时限，**2027-01-26前** | 立案公告 |
| 终裁 | CVD终裁为初裁后75天（约2027-04上旬）；AD初裁/终裁时点另行公告 | 2027-04前后 |

**产品范围的三个"超预期"（对恒立最关键）**：
1. **主产品**：钢制缸筒线性液压缸，缸内径≥25.4mm、缩回总长≥101.6mm，含拉杆式/焊接/伸缩/柱塞/单双作用等全部结构——**恒立挖机油缸、非挖油缸、盾构/海工油缸几乎全部落入范围**；
2. **随整机出口的油缸**：明确覆盖"附着于或与第84章（机械设备）项下设备一同进口"的油缸及零部件，仅对油缸本身价值征税——**即挖掘机、装载机、叉车整机出口美国时，其中的恒立油缸需单独缴税**，这将直接影响卡特彼勒等客户采购中国/墨西哥产油缸的意愿；
3. **第三国组装的中国缸筒/活塞杆**：明确覆盖"在第三国组装或轻微加工后进入美国"的中国产缸筒、活塞杆，以及"中国产油缸在第三国装入第84章设备后再出口美国"的情形——**这直接击穿"墨西哥工厂用中国缸筒/活塞杆组装"的关税套利路径**。

**涉案规模与税率区间**：美方2025年进口统计——中国1.84亿美元、墨西哥1.86亿美元、加拿大2.63亿美元、韩国1.48亿美元、印度0.926亿美元。**申诉倾销幅度（立案公告，trade.gov）：中国103.05%-440.48%（按替代国：马来西亚149.86%-394.07%、墨西哥103.05%-197.07%、土耳其299.38%-440.48%）、墨西哥56.79%-157.12%、印度85.31%-370.67%、韩国73.09%-158.74%、加拿大248.33%-744.85%；补贴幅度均高于de minimis**。历史判例上终裁税率通常显著低于申诉值，但即便落在25%，也足以改变北美配套的经济性。恒立2026年美国收入约8亿元（公司口径，Citi转述），其中油缸占比不低；若终裁综合税率25%且全额吸收，年化直接成本约2.0-2.3亿元，且可能丢失部分北美配套份额。

**公司应对与管理层判断**：①全部对美出口的液压缸产能已转移至印尼与墨西哥工厂（IR口径，2026-09）；②墨西哥工厂2026年底覆盖美国需求100%（当前60-70%）；③管理层在10-27说明会称"双反会影响所有参与者，不会让恒立处于劣势"（Citi转述）。**本报告的独立判断：管理层的"相对无害"判断只能部分成立——产品范围覆盖第三国组装的中国缸筒/活塞杆，意味着"墨西哥制造"的原产地护甲被部分穿透；但恒立同时具备印尼基地（不受本次双反覆盖，因印尼不在涉案国名单）与铸件—精加工垂直一体化能力，可通过"印尼出口+墨西哥本地采购缸筒"两条路径对冲，实际冲击取决于终裁税率与原产地认定细则。该风险按框架归入S（不可预测但重大），同时以PE折价表达。**

### 2.3 实质影响评估（避免情绪化放大）

1. **恒立的墨西哥工厂属于"真制造"而非"贴牌转运"**：半年报披露"各品类液压件产线实现高效运转，产能稳步释放"；铸件→精加工→总成的工艺深度是其对抗原产地审查的最硬护甲，但**本次双反的产品范围不以"实质转型"为标准，而以"缸筒/活塞杆的物理来源"为标准**，工艺深度无法完全豁免；
2. **短期财务影响有限、中期斜率受损**：2026年美国收入约8亿元（占营收约5.8%），若极端情形下全部失去，按25%净利率上限测算对利润影响约2.0亿元、按"增量毛利−可避免费用"口径约0.8-1.2亿元；真正的风险在2027年——美国收入原本是"2027年+30%"的核心增量（Citi/公司口径），双反可能使该增量归零甚至转负；**本报告保守情景已量化"美国收入-40%"（8.0→4.8亿元，单项拖累约3.2亿元，已计入保守情景营收144.0亿元；该营收为自上而下设定，较上期情景下修2.0亿元），据此毛利率由38.8%下修至38.5%，归母27.8→26.9亿元、EPS 2.07→2.01元**；
3. **印尼基地成为新的对冲支点，但非零关税**：印尼不在本次双反涉案国名单，且公司已将对美液压缸产能部分转移至印尼（IR口径：印尼有效产能对应2-3亿元营收，未经公告核实）。**这是本报告在保守情景中仍保留"海外+2%"、而非全面转负的物理基础。**但须提示：美国对印尼/墨西哥/中国分别适用不同的Section 301/232基准关税与豁免条件（具体税率与USMCA合规豁免以CBP裁定为准，本报告未逐条核验），**印尼基地并非零关税，其对冲效果应按"税率差"而非"零关税"评估**——这一不确定性已计入PE地缘折价。
4. **欧洲市场**：意大利、英国服务点设立，轨道交通铸件批量出口欧洲（2026H1），欧盟暂无针对液压件的歧视性贸易措施，属相对友好的增量市场。

### 2.4 供应链重构(China+1)的综合评分

恒立是A股机械公司中少数完成"制造出海"实质落地的企业（墨西哥3.25亿美元投产+印尼5000万美元运营+全球30余国服务网络）。China+1对其是**必答题而非选择题**，先发优势明显。**但2026年美国双反证明：China+1只能对冲"整机层面的关税"，无法对冲"零部件原产地层面的贸易救济"**。综合评分由"中性偏正面"下调至**"中性"**——短期增加合规与关税摩擦成本，中长期强化其相对于纯出口同行的准入优势，但"墨西哥通道"的溢价已被显著压缩。

### 3.2 风险性监管因素

1. **贸易救济的"产品级"扩散**：本次双反的产品范围包含"随第84章设备出口的油缸"，若其他国家（欧盟、印度、巴西）效仿，恒立的出口模型将面临系统性重估——这是比232调查更直接的风险；
2. **环保约束**：铸造环节为环保重点监管对象，公司铸件自供体系需持续投入环保改造（成本项，行业性出清反而利好龙头集中度）；
3. **出口管制反噬风险**：高端螺纹磨床进口受限既保护国产丝杠玩家，也可能卡住恒立扩产的设备交付节奏（交期18-24个月）——Q3其他非流动资产（设备预付款）激增至6.72亿元，说明公司正在提前锁定设备，但也意味着资本开支刚性上升；
4. **数据与安全审查**：传感器、电控产品涉车载数据/工控安全的监管趋严，长期合规成本上升（当前影响可忽略）。

**本章红线结论（供后续模块继承）**：
1. **美国对线性液压缸的AD/CVD是2026年四季度最重要的新增外部约束**：ITC于2026-09-30投票肯定损害，产品范围覆盖"第84章设备内油缸"与"第三国组装的中国缸筒/活塞杆"，CVD初裁（原定2026-11-12）推迟至2027-01-19、AD初裁2027-01-26、终裁约2027-04——**恰好落在2027E的核心验证窗口**。该风险已进入保守情景的E（美国收入-40%+毛利折价0.5pct），并以PE地缘折价（-4%→-6%）表达不确定性，不重复计算；
2. 汇兑损失+掉期公允价值是2026年利润表最大的外生扰动（前三季度合计拖累约4.4亿元），2027E中性按财务费用2.8亿元计提，不赌汇率方向；即期6.669、央行上调外汇存款准备金率仅"控速"，升值方向未逆转；
3. 钢价3,100.84元/吨（11-05）构成毛利率修复的重要顺风，3400元/吨为顺风逆转预警线；
4. 政策面对主业与丝杠均为顺风（936亿设备更新资金已下达、十五五规划落地），但2027年度设备更新政策续期信号（12月底-1月初）是2027E的二元开关——**政策的礼物自带归还日期**。
