# 研报章节二：产业周期与终端穿透

**研究日期：2026年8月24日**
**标的：恒立液压（601100.SH）｜目标年份锚点：2026年**

---

## 一、产业生命周期定位：三层业务，三种周期坐标

恒立液压的业务组合横跨三个生命周期阶段，必须分层定位，严禁混为一谈：

| 业务层 | 行业坐标 | 驱动逻辑 | 当前状态 |
| :--- | :--- | :--- | :--- |
| 挖机油缸/泵阀 | **成熟行业的周期回升段** | 存量设备更新周期（8-10年）+ 国产替代残余空间（大挖泵阀） | 上行第二年（2025复苏→2026加速） |
| 非挖油缸/泵阀（农机、矿山、海工、风电、工业） | 成熟行业渗透率提升段 | 多元化对冲+高端国产替代 | 双位数增长，多点开花 |
| 线性传动件（丝杠/导轨/电动缸） | **导入期（渗透率<5%）** | 人形机器人+工业自动化电动化替代 | 送样/小批量/客户破千家，未形成规模收入 |

**中国液压行业总盘子**（前瞻产业研究院引《中国工业统计年鉴》）：2023年规模以上液压(含液力)企业营收1538亿元，2024年测算约1597亿元；预计2030年达1915亿元（CAGR约3-4%）——**母行业是典型的成熟存量市场**。其中挖掘机液压件细分市场约387.6亿元（2024年），第三方预测2025年423.8亿（+9.3%）、2026年464.2亿（+9.5%）、2027年508.1亿元（来源：中商类咨询报告汇总，未经权威来源交叉验证，仅作方向参考）。**结构比总量重要**：20吨以下挖机油缸国产化率已超90%（替代完成），而30吨级以上高压柱塞泵国产化率仅约40%、2025年预计突破60%——**剩余的替代空间集中在最难的高端泵阀**，这正是恒立中大挖泵阀2025年+40%增长的战略含义。

## 二、库存动力学与"牛鞭效应"审计：本报告最重要的预警发现

### 2.1 销量与开工率的罕见背离

将协会月度销量与开工率数据并列，出现教科书级的"销量先行、终端滞后"信号：

| 指标 | 2026年最新读数 | 同比变化 |
| :--- | :--- | :--- |
| 挖掘机销量（1-7月累计） | 171,841台 | **+24.8%** |
| 其中：国内（1-6月） | 79,025台 | +20.4%（4月+34.9%/5月+38.6%/6月+33.9%） |
| 其中：出口（1-6月） | 73,295台 | +33.5% |
| **7月国内单月** | 7,608台 | **+4.13%（骤降）** |
| 工程机械月开工率（6月） | 51.1%（挖机51.6%） | **同比-5.83pct** |
| 挖掘机月工作时长（6月） | 58.1小时 | 同比下降（4月同比约-13%） |

（来源：中国工程机械工业协会快报，经凤凰网/新浪财经/东吴证券/江海证券多源交叉核对）

### 2.2 核心辨析：本轮销量增长不是终端需求的真实全面复苏

- **量的构成拆解**：上半年国内销量增长的主导力量是**国三排放标准设备进入置换高峰**（更新需求）+专项债提速下水利/城市更新项目开工；出口贡献48.1%的销量占比。而**开工率与工作时长同比双降**说明终端工程作业量并未扩张——新卖出的设备大部分是"替旧"，而非"添新"。
- **牛鞭效应判定**：当前渠道环节不存在显著补库（主机厂以销定产纪律较好，且4-5月三一/徐工/柳工集体涨价3-5%表明主机厂对需求有信心、无去库压力），但存在另一种更隐蔽的前置风险——见下节。
- **传导时滞利好**：恒立作为零部件商，其收入跟随主机厂排产而非终端工程量，时滞约1-2个季度。这意味着即使终端走弱，公司2026H2-2027H1收入仍有韧性垫；但若更新脉冲结束而新增需求未接棒，主机厂排产下修将逐级放大传导至零部件（历史上2021Q3-2022年该机制曾致恒立收入连续六个季度负增长）。

## 三、终端需求穿透与跨期断层审计（MANDATORY）

### 3.1 最终产品画像

恒立产品最终负载于五类终端形态：①土方机械（挖机，收入占比约45-50%）；②起重/混凝土/路面机械等泛工程机械；③农业机械（拖拉机/收割机高压柱塞泵与多路阀）；④高空作业平台（行走马达、闭式泵）；⑤新兴：人形机器人直线执行器（丝杠）、风电变桨/偏航、海工/盾构非标油缸。

### 3.2 各终端未来1-3年景气度审计

**① 挖掘机（最大权重）**：光大证券基于8-10年使用寿命测算，国内挖机2026年及后续几年存在**复合30%左右的替换量增长**；上一轮销量顶部在2021年初（国内峰值约27.4万台/年），对应2029-2031年为下一轮置换高峰。2026年全年国内销量有望冲击14万台级别（1-6月已7.9万台）。**但需警惕：7月国内+4.13%的单月骤降可能预示补贴脉冲衰减后的自然回落斜率远陡于线性外推。**

**② 政策性需求（跨期断层强制审计项）**：
- 《发改环资〔2025〕1745号》确认2026年**连续第三年**实施大规模设备更新政策，超长期特别国债继续支持工业领域设备更新、老旧农机报废更新；
- 审计结论：**存在明确的需求前置证据**。2024-2025年的设备更新补贴已提前兑现了部分2026-2027年的自然换机需求；国三设备保有量池是有限存量，补贴退坡后更新动能将向自然更换率回归。7月内销增速从5月+38.6%骤降至+4.13%，与"补贴脉冲前高后低"的模式吻合。**这是本研报对2027年后挖机链景气度的核心保守假设来源**：我们假设2027年国内挖机销量增速回落至0-10%区间，而非券商一致预期的持续两位数增长。
- 对冲因素：雅鲁藏布江下游水电、新藏铁路等超大型基建项目处于启动初期，2027-2030年提供新增量托底；二手机大量出口拉低国内保有量，结构性抬升自然更新率。

**③ 农业机械**：农机报废更新补贴延续（拖拉机最高报废补贴2万元/台），高端农机（大马力拖拉机CVT、联合收割机）液压件国产化刚起步，恒立高压柱塞泵已进入国内外头部农机供应链（2025年报），农机板块为公司非挖增长的重要引擎，确定性中等偏高。

**④ 高空作业平台**：2025年国内高机销量-42%（深度去库），2026年1-5月升降工作平台恢复至+16.5%（协会快报）。该市场经历洗牌后租赁商盈利修复，但渗透率已高，属于"低基数修复"而非新成长，对恒立弹性有限。

**⑤ 人形机器人（丝杠终局赛道）**：复用《中国人形机器人产业深度研究报告》（2026-08-02）结论——2025年全球出货1.6-1.8万台，2026E基准3-5万台（乐观10-15万台）、2027E基准5-8万台；行星滚柱丝杠单机用量8-14根、单机价值3-6万元、占BOM19-30%；PRS市场规模2025年数亿元→2030年百亿+（CAGR>80%）。**恒立现状：T2梯队**（滚珠丝杠小批供货、行星滚柱丝杠送样+初步量产，送样Tesla等）；2025年已建成年产直线导轨36万米、磨削滚珠丝杠7万套能力，合作客户超300家，2026H1新增客户超千家。**关键缺口：尚未公告任何头部整机厂的批量定点合同**——千家客户以中小工业客户为主，机器人整机大单仍属期权而非现金流。

### 3.3 动能溯源定性

| 动能源 | 内生/外生 | 强度评估 |
| :--- | :--- | :--- |
| 设备更新周期 | 外生政策催化+内生寿命规律叠加 | 强但有时限（2026年内最强） |
| 出口/国际化 | 内生（性价比+服务网络+海外建厂） | 强且可持续 |
| 大挖泵阀国产替代 | 内生技术突破 | 中强，剩余空间约40pct国产化率 |
| 人形机器人丝杠 | 内生布局+外生产业浪潮 | 期权性质，2026年收入贡献可忽略 |
| 基建实物工作量 | 外生财政 | 弱（开工率下滑证伪强复苏） |

## 四、供需边际与压力传导

### 4.1 供需平衡审计

**供给侧**：液压件行业CR格局稳定，恒立挖机油缸国内市占率约58-64%（多源区间，第三方报告口径未经权威交叉验证）、液压件整体市占率28.5%；主要竞争对手川崎重工（挖机液压件22.1%）、KYB、博世力士乐、艾迪精密（阀组+破碎锤）。恒立自身产能扩张集中于：墨西哥基地（投产爬坡）、线性驱动器项目（预算15.27亿元，进度61%）、油缸技改二期（进度50%）、泵阀技改二期（进度32%）、印尼工厂（在建）——**扩产节奏与需求匹配度高，未见激进过剩产能投放**。
**需求侧**：挖机液压件市场2024-2028E CAGR约17%（券商测算），高于挖机整机销量增速，因泵阀价值量占比提升+大挖占比上移。
**边际判断**：传统液压主业供需处于**紧平衡向温和宽松滑落的前夜**——2027年后若更新脉冲衰减，行业将重回份额竞争；但恒立凭借墨西哥本土化产能与高端泵阀独供地位，压力传导弱于二线同行。丝杠赛道则是相反图景：**30+企业涌入、规划产能远超需求，2027-2028年必然经历残酷出清**（复用行业研报结论），恒立的精密加工积淀是入场券但非胜出保证。

### 4.2 压力传导特征分析

1. **波动放大效应（上游→公司）**：钢材占成本55.17%（2025年），钢价±10%波动直接扰动毛利率±2-3pct，但2025年以来钢价低位企稳，成本端友好；
2. **波动放大效应（公司←→主机厂）**：主机厂2026年4-5月集体提价3-5%落地，标志价格战缓和，零部件商议价环境改善——恒立2026H1毛利率下滑主因是新工厂爬坡而非降价，属于"主动的成本"而非"被动的挤压"，两者性质截然不同；
3. **传导时滞与博弈筹码**：油缸/泵阀为安全件（失效即机毁人亡），认证切换成本极高（18-24个月），主机厂轻易不敢换供应商——恒立的刚性配套属性使其在下行周期中的收入韧性显著优于通用件厂商；应收账款账期被动拉长（2025年应收+39%）是其承受的最主要周期代价。

**【强制复核项确认】**：
1. ✅ 已穿透并引用最终终端产品（挖机/农机/高机/人形机器人整机）未来两年景气度预测（协会月度数据、光大替换量测算、机器人出货量三态预测）；
2. ✅ 已审计跨期需求移位：设备更新政策连续第三年+国三置换高峰+7月内销增速骤降至+4.13%，判定**存在实质性需求前置**，并已在盈利预测假设中体现（2027年国内挖机销量增速下调至0-10%）；
3. ✅ 已基于产能与终端需求分析供需边际演变（传统主业紧平衡转温和宽松、丝杠赛道供给过剩出清在即）及压力传导特征（安全件认证壁垒延缓传导、账期拉长为主要代价）。

**本章红线结论（供后续模块继承）**：2026年是本轮挖机更新的高点年份，公司收入端的高增长在2026年内具备高确定性；2027年起国内挖机需求大概率降速，公司的持续增长必须依靠①出口与非挖多元化、②大挖泵阀替代深化、③丝杠业务从期权变现金流。估值定价必须对"2026年利润=周期高点利润"的可能性保持警惕。
