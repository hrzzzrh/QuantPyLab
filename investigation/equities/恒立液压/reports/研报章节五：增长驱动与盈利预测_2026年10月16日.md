**2027E推演的两个实证锚点**：

1. **协会9月快报（2026-10-12发布）**：9月销售各类挖掘机22,717台、同比+14.4%，其中**国内9,911台（含电动218台）+7.16%**、出口12,806台+20.7%；1-9月累计出口109,744台首超内销104,530台（估算口径）。**7月+4.13%→8月+3.92%→9月+7.16%已连续三个月国内单月增速<10%，跟踪手册E1保守情景阈值持续处于触发状态**；但9月较8月边际回升3.24pct、出口再加速至+20.7%，行业增长重心已完成向出口的切换。该结构直接决定2027E三态的收入分化：**国内增速假设的方差被压缩在低区间，出口与替代成为区分三态的主变量**。
2. **2026年半年度权益分派实施（公告2026-10-09）**：以总股本134,082.10万股为基数每10股派3.00元、合计4.02亿元，占2026H1归母净利28.00%，**为公司历史上首次中期分红**，股权登记日10-15、**除权除息日2026-10-16**。该事件不改变2027E盈利，但改变了资本配置纪律的评估（审计矩阵DNA维度），并使10-16起的股价进入除权后口径（每股机械下调0.30元）。

H1'26收入+32.1%、归母净利仅+0.5%（扣非-5.0%）的剪刀差由三因素构成：新工厂爬坡推高成本（成本增速37.98%>收入增速）、汇兑损失拖累约4.6亿元利润总额、销售费用+40.7%。**2026年盈利预测的核心是判断这三项在H2的收敛速度；2027年盈利预测的核心则是在"国内降速+出口接棒"的新结构下，判断毛利率修复的终点位置与线性传动的兑现斜率。**

## 二、价格与毛利趋势推演（2027E）

**定价权本质还原**：恒立对主机厂无名义提价权（章节三），其毛利率改善只能来自①原材料红利、②规模摊薄与爬坡收敛、③高端品占比提升。2027年三者力度较2026年发生结构变化：

| 因素 | 对2027E毛利率影响 | 确定性 |
| :--- | :--- | :--- |
| 钢价（螺纹钢3318元/吨，10-15，较9月下旬统计局3175.9元/吨小幅回升，仍低于3400元/吨预警线） | +0.2~0.5pct（原料占成本55%，采购价滞后市场价2-3个月） | 中高 |
| 新工厂爬坡收敛（墨西哥2025投产→2026爬坡→2027达产、精密工业良率改善） | **+0.8~1.2pct（2027年最大正向变量）** | 中 |
| 折旧基数抬升（2025年固定资产+28.5%集中转固） | -0.5pct（永久性压制，2026年已充分体现） | 高（负向） |
| 产品结构升级（中大挖泵阀占比、丝杠占比提升） | +0.3pct（线性传动毛利率33%低于综合，占比提升形成小幅拖累，与泵阀升级部分对冲） | 中高 |
| 国内降速引发的价格竞争（艾迪+艾崎精密产能释放） | -0.5~-1.0pct（保守情景全额兑现，中性情景部分兑现） | 中 |
| 存货跌价冲回/新增计提 | 净影响约+0.1pct（爬坡改善） | 中 |
| **综合** | 2027E全年毛利率**40.0%**（vs 2026E 39.7%，修复0.3pct；低于2024年42.83%与2025年41.58%，仅回到2022年40.55%水平） | |

**毛利率口径的审慎声明**：本报告拒绝将2027E毛利率假设修复至2024-2025年水平（41.6%-42.8%），理由：①国内挖机2027年降速意味着产能利用率下行，规模摊薄逻辑弱化；②折旧基数为永久性抬升项；③艾迪精密泰国二期（2026年8月底具备投产条件，规划8万个液压件/年产值6亿元）与川崎合资艾崎精密的产能释放将在2027年形成正面价格竞争。**中性情景的毛利率假设（40.0%）已内含约-0.7pct的价格竞争折价**，保守情景（38.3%）则假设价格战全额兑现且爬坡反复。

**勾稽校验**：Σ板块模拟净利36.15亿 + 其他业务模拟净利0.09亿（营收0.6亿×毛利率30%） = 36.24亿；再加投资收益/其他收益净额1.50亿（=掉期收益与现金理财2.5亿 − 减值及其他0.8亿，税后） = **37.73亿 ≈ 中性情景预测总净利37.78亿，偏差-0.12%，勾稽通过**。分部毛利率加权（40.2%，不含其他业务）与综合毛利率假设（40.0%）差异0.2pct，在容差内。

**SOTP揭示的结构真相（2027E版）**：泵阀板块贡献模拟净利的51.4%（18.57亿），油缸贡献42.9%（15.51亿），而**市场热炒的线性传动在2027E中性情景下仍仅贡献2.3%（0.82亿，较2026E的1.3%绝对额仍可忽略）**——当前1065.7亿元市值（79.48元，10-15）较09-10的1342亿（100.10元）回落-20.6%、较10-09的1136亿（84.75元）再回落-6.2%，但隐含定价与利润结构的脱节仍未消除（详见模块六）。

**桥接结论**：2027E较2026E的+5.95亿元税后增量，可完整分解为四项（统一为税后口径、以2027E收入为费率基数）：①**收入自然增长（+18.9亿元）在扣除相应费用后的净贡献 +4.58亿元**（=毛利收入效应+6.64亿 − 三项费用收入效应-2.06亿）；②**毛利率提升0.3pct贡献 +0.41亿元**；③**期间费用率下行0.89pct贡献 +0.85亿元**（其中财务费用额由3.00亿降至2.50亿贡献+0.44亿、销售+管理+研发费率由12.3%降至12.0%的规模摊薄贡献+0.41亿）；④投资收益与减值的净改善 +0.09亿元。合计+5.93亿≈+5.95亿。该桥接的最大脆弱点有两处：①**收入端**——若2027年国内挖机销量转负（保守情景），收入增速将自+13.9%坍缩至+4.4%，①项即告失效；②**财务费用端**——若人民币升破6.5且套保到期不续，中性情景将滑向保守情景（这正是保守情景存在的意义）。结合章节一披露的Q2单季扣非已转正(+6.8%)的证据，桥接方向具备实证支撑，幅度依赖出口斜率与汇率路径。
