## 二、价格与毛利趋势推演

**定价权本质还原**：恒立对主机厂无名义提价权（章节三），其毛利率改善只能来自①原材料红利、②规模摊薄、③高端品占比提升。三者2026年均成立但力度不同：

| 因素 | 对2026E毛利率影响 | 确定性 |
| :--- | :--- | :--- |
| 钢价低位（螺纹钢<3000元/吨，8月3日破位） | +1.0~1.5pct | 高（原料占成本55%，采购价滞后市场价2-3个月） |
| 新工厂爬坡收敛（墨西哥90%转固后效率提升、精密工业良率改善） | H2环比逐季改善，全年仍为负贡献约-1pct | 中 |
| 产品结构升级（中大挖泵阀、丝杠占比提升） | +0.5pct | 中高 |
| 存货跌价冲回/新增计提 | 净影响约-0.1pct（H1已计提6110万） | 中 |
| **综合** | 全年毛利率约39.7%（H1实际39.27%，H2约40.2%） | |

## 五、SOTP 分部利润模拟（框架规范算法）

**参数**：总期间费用率15.0%（四项费用/收入，含汇兑损失）；有效税率11.5%（2026H1利润表隐含实际税率约10%，考虑H2利润基数抬升与高新15%法定税率+研发加计的混合效应，取11.5%）；K分配——液压成熟制造K=1.0、线性传动成长孵化K=1.3。

| 板块 | 营收(亿) | 毛利率 | K | 模拟净利(亿) |
| :--- | ---: | ---: | :---: | ---: |
| 液压油缸 | 62.5 | 40.0% | 1.0 | 13.83 |
| 液压泵阀及马达 | 55.0 | 49.5% | 1.0 | 16.79 |
| 液压系统 | 4.8 | 35.0% | 1.0 | 0.85 |
| 配件及铸件(剔除丝杠) | 10.5 | 17.0% | 1.0 | 0.19 |
| 线性传动 | 3.0 | 35.0% | 1.3 | 0.41 |
| **Σ板块模拟净利** | | | | **32.07** |

**勾稽校验**：Σ=32.07亿 ≈ 中性情景预测总净利31.9亿（差额+0.2亿对应投资收益/政府补助约2.2亿扣除总部未分摊项，偏差<1%，勾稽通过）。**SOTP揭示的结构真相：泵阀板块贡献模拟净利的52%，油缸贡献43%，而市场热炒的线性传动当前仅贡献1.3%**——当前1409亿市值的隐含定价与利润结构严重脱节（详见模块六）。

*注：分部营收加总135.8亿元与全年预测136.4亿元之间约0.6亿元差额为"其他业务收入"（2025年实际约1.5亿元口径下的自然余量），不影响板块利润模拟。*

## 五B、中性情景H2利润桥接表（可验证性补充）

中性情景全年31.9亿元隐含H2归母约17.5亿元（同比+34%）、H2净利率约25.9%（vs H1'26实测21.0%、H2'25实测22.6%）。净利率跳升4.9pct的推导链必须显性展示：

| 桥接项 | H2'26E | H2'25实测 | 差异来源 |
| :--- | ---: | ---: | :--- |
| 收入(亿) | 68.1 | 57.70 | +18%（更新动能延续+出口+丝杠确认） |
| 毛利(亿) | 27.35（毛利率40.2%） | 23.83（毛利率41.3%，倒算） | 毛利率同比-1.1pct：爬坡成本仍拖累 |
| 销售+管理+研发费用(亿) | -8.16（费率12.0%） | -8.53（费率14.8%，倒算） | 规模摊薄贡献约2.8pct（与H1实际摊薄幅度2.3pct同量级） |
| 财务费用(亿) | -1.05 | **-2.73**（全年0.06−上半年(-2.67)倒算，H2'25已含大额汇兑损失） | **核心变量**：H2'25基数中含2.73亿汇兑损失，中性假设H2'26收窄至约1亿损失（套保掉期垫+升值斜率放缓），同比改善约1.7亿 |
| 投资收益/其他收益(亿) | +2.2 | 约+2.4（掉期收益+现金理财，平稳假设） | 掉期头寸63.5亿元存续，收益可持续性中等 |
| 减值与其他(亿) | -0.6 | —（Q4计提惯性前移假设） | 存货跌价随爬坡改善 |
| 税率 | 12.5% | 约11% | 保守取值 |
| **归母净利(亿)** | **≈17.5** | **13.05** | **+34%** |

**桥接结论**：H2净利率修复的4.9pct中，约2.8pct来自规模摊薄（有H1实证）、约3.5pct来自财务费用的同比改善（H2'25本就含2.73亿汇兑损失的高基数——即中性情景并非要求"H2利润率创历史新高"，而是要求"H2不再重复上半年的极端汇兑强度"，经正常化后H2'26净利率约与H2'25持平）。该桥接的最大脆弱点仍是财务费用项——若人民币升破6.6且套保到期不续，中性情景将滑向保守情景（这正是保守情景存在的意义）。结合章节一披露的Q2单季扣非已转正(+6.8%)的证据，桥接方向具备实证支撑、幅度依赖汇率路径。

## 六、EPS预测结论

| 情景 | 2026E归母净利 | 2026E EPS | 2027E EPS(参考) |
| :--- | ---: | ---: | ---: |
| 保守 | 27.8亿 | **2.07元** | 2.11元 |
| 中性 | 31.9亿 | **2.38元** | 2.64元 |
| 乐观 | 37.2亿 | **2.77元** | 3.27元 |

**与卖方一致预期的差异声明**：主流券商对恒立2026年净利预测集中在35-36亿元区间（如华创证券2026-05-31预测35.8亿元），本报告中性预测（31.9亿）较其低约11%，分歧点在于：①卖方普遍假设汇兑中性而本报告计入全年3亿元财务费用（H1已实损1.95亿）；②卖方对H2毛利率修复斜率的假设更激进；③卖方收入假设隐含H2增速不衰减，与本报告基于7月协会数据的降速判断不同。本报告坚持从已披露数据出发的第一性推演，不做一致性妥协。

---

**本章红线结论（供模块六继承）**：中性EPS 2.38元（2026E）/2.64元（2027E）；利润结构上95%+来自液压主业，丝杠的盈利贡献在2026年可忽略。当前市值1409亿对应中性2026PE约44倍、2027PE约40倍——估值的重担几乎完全压在"期权价值"上。
