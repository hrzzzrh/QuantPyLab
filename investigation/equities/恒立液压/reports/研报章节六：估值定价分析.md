**研究日期：2026年8月24日**
**标的：恒立液压（601100.SH）｜现价105.11元（不复权收盘，2026-08-24）｜总市值1409亿元｜股本13.408亿股**

## 一、价值锚定：适配性估值方法选择及理由

| 方法 | 采用与否 | 理由 |
| :--- | :--- | :--- |
| **PE（当年EPS锚定）** | **主方法** | 公司盈利为正且波动主要来自量与毛利率，PE是最直接的市场沟通语言；当前处Q3，锚定**2026E EPS** |
| **PB-ROE** | **交叉验证主方法** | 公司账面净资产受百亿净现金夯实、ROE被现金稀释失真，PB-ROE能剥离利润表噪声看资产回报定价是否合理；历史上该股2024年底部由PB 4.25x有效支撑 |
| DCF | 弃用 | 终端需求含强周期成分+丝杠现金流起点为零，终值假设将主导结果，伪精确 |
| PEG/PS | 辅助参考 | 仅用于检验乐观情景下市场叙事的容忍边界 |

## 四、逻辑纯净性校验

1. **E与PE的分界**：汇兑损失、钢价红利、爬坡成本→全部进E（盈利预测已逐项建模）；USMCA不确定性、政策退坡时点、风格切换风险→全部进PE（审计矩阵）；无重复计算。
2. **锚点回测**：修正后隐含2026E综合PE = 1060/31.9 = **33.2x**，高于2024年谷底(22.8x)、略低于5年中位(34.7x)。商业逻辑支撑：①当前盈利质量低于2021-2024（净利率25% vs 29%）故不应回到中位数之上；②丝杠在手订单+泵阀替代纵深提供2024年不具备的结构性成长证据，故不应贴到谷底。33x位于可辩护区间(28.8x-34.7x)的偏上沿，其溢价部分由丝杠期权信用解释。
3. **期权价值的显式声明**：中性32x中约包含3-4x的丝杠期权信用（以可比公司五洲新春/拓普集团丝杠业务的市值/收入比粗估，若机器人定点落地该部分价值弹性向上，反之归零）。**本报告拒绝将未确认定点按概率加权计入目标价**——送样≠定点的证据标准已在章节三确立。

## 五、确定性与胜率矩阵（Win Rate & Risk-Reward）

**三态概率赋权**：保守25% / 中性60% / 乐观15%（依据章节五）

| 项目 | 数值 |
| :--- | ---: |
| 加权目标价 = 0.25×49.7 + 0.60×79 + 0.15×110.4 = 12.43 + 47.40 + 16.56 | **76.4元** |
| 现价（2026-08-24不复权收盘） | 105.11元 |
| 加权期望收益空间 = 76.4 ÷ 105.11 − 1 | **-27.3%** |
| 盈亏比 = (76.4 − 105.11) ÷ (105.11 − 49.7) = -28.71 ÷ 55.41 | **-0.52** |

**结论定性**：加权期望收益为负、盈亏比为负值——数学含义是"即使按60%概率兑现中性改善，期望回报仍显著为负，且下行距离(-52.7%)大于任何单边上行距离"。当现价≥保守场景价格时分母为正、公式直接适用，无需启用"下行空间为负"表述。

## 六、逻辑证伪与极限压力测试

**一击毙命事件定义（黑天鹅模拟）**：美国232条款对墨西哥产重型机械加征关税并追溯原产地审查 + 国内挖机销量2027年同比转负15%以上 + 人形机器人板块整体估值崩塌（Optimus量产再度跳票至2028年后）三者叠加。

**极限情形推演**：
- 盈利坍缩：收入回落至95-100亿元（2022年水平），净利20-22亿元；
- 估值坍缩：跌破2024年谷底估值（PE<22.8x/PB<4.25x），按PE 18x/PB 3.2x计；
- 极端情形提示：对应市值约360-480亿元、**股价27-36元**（较现价-66%~-71%）。此为压力测试口径，不计入盈亏比公式。

**绝对清算底线（地狱价格）**：货币资金+理财约103亿元（几乎无有息负债）+ 营运资本回收约30亿元 − 固定资产/无形资产清算折价约35亿元 ≈ **98-100亿元清算价值，折合每股7.3-7.5元**。该价格为理论破产清算锚，实际发生概率趋近于零，仅作为风险管理的终极标尺。

---

**本章红线结论**：三态目标价 **49.7元 / 79元 / 110.4元**（保守/中性/乐观，均为不复权口径），概率加权目标价**76.4元**，较现价105.11元存在-27.3%的期望回撤，盈亏比-0.52。当前市场价格已经透支中性情景的全部上行空间并预支了相当部分的乐观情景，投资建议的性质判定移交模块八。
