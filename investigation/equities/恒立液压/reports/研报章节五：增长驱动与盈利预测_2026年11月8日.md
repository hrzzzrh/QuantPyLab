## 二、价格与毛利趋势推演（2027E）

**定价权本质还原**：恒立对主机厂无名义提价权（章节三），其毛利率改善只能来自①原材料红利、②规模摊薄与爬坡收敛、③高端品占比提升、④新业务自身毛利转正。2027年四者力度较2026年发生结构变化：

| 因素 | 对2027E毛利率影响 | 确定性 |
| :--- | :--- | :--- |
| 钢价（螺纹钢3,100.84元/吨，11-05，较10-15再降6.5%、低于3400预警线9%） | +0.3~0.6pct（原料占成本55%，采购价滞后市场价2-3个月） | 中高 |
| 新工厂爬坡收敛（墨西哥2027年覆盖美国需求100%、精密工厂Q4扭亏、2027年转盈利） | **+0.8~1.2pct（2027年最大正向变量，且已有Q3毛利率转正的实证）** | 中 |
| 折旧基数见顶（固定资产49.88亿，连续两季不再增长） | -0.2pct（由"增量压制"转为"存量摊销"） | 高（负向） |
| 产品结构升级（泵阀占比由40.7%升至41.0%、线性传动占比由2.2%升至5.4%） | 净影响约-0.1pct（线性传动毛利率30%低于综合，占比提升形成拖累，被泵阀升级对冲） | 中高 |
| 国内降速引发的价格竞争（艾迪泰国产线2026-11投产、艾崎精密放量） | -0.5~-0.8pct（保守情景全额兑现，中性情景部分兑现） | 中 |
| 美国AD/CVD（终裁约2027-04） | 0（基准不入价，保守情景计入-0.5pct） | 低（事件） |
| 存货跌价冲回/新增计提 | 净影响约+0.1pct（爬坡改善） | 中 |
| **综合** | 2027E全年毛利率**40.3%**（vs 2026E 39.82%，修复0.5pct；仍低于2025年41.58%与2024年42.83%，仅回到2022年40.55%水平） | |

**毛利率口径的审慎声明**：本报告拒绝将2027E毛利率修复至2024-2025年水平（41.6%-42.8%），理由：①国内挖机2027年降速意味着产能利用率下行，规模摊薄逻辑弱化；②艾迪泰国产线（规划8万个液压件/年产值6亿元）与川崎合资艾崎精密的产能释放将在2027年形成正面价格竞争；③线性传动（毛利率30%）占比由2.2%升至5.4%，结构性拖累综合毛利率。**中性情景的40.3%已内含约-0.6pct的价格竞争折价**，保守情景（38.5%）则假设价格战全额兑现+美国双反落地。

*口径说明：2026E其他收益/投资收益/公允价值净额+0.67亿的构成为——前三季度其他收益0.53亿+投资收益2.27亿+公允价值变动-2.53亿=+0.27亿；Q4按+0.40亿计提（掉期赎回收益与公允价值损失的净额，不假设汇率方向）。2027E+1.70亿的构成为——掉期与理财净收益+1.40亿（不假设公允价值损失再度扩大）+其他收益0.50亿−公允价值变动-0.20亿；其中"其他收益"含政府补助（2025年全年0.89亿），属中性假设。*

**桥接结论**：2027E较2026E的+6.58亿元税后增量，可分解为五项（按10%税率还原，残差0.05亿为四舍五入）：①**收入效应（+19.6亿×2026年毛利率39.82%，扣除同比例三项费用与税金）税后+4.58亿元**；②**毛利率提升0.49pct（157.5×0.49%=0.77亿）税后+0.69亿元**；③**三项费用率下行0.45pct（157.5×0.45%=0.71亿）税后+0.64亿元**；④**财务费用增加0.37亿税后-0.33亿元**；⑤**投资收益/减值/营业外净改善1.39亿税后+1.25亿元**；⑥所得税率由9.5%升至10.0%影响-0.20亿元。合计+6.63亿≈+6.58亿。**桥接的最大脆弱点有三处**：①收入端——若2027年国内挖机销量转负（保守情景），收入增速将自+14.2%坍缩至+4.4%；②线性传动端——8.5亿收入中2.0亿为机器人（无公告定点），若客户爬坡不及预期，收入与毛利双降；③财务费用端——若人民币升破6.6且掉期到期不续，中性情景将滑向保守情景。

- **对卖方**：主流券商2027E归母集中在39.7-42.8亿元（国信38.55、东吴42.8、国金42.0、华龙39.69、浙商41.0），本报告中性35.6亿元低约10%-13%，分歧点在于：①**国内挖机销量假设**（卖方普遍假设2027年延续两位数增长，本报告仅+3%，基于10月出口骤降与更新脉冲透支）；②**毛利率修复终点**（卖方假设41%以上，本报告40.3%，考虑折旧与艾迪/艾崎价格竞争）；③**汇兑与税金及附加**（卖方普遍假设汇兑中性且部分模型未计税金及附加）。**同时必须记录的逆向证据**：花旗2026-10-30将2027年净利增速由5.2%上调至43.9%（对应约42亿元），摩根大通维持正面、目标价126元，高盛中性96元、大摩115元、花旗135元——卖方与买方对2027年的核心分歧在于"线性传动8-10亿指引能否兑现+主业降速幅度"，该分歧将在2026年报（2027-04）与2027年协会月度数据中逐步裁决。本报告坚持从已披露数据出发的第一性推演，不做一致性妥协。
