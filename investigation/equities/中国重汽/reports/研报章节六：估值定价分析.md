## 一、方法论批判：为什么不能直接用Forward PE

### 1.1 周期股的PE陷阱

中国重汽是一家**强周期制造业企业**。自1996年上市以来，其归母净利润经历了5轮完整的繁荣-崩溃周期：

| 周期 | 峰值年份 | 峰值净利 | 谷底年份 | 谷底净利 | 跌幅 |
|:---|:---|:---:|:---|:---:|:---:|
| 第3轮 | 2010 | 6.73亿 | 2012 | 0.46亿 | **-93%** |
| 第4轮 | 2020 | 18.80亿 | 2022 | 2.14亿 | **-89%** |
| 第5轮(当前) | 2026E | 22.3亿（08-26下修自24.0） | ？ | ？ | ？ |

每一轮周期峰值→谷底的利润跌幅都在85-93%。在周期股中，**当利润处于峰值时，Forward PE天然就低——这不是低估，这是周期股定价的内在特征。** 用峰值利润的PE判断"便宜"或"贵"，相当于用体重最轻的一天证明自己需要增肥。

**正确的周期股PE估值方法**：以跨越周期的"归一化利润"为E，而非以当期利润为E。归一化利润应剔除极端景气年份的干扰，反映公司在一个完整周期内的"平均赚钱能力"。

### 1.2 方法论重新选择

| 估值方法 | 适用性 | 理由 |
|:--- | :---: | :--- |
| **中周期归一化PE** | ★★★★★ 主力 | 以近三年均值利润为基准，叠加出口结构性溢价，是周期股最恰当的PE框架 |
| **PB-ROE** | ★★★★★ 核心验证 | 不依赖利润预测，基于净资产回报率的长期可持续性——天然适配周期股 |
| **EV/EBITDA** | ★★★★ 重要参考 | 公司零有息负债，EV剔除了资本结构干扰；EBITDA较净利润更少受周期扰动 |
| **Forward PE** | ★ 仅作风险提示参考 | 仅用于说明"如果2026年利润可持续"的上限情景，不作为定价锚点 |
| **PEG** | ☆ 不适用 | 周期股的利润增速本身是周期波动的产物，用PEG定价构成循环论证 |
| **DCF** | ☆ 不适用 | 公司自由现金流波动极大（OCF在-6.5亿至52.8亿之间跳跃），10年预测无意义 |

## 二、主力框架：中周期归一化PE

### 2.1 步骤一：确定"正常赚钱能力"

取近三个完整财年（2023-2025）的归母净利润均值，作为未受补贴政策严重扭曲的"内生盈利基线"：

| 年份 | 归母净利润 | 行业背景 |
|:---|---:|:---|
| 2023 | 10.80亿 | 疫情后复苏，出口开始加速，行业91.1万辆 |
| 2024 | 14.80亿 | 下半年以旧换新起步，行业89.9万辆 |
| 2025 | 16.66亿 | 以旧换新全面发力，行业114.5万辆 |

**三年均值归一化净利润 = 14.09亿**

2026年的22.3亿预期利润（08-26下修）仍包含国四补贴扩围+NE爆发式增长的双重政策红利——在历史上，这类外生驱动的利润增量从未被证明可持续（参考2021年国六透支后2022年的-89%暴跌）。**在确定"正常赚钱能力"时，必须剔除政策催化的超额部分。**

### 2.2 步骤二：叠加出口结构性溢价

出口是过去三年唯一被验证的"去周期化"结构变量：

| 指标 | 2023年 | 2025年 | 2026H1 | 变动 |
|:---|---:|---:|---:|:---|
| 全行业重卡出口 | 31.9万 | 33万 | 22.25万（H1）| +35% |
| 重汽出口占比(估) | ~40% | ~50% | **>50%（H1）** | +10pct |
| 归一化期间出口权重 | ~1/3权重 | ~2/3权重 | **>50%权重** | 显著提升 |

出口利润的三大特征使其具备结构性溢价：①海外定价高于国内，毛利率更优；②非洲/东南亚基建需求为长期趋势，不受国内排放标准周期影响；③21年出口第一的渠道壁垒难以被竞争对手短期复制。

给予12%的归一化利润上浮（审慎原则，仅反映出口占比从35%→50%的确定性增量，不包含对出口继续高增长的乐观假设）：

```
调整后归一化净利润 = 14.09 × 1.12 ≈ 15.78亿
调整后归一化EPS    = 15.78 / 11.68995 ≈ 1.35元
```

*注：总股本已从11.748亿变更为11.68995亿（注销587万股），EPS微增0.01元。*

### 2.3 步骤三：确定合理PE倍数

| PE区间 | 适用逻辑 |
|:---:|:---|
| ≤12x | 纯周期股定价：利润100%跟随行业波动，历史中枢下沿 |
| 14-16x | **当前适用**：出口占比>50%提供部分去周期化，但内销仍受政策周期支配 |
| 18x+ | 成长股定价：需NE扭亏+出口持续高增+补贴政策长期化，三重条件同时成立 |

取15x（认可结构改善但保持周期股审慎）：

```
基准目标价（归一化PE） = 1.35 × 15 = 20.25元
```

取16x（对出口去周期化给予更充分认可）：

```
偏乐观目标价（归一化PE） = 1.35 × 16 = 21.60元
```

**20.25-21.60元的估值区间与当前股价20.07元基本吻合。** 市场定价并未严重偏离公司的"正常赚钱能力"，且当前股价已跌至区间下沿，具备安全边际。

## 三、核心验证框架：PB-ROE

### 3.1 ROE的可持续性判断

| 年份 | ROE（加权） | 核心驱动 |
|:---|:---:|:---|
| 2023 | 7.59% | 行业从冰点复苏，利润恢复但基数仍低 |
| 2024 | 9.85% | 出口加速+成本管控，利润质量改善 |
| 2025 | 10.58% | 以旧换新驱动，但OCF恶化削弱质量 |
| **2026H1年化** | **~11.76%（9.73*2/165.51）** | **OCF修复+费用率1.56%新低，但毛利6.89%拖累** |

2023-2025三年平均ROE ≈ 9.3%。2026H1年化11.76%（vs 2025 10.58%）显示ROE中枢已上移至11-12%区间（出口高毛利+费用管控），验证PB-ROE框架中12%假设的合理性。

### 3.2 PB-ROE公允价值

```
当前BVPS     = 165.51 / 11.68995 = 14.16元
当前PB       = 20.07 / 14.16  = 1.42x
要求回报率   = Rf 2.5% + ERP 6.0% = 8.5%
```

| 可持续ROE假设 | 公允PB (= ROE÷COE) | 目标价 | vs 现价20.07 | 逻辑 |
|:---:|:---:|:---:|:---:|:---|
| 9.3%（三年均值） | 1.09 | **15.44元** | -23% | 纯历史均值，无结构性改善 |
| 11%（出口提振后） | 1.29 | **18.27元** | -9% | 出口结构性改善被部分定价 |
| 12%（H1年化验证） | 1.41 | **19.97元** | -0.5% | **当前市场隐含ROE约12.1%，接近H1年化11.76%** |
| 14%（2026E乐观） | 1.65 | **23.36元** | +16% | 仅当2026E 22.3亿可持续时成立 |

**当前PB 1.42隐含市场正在定价约12.1%的可持续ROE**——与H1年化11.76%基本吻合，反映市场对重汽的结构性改善已给予充分认可，但未买入峰值ROE。

PB-ROE框架合理区间为**15.4-23.4元**，中值约19.9元（vs 7/22中值21元小幅下移，因BVPS从14.22→14.16微降）。

## 四、独立校验框架：EV/EBITDA

### 4.1 核心优势

EV/EBITDA用于中国重汽具有三个独特优势：①公司零有息负债，EV直接剔除现金冗余的干扰；②EBITDA较净利润更少受减值计提、税率变动等非经营因素干扰；③EBITDA波动幅度小于净利润，更适用于周期性标的。

### 4.2 估值计算

```
2026H1年化近似EBITDA = 净利润14.89*2 + 所得税2.69*2 + 折旧摊销~4.0 ≈ 39.2亿（vs 2025年32.4亿）
EV               = 市值234.6亿 - 净现金110.15亿 = 124.5亿（vs 7/22 179亿）
当前EV/EBITDA    = 124.5 / 39.2 = 3.2x（vs 7/22 5.5x）——因现金大幅增加+市值回落，显著低估
```

*注：2026H1现金110.15亿（+29.8%）导致EV大幅下降，当前3.2x处于极低位，显示市场对重汽的现金价值未充分定价。但需注意H1 EBITDA年化可能高估（H2若放缓则全年EBITDA约35亿，对应EV/EBITDA约3.6x）。*

**全球对标**：

| 企业 | EV/EBITDA | 特征 |
|:---|:---:|:---|
| 戴姆勒卡车 | 6-8x | 全球龙头，成熟市场，15-20%毛利率 |
| 帕卡 | 8-10x | 北美龙头，高利润，品牌壁垒 |
| 中国重汽H(03808) | 4-5x | 港股折价，同一集团 |
| 中国重汽A(000951) | **3.2x（当前，H1年化）** | **A股极度低估，现金充裕** |

合理EV/EBITDA区间为**6-7.5x**（维持）：

| EV/EBITDA | EV | +净现金110.15亿 | 市值 | 目标价 |
|:---:|:---:|:---:|:---:|:---:|
| 6.0x（保守） | 235亿（39.2*6） | → | 345亿 | **29.5元** |
| 6.8x（中性） | 267亿 | → | 377亿 | **32.2元** |
| 7.5x（乐观） | 294亿 | → | 404亿 | **34.5元** |

*EV/EBITDA框架因现金激增而给出偏高目标价（29.5-34.5元），与PE框架（20.25-21.60）差距拉大，反映现金价值与利润质量改善未被PE充分反映。但EV/EBITDA易受H1年化高估影响，取两者重叠区间的偏保守值。*

- 下行风险 = (20.07 - 18.0) / 20.07 = -10.3%（vs 7/22 -18.0%收窄）
- 盈亏比（基准口径）= 12.1 / 10.3 = 1.17x（vs 7/22 0.14x）

**盈亏比（概率加权，框架强制口径）**：
- 上行空间 = (22.05 - 20.07) / 20.07 = +9.86%
- 下行风险 = (20.07 - 18.0) / 20.07 = 10.31%
- **盈亏比（加权）= 9.86 / 10.31 = 0.96x（vs 7/22 0.14x改善但未突破1.0）**

### 关键辨析：0.96x（加权） vs 1.17x（基准）的差异

框架强制要求盈亏比分子必须采用三态概率加权目标价22.05元（27.0×0.2+22.5×0.5+18.0×0.3），而非基准目标价22.5元。按正确口径，加权盈亏比0.96x（vs基准1.17x），**未突破1.0重仓阈值**，仅具配置价值而非积极建仓价值。7/22的0.14x→0.96x改善主因股价回落-8.6%+ OCF修复降低风险折价，但赔率仍需Q3毛利率守7.0%+及8月销量止跌进一步验证，若Q3毛利跌破6.8%或8月再-5%，加权盈亏比将回落至0.8x以下。
