## 一、价值锚定：适配性方法论选择

### 1.1 方法论筛选逻辑

中国西电的商业模式和财务特征决定了估值路径的选择：

| 方法论 | 适配度 | 选择理由 | 权重 |
| :--- | :---: | :--- | :---: |
| **PE（市盈率）** | ★★★★★ | 盈利稳定增长、行业可比性强、市场主流方法 | 40% |
| **DCF（现金流折现）** | ★★★★ | 长周期基础设施资产，FCF可预测性强，适合作为交叉验证 | 40% |
| **PB-ROE** | ★★★ | ROE偏低(5.6%)限制了该方法的有效性，但可作为下限参考 | 10% |
| **SOTP（分部估值）** | ★★★ | 各板块属性差异大，已在模块五完成分部模拟 | 10% |
| PEG | ★★ | 利润增速~15%且波动性较大，PEG易失真 | 0% |

**核心逻辑**：
- 公司处于盈利爬坡期（E从6.2亿翻倍至15.0亿），PE会因E的快速增长而被动压缩——这是"越涨越便宜"的正向循环。PE方法论在此阶段最能捕捉这一动态。
- DCF提供绝对价值锚——长周期电网投资的现金流可预测性高于一般制造业。
- PB-ROE作为下限校验——若估值隐含ROE远超可实现水平，则是危险信号。

### 1.2 历史分位审计（附审慎解读，更新至2026-10-08视图实测）

| 指标 | 当前值（2026-10-08） | 上期（2026-09-08） | 历史中位数 | 全历史分位 | 近5年中位数 | 近5年分位 | 2025年平均 | 2026年平均 |
| :--- | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| PE TTM | 44.45x | 46.83x | 38.74x | ~68% | 41.05x | ~72% | 31.04x | 65.99x |
| PB | 2.58x | 2.72x | — | ~87% | — | ~86% | — | — |

**变化解读**：股价自12.42元回调至11.79元（-5.1%）而TTM净利持平13.60亿，PE自46.83x压缩至44.45x、分位再回落约4pp，PB自2.72x回落至2.58x，估值压力边际缓释。9月30日曾探底至11.61元（PE 43.77x）后国庆后小幅反弹至11.79元，本期PE压缩仍纯由股价回落驱动（TTM未变）。

**审慎解读**——为何不能简单套用历史分位：

1. **"E"的基数效应**：2022年归母净利润仅6.19亿，2026E预计15.0亿（翻2.4倍）。过去5年PE在30-50x是因为E被严重低估（盈利低谷），而非估值本身合理。当前50.4x对应的是已经翻倍的E，若E继续增长至18亿（2027E），PE将自然压缩至约37x——低于历史中位数。

2. **行业环境的质变**：2025年之前，电网投资在"十四五"期间年均约5000亿；2026年起"十五五"跃升至年均8000亿+，且全球变压器进入结构性短缺。估值中枢理应上移——因为增速和确定性与历史不可比。

3. **市场已完成重定价但已有回撤**：2026年PE均值65.99x（显著高于2025年的31.04x），说明市场已经将"十五五"4万亿的预期计入估值。当前53x低于2026年均值，反映7月中旬技术破位后的估值回落。

**结论**：以历史分位简单推导会低估合理估值。更合适的方法是以DCF为绝对锚，以PE为相对锚，结合同业比较进行三角定位。

## 三、全变量对冲审计矩阵（强制输出）

### 3.1 估值影响力过滤

在进行调节前，必须审慎区分"真正的定价因子"与"平庸的关联"：

| 因子 | 初步判断 | **影响力过滤结论** |
| :--- | :--- | :--- |
| 特高压技术领先 | 是否溢价？ | **否** → 已在E（份额19-20%）中体现，不应在PE中重复计算 |
| 全球变压器短缺 | 是否溢价？ | **是** → 这是改变行业供需结构的系统性力量，赋予板块估值溢价逻辑 |
| 央企身份 | 是否溢价？ | **否** → 市场长期给央企ROE折价，身份本身非溢价因子 |
| 4万亿政策 | 是否溢价？ | **是** → 这是写入规划的刚性投资（非愿景），为5年确定性提供法律锚 |
| 新增中标高增长 | 是否溢价？ | **否** → 已在E预测和情景概率中体现，不应在PE中重复计算 |
| ROE偏低(5.6%) | 是否折价？ | **是** → 持续性结构问题，限制估值倍数天花板 |
| 欧盟贸易摩擦 | 是否折价？ | **是** → 虽短期影响小，但长期"安全化"叙事扩散构成持续风险 |
| 铜价高位 | 是否折价？ | **否** → 已在毛利率假设中保守处理，属可量化成本 |

### 3.2 全变量审计矩阵

**审计公式**：修正目标市值 = 基准市值(720亿，DCF修正后710-720亿中枢) × (1 + Σ调节幅度)

| 审计维度 | 核心审计因子 | **审慎思考（估值影响力过滤）** | 调节建议 | 深度理由 |
| :--- | :--- | :--- | :---: | :--- |
| **内部：企业底层特质** | 全品类唯一性+技术内生能力（内部研发形成无形资产占比55%） | 全品类覆盖在国网集中招标体系中转化为真实的份额优势（19-20%综合第一），且"一站式"能力同行无法复制。技术内生性（vs外部引进）在面临技术封锁时抗风险更强。**这是真正能改变估值中枢的稀缺性**，不是平庸的"技术领先" | **+8%** | 长期确定性溢价。全品类覆盖+内生技术能力使公司在任何电网投资结构下都能受益，降低了"选错技术路线"的风险，应给予DCF意义上的折现率折让 |
| **宏观：政策与战略对齐** | 5万亿"十五五"全国电网投资（+80% vs "十四五"）+ 4万亿国网投资 | 5万亿为"十五五"碳达峰行动方案及国家能源局官宣（2026H1管理层讨论披露），较"十四五"大增超80%，且新增15回特高压直流得到规划确认，远超此前券商预测。这种确定性在A股中排前5%。**它能转化为估值溢价**，因为5年的营收下限被锁定 | **+5%** | 政策确定性 = 远期的折现率降低。当市场对一家公司未来5年的需求几乎0疑问时，DCF中的风险溢价应当下调，表现为PE中枢的系统性上移 |
| **宏观：地缘与外部约束** | 欧盟将中国列为"高风险国家"（逆变器）+ 中美贸易摩擦 + 变压器反倾销调查传闻 | 对一次设备（变压器/GIS，不含通信功能）的"安全化"外溢概率低（<30%），但市场会因"关联想象"而要求风险溢价。**这是真实但有节制的折价因子**——不是生存威胁，但构成估值天花板 | **-3%** | 折现率中的地缘风险溢价。即使发生（如加征关税），对营收影响≤5%，但对情绪影响更大。将这一不确定性从PE倍数中扣除~1.5x |
| **市场：流动性与风格** | 总市值701亿（中大盘），北向资金持有，央企改革主题+电网设备赛道热度 | 当前A股市场风格对电网设备板块友好（"十五五"主题+设备更新），但这是**短期博弈因素**而非可持续溢价。真正的机构持仓（北向资金重点配国电南瑞324亿而非中国西电）反映专业投资者对ROE的挑剔。**不构成可持续溢价** | **0%** | 风格溢价是随风而逝的泡沫。当前电网设备板块的PE膨胀（均值65x vs 去年31x）部分源于主题炒作，不应在估值锚中给予权重 |
| **综合调节系数** | — | — | **Σ = +10%** | 对冲后净效果：稀缺性溢价(+8%)+政策确定性(+5%) ＞ ROE折价(-5%计入PE倍数)+地缘折价(-3%)。市场应当给公司约10%的估值溢价 |

> **修正目标市值** = 720亿 × (1 + 10%) = **792亿**
> 
> **修正目标股价** = 792 / 51.26 = **15.45元/股**

### 3.3 逻辑纯净性校验

**E vs PE 的严格区分（2026H1更新）**：

| 因素 | 归入E（利润预测） | 归入PE（估值倍数） | 理由 |

| 海外出口+40%增长（H1境外20.92亿，毛利率11.14%） | ✓ | — | 可量化为营收增长和毛利率变化，但低毛利率已在E中审慎计入 |

| 全品类唯一性 | — | ✓ | 不可量化——关乎"在任何投资结构下都受益"的确定性 |
| 5万亿政策确定性（+80% vs "十四五"） | — | ✓ | 不可量化——关乎远期的折现率下调（2026H1获官方确认） |
| 欧盟贸易摩擦风险 | — | ✓ | 不可量化——关乎风险溢价的要求 |
| ROE系统性偏低（H1年化约6.0%） | — | ✓ | 已在E中体现（低利润率），但ROE对倍数的影响是PE层面 |

**锚点回测（更新至2026-10-08，现价11.79）**：
- 修正目标PE（隐含）= 792亿 / (0.292 × 51.26) = **52.9x 2026E PE**（基于现价11.79，前瞻PE 40.4x）
- 修正目标PB = 15.45 / 4.57(2026H1 BVPS 234.27亿/51.26) = **3.38x**（现价对应PB 2.58x）
- 历史PE中位数38.7x → 当前隐含52.9x高出37%
- 现价11.79对应2026E PE 40.4x（11.79/0.292），仍高于历史中位数但已较9月08日的42.5x再压缩2.1x

**解释**：约53x目标隐含PE高于历史中位数，但这是在以下三个结构性变化下的合理结果：
1. E正在翻倍爬坡期（12.7→15.0→18+），PE会自然压缩
2. 行业需求确定性从"3年可见"延长至"5年锁定"（5万亿写入规划，H1获确认+80%）
3. 全球变压器缺口赋予了板块系统性重估逻辑

若2027年E达到18亿（EPS 0.35），前瞻PE将压缩至37x——进入历史舒适区。

### 4.2 盈亏比计算（框架口径：分子用概率加权目标价，更新至现价11.79）

> **盈亏比（框架口径）** = (15.94 - 11.79) / (11.79 - 9.80) = 4.15 / 1.99 ≈ **2.09**
> 上期（09-08）框架口径1.34；基准口径本期(15.45-11.79)/1.99≈1.84（上期1.16）

**解读**：以现价11.79元买入，基准上行31.0%（vs上期24.4%）、概率加权上行35.2%（vs上期28.3%）。盈亏比自1.34修复至2.09（框架口径）已越过高赔率阈值1.5进入“可重仓”区间，分母收窄至1.99元使赔率弹性放大。下行保护（至保守价-16.9%）较上期-21.1%继续收窄但绝对距离仍1.99元。现价已接近保守价溢价仅20%（vs上期27%），赔率进入历史优异区间。

## 五、逻辑证伪与极限压力测试

### 5.1 黑天鹅场景——"一击毙命"事件

**场景定义**：欧盟将中国产变压器/GIS纳入"高风险设备"清单，禁止使用中国一次设备的电网项目获得欧盟资金支持（类似于2026年5月对逆变器的做法），且美国同步跟进，对中国变压器征收25%+的惩罚性关税。

**影响链**：
- 海外营收（当前43.5亿，占比18.3%）→ 短期内暴跌50%+（欧洲+美国市场份额丧失）
- 国内市场出现"踩踏"——出口产能被迫回流国内，竞争加剧，毛利率大幅压缩
- 全年营收降至220亿（-8%），毛利率降至18%（-5ppt），归母净利润降至6亿（-53%）

**地狱价格（极限支撑位）**：

| 估值方法 | 计算 | 结果 |
| :--- | :--- | :--- |
| 清算价值（净现金） | (105亿现金 - 21亿有息负债) / 51.26亿股 | **1.64元** |
| 重资产清算（净资产折价） | 归母权益230亿 × 0.5（清算折价）/ 51.26亿股 | **2.24元** |
| 盈利崩溃PE | 6亿 × 20x（危机PE）/ 51.26亿股 | **2.34元** |
| **综合极限支撑位** | — | **2.0-2.5元** |

> **在极端黑天鹅下，股价理论极限可跌至2-2.5元（跌幅83-87%）**。这一价格对应的是"全球脱钩"情景下的清算/崩溃估值，概率极低（<3%），但定义了尾部风险的边界。

### 5.2 较现实的悲观支撑位

在"行业景气度回落但非崩溃"的正常下行周期中（如特高压投资节奏放缓、毛利率回落到FY2023水平）：

- 市场给予保守PE 30x（接近FY2024-2025年均值低点）

## 六、模块六核心结论（更新至2026-10-08，现价11.79视测）

1. **基准合理市值720亿（14.0元），修正后792亿（15.45元，维持）**。修正主要来自全品类唯一性(+8%)和政策确定性(+5%，H1确认5万亿/+80%)的溢价，部分被ROE折价和地缘风险抵消；维持目标价不调整，估值框架未变。

2. **现价11.79元（2026-10-08）较修正目标价15.45元有约31.0%上行空间（vs上期24.4%），较概率加权目标价15.94元有35.2%上行（vs上期28.3%）**，安全边际较09-08进一步增厚7pp；主要来自股价再回调（-5.1%）带来的被动赔率修复，Forward PE自42.5x压缩至40.4x。

3. **上涨空间取决于两个关键变量**：①业绩超预期（乐观情景EPS 0.35→20.8元目标价，+76.4% vs现价）；②估值中枢上移（若市场接受50x+为电网设备板块新常态，前瞻PE现价40.4x vs目标隐含52.9x）。H1毛利率24.54%+国网H1 3100亿+12.6%为变量①提供支撑，但OCF -2.97亿与铜价111,320元/LME 14,875再破史高为变量②增加不确定性，三季报铜价传导为关键验证。

4. **下行保护边际收窄但PE安全垫增厚**：若行业景气度回落至FY2023水平，合理价格仅5.3元（vs现价-55.0%）。Forward PE 40.4x（vs上期42.5x）再压缩2.1x，戴维斯双杀空间仍大但估值风险边际缓释。

5. **盈亏比自1.34修复至2.09（框架口径，已越过1.5高赔率阈值）→ 赔率进入可重仓区间**。现价11.79已跌破年线13.04（MA250 raw）约9.6%进入超卖，左侧关注11.60-11.79支撑与11.48前低，右侧确认需放量收复12.14（MA20 raw）→12.86（MA60）→13.04（年线），技术破位但赔率极优形成“估值底”与“技术底”背离。
