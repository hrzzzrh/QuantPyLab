## 三、量价行为解读

### 3.1 最近15个交易日量价特征

| 指标 | 当前值 | 解读 |
| :--- | ---: | :--- |
| 7月29日成交量 | 214.21万手 | 高于20日均量158.02万手约36%，说明反弹仍有交易热度 |
| 7月24日成交量 | 369.11万手 | 中标公告后的峰值放量，但次日未持续突破14.2元 |
| 7月17日低点 | 不复权11.64元 / HFQ 13.80元 | 恐慌杀跌阶段低点，随后形成技术反弹 |
| 7月27日高点 | 不复权14.20元 / HFQ约16.85元 | 当前第一反压，未突破前仍属低位箱体 |

**量价判断**：
- 7月17日低点之后的反弹有基本面催化配合，不是纯技术超跌反抽；41.29亿元中标公告提升了市场对H2订单兑现的信心。
- 但7月24日放出369万手后，股价没有连续冲过14.20元，显示前期套牢盘在第一反压区兑现。量能越高、价格越无法突破，越说明上方筹码压力仍重。
- 20日均量从6月的高位逐步回落到158万手附近，若后续缩量守住13.0-13.2元，才是健康的二次筑底；若放量跌破13元，则反弹失败。

### 3.2 量价背离判断

**日线级别**：7月下旬股价反弹但尚未收复MA60/MA120，属于"价格先行修复、趋势尚未确认"。若后续股价挑战15.1-15.6元时成交量不能明显放大，容易形成缩量反弹后的二次回落。

**周线级别**：从3月高点以来的周线结构仍是高位回撤，7月中旬触及年线附近后反弹，说明长线资金仍愿意在深度回撤位置承接。但周线要重新转强，至少需要站回不复权15.6元上方并维持两周。

## 四、未来走势演绎

### 4.1 短期走势（1-3个月）

**路径A（最可能，概率45%）——13.0-15.6元箱体修复**
- 股价守住MA20附近（不复权13.05-13.15元），在13.0-15.6元区间反复震荡。
- 订单利好限制下行，但8月20日半年报披露前，资金仍会等待Q2毛利率、合同负债、应收账款验证。
- 标志：成交量回落至120-160万手区间，价格不再跌破13元。

**路径B（概率30%）——放量收复MA60/MA120，趋势修复确认**
- 股价突破14.2元后继续放量，站上15.10-15.60元核心反压。
- 触发因素：半年报确认Q2营收增速加快、毛利率维持23%+、合同负债重新扩张，或新增特高压大单公告。
- 站稳15.6元后，下一目标为16.9-17.2元。

**路径C（概率25%）——反抽失败，回测年线**
- 跌破13.0元后回踩12.3-12.5元，若仍无法止跌则再次测试11.5-11.7元年线/恐慌低点。
- 触发因素：半年报毛利率低于预期、应收账款继续快速上升、铜价急涨或大盘系统性回撤。

### 4.2 长期走势（6-12个月以上）

**核心判断**：长线牛市结构未被年线击穿，但中线必须重新收复MA120才能恢复进攻性。

MA250当前在HFQ 13.68（折算不复权约11.53元），已经从6月的10.38元明显上移。年线持续上移说明长期趋势仍有惯性，但当前价格距离年线并不远，已不再是6月时"远高于年线、长线安全垫厚"的状态。

若基本面按基准情景兑现（2026E EPS 0.29元），且市场维持45-53x PE：
- 2026年底合理波动区间：**13.1-15.5元（不复权）**
- 若提前交易2027年EPS 0.35+，并且订单兑现形成连续超预期，则可能回到17-20元区间

## 五、技术面综合研判

| 周期 | 趋势 | 关键位（不复权） | 策略含义 |
| :--- | :--- | :--- | :--- |
| 超短期（1-4周） | ↑反抽 | 支撑13.05 / 阻力14.20 | 站稳13元可继续观察，突破14.2元才有二段修复 |
| 短期（1-3月） | →箱体修复 | 区间13.0-15.6 | 中性偏积极，但不追高 |
| 中期（3-6月） | ↓待修复 | MA60/MA120为15.1-15.6 | 未收复前仍属破位后的反弹 |
| 长期（6-12月+） | ↑未破坏 | MA250约11.53 | 年线不破，长线逻辑仍保留 |

**重要提示**：
1. 7月中旬已经有效跌破6月报告中的MA120支撑，旧的"MA120不破仍可看多"条件已经失效，必须等待重新收复15.1-15.6元核心均线区。
2. 7月23日41.29亿元中标公告改变了短线资金情绪，但尚未改变趋势结构；技术面从"弱势下跌"修复为"低位箱体反抽"。
3. 13.0-13.2元是当前最重要的短线防守线，跌破则反抽失败；15.1-15.6元是最重要的右侧确认线，站稳才可提高仓位。
4. 技术面与估值面形成新的平衡：当前13.67元低于15.45元基准目标价，但盈亏比仅0.46，适合观察仓或已有仓位持有，不适合追涨式重仓。
