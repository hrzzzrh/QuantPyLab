### 结构性重大变化

1. **士兰集华出表**：2026年4月增资完成后持股由100%降至29.55%，不再纳入合并报表（公司累计实缴出资15.10亿元）。12英寸高端模拟IC线主体转为权益法核算——未来该线建设期的折旧亏损不再拖累合并报表，但也不再并表其收入。
2. **12英寸模拟IC线总投资确认为200亿元**（一期100亿+二期100亿，两期合计年产54万片；一期2030年全面达产24万片/年）。
3. SiC募投项目（6吋）已于2025年6月结项但"尚未实现盈利"，本年度效益-8,439万元。
4. 担保总额29.11亿元，占净资产23.57%（对士兰集科担保余额6.95亿）。

### H1偏差归因（为什么"涨价周期中利润反而下滑"）

1. **成本先行、传导滞后**：硅片/贵金属/封测材料自2025Q3持续涨价，而3月首轮涨价仅覆盖部分产品且按商务流程分批落地（斯达半导同期表述印证："客户认可行业成本走势，但价格调整需按商务流程推进"）
2. **SiC产线折旧集中释放**：士兰明镓H1亏3.24亿（2025全年约亏4亿量级的节奏前移）
3. **产品结构弱化**：低毛利分立器件占比被动提升+LED毛利率转负（H1为-3.11%）
4. **白电去库压制IPM量价**：8月空调内销排产-24.1%

## 五、跟踪清单（简易操作版）

每次季报后按此清单逐项打钩：

- [ ] 营收YoY是否在基准区间（15-22%）？（H1 +14.62%，略低）
- [ ] 毛利率是否环比改善？（H1 18.56%同比-1.86pct，Q3需回到19.5%+）
- [ ] 扣非增速是否止跌回升？（47.8%→8.8%→0.67%连续衰减，Q3为关键拐点）
- [ ] 7/1涨价是否顺利向下游传导？（Q3毛利率是唯一硬验证）
- [ ] 归母vs扣非常态化差距是否收窄？（H1差2.45亿）
- [ ] 经营现金流是否>净利润？（H1仅0.57x，黄灯）
- [ ] 有息负债是否在可控范围（<100%权益）？
- [ ] IPM出货是否恢复20-30%增速？（H1仅+9%触红灯，Q3-Q4排产修复后观察）
- [ ] SiC产线是否按计划爬坡？（8英寸线7月正式投产、向1万片/月拓展中）
- [ ] 士兰明镓亏损是否收窄？（H1亏3.24亿，SiC衬底价格反弹+器件涨价双利好减亏）
- [ ] 研发费用率是否持续下降？（H1投入口径7.82%，绿灯）
- [ ] 功率半导体第三波涨价是否落地？（台系10月起、ST已第三次调价）
- [ ] 证伪警报是否触发？（见第三节——IPM红灯已亮，但未达"市占率跌破40%"级别证伪）
- [ ] 股价是否跌破MA250（~31.4元）？— 技术面终极防线
- [ ] 46-53元套牢盘是否出现解套迹象？— 反弹空间判断
