## 一、投资摘要（Investment Summary）

### 1.1 公司定性

南网储能（600995.SH）是南方电网旗下唯一的储能上市平台，南方五省区（粤桂滇黔琼）抽水蓄能**100%区域垄断运营商**（在运1268万千瓦，全国#2仅次于国网新源），并运营调峰水电203万千瓦（天生桥二级+鲁布革）与新型储能65.42万千瓦/129.83万千瓦时。商业模式为"容量电费（政府/省级核定保底）+电量电费（现货市场价差）"双轮驱动，属重资产、40年经营期、类特许经营的成长型公用事业。

### 1.2 核心投资逻辑（证据链摘要）

**① 量增确定性（确定性评分4/5，模块五）**：8座在建抽蓄960万千瓦+新丰120万千瓦筹建，投产计划公告锁定（肇庆浪江2026年底首台/2027H1全部、惠州中洞2027年、电白2028H1、广西5座2029年），对应"十五五"末抽蓄2100万千瓦目标（+66%）；在建工程174亿→2026Q1转固44亿（梅蓄二期+南宁）已验证兑现路径。

**② 存量资产政策锁定（模块四）**：114号文（2026年1月）明确7座存量电站（广蓄二期/惠蓄/清蓄/深蓄/海蓄/梅蓄一期/阳蓄一期）继续执行政府定价容量电价（6.5%资本金IRR核价，纳入输配电价回收）——**收入基本盘的政策级确定性**；第二类（9座新电站）省级核价"弥补平均成本"保底+市场收益按比例分享，收益结构"下有保底、上有弹性"。

**③ 成长弹性（确定性3/5）**：南方区域现货市场2025年6月启动连续结算试运行、2026-2027年转正式运行；抽蓄现货价差2025年实证146厘/千瓦时（梅蓄一期电能量净收益约0.83亿元）——2026年梅蓄二期+南宁入市后现货收益放大至1.5-2.5亿元级；新型储能获国家层面容量电价机制（114号文），"十五五"末500万千瓦目标提供第二曲线。

**④ 财务验证（模块一）**：2025年营收73.77亿（+19.5%）、归母16.89亿（+49.9%）、ROE 7.66%、OCF 46.2亿（OCF/净利2.7x）；**2026H1快报营收41.20亿（+24.8%）、归母11.67亿（+40.3%，创同期新高）**；毛利率50.8%，应收账款/营收≈0（电网直结零坏账），费用率下行（期间费用率8.9%→8.5%）。

## 三、研究结论象限图（Final Evaluation Matrix）

**定位：第三象限（Defensive Value）偏第一象限边界——"高确定性 + 中等预期收益"**

```
预期收益空间（中性目标价较现价）
        ▲
  高   │ ① Strong Buy     ● 第一象限边界(现价12.87)
       │                   (中性+18.1% / 盈亏比0.94)
       │      ② Speculative
       │
  中 ──┼───────────────────────► 确定性
       │   ③ Defensive ★
       │      ④ Avoid
  低   │
```

**判断依据：**
- **确定性维度（高）**：区域垄断特许经营权（制度性壁垒）+存量容量电价政策锁定（114号文）+装机扩张路径公告锁定（4/5确定性评分）+2026H1业绩+40%已兑现——公司是全A股对"容量电价机制"暴露最纯正、确定性最清晰的储能运营商；
- **预期收益维度（中等）**：中性目标价+18.1%、盈亏比0.94——赔率不足以支撑"强烈买入/核心重仓"（盈亏比>2），主要约束为：①股息率仅1.3%（2025年度分红率32%），红利属性弱，估值缺乏股息锚；②第二类核价与现货价差两大单变量尚未落地，估值弹性被政策不确定性压制；
- **操作含义**：作为**底仓型防御配置**（5-10%仓位）持有，11.5-12.5元分批加仓，13.4元（MA60）放量突破后右侧确认增持；若两省核价落地且价差企稳（催化兑现），象限定位上移至第一象限，盈亏比有望修复至2以上。
