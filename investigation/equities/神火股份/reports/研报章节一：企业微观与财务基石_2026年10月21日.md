## 一、企业业务画像

神火股份（000933.SZ）是一家典型的 **"煤电铝一体化"** 综合资源型企业，主营业务横跨电解铝、煤炭和铝箔深加工三大板块。截至2025年12月31日：

| 业务板块 | 产能规模 | 运营主体 | 核心特征 |
|---------|---------|---------|---------|
| 电解铝 | **170万吨/年** | 新疆煤电（80万吨）+ 云南神火（90万吨） | 新疆低成本煤电 + 云南绿电水电 |
| 煤炭 | **855万吨/年核定产能** | 永城矿区（345万吨）+ 许昌/郑州矿区（510万吨） | 无烟煤/贫瘦煤，保有储量 12.93亿吨 |
| 铝箔 | **14万吨/年** | 神火新材（11.5万吨电池箔）+ 上海铝箔（2.5万吨包装箔） | 电池箔出货 Q1 同比+200% |
| 阳极炭块 | **80万吨/年** | 新疆炭素（40万吨）+ 云南炭素（40万吨） | 完全自给，配套产业链 |
| 电力 | **1,400MW 装机** | 新疆4×350MW燃煤机组 | 自发自用，孤网运行 |

### 1.1 电解铝业务：双基地格局的深度优势

公司的核心盈利来源是电解铝。170万吨产能位列全国第六，战略性地布局在中国成本最低的两个极点：

**新疆基地（80万吨）**：位于准东煤田腹地，自建4×350MW燃煤机组，孤网运行，配套40万吨阳极炭块。吨铝电力成本仅约1,215-1,755元（煤价极低区域），是中国电解铝成本最具竞争力的单一产地。2025年报披露，公司与中电国际合作建设的80万KW风电项目已实现首期并网，将进一步提升绿电比例、降低碳风险敞口。

**云南基地（90万吨）**：全部采用水电直供，已通过全国首批绿电铝产品评价。所在富宁县距氧化铝主产地广西百色仅120余公里，且紧邻华南铝消费市场。丰水期吨铝电费约4,300-4,700元，成本竞争力与新疆煤电铝接近。但枯水期（11月-次年4月）成本显著上升，存在限产风险。

### 1.2 煤炭业务：现金流压舱石

公司拥有855万吨煤炭核定产能，煤种以无烟煤和贫瘦煤为主，具备低硫、低磷、高发热量等品质优势。2025年煤炭行业供过于求，煤价整体下行，但公司矿区成本优势明显，仍保持正向盈利贡献。更为关键的是，新疆基地的煤炭资源优势直接转化为电解铝的电力成本优势——输煤皮带走廊从矿区直达电厂，煤价在成本端被压制至极低水平。

### 1.3 铝箔业务：高附加值延伸

公司铝箔业务正处于产能快速爬坡期。神火新材电池铝箔产能已达11.5万吨/年，2026Q1出货量同比暴增200%至1.2万吨，毛利率超35%，远高于电解铝主业的20-23%。铝箔业务的成长性是公司从纯周期性标的向"周期+成长"转型的关键观察变量。

### 2.2 利润波动归因：铝价是核心驱动变量

神火股份的利润呈现典型的大宗商品周期波动特征。2022年为利润峰值（75.8亿），对应LME铝均价约3,000美元/吨、国内铝价约22,000元/吨；2023-2024年随着铝价中枢回落至19,000-20,000元/吨，归母净利润从75.8亿降至43.1亿。

**2025年的特殊现象**：营业收入同比增长7.5%至412.4亿，但归母净利润反而下降7.0%至40.1亿。核心原因是毛利率从21.2%（2024）仅小幅恢复至23.4%（2025），而2024年有大量非经常性收益（资产处置收益约2.87亿）形成了利润的"虚高"。扣非净利润仅微降0.94%，表明真实经营利润已企稳。

**2026Q1的爆发性转折**：Q1归母净利润22.9亿（+223.3% YoY），毛利率飙升至33.48%（+18.56pct YoY）。这是"量价齐升+成本下行"三重共振的结果：
1. 铝价中枢上移：Q1国内铝均价约24,100元/吨（vs 2025Q1约19,000元/吨）
2. 电解铝产量增长：Q1产量58.3万吨，同比+15%
3. 氧化铝价格下行：产能严重过剩带动原料成本下降
4. 电池箔放量：高毛利产品占比提升

**2026年三季报验证（10-20披露，公告2026-059）**：前三季度归母净利 74.87亿（+114.54%）、扣非 74.84亿（+109.10%）、基本EPS 3.383元、加权ROE 27.42%（+12.08pct）；Q3单季归母 27.05亿（同比+70.66%、环比+8.55%），较 10-12 业绩预告（9M 74.00-74.10亿）超出上限约0.77亿。**关键在于：该业绩是在Q3单季计提 4.13亿资产减值（新密市超化煤矿崔岗井田，减少归母净利约2.10亿）之后实现的，扣非与归母仅差 262 万元（74.87 vs 74.84 亿），利润质量极高。** TTM归母净利升至 80.02亿，再创历史新高。

**利润归属结构的关键变化**：9M净利润 93.43亿，其中少数股东损益 18.57亿（+152.09%），占比达 19.9%（2025年同期 17.4%）。公司说明为控股子公司云南神火铝业盈利能力大幅增强——神火股份仅持股 58.25%（另41.75%由神火集团30.20%、文山州财信8.25%、央企扶贫基金3.30%持有；神火集团已将表决权委托给上市公司，表决权合计88.45%）。**这意味着云南基地盈利越强，归母口径的"漏损"越大**，是评估2027E归母净利时不可忽略的结构性因素。

## 三、资产负债表：一场史诗级的去杠杆

神火股份在过去五年完成了令人瞩目的资产负债表修复，从高杠杆的"债务陷阱"蜕变为财务健康的"现金牛"。

### 3.2 去杠杆路径：以现金流偿还债务，用利润增厚权益

过去五年的总负债从482.1亿降至206.1亿，绝对降幅**276亿**。同期归母权益从69.8亿增至245.7亿，增长252%。资产负债率从79.5%降至42.2%——这在A股资源类上市公司中极为罕见。

**偿债资金来源**：五年累计经营活动现金流净额约531亿（2021-2025加总），同期累计归母净利润约251亿。这意味着公司产生了**远超利润的现金流**（OCF/NP≈2.1x），为大规模偿债提供了坚实基础。

**财务费用的断崖式下降**：从2020年的14.2亿降至2025年的0.9亿，降幅达94%。仅此一项，每年释放税前利润超过13亿，相当于当前市值的约2.7%。

在建工程合计从2024年的17.0亿降至2025年的6.4亿后小幅回升至2026/9/30的8.13亿，仍属轻资本开支状态（9M购建长期资产支付现金仅3.21亿，同比-47.85%，公司口径为云南炭素40万吨与云南新材11万吨铝箔坯料项目已于上年转固），未来自由现金流改善与分红提升的空间未被侵蚀。

**核心认知**：
1. **OCF始终为正且绝对规模可观**：2026年9M已达111.12亿（+61.09%），超过2025年全年87.4亿。这主要得益于高额折旧（重资产行业特性）的加回与盈利绝对额的跃升。
2. **OCF/归母净利降至1.48x（2025年2.18x）**：并非盈利质量恶化，而是分母（净利润）增长快于经营现金流；同时 9M 期货保证金累计净流出 3.45 亿（支付 13.83 亿 / 收回 10.38 亿，其中 Q3 单季约 2.08 亿）与应收账款 +44.34%、应收款项融资 +191.46% 占用了部分营运资金。**这是高盈利年份的典型特征，需在Q4观察应收回收节奏**。
3. **筹资现金流大幅收敛至-1.57亿**：去杠杆工程已基本完成，筹资端从"净偿还"转为"净平衡"，同时分配股利/偿付利息支付24.17亿（+42.07%）。**这意味着公司现金配置重心已从还债转向分红与留存，为分红率提升至50-60%提供了现金流基础**。
4. **投资现金流温和（-4.99亿）**：9M资本开支仅3.21亿，公司已进入"现金回收"阶段。

- PE TTM 7.13x（TTM 80.02亿，三季报已计入Q3 27.05亿），**低于P50 7.99x、位于P25 6.28x与P50之间**，较10-14的8.68x显著下移。下移由"分母扩张+分子收缩"双向驱动：TTM净利从68.82→80.02亿（+16.3%），股价从26.55→25.38（-4.4%）。**这意味着三季报的盈利超预期并未被市场定价，估值反而被动压缩**。
- PB 1.88x（较10-14的2.16x下降0.28x），**仅高于5年P5 1.84x、低于P25 2.22x**，处于近5年最低区间（5年最低1.73x）。归母权益303.40亿较年初+23.5%，PB下行完全由股价与权益的剪刀差造成。
- 前瞻PE：按2026E Base 95亿为6.01x；按2027E Base 80亿为7.13x、Bear 40亿为14.3x、Bull 107亿为5.34x。**Base口径处于历史底部区域（P25 6.28x以下）**。

## 六、利润分配与股东回报

2025年分红方案：每10股派发现金红利**8.00元**（含税），对应总分红约**17.99亿元**，占当年归母净利润（40.05亿）的**44.9%**。以10-21收盘25.38元计算，**股息率约3.15%**。

若以2026年前三季度归母净利74.87亿、全年Base约95亿为基准，按44.9%派息率测算2026年度分红约42.7亿，对应动态股息率约**7.5%**；即便分红率维持44.9%不变，**2026年股息率也将较2025年翻倍**。公司偿债高峰已过（有息负债结构由长转短，短债覆盖率142%、全部有息负债覆盖率123%）、9M资本开支仅3.21亿，预计2026-2027年分红比例有望提升至50-60%，对应动态股息率约8.4-10.0%（按95亿基数）——**这是当前PB 1.88x、PE 7.13x估值下最硬的价值支撑**。

## 七、财务亮点与潜在风险点

### 7.1 财务亮点
1. **去杠杆的史诗级完成度**：D/A从79.5%（2020）→40.8%（2026/9/30），财务费用9M仅0.79亿（同比-39.78%，Q3单季已转负为-0.05亿，即利息收入超过利息支出），近年财务费用释放超过13亿/年
2. **2026年9M利润再超预期**：归母74.87亿（+114.54%），超过业绩预告上限；Q3单季27.05亿创历史单季新高，且是在计提4.13亿资产减值后实现
3. **经营现金流质量高但在高盈利年边际回落**：9M OCF 111.12亿（+61.09%），**OCF/归母 1.48x、OCF/合并净利润 1.19x**（2025年 OCF/归母 2.18x），主因净利增速更快与保证金/应收占用
4. **毛利率自2025Q4起连续四季改善（单季口径）**：2025Q4 23.9%→2026Q1 33.5%→2026Q2 38.9%→**2026Q3 39.0%**（2025 年单季依次为 14.9%→24.4%→29.4%→23.9%，2025Q4 曾环比回落，故"连续五季改善"不成立，全文已统一为单季口径）
5. **分红能力质变**：9M货币资金148.5亿、资本开支3.21亿、筹资端已由净偿还转为净平衡，2026年度分红金额有望较2025年翻倍以上

### 7.2 潜在风险点
1. **利润高度依赖铝价**：铝价每变动1,000元/吨，年化归母净利影响约11-12亿（理论值11.3亿，已扣增值税、所得税与少数股东；敏感性测算详见章节二）
2. **年末计提的季节性风险仍在**：2025Q4归母仅5.2亿（全年减值12.56亿），2026Q3已提前计提4.13亿（崔岗井田），Q4是否继续计提煤炭板块减值需跟踪
3. **云南枯水期限产风险**：11月-次年4月云南基地90万吨产能面临限电减产，2026年超强厄尔尼诺背景下减产幅度可能高于基准10%
4. **煤炭价格10月已转弱**：Q3永城无烟精煤均价1,708元/吨（环比+37.5%）、许昌瘦煤1,890元/吨（+24.0%），但10月中旬现货分别回落至1,580元/吨（-2.5%）与2,020元/吨（-10.2%），**Q4煤炭板块贡献将环比回落**
5. **少数股东分流加剧**：少数股东损益占净利润19.9%（9M），云南神火41.75%的少数股权结构使归母口径无法完全享受云南基地盈利弹性
6. **期货保证金占用上升**：Q3 单季保证金净流出约 2.08 亿（支付 3.39 亿 / 收回 1.31 亿；9M 累计净流出 3.45 亿），需关注套保规模扩大对现金流的持续影响

## 八、小结：财务底色的核心判断

神火股份在财务层面呈现出一幅 **"资产负债表修复已完成 + 盈利爆发已连续三季度验证 + 估值被动压缩"** 的图景：

1. 五年的去杠杆工程使公司面貌一新，从高风险的"债务陷阱"蜕变为财务健康的现金牛企业。2026年9月末资产负债率进一步降至40.8%，归母权益303.40亿较年初+23.5%，BVPS升至13.49元。
2. 2026年9M的盈利爆发（74.87亿，+114.54%）不是单一季度的偶然，而是铝价上行周期、成本红利（氧化铝2,744元/吨低位）和煤价回升（Q3环比+24%至+37.5%）三重共振的结果，且Q3是在计提4.13亿减值的前提下创出单季新高。**9M扣非74.84亿与归母74.87亿几乎完全一致，说明这一轮利润几乎没有依赖非经常性损益**。
3. 电池箔等深加工业务的放量为公司从"纯周期"向"周期+成长"转型提供了增量叙事，但当前利润结构中电解铝仍占绝对主导。
4. 当前 PE 7.13x（5年P50 7.99x下方）/ PB 1.88x（逼近5年P5 1.84x）与三季报超预期形成明显背离——**盈利上修未被定价，估值被进一步压缩至近5年低位区**。这一背离的修复取决于市场是否愿意为2027年供给拐点之前的"最后一个高盈利年度"付钱，需结合行业周期位置（详见模块二）与2027年供给拐点风险（详见模块六）综合判断。
