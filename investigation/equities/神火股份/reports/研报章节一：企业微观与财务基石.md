## 一、企业业务画像

神火股份（000933.SZ）是一家典型的 **"煤电铝一体化"** 综合资源型企业，主营业务横跨电解铝、煤炭和铝箔深加工三大板块。截至2025年12月31日：

| 业务板块 | 产能规模 | 运营主体 | 核心特征 |
|---------|---------|---------|---------|
| 电解铝 | **170万吨/年** | 新疆煤电（80万吨）+ 云南神火（90万吨） | 新疆低成本煤电 + 云南绿电水电 |
| 煤炭 | **855万吨/年核定产能** | 永城矿区（345万吨）+ 许昌/郑州矿区（510万吨） | 无烟煤/贫瘦煤，保有储量 12.93亿吨 |
| 铝箔 | **14万吨/年** | 神火新材（11.5万吨电池箔）+ 上海铝箔（2.5万吨包装箔） | 电池箔出货 Q1 同比+200% |
| 阳极炭块 | **80万吨/年** | 新疆炭素（40万吨）+ 云南炭素（40万吨） | 完全自给，配套产业链 |
| 电力 | **1,400MW 装机** | 新疆4×350MW燃煤机组 | 自发自用，孤网运行 |

### 1.1 电解铝业务：双基地格局的深度优势

公司的核心盈利来源是电解铝。170万吨产能位列全国第六，战略性地布局在中国成本最低的两个极点：

**新疆基地（80万吨）**：位于准东煤田腹地，自建4×350MW燃煤机组，孤网运行，配套40万吨阳极炭块。吨铝电力成本仅约1,215-1,755元（煤价极低区域），是中国电解铝成本最具竞争力的单一产地。2025年报披露，公司与中电国际合作建设的80万KW风电项目已实现首期并网，将进一步提升绿电比例、降低碳风险敞口。

**云南基地（90万吨）**：全部采用水电直供，已通过全国首批绿电铝产品评价。所在富宁县距氧化铝主产地广西百色仅120余公里，且紧邻华南铝消费市场。丰水期吨铝电费约4,300-4,700元，成本竞争力与新疆煤电铝接近。但枯水期（11月-次年4月）成本显著上升，存在限产风险。

### 1.2 煤炭业务：现金流压舱石

公司拥有855万吨煤炭核定产能，煤种以无烟煤和贫瘦煤为主，具备低硫、低磷、高发热量等品质优势。2025年煤炭行业供过于求，煤价整体下行，但公司矿区成本优势明显，仍保持正向盈利贡献。更为关键的是，新疆基地的煤炭资源优势直接转化为电解铝的电力成本优势——输煤皮带走廊从矿区直达电厂，煤价在成本端被压制至极低水平。

### 1.3 铝箔业务：高附加值延伸

公司铝箔业务正处于产能快速爬坡期。神火新材电池铝箔产能已达11.5万吨/年，2026Q1出货量同比暴增200%至1.2万吨，毛利率超35%，远高于电解铝主业的20-23%。铝箔业务的成长性是公司从纯周期性标的向"周期+成长"转型的关键观察变量。

### 2.2 利润波动归因：铝价是核心驱动变量

神火股份的利润呈现典型的大宗商品周期波动特征。2022年为利润峰值（75.8亿），对应LME铝均价约3,000美元/吨、国内铝价约22,000元/吨；2023-2024年随着铝价中枢回落至19,000-20,000元/吨，归母净利润从75.8亿降至43.1亿。

**2025年的特殊现象**：营业收入同比增长7.5%至412.4亿，但归母净利润反而下降7.0%至40.1亿。核心原因是毛利率从21.2%（2024）仅小幅恢复至23.4%（2025），而2024年有大量非经常性收益（资产处置收益约2.87亿）形成了利润的"虚高"。扣非净利润仅微降0.94%，表明真实经营利润已企稳。

**2026Q1的爆发性转折**：Q1归母净利润22.9亿（+223.3% YoY），毛利率飙升至33.48%（+18.56pct YoY）。这是"量价齐升+成本下行"三重共振的结果：
1. 铝价中枢上移：Q1国内铝均价约24,100元/吨（vs 2025Q1约19,000元/吨）
2. 电解铝产量增长：Q1产量58.3万吨，同比+15%
3. 氧化铝价格下行：产能严重过剩带动原料成本下降
4. 电池箔放量：高毛利产品占比提升

2. **毛利率从14.9%到33.5%的V型反转**：2025Q1毛利率触底至14.9%后连续四个季度改善，2026Q1达到33.5%，反映了铝价回升与成本下降的双重红利。
3. **季度波动幅度巨大**：单季净利从最低5.2亿到最高22.9亿，波动幅度高达4.4倍，体现了大宗商品周期股的固有特征。

## 三、资产负债表：一场史诗级的去杠杆

神火股份在过去五年完成了令人瞩目的资产负债表修复，从高杠杆的"债务陷阱"蜕变为财务健康的"现金牛"。

### 3.2 去杠杆路径：以现金流偿还债务，用利润增厚权益

过去五年的总负债从482.1亿降至206.1亿，绝对降幅**276亿**。同期归母权益从69.8亿增至245.7亿，增长252%。资产负债率从79.5%降至42.2%——这在A股资源类上市公司中极为罕见。

**偿债资金来源**：五年累计经营活动现金流净额约531亿（2021-2025加总），同期累计归母净利润约251亿。这意味着公司产生了**远超利润的现金流**（OCF/NP≈2.1x），为大规模偿债提供了坚实基础。

**财务费用的断崖式下降**：从2020年的14.2亿降至2025年的0.9亿，降幅达94%。仅此一项，每年释放税前利润超过13亿，相当于当前市值的约2.7%。

**核心认知**：
1. **OCF始终为正且绝对规模可观**：即使在利润最低的2025年仍产生87.4亿经营现金流，是当期净利润的2.18倍。这主要得益于高额折旧（重资产行业特性）的加回。
2. **筹资现金流连续五年大幅净流出**：累计净偿还/分红约492亿，是去杠杆工程的直接体现。
3. **投资现金流温和**：年均CAPEX约15-20亿，低于折旧水平，表明公司已过了高速投资扩张期，进入"现金回收"阶段。
4. **OCF/Rev在2024-2025年降至0.20**：主要因煤炭业务盈利能力下滑和营运资金占用增加。

## 六、利润分配与股东回报

2025年分红预案：每10股派发现金红利**8.00元**（含税），对应总分红约17.9亿元，占当年归母净利润的44.6%。以当前股价21.35元计算，**股息率约3.75%**。

若以2026Q1 TTM净利润55.9亿为基准，分红派息率仅32%，未来存在提升空间。公司偿债高峰已过（短债从220亿降至46亿），预计2026-2027年分红比例有望提升至50-60%。

## 七、财务亮点与潜在风险点

### 7.1 财务亮点
1. **去杠杆的史诗级完成度**：D/A从79.5%→42.2%，释放财务费用13亿+/年
2. **2026Q1利润大爆发**：净利润+223%，毛利率回升至33.5%，TTM年化净利润达55.9亿
3. **经营现金流质量极高**：OCF/NP长期在1.8-3.5x，股息支付有坚实基础
4. **电池箔业务加速放量**：Q1出货量+200%，毛利率35%+，贡献结构性成长元素
5. **在建工程大幅收缩**：CAPEX压力减弱，未来自由现金流预期大幅改善

### 7.2 潜在风险点
1. **利润高度依赖铝价**：任何超过10%的铝价下跌将显著侵蚀单季利润（敏感性：铝价每变动1,000元/吨，年化利润影响约12-15亿）
2. **Q4利润"塌陷"提示盈余管理风险**：2025Q4仅5.2亿净利润，远低于Q3的15.9亿，需关注是否存在隐藏的资产质量风险
3. **云南枯水期限产风险**：每年11月-次年4月，云南基地90万吨产能面临限电减产可能，影响量约10-15万吨/年
4. **煤炭业务持续承压**：2025年煤价整体下行，煤炭板块利润贡献在缩水
5. **货币资金降至低位**：30.2亿现金覆盖度不高，对突发性大额支出（环保改造、资产减值等）的缓冲能力有限

## 八、小结：财务底色的核心判断

神火股份在财务层面呈现出一幅 **"周期底部的资产负债表修复已完成 + 盈利拐点已现"** 的图景：

1. 五年的去杠杆工程使公司面貌一新，从高风险的"债务陷阱"蜕变为财务健康的现金牛企业。
2. 2026Q1的盈利爆发不是单一季度的偶然，而是铝价上行周期、成本红利（氧化铝降价）和量增（产量+15%）三重共振的结果。TTM净利润已突破55.9亿，超过任何过往年份。
3. 电池箔等深加工业务的放量为公司从"纯周期"向"周期+成长"转型提供了增量叙事。
4. 当前PE 8.6x / PB 1.79x 处于历史估值低位区域，但需结合行业周期位置（详见模块二）综合判断。

> **后续模块需回应的关键问题**：铝价高位的可持续性（模块二）、新疆/云南双基地的竞争壁垒持久性（模块三）、碳政策对绿电铝的成本溢价影响（模块四），以及基于上述判断的盈利预测模型（模块五）。
