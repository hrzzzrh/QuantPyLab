# 研报章节五：增长驱动与盈利预测

**研究日期**：2026年08月28日
**研究对象**：杭州天地数码科技股份有限公司（300743.SZ）
**目标年份**：2026年（当前为Q3，锚定当年EPS，H1已披露重审）

## 一、核心增长驱动力解构

### 1.1 驱动力一：中高端产能释放——维森二期投产 [E1][E7]

**【证据链】**

| 时间节点 | 事件 | 确定性 |
|:---|:---|:---|
| 2022年 | 收购安徽维森100%股权 | 已完成 |
| 2023-2024年 | 维森一期技改（1.5→5.6亿平米） | 已完成 |
| 2025年 | 二期项目建设（主体完工+设备安装调试） | 已完成 |
| 2026年2月 | 取得排污许可证，进入试生产 | **已实现** |
| 2026年02月28日 | 达预定可使用状态并转固 | **已实现（H1效益-4.9万亏损）** |
| 2026年H2 | 产能爬坡期 | **进行中（验证中）** |

维森二期规划产能2.3亿平米，专注TTO高速边压碳带（中高端）。H1已转固但**效益-4.9万亏损**，证明处于爬坡初期。

**销量（Q）预测（重审下修）**：
- 原假设35%利用率≈0.8亿平米，H1未见贡献，现下修至**全年20-30%利用率≈0.46-0.69亿平米**（取中值0.58亿）
- 2025年总销量18.93亿平米，2026年H1推算销量约10.2亿平米（营收4.78亿/ASP 4.67），自然增长约5%（约0.95亿）
- **2026年总销量预测：18.93 + 0.95 + 0.58 = 20.46亿平米**（+8.1%，前20.7亿）

**确定性评分：4→3分（中高→中等）**
已转固但H1亏损证实爬坡慢于预期，下修确定性。

### 1.2 驱动力二：CALOR/RTT全年并表贡献 [E6]

2025年2月28日完成对德国CALOR和法国RTT的收购（对价594万欧元），2025年仅并表10个月。2026年将实现全年并表。

**收入增量估算**：
- 2025年CALOR+RTT并表收入估计约0.3-0.5亿（10个月）
- 2026年全年收入估计：0.4-0.6亿
- 增量贡献：**约0.1-0.2亿**

这部分收入主要来自彩色碳带和欧洲本地化服务，毛利率预计在35-40%，高于公司平均水平。

**确定性评分：4分（高）**
已完成交割，团队和产线已就位。

### 1.3 驱动力三：新兴市场渠道扩张 [E7]

2025年新增新加坡、印尼子公司。越南子公司（2023年设立）和泰国子公司（2024年设立）仍处于早期爬坡阶段。

**收入增量估算**：
- 越南+泰国+新加坡+印尼四国的渠道收入：2025年估计约0.3-0.5亿
- 2026年在低基数上实现高增长（50-100%）：增量约**0.2-0.4亿**

**确定性评分：3分（中等）**
方向确定（东南亚制造业扩张带来增量需求），但收入规模爬升节奏存在不确定性。

### 1.4 驱动力四：产品结构升级（混合基/树脂基占比提升） [E2][E3]

根据行业数据，蜡基碳带ASP约2-3元/平米，混合基约5-8元/平米，树脂基约10-15元/平米。维森二期和CALOR/RTT的产品均为中高端碳带，天然推升ASP。

2025年天地数码ASP（按总营收/总销量）：8.85亿/18.93亿平米 = **4.67元/平米**。这一ASP在行业中处于中低水平（大量蜡基产品拉低均值），隐含的混合基+树脂基占比可能仅25-30%。随着维森产能释放和产品升级，ASP有望温和提升。

**ASP预测**：
- 保守情景：ASP维持4.67元/平米（竞争加剧，价格承压）
- 基准情景：ASP升至4.75元/平米（结构优化+1.7%）
- 乐观情景：ASP升至4.85元/平米（中高端放量+3.9%）

**确定性评分：3分（中等）**
方向明确但速度取决于市场开拓进度。

### 1.5 驱动力五：成本端改善（预期证伪→恶化） [E3][E8]

**H1证伪**：2026H1营业成本+15.65% >营收+10.97%，BOPET 8/26持稳微涨（+80元/吨）、Brent 87-91美元高位（+38% YoY），与“Q2起回落”预期相反。条码碳带毛利率31.47%（-2.85pp）、H1综合30.39%（-2.82pp）连续下行。

**毛利率重估**：
- H1 30.39%已低于2025年32.0%、Q1 30.56%，H2若维持30-31%则全年约30.4-30.5%
- 原“修复至31-33%”**下修至30-31%区间**，较基准-1.0pp

**确定性评分：3→2分（中等→偏低）**
由“改善驱动”转为“压制因子”，趋势逆转。

## 三、多态逻辑情景推演

### 3.1 保守情景（Bear Case，概率30%↑，原25%）

**触发条件（H1部分兑现）**：原油维持85-90高位→毛利率29-30%；维森爬坡<20%→新增产能贡献不足；人民币维持升值+费用率高企。

| 参数 | 保守值（重审） | vs新基准 |
|:---|:---|:---|
| 营收(亿) | 9.55 | -2.7% |
| 毛利率 | 29.5% | -0.95ppt |
| 费用率（含汇兑） | 18.3% | +0.8ppt |
| **净利润(亿)** | **1.03** | **-12.7%** |
| **扣非(亿)** | **0.80** | -15.8% |
| **EPS(元)** | **0.68** | -12.8% |
| **YoY净利润增速** | **-4.6%** | 微下滑 |

**情景特征**：由“大幅下滑”修正为“微下滑”，因H1已兑现部分悲观但营收韧性超预期；即便保守，仍靠非经常性支撑不至崩塌，但扣非-18.6%揭示主业萎缩。

### 3.2 基准情景（Base Case，概率45%↓，原50%）

参数见上文P*Q模型，EPS = **0.78元**（前0.84元，-7.1%），扣非0.95亿（-3.1% YoY，增收不增利）。

**情景特征**：维森爬坡20-30%、毛利率30.4%、费用率抬升+汇兑损失，净利润+9.3%但扣非转负，主业与报表背离。

### 3.3 乐观情景（Bull Case，概率25%维持）

**触发条件（门槛提高）**：维森爬坡>30%且Q3验证、Brent回落至<85+BOPET跌5%以上→毛利率32%+、费用率回落至17%以下。

## 八、模块五结论摘要

H1后“产能释放+成本改善”**证伪为“产能爬坡迟滞+成本汇兑双压”**。基准下修至营收9.82亿（+11.0%）、净利润1.18亿（+9.3%，-7.1% vs 07-02）、EPS 0.78元（-7.1%）、扣非0.95亿（-3.1% YoY，增收不增利）。核心驱动由维森二期（4→3分）与原材料（3→2分，负贡献）双降，整体确定性3.5→3.0。加权EPS 0.775元（-7.7%）。保守1.03亿（EPS 0.68，-4.6% YoY）概率上调至30%（H1部分兑现），乐观1.34亿（EPS 0.88）需Brent<85+汇兑企稳才触发。H2验证焦点：维森爬坡≥30%利用率与毛利率能否守住30%。
