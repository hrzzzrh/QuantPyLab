# 研报章节五：增长驱动与盈利预测

**研究日期**：2026年10月13日
**研究对象**：杭州天地数码科技股份有限公司（300743.SZ）
**目标年份**：2027年（Q4切换期，锚定次年EPS，框架§1.5估值锚点切换条款）

---

## 一、核心增长驱动力解构（2027E视角）

### 1.1 驱动力一：维森二期全年贡献——爬坡兑现 [E1][E7]

**【证据链】**

| 时间节点 | 事件 | 确定性 |
|:---|:---|:---|
| 2022年 | 收购安徽维森100%股权 | 已完成 |
| 2023-2024年 | 维森一期技改（1.5→5.6亿平米） | 已完成 |
| 2025年 | 二期项目建设（主体完工+设备安装调试） | 已完成 |
| 2026年2月 | 取得排污许可证，进入试生产 | **已实现** |
| 2026年02月28日 | 达预定可使用状态并转固 | **已实现（H1效益-4.9万亏损）** |
| 2026年H2 | 产能爬坡期 | **进行中（验证中）** |
| **2027年全年** | **二期产能全年贡献** | **关键增量** |

维森二期规划产能2.3亿平米，专注TTO高速边压碳带（中高端）。2026H1已转固但效益-4.9万亏损，证明处于爬坡初期。**2027年为二期首个完整年度**，若爬坡顺利，将贡献显著增量。

**销量（Q）预测**：
- 2026年总销量预测20.46亿平米（+8.1%）
- 2027年假设维森二期利用率提升至40-60%（0.92-1.38亿平米），叠加自然增长5%
- **2027年总销量预测：20.46 + 1.0~1.4 + 1.0 = 22.5~22.9亿平米**（取中值22.7亿，+11.0%）

**确定性评分：3分（中等）**
已转固但2026H1亏损证实爬坡慢于预期，2027年全年贡献取决于H2爬坡速度。**若爬坡不及预期（利用率<30%）**：销量增量仅0.46-0.69亿平米，营收增量约0.23-0.34亿，EPS影响约-0.03~-0.05元，触发保守情景。

### 1.2 驱动力二：CALOR/RTT全年并表+彩色碳带放量 [E6]

2025年2月28日完成对德国CALOR和法国RTT的收购（对价594万欧元），2025年仅并表10个月，2026年全年并表。2027年彩色碳带全链条打通后，产品矩阵进一步完善。

**收入增量估算**：
- 2026年全年收入估计：0.4-0.6亿
- 2027年假设彩色碳带渗透率提升，收入增至0.6-0.8亿
- 增量贡献：**约0.1-0.2亿**

**确定性评分：4分（高）**
已完成交割，团队和产线已就位，2027年为第三个完整年度。

### 1.3 驱动力三：新兴市场渠道扩张+UDI合规红利 [E7][E10]

2025年新增新加坡、印尼子公司。越南子公司（2023年设立）和泰国子公司（2024年设立）仍处于早期爬坡阶段。**2027年6月1日UDI全部二类器械强制赋码**，树脂基碳带需求加速。

**收入增量估算**：
- 越南+泰国+新加坡+印尼四国的渠道收入：2026年估计约0.5-0.7亿
- 2027年在低基数上实现高增长（30-50%）：增量约**0.2-0.4亿**
- UDI合规带动树脂基碳带需求，2027-06-01后加速

**确定性评分：3分（中等）**
方向确定（东南亚制造业扩张+UDI合规），但收入规模爬升节奏存在不确定性。

### 1.4 驱动力四：产品结构升级（混合基/树脂基占比提升） [E2][E3]

根据行业数据，蜡基碳带ASP约2-3元/平米，混合基约5-8元/平米，树脂基约10-15元/平米。维森二期和CALOR/RTT的产品均为中高端碳带，天然推升ASP。

2025年天地数码ASP（按总营收/总销量）：8.85亿/18.93亿平米 = **4.67元/平米**。随着维森产能释放和产品升级，ASP有望温和提升。

**ASP预测**：
- 保守情景：ASP维持4.80元/平米（竞争加剧，价格承压）
- 基准情景：ASP升至4.90元/平米（结构优化+2.1%）
- 乐观情景：ASP升至5.00元/平米（中高端放量+4.3%）

**确定性评分：3分（中等）**
方向明确但速度取决于市场开拓进度。

### 1.5 驱动力五：成本端——EIA预测2027年油价回落 [E8][E11]

**关键证据**：EIA 2026年10月STEO预测2027年Brent原油均价**$69.39/桶**（vs 2026年预测$86.81），降幅约20%。若兑现，将显著缓解石化原材料成本压力。

**2026H1回顾**：Brent 87-91美元高位（+38% YoY），BOPET持稳微涨，营业成本+15.65% >营收+10.97%，毛利率30.39%（-2.82pp）。

**2027E成本假设**：
- 保守：Brent维持$85+，毛利率29.5%（成本仍高位）
- 基准：Brent回落至$70-75，毛利率30.5%（部分修复）
- 乐观：Brent回落至$65以下，毛利率32.5%（显著修复）

**确定性评分：3分（中等）**
EIA预测方向明确，但油价受地缘政治影响大，存在不确定性。

## 三、多态逻辑情景推演（2027E）

### 3.1 保守情景（Bear Case，概率30%）

**触发条件**：Brent维持$85+→毛利率29.5%；维森爬坡<30%→新增产能贡献不足；人民币继续升值+费用率高企；卓立产能释放加剧竞争。

| 参数 | 保守值 | vs 2027E基准 |
|:---|:---|:---|
| 营收(亿) | 10.20 | -3.8% |
| 毛利率 | 29.5% | -1.0ppt |
| 费用率（含汇兑） | 19.0% | +0.5ppt |
| **净利润(亿)** | **1.02** | **-17.7%** |
| **扣非(亿)** | **0.85** | -22.0% |
| **EPS(元)** | **0.67** | **-17.7%** |
| **YoY净利润增速** | **-12.7%** | 下滑 |

**情景特征**：维森爬坡仍不及预期+成本高位+竞争加剧，扣非延续负增长。

### 3.2 基准情景（Base Case，概率45%）

参数见上文P*Q模型，EPS = **0.82元**，扣非1.09亿（+14.7% YoY，恢复正增长）。

**情景特征**：维森爬坡40-60%利用率、油价回落至$70-75、毛利率30.5%、费用率小幅改善，净利润+5.1%且扣非恢复正增长。

### 3.3 乐观情景（Bull Case，概率25%）

**触发条件**：Brent回落至$65以下→毛利率32.5%；维森爬坡>60%且UDI全面放量；费用率回落至17.5%以下；海外渠道突破。

| 毛利率 | 32.5% | +2.0ppt |

## 八、模块五结论摘要

2027E盈利预测基于Q4切换期条款（框架§1.5），锚定次年EPS。**三态EPS：保守0.67元/基准0.82元/乐观1.11元**，加权0.847元（vs 2026E加权0.775元，+9.3%）。核心驱动：维森二期全年贡献（+0.08）、EIA预测2027年油价回落$69.39（+0.06）、UDI 2027-06强制赋码（+0.05）、CALOR/RTT全年并表（+0.03）。基准营收10.60亿（+7.9%）、毛利率30.5%、归母1.24亿（+5.1%）、扣非1.09亿（+14.7%恢复正增长）。保守情景假设维森爬坡<30%+Brent $85+，EPS 0.67元（-12.7% YoY）；乐观情景假设Brent <$65+UDI全面放量+维森满产，EPS 1.11元（+46.8% YoY）。整体确定性3.2/5，较2026E的3.0小幅提升（EIA油价预测+UDI政策确定性增强）。
