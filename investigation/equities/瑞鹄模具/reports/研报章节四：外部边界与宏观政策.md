## 1. 宏观环境变量

### 1.1 大宗商品：铝价（核心成本变量）与钢材（对冲项）

**铝（零部件成本端主压力）**：
- 2026 上半年沪铝均价约 23,000+ 元/吨（高位震荡）；**7/30 现货 23,630 元/吨、8 月中旬沪铝回升至 23,885 元/吨（8/14），7 月末以来累计反弹约 +3%**，处于机构预测区间（21,500-25,000 元/吨）中枢偏上；LME 库存降至 24.8-26.9 万吨（1990 年以来最低水平附近），但 Cash-3M 基本回平、未演化为近端挤仓，EGA 中东产能仅恢复约 18%（复产预计 2027Q1）；
- 瑞鹄 2026H1 铝锭/铝水采购价仍处高位（零部件毛利率 -0.14% 的重要压制项），但 H1 毛利率已从 Q1 的 -0.9% 修复，显示"年降出清"的临时因子在消退，铝价成为下半年毛利率修复的首要变量；
- 供需面：国内电解铝产能天花板（4,543 万吨）刚性约束（运行产能 4,531 万吨接近满产）、电解铝即时利润 7,000+ 元/吨偏高、铝锭社会库存降至 87.6-89.8 万吨继续去库，**低库存支撑沪铝估值，但高利润+淡季需求（铝棒/铝合金累库）限制上行空间，主流机构（南华/瑞达）判断沪铝短期震荡偏强、2.4 万元以上缺强现实支撑**——对瑞鹄是"高位不恶化、回落看 Q4 加工材库存与订单"的最优平衡，2027 年海外供给修复（印尼+中东复产）后铝价中枢或下移构成零部件中期修复逻辑。

**钢（装备成本端对冲项）**：
- 2026 年国内钢材仍处产能过剩磨底期，价格中枢 3,000-3,500 元/吨低位震荡；
- 瑞鹄装备业务（模具）主要原材料为钢材，钢价低位+结构升级支撑其毛利率稳定（2026H1 实绩 31.74%，+1.02pct），2026 年该逻辑延续且已被半年报验证。

### 1.2 汇率与利率

- **汇率**：2026 年人民币兑美元走强，对瑞鹄的影响分两面：
  - 公司出口占比由 2025H1 的 10.49% 升至 2026H1 的 16.59%（出口收入 3.10 亿元，+77.59%），直接汇兑敞口扩大；
  - **2026H1 财务费用 671 万元（同比 +1000.18%），主因"汇兑净损失"**——出口高增带来的人民币升值侵蚀已在报表兑现，且随出口占比继续提升，汇兑敏感性上升；
  - 核心客户奇瑞出口（占比 73%）以美元/本地币结算，人民币升值压制奇瑞出口利润→传导为对上游的年降压力；
  - **净效应**：人民币温和升值对瑞鹄是中性偏负（财务费用 + 下游压力），2026H1 已兑现，规模数千万级且可控。
- **利率**：2026 年国内维持宽松货币政策（LPR 低位），公司有息负债率低（短借 0.63 亿+长借 2.05 亿），融资成本敏感度低；新可转债（6.86 亿元）待证监会注册，票面利率预计 0.2%-1.5% 区间，成本优势明显。

## 2. 地缘政治风险

### 2.1 欧盟关税与中国车企出海（核心地缘变量）

| 要素 | 现状（2026-08） | 对瑞鹄的影响 |
| :--- | :--- | :--- |
| 欧盟反补贴关税 | 奇瑞适用 30.7%（10% 基础 + 20.7% 反补贴）；2026 年 5 月中国乘用车欧盟份额冲高至 10.7% | 直接出口敞口小；间接影响奇瑞欧洲战略节奏 |
| 奇瑞欧洲本地化 | 西班牙巴塞罗那 EBRO 工厂（2024 投产、2026-06 M1 产线启用、2029 目标 15 万辆/年）；英国桑德兰日产代工 MOU（最快 2027 财年） | **利好装备出海**：本地化建厂带动焊装线/模具订单（2026Q1 海外订单增速快于国内）；**利空零部件配套**：本地化后零部件转向欧洲供应链 |
| 欧盟《工业加速器法案》（IAA） | 草案：外资持股≤49%、≥50% 欧盟员工、70% 零部件本地化；预计最早 2027 年中落地 | 若落地将压制中国车企欧洲扩张速度与瑞鹄装备出口天花板；窗口期约 1 年 |
| 美国关税 | Section 122 已到期（2026-07-24），301 强劳 12.5% 落地 | 奇瑞/瑞鹄美国敞口极小，影响可忽略 |
| 中东地缘 | 美伊冲突反复，霍尔木兹海峡通航风险，中东铝产能 235-250 万吨停产 | 通过铝价间接影响（见 1.1），2026 年铝价高位的核心地缘推手 |

**结论**：地缘维度对瑞鹄呈"装备受益、零部件中性偏空"的非对称影响。关税壁垒加速中国车企（尤其奇瑞）海外建厂 → 瑞鹄装备（模具/焊装线）作为"卖水人"受益；但欧洲本地化供应链替代长期削弱其国内零部件出口配套逻辑。

### 2.2 供应链重构（China+1）与出口管制

- 中国车企"西班牙产线带"（奇瑞、零跑、上汽、吉利、东风、比亚迪候选）成型，设备投资（焊装线、模具）的国产化采购是瑞鹄装备出海的直接订单来源；
- 关键零部件（模具钢、压铸机）无出口管制风险；电子元器件（控制柜）采购存在一定进口依赖，但非核心约束。

## 3. 监管与产业政策

| 政策 | 内容 | 与瑞鹄的关联度 |
| :--- | :--- | :--- |
| 《扩大消费"十五五"规划》（2026-07-13） | 限购差异化松绑、二手车流通简化、置换占比提升至 55%+ | 中期（2027+）汽车内需修复的政策底，间接利好零部件需求 |
| 新能源购置税优惠到期 | 2026 年起购置税优惠退出（政策透支主因之一） | 短期（2026）内需承压的直接政策原因 |
| 一体压铸政策支持 | "高强度铝合金一体化压铸成型"列入《产业结构调整指导目录》鼓励类；《超大型压铸模具产业三年行动方案》 | 与瑞鹄零部件/模具业务方向契合，但政策红利更多普惠行业而非定向企业 |
| "十五五"智造/机器人 | 智能机器人列为新质生产力核心赛道；安徽省/芜湖市机器人产业政策（芜湖市"机器人之城"规划） | 瑞鹄机器人业务（与安川合作）受益，可转债募投含机器人项目，属政策风口 |
| 汽车行业"治卷" | 2026 年监管层治理"内卷式"竞争 | 利好有技术壁垒的企业（瑞鹄装备），但执行力度待观察 |
| 碳市场/绿色制造 | 电解铝纳入碳交易预期推高铝价 | 通过铝价间接负面传导（成本端） |

## 4. 章节结论

1. **宏观成本变量**：铝价 8 月中回升至 23,885 元/吨、低库存支撑但高利润与淡季限制上行（机构区间 21,500-25,000 元/吨）、2027 年或中枢下移；钢价低位支撑装备毛利率稳定（2026H1 实绩 31.74% 验证）；
2. **地缘变量**：奇瑞欧洲本地化扩张（西班牙 EBRO、南非罗斯林）是瑞鹄装备出海的核心顺风（2026H1 出口收入 +77.59% 已兑现），IAA 法案 2027 年中是潜在天花板；新加坡子公司设立为装备出海提供国际平台；人民币升值构成轻度负面（2026H1 财务费用 +1000% 已兑现）；
3. **政策变量**：汽车内需政策托底（十五五规划）与一体压铸/机器人产业政策为中期顺风，购置税退出为短期逆风；"治卷"政策利好装备端技术壁垒企业；
4. **对盈利预测的含义**：2026 年外部环境整体中性（铝价高位+人民币升值+内需政策空窗已被半年报实际数据吸收），2027 年外部环境趋于中性偏顺（铝价回落预期+消费政策落地+欧洲产能释放）——**盈利修复的节奏正在 2026H2 验证（Q2 毛利率已回升）、2027 年兑现**。
