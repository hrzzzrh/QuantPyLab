# 研报章节四：外部边界与宏观政策

**研究日期**：2026年07月22日

---

## 一、宏观环境变量

### 1.1 利率与折现率环境

当前中国10年期国债收益率在1.6-1.8%区间低位运行，无风险利率处于历史低位。这对于DCF估值意味着更低的折现率、更高的终值权重。对于瑞鹄模具（PE约15.87x），低利率环境提供了估值支撑。

2026年美联储6月议息会议释放强烈鹰派信号，联邦基金利率维持3.50-3.75%，点阵图显示加息前置倾向。美元指数突破101（逾一年新高），对有色金属整体构成系统性压制——这也部分解释了近期铝价的下跌。若下半年美联储开启降息，将有利于全球风险资产估值修复。

### 1.2 原材料成本：铝价持续回落，但地缘尾部风险再现

**铝价分析（关键更新）**：自2026年6月24日上次研究以来，铝价延续回落趋势，但7月中旬地缘政治再度升温。

- **LME铝价**：从6月23日的3,251.5美元/吨进一步回落至7月21日的约3,162美元/吨，跌幅约2.7%。自6月初高点~3,700美元累计回落约14.5%。现货结算价3,183.5美元
- **驱动因素**：美伊和平协议的积极预期仍在消化，海湾铝厂（Alba、EGA、Qatalum）产能正在有序恢复。但**7月中旬美伊局势再次升级**（伊朗声称袭击美国亚马逊在巴林的数据基础设施），霍尔木兹海峡及红海面临新的关闭风险。目前该事件对铝价的短期冲击有限（LME铝价在3,160附近窄幅震荡），但地缘尾部风险重新抬头
- **LME库存**：27.83万吨（7月21日），持续下降，仍处历史低位
- **沪铝**：从6月23日的23,520元/吨回落至7月21日的23,155元/吨，跌幅约1.6%。长江现货A00铝锭报23,080元/吨（7月22日），23000元/吨关口韧性显现
- **国内库存**：上期所铝库存47.63万吨（7月17日），周度去库；铝锭社会库存淡季去库未断
- **供给端硬约束**：国内电解铝运行产能缓慢抬升至4,530万吨左右，已接近4,500万吨产能天花板。6月国内原铝产量398万吨（+4.7%），1-6月累计2,319万吨（+3.8%）。产能触顶构成中长期铝价底部支撑
- **需求端分化**：铝加工龙头企业开工率下滑至61%（建筑型材与光伏订单平淡），但新能源赛道拉动铝型材需求逆势小幅回升；AI轻量化刚需构成新兴增长极
- **中期展望**：机构预计LME铝价在2,850-3,150美元/吨区间震荡，国内沪铝在22,000-24,000元/吨。地缘局势是最大不确定性变量

**对瑞鹄模具的影响——持续边际改善，但幅度有限**：

| 影响方向 | 机制 | 强度变化 |
| :--- | :--- | :--- |
| **成本端（利空→持续减弱）** | 零部件业务直接材料占比26.17%（2025），LME铝价从高点累计回落14.5%系统性缓解成本压力 | ⚠️ 从"中高"降至"中" |
| **需求端（利好）** | 铝价下跌短期可能降低车企轻量化紧迫性，但长期趋势不变 | 中（不变） |
| **零部件毛利率修复** | Q1毛利率-0.9%，铝价持续回落叠加H2产能利用率回升，毛利率回升至盈亏平衡以上的概率较6月24日进一步提高 | **正向边际巩固** |

**关键判断**：铝价从3,700→3,162（-14.5%）的回落是本次审计周期内最持续的正面边际信号。但需注意：1）沪铝回撤幅度（-1.6%）远小于LME，国内成本改善空间有限；2）7月中旬地缘局势再升级，铝价的"地缘风险溢价"可能随时回归；3）即使铝价回落3,000美元以下，零部件毛利率修复仍取决于产能利用率和年降谈判结果。H1零部件毛利率大概率仍为负值（Q1为-0.9%），真正的修复窗口在H2。

钢铁价格方面，国内钢材价格相对平稳，对装备业务成本影响可控。

### 1.3 国内汽车需求与A股市场：系统性调整冲击

**汽车板块7月遭遇剧烈调整**。7月13日，A股汽车板块大跌4.22%——赛力斯发布2026年H1预亏15-18亿元（去年同期盈利29.41亿），众泰汽车因信息披露违规被立案调查，双股跌停带崩整车及零部件板块。广汽、江淮、北汽蓝谷跌幅超6%，长安、比亚迪等头部也出现明显回落。赛力斯从盈利到巨亏的"爆雷"打破了市场对车企二季度触底复苏的预期，整车板块盈利预期全面下修。

**瑞鹄在板块系统性下跌中未能幸免**。股价从7月3日高点30.77元（可转债过会+智界V9交付利好驱动）一路下滑至7月22日的25.21元，跌幅18.1%。除了板块拖累外，公司自身因素——H1业绩预告未发（市场担忧）、投资者互动中关于价格谈判无实质进展的回复、以及管理层对回购诉求的冷淡回应——共同加剧了股价下行压力。

**A股整体环境**也不利：深成指7月跌约1.4%，创业板指跌超3%，全市场日均超3,800只个股下跌。华鑫证券判断7月下跌主因资金情绪扰动而非基本面恶化，市场处于"快速下跌→底部震荡"阶段。但汽车板块的困境具有基本面基础——购置税优惠退坡、价格战加剧、碳酸锂及芯片成本上涨——并不完全是情绪因素。

### 1.4 汇率损益

- 公司出口销售占比7.51%（2025年），外销毛利率42.98%
- 美元指数走强至101+、人民币偏弱有利于出口业务毛利率改善
- 海外订单占比已达44-45%（2026Q1），汇率弹性将进一步增大
- 公司目标使海外业务收入和订单量占总体50%以上

## 二、监管与产业政策

### 2.1 新能源汽车购置税减半（2026-2027）

2026年起新能源汽车购置税从免征调整为减半征收（5%），单车上限1.5万元。标志行业从"政策驱动"向"市场驱动"的实质性切换。短期内可能压制部分价格敏感型消费者的购车意愿，但中高端车型（16.7万以上）影响有限。

### 2.2 以旧换新政策延续

2026年继续实施汽车报废更新和置换更新补贴，从"定额补贴"调整为"按车价比例补贴"。新能源乘用车报废更新补贴车价12%（上限2万），置换更新补贴8%（上限1.5万）。

### 2.3 "十五五"规划利好

- 模具行业作为高端装备列入重点发展领域
- 智能制造、工业机器人国产替代获得政策重点扶持
- 轻量化材料（铝镁合金）被列为战略性新兴产业

### 2.4 欧盟CBAM碳关税

2027年起欧盟要求进口产品再生铝比例不低于30%且碳足迹需符合PEF标准。瑞鹄已研发100%再生铝免热材料并通过量产验证，在碳合规方面具有先发优势。

## 三、地缘政治风险

### 3.1 中东冲突与铝供应链——持续改善但尾部风险再现

2026年2月爆发的中东冲突曾导致霍尔木兹海峡航运受阻、全球铝供应出现结构性缺口。**6月美伊达成和平协议是6月审计周期最重要的地缘变量变化**——LME铝价地缘溢价快速出清。但**7月中旬局势再度升级**：伊朗声称袭击美国亚马逊公司在巴林的数据基础设施，霍尔木兹海峡及红海面临新的关闭风险，全球风险偏好同步下行，亚太市场（日韩）出现剧烈波动。

对瑞鹄而言：成本端边际持续改善，但地缘尾部风险重新抬头意味着铝价的"风险溢价"可能随时回归。海湾铝厂（Alba、EGA、Qatalum）当前仍仅以30-60%开工率运营，全面恢复需6-18个月，全球铝供应偏紧格局短期不会根本扭转。

### 3.2 中美贸易摩擦

当前美国对中国汽车零部件征收25%关税，但对瑞鹄直接影响有限（出口占比仅7.51%，且主要面向非美市场）。若贸易摩擦进一步升级至欧洲、东南亚市场，需重新评估。

### 3.3 全球供应链重构

"China+1"战略驱动车企在东南亚、拉美建厂，瑞鹄作为设备供应商正在间接受益——奇瑞海外扩张（5月出口18.19万辆，占销量73%）为瑞鹄提供了伴随"出海"的增量订单。海外订单占比已达44-45%。

---

## 四、结论：政策环境中性偏利好，铝价是当前最大边际改善变量

1. **铝价显著回落**（LME -12%/沪铝 -3.2%）是本次审计的最大边际利好。零部件毛利率修复的宏观条件正在改善，H2回升至盈亏平衡以上的概率显著增加
2. **购置税减半**是短期利空（影响终端消费），但以旧换新补贴延续提供了托底
3. **奇瑞出口爆发式增长**（5月+80.5%）为瑞鹄装备业务的海外订单提供强劲支撑
4. **国产替代政策**是长期利好（智能制造、机器人国产化）
5. **碳关税**对瑞鹄是差异化优势（再生铝技术领先）
