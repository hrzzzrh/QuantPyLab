## 二、价值锚定：适配性估值方法选择及理由

### 2.1 方法选择与理由

东鹏饮料具备以下特点：稳定盈利（净利率20%+）、高速增长（3年净利润CAGR约19.6%）、轻资产（非资本密集型）。基于此，选择以下三种方法进行交叉验证：

| 方法 | 适用性 | 权重 | 理由 |
|:---|:---|:---|:---|
| **PE估值** | 核心方法 | 50% | 盈利稳定可持续，成长性可量化，消费品行业首选 |
| **PEG估值** | 辅助验证 | 25% | 高增长公司需用PEG校准PE，防止高PE陷阱 |
| **DCF估值** | 参考锚点 | 25% | 现金流可预测，轻资产模式下FCF质量高 |

**不适用方法说明**：
- **PB-ROE**：H股IPO导致净资产翻倍（76亿→205亿），PB被动大幅稀释，历史分位已严重失真，不适用
- **SOTP**：海外业务几乎为零，各板块虽然属性不同但共用渠道/供应链，难以精确拆分估值
- **PS**：毛利率差异大（能量饮料52.5% vs 其他饮料27%），PS会严重高估低毛利业务价值

### 2.2 历史分位审计与谨慎评估

| PE分位 | 数值 | 位置解读 |
|:---|:---|:---|
| 5年最低 | 17.35 | 2026年6月26日触及；当前系统实测17.07仍低于5年最低 |
| 5%分位 | 25.23 | 当前系统实测17.07，仍远低于此 |
| 25%分位 | 37.42 | |
| 50%分位 | 41.57 | |
| 75%分位 | 51.25 | |
| 5年最高（近5年窗口） | 89.05 | 2021年8月；上市以来最高约114倍（2021年7月IPO初期） |

**谨慎评估**：当前系统实测PE-TTM约17.07倍（10月9日114.11元），仍低于5年最低17.35倍，处于历史底部区。但需注意以下历史分位的参考意义修正：

1. **2021年IPO初期的高PE（上市以来最高约114倍）包含新股溢价，不可作为合理估值锚点**
2. **2022-2023年的PE中枢（35-45倍）对应当时40%+的营收增速，现在2027E收入增速约18%**
3. **H股IPO导致的ROE稀释（47%→约25%）尚未完全反映在历史分位中**
4. **整体A股消费板块估值中枢在过去两年持续下移**

因此，合理PE区间的判断需结合PEG方法和可比公司分析，不能简单套用历史中位数。

## 三、核心估值计算（2027E口径）

### 3.1 PE估值法（权重50%）

**可比公司对标**：

| 公司 | 2026E PE | 3年CAGR | PEG | 备注 |
|:---|:---|:---|:---|:---|
| 农夫山泉 | ~35x | ~20% | ~1.75 | 软饮龙头，品类多元（2026H1茶+30.1%成第一大品类） |
| 康师傅 | ~18x | ~5% | ~3.6 | 方便面+饮料，增速低（H1饮品仅+0.7%） |
| 统一企业 | ~15x | ~5% | ~3.0 | 增速低，估值折扣（H1饮品-0.3%） |
| 贵州茅台 | ~20x | ~10% | ~2.0 | 白酒龙头，确定性溢价 |
| **东鹏饮料** | **~16x（2027E中性）** | **19.6%** | **~0.82** | 利润高增但收入降速；卖方2027E隐含约18x |

**合理PE区间判断**：

- 东鹏净利润3年CAGR约19.6%，仍接近农夫山泉（~20%），远高于康师傅/统一（~5%）
- 中性口径PEG仅0.82（17.07/19.6按TTM计；Forward 13.3/19.6=0.68），与农夫山泉的PEG 1.75相比存在明显折价
- 折价原因：品类单一风险（能量饮料仍占65%）、补水啦增速下修、H股上市后的ROE稀释、PET 9月回升
- 给予约10%的PEG折价后，合理PEG约0.95-1.0
- **合理Forward PE = 0.95~1.05 × 19.6% = 19-21倍**；考虑茶饮料放量与分红规划落地，给予中性情景21倍
- **卖方交叉锚点**：某卖方维持2027年18倍PE估值中枢（来源：卖方研报，未经公告验证），本预测保守情景18倍与之对齐

**三态市值计算（2027E盈利 × 情景PE）**：
- 保守：53.8亿 × 18x = 968亿 → **取整970亿**
- 中性：63.3亿 × 21x = 1329亿 → **取整1330亿**
- 乐观：73.5亿 × 25x = 1838亿 → **取整1840亿**（平台化兑现+成本回落，给予25x成长溢价）
- 对应目标价（不复权市价，股本7.342亿）：保守132元 / 中性181元 / 乐观251元（中性待审计调节，见§四）

### 3.2 PEG估值法（权重25%）

PEG = Forward PE / 3年净利润CAGR（约19.6%）

- 合理PEG: 1.0（消费品龙头正常定价）
- 隐含合理PE = 1.0 × 19.6 = **19.6倍**
- 目标价 = 19.6 × 8.5（加权EPS）= **166.6元**

若给予PEG=1.2（考虑品牌护城河+渠道壁垒+80%分红规划溢价）：
- 合理PE = 23.5倍
- 目标价 = **199.8元**

### 3.3 DCF估值法（权重25%）

**关键假设**：

| 参数 | 假设值 | 依据 |
|:---|:---|:---|
| 预测期 | 10年（2027-2036） | 涵盖一个完整资本开支周期 |
| 永续增长率 | 3.0% | 饮料行业长期与GDP同步 |
| WACC | 9.0% | 无风险利率~2.8%+ERP~6.2% |
| 初始FCF（2027E） | 约30亿 | 经营CF约82亿−资本开支约40亿，扣除新增理财净投放后（模块五3.3） |
| 稳态FCF利润率 | 15% | 成熟消费品公司水平 |
| 终值占比 | ~50% | 合理的终值依赖度 |

**简化DCF估算**：

| 阶段 | 期间 | 净利润CAGR | FCF转化率 | 累计折现FCF（亿） |
|:---|:---|:---|:---|:---|
| 高增长期 | 2027-2029 | 19.6% | 50%（天津爬坡+昆明投产） | ~150 |
| 稳定增长期 | 2030-2033 | 12% | 60% | ~350 |
| 成熟期 | 2034-2036 | 5% | 75% | ~250 |
| 终值（永续） | 2036+ | 3% | 75% | ~650 |
| **企业价值** | | | | **~1400** |
| 加：净现金 | | | | +60（货币资金扣除分红回购后，保守估计） |
| **股权价值** | | | | **~1460亿** |

**DCF隐含目标价 = 1460 / 7.342 ≈ 199元**（隐含2027E中性PE约23x）

## 七、模块六核心结论（2027E口径）
