## 二、价值锚定：适配性估值方法选择及理由

### 2.1 方法选择与理由

东鹏饮料具备以下特点：稳定盈利（净利率21%+）、低速增长（2025-2028年净利润CAGR约8.7%）、轻资产、高分红（80%）、净现金充裕。基于此，选择以下三种方法进行交叉验证：

| 方法 | 适用性 | 角色 | 理由 |
|:---|:---|:---|:---|
| **PE估值** | 核心方法 | 主锚 | 盈利稳定、分红率高、成长性可量化，消费品行业首选 |
| **PEG估值** | 辅助验证 | 下界校验 | 低增长阶段需用PEG校准PE，防止“低PE陷阱” |
| **DCF估值** | 参考锚点 | 下界/中界校验 | 现金流可预测、净现金充裕、轻资产模式下FCF质量高 |

**说明**：本轮不采用“PE 50% + PEG 25% + DCF 25%”的机械加权，因为三种方法对低增长、高分红的消费品给出的锚点差异较大，机械平均会掩盖“市场愿给多少倍”这一核心分歧。本报告以PE法为主锚，PEG与DCF作为上下界校验；PEG/DCF构成99-129元的下界校验，PE主锚130元。

**不适用方法说明**：
- **PB-ROE**：H股IPO导致净资产翻倍（94亿→186亿），PB被动大幅稀释，历史分位已严重失真；当前PB 4.43倍对应ROE 24.5%，PB-ROE隐含估值并不便宜
- **SOTP**：海外业务几乎为零，各板块虽然属性不同但共用渠道/供应链，难以精确拆分估值；茶饮料/电解质仍处孵化期，SOTP会放大亏损板块的负价值
- **PS**：毛利率差异大（能量饮料52.5% vs 茶饮料26%），PS会严重高估低毛利业务价值

**谨慎评估**：当前PE-TTM约17.13倍，低于5%分位18.87倍，但已高于5年最低15.06倍；最低点出现在2026年10月21日（三季报前9天），说明市场在三季报前已把估值打到历史极值，10月30日后的反弹是“利空出尽”而非“估值修复”。需注意以下历史分位的参考意义修正：

1. **2021年IPO初期的高PE（上市以来最高约114倍）包含新股溢价，不可作为合理估值锚点**
2. **2022-2023年的PE中枢（35-45倍）对应当时40%+的营收增速，现在2027E收入增速约9%**
3. **H股IPO导致的ROE稀释（47%→约25%）尚未完全反映在历史分位中**
4. **整体A股消费板块估值中枢在过去两年持续下移，且公司增长中枢下台阶，历史中位数不可直接套用**

因此，合理PE区间的判断需结合PEG、股息率和可比公司分析，不能简单套用历史中位数。

## 三、核心估值计算（2027E口径）

### 3.1 PE估值法（主锚）

**可比公司对标**：

| 公司 | 2026E PE | 3年CAGR | PEG | 备注 |
|:---|:---|:---|:---|:---|
| 农夫山泉 | ~35x | ~15% | ~2.3 | 软饮龙头，毛利率60.9%，2026H1茶+30.1% |
| 康师傅 | ~18x | ~5% | ~3.6 | 方便面+饮料，增速低 |
| 统一企业 | ~15x | ~5% | ~3.0 | 增速低，估值折扣 |
| 贵州茅台 | ~20x | ~10% | ~2.0 | 白酒龙头，确定性溢价 |
| **东鹏饮料** | **~17.4x（2026E）/15.7x（2027E）** | **8.7%** | **~1.80** | 利润低增但分红率80%、净现金19.8% |

**合理PE区间判断**：

- 东鹏2025-2028年净利润CAGR约8.7%，低于农夫山泉，高于康师傅/统一；但净利率21%、ROE 24.5%、分红率80%、净现金占市值19.8%，质量显著优于康师傅/统一
- 当前2027E Forward PE 15.7倍、PEG约1.80；考虑4.6%股息率与净现金，PEG 1.7-1.9属于合理区间，不再“深度折价”
- 折价原因：能量饮料负增长、电解质份额流失、2027年PET成本上行、ROE稀释、治理/汇率复杂化
- **合理Forward PE = 17-18倍**；中性取17倍（PEG约2.0，但股息率与净现金提供支撑；审计+7%后的隐含倍数为18.2x，属审计溢价，不改变倍数区间选取口径）；保守14倍（低增长+成本压力）、乐观22倍（2027年修复超预期）
- **卖方锚点**：招商证券国际11/4将H股目标价下调至101港元、评级降至中性；101港元按0.8562折合约86.5元人民币，按当前29.5%的A/H溢价折算约112元，隐含A股零上行。花旗维持买入但承认“最困难阶段”，其H股目标价约161.7港元（6月），按当前汇率/溢价折算约140元。本报告中性130元低于花旗、高于招商国际的A股等价112元，处于中间偏审慎位置。

**三态市值计算（2027E盈利 × 情景PE）**：
- 保守：43.8亿 × 14x = 613.2亿 → **取整613亿**
- 中性：52.3亿 × 17x = 889.1亿 → **取整889亿**（审计调节后951亿）
- 乐观：59.0亿 × 22x = 1298亿 → **取整1298亿**
- 对应目标价（不复权市价，股本7.342亿）：保守84元 / 中性130元 / 乐观177元（中性待审计调节，见§四）

### 3.2 PEG估值法（下界校验）

PEG = Forward PE / 3年净利润CAGR（2025-2028约8.7%）

- 合理PEG: 1.0-1.2（低增长消费品龙头）
- 隐含合理PE = 1.0-1.2 × 8.7 = **8.7-10.4倍**
- 目标价 = 9.5 × 7.12 = **67.6元**

若给予PEG=1.6-1.8（考虑80%分红、净现金、品牌护城河）：
- 合理PE = 13.9-15.7倍
- 目标价 = **99-112元**

**PEG交叉结论**：纯PEG口径（8.7-10.4倍）会给出62-74元的极低估值，但忽略了80%分红率与净现金；考虑分红后，PEG 1.6-1.8对应99-112元。这说明当前112元已基本反映“低增长+高分红”的合理定价，向上空间主要来自估值修复而非PEG折价；PEG 1.9-2.0对应118-124元，接近本报告中性档的下沿。

### 3.3 DCF估值法（下界/中界校验）

**关键假设**：

| 参数 | 假设值 | 依据 |
|:---|:---|:---|
| 预测期 | 10年（2027-2036） | 涵盖一个完整资本开支周期 |
| 永续增长率 | 3.0% | 饮料行业长期与GDP同步 |
| WACC | 9.0% | 无风险利率~2.8%+ERP~6.2% |
| 初始FCF（2027E） | 约32亿 | 归母52.3亿×60% FCF转化率（经营CF 76亿−capex 28亿−营运资本增加） |
| 稳态FCF利润率 | 15% | 成熟消费品公司水平 |
| 终值占比 | ~60% | 低增长下终值依赖度上升 |

**简化DCF估算**：

| 阶段 | 期间 | 净利润CAGR | FCF转化率 | 累计折现FCF（亿） |
|:---|:---|:---|:---|:---|
| 高增长期 | 2027-2029 | 8.7% | 60% | ~88 |
| 稳定增长期 | 2030-2033 | 7% | 70% | ~110 |
| 成熟期 | 2034-2036 | 4% | 80% | ~73 |
| 终值（永续） | 2036+ | 3% | 80% | ~400 |
| **企业价值** | | | | **~671** |
| 加：净现金 | | | | +162 |
| **股权价值** | | | | **~833亿** |

**DCF隐含目标价 = 833 / 7.342 ≈ 113元**（隐含2027E中性PE约15.9x）

> DCF对永续增长率与WACC敏感：若WACC 8.5%、永续3.5%，股权价值约950亿→129元；若WACC 9.5%、永续2.5%，约760亿→104元。DCF区间104-129元，与PEG的99-112元、PE主锚130元，PEG/DCF提供99-129元下界校验；DCF本身不单独构成目标价。

### 5.2 盈亏比计算

- 当前股价（不复权市价）：**112.00元**（2026年11月4日收盘）
- 中性目标价：130元
- 保守目标价：84元
- 乐观目标价：177元

**盈亏比（Risk-Reward）**：
- 中性上行空间：130 - 112 = 18元（**+16.1%**）
- 保守情景：112 - 84 = 28元（**-25.0%**）
- **盈亏比 = (加权目标价 - 现价) / (现价 - 保守场景价格) = (121 - 112) / (112 - 84) = 9 / 28 = 0.32**
- 若以概率加权目标价121元计，加权上行空间为（121-112）/112 ≈ **+8.0%**
- 在乐观情景下：上行65元（177-112，+58.0%）

> 盈亏比0.32显著低于1.0，意味着当前价位的期望收益远不足以补偿下行风险。现价112元已高于保守价84元，赔率框架适用且不支持买入，这是评级下调至中性的核心依据。

## 七、模块六核心结论（2027E口径）

1. **三态目标价84/130/177元（不复权市价），概率加权121元**，较当前112.00元：中性上行约16.1%，加权上行约8.0%，保守下行约-25.0%。

2. **当前系统实测PE-TTM约17.13倍，低于5%分位18.87倍、高于5年最低15.06倍**，Forward PE（2027E中性）约15.7倍，PEG约1.80；估值处于历史底部区，但不再是“深度折价”，且低点就在三季报前9天。

3. **全变量对冲审计按框架§3剔除双重计减**：成本与价格战已在E/情景中体现，PE端归零；渠道+5%、平台化+1%、ROE-1%、股东回报+2%，综合+7%；中性目标130元已包含该调节。

4. **盈亏比0.32，远低于1.0**：当前价位的期望收益不足以补偿下行风险。评级为“中性（第四象限，观察）”。

5. **A/H是硬约束**：H股11/4收101.00港元（约86.5元人民币），A/H溢价29.5%，H股PE-TTM约13.2x；招商国际目标价101港元按现溢价折算约112元，隐含A股零上行。A股中性目标130元较H股人民币价格86.5元高约50%，较按现溢价折算的A股等价112元高约16%，需要A股流动性/股息溢价支撑，不能视为“安全垫”。

6. **极限支撑位14元（清算价值）**提供了极端底线参考；现实下行参考：若2027E利润43.8亿、14倍PE，股价约84元；若利润48亿、15倍PE，约98元。当前112元处于“保守价上方、中性价下方”的尴尬位置。
