## 二、价值锚定：适配性估值方法选择及理由

### 2.1 方法选择与理由

东鹏饮料具备以下特点：稳定盈利（净利率20%+）、高速增长（3年CAGR 22%）、轻资产（非资本密集型）。基于此，选择以下三种方法进行交叉验证：

| 方法 | 适用性 | 权重 | 理由 |
|:---|:---|:---|:---|
| **PE估值** | 核心方法 | 50% | 盈利稳定可持续，成长性可量化，消费品行业首选 |
| **PEG估值** | 辅助验证 | 25% | 高增长公司需用PEG校准PE，防止高PE陷阱 |
| **DCF估值** | 参考锚点 | 25% | 现金流可预测，轻资产模式下FCF质量高 |

**不适用方法说明**：
- **PB-ROE**：H股IPO导致净资产翻倍（76亿→205亿），PB被动大幅稀释，历史分位已严重失真，不适用
- **SOTP**：海外业务几乎为零，各板块虽然属性不同但共用渠道/供应链，难以精确拆分估值
- **PS**：毛利率差异大（能量饮料51% vs 其他饮料16%），PS会严重高估低毛利业务价值

### 2.2 历史分位审计与谨慎评估

| PE分位 | 数值 | 位置解读 |
|:---|:---|:---|
| 5年最低 | 17.35 | 2026年6月26日触及 |
| 5%分位 | 25.23 | 当前手算PE-TTM约20.68，仍低于此 |
| 25%分位 | 37.42 | |
| 50%分位 | 41.57 | |
| 75%分位 | 51.25 | |
| 5年最高 | 50+ | 2021年IPO初期 |

**谨慎评估**：当前手算PE-TTM约20.68倍，仍处于上市以来历史低位区间。但需注意以下历史分位的参考意义修正：

1. **2021年IPO初期的高PE（50+）包含新股溢价，不可作为合理估值锚点**
2. **2022-2023年的PE中枢（35-45倍）对应当时40%+的营收增速，现在2026E收入增速已下修至约20%**
3. **H股IPO导致的ROE稀释（47%→约26%）尚未完全反映在历史分位中**
4. **整体A股消费板块估值中枢在过去两年持续下移**

因此，合理PE区间的判断需结合PEG方法和可比公司分析，不能简单套用历史中位数。

## 三、核心估值计算

### 3.1 PE估值法（权重50%）

**可比公司对标**：

| 公司 | 2026E PE | 3年CAGR | PEG | 备注 |
|:---|:---|:---|:---|:---|
| 农夫山泉 | ~35x | ~20% | ~1.75 | 软饮龙头，品类多元 |
| 康师傅 | ~18x | ~5% | ~3.6 | 方便面+饮料，增速低 |
| 统一企业 | ~15x | ~5% | ~3.0 | 增速低，估值折扣 |
| 贵州茅台 | ~20x | ~10% | ~2.0 | 白酒龙头，确定性溢价 |
| **东鹏饮料** | **~19x** | **21%** | **~0.90** | 利润高增但收入降速 |

**合理PE区间判断**：

- 东鹏净利润3年CAGR约21%，仍高于茅台（10%），与农夫山泉接近
- PEG低于1.0，与农夫山泉的PEG 1.75相比存在明显折价
- 折价原因：品类单一风险（能量饮料仍占71.92%）、补水啦增速下修、H股上市后的ROE稀释
- 给予10-15%的PEG折价后，合理PEG约1.0-1.1
- **合理Forward PE = 0.95~1.05 × 21% = 20-22倍**；考虑H1毛利率超预期和茶饮料放量，给予中性情景23倍而非压到20倍以下

**基准市值计算**：
- 2026E加权EPS: 7.3元
- 合理PE: 21-23倍
- **目标价（不复权市价）: 153 ~ 168元**
- **基准市值: 1123 ~ 1233亿**（基于约7.34亿总股本）

### 3.2 PEG估值法（权重25%）

PEG = Forward PE / 3年净利润CAGR（约21%）

- 合理PEG: 1.0（消费品龙头正常定价）
- 隐含合理PE = 1.0 × 21 = **21倍**
- 目标价 = 21 × 7.3 = **153.3元**

若给予PEG=1.2（考虑品牌护城河+渠道壁垒溢价）：
- 合理PE = 25.2倍
- 目标价 = **184.0元**

### 3.3 DCF估值法（权重25%）

**关键假设**：

| 参数 | 假设值 | 依据 |
|:---|:---|:---|
| 预测期 | 10年（2026-2035） | 涵盖一个完整资本开支周期 |
| 永续增长率 | 3.0% | 饮料行业长期与GDP同步 |
| WACC | 9.0% | 无风险利率~2.8%+ERP~6.2% |
| 初始FCF（2026E） | 约10亿 | 经营现金流上修，但理财和产能投入仍压制FCF |
| 稳态FCF利润率 | 15% | 成熟消费品公司水平 |
| 终值占比 | ~55% | 合理的终值依赖度 |

**简化DCF估算**：

| 阶段 | 期间 | 净利润CAGR | FCF转化率 | 累计折现FCF（亿） |
|:---|:---|:---|:---|:---|
| 高增长期 | 2026-2028 | 21% | 35%（扩产期） | ~85 |
| 稳定增长期 | 2029-2032 | 12% | 60% | ~250 |
| 成熟期 | 2033-2035 | 5% | 75% | ~200 |
| 终值（永续） | 2035+ | 3% | 75% | ~650 |
| **企业价值** | | | | **~1220** |
| 减：净债务 | | | | +80（净现金） |
| **股权价值** | | | | **~1300亿** |

**DCF隐含目标价 = 1300 / 7.34 ≈ 177.1元**

### 3.4 三种方法综合

| 方法 | 权重 | 目标价区间 | 隐含PE |
|:---|:---|:---|:---|
| PE估值 | 50% | 153-168 | 21-23x |
| PEG估值 | 25% | 153-184 | 21-25.2x |
| DCF估值 | 25% | ~177 | ~24x |
| **综合目标价** | | **160-172元** | **22-24x** |
| **基准市值** | | **1174-1262亿** | |

## 六、逻辑证伪与极限压力测试

### 6.1 黑天鹅场景定义

**场景：能量饮料消费习惯被替代性颠覆**

触发条件（需同时发生）：
1. 权威医学研究证实能量饮料与严重健康风险强相关（类似烟草的致癌定论）
2. 国家出台能量饮料广告禁令和消费年龄限制（类似烟酒管控）
3. 消费者恐慌性转向替代品（咖啡、茶饮）

### 6.2 极限支撑位审计

在此极端场景下，计算东鹏的地狱价格：

| 资产/指标 | 数值 | 清算价值（折价后） |
|:---|:---|:---|
| 货币资金 | 144.75亿 | 144.75亿（100%） |

| 固定资产（574万吨产能） | ~80亿 | 40亿（50%，专用性强） |
| 土地/在建工程 | ~80亿 | 60亿（75%） |
| 存货 | 5亿 | 3亿（60%） |
| 减：负债合计 | 164亿 | 150亿（部分可清偿） |
| **净清算价值** | | **约152亿** |

**极限价格判断**：
- 净现金价值：货币资金144.75亿 - 短期借款56.49亿 ≈ 88亿，对应每股约12元；综合考虑理财资产和固定资产折价后，极限支撑位约21元/股

1. 补水啦增速维持个位数且Q3旺季无法恢复
2. PET维持8500元/吨以上并穿透锁价保护
3. 能量饮料增速降至5%

则2026E净利润可能降至45-48亿，对应20倍PE的目标价约**123-131元**。

## 七、模块六核心结论

1. **综合目标价166-179元（不复权市价）**，较当前138.20元有20-30%的上行空间。

2. **当前手算PE-TTM约20.68倍处于历史极低分位**（低于上市以来5%分位25.23倍），Forward PE约18.9倍，估值吸引力仍在。

3. **全变量对冲审计后调节幅度提升至+4%**，说明成本风险被H1财报阶段性证伪后，渠道+数字化+平台化的溢价重新占上风；但补水啦降速仍压制估值倍数上限。

4. **盈亏比3.88:1**，来自目标价上修和保守情景抬升；但7月30日已放量反弹至138.20元，短线不宜把财报利好后的追涨当成安全边际。

5. **极限支撑位20-21元（清算价值）**提供了极端的底线参考，但正常情景下若2026E业绩不及预期，股价更现实的下探区间为123-131元。

6. **催化剂关注**：Q3旺季后合同负债与补水啦增速、茶饮料毛利率、H2 PET锁价到期后的实际毛利率、现金分红落地。
