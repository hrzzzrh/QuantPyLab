**价格（P）趋势逻辑推演**：

- **柴油发动机ASP**：受新能源替代压力，中小马力段面临压价，预计-2%~0%。大马力（13L+）因技术壁垒维持稳定甚至小幅上涨。
- **天然气发动机ASP**：大马力燃气机因潍柴独家技术享有溢价权，ASP稳定或微涨+1-2%。天然气渗透率短期因气价回落承压，但潍柴份额提升（53.7%）提供结构支撑。
- **M系列大缸径ASP**：数据中心柴发发动机因供需缺口和国产替代，涨价确定性强。国内单机均价近300万元、纯外资原装机组超300万元/台，潍柴仍有+5-10%涨价空间。
- **新能源三电ASP**：随着规模效应释放和竞争加剧，电池pack有望降价，但出货量暴增抵消降价影响。

**纯柴油发动机销量桥接说明（2026E 64-70万台，较2025年59.6万台+7.5%~+17.5%）**：国内柴油重卡配套受新能源渗透率超预期（6月约45%）侵蚀约-8%~-12%，但增长来自：①出口发动机增量（2026H1重卡出口+43%，发动机出口同步高增）；②工程机械/农机/发电用发动机随下游回暖（2026H1挖机+26.4%）；③潍柴多缸柴油机市占率提升（2026M1-5为20.19%，同比+0.5pct）。需注意章节二渗透率表中"柴油重卡占比"为市场结构口径（含出口），与潍柴发动机销量口径（含工程机械/农机/发电/出口多元应用）不同，二者不存在直接换算关系。

**内生动力→外生拉动→博弈空间三重验证**：
- 内生：产能利用率当前72%（74.3万台/102万台产能），提升空间充足
- 外生：国四/国五52万辆+淘汰需求+以旧换新补贴延续（2026-12-31）+AI数据中心建设
- 博弈：玉柴追赶凶猛（H1燃气机+31%）但潍柴在13L+大马力技术壁垒短期内难以被突破；新能源重卡渗透率超预期（6月约45%）加速柴油机长期份额流失，但潍柴三电同步放量对冲

### 2.2 利润边际变化的核心驱动

**正面因素**（增利）：
1. 凯傲效率计划一次性费用消除 → 管理费用同比-18.95%（H1）、销售费用-9.05%，合计增利约15-20亿（H1已兑现：凯傲H1净利2.08亿欧元同比+333%、Q2单季1.15亿欧元）
2. 大缸径/数据中心发动机量价齐升 → H1超1400台（已超2025年全年）+ M系列6700台（+31.5%），高毛利产品占比提升，结构性推升综合毛利率（动力总成20.16%同比+1.01pct已验证）
3. 重卡总量韧性 → 1-7月累计74.49万辆（+19.4%）验证需求，但7月单月回落提示H2斜率放缓；发动机41.5万台（H1）规模效应释放，产能利用率从72%回升至81%+
4. 新能源三电放量（H1 26亿元，+113%）、陕重汽整车（7.6万辆，+5.1%）→ 收入增量但利润率偏低

**负面因素**（减利）：
1. **天然气发动机销量加速下滑** → 5-6月连续双降（6月-12%）、7月0.5万台（-61%）创年内新低，潍柴燃气机H1 5.8万台（+22%）但Q3承压；天然气发动机利润率高于同排量柴油机，此消彼长拖累结构
2. 中小马力柴油发动机价格竞争 → ASP下行压力，但潍柴多缸柴油机市占率20.19%（+0.5pct）显示份额韧性
3. 新能源三电仍处投入期 → 烟台产业园折旧计提，H1毛利率未显著修复（综合21.46%与2025年持平）
4. 财务费用大幅转正：H1为6.46亿元（2025H1为-4.69亿元，同比+11.15亿元），汇兑损益变动抵消部分费用管控红利，全年预计+6~+8亿元（vs 原预测+3~+5亿）
5. 新能源重卡渗透率上半年超预期（5月41.5%、6月约45%）但7月回落至27%，累计21%（1-7月）仍对柴油机长期空间构成压力

**综合净影响**：H1实际验证“正面＞负面”但边际收敛——扣非后利润改善（+18.86%）远温和于报表（+36.46%），Q2扣非环比仅+4.6%，综合毛利率21.46%未修复至22%+，财务费用与燃气机下滑构成新增拖累。

### 2.3 盈利质量研判

**2025年毛利率下滑的真因**（拆解分析）：
- 动力总成板块毛利率-1.62pct至17.85% → **价格竞争（60%）+成本上行（40%）**
  - 中小马力柴油机面临玉柴/全柴价格战
  - 钢材/有色金属价格2025年处于高位
  - 新能源重卡替代效应初显，柴油机结构性降价压力
- 智慧物流毛利率-0.35pct → 凯傲效率计划相关（一次性）
- 整体毛利率-0.95pct中，约0.5pct为结构性因素（新能源替代），约0.45pct为一次性或周期性因素

**2026-2027年毛利率修复逻辑（H1审计：未兑现）**：
- 凯傲效率计划消除 → 智慧物流毛利率25.53%（同比-1.85pct）**未恢复**，虽凯傲集团调整后EBIT利润率7.6%（+0.6pct）改善，但分产品毛利率仍下滑，主因成本与结构因素
- 大缸径/数据中心高毛利产品放量 → 动力总成毛利率20.16%（同比+1.01pct）**已兑现**，但被智慧物流下滑对冲，综合毛利率21.46%（与2025年21.48%持平）
- 产能利用率上升 → 发动机41.5万台（H1）对应年化83万台（利用率81%），制造费用摊薄有限
- 柴油价格竞争 + 燃气机销量加速下滑（7月-61%）→ 基础业务毛利率承压加剧
- **合计**：H1实际综合毛利率21.46%未回升，全年22.0-22.5%目标面临挑战，下调至21.6-22.0%（2026）与22.0-22.6%（2027）；修复依赖H2费用进一步管控与大缸径放量对冲

## 五、模块五核心结论

1. **2026-2027年归母净利润预测（中性，修订）**：150亿 / 175亿，对应EPS 1.74 / 2.03元，同比增速+37% / +17%（2026高增含H1一次性收益与费用管控，2027增速收敛）。

2. **增长核心驱动力排序（H1审计后）**：
   - 凯傲效率计划利润修复（H1净利2.08亿欧元同比+333%、管理费用-18.95%已兑现，但Q2订单-19.8%、现金流0.22亿提示下半年放缓）
   - 数据中心柴发（H1超1400台已超2025年全年、M系列6700台+31.5%，增量最大、确定性最高、利润率最佳）
   - 重卡总量韧性（1-7月累计74.49万辆+19.4%，但7月单月回落提示H2斜率放缓）
   - 新能源三电（H1 26亿元+113%、电池4.7GWh+103%，Q2环比放缓）
   - 陕重汽整车（H1 7.6万辆+5.1%、7月1.11万辆，规模效应）
   - 天然气发动机（H1 5.8万台+22%但7月行业0.5万台-61%创年内新低，短期承压加剧）

3. **主要下行风险（H1审计后上调）**：天然气重卡7月创年内新低（渗透率6%）对燃气机Q3销量冲击、综合毛利率21.46%未修复至22%+（H1企稳但未回升）、财务费用H1 6.46亿（同比+11.15亿）抵消费用管控红利、凯傲Q2订单-19.8%与自由现金流0.22亿（-86%）提示欧洲需求放缓、新能源渗透率7月回落但累计21%仍对柴油机长期空间构成压力。

4. **概率加权EPS**：2026E 1.74元，2027E 2.01元。

5. **扣非可持续性敏感性（新增）**：以扣非中性125-130亿（EPS 1.45-1.50元）为可持续基数，对应PE 15.6x（现价27.17元）隐含约17.5-18.7x，高于headline口径15.6x，显示headline盈利中一次性占比（H1为20.5%）对估值有约3.5-4.0元/股的抬升；H2一次性若显著回落（Ballard剩余股权已转交易性金融资产，后续波动计入公允价值变动），headline与扣非将收敛。

6. **逻辑继承校验**：模块一H1综合毛利率21.46%（与2025年持平）显示修复不及预期（原预测22.0%），动力总成20.16%（+1.01pct）回升被智慧物流25.53%（-1.85pct）对冲；模块二新能源渗透率上半年超预期（6月约45%）但7月回落至27%、天然气加速下滑（7月-61%）已纳入情景假设；模块三凯傲H1利润修复兑现但订单与现金流放缓已下调确定性评分。
