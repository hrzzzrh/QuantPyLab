**价格（P）趋势逻辑推演**：

- **柴油发动机ASP**：受新能源替代压力，中小马力段面临压价，预计-2%~0%。大马力（13L+）因技术壁垒维持稳定甚至小幅上涨。
- **天然气发动机ASP**：大马力燃气机因潍柴独家技术享有溢价权，ASP稳定或微涨+1-2%。天然气渗透率提升带来结构性ASP提升。
- **M系列大缸径ASP**：数据中心柴发发动机因供需缺口和国产替代，涨价确定性强。参考外资机组涨价20%，潍柴产品也有+5-10%涨价空间。
- **新能源三电ASP**：随着规模效应释放和竞争加剧，电池pack有望降价，但出货量暴增抵消降价影响。

**内生动力→外生拉动→博弈空间三重验证**：
- 内生：产能利用率当前72%（74.3万台/102万台产能），提升空间充足
- 外生：国四52万辆淘汰需求+以旧换新补贴+AI数据中心建设
- 博弈：玉柴追赶凶猛但潍柴在13L+大马力技术壁垒短期内难以被突破；中小马力面临价格战但潍柴有规模优势

### 2.2 利润边际变化的核心驱动

**正面因素**（增利）：
1. 凯傲效率计划一次性费用消除 → 管理费率下降0.25-0.35pct，增利约6-8亿
2. 大缸径/数据中心发动机量价齐升 → 高毛利产品占比提升，结构性推升综合毛利率
3. 天然气发动机渗透率提升 → 天然气发动机利润率高于同排量柴油机
4. 规模效应释放 → 产能利用率从72%回升至80%+，固定成本摊薄

**负面因素**（减利）：
1. 中小马力柴油发动机价格竞争 → ASP下行压力，影响动力总成板块毛利率
2. 新能源三电仍处投入期 → 烟台产业园折旧开始计提，早期利润率偏低
3. 原材料（钢材/铜/铝）价格高位波动 → 除非大幅回落，否则成本压力持续

**综合净影响**：正面因素＞负面因素，2026-2027年利润率有望温和改善。

### 2.3 盈利质量研判

**2025年毛利率下滑的真因**（拆解分析）：
- 动力总成板块毛利率-1.62pct至17.85% → **价格竞争（60%）+成本上行（40%）**
  - 中小马力柴油机面临玉柴/全柴价格战
  - 钢材/有色金属价格2025年处于高位
  - 新能源重卡替代效应初显，柴油机结构性降价压力
- 智慧物流毛利率-0.35pct → 凯傲效率计划相关（一次性）
- 整体毛利率-0.95pct中，约0.5pct为结构性因素（新能源替代），约0.45pct为一次性或周期性因素

**2026-2027年毛利率修复逻辑**：
- 凯傲效率计划消除 → 智慧物流毛利率恢复（+0.3-0.4pct）
- 大缸径/数据中心高毛利产品放量 → 动力总成结构优化（+0.2-0.3pct）
- 产能利用率上升 → 制造费用摊薄（+0.1-0.2pct）
- 柴油价格竞争持续 → 基础业务毛利率承压（-0.1-0.2pct）
- **合计**：毛利率有望从21.48%回升至22.0-22.5%

## 五、模块五核心结论

1. **2026-2027年归母净利润预测（中性）**：130亿 / 162亿，对应EPS 1.50 / 1.87元，同比增速+19% / +25%。

2. **增长核心驱动力排序**：
   - 数据中心柴发（增量最大、确定性最高、利润率最佳）
   - 天然气发动机渗透率提升（存量优势，确定性高）
   - 凯傲效率计划利润修复（一次性，2026年集中释放）
   - 国七催化预期（2027年起逐步体现）
   - 重卡行业自然回升（温和）
   - 新能源三电（基数小弹性大，但短期利润贡献有限）

3. **主要下行风险**：重卡需求低于预期、原材料价格上涨、新能源替代快于预期侵蚀柴油发动机份额。

4. **概率加权EPS**：2026E 1.51元，2027E 1.89元。

5. **逻辑继承校验**：模块一识别的毛利率下滑趋势（21.48%）在本次预测中已通过凯傲修复+大缸径结构优化给予适当修复（→21.9%），但未假设显著反弹（保守策略）。模块二国七催化和数据中心漏洞已转化为Q的驱动变量。模块三玉柴追赶压力已通过假设中小马力竞争持续（ASP承压）予以反映。
