## 一、分业务 P*Q 模型的证据链锚定

### 1.1 动力总成、整车整机及关键零部件（营收占比43.3%）

**销量（Q）确定性溯源**：

| 产品 | 2025实际 | 2026E（修订） | 2027E（修订） | 核心证据 | 确定性评分 |

**修订说明（2026-08-03）**：天然气发动机预测由18-20万台下调至12-14万台——2026年3月起LNG价格因中东地缘冲突飙升（4月出厂价超5300元/吨、5-6月超6200元/吨），气柴价差倒挂导致5-6月天然气重卡终端销量断崖下滑（5月环比-55%、6月同比-12%），6月渗透率降至14.12%。但7月LNG出厂价已回落（供增需减，7月环比下降），下半年经济性修复有望带动销量恢复；同时潍柴H1燃气机市占率不降反升至53.7%（+1.9pct）。新能源三电预测由55-65亿上调至70-85亿（Q1实际16.9亿元，年化超70亿）。

**价格（P）趋势逻辑推演**：

- **柴油发动机ASP**：受新能源替代压力，中小马力段面临压价，预计-2%~0%。大马力（13L+）因技术壁垒维持稳定甚至小幅上涨。
- **天然气发动机ASP**：大马力燃气机因潍柴独家技术享有溢价权，ASP稳定或微涨+1-2%。天然气渗透率短期因气价回落承压，但潍柴份额提升（53.7%）提供结构支撑。
- **M系列大缸径ASP**：数据中心柴发发动机因供需缺口和国产替代，涨价确定性强。国内单机均价近300万元、纯外资原装机组超300万元/台，潍柴仍有+5-10%涨价空间。
- **新能源三电ASP**：随着规模效应释放和竞争加剧，电池pack有望降价，但出货量暴增抵消降价影响。

**纯柴油发动机销量桥接说明（2026E 64-70万台，较2025年59.6万台+7.5%~+17.5%）**：国内柴油重卡配套受新能源渗透率超预期（6月约45%）侵蚀约-8%~-12%，但增长来自：①出口发动机增量（2026H1重卡出口+43%，发动机出口同步高增）；②工程机械/农机/发电用发动机随下游回暖（2026H1挖机+26.4%）；③潍柴多缸柴油机市占率提升（2026M1-5为20.19%，同比+0.5pct）。需注意章节二渗透率表中"柴油重卡占比"为市场结构口径（含出口），与潍柴发动机销量口径（含工程机械/农机/发电/出口多元应用）不同，二者不存在直接换算关系。

**内生动力→外生拉动→博弈空间三重验证**：
- 内生：产能利用率当前72%（74.3万台/102万台产能），提升空间充足
- 外生：国四/国五52万辆+淘汰需求+以旧换新补贴延续（2026-12-31）+AI数据中心建设
- 博弈：玉柴追赶凶猛（H1燃气机+31%）但潍柴在13L+大马力技术壁垒短期内难以被突破；新能源重卡渗透率超预期（6月约45%）加速柴油机长期份额流失，但潍柴三电同步放量对冲

### 2.2 利润边际变化的核心驱动

**正面因素**（增利）：
1. 凯傲效率计划一次性费用消除 → 管理费率下降0.25-0.35pct，增利约6-8亿（H1已兑现：凯傲净利润+100%+）
2. 大缸径/数据中心发动机量价齐升 → 高毛利产品占比提升，结构性推升综合毛利率
3. 重卡总量超预期 → 发动机/变速箱/车桥规模效应释放，产能利用率从72%回升至80%+
4. 新能源三电放量（Q1 16.9亿元，+200%）→ 收入增量但利润率偏低

**负面因素**（减利）：
1. **天然气发动机销量下滑（新增）** → 5-6月燃气重卡市场连续负增长（LNG气价倒挂），潍柴燃气机H1销量5.8万台（+22%）但Q2起边际转弱；天然气发动机利润率高于同排量柴油机，此消彼长拖累结构
2. 中小马力柴油发动机价格竞争 → ASP下行压力，影响动力总成板块毛利率
3. 新能源三电仍处投入期 → 烟台产业园折旧开始计提，早期利润率偏低
4. 原材料（钢材/铜/铝）价格高位波动 + 2026Q1汇兑损失5.7亿元（财务费用率+0.9pct）

**综合净影响**：正面因素＞负面因素，2026-2027年利润率有望温和改善，但天然气发动机销量下滑与汇兑损失是2026年两大边际扰动。

### 2.3 盈利质量研判

**2025年毛利率下滑的真因**（拆解分析）：
- 动力总成板块毛利率-1.62pct至17.85% → **价格竞争（60%）+成本上行（40%）**
  - 中小马力柴油机面临玉柴/全柴价格战
  - 钢材/有色金属价格2025年处于高位
  - 新能源重卡替代效应初显，柴油机结构性降价压力
- 智慧物流毛利率-0.35pct → 凯傲效率计划相关（一次性）
- 整体毛利率-0.95pct中，约0.5pct为结构性因素（新能源替代），约0.45pct为一次性或周期性因素

**2026-2027年毛利率修复逻辑**：
- 凯傲效率计划消除 → 智慧物流毛利率恢复（+0.3-0.4pct，H1已兑现利润率7.6%）
- 大缸径/数据中心高毛利产品放量 → 动力总成结构优化（+0.2-0.3pct）
- 产能利用率上升 → 制造费用摊薄（+0.1-0.2pct）
- 柴油价格竞争持续 + 燃气机销量下滑 → 基础业务毛利率承压（-0.1-0.3pct）
- **合计**：毛利率有望从21.48%回升至22.0-22.5%

## 四、分部估值（SOTP）利润模拟

潍柴各业务板块属性差异显著，分部利润模拟如下：

### 4.1 分部利润模拟（2026E中性情景，修订）

| 业务板块 | 营收（亿元） | 毛利率 | 总期间费用率 | K系数 | 有效税率 | 板块模拟净利（亿元） |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| 动力总成/整车/零部件 | 1,110 | 18.5% | 13.0% | 1.0 | 18% | **50.1** |
| 智慧物流/凯傲 | 955 | 27.0% | 13.0% | 1.0 | 25% | **33.4** |
| 农业装备 | 202 | 16.5% | 13.0% | 1.0 | 18% | **5.8** |
| 电力能源/大数据 | 105 | 32.0% | 13.0% | 1.2 | 18% | **14.1** |
| 其他零部件 | 130 | 15.0% | 13.0% | 0.8 | 18% | **4.9** |
| 其他 | 103 | 20.0% | 13.0% | 1.0 | 18% | **5.9** |
| **合计** | **2,555\*** | | | | | **114.2** |

*注：①板块营收合计2,605亿元，与合并口径2,555亿元差额约50亿元为板块间内部交易抵消。②凯傲行采用P*Q模型实际预测（4.0-4.5亿欧元×汇率7.85≈31-35亿元，取中值33.4亿元）：凯傲为高营收、低净利率（约3.5%）的并购整合型业务，若按框架公式（毛利率27%−费用率13%）计算将得到约100亿元净利，与凯傲实际盈利水平（2026H1净利率3.7%）严重不符，故该行不适用K系数公式，改以P*Q模型预测值为准。其余板块按框架公式：板块净利=营收×(毛利率−费用率×K)×(1−税率)。*

**勾稽校验**：板块模拟净利合计114.2亿元为合并口径（含少数股东）。2026E合并净利润约为168亿元（归母138亿+少数股东约30亿），差额约54亿元主要源于：①SOTP公式未纳入公司层面非经营性收益（投资收益、其他收益、公允价值变动，2026Q1合计约9亿元）及利息收入；②板块间费用分摊与有效税率的近似误差；③凯傲板块采用P*Q模型净利率低于公式隐含值。**SOTP用于板块结构与利润池分布的结构性参考，最终归母净利138亿元以P*Q模型（§2.1）为准。**

## 五、模块五核心结论

1. **2026-2027年归母净利润预测（中性，修订）**：138亿 / 172亿，对应EPS 1.60 / 1.99元，同比增速+26% / +25%。

2. **增长核心驱动力排序**：
   - 数据中心柴发（增量最大、确定性最高、利润率最佳）
   - 重卡总量超预期复苏（H1批发+22.6%，国四/国五置换）
   - 凯傲效率计划利润修复（H1已兑现：净利润+100%+）
   - 国七催化预期（2027年起逐步体现）
   - 新能源三电（Q1营收16.9亿元+200%，基数小弹性大）
   - 天然气发动机（短期受LNG气价压制，7月起边际改善）

3. **主要下行风险**：LNG气价反弹压制天然气重卡、新能源渗透率超预期加速侵蚀柴油机、原材料价格上涨、汇率波动（2026Q1汇兑损失5.7亿元已显现）。

4. **概率加权EPS**：2026E 1.60元，2027E 2.00元。

5. **逻辑继承校验**：模块一识别的毛利率下滑趋势（21.48%）在本次预测中已通过凯傲修复（H1利润率7.6%兑现）+大缸径结构优化给予适当修复（→22.0%），但未假设显著反弹（保守策略）。模块二新能源渗透率超预期（6月约45%）与天然气重卡下滑已通过下调天然气发动机预测（18-20万→12-14万台）与上调重卡总量予以反映。模块三玉柴追赶压力已通过假设中小马力竞争持续（ASP承压）予以反映；凯傲H1实际业绩与模块二判断一致。
