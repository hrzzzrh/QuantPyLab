# 研报章节二：产业周期与终端穿透

**研究日期：2026年11月05日**

---

## 一、产业生命周期与库存节奏

### 1.1 重卡行业：存量更新主导，上行周期斜率放缓

中国重卡行业已从"经济周期品"进入**存量更新主导阶段**。国内重卡保有量约700万辆（含52万辆国四重卡），合理更新周期8-10年，中期年更新需求中枢约90-110万辆。

**周期定位**：重卡行业正处于新一轮上行周期初期，且2026年上半年实际销量超预期验证了上行斜率。

| 年份 | 重卡批发销量（万辆） | 同比 | 备注 |
| :--- | :--- | :--- | :--- |
| 2022 | 67.2 | -52.0% | 周期低谷 |
| 2023 | 90.2 | +34.2% | 触底回升 |
| 2024 | 90.2 | — | 底部企稳 |
| 2025 | 114.4 | +26.8% | 政策驱动放量 |
| 2026H1 | 66.09 | +22.6% | 近五年同期新高（6月单月11.66万辆，+19.2%） |
| 2026年1-8月 | 82.8 | +16.0% | 8月8.3万辆（环比-1%、同比-9.4%），首次两连降；新能源2.2万辆+35%同比、-23%环比，增速回落 |
| 2026年1-9月 | 92.94 | +12.96% | 近五年同期最高；9月9.87万辆（环比+15%、同比-7%），同比“3连降”，累计增幅较8月末收窄约3个百分点 |
| 2026年1-10月 | 102.1 | +10% | 10月9.2万辆（环比-7%、同比-13%），同比“4连降”；出口同比约+20%，新能源重卡3.4万辆、渗透率约55% |

*数据来源：中汽协、第一商用车网、交强险终端、公司公告/投资者关系活动记录表、KION季报、康明斯财报；行业媒体与公众号仅作线索，关键数字以公告/协会/官方季报为准。*

**库存动力学**：
- 2025Q4末重卡库存环比+0.6万辆，为2021年以来首次Q4加库存
- 2026Q1末库存环比+4.0万辆，补库信号明确
- 2026年9月行业整体库存-0.83万辆（企业-0.07万、渠道-0.76万），总库存系数1.6，处于合理水平；10月行业仍在去库存
- **2026年7-10月**：批发销量8.40→8.3→9.87→9.2万辆，同比-1.1%→-9.4%→-7%→-13%，连续四个月同比下滑。回落主因AEBS法规7月中旬切换透支、以旧换新政策效果减弱、货运运价低迷、行业去库存及去年同期高基数；**“金九银十”成色不足，但1-10月累计102.1万辆仍为近五年最好，中期上行周期尚未被证伪，斜率已明显放缓**

**关键增长驱动**：
1. **国四淘汰政策**：国四重卡保有量52万辆，以旧换新政策已确认延续至2026年12月31日（报废国三/国四最高补4.5万元、换国六柴油最高补9.5万元、置换新能源最高补14万元）
2. **国五置换前奏**：地方政策已开始收紧国五卡车路权，国七标准预计2026年底-2027年公开征求意见、2028年试点、2029-2030年全国推广，将催生集中置换
3. **国七切换催化**：参照国五切国六经验（透支约65万辆），国七切换期间国内年销量可达120万辆；国七征求意见稿已于2026年4月通过技术审查，但截至11-04仍未公开征求意见，时点后移

**牛鞭效应辨析**：2026H1批发66.09万辆（+22.6%），其中国内43.9万辆（+10.3%）、出口约22.3万辆（+43%，中汽协口径；海关总署口径22.2万辆、+57.2%——两口径差异源于统计范围，非洲跃升第一大出口市场、H1出口非洲9.5万辆+75%）。国内增长主要受国四/国五置换政策驱动，但1-6月终端需求持续放量（6月交强险口径终端同比增长约20%），需求韧性并非单纯政策透支，终端物流需求稳中有升。

### 1.2 工程机械：国内外共振，温和复苏延续

中国工程机械行业在经历2021-2023年深度调整后，2025年进入全面复苏通道。

| 年份 | 挖掘机销量（万台） | 同比 |
| :--- | :--- | :--- |
| 2023 | 19.5 | -25.4% |
| 2024 | 20.0 | +2.6% |
| 2025 | 23.5 | +17.0% |
| 2026M1-6 | 15.2 | +26.4% |

**周期定位**：上行周期起点，东吴证券预测本轮周期于2028年见顶（高点挖机销量25万台），当前处于斜率较低的温和复苏通道。

**库存状态**：行业在经历2023-2024年去库后，库存水平趋于健康，企业补库意愿回升。

**结构亮点**：
- 电动装载机2026年1-6月销量2.5万台（+82.4%），渗透率加速攀升
- 非洲/拉美出口高景气（2025年出口+14.5%，2026Q1出口+33.5%）

### 1.3 叉车/智慧物流：长周期稳定增长，电动化结构性红利（2026H1验证）

全球叉车市场2025-2030年CAGR约5%，中国市场约5.9%。行业处于**成熟期电动化升级阶段**。

**核心趋势（凯傲集团2026年7月30日发布2026H1财报，实际验证）**：
- 凯傲2026H1集团营收56.87亿欧元（+3.5%），其中智能自动化（IAS）16.29亿欧元（+18.0%）、叉车（ITS）40.79亿欧元（-1.4%）
- 2026H1调整后EBIT 4.30亿欧元（+11.6%），利润率7.6%（+0.6pct）
- 2026Q2订单28.09亿欧元（-19.8%，受2025Q2创纪录高基数及Q1预购透支影响），订单簿52.1亿欧元（+2%）
- 凯傲2026全年指引：集团营收115.25-120.25亿欧元（+2.0%~6.4%）、调整后EBIT 9.95-11.05亿欧元（指引中值较年初微降，反映对下半年宏观与地缘的谨慎）
- 欧洲平衡重式叉车电动化率已升至68%，中国仅35%，替代空间巨大

**解读**：凯傲2026H1利润修复（净利2.08亿欧元，同比+333%）兑现效率计划红利，但Q2订单下滑（高基数+宏观谨慎）提示全球叉车需求进入温和增长而非爆发阶段——**对潍柴为"利润修复兑现、订单动能转平"的中性偏正信号**。

### 1.4 农业装备：补贴驱动结构升级，非总量扩张

农机行业已告别普及增量阶段，进入存量替换+结构升级期。2026年国家大规模设备更新政策落地，超长期特别国债资金达1851亿元，驱动老旧农机报废更新。行业增长逻辑从"品类扩张"转向"智能化+绿色化+大马力化"。

### 1.5 数据中心柴发：爆发式增长新赛道（关键增量极，2026H1持续验证）

全球AI资本开支进入爆发阶段（2026年北美四大科技公司AI资本开支合计超6000亿美元，同比+70%+），推动数据中心建设井喷。柴发（柴油发电机组）作为A级数据中心刚性备用电源，需求确定性极强。

| 指标 | 数值 |
| :--- | :--- |
| 2026年全球柴发市场规模 | ~226亿美元 |
| 全球柴发需求 | ~4.2万台 |
| 2025年国内数据中心柴发需求 | ~5600-6000台 |
| 2025年国内数据中心柴发市场规模 | ~91亿元（+50%） |
| 2028年国内数据中心柴发市场规模 | ~181亿元 |
| 数据中心备用电源需求功率 | ~152GW |
| 外资机组价格 | >300万元/台（+20%） |
| 北美2030年前年均电力缺口 | >20GW |

**供需矛盾突出（2026Q3潍柴兑现验证）**：潍柴2026年1-9月M系列大缸径发动机销量超1.1万台（同比+40%以上），其中数据中心柴发超2700台（同比+近200%），Q3单季约1300台；上半年数据中心柴发1400余台已超2025年全年。康明斯2026Q2 Power Systems +19%（北美+19%/国际+19%）、全年指引二度上修至+10-13%（原+8-11%）、订单排产仍至2027-2028年/交付12-18个月且Q2 EBITDA率-0.9pp（激励薪酬致紧平衡）；康明斯Q3财报定于2026-11-05，截至本报告日尚未发布，最新可比数据仍为Q2。卡特彼勒/MTU订单排期至2026-2027年；罗罗（MTU）苏州扩产（与玉柴合资首台mtu新2000系列已下线）——外资扩产需2-3年产业链协同，国产替代窗口持续，国产交期2-3个月为外资1/6-1/4。玉柴H1 AI数据中心发动机销量约1800台（含MTU合资），全年指引约3500台，是国产阵营中最接近的追赶者。

## 二、终端需求穿透与跨期断层审计（核心分析）

### 2.1 潍柴动力的终端产品画像

潍柴动力不是一家简单的发动机制造商，其产品负载于五大终端形态：

| 终端形态 | 潍柴核心产品 | 下游应用场景 |
| :--- | :--- | :--- |
| 重型卡车 | 柴油/天然气发动机+陕重汽整车 | 公路物流、矿产运输、基建 |
| 工程机械 | 柴油发动机+液压件 | 挖掘机、装载机、起重机、矿卡 |
| 农业机械 | 柴油发动机+潍柴雷沃整机 | 拖拉机、收割机、播种机 |
| 叉车/仓储 | 凯傲林德/斯蒂尔叉车 | 制造业、电商物流、港口 |
| 发电设备 | M系列大缸径发动机 | 数据中心、油田、矿山备电 |

### 2.2 终端景气度审计（2026-2028年）

**重卡终端**：
- 国海证券：中期年更新需求中枢90-110万辆，国七切换期间年销量120万辆
- 中汽协：2026年1-9月批发92.94万辆（+12.96%）、1-10月102.1万辆（+10%），均为近五年同期最好；但9月9.87万辆（-7%）、10月9.2万辆（-13%）已连续四个月同比下滑，Q4进入“政策透支+去库存+运价低迷”叠加期
- 出口：1-9月33.8万辆（+40%）、9月4.1万辆（+29.4%），非洲/东南亚/拉美仍是主要增量；出口是2026年重卡唯一的确定性支撑
- 终端：9月国内重卡终端6.6万辆（-21.1%），以旧换新效果减弱、AEBS透支、货运运价低迷三重压制
- **结论**：2026全年重卡批发预计120-122万辆（+5%-7%），Q4同比双位数下滑已成定局；2027年国五集中更新+出口可支撑115-125万辆，但“总量横盘、结构剧变”是主基调——新能源替代柴油的速度快于总量增长

**工程机械终端**：
- 中诚信国际：2026年景气度全面回稳，"稳定弱化"→"稳定"
- 东吴证券：2026-2028年挖机需求年均增速30%+（理论值），实际因资金到位率呈现温和复苏
- 2026年1-6月挖机销量同比+26.4%，装载机+26.7%
- **结论**：国内温和复苏+海外高景气，工程机械处于上行周期，是潍柴发动机非道路应用的重要缓冲垫

**数据中心柴发终端**：
- 华源证券/国海证券：AIDC建设需求高景气延续，2026年为井喷之年
- 北美缺电将是一个长期约束（2027-2030年年均电力缺口>20GW）；IEA测算2030年全球AI数据中心用电量为2025年的3倍
- 康明斯2026Q2兑现：Power Systems +19%（$22.55亿，EBITDA 24.5%）、全年指引二度上修至+10-13%（原+8-11%）、H2强于H1；Q3财报定于11-05，尚未发布
- 潍柴2026年1-9月数据中心柴发超2700台（+近200%）、Q3单季约1300台、M系列大缸径超1.1万台（+40%）；气发Q4开始交付，SOFC多个示范项目投运
- 玉柴H1 AI数据中心发动机约1800台（含MTU合资）、全年指引约3500台，国产阵营竞争升温
- **结论**：柴发需求处于爆发期，未来3-5年高景气确定性极强；但2027年需关注外资扩产（罗罗苏州2-3年）与玉柴/MTU放量对份额的边际挤压

**农业装备终端**：
- 以旧换新政策+超长期国债支撑存量更新
- 2026年Q1农机出口+26.5%
- 大型化、智能化产品保持增长
- **结论**：总量平稳、结构优化，中高速增长可期

**叉车/物流终端**：
- 凯傲2026Q3：营收28.35亿欧元（+4.8%）、调整后EBIT 2.03亿欧元（+6.5%）、净利润1.02亿欧元（-14.8%）；Q3订单26.51亿欧元（-0.9%）、订单簿48.84亿欧元（-0.2%）
- 分业务：IAS营收8.90亿欧元（+15.8%）、调整后EBIT 0.66亿欧元（+38.8%）；ITS营收19.55亿欧元（+0.6%）、调整后EBIT 1.63亿欧元（-4.4%）
- 9M：营收85.22亿欧元（+3.9%）、调整后EBIT 6.33亿欧元（+9.9%，利润率7.4%）、净利润3.09亿欧元（+85%）；但9M自由现金流仅1.21亿欧元（-69.2%）
- **结论**：IAS结构性高增、ITS承压，凯傲利润修复仍在但Q3单季净利与现金流边际转弱；2026全年净利润预计4.2-4.4亿欧元，接近原指引下沿

### 2.3 动能溯源与透支审计

**关键问题一：重卡需求的增长是内生还是外生？**

增长动能呈现**双轮驱动**特征：
- **内生动力（60%）**：存量更新周期自然回归。国四保有量52万辆需在2-3年内淘汰，按自然经济寿命8-10年计算的年更新中枢90-110万辆。2026年1-9月批发92.94万辆（+12.96%）验证内生韧性，但9-10月连续同比下滑说明自然更新不足以对冲政策透支与运价低迷。
- **外生干预（40%）**：以旧换新补贴政策（延续至2026-12-31，报废国三/国四最高补4.5万、换新能源最高补14万）提前释放部分置换需求。补贴提振的是“时间”而非“总量”，且2026年国四存量较2025年大幅减少，边际刺激递减；2027年政策是否延续仍不确定。

**关键问题二：是否存在"需求前置"导致的跨期断层风险？**

**存在且正在兑现，新能源渗透加速已改变断层结构**。参照国五切国六的经验（透支约65万辆前置需求），国七切换（预计2028年试点、2029-2030年全国推广）前可能出现抢装潮。但当前更重要的变化是：
1. 2026年9月新能源重卡终端渗透率50.28%、10月约55%，连续两个月站上50%，1-9月累计38.1%（22.64万辆，+64%）——**新能源替代已从“远期隐忧”变为“当期现实”，且速度快于国七切换节奏**
2. 天然气重卡9月0.73万辆（-69%）、10月约0.7万辆（-68%），LNG 10月均价6757元/吨（环比+10.2%、同比+72.6%），气柴价差倒挂，燃气车短期无修复基础
3. 海外出口（1-9月33.8万辆，+40%）提供需求缓冲，但出口以柴油车为主，无法对冲国内柴油机份额流失

**跨期断层风险评级**：高（4.0/5，较上期3.5/5上调）。2026Q4-2027Q1重卡批发同比双位数下滑已定，2027年国五集中更新可部分对冲，但新能源渗透率若在2027年升至55%-60%，柴油发动机国内需求将面临“总量横盘+份额萎缩”的双重挤压。

**关键问题三：数据中心柴发的高增长是否可持续？**

**可持续性强且确定性高**。核心逻辑：
1. 2030年美国数据中心电力负荷预计70GW，2027-2030年年均缺口>20GW——这不仅是"趋势"，而是物理基础设施的硬约束
2. 柴发作为A级数据中心刚性配置，不可能被短期替代；气发/ SOFC作为主电方案打开第二、第三曲线
3. 外资供应链紧张（康明斯排产至2027-2028年、交付12-18个月；罗罗扩产周期2-3年）而非短期震荡，供需缺口至少持续3年
4. 国内AI资本开支（字节、阿里、腾讯）2026年指引积极，国内需求接力海外；潍柴已进入全球头部云厂商核心供应链

**透支风险评级**：极低（1/5）。AI基础设施建设处于早期阶段，电力基础设施的建设周期远长于算力需求增长速度，缺电将是中长期结构性矛盾；但需警惕2027年外资扩产、玉柴/MTU放量带来的份额竞争，以及美国AI资本开支若阶段性降温导致的订单波动。

## 三、供需边际与压力传导

### 3.1 重卡行业供需平衡审计

**供给端**：
- 中国重汽2026年1-9月累销27.71万辆、份额29.8%（同比+2.5pct），龙头优势扩大；陕汽13.77万辆、份额14.8%；一汽解放15.82万辆、份额17.0%
- 行业产能充足但非显著过剩；新能源重卡产能快速扩张，2026年1-9月新能源重卡22.64万辆（+64%），传统柴油产能利用率下降
- 出口是产能消化的核心出口：1-9月重卡出口33.8万辆（+40%），9月4.1万辆（+29.4%），非洲/东南亚/拉美为主

**需求端**：
- 内需：年更新中枢90-110万辆；2026年1-9月国内终端受以旧换新退坡、AEBS透支、运价低迷影响，9月终端6.6万辆（-21.1%）
- 出口：1-9月33.8万辆（+40%），10月预计同比+20%，是Q4唯一确定性增量
- 库存：9月行业整体库存-0.83万辆（企业-0.07万、渠道-0.76万），总库存系数1.6；10月继续去库存

**供需边际判断**：**总量“前高后低”、结构“油退电进”**。2026年1-10月批发102.1万辆（+10%），全年预计120-122万辆；但7-10月连续四个月同比下滑（-1.1%/-9.4%/-7%/-13%），Q4同比双位数下滑已成定局。新能源重卡9月渗透率50.28%、10月约55%，月度渗透率连续两个月超过50%，行业已进入“燃油退、电动进”的存量置换阶段；天然气重卡9月0.73万辆（-69%）、10月约0.7万辆（-68%），渗透率仅11%，LNG高价使其短期失去经济性。**2027年重卡总量预计115-125万辆，国五集中更新+出口可部分对冲政策退坡，但柴油发动机国内需求将面临“总量横盘+份额萎缩”的双重挤压。**

### 3.2 潍柴终端的压力传导特征

**柴油发动机板块——“总量横盘、份额被新能源侵蚀”，但高价值产品对冲使毛利率逆势上行**：

这是模块一发现的核心问题（2025年动力总成毛利率-1.62pct至17.85%）的产业级解释。2026年三季报显示，**新能源重卡渗透率已从“远期隐忧”变为“当期现实”**：

| 年份 | 天然气重卡渗透率 | 新能源重卡渗透率 | 柴油重卡占比 |
| :--- | :--- | :--- | :--- |
| 2024 | ~12% | ~20%（商用车口径；重卡口径约15%） | ~70% |
| 2025 | ~17% | ~29%（商用车口径；重卡口径约25%） | ~55% |
| 2026E（修订） | ~13-14%（受LNG气价压制，9月11.1%、10月约11%） | **~40%（1-9月累计38.1%，9月50.28%、10月约55%，连续两个月>50%）** | ~45-47% |

*注：渗透率未特别标注时均为交强险重卡口径（终端实销）；交强险终端与国内批发口径差异约5-8pct，含出口的批发口径渗透率约33-35%（9月），不可将50.28%的终端渗透率直接套用于含出口的批发总量。表中“柴油重卡占比”为市场结构口径（含出口），与潍柴发动机销量口径（含工程机械/农机/发电/出口多元应用）不同，二者不可直接换算。*

**新能源渗透率在9-10月连续突破50%，是本期最重要的行业级变量**：
- 2026年9月新能源重卡3.31万辆（+37%）、渗透率50.28%；10月约3.4万辆（同比+近70%）、渗透率约55%；1-9月累计22.64万辆（+64%）、累计渗透率38.1%
- 交通运输部等11部门《推动新能源重卡规模化应用实施方案》明确2030年渗透率40%、保有量160万辆——**销量渗透率目标已在2026年9-10月单月提前实现，政策目标不再构成约束，真正的约束转为保有量、跨省补能网络与干线运营强度**
- 新能源重卡对柴油发动机需求的替代提前2-3年兑现；潍柴三电业务1-9月电池销量9.3GWh（+140%）、收入48.5亿元，放量对冲部分侵蚀，但利润率远低于传统柴油机
- **潍柴终端发动机份额承压**：9月终端配套0.83万辆（同比-48.8%），整体份额12.6%（较2025年全年-6.6pct）；Q3发动机终端约1.8万台（同比-54.3%），其中天然气1.0万台（-63.8%）、柴油0.8万台（-31.2%）

**天然气发动机——LNG气价冲击导致2026年全年“先扬后抑”，9-10月仍在谷底**：
- 2026年3月起受中东地缘冲突影响，LNG价格飙升（4月出厂价超5300元/吨、5-6月超6200元/吨），车用LNG加气价一度高于柴油零售价
- 天然气重卡终端销量：6月1.2万辆（-12%）、7-8月降至6000辆级、9月0.73万辆（-69%）、10月约0.7万辆（-68%）；9月渗透率11.1%、10月约11%
- 1-9月累计约12.8万辆，同比转负（1-8月12.05万辆、-1%），"金三银四"（3月3.2万辆为史上第二高）的涨幅已被下半年完全吞噬
- **LNG价格10月继续上涨**：国内主产地LNG均价6757元/吨（环比+10.2%、同比+72.6%），全国接货均价7153元/吨（环比+12.7%、同比+66.4%）；各地加气价普遍7元/kg以上，部分8元/kg，气柴价差仍倒挂
- **潍柴H1燃气机5.8万台（+22%）、市占率53.7%（+1.9pct），但Q3燃气机约1.0万台（-63.8%）；9月燃气机终端份额56.48%（较2025年全年+4.72pct），份额仍在提升，但行业总量萎缩使绝对量承压**——需LNG回落至5元/kg以下才能触发实质性回暖，基准情景下修复时点推迟至2027年

**传导时滞与弹性**：
- 柴油→天然气替代对潍柴是**结构内转化**（潍柴在天然气发动机市占率53.7%-56.5%），利润率差异不大
- 柴油→纯电动替代对潍柴是**实质性损失**（三电业务体量小+利润率低），且替代速度已超预期；9月新能源渗透率50%意味着国内重卡新增销量中约一半不再需要柴油/天然气发动机
- 对冲力量来自三条：①出口（1-9月重卡出口+40%，海外电动化渗透率低）；②非道路（工程机械/农机/发电）；③数据中心柴发/气发/ SOFC。Q3毛利率22.88%证明高价值产品结构上移已足以对冲传统动力量的下滑
- **但这一对冲并非无限**：若2027年新能源渗透率升至55%-60%，传统动力利润池的萎缩速度可能超过数据中心增量，届时毛利率将再次承压

**波动放大效应**：下游重卡整车企业（含陕重汽）在新能源转型中面临价格战，对上游发动机的压价力度加大。重卡整车的“反内卷”能否传导至发动机环节，取决于潍柴在特定领域的议价权。在天然气大马力领域（潍柴独家掌控15L+燃气机技术标准），定价权较强；在柴油中小马力领域，面临玉柴、康明斯的激烈竞争。

### 3.3 数据中心柴发——供不应求，价格上行（2026Q3持续验证）

这是潍柴当前最具**定价权的赛道**：
- 全球供给缺口持续扩大，外资扩产谨慎且周期长（罗罗苏州工厂扩产为2-3年周期；康明斯排产至2027-2028年）
- 潍柴2026年1-9月数据中心柴发超2700台（+近200%），Q3单季约1300台；2026H1 1400余台已超2025年全年
- 国产替代率从2024年的不足20%跃升至2025年30%+，2026年继续提升
- 2MW柴发机组价格从2024年约200万元涨至当前220-300万元，涨价趋势延续；纯外资原装机组已超300万元/台
- 博杜安数据中心全球装机2026年9月达到5000台（公司官网），全球渠道与客户认证构成先发优势

**弹性测算**：潍柴2026年1-9月M系列大缸径超1.1万台（+40%）、数据中心柴发超2700台（Q3约1300台），全年数据中心柴发有望达3600-3900台（Q4 900-1200台）。假设单台均价150万元，对应收入约54-59亿元（较原2026E 45-60亿元上沿）。气发产品Q4开始交付，2027年有望快速放量；SOFC多个示范项目投运，产能按计划建设。若2027年数据中心柴发交付5000-6000台、均价上涨5%-10%，该板块收入可达85-105亿元——增长弹性极大，且利润率远高于传统动力总成（大缸径发动机毛利率预估30%+）；燃气发电机组（2.5-3MW）与SOFC构成第二、第三增长曲线。

### 3.4 凯傲集团（智慧物流）——穿越周期的稳定器（利润修复延续，Q3边际转弱）

凯傲集团（KION）2026Q3营收28.35亿欧元（+4.8%）、调整后EBIT 2.03亿欧元（+6.5%，利润率7.2%）、净利润1.02亿欧元（-14.8%）；9M营收85.22亿欧元（+3.9%）、调整后EBIT 6.33亿欧元（+9.9%，利润率7.4%）、净利润3.09亿欧元（+85%）。核心特征：
- **IAS是利润修复主引擎**：Q3营收8.90亿欧元（+15.8%）、调整后EBIT 0.66亿欧元（+38.8%）；9M营收25.19亿欧元（+16.9%）、调整后EBIT 1.72亿欧元（+36.6%）
- **ITS承压**：Q3营收19.55亿欧元（+0.6%）、调整后EBIT 1.63亿欧元（-4.4%）；9M营收60.34亿欧元（-0.7%）、调整后EBIT 5.29亿欧元（-0.2%）
- **订单与现金流是领先预警**：Q3订单26.51亿欧元（-0.9%）、9M 84.45亿欧元（-4.9%）；Q3自由现金流0.99亿欧元（-57.2%）、9M 1.21亿欧元（-69.2%）；净金融负债11.96亿欧元（较2025年末5.84亿欧元翻倍）
- 与潍柴发动机业务形成天然对冲：物流景气→叉车需求↑，重卡下行→叉车平稳；但KION的利润修复更多来自效率计划与IAS项目，而非终端需求全面复苏
- **风险提示**：Q3净利-14.8%、FCF-57.2%、订单-0.9%，显示欧洲需求与现金流压力仍在；2026全年净利润预计4.2-4.4亿欧元，接近原指引下沿；2027年增速依赖欧洲宏观回暖与IAS订单转化，若Q4订单继续低于28亿欧元/季，商誉减值风险需重新评估

## 四、【强制复核项】终端穿透审计结论

- [x] **已穿透终端景气度**：重卡（1-10月102.1万辆+10%，但7-10月四连降、Q4同比双位数下滑）、工程机械（复苏延续）、数据中心柴发（9M 2700台+近200%，Q3约1300台）、农机（结构升级）、叉车（IAS利润修复、ITS与现金流转弱）五大终端未来2年景气度分化，唯一确定性上行的是数据中心电力能源，最大风险是新能源重卡渗透率连续两个月>50%对柴油机份额的侵蚀。
- [x] **已审计跨期需求移位**：国七切换前的重卡抢装可能造成2028-2029年前置需求，但中期更新中枢（90-110万辆）不受影响；新能源渗透率已在2026年9-10月连续突破50%，替代进程比原预期提前2-3年，跨期断层风险评级上调至4.0/5；柴发赛道暂无透支担忧。
- [x] **已分析供需边际与压力传导**：传统柴油发动机面临“总量横盘+份额萎缩”的结构性压力，9月潍柴终端配套-48.8%、份额12.6%（-6.6pct）；天然气发动机受LNG高价压制（9月-69%、10月-68%）；数据中心柴发是当前潍柴最具供需缺口的增长极，但2027年需警惕玉柴/MTU与外资扩产的竞争。

## 五、模块二核心结论

1. **重卡行业总量“前高后低”，2027年进入横盘期**：2026年1-10月批发102.1万辆（+10%）为近五年最好，但7-10月连续四个月同比下滑（-1.1%/-9.4%/-7%/-13%），Q4同比双位数下滑已成定局；全年预计120-122万辆（+5%-7%），较年初125万辆预期下修。2027年国五集中更新+出口（1-9月+40%）可支撑115-125万辆，但总量增长已让位于结构变化。潍柴多缸柴油机1-9月68.85万台（+20.02%）、份额20.30%（+1.77pct），商用车柴油机份额23.91%（+2.12pct），传统基本盘仍强，但发动机终端配套量已开始下滑。

2. **新能源重卡渗透率9-10月连续突破50%，是本轮最重要的行业级变量**：9月3.31万辆（+37%）、渗透率50.28%；10月约3.4万辆（+近70%）、渗透率约55%；1-9月累计22.64万辆（+64%）、累计渗透率38.1%。交通运输部2030年40%的销量渗透率目标已在2026年单月提前实现，政策目标不再构成约束。潍柴三电1-9月电池9.3GWh（+140%）、收入48.5亿元，放量对冲部分侵蚀，但利润率远低于传统柴油机；**2027年若渗透率升至55%-60%，柴油机国内利润池的萎缩速度可能超过数据中心增量，这是估值中枢的最大压制项**。

3. **天然气发动机全年“先扬后抑”，9-10月仍在谷底**：LNG 10月主产地均价6757元/吨（环比+10.2%、同比+72.6%），加气价普遍7元/kg以上，气柴价差倒挂；天然气重卡9月0.73万辆（-69%）、10月约0.7万辆（-68%），渗透率仅11%；1-9月累计约12.8万辆，同比转负。潍柴H1燃气机5.8万台（+22%）、市占率53.7%，Q3约1.0万台（-63.8%），9月终端燃气份额56.48%（+4.72pct）——份额仍在提升，但行业总量萎缩使绝对量承压，修复需LNG回落至5元/kg以下，基准情景推迟至2027年。

4. **数据中心柴发是增长极中“最硬的确定性”，且2026年已上修**：全球AI资本开支爆发+电网瓶颈+外资产能不足（康明斯排产至2027-2028年），三重因素叠加形成至少3年的供需缺口。潍柴2026年1-9月数据中心柴发超2700台（+近200%）、Q3约1300台，全年有望3600-3900台，较原2800-3500台上修；气发Q4开始交付、SOFC示范项目投运，第二、第三曲线启动。该板块收入有望从2025年约21亿元增至2026年54-59亿元、2027年85-105亿元。

5. **凯傲智慧物流提供周期对冲，但Q3边际转弱**：2026Q3净利润1.02亿欧元（-14.8%）、9M 3.09亿欧元（+85%）；IAS收入+15.8%、调整后EBIT+38.8%，ITS调整后EBIT-4.4%；Q3订单-0.9%、FCF-57.2%、净负债翻倍至11.96亿欧元。利润修复仍在，但订单与现金流领先指标转弱，2027年增速依赖欧洲宏观回暖与IAS订单转化，商誉减值风险需持续跟踪。

6. **农机板块稳中求进**：潍柴雷沃稳居国内农机第一品牌，CVT动力总成打破进口垄断。受益于设备更新政策和出口增长，确定性较强但弹性有限。
