# 研报章节二：产业周期与终端穿透

**研究日期：2026年08月03日**

---

## 一、产业生命周期与库存节奏

### 1.1 重卡行业：存量更新主导，3-5年向上周期确立

中国重卡行业已从"经济周期品"进入**存量更新主导阶段**。国内重卡保有量约700万辆（含52万辆国四重卡），合理更新周期8-10年，中期年更新需求中枢约90-110万辆。

**周期定位**：重卡行业正处于新一轮上行周期初期，且2026年上半年实际销量超预期验证了上行斜率。

| 年份 | 重卡批发销量（万辆） | 同比 | 备注 |
| :--- | :--- | :--- | :--- |
| 2022 | 67.2 | -52.0% | 周期低谷 |
| 2023 | 90.2 | +34.2% | 触底回升 |
| 2024 | 90.2 | — | 底部企稳 |
| 2025 | 114.4 | +26.8% | 政策驱动放量 |
| 2026H1 | 66.09 | +22.6% | 近五年同期新高（6月单月11.66万辆，+19.2%） |

**库存动力学**：
- 2025Q4末重卡库存环比+0.6万辆，为2021年以来首次Q4加库存
- 2026Q1末库存环比+4.0万辆，补库信号明确
- 2026年6月末行业库存水平合理（6月销量11.66万辆为近五年同期最高），当前处于**主动补库阶段初期**，尚未出现过度积压

**关键增长驱动**：
1. **国四淘汰政策**：国四重卡保有量52万辆，以旧换新政策已确认延续至2026年12月31日（报废国三/国四最高补4.5万元、换国六柴油最高补9.5万元、置换新能源最高补14万元）
2. **国五置换前奏**：地方政策已开始收紧国五卡车路权，国七标准2027-2028年推出将催生集中置换
3. **国七切换催化**：参照国五切国六经验（透支约65万辆），国七切换期间国内年销量可达120万辆；国七征求意见稿已于2026年4月通过技术审查、进入发布倒计时

**牛鞭效应辨析**：2026H1批发66.09万辆（+22.6%），其中国内43.9万辆（+10.3%）、出口约22.3万辆（+43%，中汽协口径；海关总署口径22.2万辆、+57.2%——两口径差异源于统计范围，非洲跃升第一大出口市场、H1出口非洲9.5万辆+75%）。国内增长主要受国四/国五置换政策驱动，但1-6月终端需求持续放量（6月交强险口径终端同比增长约20%），需求韧性并非单纯政策透支，终端物流需求稳中有升。

### 1.2 工程机械：国内外共振，温和复苏延续

中国工程机械行业在经历2021-2023年深度调整后，2025年进入全面复苏通道。

| 年份 | 挖掘机销量（万台） | 同比 |
| :--- | :--- | :--- |
| 2023 | 19.5 | -25.4% |
| 2024 | 20.0 | +2.6% |
| 2025 | 23.5 | +17.0% |
| 2026M1-6 | 15.2 | +26.4% |

**周期定位**：上行周期起点，东吴证券预测本轮周期于2028年见顶（高点挖机销量25万台），当前处于斜率较低的温和复苏通道。

**库存状态**：行业在经历2023-2024年去库后，库存水平趋于健康，企业补库意愿回升。

**结构亮点**：
- 电动装载机2026年1-6月销量2.5万台（+82.4%），渗透率加速攀升
- 非洲/拉美出口高景气（2025年出口+14.5%，2026Q1出口+33.5%）

### 1.3 叉车/智慧物流：长周期稳定增长，电动化结构性红利（2026H1验证）

全球叉车市场2025-2030年CAGR约5%，中国市场约5.9%。行业处于**成熟期电动化升级阶段**。

**核心趋势（凯傲集团2026年7月30日发布2026H1财报，实际验证）**：
- 凯傲2026H1集团营收56.87亿欧元（+3.5%），其中智能自动化（IAS）16.29亿欧元（+18.0%）、叉车（ITS）40.79亿欧元（-1.4%）
- 2026H1调整后EBIT 4.30亿欧元（+11.6%），利润率7.6%（+0.6pct）
- 2026Q2订单28.09亿欧元（-19.8%，受2025Q2创纪录高基数及Q1预购透支影响），订单簿52.1亿欧元（+2%）
- 凯傲2026全年指引：集团营收115.25-120.25亿欧元（+2.0%~6.4%）、调整后EBIT 9.95-11.05亿欧元（指引中值较年初微降，反映对下半年宏观与地缘的谨慎）
- 欧洲平衡重式叉车电动化率已升至68%，中国仅35%，替代空间巨大

**解读**：凯傲2026H1利润修复（净利2.08亿欧元，同比+333%）兑现效率计划红利，但Q2订单下滑（高基数+宏观谨慎）提示全球叉车需求进入温和增长而非爆发阶段——**对潍柴为"利润修复兑现、订单动能转平"的中性偏正信号**。

### 1.4 农业装备：补贴驱动结构升级，非总量扩张

农机行业已告别普及增量阶段，进入存量替换+结构升级期。2026年国家大规模设备更新政策落地，超长期特别国债资金达1851亿元，驱动老旧农机报废更新。行业增长逻辑从"品类扩张"转向"智能化+绿色化+大马力化"。

### 1.5 数据中心柴发：爆发式增长新赛道（关键增量极，2026H1持续验证）

全球AI资本开支进入爆发阶段（2026年北美四大科技公司AI资本开支合计超6000亿美元，同比+70%+），推动数据中心建设井喷。柴发（柴油发电机组）作为A级数据中心刚性备用电源，需求确定性极强。

| 指标 | 数值 |
| :--- | :--- |
| 2026年全球柴发市场规模 | ~226亿美元 |
| 全球柴发需求 | ~4.2万台 |
| 2025年国内数据中心柴发需求 | ~5600-6000台 |
| 2025年国内数据中心柴发市场规模 | ~91亿元（+50%） |
| 2028年国内数据中心柴发市场规模 | ~181亿元 |
| 数据中心备用电源需求功率 | ~152GW |
| 外资机组价格 | >300万元/台（+20%） |
| 北美2030年前年均电力缺口 | >20GW |

**供需矛盾突出（持续验证）**：康明斯订单排产至2027-2028年、交付周期12-18个月；卡特彼勒/MTU订单排期到2026年；罗罗（MTU）已在中国苏州扩产（与玉柴合资工厂首台mtu新2000系列下线）——外资扩产周期长（2-3年产业链协同），国产替代窗口持续打开。国产柴发交货期2-3个月，为外资的1/6-1/4。

## 二、终端需求穿透与跨期断层审计（核心分析）

### 2.1 潍柴动力的终端产品画像

潍柴动力不是一家简单的发动机制造商，其产品负载于五大终端形态：

| 终端形态 | 潍柴核心产品 | 下游应用场景 |
| :--- | :--- | :--- |
| 重型卡车 | 柴油/天然气发动机+陕重汽整车 | 公路物流、矿产运输、基建 |
| 工程机械 | 柴油发动机+液压件 | 挖掘机、装载机、起重机、矿卡 |
| 农业机械 | 柴油发动机+潍柴雷沃整机 | 拖拉机、收割机、播种机 |
| 叉车/仓储 | 凯傲林德/斯蒂尔叉车 | 制造业、电商物流、港口 |
| 发电设备 | M系列大缸径发动机 | 数据中心、油田、矿山备电 |

### 2.2 终端景气度审计（2026-2028年）

**重卡终端**：
- 国海证券：中期年更新需求中枢90-110万辆，国七切换期间年销量120万辆
- 国联民生证券：2026H1批发66.09万辆（+22.6%）实际验证，非俄出口延续高增，新能源渗透率加速
- 开源证券：2026H1出口22.2万辆（+57.2%），非洲跃升第一大出口市场（9.5万辆，+75%）
- 一汽解放2026H1业绩预告：归母净利2.7-3.2亿元（+1274%~1528%）——行业景气回升的直接证据
- **结论**：重卡终端需求未来2-3年处于上行通道，有政策和内生更新双重支撑，景气度稳健向上；2026H1实际销量（66.09万辆，年化超120万辆）验证并强化上行斜率

**工程机械终端**：
- 中诚信国际：2026年景气度全面回稳，"稳定弱化"→"稳定"
- 东吴证券：2026-2028年挖机需求年均增速30%+（理论值），实际因资金到位率呈现温和复苏
- 2026年1-6月挖机销量同比+26.4%，装载机+26.7%
- **结论**：国内温和复苏+海外高景气，工程机械处于上行周期

**数据中心柴发终端**：
- 华源证券/国海证券：AIDC建设需求高景气延续，2026年为井喷之年
- 北美缺电将是一个长期约束（2027-2030年年均电力缺口>20GW）
- 康明斯2026Q1上调全年指引：Power Systems收入+14-19%（此前+12-17%）、EBITDA利润率25-26%——**外资龙头对数据中心动力的需求确认**
- 潍柴2026Q1数据中心用发电机组交付500台+（+240%），迈入高速兑现期
- **结论**：柴发需求处于爆发期起点，未来3-5年高景气确定性极强

**农业装备终端**：
- 以旧换新政策+超长期国债支撑存量更新
- 2026年Q1农机出口+26.5%
- 大型化、智能化产品保持增长
- **结论**：总量平稳、结构优化，中高速增长可期

**叉车/物流终端**：
- 凯傲2026H1实际数据：IAS收入+18%、ITS收入-1.4%（需求温和）
- 凯傲Q2订单28.09亿欧元（-19.8%，2025Q2创纪录高基数+Q1预购透支）
- 凯傲2026全年指引中值微降（营收+2.0%~6.4%），反映宏观谨慎
- **结论**：全球需求温和上行（不及此前"订单拐点强反弹"预期），智能化（IAS）结构性高增，凯傲利润修复（H1净利同比+333%）为主要弹性来源

### 2.3 动能溯源与透支审计

**关键问题一：重卡需求的增长是内生还是外生？**

增长动能呈现**双轮驱动**特征：
- **内生动力（60%）**：存量更新周期自然回归。国四保有量52万辆需在2-3年内淘汰，按自然经济寿命8-10年计算的年更新中枢90-110万辆。2026H1批发66.09万辆（+22.6%）、6月单月11.66万辆（+19.2%）为近五年同期最高，验证内生韧性。
- **外生干预（40%）**：以旧换新补贴政策（延续至2026-12-31，报废国三/国四最高补4.5万、换新能源最高补14万）提前释放部分置换需求，但政策提振的是"时间"而非"总量"——淘汰的车辆终将淘汰，补贴只是加速了这一过程。

**关键问题二：是否存在"需求前置"导致的跨期断层风险？**

**存在但可控，且新能源渗透加速改变了断层结构**。参照国五切国六的经验（透支约65万辆前置需求），国七切换（预计2027-2028年）前可能出现抢装潮。但区别在于：
1. 当前国五保有量基数更大（远大于国三切换时的国四保有量），透支/置换比更低
2. **新能源重卡渗透率超预期加速（2026年5月41.5%、6月约45%，远超2026年初预期）**——传统柴油车置换需求部分被新能源替代而非顺延，跨期断层的"纯柴油口径"风险被新能源增量部分对冲
3. 海外出口（2026H1出口22.3万辆，+43%）提供了额外的需求缓冲垫

**跨期断层风险评级**：中等偏高（3.5/5）。2027年国七补贴推出后的集中释放仍可能造成2028-2029年需求回补，且新能源渗透加速对柴油发动机需求的侵蚀快于预期——**这一结构性变量已从"远期隐忧"升级为"中期现实"**。

**关键问题三：数据中心柴发的高增长是否可持续？**

**可持续性强且确定性高**。核心逻辑：
1. 2030年美国数据中心电力负荷预计70GW，2027-2030年年均缺口>20GW——这不仅是"趋势"，而是物理基础设施的硬约束
2. 柴发作为A级数据中心刚性配置，不可能被短期替代
3. 外资供应链紧张（康明斯排产至2027-2028年、交付12-18个月；罗罗扩产周期2-3年）而非短期震荡，供需缺口至少持续3年
4. 国内AI资本开支（字节、阿里、腾讯）2026年指引积极，国内需求接力海外

**透支风险评级**：极低（1/5）。AI基础设施建设处于早期阶段（渗透率仍低），不存在透支；电力基础设施的建设周期远长于算力需求增长速度，缺电将是中长期结构性矛盾。

## 三、供需边际与压力传导

### 3.1 重卡行业供需平衡审计

**供给端**：
- 中国重汽2025年交付压力显现（"N+3"预测、月产能提升25%、单日1300辆）
- 行业产能充足但非显著过剩，历史产能过剩问题因出口放量得到部分消化
- 新能源重卡产能快速扩张但尚未形成过剩

**需求端**：
- 内需：年更新中枢90-110万辆，2026年内销预计95-105万辆（以旧换新延续至2026年底+国四/国五置换）
- 出口：2026H1累计约22.3万辆（+43%，中汽协口径），非洲为第一大市场（9.5万辆，+75%）；俄罗斯占比已充分反映地缘风险
- 俄罗斯出口降至2355辆（-12.2%），已充分反映地缘风险

**供需边际判断**：紧平衡向温和宽松过渡。新能源重卡产能扩张速度快于传统重卡需求增速（因车队转化需要时间和基础设施），短期难以出现大规模过剩。但电动化转型可能改变竞争格局——传统柴油发动机企业面临"量稳价跌"的结构性压力。

### 3.2 潍柴终端的压力传导特征

**柴油发动机板块——"量稳/略降、价跌"的结构性压力显现，且新能源替代超预期加速**：

这是模块一发现的核心问题（2025年动力总成毛利率-1.62pct至17.85%）的产业级解释。重卡传统能源市场面临"蛋糕萎缩、但参与者不减少"的困境。2026年上半年实际数据显示，**新能源重卡渗透率上升斜率远超年初预期**：

| 年份 | 天然气重卡渗透率 | 新能源重卡渗透率 | 柴油重卡占比 |
| :--- | :--- | :--- | :--- |
| 2024 | ~12% | ~20%（商用车口径；重卡口径约15%） | ~70% |
| 2025 | ~17% | ~29%（商用车口径；重卡口径约25%） | ~55% |
| 2026E（修订） | ~15-18%（受LNG气价压制） | **~40%+（5月41.5%、6月约45%）** | ~40-45% |

*注：渗透率为交强险口径，不同统计范围（重卡 vs 中重卡 vs 新能源商用车整体）数值略有差异（如5月重卡口径41.5%、第一商用车网统计40.88%）。表中"柴油重卡占比"为市场结构口径（含出口），与潍柴发动机销量口径（含工程机械/农机/发电/出口多元应用）不同，二者不可直接换算。*

**新能源渗透率超预期加速（2026年5月41.5%、6月约45%，上半年累计12.62万辆+85%）**是本轮更新最重要的行业级变量：
- 交通运输部等11部门2026年6月12日印发《推动新能源重卡规模化应用实施方案》，首次国家层面明确2030年新能源重卡渗透率40%、保有量突破160万辆
- 行业机构预测2026年全年渗透率35%左右、2027年有望突破50%（此前预期2028-2029年）
- 新能源重卡对柴油发动机需求的替代提前2-3年兑现，潍柴三电业务（2026Q1营收16.9亿元，+200%）放量对冲部分侵蚀，但利润率远低于传统柴油机

**天然气发动机——LNG气价冲击导致2026H1先扬后抑**：
- 2026年3月起受中东地缘冲突影响，LNG价格飙升（4月出厂价超5300元/吨、月末超6000元/吨，5-6月超6200元/吨），车用LNG加气价一度高于柴油零售价（气柴价差倒挂）
- 天然气重卡终端销量5月环比-55%（高台跳水）、6月1.18万辆（同比-12%），连续两个月环比、同比双降，6月渗透率降至14.12%
- 2026H1累计10.79万台（+18%）——"金三银四"（3月3.2万台为史上第二高）托底
- **潍柴H1燃气机销量5.8万台（+22%）、市占率53.7%（+1.9pct）——份额逆势提升，但行业总量收缩**
- 7月LNG出厂价已回落（供增需减），下半年气柴价差修复有望带动燃气重卡恢复——**潍柴在燃气机的份额优势将随行业回暖转化为销量弹性**

**传导时滞与弹性**：
- 柴油→天然气替代对潍柴是**结构内转化**（潍柴在天然气发动机市占率53.7%），利润率差异不大
- 柴油→纯电动替代对潍柴是**实质性损失**（三电业务体量小+利润率低），且替代速度已超预期
- 当前新能源渗透率40%+已大幅跨过临界点，2025年潍柴动力总成毛利率下滑1.62pct即是对这一趋势的提前反应

**波动放大效应**：下游重卡整车企业（含陕重汽）在新能源转型中面临价格战，对上游发动机的压价力度加大。重卡整车的"反内卷"能否传导至发动机环节，取决于潍柴在特定领域的议价权。在天然气大马力领域（潍柴独家掌控15L+燃气机技术标准），定价权较强；在柴油中小马力领域，面临玉柴、康明斯的激烈竞争。

### 3.3 数据中心柴发——供不应求，价格上行（2026H1持续验证）

这是潍柴当前最具**定价权的赛道**：
- 全球供给缺口持续扩大，外资扩产谨慎且周期长（罗罗苏州工厂扩产为2-3年周期）
- 潍柴2026Q1数据中心用大缸径发动机销量500台+（+240%），2025年全年1400台（+260%）
- 国产替代率从2024年的不足20%跃升至2025年30%+
- 2MW柴发机组价格从2024年约200万元涨至当前220-300万元，涨价趋势延续；纯外资原装机组已超300万元/台

**弹性测算**：潍柴2026Q1数据中心柴发发动机交付约500台+，全年有望达2,500-3,000台（若Q2-Q4维持Q1节奏）。假设单台均价150万元，对应收入约37-45亿元（与章节五2026E数据中心用40-55亿元区间基本一致，差异源于均价与台数假设上沿）。若2027年交付量再翻倍且均价上涨10%，该板块将贡献超100亿元收入——增长弹性极大，且利润率远高于传统动力总成（大缸径发动机毛利率预估30%+）。

### 3.4 凯傲集团（智慧物流）——穿越周期的稳定器（2026H1利润修复兑现）

凯傲集团（KION）2026H1收入56.87亿欧元，其中叉车40.79亿欧元（-1.4%）、智能自动化16.29亿欧元（+18%）。核心特征：
- 2026H1净利润2.08亿欧元（2025H1仅0.48亿欧元，**同比+333%**）——**效率计划利润修复实质兑现**
- 2026Q2调整后EBIT利润率7.7%（+70bp），Q2营收29.16亿欧元（+7.7%）
- 智能自动化（IAS）高速增长（H1收入+18%、Q2调整EBIT+42.5%），项目业务受益于前期订单累积
- 与潍柴发动机业务形成天然对冲：物流景气→叉车需求↑，重卡下行→叉车平稳
- **风险提示**：Q2订单28.09亿欧元（-19.8%），受2025Q2创纪录高基数（含大额项目订单）及2026Q1预购透支影响；凯傲2026全年指引中值较年初微降（集团营收+2.0%~6.4%），反映对下半年宏观经济与地缘的谨慎——利润修复确定，但订单动能转平，2027年增速依赖宏观回暖

## 四、【强制复核项】终端穿透审计结论

- [x] **已穿透终端景气度**：重卡（更新周期向上，2026H1批发66.09万辆实际验证）、工程机械（复苏延续）、数据中心柴发（爆发增长，2026Q1潍柴交付+240%验证）、农机（结构升级）、叉车（利润修复兑现、订单动能转平）五大终端未来2年景气度均偏正面，唯一风险在于柴油发动机在重卡领域的结构性份额流失且新能源渗透加速超预期。
- [x] **已审计跨期需求移位**：国七切换前的重卡抢装可能造成2027-2028年前置需求，但中期更新中枢（90-110万辆）不受影响；新能源渗透率超预期（6月约45%）加速柴油机替代进程，跨期断层风险评级上调至中等偏高（3.5/5）；柴发赛道暂无透支担忧。
- [x] **已分析供需边际与压力传导**：传统柴油发动机面临"量减价跌"的结构性压力且新能源替代加速（5月41.5%、6月约45%）；天然气发动机短期受LNG气价倒挂压制（H1累计+18%但5-6月连续双降）；数据中心柴发是当前潍柴最具供需缺口的增长极。

## 五、模块二核心结论

1. **重卡行业处于3-5年向上周期，2026H1实际销量超预期**：上半年批发66.09万辆（+22.6%）为近五年同期新高，存量更新需求中枢90-110万辆为中期底部提供安全垫，国七切换催化2027-2028年潜在销量高峰。潍柴作为重卡发动机绝对龙头（多缸柴油机市占率20.19%、天然气53.7%），周期性上行趋势明确。

2. **结构性隐忧来自电动化替代，且渗透率超预期加速**：新能源重卡渗透率5月41.5%、6月约45%，大幅跨越30%临界点，对柴油发动机需求形成结构性侵蚀的速度快于年初预期。潍柴三电业务（2026Q1营收16.9亿元，+200%）放量对冲部分侵蚀，但利润率远低于传统柴油机，这一矛盾将在2027-2028年显著加剧。

3. **天然气发动机短期承压但份额优势巩固**：LNG气价飙升（5-6月超6200元/吨）致气柴价差倒挂、5-6月燃气重卡连续双降（6月-12%）；但潍柴H1燃气机市占率逆势提升至53.7%（+1.9pct），7月气价已回落，下半年经济性修复将转化为销量弹性。

4. **数据中心柴发是增长极中"最硬的确定性"**：全球AI资本开支爆发+电网瓶颈+外资产能不足（康明斯排产至2027-2028年），三重因素叠加形成至少3年的供需缺口。潍柴2026Q1交付500台+（+240%），该板块有望从2025年约21亿收入增长至2028年超100亿。

5. **凯傲智慧物流提供周期对冲，利润修复已兑现**：2026H1净利润2.08亿欧元（同比+333%）、IAS收入+18%，效率计划红利落地；但Q2订单-19.8%（高基数）与2026指引中值微降提示需求动能转平，2027年增长依赖宏观回暖。

6. **农机板块稳中求进**：潍柴雷沃稳居国内农机第一品牌，CVT动力总成打破进口垄断。受益于设备更新政策和出口增长，确定性较强但弹性有限。
