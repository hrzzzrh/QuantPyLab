# 研报章节二：产业周期与终端穿透

**研究日期：2026年07月13日**

---

## 一、产业生命周期与库存节奏

### 1.1 重卡行业：存量更新主导，3-5年向上周期确立

中国重卡行业已从"经济周期品"进入**存量更新主导阶段**。国内重卡保有量约700万辆（含52万辆国四重卡），合理更新周期8-10年，中期年更新需求中枢约90-110万辆。

**周期定位**：重卡行业正处于新一轮上行周期初期。

| 年份 | 重卡批发销量（万辆） | 同比 | 备注 |
| :--- | :--- | :--- | :--- |
| 2022 | 67.2 | -52.0% | 周期低谷 |
| 2023 | 90.2 | +34.2% | 触底回升 |
| 2024 | 90.2 | — | 底部企稳 |
| 2025 | 114.4 | +26.8% | 政策驱动放量 |
| 2026M1-5 | 54.4 | +23.3% | 延续增长 |

**库存动力学**：
- 2025Q4末重卡库存环比+0.6万辆，为2021年以来首次Q4加库存
- 2026Q1末库存环比+4.0万辆，补库信号明确
- 截至2026年5月末，行业总库存18.5万辆，动态库销比2.7，处于合理范围
- 当前处于**主动补库阶段初期**，尚未出现过度积压

**关键增长驱动**：
1. **国四淘汰政策**：国四重卡保有量52万辆，以旧换新政策2026年延续
2. **国五置换前奏**：地方政策已开始收紧国五卡车路权，国七标准2027-2028年推出将催生集中置换
3. **国七切换催化**：参照国五切国六经验（透支约65万辆），国七切换期间国内年销量可达120万辆

**牛鞭效应辨析**：2025年销量放量（+26.8%）主要受补贴政策驱动（测算补贴贡献增量约18万辆），但2026年1-5月在无额外补贴刺激下仍实现+16.3%同比终端增长，显示需求韧性并非单纯政策透支，终端物流需求稳中有升（1-5月公路货物周转量+3.1%）。

### 1.2 工程机械：国内外共振，温和复苏延续

中国工程机械行业在经历2021-2023年深度调整后，2025年进入全面复苏通道。

| 年份 | 挖掘机销量（万台） | 同比 |
| :--- | :--- | :--- |
| 2023 | 19.5 | -25.4% |
| 2024 | 20.0 | +2.6% |
| 2025 | 23.5 | +17.0% |
| 2026M1-6 | 15.2 | +26.4% |

**周期定位**：上行周期起点，东吴证券预测本轮周期于2028年见顶（高点挖机销量25万台），当前处于斜率较低的温和复苏通道。

**库存状态**：行业在经历2023-2024年去库后，库存水平趋于健康，企业补库意愿回升。

**结构亮点**：
- 电动装载机2026年1-6月销量2.5万台（+82.4%），渗透率加速攀升
- 非洲/拉美出口高景气（2025年出口+14.5%，2026Q1出口+33.5%）

### 1.3 叉车/智慧物流：长周期稳定增长，电动化结构性红利

全球叉车市场2025-2030年CAGR约5%，中国市场约5.9%。行业处于**成熟期电动化升级阶段**。

**核心趋势**：
- 全球电动化率从74%（2025）升至96%+（2030E）
- 无人叉车6年增长12.5倍（0.2万→2.5万台），CAGR约19%
- 凯傲集团2Q25新接订单+22.2%，全球需求进入上行通道
- 欧洲平衡重式叉车电动化率已升至68%，中国仅35%，替代空间巨大

### 1.4 农业装备：补贴驱动结构升级，非总量扩张

农机行业已告别普及增量阶段，进入存量替换+结构升级期。2026年国家大规模设备更新政策落地，超长期特别国债资金达1851亿元，驱动老旧农机报废更新。行业增长逻辑从"品类扩张"转向"智能化+绿色化+大马力化"。

### 1.5 数据中心柴发：爆发式增长新赛道（关键增量极）

全球AI资本开支进入爆发阶段（2026年北美四大科技公司AI资本开支合计超6000亿美元，同比+70%+），推动数据中心建设井喷。柴发（柴油发电机组）作为A级数据中心刚性备用电源，需求确定性极强。

| 指标 | 数值 |
| :--- | :--- |
| 2026年全球柴发市场规模 | ~226亿美元 |
| 全球柴发需求 | ~4.2万台 |
| 2025年国内数据中心柴发需求 | ~5600-6000台 |
| 2026-2030年全球数据中心新增功率 | ~95GW |
| 数据中心备用电源需求功率 | ~152GW |
| 外资机组价格 | >300万元/台（+20%） |
| 北美2030年前年均电力缺口 | >20GW |

**供需矛盾突出**：康明斯/MTU/卡特彼勒等外资巨头订单排至2027-2028年，交付周期拉长至18个月以上。国产替代窗口已经打开。

## 二、终端需求穿透与跨期断层审计（核心分析）

### 2.1 潍柴动力的终端产品画像

潍柴动力不是一家简单的发动机制造商，其产品负载于五大终端形态：

| 终端形态 | 潍柴核心产品 | 下游应用场景 |
| :--- | :--- | :--- |
| 重型卡车 | 柴油/天然气发动机+陕重汽整车 | 公路物流、矿产运输、基建 |
| 工程机械 | 柴油发动机+液压件 | 挖掘机、装载机、起重机、矿卡 |
| 农业机械 | 柴油发动机+潍柴雷沃整机 | 拖拉机、收割机、播种机 |
| 叉车/仓储 | 凯傲林德/斯蒂尔叉车 | 制造业、电商物流、港口 |
| 发电设备 | M系列大缸径发动机 | 数据中心、油田、矿山备电 |

### 2.2 终端景气度审计（2026-2028年）

**重卡终端**：
- 国海证券：中期年更新需求中枢90-110万辆，国七切换期间年销量120万辆
- 国联民生证券：非俄出口延续高增，新能源渗透率加速至35-40%
- 国金证券：反内卷落地+央国企市值管理，盈利修复成为核心变量
- **结论**：重卡终端需求未来2-3年处于上行通道，有政策和内生更新双重支撑，景气度稳健向上

**工程机械终端**：
- 中诚信国际：2026年景气度全面回稳，"稳定弱化"→"稳定"
- 东吴证券：2026-2028年挖机需求年均增速30%+（理论值），实际因资金到位率呈现温和复苏
- 2026年1-6月挖机销量同比+26.4%，装载机+26.7%
- **结论**：国内温和复苏+海外高景气，工程机械处于上行周期

**数据中心柴发终端**：
- 华源证券/国海证券：AIDC建设需求高景气延续，2026年为井喷之年
- 北美缺电将是一个长期约束（2027-2030年年均电力缺口>20GW）
- 潍柴2025年数据中心用发电机组交付>1400台（+260%）
- **结论**：柴发需求处于爆发期起点，未来3-5年高景气确定性极强

**农业装备终端**：
- 以旧换新政策+超长期国债支撑存量更新
- 2026年Q1农机出口+26.5%
- 大型化、智能化产品保持增长
- **结论**：总量平稳、结构优化，中高速增长可期

**叉车/物流终端**：
- 全球叉车订单拐点已现（2Q25亚太+17%）
- 具身智能/无人叉车打开新成长空间
- 凯傲集团2Q25新接订单+22.2%
- **结论**：全球需求稳健上行，智能化带来增量空间

### 2.3 动能溯源与透支审计

**关键问题一：重卡需求的增长是内生还是外生？**

增长动能呈现**双轮驱动**特征：
- **内生动力（60%）**：存量更新周期自然回归。国四保有量52万辆需在2-3年内淘汰，按自然经济寿命8-10年计算的年更新中枢90-110万辆。2026年1-5月在无额外补贴加码下终端+16.3%，验证内生韧性。
- **外生干预（40%）**：以旧换新补贴政策提前释放部分置换需求，但政策提振的是"时间"而非"总量"——淘汰的车辆终将淘汰，补贴只是加速了这一过程。

**关键问题二：是否存在"需求前置"导致的跨期断层风险？**

**存在但可控**。参照国五切国六的经验（透支约65万辆前置需求），国七切换（预计2027-2028年）前可能出现抢装潮。但区别在于：
1. 当前国五保有量基数更大（远大于国三切换时的国四保有量），透支/置换比更低
2. 新能源重卡渗透率从2023年的5%跃升至2026年的30%+，技术迭代正在创造新增需求，部分对冲了政策透支效应
3. 海外出口（2025年34.1万辆，+17.4%）提供了额外的需求缓冲垫

**跨期断层风险评级**：中等（3/5）。如果2027年国七补贴推出后出现集中释放，2028-2029年可能出现需求短暂回补。但中期中枢（90-110万辆）的支撑逻辑不因节奏扰动而改变。

**关键问题三：数据中心柴发的高增长是否可持续？**

**可持续性强且确定性高**。核心逻辑：
1. 2030年美国数据中心电力负荷预计70GW，2027-2030年年均缺口>20GW——这不仅是"趋势"，而是物理基础设施的硬约束
2. 柴发作为A级数据中心刚性配置，不可能被短期替代
3. 外资供应链紧张（订单排至2027-2028年）而非短期震荡，供需缺口至少持续3年
4. 国内AI资本开支（字节、阿里、腾讯）2026年指引积极，国内需求接力海外

**透支风险评级**：极低（1/5）。AI基础设施建设处于早期阶段（渗透率仍低），不存在透支；电力基础设施的建设周期远长于算力需求增长速度，缺电将是中长期结构性矛盾。

## 三、供需边际与压力传导

### 3.1 重卡行业供需平衡审计

**供给端**：
- 中国重汽2025年交付压力显现（"N+3"预测、月产能提升25%、单日1300辆）
- 行业产能充足但非显著过剩，历史产能过剩问题因出口放量得到部分消化
- 新能源重卡产能快速扩张但尚未形成过剩

**需求端**：
- 内需：年更新中枢90-110万辆，2026年内销预计80-90万辆（政策支持下）
- 出口：2026年1-5月出口20.1万辆（+42.3%），非俄地区19.9万辆（+43.4%）
- 俄罗斯出口降至2355辆（-12.2%），已充分反映地缘风险

**供需边际判断**：紧平衡向温和宽松过渡。新能源重卡产能扩张速度快于传统重卡需求增速（因车队转化需要时间和基础设施），短期难以出现大规模过剩。但电动化转型可能改变竞争格局——传统柴油发动机企业面临"量稳价跌"的结构性压力。

### 3.2 潍柴终端的压力传导特征

**柴油发动机板块——"量稳/略降、价跌"的结构性压力显现**：

这是模块一发现的核心问题（2025年动力总成毛利率-1.62pct至17.85%）的产业级解释。重卡传统能源市场面临"蛋糕萎缩、但参与者不减少"的困境：

| 年份 | 天然气重卡渗透率 | 新能源重卡渗透率 | 柴油重卡占比 |
| :--- | :--- | :--- | :--- |
| 2024 | ~12% | ~10% | ~78% |
| 2025 | ~17% | ~20% | ~63% |
| 2026E | ~20% | ~30-35% | ~45-50% |

柴油发动机绝对需求量正在被新能源和天然气双重挤压。潍柴虽在天然气市场占据54.7%份额（2026Q1），但新能源动力系统（三电）的利润率远低于传统柴油机（2025年三电收入30.4亿仅仅是起步阶段）。

**传导时滞与弹性**：
- 柴油→天然气替代对潍柴是**结构内转化**（潍柴在天然气发动机市占率54.7%），利润率差异不大
- 柴油→纯电动替代对潍柴是**实质性损失**（三电业务体量小+利润率低）
- 当前新能源渗透率30%+已跨过临界点，2025年潍柴动力总成毛利率下滑1.62pct即是对这一趋势的提前反应

**波动放大效应**：下游重卡整车企业（含陕重汽）在新能源转型中面临价格战，对上游发动机的压价力度加大。重卡整车的"反内卷"能否传导至发动机环节，取决于潍柴在特定领域的议价权。在天然气大马力领域（潍柴独家掌控15L+燃气机技术标准），定价权较强；在柴油中小马力领域，面临玉柴、康明斯的激烈竞争。

### 3.3 数据中心柴发——供不应求，价格上行

这是潍柴当前最具**定价权的赛道**：
- 全球供给缺口持续扩大，外资扩产谨慎且周期长
- 潍柴M系列大缸径发动机2025年销量破万台（+32%），数据中心用产品+259%
- 国产替代率从2024年的不足20%跃升至2025年30%+
- 2MW柴发机组价格从2024年约200万元涨至当前220-300万元，涨价趋势延续

**弹性测算**：潍柴2025年数据中心柴发发动机交付约1400台，假设单台均价150万元，对应收入约21亿元。若2026年交付量翻倍至3000台且均价上涨10%，该板块将贡献约50亿元收入——增长弹性极大，且利润率远高于传统动力总成（大缸径发动机毛利率预估30%+）。

### 3.4 凯傲集团（智慧物流）——穿越周期的稳定器

凯傲集团（KION）2025年收入113亿欧元，其中叉车82.7亿欧元（林德/斯蒂尔品牌）。核心特征：
- 全球叉车龙头地位稳固，订单持续增长（2Q25新接订单+22.2%）
- 电动化转型受益（欧洲电动化率68%，中国企业通过凯傲分享高端市场红利）
- 24-25年效率计划完成后利润弹性释放
- 与潍柴发动机业务形成天然对冲：物流景气→叉车需求↑，重卡下行→叉车平稳

**风险提示**：凯傲2025年"效率计划"产生的管理费增量（同比+16.97%）对潍柴合并报表构成短期拖累。但效率计划为一次性支出，2026年预计改善。

## 四、【强制复核项】终端穿透审计结论

- [x] **已穿透终端景气度**：重卡（更新周期向上）、工程机械（复苏延续）、数据中心柴发（爆发增长）、农机（结构升级）、叉车（稳定增长）五大终端未来2年景气度均偏正面，唯一风险在于柴油发动机在重卡领域的结构性份额流失。
- [x] **已审计跨期需求移位**：国七切换前的重卡抢装可能造成2027-2028年前置需求，但中期更新中枢（90-110万辆）不受影响；柴发赛道暂无透支担忧。
- [x] **已分析供需边际与压力传导**：传统柴油发动机面临"量减价跌"的结构性压力，天然气转化能对冲部分影响，新能源三电仍是短板；数据中心柴发是当前潍柴最具供需缺口的增长极。

## 五、模块二核心结论

1. **重卡行业处于3-5年向上周期**：存量更新需求中枢90-110万辆为中期底部提供安全垫，国七切换催化2027-2028年潜在销量高峰。潍柴作为重卡发动机绝对龙头（综合市占率约23%，天然气54.7%），周期性上行趋势明确。

2. **结构性隐忧来自电动化替代**：新能源重卡渗透率已跨过30%临界点，对柴油发动机需求形成结构性侵蚀。潍柴三电业务当前规模（2025年30.4亿元）和利润率不足以填补柴油机份额流失，这一矛盾将在2027-2028年显著加剧。

3. **数据中心柴发是增长极中"最硬的确定性"**：全球AI资本开支爆发+电网瓶颈+外资产能不足，三重因素叠加形成至少3年的供需缺口。潍柴M系列大缸径产品已证明竞争力，该板块有望从2025年约21亿收入增长至2028年超100亿。

4. **凯傲智慧物流提供周期对冲**：全球叉车订单拐点已现，凯傲效率计划完成后利润弹性释放，与潍柴重卡周期形成互补。

5. **农机板块稳中求进**：潍柴雷沃稳居国内农机第一品牌，CVT动力总成打破进口垄断。受益于设备更新政策和出口增长，确定性较强但弹性有限。
