# 研报章节六：估值定价与全变量风险对冲

**研究日期：2026年08月31日**

## 一、价值锚定：适配性方法选择

### 1.1 方法论选择理由

**选择PE作为第一锚点**，理由：
- 潍柴动力为盈利稳定的装备制造龙头，PE估值在A股市场最为主流且被广泛接受
- 近5年PE在10-26x区间波动，均值15.5x，处于可参照的历史区间
- 2022年亏损/低盈利期间PE失真，但2023-2025年已恢复正常

**选择SOTP分部估值作为第二锚点**，理由：
- 潍柴拥有动力总成、智慧物流（凯傲）、农业装备、电力能源等多个属性差异显著的板块
- 凯傲（叉车/智慧物流）应享有比柴油发动机更高的估值倍数
- 数据中心柴发（高增长赛道）的估值溢价应单独计量

**不选用PB-ROE**，理由：ROE仅12%，PB 2.58x隐含回报率约4.7%，PB-ROE模型给出的估值偏低，但未充分反映成长性溢价。

**不选用DCF**，理由：潍柴为强周期企业，自由现金流波动大，DCF对终值假设过于敏感，现实指导意义有限。

### 1.2 历史估值分位审计

当前PE（2026E）基于中性EPS 1.74元，对应约15.6x（2026-08-31收盘27.17元）；PE TTM已回落至18.07x（2026-08-31，TTM归母129.88亿），**回落至近5年P75（18.16x）附近**（vs 8月3日21.77x超P90显著消化），PB 2.44x位于P75（2.13x）-P90（2.74x）之间。考虑到：
- 2026年8月31日收盘价27.17元较8月3日28.48元回落4.6%，但TTM从113.05亿跃升至129.88亿（+14.9%）使PE TTM被动消化约3.7x，估值分位从超P90回归至P75附近
- 2026H1归母77.01亿（+36.46%，其中扣非61.19亿+18.86%，一次性收益15.82亿占比20.5%）、Q2单季46.16亿（+57%）创单季新高，但扣非后改善温和（Q2扣非环比仅+4.6%）、综合毛利率21.46%未修复至22%+
- 新能源重卡上半年渗透率超预期（6月约45%）但7月回落至27%（AEBS透支+淡季），累计21%（1-7月）仍对传统柴油机长期空间构成压力
- 数据中心柴发H1超1400台（已超2025年全年）、M系列6700台（+31.5%）兑现超预期，但7月重卡整体回落（8.40万辆，-28%）与燃气重卡创年内新低（0.5万台，-61%）提示H2斜率放缓
- 控股股东潍柴集团7月21日公告拟增持2-4亿元（关联交易额度同步大幅上调：向重汽销售300亿→360亿/向陕汽590亿→850亿，反映业务量上涨+数据中心需求拉动）

**估值锚点说明（框架滚动规则）**：当前处于2026年Q3，按框架"当年(Q1-Q3)锚定当年EPS"规则，**本报告以2026E为主锚进行三态定价，2027E作为前瞻对照**（2026E EPS 1.74元/2027E EPS 2.03元）。

**基准PE锚点**：给予2026E EPS **15-17x** 估值中枢（H1兑现后中枢下移1x，反映毛利率未修复与燃气机下滑），2027E EPS **13-15x**。

### 2.3 修正目标市值

**修正目标市值（2026E主锚） = 基准市值 2,408亿 × (1 + 6%) = 2,552亿元**

*扣非可持续性对照：若以扣非中性125亿元（EPS 1.45元）为基数、PE 15.6x，则基准市值约1,950亿、修正市值约2,067亿（+6%）、对应目标价约23.9元，低于现价27.17元，显示headline盈利中约20.5%一次性收益对目标价有约5.6元抬升；本报告主锚仍以headline归母为PE分母（与市场一致预期口径对齐），扣非仅作敏感性披露。*

*综合调节敏感性：若综合调节按+4%（vs 当前+6%）测算，中性目标价约28.9元（-0.6元）、加权目标价约28.0元（-0.6元），盈亏比相应回落约0.13，显示调节主观性对定价影响有限（约2%市值）。*

对应目标价（不复权市价）= 2,552亿 / 86.40亿股 = **29.54元**

以2027E利润为锚（前瞻对照，假设PE 14.5x）：
- 2027E市值 = 175亿 × 14.5x × (1+6%) ≈ 2,690亿
- 对应目标价 = **31.13元**

### 3.2 隐含PE锚点回测

修正后的2026E隐含PE = 29.54 / 1.74 = **17.0x**

这一PE水平：
- 高于历史均值15.54x约9%
- 处于近5年P50（15.00x）-P75（18.16x）之间，较8月3日的18.2x（P75-P90）下移
- 低于2024年盈利高点时估值（2024年PE曾达20x+）

**偏离解释**：H1盈利兑现（TTM 129.88亿 vs 113.05亿）使PE中枢被动下移，17.0x溢价主要源于1）数据中心柴发H1超1400台（已超2025年全年）的结构性成长赛道在历史估值中不存在，2）国七催化确定性高于过往周期，3）新能源重卡7月回落至27%显示电动化斜率放缓（vs 6月45%峰值），对柴油机长期空间的侵蚀预期边际缓和。17.0x在成长性框架下具备合理性，但综合毛利率21.46%未修复（vs 预测22.0%）提示需用H2业绩验证。

### 4.3 盈亏比计算（主锚2026E口径，2026-08-31）

- 现价（不复权市价）：**27.17元**（2026-08-31收盘，vs 8月3日28.48元回落4.6%）

- **盈亏比（2026E） = (28.65 - 27.17) / (27.17 - 22.68) = 1.48 / 4.49 = 0.33**

**当年口径结论**：现价27.17元较2026E概率加权目标价28.65元有5.4%空间（vs 8月3日0.2%空间显著改善），盈亏比0.33（vs 8月3日0.01显著改善），主因TTM盈利跃升（129.88亿 vs 113.05亿）使保守底抬升与估值消化。虽仍未达1:1，但较8月3日"当年盈利已完全定价"状态边际修复。

**2027E前瞻口径（次级参考，2026-08-31）**：

2027E前瞻口径下盈亏比0.81较8月3日0.78微升，仍小于1:1，但中性目标价31.13元（+14.6%空间）较保守价23.27元（-14.4%）的赔率已接近对称。

**以乐观情景计算（2027E）**：
- 乐观目标价：**34.24元**
- **盈亏比 = (34.24 - 27.17) / (27.17 - 23.27) = 7.07 / 3.90 = 1.81**

## 五、逻辑证伪与极限压力测试

### 5.1 "一击毙命"黑天鹅场景

**场景：中国新能源重卡渗透率在2027年突破50%，柴油发动机需求结构性崩塌。**

触发条件：
- 电池成本降至400元/kWh以下（当前约550元）
- 充电/换电基础设施在高速公路干线完成全覆盖
- 国七标准对柴油发动机合规成本大幅增加（+8万/辆）

在此场景下：
- 潍柴柴油发动机销量从74万台骤降至40万台
- 天然气发动机短期受益但中长期同样被纯电替代
- M系列大缸径/数据中心柴发不受影响（无法电动化）
- 凯傲业务不受影响

**地狱价格测算**：
- 保守假设柴油发动机业务利润归零（此前贡献约40%净利润）
- 剩余业务（凯傲+农机+柴发）净利润约70-80亿
- 给予13x PE（周期底部估值）
- **地狱市值 ≈ 70亿 × 13x = 910亿**
- **地狱价格 ≈ 910亿 / 86.40亿股 = 10.53元（不复权市价）**

**地狱价格 vs 现价 = 10.53 vs 27.17 = 下跌61.2%**

### 5.2 重资产清算价值锚

以2025年末资产负债表为基准：
- 归母权益 932亿
- 减：商誉 253亿（假设全额减值）
- 减：无形资产
- **重资产清算价值 ≈ 550-600亿**
- **清算价格 ≈ 6.37-6.94元/股**

当前PB 2.58x距离1.0x PB（净资产价值）仍有较大距离，显示市场给予了无形资产和商誉较高定价。
