# 研报章节六：估值定价与全变量风险对冲

**研究日期：2026年08月03日**

## 一、价值锚定：适配性方法选择

### 1.1 方法论选择理由

**选择PE作为第一锚点**，理由：
- 潍柴动力为盈利稳定的装备制造龙头，PE估值在A股市场最为主流且被广泛接受
- 近5年PE在10-26x区间波动，均值15.5x，处于可参照的历史区间
- 2022年亏损/低盈利期间PE失真，但2023-2025年已恢复正常

**选择SOTP分部估值作为第二锚点**，理由：
- 潍柴拥有动力总成、智慧物流（凯傲）、农业装备、电力能源等多个属性差异显著的板块
- 凯傲（叉车/智慧物流）应享有比柴油发动机更高的估值倍数
- 数据中心柴发（高增长赛道）的估值溢价应单独计量

**不选用PB-ROE**，理由：ROE仅12%，PB 2.58x隐含回报率约4.7%，PB-ROE模型给出的估值偏低，但未充分反映成长性溢价。

**不选用DCF**，理由：潍柴为强周期企业，自由现金流波动大，DCF对终值假设过于敏感，现实指导意义有限。

### 1.2 历史估值分位审计

当前PE（2026E）基于中性EPS 1.60元，对应约17.8x；PE TTM已升至21.77x（2026-08-03），**突破近5年P90分位（20.70x）**，PB 2.58x位于P75（2.13x）-P90（2.74x）之间。考虑到：
- 2026年8月3日收盘价28.48元较7月13日锚点（26.60元）上涨7.1%，估值快速抬升
- 新能源重卡渗透率超预期（6月约45%）对传统柴油机的结构性侵蚀加速，成长溢价需要重新审视
- 数据中心柴发兑现节奏超预期（2026Q1交付500台+，同比+240%），成长属性强化
- 控股股东潍柴集团7月21日公告拟增持2-4亿元，提供阶段性信心支撑

**估值锚点说明（框架滚动规则）**：当前处于2026年Q3，按框架"当年(Q1-Q3)锚定当年EPS"规则，**本报告以2026E为主锚进行三态定价，2027E作为前瞻对照**（2026E EPS 1.60元/2027E EPS 1.99元）。

**基准PE锚点**：给予2026E EPS **16-18x** 估值中枢，2027E EPS **14-16x**。

### 2.3 修正目标市值

**修正目标市值（2026E主锚） = 基准市值 2,350亿 × (1 + 7%) = 2,515亿元**

对应目标价（不复权市价）= 2,515亿 / 86.40亿股 = **29.10元**

- 2027E市值 = 172亿 × 15x × (1+7%) ≈ 2,761亿
- 对应目标价 = **31.95元**

## 三、逻辑纯净性校验

### 3.1 E vs PE 分配审计

| 因素 | 影响E | 影响PE | 理由 |
| :--- | :--- | :--- | :--- |
| 国七催化重卡换车 | ✅ +10-15%销量 | ❌ | 可计算的钱→进E |
| 数据中心柴发爆发 | ✅ +60-80%收入 | ✅ 小幅度 | 2026-2027年量价进E；+5%政策溢价对应的是2028年之后未能进E的远期期权（SOFC、天然气发电主电源）与国七确定性溢价 |
| 凯傲效率计划 | ✅ 管理费下降 | ❌ | 一次性费用消除→进E |
| 技术壁垒（热效率纪录） | ❌ | ✅ +3% | 不可计算的钱→进PE |
| 汇率波动 | ✅ 小幅 | ✅ 小幅 | 可量化的进E，不确定性进PE |
| 控股股东增持 | ❌ | ✅ +1% | 信号意义为主，规模（0.1%市值）不足以进E |

### 3.2 隐含PE锚点回测

修正后的2026E隐含PE = 29.10 / 1.60 = **18.2x**

这一PE水平：
- 高于历史均值15.5x约17%
- 处于近5年P75-P90之间
- 与2024年盈利高点时估值相当（2024年PE曾达20x+）

**偏离解释**：溢价主要源于1）数据中心柴发的结构性成长赛道在历史估值中不存在，2）国七驱动的新一轮换车周期确定性高于过往周期，3）新能源重卡渗透率超预期（6月约45%）虽对柴油机长期空间构成侵蚀，但潍柴自身新能源三电（2026Q1营收16.9亿元，+200%）与燃气机份额提升（53.7%）形成对冲。18.2x在成长性框架下具备合理性，但已较为激进——需要在6-12个月内用业绩验证。

### 4.3 盈亏比计算（主锚2026E口径）

- 现价（不复权市价）：**28.48元**（2026-08-03收盘）
- 中性目标价（2026E，修正市值）：**29.10元**
- 保守场景价格：**20.85元**
- **概率加权目标价（2026E） = 20.85×20% + 29.10×55% + 33.44×25% = 28.54元**
- **盈亏比（2026E） = (28.54 - 28.48) / (28.48 - 20.85) = 0.06 / 7.63 = 0.01**

**当年口径结论**：现价28.48元与2026E概率加权目标价28.54元几乎持平，**2026年盈利预期已被完全定价**，盈亏比≈0.01——当前价位买入对应当年盈利几乎无风险补偿。

**2027E前瞻口径（次级参考）**：
- **概率加权目标价（2027E） = 23.94×20% + 31.95×55% + 38.59×25% = 32.01元**
- **盈亏比（2027E） = (32.01 - 28.48) / (28.48 - 23.94) = 3.53 / 4.54 = 0.78**

2027E前瞻口径下盈亏比0.78仍小于1:1，较7月13日的0.30显著改善（现价自26.60元反弹至28.48元，中性目标价因盈利预测上调而上修），但赔率仍不充分——上行空间（+12.4%）已接近下行空间（-15.9%至保守价）。

**以乐观情景计算（2027E）**：
- 乐观目标价：**38.59元**
- **盈亏比 = (38.59 - 28.48) / (28.48 - 23.94) = 10.11 / 4.54 = 2.23**

## 五、逻辑证伪与极限压力测试

### 5.1 "一击毙命"黑天鹅场景

**场景：中国新能源重卡渗透率在2027年突破50%，柴油发动机需求结构性崩塌。**

触发条件：
- 电池成本降至400元/kWh以下（当前约550元）
- 充电/换电基础设施在高速公路干线完成全覆盖
- 国七标准对柴油发动机合规成本大幅增加（+8万/辆）

在此场景下：
- 潍柴柴油发动机销量从74万台骤降至40万台
- 天然气发动机短期受益但中长期同样被纯电替代
- M系列大缸径/数据中心柴发不受影响（无法电动化）
- 凯傲业务不受影响

**地狱价格测算**：
- 保守假设柴油发动机业务利润归零（此前贡献约40%净利润）
- 剩余业务（凯傲+农机+柴发）净利润约70-80亿
- 给予13x PE（周期底部估值）
- **地狱市值 ≈ 70亿 × 13x = 910亿**
- **地狱价格 ≈ 910亿 / 86.40亿股 = 10.53元（不复权市价）**

**地狱价格 vs 现价 = 10.53 vs 28.48 = 下跌63.0%**

### 5.2 重资产清算价值锚

以2025年末资产负债表为基准：
- 归母权益 932亿
- 减：商誉 253亿（假设全额减值）
- 减：无形资产
- **重资产清算价值 ≈ 550-600亿**
- **清算价格 ≈ 6.37-6.94元/股**

当前PB 2.58x距离1.0x PB（净资产价值）仍有较大距离，显示市场给予了无形资产和商誉较高定价。

**定价结论**：当前股价28.48元（2026-08-03）——**对2026年盈利已完全定价（概率加权目标价28.54元，盈亏比仅0.01）**；以2027年成长视角看，中性目标价31.95元（+12.2%空间）、盈亏比0.78仍小于1，赔率尚不充分。7月20日盘中低点23.80元已兑现7月13日"等待回调至22-24元区间"的布局判断，但此后受控股股东增持公告+机构密集上调盈利预测推动反弹17%。建议等待回调至24-26元区间（2026E PE约15.0-16.3x、2027E PE约12.1-13.1x），届时2026E口径盈亏比可改善至1:1以上、2027E口径盈亏比可改善至2:1以上，或待8月28日半年报确认Q2毛利率与凯傲修复持续性后再作决策。
