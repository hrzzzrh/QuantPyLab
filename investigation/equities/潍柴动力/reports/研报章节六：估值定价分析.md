# 研报章节六：估值定价与全变量风险对冲

**研究日期：2026年07月13日**

---

## 一、价值锚定：适配性方法选择

### 1.1 方法论选择理由

**选择PE作为第一锚点**，理由：
- 潍柴动力为盈利稳定的装备制造龙头，PE估值在A股市场最为主流且被广泛接受
- 近5年PE在10-26x区间波动，均值15.5x，处于可参照的历史区间
- 2022年亏损/低盈利期间PE失真，但2023-2025年已恢复正常

**选择SOTP分部估值作为第二锚点**，理由：
- 潍柴拥有动力总成、智慧物流（凯傲）、农业装备、电力能源等多个属性差异显著的板块
- 凯傲（叉车/智慧物流）应享有比柴油发动机更高的估值倍数
- 数据中心柴发（高增长赛道）的估值溢价应单独计量

**不选用PB-ROE**，理由：ROE仅12%，PB 2.42x隐含回报率约5%，PB-ROE模型给出的估值偏低，但未充分反映成长性溢价。

**不选用DCF**，理由：潍柴为强周期企业，自由现金流波动大，DCF对终值假设过于敏感，现实指导意义有限。

### 1.2 历史估值分位审计

当前PE（2026E）基于中性EPS 1.50元，对应约17.7x，位于近5年PE均值（15.5x）上方、P75（18.0x）附近。考虑到：
- A股重卡/工程机械板块处于盈利上行周期，PE理应高于下行期
- 数据中心柴发赋予的结构性成长溢价不能简单套用历史均值
- 但考虑到当前价格已从近期高点（29.72元，PE~20x）回落至26.60元

**基准PE锚点**：给予2026E EPS **16-18x** 估值中枢，2027E EPS **14-16x**。

### 2.3 修正目标市值

**修正目标市值 = 基准市值 2,300亿 × (1 + 6%) = 2,438亿元**

对应目标价（不复权市价）= 2,438亿 / 86.62亿股 = **28.14元**

以2027E利润为锚（假设PE 15x）：
- 2027E市值 = 162亿 × 15x × (1+6%) ≈ 2,576亿
- 对应目标价 = **29.74元**

## 三、逻辑纯净性校验

### 3.1 E vs PE 分配审计

| 因素 | 影响E | 影响PE | 理由 |
| :--- | :--- | :--- | :--- |
| 国七催化重卡换车 | ✅ +10-15%销量 | ❌ | 可计算的钱→进E |
| 数据中心柴发爆发 | ✅ +60-80%收入 | ✅ 小幅度 | 量进E，赛道结构性溢价进PE |
| 凯傲效率计划 | ✅ 管理费下降 | ❌ | 一次性费用消除→进E |
| 技术壁垒（热效率纪录） | ❌ | ✅ +3% | 不可计算的钱→进PE |
| 汇率波动 | ✅ 小幅 | ✅ 小幅 | 可量化的进E，不确定性进PE |

### 3.2 隐含PE锚点回测

修正后的2026E隐含PE = 28.14 / 1.50 = **18.8x**

这一PE水平：
- 高于历史均值15.5x约21%
- 处于近5年P85附近
- 与2024年盈利高点时估值相当（2024年PE曾达20x+）

**偏离解释**：溢价主要源于1）数据中心柴发的结构性成长赛道在历史估值中不存在，2）国七驱动的新一轮换车周期确定性高于过往周期。18.8x在成长性框架下具备合理性，但已较为激进——需要在6-12个月内用业绩验证。

### 4.2 盈亏比计算（中性情景，2027E锚点）

- 现价（不复权市价）：**26.60元**
- 中性目标价（2027E）：**28.05元**
- 保守场景价格：**21.84元**
- **盈亏比 = (28.05 - 26.60) / (26.60 - 21.84) = 1.45 / 4.76 = 0.30**

盈亏比小于1:1，表明当前价位安全边际不足——下跌空间大于上涨空间。

**以乐观情景计算**：
- 乐观目标价：**37.23元**
- **盈亏比 = (37.23 - 26.60) / (26.60 - 21.84) = 10.63 / 4.76 = 2.23**

考虑概率（25%乐观、55%中性、20%保守），**概率加权盈亏比 ≈ 0.84**，勉强大于0.5。

## 五、逻辑证伪与极限压力测试

### 5.1 "一击毙命"黑天鹅场景

**场景：中国新能源重卡渗透率在2027年突破50%，柴油发动机需求结构性崩塌。**

触发条件：
- 电池成本降至400元/kWh以下（当前约550元）
- 充电/换电基础设施在高速公路干线完成全覆盖
- 国七标准对柴油发动机合规成本大幅增加（+8万/辆）

在此场景下：
- 潍柴柴油发动机销量从74万台骤降至40万台
- 天然气发动机短期受益但中长期同样被纯电替代
- M系列大缸径/数据中心柴发不受影响（无法电动化）
- 凯傲业务不受影响

**地狱价格测算**：
- 保守假设柴油发动机业务利润归零（此前贡献约40%净利润）
- 剩余业务（凯傲+农机+柴发）净利润约70-80亿
- 给予13x PE（周期底部估值）
- **地狱市值 ≈ 70亿 × 13x = 910亿**
- **地狱价格 ≈ 910亿 / 86.62亿股 = 10.50元（不复权市价）**

**地狱价格 vs 现价 = 10.50 vs 26.60 = 下跌60.5%**

### 5.2 重资产清算价值锚

以2025年末资产负债表为基准：
- 归母权益 932亿
- 减：商誉 253亿（假设全额减值）
- 减：无形资产
- **重资产清算价值 ≈ 550-600亿**
- **清算价格 ≈ 6.35-6.93元/股**

当前PB 2.42x距离1.0x PB（净资产价值）仍有较大距离，显示市场给予了无形资产和商誉较高定价。

## 六、模块六核心结论

| 指标 | 数值 |
| :--- | :--- |
| 当前股价（不复权） | **26.60元** |
| 当前市值 | **2,304亿** |
| 2026E中性EPS | **1.50元** |
| 当前2026E PE | **17.7x** |
| 中性目标价（2026E） | **25.50元** |
| 中性目标价（2027E） | **28.05元** |
| 当前隐含涨跌空间（2027E中性） | **+5.5%** |
| 保守-中性-乐观目标价（2027E） | **21.84 / 28.05 / 37.23元** |
| 概率加权目标价 | **~28元** |
| 地狱价格（黑天鹅） | **~10.50元（-60.5%）** |

**定价结论**：当前股价26.60元基本反映了中性预期（28.05元的目标价空间仅5.5%），安全边际不足。盈亏比<1，在当前位置买入的赔率不具备吸引力。建议等待回调至22-23元区间（对应2026E PE 15x），届时盈亏比可改善至大于2:1。
