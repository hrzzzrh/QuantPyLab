# 研报章节六：估值定价分析

**研究日期**：2026年08月01日

## 一、价值锚定：PE为主，SOTP为校验

先惠技术的商业模式是锂电智能装备+电池结构件双轮驱动，利润弹性来自订单确认、海外高毛利项目和福建东恒结构件放量。当前最适合的估值方法仍是PE：公司已走出亏损期，2026Q1收入和利润继续高增，EPS可预测性高于现金流预测。

| 估值方法 | 适配性 | 理由 |
|:---|:---|:---|
| **PE（市盈率）** | ★★★★★ 首选 | 利润释放期，EPS是最直接定价锚 |
| **PEG（成长性估值）** | ★★★★ 辅助 | 2026E利润增速仍高，需检验PE是否匹配成长 |
| **SOTP（分部估值）** | ★★★★ 辅助 | 装备与结构件业务属性不同，可用于下限校验 |
| **DCF（现金流折现）** | ★★ 参考 | 项目制回款波动大，2026Q1经营现金流仍为负 |
| **PB-ROE** | ★★ 参考 | PB低位有辅助意义，但不是主估值锚 |

### 3.1 EPS暂不调整的原因

7月中旬公司公告先惠技术及控股子公司福建东恒累计收到CATL系合同和定点通知约**9.20亿元（不含税）**，约等于2025年营收30.40亿元的**30.3%**。这显著提高2026-2027收入可见度，但不直接上调2026E EPS，原因是：

1. 合同的设备/结构件拆分尚未披露。
2. 收入确认节奏尚未披露。
3. 毛利率、预收条款和现金流质量尚未披露。
4. 8月27日半年报尚未验证Q1经营现金流为负是否修复。

因此本次只调整情景概率：Bear从25%降至20%，Bull从20%升至25%，Base维持55%；三态EPS维持不变。

### 4.1 量化对冲审计矩阵（框架公式：修正目标市值 = 基准市值 × (1 + Σ调节幅度)）

**基准市值**：以Base归母净利润5.34亿元 × Base PE 24.9x = **132.97亿元**（对应105.08元/股）。

| 审计维度 | 核心审计因子 | 调节幅度 |
|:---|:---|:---:|
| 内部：企业底层特质 | CATL单客户依赖77%（致命级折价，9.20亿元新增合同强化订单的同时也强化依赖） | **−15%** |
| 内部：企业底层特质 | 在手订单33亿+CATL系新增9.20亿元合同（订单可见度上升） | **+8%** |
| 宏观：政策与战略对齐 | 欧盟IAA本土化要求+十五五智能制造+固态电池政策红利 | **+6%** |
| 宏观：地缘与外部约束 | 中欧贸易摩擦反复风险+中东地缘油价冲击 | **−5%** |
| 市场：流动性与风格 | 技术面破位+小市值流动性折价，市场风险偏好未修复 | **−8%** |
| 市场：流动性与风格 | 低利率环境对成长股估值中枢的支撑 | **+4%** |
| **综合调节系数** | **Σ** | **−10%** |

**修正目标市值** = 132.97 × (1 − 10%) = **119.67亿元**，对应**94.65元/股**（隐含Base PE 22.4x）。

**交叉验证**：对冲修正目标价94.65元低于PE矩阵Base目标价105.08元约10%，反映客户集中折价与技术面破位折价无法被订单与政策利好完全对冲；修正后隐含PE 22.4x介于Bear（20x）与Base（24.9x）之间，与"第二象限：赔率极高、确定性不足"的定位自洽。三态目标价与概率加权目标价以PE矩阵为准，修正目标市值作为基准市值的保守校验下限。

**综合判断**：当前估值端给出的结论是"极端低估"，但风险端给出的约束是"不能无视客户集中度和现金流"。这使先惠技术仍是第二象限品种：赔率极高，但确定性尚未达到可重仓的第一象限。

## 五、风险收益表达

传统盈亏比公式在现价低于Bear价时失效，因为“下行到保守价”的距离已经为负。当前更合适的表达方式是情景上行空间：

| 目标 | 价格 | 相对57.00元空间 |
|:---|:---:|:---:|
| Bear目标价 | 66.00元 | +15.8% |
| Base目标价 | 105.08元 | +84.4% |
| 对冲修正Base参考价 | 94.65元 | +66.1% |
| 概率加权目标价 | 111.12元 | +95.0% |
| Bull目标价 | 160.50元 | +181.6% |

**核心定价结论**：57.00元已跌破Bear情景价66.00元，估值层面进入极端低估区。7月17日CATL系9.20亿元合同和CATL H1高增，使“股价下跌=订单恶化”的解释暂不成立；但技术面破位说明市场正在用流动性折价和小市值锂电链风险偏好重新定价公司。当前策略应是“估值确认、技术等待”：维持15-20%配置，新增仓位分批，不追弹；站回60-63元再考虑加仓，跌破52.74元且无基本面解释则降低战术仓位。

## 六、极限压力测试

**一击毙命风险**仍是CATL供应链关系变化：若CATL将先惠技术在模组/PACK设备和结构件的供应份额削减50%，则2027年设备订单和结构件出货都会受到断崖式冲击，商誉和应收账款也会面临减值压力。

| 压力项 | 估算影响 |
|:---|:---|
| 每股净资产 | 约18.25元 |
| 扣除商誉后的调整BVPS | 约13.27元（23.08亿元归母权益−6.30亿元商誉）/1.2644亿股 |
| 再考虑应收减值压力 | 极限底价约10.64元/股（13.27元−11.10亿元应收×30%≈3.33亿元对应2.63元/股） |

这是低概率尾部风险，但它解释了为什么即使现价极低，也不应忽略CATL单客户依赖折价。
