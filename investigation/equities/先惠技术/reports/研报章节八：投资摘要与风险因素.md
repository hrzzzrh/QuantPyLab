## 一、投资摘要（Investment Summary）

### 1.1 一句话结论（2027E切换版）

先惠技术是一家深度绑定宁德时代（2025年贡献77%营收，2026年以来新增合同仍全部来自CATL系）的锂电智能装备+结构件双轮驱动企业。半年报"订单强、盈利弱"的分裂格局未变（H1营收18.90亿+48.5%、Q2归母-39%、综合毛利率26.14%、经营现金流-1.43亿），但9-10月出现三重边际改善：实控人9月11-14日累计增持787,066股（公告2026-039，持股47.02%，仍在实施期）、股价10月08-09日放量突破55元（第一修复确认）、CATL 2027年排产1.6-1.7TWh与行业2027年需求+24~32%为远期提供需求锚。依据框架Q4切换条款，本轮将目标年份由2026E切换至2027E：2027E三态EPS 3.93/4.71/5.65元（归母5.00/6.00/7.20亿），三态目标价62.81/94.22/141.33元，概率加权目标价95.79元（25%/55%/20%），对冲修正中性参考价77.26元（Σ −18%），盈亏比记∞+口径（现价低于保守价10.4%）。**现价56.25元对应2027E Base Forward PE仅11.9x——市场仍按悲观情景定价2027年+25.8%的增长，预期差显著；但2027E基数（2026E Base）尚未兑现，10月29日（预约）三季报（毛利率≥25.5%分水岭）为决定性验证节点。**

### 1.2 核心投资逻辑（Bull Case）

**当前成立的基本面逻辑**：
1. **CATL扩产周期未完且延伸至2027年**：在建764GWh未来1-2年投产；2027年排产1.6-1.7TWh、确收1.2-1.3TWh（东吴/交银口径）；9月产量同比+79%领跑；拟200-400亿回购彰显信心。
2. **订单可见度强且有财务验证**：33亿在手订单+年内CATL系新增合同约18.65亿元滚动落地；合同负债14.78亿元（+18.8%）交叉验证；9月西班牙市场+匈牙利电池产线订单线索（待公告验证）指向海外接力。
3. **海外业务是盈利质量的结构性支撑**：H1海外收入5.40亿元（占比28.6%），毛利率38.6%显著高于国内21.2%；捷克工厂在建、美国工厂筹建；IAA预计2027年生效（与定价锚年份重合）提供法律确定性。
4. **储能是最强边际增量且延续至2027年**：2026年储能电芯排产占比四成、价格+18%；花旗预测2027年ESS需求1390GWh（+35%）；公司储能PACK产线及配套结构件已市场化销售。
5. **2027年行业需求预期差**：中信建投预测2027年锂电需求+24~32%、花旗+26%，市场定价隐含预期低于20%；CATL 2027E PE仅约11倍、先惠2027E Base Forward PE仅11.9x，悲观预期已充分定价。
6. **估值仍处低位且技术面第一修复确认**：PE TTM 17.49x（近1年p10附近）、PB 2.95x（仍低于p3）；10月08-09日连续放量站上55元，现价较Bear目标价折价10.4%，具备安全垫。

### 1.3 核心风险逻辑（Bear Case）

1. **盈利质量恶化尚未证伪**：Q2归母同比-39%、毛利率三大板块全线下滑、经营现金流-1.43亿、应收+存货合计34.38亿元占总资产52.5%。若Q3毛利率不能回到25.5%以上，2026E滑向Bear情景，2027E基数同步证伪。
2. **CATL单客户依赖是致命级风险**：77%收入来自CATL且新增合同100%来自CATL体系，议价弱势已在毛利率上兑现，不可分散。
3. **竞争地位边际恶化未逆转**：思客琦100亿产能投产；先导合同负债174亿（+33.3%）龙头虹吸；先导固态整线领先挤压固态期权；科达利三季报（10月24日）为对照验证节点。
4. **2027年远期增长受政策压制**：新增产能审批实质暂停（待文件化）+储能增速换挡预期（JPM预测2027年+25%），设备订单总盘子增长斜率被系统性压制；高盛10月空头报告（2027年表观+1%）虽为含补库口径的极端假设，但提示预期差收敛路径存在分歧。

## 三、研究结论象限图（Final Evaluation Matrix）

基于"确定性"与"预期收益空间"两个维度：

                     预期收益空间 低

**先惠技术的最终研究定位：第二象限（Speculative Growth / 黑马/期权仓位），赔率占优但确定性因盈利质量未验证而无法升级**

**定位理由（2026-10-11切换2027E后更新）**：
- **赔率端占优且随目标年份切换扩大**：现价56.25元较2027E Bear目标价62.81元折价10.4%，保守情景下行空间为负（盈亏比记∞+口径）；Base情景上行+67.5%，加权目标价上行+70.3%，修正中性参考价上行+37.3%。2027E Base Forward PE仅11.9x定价+25.8%增长，预期差较2026E口径（14.3x定价+35.9%）更为显著。
- **确定性端仍受损**：2027E建立在尚未兑现的2026E Base之上（双重不确定性）；半年报证实的毛利率下滑、Q2利润负增长、现金流为负均待Q3验证；竞争格局分化未逆转；产能"关闸"压制2027年后远期。这是维持第二象限而非上调至第一象限的核心原因。
- **观察升级触发器**：（1）Q3综合毛利率回到25.5%以上（确认2026E路径→2027E基数成立）；（2）经营现金流转正；（3）股价放量突破58-59元（第二修复）。三者共振可将评级向第一象限边缘上调。

**当前的操作建议（2026-10-11更新）**：
- **维持底仓持有不追高**：2027E预期差显著+订单可见度仍强，但盈利质量待验证+技术面R2攻坚未果限制追高，55-58元区间仅持有不加仓。
- **新增仓位纪律**：回踩55元不破且Q3毛利率≥25.5%共振后可小幅加仓至20%上沿；放量突破58-59元（第二修复）后看61.5-63元。
- **风控线**：55元为短线生命线（第一修复防线），有效跌破且伴随基本面利空则降低战术仓位至观望，52.74元前低为最终风控线，48-50元为二次探底观察区。
- **三季报为决定性验证节点**：10月29日（预约）披露，Q3毛利率≥25.5%+经营现金流转正为加仓前提；若证伪则2026E与2027E同步重估。
