## 一、投资摘要（Investment Summary）

### 1.1 一句话结论

先惠技术是一家深度绑定宁德时代（2025年贡献77%营收，2026年以来新增合同仍全部来自CATL系）的锂电智能装备+结构件双轮驱动企业。2026年三季报给出了本轮跟踪以来最明确的证伪信号：**Q3营收10.02亿元（+50.93%）创历史新高，但归母净利润仅0.57亿元（+7.68%）、综合毛利率18.99%（同比-7.32pct、环比-2.12pct）**，击穿25.5%多空分水岭；Q2单季毛利率实际为21.11%（此前被H1累计26.14%掩盖），毛利率恶化已连续两个季度。受此影响，2026E归母由4.77亿下修至**3.85亿元**（-19.3%），2027E Base归母从6.00亿下修至**4.00亿元**（-33.3%）。2027E三态EPS 2.34/3.14/4.24元（归母2.98/4.00/5.40亿），三态目标价**28.08/46.97/84.80元**，概率加权目标价**48.87元**（30%/50%/20%），盈亏比**0.18**（现价45.70元高于Bear价，公式恢复适用），评级由第二象限下调至**第四象限（Avoid/Wait）**。**当前价对应2027E Base Forward PE 14.6x，但对应Bear仅19.5x——低PE是盈利未下修的错觉；在毛利率企稳（Q4≥22%）与新增订单恢复之前，不存在足够的安全边际。**

### 1.2 核心投资逻辑（当前仍成立的部分）

1. **收入端景气未证伪**：Q3营收+50.93%创历史新高；CATL Q3动力+储能出货超260GWh（储能约65GWh、同比接近翻倍），2027年全行业电池需求+20~30%；国内储能Q3单季13.40GW/43.00GWh首次破10GW。
2. **结构件需求随CATL排产增长**：东恒结构件覆盖模组侧板、端板、CCS组件，随CATL全球产能扩张同步供货；2026E结构件营收约23.0亿元，2027E Base 27.5亿元（+19.6%）。
3. **海外业务仍是最高毛利池**：H1海外收入5.40亿元（+93.7%）、占比28.6%、毛利率38.6%；捷克工厂在建、美国工厂筹建；欧盟IAA预计2027年生效。
4. **经营现金流由负转正**：9M +1.49亿元（+150.6%），Q3单季约+2.92亿元；应收账款从13.98亿元降至10.08亿元，CATL缩短账期的阶段性安排已见效。
5. **实控人增持仍在实施期**：9月11-14日累计增持787,066股（0.62%，公告2026-039），持股46.40%→47.02%，6个月窗口至2027年3月；信号意义大于资金意义。
6. **估值分位处于历史底部**：PE TTM 14.07x跌破近1年p3（14.71x）、PB 2.36x低于p3（2.48x）；但低分位是"盈利下修前"的TTM口径，不能单独作为买入理由。

### 1.3 核心风险逻辑（当前占主导）

1. **毛利率结构性下移已兑现**：Q2 21.11%、Q3 18.99%，连续两季低于22%；CATL Q3毛利率20.69%（-5.1pct）、单Wh净利环比-15%，价格压力正向设备/结构件供应商传导。先惠Q3合并毛利率降幅（-7.32pct）远大于科达利（-2.59pct），且科达利/震裕环比修复、先惠环比-2.12pct——竞争位次恶化得到方向性证实（合并口径不可直接相减，同分部对照见章节三）。
2. **"增收不增利"成为主线**：Q3收入+50.9%、毛利额仅+8.9%、归母+7.7%；2025年"营收+23%/归母+57%"的经营杠杆已逆转为"营收高增/利润停滞"。
3. **订单断档**：33亿在手订单为2025年末口径，7月16日后至10月31日无新增CATL系合同公告；合同负债14.15亿元（环比-4.3%）；先导合同负债189.80亿元（+47.44%）形成13.4倍差距。
4. **2027年设备订单盘子收缩**：广东省电池行业协会预计2027年行业设备需求-20%、8月规划产能较4月高位-87%；先惠模组/PACK细分2026H1增速仅+31%（低于行业+38%），2027年国内装备收入大概率零增长至负增长。
5. **资产负债表压力**：存货22.96亿元（+35.2% YTD）创历史新高、存货/TTM营收约57.5%；货币资金5.72亿元（-29.5%）；有息负债/货币资金约1.20x触及警戒线；9M资产减值1.37亿元（上年同期为转回约0.07亿）。
6. **技术面破位**：10月12日57.77→10月30日45.70（-20.9%），跌破55/52.74/48-50全部支撑，年内新低43.11元；均线空头排列，反弹缩量。

## 三、研究结论象限图（Final Evaluation Matrix）

基于"确定性"与"预期收益空间"两个维度：

```
                    预期收益空间 高

                          │
                          │

                          │
        第四象限          │          第三象限
     (Avoid/Wait)         │    (Defensive Value)
     ★ 先惠技术           │    — 高确定性低估值标的（示意）
     (确定性低,            │
      预期收益低)          │
                     预期收益空间 低
```

**先惠技术的最终研究定位：第四象限（Avoid/Wait / 回避或等待），确定性低+预期收益低**

**定位理由**：
- **赔率端已不占优**：现价45.70元高于Bear目标价28.08元，盈亏比0.18（承担1元下行风险仅换0.18元期望收益）；加权目标价48.87元仅较现价+6.9%，而Bear下行-38.6%。赔率结构已由"下行空间为负"转为"下行空间显著大于上行空间"。
- **确定性端进一步受损**：Q3毛利率18.99%击穿25.5%分水岭，2026E/2027E Base分别下修19.3%/33.3%；订单断档、竞争位次恶化、存货创历史新高，三重压力叠加。2027E Base归母4.00亿几乎零增长（+3.9%），"成长股"叙事已不成立。
- **低估值是错觉**：PE TTM 14.07x、PB 2.36x看似历史底部，但按2027E Bear EPS 2.34元，Forward PE 19.5x；按Q3毛利率19.0%外推，2027E PE约20.0x，高于先导/科达利。低PE来自"盈利尚未下修"的TTM口径，不是安全边际。

**当前的操作建议**：
- **不新建仓位**：第四象限，赔率与确定性双低；空仓者等待，不抄底。
- **已有仓位反弹减仓**：47.5-48.2元（短期反抽压力）减仓；49.9-50.1元（MA20）若放量站稳3日，才可重新评估。
- **风控线**：43.11元（年内低点）为最后技术防线，跌破且放量则清仓观察，下一支撑41.45/40/35.70元。
- **右侧信号（三者需同时满足）**：①11月12日业绩说明会给出Q3毛利率下滑的可验证解释与Q4修复指引；②Q4毛利率≥22%；③新增CATL系合同公告恢复。三者未共振前不参与。
- **下一验证节点**：11月12日业绩说明会（Q3毛利率原因、Q4订单/验收指引、CATL收入占比、在手订单最新口径）→2027年1月业绩预告（2026E收口3.85亿的最终验证）→2027年4月年报（2027E基数与毛利率路径裁决）。
