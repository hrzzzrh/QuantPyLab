**研究日期：2026年11月08日**
**目标年份：2027年（Q4切换期，按框架「估值锚点切换：Q4自动滚算至次年」条款，锚定2027E）**

## 一、投资摘要

### 1.1 公司核心画像

蔚蓝锂芯（002245.SZ）是一家从金属物流转型而来的锂电池制造商，当前业务结构为**锂电池52%+金属物流28%+LED 18%**，战略核心聚焦于圆柱小动力锂电池。通过子公司天鹏电源（20年圆柱电芯经验），公司在高倍率小圆柱电芯领域建立了**全球领先地位**，客户涵盖博世、TTI、史丹利百得等全球TOP4电动工具品牌。2026年前三季度营收75.38亿元（+29.6%）、归母净利8.46亿元（+64.8%），其中Q3单季营收26.80亿元（+28.4%）、归母3.35亿元（+86.0%）、毛利率22.97%（2022年以来单季最高）。业绩增长的核心驱动已从"补库+国产替代"切换为**"全极耳/BBU结构升级"**：券商测算Q3锂电池ASP环比+12%至7.6-7.7元/颗、分部单颗盈利约1.20元（同比翻倍，未经公告确认）。

### 1.2 投资逻辑三支柱

**支柱一：结构升级带来的ASP与单颗盈利跃迁（已兑现，确定性较高）**

公司是国内唯一量产NCA体系圆柱电池的企业，2025年5月率先实现全极耳电芯量产，2026年8月马来西亚再增两条全极耳产线（日产能50万只）。结构升级的效果已在报表中验证：Q3毛利率22.97%（同比+4.94pct、环比+2.08pct）、ASP环比+12%、单颗盈利1.20元。**这是本研报唯一获得报表级验证的正面逻辑**，也是2027年"锂电池毛利率25.0%、单颗净利0.88元"假设的基础。

**支柱二：BBU/AI机器人的第二增长曲线（趋势确定，但份额与身份未确认）**

据东吴证券2026-07-07测算，BBU电芯需求2026年近4亿颗、2028年超12亿颗、2030年逼近28亿颗；2027年CSP资本支出预计+60%至1.5万亿美元（TrendForce）、AI服务器出货+36%。蔚蓝通过Molicel代工已量产（2025年约500万颗、2026年约5,000万颗），铁锂电芯通过联合销售进入Google/AWS体系，机器人领域已覆盖国内主要客户（宇树为重要供应商）。

**但必须记录公司自己的降温表述**（2026-11-02互动易）："现有BBU电池供应主要由日韩企业主导，公司通过为台湾能元代工等方式**有限参与**……现有BBU电池**供需总体处于平衡状态**"；11-05对"直供落地"仅答"正常推进中"，未重申"年底前落地"目标。因此本研报按**代工为主、直供0.2-0.3亿颗**建基准，而非卖方隐含的1.5-2亿颗。

**支柱三：客户认证壁垒+全球化产能（护城河由"中深"下调至"中等"）**

与博世（2025年全球供应商大奖）、TTI、史丹利百得的长期认证关系仍是核心资产。但两项事实削弱了护城河：①**日韩回归**——三星SDI 2026Q3电池营业利润3,619亿韩元（12个季度新高），明确由ESS+BBU+工具圆柱驱动，7月起马来量产BBU用21700、推出圆柱LFP BBU电芯；②**海外产能不再独占**——亿纬马来一期圆柱6.8亿只/年已量产（蔚蓝的1.7倍），长虹三杰马来1.7亿只在建，这直接导致**马来天鹏2026H1收入仅0.83亿、亏损0.50亿**，且公司明确2026年无进一步扩产计划。

### 1.3 核心风险

1. **利润的现金含量恶化（最重要的新风险）**：前三季OCF 7.58亿（-27.8%），Q3单季对归母覆盖率仅0.65倍；存货30.0亿（较年初+55%）、应收25.87亿（+32.6%）。
2. **Q4存货跌价风险**：10月碳酸锂现货自10.2万跌至9.36万/吨（较9月11日-30.5%），30亿存货存在现实减值敞口。
3. **税费双重压制（2027年）**：消费税2027-09-01由2%升至4%、出口退税2027-01-01归零，合计对2027年税前利润拖累约1.85亿元（税后约1.6亿、占2026年归母14%）。
4. **BBU身份升级未确认**：直供若始终未落地，2027年将是"量增利平"的平台年，估值应回落至13-15x。
5. **竞争加剧**：亿纬/三星/长虹三杰/比克/新能安在全极耳与BBU双线扩张，全极耳供不应求预计2027年缓解。
6. **财务杠杆与担保**：资产负债率42.47%（+5.65pct）、担保额度71.5亿=净资产93.55%、短期借款+183.6%、财务费用+237.6%。
7. **马来西亚基地持续亏损**：2026H1净利-0.50亿（2025全年-0.22亿），亏损扩大。
8. **印尼项目资本开支**：2.9亿美元5GWh，2027年开工、2029年投产，2027-2029年自由现金流承压。
9. **地缘风险**：中国第58号出口管制暂停期在法条上于11-10到期（已宣布延至2027-01-10但无修订文书）；美国对非车用锂电池25%的301关税档次未变。
10. **股价异动原因未明**：10-20至10-30股价-27%，公司仅回复"经营正常"，存在未披露利空的尾部风险。

## 三、研究结论象限图

基于**确定性**与**预期收益空间**二维评估：

```
                      预期收益空间
                    低              高
            ┌─────────────────────────┐
    高      │  第三象限              │  第一象限             │
            │ (Defensive Value)      │ (High-Conviction Buy) │
    确      │                        │                       │
            │                        │                       │
    定   ───┼─────────────────────────┼───────────────────────
            │                        │                       │
    性      │  第四象限              │  第二象限             │
            │ (Avoid/Wait)           │ (Speculative Growth)  │
    低      │                        │    ★蔚蓝锂芯（偏上沿） │
            └─────────────────────────┘
```

**蔚蓝锂芯当前定位：第二象限偏上沿（Speculative Growth），向第一象限过渡的条件尚未满足**

**理由**：
1. **预期收益空间中高**：现价11.01元低于加权目标价14.30元约+29.9%、低于修正中性目标价13.55元约+23.1%，盈亏比1.25
2. **确定性中等（3.0/5）**：结构升级已被Q3报表验证（正面），但OCF/存货/担保/马来亏损同步恶化（负面），两者相互抵消，维持"中"档
3. **为何不是第一象限**：第一象限要求"高确定性"，而2027年利润的三大变量（BBU直供、税费传导率、工具去库幅度）均未验证；且盈亏比1.25未达1.5

**操作建议**：
- **当前位置**：**增持（左侧分批建仓，仓位上限1/3）**，评级由"观望"上调一档，不称"买入"
- **建仓节奏**：首批不超过计划仓位的1/3，在10.25-11.00元区间建仓；收复MA20（12.34元）后加第二批；2027H1 BBU直供落地或Q4报表OCF修复后加第三批
- **防守位**：跌破10.25元（双底）减仓；跌破8.37元（保守目标价）清仓重估
- **不加仓的情形**：马来天鹏2027H1仍亏损且收入<2亿、锂电池毛利率连续两季<20%、BBU直供确认失败

## 四、最终判断

蔚蓝锂芯是一家**好赛道里的二线龙头**，2026年的经营成果（前三季归母+64.8%、Q3合并毛利率22.97%创四年新高）证明了"结构升级"战略的正确性；但同一份报表也暴露了扩张期的代价（OCF-27.8%、存货+55%、担保93.55%、马来亏损0.50亿）。

市场在10月用-27%的暴跌完成了对"增长质量"的重新定价：PE-TTM从27.6x压缩至18.05x（5年0.4%分位）、PB-ROE溢价从+120%（10月中旬）收窄至+15%、Forward PB 1.96x已等于理论值1.91x。**估值泡沫已基本出清。**

但必须正视市场预期与本研究的分歧：卖方2027E为16.2-20.0亿（中金18.25/东吴20/方正16.2），本报告仅12.2亿，低25%-39%。按卖方预测，现价188.29亿仅对应9.4-11.6x PE——**市场并非在为"零增长"定价，而是在为"BBU大幅放量"定价**。本报告的相对谨慎来自：公司自述BBU"有限参与、供需总体平衡"、直供无定点、Q3出货环比-10%、存货与OCF恶化。若卖方正确，则上行空间远大于本报告测算；若本报告正确，则现价只是"合理"而非"便宜"。

**投资建议**：由"观望"上调至**"增持（左侧分批建仓，仓位上限1/3）"**。核心逻辑不是"公司很好"，而是"价格已经反映了大部分坏消息，而好消息（结构升级）仍在持续，赔率由负转正"。盈亏比1.25、上行空间+29.9%，已跨过1但未达1.5的积极配置阈值；确定性仅中等，因此必须分批、必须设防守位（10.25元）、必须以2027H1的BBU直供落地作为最后的加仓裁决点。

**一句话结论**：好的公司在错误的价格上是坏的投资；蔚蓝锂芯现在不再是错误的价格，但也还不是"可以闭眼买"的价格——赔率已站在这边，确定性还没有。
