# 研报章节八：投资摘要与风险因素

**研究日期：2026年10月16日**

## 一、投资摘要

### 1.1 公司核心画像

蔚蓝锂芯（002245.SZ）是一家从金属物流转型而来的锂电池制造商，当前业务结构为**锂电池52%+LED 18%+金属物流28%**，战略核心聚焦于圆柱小动力锂电池。通过子公司天鹏电源（20年圆柱电芯经验），公司在高倍率小圆柱电芯领域建立了**全球领先地位**，客户涵盖博世、TTI、史丹利百得等全球TOP4电动工具品牌。2025年营收81.13亿元（+20%），归母净利7.11亿元（+46%），锂电池出货6.73亿颗（+52%），三项均创历史新高。2026年H1延续强劲增长，营收48.58亿元（+30.4%），归母净利5.11亿元（+53.4%），其中锂电池业务营收25.27亿元（+58.43%），增长动力来自高端化战略推进和海外客户补库延续。

### 1.2 投资逻辑三支柱

**支柱一：国产替代+补库双轮驱动的业绩修复（确定性强）**

日韩电池企业（三星SDI、LG、松下）战略性退出或减少电动工具小圆柱电池供给，中国厂商份额从2023年29.3%跃升至2024年43.6%。蔚蓝锂芯作为增速最快的中国企业（+100%+），正在系统性替代日韩份额。叠加2024-2025年电动工具渠道补库周期，**锂电池业务营收从2023年的约16亿元翻倍至2025年的35.97亿元**。2026年马来西亚工厂产能释放将进一步支撑增长。

**支柱二：全极耳+BBU/AI/eVTOL的成长期权（想象空间大，不确定性高）**

公司是国内唯一量产NCA体系圆柱电池的企业，2025年5月率先实现全极耳电芯量产，卡位BBU（数据中心备用电源）、AI机器人、eVTOL（飞行汽车）等爆发性场景。根据东吴证券7月研报，**26年BBU需求近4亿颗，28年需求超12亿颗，30年需求超28亿颗**，赛道成长性极强。公司BBU电源已进入放量出货阶段（4月28日业绩说明会确认），近期铁锂电芯实现突破，通过联合销售形式进入Google和AWS体系。东吴证券上修26-28年归母净利为13/25/36亿元，BBU利润27年有望突破1亿美金。但技术放量节奏、客户验证进度、竞争格局演变均存在较大不确定性。

**支柱三：全球化产能+客户认证壁垒（护城河中深）**

马来西亚工厂一期4亿支/年已于2025年4月投产，是中国小圆柱电池企业中首个海外工厂。与台湾能元科技（Molicel）的战略合作打通了BBU/eVTOL高端供应链。博世2025年全球供应商大奖、与TTI/史丹利百得的深度绑定构成了中强度的客户认证壁垒（1-2年切换周期）。

### 1.3 核心风险

1. **估值消化（已显著收敛）**：视图实测10-15收盘14.35元（PE-TTM 27.62x/PB 3.08x）较09-10大幅回调，已低于加权目标价16.23元（2027E口径），估值从轻度高估转为合理偏低。
2. **消费税政策（09-01已落地）**：2026年9月起2%已生效（2027年9月起4%，钠电/固态免至28-12-31，半固态不免），Q3毛利率为首个验证点；亿纬/力神已加价2%部分传导。
3. **竞争加剧（已补全）**：亿纬锂能2026H1 456.91亿+62.2%扩张激进且储能44.46GWh首超动力，三星SDI 2026Q2转正（BBU/UPS驱动，马来产能>12亿颗，BBU指引+70%）7月起量产BBU用21700全极耳，工具电池竞争强度上行。
4. **补库周期终结风险**：电动工具补库可能在2026-2027年结束，届时需依赖BBU等新兴场景填补缺口。
5. **印度尼西亚投资风险**：拟投资2.9亿美元建设5GWh项目，存在地缘政治和审批风险。

## 三、研究结论象限图

基于**确定性**与**预期收益空间**二维评估：

```
                      预期收益空间
                    低              高
            ┌─────────────────────────┐
    高      │  第三象限              │  第一象限             │
            │ (Defensive Value)      │ (High-Conviction Buy) │
    确      │                        │                       │
            │                        │                       │
    定   ───┼─────────────────────────┼───────────────────────
            │                        │                       │
    性      │  第四象限              │  第二象限             │
            │ (Avoid/Wait)           │ (Speculative Growth)  │
    低      │                        │       ★蔚蓝锂芯       │
            └─────────────────────────┘
```

**蔚蓝锂芯当前定位：第二象限（Speculative Growth）**

**理由**：
1. **预期收益空间改善**：当前股价14.35元低于加权目标价16.23元约+13.1%（2027E口径），盈亏比由负转正至0.68
2. **确定性中等**：H1业绩超预期验证增长逻辑，但估值安全边际仍不足；技术面转弱需Q3基本面验证

**操作建议**：
- **当前位置**：观望。估值已消化至合理偏低，但盈亏比仍<1
- **关注价位**：13-14元（PE约20-22x）可开始关注，11-12元（PE约17-19x）进入合理布局区域
- **理想介入点**：11.58元（保守目标价）附近，提供足够的安全边际

## 四、最终判断

蔚蓝锂芯是一家**好公司**（赛道好、管理层专注、技术领先、客户优质），当前估值已消化至**合理偏低**。公司基本面改善的故事是真实的，H1业绩超预期（归母净利5.11亿，+53.4%）验证了增长逻辑，国产替代+新兴场景的成长逻辑也是成立的。市场已将积极因素部分定价回调：现价14.35元对应2027E PE约22.3x（中性11.2亿/14.35），较09-10的32x显著改善，PE-TTM 27.62x已回落至40%分位。技术面已转弱（击穿MA20/MA60，创09-10以来新低14.35元），短线为弱势寻底。

**投资建议**：观望，等待Q3验证。好的公司在错误的价格上仍然是坏的投资。技术-基本面共振支撑11.58-13元（保守目标价-PE 20x）为下一击球区；放量收复15.26（修正中性目标价）或回踩11.58-13企稳为右侧信号。当前不追高、不抄底。
