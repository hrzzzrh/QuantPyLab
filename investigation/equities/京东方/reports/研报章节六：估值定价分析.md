## 一、价值锚定：适配性方法选择

### 1.1 方法论筛选

基于京东方"重资产+周期波动+低ROIC"的特征，筛选估值方法：

| 方法 | 适用性 | 理由 |
|:---|:---|:---|
| **PE** | ★★★★☆ | 最常用，但须注意利润周期性（PE在利润高峰时低、低谷时高） |
| **PB-ROE** | ★★★★☆ | 重资产企业天然适合PB估值，ROE是PB的锚 |
| **PCF（市现率）** | ★★★★★ | OCF远大于净利润，最能反映真实现金产出能力 |
| DCF | ★★☆☆☆ | CAPEX周期不确定、FCFF极不稳定，参数敏感度极高 |
| EV/EBITDA | ★★★☆☆ | 排除了折旧政策差异，适合重资产同行比较 |
| PEG | ★☆☆☆☆ | 利润增速低且不稳定，不适用 |
| SOTP | ★★★☆☆ | 多业务板块，但非核心板块体量太小（<20%营收） |

**选择组合**：**PB-ROE**（主）+ **PE**（辅，基于概率加权EPS）+ **PCF**（交叉验证）

### 1.2 PE估值法（基准：2026E Base EPS 0.26元）

| 情景 | 2026E EPS | 适用PE | 目标价（元） | 目标市值（亿） |
|:---|:---|:---|:---|:---|
| Bear | 0.22 | 18x（危机PE） | 3.96 | 1,467 |
| Base | **0.26** | 22x | **5.72** | **2,119** |
| Bull | 0.29 | 25x（乐观PE） | 7.25 | 2,686 |

**PE选择逻辑**：Base PE从25x下调至22x——理由：(1) H1约20亿非经常性损益（公允价值变动收益）降低盈利质量，扣非口径全年约64-68亿（EPS约0.18元）；(2) H2面板价格进入跌价周期，盈利环比将下行；(3) 但盈利基数大幅上修+OLED量产+三星合作扩容+35%分红承诺提供支撑，维持周期股合理偏上的倍数。22x PE对应目标市值2,119亿，目标价5.72元，**较当前价5.51元溢价3.8%**——注意5月27日研报中25x PE的目标价5.25元恰好与当前价5.51元接近，本次盈利上修（EPS 0.21→0.26）使PE锚整体上移。

### 1.3 PB-ROE估值法（主力方法）【更新】

**参数设定（2026E）**：
- ROE（Base 2026E）= **7.0%**（净利95亿/平均净资产约1,370亿，较2025年的4.39%大幅提升；2025年末归母净资产1,360.97亿，加2026年留存盈利减分红后年末约1,421亿）
- COE = 9.6%（无风险利率3.0% + ERP 5.5% × β 1.2）
- g = 2.0%

```
公允PB = (7.0% - 2.0%) / (9.6% - 2.0%) = 5.0% / 7.6% = 0.66x
```

**当前PB 1.50x vs 公允PB 0.66x → 当前定价仍包含显著ROE改善预期**（隐含ROE 13.4%），但偏离度从5月的"3.2倍ROE"收窄至"1.9倍"。

| ROE水平 | 对应PB（公允） | 对应市值（亿） | 对应股价（元） | 对应情景 |
|:---|:---|:---|:---|:---|
| 3%（长期低迷） | 0.13x | 185 | 0.50 | 极端悲观 |
| 7%（2026E Base） | 0.66x | 938 | 2.53 | PB-ROE理论公允 |
| **8%（2026-27E改善）** | **0.79x** | **1,123** | **3.03** | 中性偏保守 |
| **10%（OLED放量）** | **1.05x** | **1,492** | **4.03** | 2027-28E乐观（中性情景目标价基于2026E盈利） |
| **13.4%（当前价隐含）** | **1.50x** | **2,041** | **5.51** | **当前价** |
| 15%（超级周期） | 1.71x | 2,430 | 6.56 | 需超级周期 |

**PB-ROE基准估值**：考虑折旧下降通道+OLED放量+分红提升+康宁期权，给予2026E ROE 7%约1.0x PB（估值修复溢价，2027年ROE有望维持6.5-7%），对应股价约3.84元（每股净资产2026E约3.84元×1.0x）。

### 1.4 PCF（市现率）交叉验证

| 指标 | 当前值 | 历史低位 | 合理区间 | 
|:---|:---|:---|:---|
| PCF(TTM) | 4.31x | ~2.0x（2021年） | 4-6x（正常化） |
| EV/EBITDA | ~6.0x（估算） | ~3x | 5-8x |

当前PCF 4.31x处于合理区间下沿。OCF/股约1.28元（TTM 474亿/370亿股），2026E OCF预计约510亿（折旧下降+以价换量出货增长），对应OCF/股约1.38元：
- 4x PCF → 股价5.51元

**PCF视角**：当前价5.51元位于4x PCF附近（5月时位于4-5x区间），反映市场对现金流质量的认可趋于理性。新分红承诺（2025年度已实施21亿，占35.3%）提升现金流回报效率。

### 4.2 盈亏比计算【2026年8月2日重算】

```
盈亏比 = (概率加权目标价 - 现价) / (现价 - 保守价格)

       = -0.73 / 1.55
       = -0.47
```

**盈亏比为负值（-0.47）**——当前价格下的预期下行风险仍略大于上行空间，但较5月27日的-0.52改善。核心变化：盈利大幅上修使分子（期望收益）从-2.44元收窄至-0.73元，同时股价回落42%使分母（保护垫）更厚。**若股价回落至4.50元以下，盈亏比将转为正值区间。**
