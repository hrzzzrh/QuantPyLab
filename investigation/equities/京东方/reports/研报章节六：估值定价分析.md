## 一、价值锚定：适配性方法选择

### 1.1 方法论筛选

基于京东方"重资产+周期波动+低ROIC"的特征，筛选估值方法：

| 方法 | 适用性 | 理由 |
|:---|:---|:---|
| **PE** | ★★★★☆ | 最常用，但须注意利润周期性（PE在利润高峰时低、低谷时高） |
| **PB-ROE** | ★★★★☆ | 重资产企业天然适合PB估值，ROE是PB的锚 |
| **PCF（市现率）** | ★★★★★ | OCF远大于净利润，最能反映真实现金产出能力 |
| DCF | ★★☆☆☆ | CAPEX周期不确定、FCFF极不稳定，参数敏感度极高 |
| EV/EBITDA | ★★★☆☆ | 排除了折旧政策差异，适合重资产同行比较 |
| PEG | ★☆☆☆☆ | 利润增速低且不稳定，不适用 |
| SOTP | ★★★☆☆ | 多业务板块，但非核心板块体量太小（<20%营收） |

**选择组合**：**PB-ROE**（主）+ **PE**（辅，基于概率加权EPS）+ **PCF**（交叉验证）

### 1.2 PE估值法（基准：2027E Base EPS 0.19元）

| 情景 | 2027E EPS | 适用PE | 目标价（元） | 目标市值（亿） |
|:---|:---|:---|:---|:---|
| Bear | 0.11 | 30x（周期底部PE：折旧压制下盈利处低位，市场看穿周期给高倍数） | 3.30 | 1,222 |
| Base | **0.19** | 24x | **4.56** | **1,689** |
| Bull | 0.30 | 25x（乐观PE） | 7.50 | 2,778 |

**PE选择逻辑**：Base PE从2026E口径的22x上调至24x——理由：(1) 2027E盈利因折旧净增70亿而回落至70亿（EPS 0.19，较2026E -26%），属周期下行年，市场对下行年盈利给予更高倍数（"看穿周期"）；(2) 但B16折旧集中兑现+ROIC<WACC+1260H地缘折价压制，倍数不能过高，24x对应目标市值1,689亿、目标价4.56元（**较当前价5.05元仍折价-9.7%**）；(3) Bear情景采用30x底部PE（EPS 0.11），Bull采用25x（EPS 0.30）。**PE法三态与PB-ROE法（§1.3）交叉验证：Base PE法4.56元 ≈ PB-ROE法（ROE 5.0%×PB 1.15x→4.47元），互证成立。**

### 1.3 PB-ROE估值法（主力方法）

**参数设定（2027E）**：
- ROE（Base 2027E）= **5.0%**（净利70亿/平均净资产约1,400亿；2027E年末归母净资产预计约1,439亿，含2026E留存约62亿+2027E留存约45亿，扣回购注销）
- 每股净资产（2027E年末）= 约3.89元
- COE = 9.6%（无风险利率3.0% + ERP 5.5% × β 1.2）
- g = 2.0%

```
公允PB = (5.0% - 2.0%) / (9.6% - 2.0%) = 3.0% / 7.6% = 0.39x
```

**当前PB 1.41x（10-15收盘5.05元/H1末每股净资产3.59元，9-30时1.59x） vs 公允PB 0.39x → 当前定价仍包含显著ROE改善预期**（隐含ROE 12.7%），偏离度较9-30走阔（因2027E ROE基准下移）。

| ROE水平 | 对应PB（公允） | 对应市值（亿） | 对应股价（元） | 对应情景 |
|:---|:---|:---|:---|:---|
| 2%（长期低迷） | 0.00x | 0 | 0.00 | 极端悲观（理论下限，实际以历史5%分位PB 1.01x=3.93元为底） |
| 5%（2027E Base） | 0.39x | 564 | 1.52 | PB-ROE理论公允 |
| **5%（2027E Base+估值修复溢价）** | **1.15x** | **1,652** | **4.47** | **中性（含折旧通道+OLED+分红溢价）** |
| **7.7%（2027E Bull）** | **1.45x** | **2,089** | **5.64** | 乐观（OLED放量+面板企稳） |
| **2.5%（2027E Bear）** | **0.85x** | **1,226** | **3.31** | 保守（历史5%分位PB 1.01x下方） |
| **12.7%（当前价隐含）** | **1.41x** | **1,871** | **5.05** | **当前价** |

**PB-ROE基准估值**：考虑折旧压力（B16转固）+OLED放量+分红提升（35%）+康宁期权+地缘折价，给予2027E Base ROE 5.0%约1.15x PB（估值修复溢价，低于历史5%分位1.01x之上但显著高于理论公允0.39x），对应股价约4.47元（每股净资产2027E约3.89元×1.15x）。**PB-ROE法Base（4.47元）与PE法Base（4.56元）互证，取整后中性情景目标价4.56元。**

### 1.4 PCF（市现率）交叉验证

| 指标 | 当前值 | 历史低位 | 合理区间 | 
|:---|:---|:---|:---|
