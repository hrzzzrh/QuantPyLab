## 一、价值锚定：适配性方法选择

### 1.1 方法论选择与理由

豪威集团是Fabless半导体设计公司，兼具周期成长属性。选择以下三种方法进行交叉验证：

| 方法 | 适用理由 | 权重 |
| ---- | -------------------------------------------- | ---- |
| **PE估值法**（主导） | 盈利已进入稳态，PE是科技成长股最主流的定价锚 | 50% |
| **PEG估值法** | 公司处于成长阶段，需要纳入增速考量 | 25% |
| **历史PE分位法**（参考校验） | 提供长周期坐标 | 25% |

不使用DCF的理由：半导体行业周期性显著，远期自由现金流预测不确定性过高。不使用PB的理由：Fabless公司轻资产属性，PB参考意义有限。

### 1.2 基准PE与市值

**当前估值锚点**：2026年EPS（加权）= 2.43元/股（8月24日下修版）

> 股本口径说明：PE TTM（28.2x）按系统现时总股本12.577亿股计算；全部远期EPS、目标价与市值测算按回购注销后的12.4895亿股口径（875万股注销尚待2026年9月中旬临时股东会审议，若未获通过则EPS与目标价需按12.577亿股下调约0.7%）。

**可比公司PE参照（2026年8月更新）**：

| 公司 | 最新盈利趋势 | 当前估值特征 | 对比结论 |
| ------------ | ---------------- | ----------- | -------------------------------- |
| 索尼（I&SS口径） | Q1 FY26营业利润+125%，全年指引上修 | ~17x | 高端垄断+盈利上修，垄断溢价成立 |
| 思特威 | H1归母+33.15%，逆行业周期增长 | A股~30-35x | 高成长稀缺标的享受A股溢价 |
| 安森美 | Q2 EPS超预期，Q3毛利率指引40-42%扩张 | FY26E约27x | AI电源叙事+盈利扩张双击 |
| **豪威集团** | **H1归母-39.85%，全年下修至30亿（-26%）** | **PE TTM 28.2x** | **平台型龙头，2026年为盈利下修年** |

**基准PE判断（较8月5日版本再降2x）**：

- 豪威的盈利规模（30亿E）与全场景平台地位仍高于思特威，应保留部分龙头溢价；
- 但2026年盈利同比-26%、2027年恢复幅度收窄（38亿左右，原机构一致预期55亿的路径不现实）、复苏时点推迟至2028年——增速溢价的根基受损；
- 可比对标下移：索尼17x（无增长）、安森美27x（AI叙事+盈利扩张），豪威介于两者之间；
- 合理PE区间：**26-32x**（原28-36x下修）
- **基准PE = 30x** → 基准目标市值 = 30亿 × 30 = **900亿**

**修正目标市值 = 900亿 × (1-2%) = 882亿**  
**修正目标价 = 882亿 ÷ 12.4895亿股 ≈ 70.6元/股（不复权市价）**

### 交叉验证1：PEG估值（2027年口径）

2026年为盈利大幅下滑年（30亿 vs 40.45亿），PEG分子使用2027年增速：本模型2027E归母约38亿（同比+27%），现市值约1,030亿（82.50元×12.4895亿股）对应2027E PE 27.1x，PEG = 27.1/26.7 ≈ **1.02**——**估值已不再显著低估**（8月5日版本同口径PEG约0.57，一个月内因盈利下修而快速正常化）。若以更远的2028年复苏口径测算（假设归母回到45亿+），现价对应2028E PE约23x——安全垫存在但兑现时点在两年以后。

### 交叉验证2：历史PE分位（8月24日实测）

| 分位 | PE值 | 说明 |
| ------------- | --------- | ------------------------------------------- |
| P25 | 33.2x | 近5年样本（2021-08至2026-08） |
| P50（中位数） | 42.2x | 受2021-2023年极致高估/亏损期的影响 |
| 当前 | **28.2x** | **近5年约5%分位（低于P25）** |

**审慎判断**：PE TTM 28.2x处于近5年约5%分位，绝对坐标已低于8月5日时的26%分位并跌破P25。但必须警惕"低分位陷阱"：①当前TTM盈利（截至Q1约36.8亿）尚未完全反映H2盈利下修，分母还将收缩；②上一轮P25以下区域（2023年）对应的是扣非净利仅1.38亿的盈利谷底，低分位本身不构成反转证据。**极低分位提供的是缓冲而非买点，方向确认需等Q3财报。**

## 三、三态目标价与盈亏比

| 情景 | 概率 | 2026E EPS | 目标PE | 目标价（不复权） | 相对现价涨幅 |
| -------- | :------: | ---------- | :-----: | ---------------- | :--------: |
| 保守 | 20% | 2.16元 | 24x | 51.9元 | -37.1% |
| **基准** | **55%** | **2.40元** | **30x** | **70.6元**（含-2%审计调节） | **-14.4%** |
| 乐观 | 25% | 2.72元 | 36x | 98.0元 | +18.8% |
| **加权** | **100%** | **2.43元** | — | **73.7元** | **-10.7%** |

**加权目标价 = 51.9×0.20 + 70.6×0.55 + 98.0×0.25 = 73.7元**（基准档采用修正目标价70.6元，保守/乐观为未调节情景价；保守档PE 24x对应盈利无增长可见度下的谷底倍数，乐观档PE 36x为合理区间上沿）

**盈亏比 = (73.7 - 82.5) / (82.5 - 51.9) = -8.8 / 30.6 = -0.29**

盈亏比转负（8月5日版本为0.48）：概率加权目标价73.7元低于现价82.50元，**期望收益为-10.7%，下行风险大于上行空间且期望值为负**。核心变化：①全年盈利预测再度下修25%（40亿→30亿）；②手机需求复苏推迟至2028年；③税率结构性抬升压降利润中枢；④股价虽自90.83元下跌9.2%，但仍未跌入与下修后基本面匹配的价值区间。**框架含义：在当前价格上，既不建议持有博反弹，也不建议追空——正确动作是等待，直到价格落入价值区间或基本面出现右侧拐点。**

## 四、极限压力测试（黑天鹅）

**定义事件**：中美全面科技脱钩，中国CIS被列入实体清单，无法获取台积电等主要代工厂的晶圆供应。

**情景推演**：

- 设计业务产能骤降至30%（仅靠国内代工厂如中芯国际、晶合等接续，但良率/产能/先进节点不匹配）
- 汽车与手机海外客户收入大部分流失，归母净利降至约5亿（参考2023年低谷水平）
- 当年PE炒作至60x+（供给短缺预期），市值约300亿
- 但此后若代工彻底断绝，长期归零风险

**极限支撑位（基于资产价值，按2026H1末报表更新）**：

- 归母净资产：327.08亿 ÷ 12.4895亿股 ≈ **26.2元/股**（净现金价值锚）
  - 货币资金：149.36亿 → 每股净现金约**12.0元**
- **地狱价格 = 净现金价值 ≈ 12.0元/股**（极端清算情景，概率<1%）
