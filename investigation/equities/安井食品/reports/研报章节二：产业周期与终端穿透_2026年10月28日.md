# 研报章节二：产业周期与终端穿透

**研究日期**：2026年10月28日
**研究对象**：安井食品（603345）
**目标年份**：2027年（Q4 切换期锚定次年，2026年（F）保留为对照口径）

---

## 一、产业生命周期与库存节奏

### 1.1 周期定位：成长期中后段，结构性分化明显

中国速冻食品行业整体处于**成长期中后段**，但子行业生命周期分化显著：

| 子行业 | 生命周期阶段 | 2024年市场规模 | 2024-2029 E CAGR | 核心驱动力 |
| :--- | :--- | :--- | :--- | :--- |
| 速冻调制食品 | **成长期** | ~565亿元 | 7.1% | 火锅连锁化、麻辣烫、烧烤场景扩容 |
| 速冻菜肴制品 | **起步期/成长早期** | ~868亿元 | **16.1%** | 餐饮B端标准化、预制菜国标规范、家庭便捷需求 |
| 速冻面米制品（传统） | **成熟期** | ~771亿元（含新兴） | 低个位数 | 存量替代，现包饺子冲击 |
| 速冻面米制品（新兴） | **成熟前期** | — | 高个位数 | 手抓饼/烧麦等场景化创新 |
| 冷冻烘焙 | **成长早期** | — | >15% | 烘焙连锁化、冻转鲜技术 |

_数据来源：弗若斯特沙利文、安井年报_

**总体判断**：中国速冻食品行业2024年市场规模约2,212亿元（沙利文口径；分项565+868+771=2,204，差额为其他子类），2024-2029年预计CAGR 9.4%。不同机构对2025年绝对值口径存在差异（2,042-2,131亿元），本报告以2024年沙利文口径为基准，不用2025年区间做趋势外推。中国人均速冻食品消费量仅10.0公斤，远低于美国（62.2公斤）、英国（45.9公斤）和日本（25.3公斤），**行业远未触及天花板**。

### 1.2 库存动力学——小龙虾的"牛鞭效应"警报

安井2025年产销数据暴露了库存问题的严重分化：

| 品类 | 2025年产量同比 | 2025年销量同比 | 库存量同比 | 库存/销量比 |
| :--- | :--- | :--- | :--- | :--- |
| 速冻调制食品 | +3.93% | +5.93% | +0.76% | 14.6%（健康） |
| 速冻面米制品 | -1.94% | +1.57% | -12.28% | 14.2%（去库） |
| 速冻菜肴制品 | **+18.84%** | **+7.19%** | **+54.84%** | **18.6%（危险）** |

**核心辨析**：速冻菜肴制品（主要是小龙虾及虾滑系列）出现严重的**产大于销**——产量暴增18.84%，但销量仅增7.19%，导致库存同比暴增54.84%。这究竟是终端需求减弱，还是渠道"牛鞭效应"？

综合判断更倾向于**需求侧结构性问题 + 渠道囤货放大效应**：

1. **小龙虾消费增速放缓**：经过2020-2023年爆发式增长后，小龙虾品类逐步进入成熟期，消费者新鲜感减退。
2. **产量被动扩张**：安井通过收购新柳伍等上游资产保证原料供应，导致产量刚性增长，但终端需求未能同步吸收。
3. **渠道牛鞭效应**：经销商在2024年小龙虾旺季预期乐观大量备货→终端销售不及预期→库存积压→2025年继续压货→库存进一步堆积。

**借鉴教训（模块一关联）**：2024年资产减值损失0.52亿→2025年飙升至2.14亿（含商誉减值和小龙虾存货跌价）。若2026年小龙虾行情持续低迷，存货减值风险仍未释放完毕。

## 二、终端需求穿透与跨期断层审计

### 2.1 最终产品画像——安井食品"最终负载"于何处？

安井的产品最终负载在以下终端消费形态：

```
B端（约70-75%）                    C端（约25-30%）
├─ 火锅店 → 鱼丸、肉丸、虾滑      ├─ 家庭火锅 → 锁鲜装、火锅料
├─ 麻辣烫/关东煮 → 丸子系列        ├─ 空气炸锅 → 烤肠、小酥肉
├─ 连锁中餐 → 小酥肉、牛肉卷       ├─ 早餐场景 → 手抓饼、烧麦
├─ 团餐/食堂 → 标准化菜肴          ├─ 休闲零食 → 烤肠、薯条
├─ 西式快餐 → 冷冻烘焙(鼎味泰)     └─ 快手烹饪 → 预制菜肴
└─ 烧烤店 → 烤肠系列
```

**核心依赖路径**：安井食品与火锅/麻辣烫产业链深度绑定，其B端营收约70%依赖餐饮渠道。火锅料（鱼丸、肉丸、虾滑等）和面向餐饮的标准化菜肴是关键业绩变量。

### 2.2 终端景气度审计——增速放缓但结构性机遇并存

#### （1）火锅/麻辣烫行业：存量出清延续，B端基本盘承压但结构利好龙头

- 2025年中国火锅市场规模约6,390亿元，同比增长3.5%；2026年预计约6,700亿元
- 火锅门店数从2024年高峰52万家回落至2025年的44.8万家（-15.4%），**关店潮延续**：2026Q1一线城市标杆商场火锅闭店1,300家、约为新开店1.5倍
- **2026Q3边际企稳**：红餐大数据口径火锅门店由2026Q2的42.7万家回升至Q3的43.2万家（环比+1.2%），为连续两季下降后首次止跌；窄门餐眼口径截至9月48.3万家、近一年仍净减5.2万家（开14.3万/关约20万），说明总量仍在出清、但边际关店速度放缓
- **麻辣烫门店加速收缩**：从2024年16.6万家降至2025年14.7万家（-11.45%），2026年6月底进一步降至约13.4万家——麻辣烫/冒菜是丸子类产品的重要B端场景，门店收缩构成需求侧持续压力
- 结构性亮点：连锁化率25%→预计2030年35%；围辣小火锅（年新开800+店）、许府牛等高性价比细分品牌快速扩张；CR10约20%（+3.8pct）

**需求侧最新坐标（2026年9月）**：全国餐饮收入4,603亿元、同比+2.1%（较8月+1.0%回升），限额以上餐饮收入1,413亿元、同比+2.0%（由8月的-0.7%转正），1-9月餐饮收入41,969亿元、同比+2.4%。餐饮景气指数9月回落至99.4（2025年10月以来首次进入不景气区间），说明9月回暖更多来自中秋国庆双节错位与低基数，行业仍处弱复苏通道。**对安井的影响**：门店总数收缩压制行业总量，但Q3安井营收+11.37%、显著高于餐饮大盘+2.1%，验证"总量弱、结构升"——连锁化与供应链标准化带来的份额转移仍在继续。2026H1公司调制食品收入+26.4%，Q3在更高基数上仍保持双位数，龙头份额逻辑未破。

#### （2）餐饮连锁化率：核心结构性驱动，确定性极强

- 中国餐饮连锁化率从2019年13%提升至2025年25%，2024年501-1000家规模品牌门店数同比暴涨93.6%
- 万店品牌已达9家，千店品牌近40个
- 连锁餐饮的标准化需求 → 中央厨房/速冻半成品 → **安井食品的直接增量市场**

**这一逻辑具有极强的不可逆性**：一家全国有1000+门店的连锁品牌，不可能在每个门店配专业厨师从零加工——中央厨房预制+门店复热是唯一具备规模可行性的解决方案。安井作为速冻半成品供应商，本质上是"连锁餐饮的体外中央厨房"。

#### （3）团餐/西式餐饮：被低估的增量引擎

- 团餐市场2024年规模2.07万亿元，预计2024-2029年CAGR 9.1%
- 西式餐饮2024年规模9,175亿元，预计CAGR 9.8%
- 这两个赛道对食品安全、出品一致性、标准化程度的要求极高，与速冻食品特性天然契合

#### （4）C端：空气炸锅+一人食的结构性红利

- 空气炸锅保有量快速攀升 → 催生"速冻小吃"品类爆发（烤肠、小酥肉、薯条从偶尔吃到高频零食）
- 家庭小型化（户均人数持续下降）→ 小包装、单人份速冻产品增速显著高于传统家庭装
- 2025年Q2速冻食品是食品饮料酒类中**唯一**实现销售额同比增长的子类目（+1.3%）
- **2026Q3终端动销实证（餐饮界10-12监测）**：传统线下零售渠道火锅丸料、虾滑销售额分别同比+9.83%、+18.68%，速冻肠实现个位数增长——虾滑增速显著高于丸料，验证"虾滑放量+烤肠接力"的结构性趋势；渠道预计四季度主业收入同比+10-15%
- **餐饮B端冻品大盘（2026H1）**：中式餐饮即烹型冻品采购规模1,413亿元、同比+13.1%，其中火锅烧烤制品+16.9%、冷冻预制菜品+15.7%、冷冻休闲小吃+11.4%——行业总量仍在双位数扩容，但白牌/贴牌占64.3%、单店产出普遍回落，说明增长更多来自渗透率提升（铺货面扩大）而非单店用量提升；这与安井"小B渠道下沉+经销商赋能"的策略同向

### 2.3 动能溯源与透支审计

#### 增长动能来源：

| 驱动因素 | 性质 | 可持续性 |
| :--- | :--- | :--- |
| 餐饮连锁化率提升 | **内生结构性** | ★★★★★（长期不可逆） |
| 冷链基础设施完善 | **外生基础设施** | ★★★★（稳步推进） |
| 家庭小型化/一人食 | **内生人口结构** | ★★★★★（长期不可逆） |
| 空气炸锅普及 | **外生设备渗透** | ★★★（短期爆发，中期饱和） |
| 预制菜国标出台 | **外生政策规范** | ★★★★（利好龙头，出清小散） |
| 火锅出海国际化 | **外生市场拓展** | ★★★（中长期渐进） |
| 消费补贴/刺激政策 | **外生短期干预** | ★（不可持续） |

#### 跨期需求透支审计：

**结论：安井食品的增长逻辑中不存在显著的"跨期需求透支"风险。**

审计要点：
1. **火锅料消费是高频重复性消费**，不存在"买了今年就不买明年"的跨期替代——这与家电/汽车的购置补贴导致的透支性质截然不同。
2. **连锁化率的提升是单向上行的产业结构变化**，不是短期政策催化的"伪需求"。
3. **唯一值得警惕的透支信号**：小龙虾品类的库存积压可能反映了2022-2024年过度扩张后需求回归常态，但实际上这更像是品类生命周期从"爆发期"进入"成熟期"的自然减速，而非政策性透支。
4. **预防性警示**：需持续关注火锅门店关店潮是否加速（2025年已关15.4%），若关店率持续超20%，火锅料B端需求可能面临阶段性收缩。

## 三、供需边际与压力传导

### 3.1 供需平衡审计——产能释放vs需求增长

**供给侧**：
- 安井2025年设计产能129.07万吨（+15.36万吨），实际产量116.63万吨（+6.15万吨），产能利用率90.37%；2026年9月末在建工程4.95亿（较年初+53.1%），雁江三期/厦门安井/泰州三期继续推进
- 2026年计划推进河南三期、四川三期、厦门安井、泰州三期及鼎益丰烘焙项目建设
- 行业层面：**二线产能扩张出现纪律性收敛**——千味央厨10月26日公告将芜湖百福源项目达到可使用状态时间延期至2027年6月、鹤壁百顺源一期延期至2028年10月，理由是"产量和收入增长不及预期、避免产能集中释放闲置"；三全Q3归母-41.02%、海欣Q3亏损扩大，二线厂商在成本冲击下缺乏继续扩产能力。这与2025年"龙头扩产、二线跟进"的格局相比，供给端边际更有利于龙头

**需求侧**：
- 速冻食品行业整体需求增速：2024-2029 CAGR 9.4%；2026H1中式餐饮即烹冻品采购额+13.1%
- 安井自身营收增速：2024年+7.7%、2025年+7.1%、2026Q1+30.84%、Q2+13.77%、Q3+11.37%（低基数效应逐季消退，但仍在行业增速上沿）

**供需边际判断**：

| 品类 | 供需关系 | 未来1-2年趋势 |
| :--- | :--- | :--- |
| 速冻调制食品 | 紧平衡偏松 | 安井产能扩张（+15万吨）与二线扩产延期并存，火锅门店Q3止跌 → 总量压力边际缓和，但鱼糜成本推升价格中枢，毛利率取决于提价传导 |
| 速冻菜肴制品 | 结构性过剩 | 小龙虾供给过剩+预制菜赛道拥挤 → 低价竞争延续，盈利改善待国标落地与行业出清 |
| 速冻面米制品 | 存量博弈 | 千味主食类仅+3.79%、安井H1 -4.5%，传统米面受现包店与思念挤压；新兴品类（烧麦/手抓饼）增量有限 |
| 冷冻烘焙 | 供不应求 | 成长早期，鼎味泰+鼎益丰+IFC（拟收购）三线并进，有望成为新增长极 |

**核心预判**：行业正从"供需两旺"向"供给略大于需求"过渡，但2026Q3出现两个边际变化：①二线扩产延期、亏损扩大，供给纪律改善；②火锅门店止跌、餐饮收入增速回升，需求侧不再单边恶化。安井凭借规模与成本优势仍是整合受益者，但**成本冲击（鱼糜/鱼粉）取代需求不足，成为2027年毛利率的第一约束**。

### 3.2 压力传导特征分析

#### 原材料价格传导：直接且即时

安井直接材料成本占比64.20%。2026年10月末最新原料价格坐标：

| 核心原料 | 最新价格动态 | 对毛利率的影响 |
| :--- | :--- | :--- |
| 猪肉 | 农业农村部10月第3周猪肉集贸价20.59元/kg，同比-10.9%（8月第2周为20.89元、同比-16.5%）；生猪均价10.71元/kg、同比-13.1%；生猪养殖行业深度报告（10-17）判断猪周期反转窗口推迟至2027Q1-Q2 | 利好肉制品成本，但红利同比收窄；2027H1猪价大概率仍处低位，对冲部分鱼糜压力 |
| 鱼糜/鱼粉 | **鱼粉再创历史新高**：10月16日秘鲁生产部宣布不开放中北部B季鳀鱼捕捞，国内秘鲁超级蒸汽鱼粉报价升至24,900-25,000元/吨（较10-13的20,900-21,000元再涨约19%），港口库存降至12-13万吨；IFFO预计2026年全球鱼粉产量<460万吨（2016年以来最低）；鱼糜已连续六季上涨、2026年B季环比A季+25-35% | H2-2027H1最大成本压力项；公司淡水鱼糜自供+新宏业/新柳伍对冲，但无法完全抵消 |
| 小龙虾/虾类 | 2026年1-7月价格同比约-30%，6月下旬起自低位回升（潜江7月末中青13元/斤）；终端专门店从约10万家缩至6.1万家 | 利好菜肴制品成本与减值收敛；终端需求仍弱 |

**报表验证（2026Q3）**：2026Q3综合毛利率18.90%（同比-1.09pct），9M 20.51%（同比+0.17pct）；H1为21.24%（同比+0.72pct），其中调制食品28.36%（+1.01pct）、菜肴制品9.31%（+0.68pct）。Q3毛利率环比Q2的17.37%回升1.53pct，但同比转负，说明鱼糜成本的上行斜率超过产品结构与促销收缩的贡献；10月1日提价尚未进入Q3报表。

**传导机制**：原材料价格上涨直接压缩毛利率（滞后1-2个季度）。公司通过集中采购招标、淘汰低效供应商、淡水鱼糜替代对冲。2026年H2-2027H1的关键变量是鱼糜涨价向调制食品毛利率的传导幅度——敏感性测算（税后口径，按2027E调制食品收入105.0亿×1%×(1-23%)）：**调制食品毛利率每-1pct → 净利润约-0.81亿 → EPS约-0.24元**。

#### 终端需求波动传导：B端具缓冲、C端更敏感

- **B端波动**：餐饮客户通常签订年度/季度框架协议，需求波动相对平稳。安井前五大客户销售占比仅7.04%，客户高度分散，不存在单一客户的"断崖式"需求冲击风险。
- **C端波动**：家庭消费对价格更敏感，但速冻食品的"低价高频"属性使其在经济下行期反而具有"口红效应"——消费者减少外出就餐转向家庭火锅/速冻食品。2025年Q2速冻食品是食品饮料领域唯一正增长子类目印证了这一点。

#### 波动放大效应评估

**安井面临的波动放大效应相对可控**，原因：
1. 经销商库存周期短（速冻食品保质期通常12个月以内，预制菜国标要求不超过12个月），不存在长鞭效应的极端放大。
2. 唯一例外：小龙虾品类的季节性备货（Q2-Q3旺季前大量生产入库）→若旺季销售不及预期→形成大量过期库存→引发减值。这是需要持续监控的核心风险点。

#### 传导时滞与弹性

- **成本传导时滞**：原材料涨价→毛利率受损存在约1-2个季度滞后（库存原料消耗周期）。
- **定价弹性**：安井在B端对连锁餐饮客户具有一定议价能力（产品定制化、供应稳定性），在C端通过"高质中价"策略维持性价比优势。但行业整体供大于求的趋势将限制其提价空间。

### ✅ 复核1：终端产品未来两年景气度预测

**Q3竞对需求侧解读**：三全Q3营收+6.75%、千味+12.28%、海欣+8.15%、安井+11.37%——四家全部正增长，验证速冻/餐饮供应链需求在2026Q3仍处温和复苏（行业性，非安井孤立alpha）；但较各自Q2单季增速分化（安井13.77%→11.37%、三全约8%→6.75%放缓；千味11.76%→12.28%、海欣-0.7%→+8.15%环比改善），行业总量增速中枢下移、内部分化加剧。安井仍处增速上沿，份额逻辑成立。

### ✅ 复核2：跨期需求移位审计

未发现由刺激政策导致的显著跨期需求透支。速冻食品的核心驱动（连锁化、冷链、家庭小型化）均为结构性因素，不存在"补贴退坡后需求崩塌"的风险。**需关注**：10月提价前渠道主动备货（合同负债8.20亿较H1翻倍、9月动销"强于预期"含备货成分），可能将部分Q4需求前置至Q3——这属于企业主动的渠道库存管理，而非政策刺激，但需在Q4动销数据中验证是否透支。

### ✅ 复核3：供需边际演变与压力传导（Q3竞对竞争强度反哺）

行业供给增速阶段性超过需求增速（9.4%），但2026Q3出现供给纪律改善：千味将芜湖/鹤壁募投项目延期至2027年6月/2028年10月，三全Q3归母-41.02%、海欣Q3亏损扩大，二线厂商在鱼糜成本冲击下缺乏扩产与价格战能力。安井凭借规模效应和淡水鱼糜自供仍具竞争优势，但毛利率中枢已从2023年的23.21%下移至2026年9M的20.51%。压力传导最敏感的是面米/传统火锅料（三全Q3毛利率17.68%、同比-4.66pct；海欣Q3毛利率承压），安井Q3毛利率18.90%、同比仅-1.09pct，**相对成本优势在行业冲击中被放大**。竞争强度侧：三全Q3利润-41%但毛利率大幅下滑，说明其以价换量/成本转嫁能力弱；千味Q3毛利率21.70%（+0.52pct）靠渠道结构（电商/直营）改善，但销售费用+43.29%、所得税+67.91%，9M净利-5.55%（Q3单季已转正+4.67%）；海欣Q3亏损扩大。行业仍处"成本冲击+二线出清"阶段，龙头费用管控与供应链优势构成相对利好，但**绝对毛利率的下行是真实的，不能把相对优势误读为绝对安全**。

## 五、模块二与模块一的"红线"贯穿

**从模块一继承的核心约束**：
1. 模块一发现2025年净利润首次下滑（-8.46%）、毛利率降至21.60% —— **模块二确认**：这背后是原材料成本上涨+小龙虾库存积压+行业竞争加剧三重因素叠加，而非偶然；2026Q3毛利率18.90%（-1.09pct）说明成本冲击尚未结束，行业出清仍在进行。
2. 模块一发现资产减值损失暴增2.14亿 —— **模块二深化**：小龙虾业务的牛鞭效应是主因；2026年9M减值1.118亿（H1占1.032亿、Q3仅0.086亿），小龙虾库存已基本消化（存货36.43亿较年初持平），减值风险主体后移至鼎味泰/新宏业年末测试。
3. 模块一发现2026Q3收入+11.37%、归母+16.93%、OCF/净利1.52x —— **模块二的解释**：需求端弱复苏（餐饮+2.1%）下安井靠份额提升维持双位数；成本端鱼糜/鱼粉冲击是毛利率同比转负的主因，猪肉低价与费用管控部分对冲。
4. 模块一发现ROE持续下行 —— **模块二补充**：行业资本开支竞赛（产能过剩）是ROE下行的产业层面原因；2026Q3二线扩产延期、亏损扩大，供给纪律改善，行业整合完成后龙头ROE有望回升，但时点取决于鱼糜成本拐点。
