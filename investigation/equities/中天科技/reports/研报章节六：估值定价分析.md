# 研报章节六：估值定价与全变量风险对冲

**研究日期**：2026年08月28日

**参考数据**：当前不复权市价 35.04元，总股本 34.13亿股，总市值 1195.90亿元（2026-08-28）。系统视图显示PE(TTM) 32.13x、扣非PE(TTM) 34.45x、PB 3.11x、PS(TTM) 2.01x、PCF(TTM) 17.70x（实测，TTM OCF 67.55亿；H1单季OCF极低不反映TTM）；近5年PE分位约75%、PB分位约88%。

## 一、价值锚定：适配性方法选择与基准市值

### 1.1 方法选择的商业逻辑

中天科技具备多元制造平台特征：光通信提供2026年最大利润弹性，海洋系列提供2027年成长接力，电网建设提供确定性底仓，铜产品和新能源板块拉低综合利润率。因此估值不能只用单一历史PE机械外推。

| 公司特征 | 估值含义 |
|---------|---------|
| 多元业务结构（光通信+电网+海缆+铜） | **SOTP** 是最适配的交叉验证方法 |
| 盈利拐点已被H1预告验证 | PE估值需基于 **2026E/2027E** 前瞻EPS |
| 重资产+净现金充裕 | **PB** 辅助参考，避免纯成长估值失真 |
| 光纤强周期属性 | 峰值利润必须打折，不能按永续成长给高PE |
| 技术面破位后估值修复 | 当前价格已从5月高点大幅回落，风险收益结构需要重新计算 |

**选择方法组合：PE（主锚）+ PEG（成长校验）+ PB（底线校验）+ SOTP（结构交叉验证）。**

### 1.2 PE估值——历史分位审计与前瞻锚定

系统视图显示，2026年7月30日中天科技PE(TTM)约29.60x（实测）、PB约2.49x，已从6月1日的46.32x明显回落，估值仍高于历史中位数但已显著回落（原报告误载32.57x/2.52x已更正）。

| 指标 | 2026-06-01 | 2026-07-30 | 当前分位判断 |
|------|-----------|------------|-------------|
| 不复权市价 | 27.70元 | **35.04元** | H1兑现后股价上涨26.5% |
| PE(TTM) | 32.57x | **32.13x** | 维持高位，盈利已入TTM部分对冲股价上涨 |
| PB | 2.52x | **3.11x** | 随股价上涨而抬升 |
| 总市值 | 945.39亿 | **1195.90亿** | 重回千亿以上 |

**但历史分位不可机械套用**：2026H1实际归母23.87亿元（+52.29%）落在预告区间内，H1已入TTM分母约一半。TTM已部分反映盈利增量，但全年盈利仍未完全兑现。以小幅下修后2026E EPS 1.52元测算，当前35.04元对应Forward PE约23.1x（此前17.6x）；以悲观情景EPS 1.26元测算约27.8x，安全边际较此前收窄。

**基准PE赋值（按光纤强周期折扣修正）**：

- **2026E EPS = 1.52元（小幅下修）**：
  - 保守 PE = 20x → 30.40元
  - 中性 PE = **24x** → 36.48元
  - 乐观 PE = 28x → 42.56元

- **2027E EPS = 1.93元**：
  - 保守 PE = 18x → 34.74元
  - 中性 PE = 21x → 40.53元
  - 乐观 PE = 25x → 48.25元

**PE锚定结论**：基于2026E中性EPS 1.52元和24倍PE，基准目标价为36.48元（原37.68元），对应市值约1245亿元。24x取值维持两个约束：一是光纤业务按强周期景气兑现期估值，高毛利率不能线性外推；二是H1综合毛利率16.48%验证但低于预期、管理费用与汇兑拖累显示盈利质量仍需跟踪。

### 1.3 PEG估值校验

- 2025→2026E净利润增速：+79.2%（下修后，原84.3%）
- 2026E→2027E净利润增速：+26.9%（原28.0%）
- 两年CAGR：约50.5%

若PEG=0.7-0.8用于强周期制造股简单折扣，合理PE会落在35-40x，但会高估光纤可持续性。更合理做法是利润承认景气兑现、倍数扣除2027-2028产能响应风险。因此PEG仅作为“当前23.1x Forward PE估值重心上移”的校验，不作为目标PE。以24x中性PE计算，2026E PEG约0.30、两年CAGR口径PEG约0.48。

| 每股净资产（元） | 10.99 | ~12.43 |

当前PB 3.11x高于历史中位数，若2026E归母52.0亿元，2026E ROE将提升至约13.0%（原13.4%），仍高于2025年8.0%。以PB-ROE框架看，3.11x已高于此前2.52x，需H2验证毛利率能否向18%修复、应收账款能否企稳与光通信订单交付。

## 五、逻辑证伪与极限压力测试

### 5.1 一击毙命场景

**场景：光纤价格在2026H2-2027快速跌回40-50元/芯公里，同时半年报显示应收账款继续扩张、经营现金流未改善。**

触发路径：
1. AI资本开支预期下修或无人机光纤需求降温，光纤价格从高位回落；
2. 全球龙头扩产和中国供给响应陆续释放，客户交付周期缩短，卖方市场结束；
3. 国内运营商/互联网客户采购节奏延后，MPO项目执行慢于公告周期；
4. 海风项目确认收入慢于预期，海洋板块高毛利率未兑现；
5. H1正式报告显示应收账款/存货继续显著上升，经营现金流仍未改善；
6. 2026E EPS从1.57元下修至1.20元以内，目标PE回到18x。

**黑天鹅目标价：18x × 1.20元 = 21.60元（较当前35.04元下跌约38.4%）。**

### 5.2 极限支撑位审计

更现实的熊市底部应上移至21.6-23.3元区间，因为H1预告已经抬高了2026年盈利底。当前可用三条支撑线交叉：

| 方法 | 计算 | 支撑价 |
|------|------|--------|
| 悲观PE | 18x × 1.20元 | 21.60元 |
| 2026E BVPS | 1.8x × 12.43元 | 22.37元 |
| 技术MA250 | 2026-08-28 MA250后复权251.10，折算不复权约27.78元 | 27.78元 |

**综合极限支撑位：21.6-27.8元区间。** 技术支撑随股价上涨而上移，若跌破21.6元且无基本面利空为极端错杀；若伴随光纤价格与现金流证伪需下调模型。

## 七、模块六核心结论

1. **估值结论由“强周期低位赔率买入”下调至“持有/观望（赔率收窄）”。** 当前不复权市价35.04元，对应2026E Forward PE约23.1x，H1实际兑现但未超预期且股价已上涨26.5%，安全边际大幅收窄。

2. **三态目标价为25.20/36.48/49.84元，概率加权目标价约36.33元。** 当前价格相对中性目标价上行仅4.1%，相对概率加权目标价上行3.6%，赔率较7/30的36.0%/34.3%显著收窄。

3. **盈亏比约0.13:1（加权价框架口径；中性价0.15:1），跌破1:1阈值。** 此前3.99:1的高赔率已因股价上涨与EPS小幅下修而消失，需等待股价回调或基本面超预期再增配。

4. **评级下调至持有/观望。** 基本面仍强但估值已price-in大部分兑现，叠加应收/存货/合同负债质量警示，不再具备积极买入条件。适合持有等待10月三季报验证或股价回落至32元以下再增配。

5. **下一验证线为10月三季报与2027年供给投放。** 10月三季报验证光通信与海洋板块毛利率、应收与合同负债企稳、OCF改善；2027年起重点观察光棒/光纤新增产能（目前已启动400亿级扩产）与交付周期变化。
