## 一、投资摘要

### 1.1 核心投资逻辑

恒铭达是一家以苹果为核心客户（第一大客户占比36.3%）的精密结构件智能制造企业，正处于**"消费电子AI升级周期 × 国产算力基础设施爆发 × 新能源充电桩放量"三重景气共振的临界点**。

**为什么是现在？**

1. **估值已压缩至合理区间底部**：股价从101.81元暴跌43.5%至57.50元，PE TTM从45x+压缩至25.6x（近5年P55分位），Forward PE仅18.2x。对于一个2026年预期利润增速+52%的公司而言，PEG=0.42，显著低估。

2. **利润加速的催化剂正在集聚**：Q1利润+39.9%已初步验证加速趋势；下半年的核心催化剂包括——8月半年报、9月iPhone 17料号图纸（散热方案导入确认）、华阳通惠州基地全面投产。三重催化剂共振将推动市场从"怀疑增速"转向"确认成长"。

3. **第二曲线华阳通处于爆发前夜**：国产AI服务器出货2026年翻倍（12→20-25万台），华为昇腾950超节点+国资委"国模国芯国用"提供强大政策确定性，华阳通作为华为核心一级供应商（2025年获技术突破奖）已锁定天工/天成机柜量产订单。

4. **财务质量远优于同业**：毛利率32%（vs 领益智造15-16%、立讯精密10.5%）、ROE 17%、ROIC 14.4%、经营现金流/净利润1.29x、资产负债率仅29.6%且几乎无有息负债——这是一份非常干净的高质量利润表。

**恒铭达 vs 领益智造：估值错配的逻辑**

| | 恒铭达 | 领益智造 |
|:---|:---:|:---:|
| 2025营收 | 28.6亿 | 514亿（18倍） |
| 毛利率 | 32% | 15-16% |
| PE TTM | 25.6x | 52x（2倍） |
| 商誉/净资产 | 2.4% | 高（34.88亿商誉） |
| 利润增速（2026E） | +52% | +20% |
| 叙事 | 无宏大叙事 | AI硬件平台+机器人+液冷 |
| **PEG** | **0.42** | **2.6** |

**恒铭达用远低于领益智造一半的PE，提供了远高于其两倍以上的利润增速和质量**——市场的"叙事定价"与"基本面定价"之间存在的裂缝，正是超额收益的来源。

## 二、风险因素（按对股价影响烈度排序）

### 🔴 级别一：可改变投资逻辑的核心风险

| # | 风险 | 影响烈度 | 发生概率 | 详细说明 |
|:---:|:---|:---:|:---:|:---|
| **1** | **散热升级方案推迟/未导入** | **极高**（目标价下修至Bear 48.40元） | 中等（30%） | 若iPhone 17未采用石墨+铜箔+纳米晶散热方案，单机ASP从3.3美元回落至2.8美元→柔性件收入增速从+38%降至+20%→2026E NP从8.1亿降至6.5亿→目标价从71元降至~50元。**关键验证节点：2026年9月初Apple新机型图纸。** |
| **2** | **301关税扩围至精密结构件** | **高**（利润率压缩2-5pp） | 中低（20-25%） | 若美国将HTS税号扩围至精密功能件/结构件，额外关税+10-25%将直接侵蚀出口利润。最终影响取决于：①苹果是否承担关税（历史上苹果常要求供应商分担）、②越南产能能否快速承接。 |
| **3** | **Apple大幅加速供应链移出中国** | **极高**（商业逻辑动摇） | 低（<10%一年内） | 若Apple要求核心供应商在18个月内将50%+产能移至印度/越南，恒铭达的CAPEX压力将急剧增大，越南基地当前产能远不足以完全承接。 |

### 🟡 级别二：影响程度中等但需持续监控

| # | 风险 | 影响烈度 | 发生概率 | 详细说明 |
|:---:|:---|:---:|:---:|:---|
| **4** | **惠州基地投产/爬坡不及预期** | **中高**（金属件收入增速从+78%降至+40%） | 中等（25%） | 若设备调试、客户认证或良率爬坡周期长于预期6个月以上，金属件放量推迟至2027年。影响2026E NP约-0.3至-0.5亿。 |
| **5** | **人民币持续大幅升值** | **中等**（境外收入折算损失） | 中低（15%） | 若人民币涨至6.5，境外收入折算减少约0.6亿+汇兑损失约0.3亿，合计影响利润约-0.9亿。但下半年美元走强预期下此风险可控。 |
| **6** | **Apple竞标份额下降** | **中等**（特定料号份额被领益分流） | 中长期持续存在 | 每年1/4/7/9月竞标机制下，若恒铭达在成本竞争中失利，特定料号份额可能从40-70%降至20-30%。**下一次关键竞标：2026年10月底。** |

### 🟢 级别三：值得关注但短期影响有限

| # | 风险 | 影响烈度 | 说明 |
|:---:|:---|:---:|:---|
| **7** | 全球智能手机市场持续低迷 | 中低 | 已被"苹果逆势扩份额"逻辑对冲，但若苹果也出现下滑（目前未见），将是追加风险 |
| **8** | 存储芯片危机延长至2027年后 | 中低 | 延迟换机→消费电子需求恢复延后，但不改变AI升级驱动的结构性趋势 |
| **9** | 华阳通在华为供应链份额被挑战 | 中低 | 当前华阳通技术壁垒（焊接免矫形）较强，短期内新进入者威胁有限 |

## 三、研究结论象限图

基于"确定性"（横轴）与"预期收益空间"（纵轴）的最终定位：

```
                ▲ 高预期收益
                │
    第二象限    │    第一象限 ★
  （黑马/期权）  │  （核心重仓建议）
                │
                │     ★ 恒铭达
                │    (确定性: 中高, 收益: 中高)
                │
   ──────────────┼─────────────────▶ 高确定性
                │
    第四象限    │    第三象限
  （回避/观望）  │  （防御/底仓）
                │
                ▼ 低预期收益
```

**定位：第一象限偏上沿 —— "High-Conviction Buy"**

**确定性评级：中高（4/5）**

| 确定性支撑因子 | 不确定性制约因子 |
|:---|:---|
| Apple逆势扩份额（Q2+15.3%已发生） | 散热方案导入尚未最终确认（9月图纸） |
| Q1利润+39.9%已验证加速趋势 | 惠州基地爬坡存在节奏不确定性 |
| 华阳通获H公司技术突破奖+天工/天成量产 | 301关税风险悬而未决 |
| 充电桩三年倍增政策确定性极高 | 大客户依赖的结构性风险 |

**预期收益空间：中高（+29%概率加权，Bull +78%）**

- 当前Forward PE 18.2x具备安全边际（下行有Bear 48.40元≈-16%），上行空间来自PE从18x→22x的修复（+22%增值）和EPS从3.21→4.09的潜在上修（Bull +27%增值）。
- 若2027E EPS 4.44元兑现+PE恢复至22x，12个月目标价98元（+70%），收益空间显著。
