## 一、投资摘要

### 1.1 核心投资逻辑（2027E目标年份版）

恒铭达是一家以苹果为核心客户（第一大客户占比36.3%）的精密结构件智能制造企业。2026年三季报（10-25披露）对投资逻辑构成**第二次、也是更实质性的修正**——半年报时市场还可以用"汇兑+股份支付一次性扰动"解释利润下滑，三季报则证明这是"增收不增利"的结构性问题：

1. **利润连续两季负增长，I2证伪警报完整触发**：Q2单季归母约-19%、Q3单季0.964亿（-44.46%），连续第二个季度负增长，按跟踪手册I2纪律"清仓至观察仓（<3%）"。前三季度归母3.50亿（-14.20%）、扣非3.33亿（-15.71%）；剔除SBC后Q3仍-14.41%，说明并非一次性费用问题。

2. **Q3营收+14.07%而毛利额零增长，是竞争卡位的财务映射**：Q3毛利率32.74%（同比-4.80pct、环比-2.45pct），环比口径约1.0pct来自低毛利算力件占比提升（18%→约26%）的稀释、约1.4pct来自终端件降价；同比口径结构稀释约2.2pct、终端降价约2.6pct。对照领益拿下iPhone Duo铰链/支撑板/超薄VC、鸿富瀚液冷整柜模组量产（Q3单季净利0.97-1.27亿已超恒铭达全季），**恒铭达在"苹果新料号"与"英伟达液冷"两个最高价值增量上均无公开可验证份额——护城河保护存量，不保护增量定价权。**

3. **"估值便宜"的前提已被推翻**：TTM归母由5.51亿降至4.74亿，PE TTM由21.87x（H1口径）升至25.92x（三季报口径，近5年约P61/近3年约P69，中位偏上），PB 3.62x（Q3权益口径）。股价从47.12跌至48.03的同时估值反而变贵——分子没变、分母塌了。2026E PE约24.5x，高于立讯（20-22x）而利润增速为-6%，估值与成长性错配。

4. **算力第二曲线真实放量，但只能带来收入、带不来利润率**：昇腾950 1024卡液冷超节点10-15点亮、950DT万卡池10-16落地、10-21集群首批交付；公司算力板块Q3收入约2.1亿（同比约+250%，2025Q3低基数）、占比约26%。但该板块毛利率25%低于终端件36%，占比提升本身即稀释综合毛利率——"收入结构优化"与"利润率优化"在当前阶段相互矛盾。

5. **资产质量仍是唯一硬底牌**：货币资金+交易性金融资产22.68亿（占总资产46.4%）、短期借款清零、有息负债仅2.70亿、商誉0.74亿、OCF/归母净利1.81x。这决定了公司不会出现财务危机，但也不构成买入理由。

## 三、研究结论象限图

基于"确定性"（横轴）与"预期收益空间"（纵轴）的最终定位：

```
                 ▲ 高预期收益
                 │
     第二象限    │    第一象限
   （黑马/期权）  │  （核心重仓建议）
                 │
                 │
    ──────────────┼─────────────────▶ 高确定性
                 │
     第四象限 ★   │    第三象限
   （回避/观望）  │  （防御/底仓）
        恒铭达    │
   (确定性: 2.5,  │
    收益: -2.5%)  │
                 ▼ 低预期收益
```

**定位：第四象限 —— "观望/回避"**

**确定性评级：2.5/5（自3.5/5下调）**

| 确定性支撑因子 | 不确定性制约因子 |
|:---|:---|
| 现金+理财22.68亿、短借清零、商誉0.74亿 | I2证伪警报完整触发（连续两季净利负增长） |
| 苹果存量料号份额稳固（口子胶~40%/保护膜~70%） | 增量料号连续两代旁落领益，毛利率同比-4.80pct |
| 算力板块真实放量（Q3收入约+250%、占比~26%） | 算力件毛利率仅25%，规模越大越稀释综合毛利率 |
| 昇腾超节点景气、惠州产能2027H1释放 | 人民币升值+无套保、301豁免两周后到期 |
| 回购3亿完成+期权行权价43.28元 | 2026E PE 24.6x高于立讯而增速为负，估值与成长错配 |

**预期收益空间：负（加权目标价46.8元低于现价48.03元2.5%；中性目标价44.5元低于现价7.4%；下行至Bear 31.6元为-34.2%）**

- 当前Forward PE 19.52x、PE TTM 25.92x（P61/P69），**估值不便宜**；
- 盈亏比-0.07，风险回报结构已反转；
- **移出回避名单**：上述三项条件至少兑现其一；**上调至第三象限**：三项必须齐备（与章节六口径一致）。

## 四、决策树：未来6-12个月的三种路径

| 路径 | 触发条件 | 概率 | 对目标价/评级的含义 |
|:---|:---|:---:|:---|
| **路径A：利空出尽+新料号突破** | 10月底竞标获2027年散热/折叠料号 + Q4毛利率≥33% + 人民币企稳 | 20% | 2027E上修至7.5-8.4亿，目标价回到60-75元，评级上调至第三象限 |
| **路径B：低位磨底、盈利缓慢修复** | 竞标无突破但守住存量 + Q4毛利率32%±0.5pct + 惠州按计划2027H1投产 | 50% | 维持2027E 6.30亿，目标价44.5元，评级"观望" |
| **路径C：竞争失利+盈利二次下修** | 竞标丢失存量料号 + Q4毛利率<31% + 算力被鸿富瀚/领益分流 | 30% | 2027E下修至5.0亿以下，目标价31.6元甚至更低，评级"回避" |

**当前定位**：路径C的概率（30%）与路径A（20%）不对称，且路径C一旦兑现，下行空间（-34%）远大于路径A的上行空间（+57%但需多重条件）。**在赔率不对称且I2已触发的情况下，"不参与"优于"赌反弹"。**

**下一次复核的硬门槛**：2026年报（2027年3月）——若全年归母≥5.0亿、Q4毛利率≥33%、SBC降至1.0亿以内，则路径B成立、可维持"观望"；若全年<4.7亿或Q4毛利率<31%，则确认路径C，需下修至Bear并维持"回避"。
