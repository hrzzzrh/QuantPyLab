## 一、价值锚定：适配性方法选择

### 1.1 商业模式与生命周期匹配的估值工具箱

东方雨虹为“产能+渠道+服务”平台化的消费建材制造商，具备以下估值特征：

- **资产属性**：重资产（总资产 417 亿元，其中固定资产约 80-90 亿元、存货 22 亿元、应收 56 亿元），但非强周期资源属性，PB 具备参考价值。
- **现金流特征**：经营现金流 35.54 亿元（2025）但净利仅 1.13 亿元，OCF/净利润 93.58 倍，盈利质量差但现金尚可，DCF 可作辅助但参数敏感性高。
- **生命周期**：成熟-出清期（渗透率驱动结束，存量博弈+海外增量），增速 8-12%（Base 11.3%），非高成长（PEG 不适用），适用 PE、PB-ROE、PS 三维交叉。

**方法选择与理由**：

1. **PE（市盈率，核心）**：直接锚定盈利修复（2026 Base EPS 0.52 元，+990% YoY），反映困境反转弹性。需注意分母极小导致 PE 失真（TTM 87.78 倍无意义），应采用 Forward PE（2026E）而非 TTM。
2. **PB-ROE（市净率-盈利模型，核心）**：资产厚实（最新净资产 205.38 亿元，2026-06-30，BVPS 8.60 元；年报 201.35 亿元为 2025-12-31 口径，估值统一用最新 205.38 亿元）、ROE 处于历史底部（0.50%），PB 1.38 倍（近 5 年 P25 1.34）已隐含悲观预期，PB-ROE 可捕捉 ROE 从 0.5%→5.87%（2026E，12.32 亿元/205.38 亿元为 6.00%，按 210 亿元预估为 5.87%）的修复弹性。
3. **PS（市销率，辅助）**：收入相对稳定（275.79→307 亿元），PS 0.98 倍（历史平均 2.39 倍）处极低位，可验证 PB/PE 的底分位合理性。
4. **DCF（辅助，压力测试）**：以 OCF 35.54 亿元为基数，但需假设永续增速 2-3% 与 WACC 8-9%，对参数敏感，作极端支撑位审计。

**组合**：PE + PB-ROE 双核心交叉验证，PS 与 DCF 作辅助校验，避免单一 PE 因盈利塌陷而失真。

## 三、确定性与胜率矩阵

### 3.1 三态概率加权（回应审查 B2 压力测试，Base 55%→50% 下调建议部分采纳，维持 55% 但增加敏感性说明）

基于盈利预测确定性 3.0/5（中等）与外部调节 +2% 的审慎性，主观赋予（B2 提示 Q2 失速 +0.83% 压力，Base 55% 已含该风险，若 Q3 <74.5 亿元则下调至 50%）：

- 保守 Bear 25%（提价失败+成本高企+新建超预期下滑）
- 中性 Base 55%（提价 60-70%+修缮 18%+海外 80%，含 Q2 失速风险溢价）
- 乐观 Bull 20%（提价 80%+ + 修缮 25%+原油回落）

∑P = 100%。

### 3.2 最终目标价合成

- 保守目标价 = 82 / 23.887 = **3.43 元**
- 中性目标价（调节后） = 347 / 23.887 = **14.53 元**（未调节 14.23 元）
- 乐观目标价 = 500 / 23.887 = **20.93 元**

**加权目标价** = 0.25×3.43 + 0.55×14.53 + 0.20×20.93 = 0.8575 + 7.9915 + 4.186 = **13.04 元**（期望收益口径）。

**现价 11.86 元 vs 加权 13.04 元，隐含上行 +9.95%**（未扣除交易成本）。

### 3.3 盈亏比计算（强制性）

盈亏比 = (加权目标价 - 现价) / (现价 - 保守场景价格) = (13.04 - 11.86) / (11.86 - 3.43) = 1.18 / 8.43 = **0.14**。

**解读**：盈亏比 0.14 远低于 1.0 门槛（理想 >1.5），显示期望收益（+9.95%）不能覆盖下行风险（-71.1% 至保守价），风险收益比差。主因保守情景 3.43 元的极端下行（PB 0.90×）拉大分母，而加权目标价 13.04 元的上行仅 +9.95%，安全边际不足。

**口径规范**：当现价 < 保守价时盈亏比为 ∞+，但当前 11.86 > 3.43，故直接计算。若用 PB-ROE 保守情景（如 PB 0.70× 对应 147 亿元/6.15 元）代入分母，将得到 0.20 的虚高盈亏比，属“估值下限制造”，按框架严禁（仅作极端提示：若核心逻辑失效，PB 0.70× 下仍有 -48% 下行）。

## 四、逻辑证伪与极限压力测试

### 4.1 黑天鹅场景模拟（一击毙命）

**事件**：核心产品被颠覆性替代 + 主要大客户流失 + 海外地缘市场关闭三重叠加。

- **产品颠覆**：高分子自粘胶膜、TPO 等被新型“自修复”或“零防水”建材（如 3D 打印建筑一体化防水）替代，东方雨虹 191.72 亿元防水材料（69.52%）面临技术性淘汰（概率 <1%，5 年内）；
- **大客户流失**：前五大客户（万科、保利、中建等，合计约 15-20% 收入）因质量事故或价格战集体转单至科顺/北新建材，收入 -15-20%、毛利率 -2pp（概率 5-10%）；
- **地缘关闭**：美国 25% 关税 + 欧盟 CBAM + 霍尔木兹封锁致沥青断供，海外 30 亿元收入归零 + 原材料成本 +50%（概率 3-5%）。

**综合黑天鹅概率约 1-2%**，虽小但足以推翻“盈利修复+估值回归”逻辑，触发 Bear 情景且可能跌至 PB 0.70×（147 亿元/6.15 元）下方。

### 4.2 极限支撑位审计（地狱价格，回应审查 B5 倒挂澄清）

在黑天鹅下，股价最坏锚点为 **重资产清算价值或净现金价值**：

- **清算价值**：最新净资产 205.38 亿元（2026-06-30，统一口径回应 B7），扣除商誉（约 5-10 亿元）、存货跌价（约 5 亿元）、应收坏账（约 10-15 亿元），可变现净资产约 170-180 亿元，对应每股 7.12-7.54 元（PB 0.83-0.88×205.38 亿元）；**按 PB 0.70×205.38 亿元计为 143.77 亿元/6.02 元，为极端清算底（原 6.15 元基于 201.35 亿元，现修正为 6.02 元）**，为“地狱价格”中枢。
- **净现金价值**：货币资金 39.10 亿元 + 交易性金融资产 5.36 亿元 - 有息负债约 65 亿元 = -20.54 亿元（净现金为负），无支撑意义。

**极限支撑位约 6.02-7.54 元（PB 0.70-0.88×205.38 亿元，修正原 6.15-7.54）**，较现价 -36%至-49%，为风险管理的终极锚点（止损参考 7.50 元）。**注：保守情景 3.43 元（82 亿元/PB 0.40×）为极端盈利失效价（EPS 0.218 持续底部，按 PE 15× 定价），低于清算地狱价 6.02 元，二者不具可比性——保守价衡量盈利持续恶化的股权价值，清算价衡量资产变现价值，不可直接比较倒挂；盈亏比分母用 3.43 元（盈利底）而非 6.02 元（资产底）符合框架“分母必须用未调节保守价（盈利情景）”的强制要求，详见 §3.3 口径规范。**



---

**估值结论**：东方雨虹当前 11.86 元已隐含“困境底部”预期（PB 1.38 倍近 P25），但盈利修复的弹性（EPS 0.05→0.52）与估值修复（PB 1.38→1.85）的双重贡献，仅带来 +9.95% 的加权上行与 0.14 的极低盈亏比，安全边际不足。估值的核心矛盾在于“盈利修复的确定性（3.0/5）”与“下行风险的极端性（保守 3.43 元，-71%）”的不对称，需等待更优价格（9-10 元，盈亏比 >0.5）或更强催化（Q3 提价落地超预期 + 修缮放量）再介入。
