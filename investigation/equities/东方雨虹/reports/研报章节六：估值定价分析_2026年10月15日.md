## 一、价值锚定：适配性方法选择

### 1.1 商业模式与生命周期匹配的估值工具箱

东方雨虹为"产能+渠道+服务"平台化的消费建材制造商，具备以下估值特征：

- **资产属性**：重资产（总资产 431.97 亿元，其中固定资产约 80-90 亿元、存货 22 亿元、应收 75 亿元），但非强周期资源属性，PB 具备参考价值。
- **现金流特征**：经营现金流 36.10 亿元（2026-06-30 TTM）但净利仅 1.62 亿元（TTM），盈利质量差但现金尚可，DCF 可作辅助但参数敏感性高。
- **生命周期**：成熟-出清期（渗透率驱动结束，存量博弈+海外增量），增速 5-12%（Base 5.9%），非高成长（PEG 不适用），适用 PE、PB-ROE、PS 三维交叉。

**方法选择与理由**：

1. **PE（市盈率，核心）**：直接锚定盈利正常化（2027 Base EPS 0.70 元，+35.4% YoY vs 2026E 12.32 亿元），反映困境反转后的估值回归。需注意 2026E 分母极小导致 PE 失真（TTM 157.86 倍无意义），应采用 Forward PE（2027E）而非 TTM。
2. **PB-ROE（市净率-盈利模型，核心）**：资产厚实（最新净资产 205.38 亿元，2026-06-30，BVPS 8.60 元）、ROE 处于修复通道（2026E 6.00%→2027E 8.8%），PB 1.25 倍（近 5 年 P25 1.37）已隐含悲观预期，PB-ROE 可捕捉 ROE 从 6.0%→8.8% 的修复弹性。
3. **PS（市销率，辅助）**：收入相对稳定（307→325 亿元），PS 0.83 倍（历史平均 2.39 倍）处极低位，可验证 PB/PE 的底分位合理性。
4. **DCF（辅助，压力测试）**：以 OCF 36.10 亿元为基数，但需假设永续增速 2-3% 与 WACC 8-9%，对参数敏感，作极端支撑位审计。

**组合**：PE + PB-ROE 双核心交叉验证，PS 与 DCF 作辅助校验，避免单一 PE 因盈利塌陷而失真。

- **PB 底部确认**：1.25 倍接近 P25 1.37，2020 年 PB 曾达 14.61 倍（高点），2021 年 5.06 倍（P75），当前 PB 已 price in 了"盈利底部 + 现金紧张 + 减值高企"的三重悲观，与 2025 年 ROE 0.50% 的极低水平匹配。
- **PS 极低验证**：0.89 倍为历史 15% 分位，低于 2021 年均值 2.39 倍，反映市场按"销量"而非"利润"给周期底部定价，与销量 +19.58% 的份额提升形成背离，存在修复空间。

**谨慎性**：A 股建材板块在 2021-2022 年曾出现估值极端（PB 0.86 倍），历史分位的参考意义需打折，不可简单均值回归，需结合 ROE 修复的实质。

## 三、确定性与胜率矩阵

### 3.1 三态概率加权

基于 2027E 盈利预测确定性 3.33/5（中等偏上，较 2026E 的 3.0/5 上调 0.33 分）与外部调节 +2% 的审慎性，主观赋予：

- 保守 Bear 22%（从 25% 下调，2027 年出清进入尾声+政策托底，价格战回吐+沥青 6000++ 新建 -15% 超预期）
- 中性 Base 58%（从 55% 上调，提价已落地 4/5+减值路径清晰 3/5，含 Q3 验证后兑现概率）
- 乐观 Bull 20%（维持，价格企稳+修缮 +25%+沥青回落）

∑P = 100%。

### 3.2 最终目标价合成

- 保守目标价 = 75 / 23.887 = **3.14 元**
- 中性目标价（调节后） = 372 / 23.887 = **15.57 元**（四舍五入取整，未调节 15.28 元）
- 乐观目标价 = 580 / 23.887 = **24.28 元**

**加权目标价** = 0.22×3.14 + 0.58×15.57 + 0.20×24.28 = 0.691 + 9.031 + 4.856 = **14.58 元**（期望收益口径）。

**现价 10.72 元 vs 加权 14.58 元，隐含上行 +36.0%**（未扣除交易成本）。

### 3.3 盈亏比计算（强制性）

盈亏比 = (加权目标价 - 现价) / (现价 - 保守场景价格) = (14.58 - 10.72) / (10.72 - 3.14) = 3.86 / 7.58 = **0.51**。

**解读**：盈亏比 0.51 仍低于 1.0 门槛（理想 >1.5），但较 2026E 的 0.33 显著改善（+54.5%），主因 2027E 盈利正常化后保守价从 3.43 略降至 3.14（Bear 归母 5.0 vs 5.2 略降）、中性/乐观目标价大幅上移（15.57/24.28 vs 14.53/20.93）。期望收益（+36.0%）仍不能充分覆盖下行风险（-70.9% 至保守价 3.14 元，(10.72-3.14)/10.72=70.9%），但安全边际较 2026E 明显改善。

**口径规范**：当现价 < 保守价时盈亏比为 ∞+，但当前 10.72 > 3.14，故直接计算。若用 PB-ROE 保守情景（如 PB 0.70× 对应 144 亿元/6.02 元）代入分母，将得到 0.35 的虚低盈亏比，属"估值下限制造"，按框架严禁（仅作极端提示：若核心逻辑失效，PB 0.70× 下仍有 -45% 下行）。

## 四、逻辑证伪与极限压力测试

### 4.1 黑天鹅场景模拟（一击毙命）

**事件**：核心产品被颠覆性替代 + 主要大客户流失 + 海外地缘市场关闭三重叠加。

- **产品颠覆**：高分子自粘胶膜、TPO 等被新型"自修复"或"零防水"建材（如 3D 打印建筑一体化防水）替代，东方雨虹 191.72 亿元防水材料（69.52%）面临技术性淘汰（概率 <1%，5 年内）；
- **大客户流失**：前五大客户（万科、保利、中建等，合计约 15-20% 收入）因质量事故或价格战集体转单至科顺/北新建材，收入 -15-20%、毛利率 -2pp（概率 5-10%）；
- **地缘关闭**：美国 25% 关税 + 欧盟 CBAM + 霍尔木兹封锁致沥青断供，海外 40 亿元收入归零 + 原材料成本 +50%（概率 3-5%）。

**综合黑天鹅概率约 1-2%**，虽小但足以推翻"盈利正常化+估值回归"逻辑，触发 Bear 情景且可能跌至 PB 0.70×（144 亿元/6.02 元）下方。

### 4.2 极限支撑位审计（地狱价格）

在黑天鹅下，股价最坏锚点为 **重资产清算价值或净现金价值**：

- **清算价值**：最新净资产 205.38 亿元（2026-06-30），扣除商誉（约 5-10 亿元）、存货跌价（约 5 亿元）、应收坏账（约 10-15 亿元），可变现净资产约 170-180 亿元，对应每股 7.12-7.54 元（PB 0.83-0.88×205.38 亿元）；**按 PB 0.70×205.38 亿元计为 143.77 亿元/6.02 元，为极端清算底**，为"地狱价格"中枢。
- **净现金价值**：货币资金 41.83 亿元 + 交易性金融资产 5.36 亿元 - 有息负债约 84 亿元 = -36.81 亿元（净现金为负），无支撑意义。

**极限支撑位约 6.02-7.54 元（PB 0.70-0.88×205.38 亿元）**，较现价 -35%至-44%，为风险管理的终极锚点（止损参考 7.50 元）。**注：保守情景 3.14 元（75 亿元/PB 0.37×）为极端盈利失效价（EPS 0.164 持续底部，按 PE 15× 定价），低于清算地狱价 6.02 元，二者不具可比性——保守价衡量盈利持续恶化的股权价值，清算价衡量资产变现价值，不可直接比较倒挂；盈亏比分母用 3.14 元（盈利底）而非 6.02 元（资产底）符合框架"分母必须用未调节保守价（盈利情景）"的强制要求，详见 §3.3 口径规范。**

**估值结论**：东方雨虹当前 10.72 元（10-14）已隐含"困境底部"预期（PB 1.25 倍低于 P25 1.37），2027E 盈利正常化（EPS 0.52→0.70，+35.4%）与估值修复（PB 1.25→1.81）的双重贡献，带来 +36.0% 的加权上行与 0.51 的盈亏比较 2026E（+22.2%/0.33）显著改善。但期望收益仍不能充分覆盖下行风险（-70.9% 至 3.14 元），安全边际改善但仍不足。估值的核心矛盾从 2026E 的"盈利修复确定性（3.0/5）与下行风险极端性（-71%）的不对称"，转为 2027E 的"盈利正常化（3.33/5）与保守价下行空间收窄（-70.9%）的再平衡"，盈亏比 0.51 仍低于 1.0 门槛，需等待更优价格（9-10 元，盈亏比 >0.7）或更强催化（Q3 提价落地超预期+修缮放量+沥青回落）再介入。
