## 一、价值锚定：适配性估值方法选择

### 1.1 方法论筛选逻辑

公司的核心属性决定了估值方法的选择：

| 公司属性 | 对估值方法选择的影响 |
|:---|:---|

### 1.2 估值锚点规则

当前为2026年10月（Q4），根据框架「估值锚点切换：Q4自动滚算至次年」条款，估值锚定为 **2027年全年预测EPS**（2026E保留为对照口径，不再作为定价锚）。

**切换依据**：① 框架模块零第5条「切换期(Q4)：目标时间点为次年」；② 模块六「估值锚点切换：当年(Q1-Q3)锚定当年EPS/BVPS，切换期(Q4)自动滚算至次年数据」；③ 2026年为运力约束下的"过渡年"（归母+4.2%），以2026E定价会使估值丧失前瞻性；④ 卖方（摩根大通、花旗）与公司管理层口径均已转向2027年（"盈利将于2027年反弹"、"2027年上半年欧洲新订单恢复"）。

### 2.1 历史PE分位的参考与扬弃

| **当前（10/15）** | **22.59x（TTM）** | **低于5年P5（23.55x）——处于5年序列的最低位区间** |

**PB分位（同期）**：P5 1.85x / P10 2.01x / P25 2.75x / P50 4.86x / P75 7.49x / P95 10.48x；**当前 PB 1.81x 亦低于5年P5**。PE与PB同时跌破5年P5，为本轮周期中的极端读数。

**历史分位的缺陷与扬弃**：过去5年PE样本中前3年（2021-2023）为国内低毛利结构（15-23%），当前出口占比82.25%、出口毛利率39.36%（H1）远超历史。**22.59x（TTM）低于P5，但2027E Forward PE仅13.8x（35.32/2.57）——历史分位参考价值有限，估值处于"过渡年向弹性年切换"的极端折价状态。**

### 2.2 2027E 三态情景PE的确定

采用"三维交叉法"确定大金重工的合理PE中枢：

| 定价维度 | 参考值 | 对大金的适用性 |
|:---|:---:|:---|
| A股风电设备行业中位数 | ~25x（含大量纯内需低毛利整机/零部件企业） | 偏低——大金的海外高毛利结构显著优于行业 |
| 大金自身5年历史中位数 | ~36x | 上限参考——反映市场对公司转型的认可，但含2021-2023低毛利失真 |
| 可比海外同业（Sif/EEW/Steelwind） | 30-35x Forward PE | 上限参考——Sif正处于现金告急+指引下调，PE失真 |
| **当前股价隐含（35.32元，2027E Base EPS 2.57元）** | **~13.8x** | 🟢 **处于极端折价区** |
| **H股隐含（约22.90港元≈19.6元，2027E Base EPS）** | **~7.6x** | 🔴 A-H折价约44%，构成A股估值中枢的向下牵引 |
| 花旗（2026-10-12）/摩根大通（2026-09-23）H股目标价 | 43港元（≈37.4元人民币） | 外部机构在H股暴跌后仍给出约+72%的上行空间 |

**2027E 三态情景PE设定：保守 14x / 中性 19x / 乐观 23x**

- **下限14x（保守）**：假设欧盟2027-06-30"下游产品审查"实质纳入单桩 + EUR/CNY跌破7.4 + 运力二次卡口，估值回到当前市场已定价的水平（13.8x），并无额外溢价
- **中枢19x（中性）**：较2026E口径的基准中枢27x下调8个点，理由有三：① **板块估值消化**——2026年风电板块回调中PE贡献-37.1%、EPS贡献+10.9%，市场从"博弈政策"转向"博弈业绩"；② **A-H折价44%的结构性牵引**（H股隐含7.6x）；③ **贸易政策尾部风险溢价**（2027-06-30窗口）。19x 仍显著低于5年P25（30.12x）与自身历史中位数（36x），亦低于A股风电设备行业中位数（25x），具备"海外基建化重估"的风险缓冲
- **上限23x（乐观）**：假设贸易风险缓解 + 欧洲2027年订单集中释放 + 造船/安装兑现 + 市场风格回摆，PE修复至接近5年P5-P10（23.55-26.13x）的下沿

**锚点回测（框架强制项）**：中性19x（经审计调节后隐含18.2x）低于5年P25（30.12x）约40%，低于2026E口径修正PE（25.7x）约29%。支撑逻辑：① **A-H折价44%使A股存在向下收敛的牵引**，19x已属"审慎中性"而非乐观；② 贸易政策尾部风险为真实的中枢折价因子（非短期情绪）；③ PEG维度上，19x对应2027E增速+65% → PEG 0.29，即便给予保守的+40%增速假设，PEG亦仅0.48，深度低于1.0低估线。**结论：19x在"过渡年→弹性年"切换期属于审慎锚定，合理性验证通过。**

## 三、PB-ROE模型（交叉验证）

### 3.1 大金重工ROE预测

| 指标 | 2024A | 2025A | 2026E Base | **2027E Base** |
|:---|:---:|:---:|:---:|:---:|
| ROE（加权）| 6.68% | 14.18% | **~8.0%** | **~12.5%** |
| 每股净资产（元，摊薄后）| 11.40 | 12.98 | **~20.5** | **~23.0** |
| 归母净利润（亿）| 4.74 | 11.03 | **11.49** | **19.0** |
| 净资产（亿，集团归母口径，含H股募资）| 72.72 | 82.80 | **~152** | **~170** |

注：2026E 净资产约152亿（H1末144.37亿 + H2利润约5.5亿 + 其他综合收益），ROE 8.0%；2027E 净资产约170亿（152 + 19.0 - 分红约1.3亿），加权平均约163亿，ROE约12.5%。**H股募资约60亿人民币使净资产基数系统性抬升，是ROE被摊薄的核心原因**——该笔资金尚未完全投产（欧洲总装基地、全球研发中心），未来3年随产能投放ROE将逐步回归。

### 3.2 PB-ROE合理性检验

以12.5%的ROE和10%的权益成本（r），零增长假设下：`合理PB = ROE/r = 1.25x`；3%永续增长假设下：`合理PB = (12.5%-3%)/(10%-3%) = 1.36x`。

**当前 PB 1.81x（10/15，系统口径，净资产144.37亿）**——高于PB-ROE理论区间（1.25-1.36x）约33-45%。对应PB-ROE隐含股价约 **28.8-31.3元**（1.25-1.36x × 2027E BVPS 23.0元）。

**PB-ROE 与 PE 的显著背离（28.8-31.3元 vs 46.8元）需审慎解释**：PB-ROE 的低读数主要源于 **H股募资约60亿现金尚未投产形成的ROE稀释**（净资产从82.8亿跃升至144.4亿，而利润尚未同步放大）。若以2026H1实际年化ROE（约15-16%）或以2028E ROE（预计15%+，净资产170-190亿口径）计算，理论PB将升至1.5-1.9x。**结论：PB-ROE在过渡期对公司的估值支撑弱于PE法，但28.8-31.3元的理论值构成"若现金始终未投产"的下限参照；PE法（46.8元）为决策锚。**

## 四、PEG校验（2027E口径）

| 情景 | 2027E净利增速 | 2027E PE（现价35.32元） | PEG | 2027E PE（目标价） | PEG（目标价口径） |
|:---|:---:|:---:|:---:|:---:|:---:|
| 保守（Bear） | +44.0% | 20.1x | 0.46 | 14.0x | 0.32 |
| **中性（Base）** | **+65.4%** | **13.8x** | **0.21** | **18.2x** | **0.28** |
| 乐观（Bull） | +72.4% | 10.4x | 0.14 | 23.0x | 0.32 |

**PEG校验结论**：2027E Base PEG 0.21（现价口径）/ 0.28（目标价口径），**深度低于1.0低估线**。即便将增速假设保守压缩至+40%（贸易壁垒实质化情形），PEG亦仅约0.46。2026E口径下PEG曾因增速收敛至+4.2%而"失真"（6.0）；**2027E 增速恢复至+65%后 PEG 工具重新有效，且指向显著低估**。PEG法支持 PE 法给出的19x中枢（甚至暗示更高的中枢），不构成对目标价的制约。

## 六、全变量对冲审计矩阵（强制性输出——2027E口径重构）

基于 **2027E Base 情景市值 361亿（PE 19x × 19.0亿归母净利）** 为"底色"，进行估值影响力过滤和调节。

### 6.1 估值影响力过滤——审慎思考

**剔除的"伪因子"（影响估值=0）：**
- H1出口毛利率39.36%创新高 → 已在E中体现
- 合同负债21.57亿（+34.07%） → 已在E的营收假设中体现
- KING系列三船交付、KING THREE首航 → 已在E的量（运力）假设中体现
- 十五五海风1亿千瓦、《风能北京宣言2.0》 → 行业性总量利好，不构成公司差异化溢价
- 9/15、9/30、10/12等单日板块异动 → 资金博弈，不改变估值中枢
- 中期分红0.88元/10股 → 已在净资产/现金流中体现
- 造船120亿订单绝对规模 → 已通过2027E确收18亿与SOTP期权价值30-40亿体现，不重复计价

**真正能改变估值中枢的因子（2027E重新审理）：**

| 因子类别 | 能否改变PE？| 审理逻辑 |
|:---|:---|:---|
| **贸易政策尾部风险（2027-06-30"下游产品审查"）** | **可以（核心折价）** | 立法原文明确"assess whether it should cover additional products...including with priority downstream iron and steel products"，单桩/导管架在审查范围内；2027H2为最可能窗口（概率35-45%）。这是2027E最大的中枢级折价因子 |
| **EUR/CNY 由8月7.85跌至10-15中间价7.5068（1年低点7.4679）** | **可以（折价）** | 人民币升值对欧元计价收入与汇兑损益形成双重压力；市场会将其视为盈利质量与远期人民币盈利的折价因子（不可计算的信心与不确定性 → 进PE） |
| **A-H折价扩大至约44%（H股约22.90港元≈19.6元）** | **可以（折价）** | H股作为国际投资者定价的窗口，隐含2027E PE仅约7.6x；13家国际基石（GIC/高瓴/UBS AM等）深度浮亏；A-H联动在7月与10月两次验证为下行加速器 |
| **"制造+运输+母港+安装"全链条闭环（KING三船+4处母港+Ulstein安装船）** | **可以（溢价）** | 全球海工基础制造商中独此一家；欧洲满足下一代风机安装的船仅约19艘，安装环节壁垒极高；从"装备制造商"向"全球深远海风电综合服务商"的稀缺性溢价 |

| **国内政策对齐（十五五海风1亿千瓦+德国WindSeeG 2027-01-01生效）** | **可以（弱溢价）** | 十五五为国家级总量目标，非公司差异化；但德国改革+英国AR8+法国AO10对"亚太唯一规模化欧洲出口商"的份额溢价有实质支撑 |
