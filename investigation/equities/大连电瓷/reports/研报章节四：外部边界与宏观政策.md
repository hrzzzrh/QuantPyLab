# 研报章节四：外部边界与宏观政策

**研究日期**：2026年08月16日

---

## 前序模块核心结论继承

模块一发现：海外收入占比23.56%、毛利率高于国内，但客户集中度高
模块二发现：十五五4万亿确定性极强，全球电网投资共振
模块三发现：公司在特高压领域护城河极深，但对国网议价能力弱

本章需评估：宏观变量（汇率、通胀）如何冲击盈利？地缘冲突如何影响海外战略？政策环境边际变化方向？

## 一、宏观环境变量

### 1.1 人民币汇率：升值趋势暂歇，但方向仍需观察

**当前汇率环境**：
- 2025年4月以来，人民币兑美元从7.35附近持续升值，至2026年6月底在6.79附近企稳，7月2日中间价6.8088
- 美元/离岸人民币（CNH）近期在6.78-6.81区间窄幅波动，大华银行判断原上升趋势已转为盘整
- 在岸人民币受央行中间价引导，波动相对克制

**对大连电瓷的传导分析**：

公司2025年海外收入4.19亿元，主要以美元报价和结算。年报明确将"汇率变动风险"列为经营风险之一。

**定量估算**：
- 假设海外收入中70%以美元结算（~2.93亿元）
- 当前汇率6.80与6月9日的6.82基本持平，近期汇率波动对2026Q2利润影响不大
- 人民币自7.35高位升值至6.80（累计7.5%），若全部发生在2026H1结算期，折算损失约2,200万元
- 占2025年归母净利润2.12亿元的约10.4%
- **影响可控但不可忽视**：2026Q1财务费用已从23万元飙升至877万元（+3568%），包含汇兑因素

**核心判断**：汇率风险对大连电瓷属中等影响，原因如下：
1. 海外收入占比约24%，低于纯出口型企业
2. 公司正推进海外本地化生产（沙特建厂），将形成"收入成本同币种"的自然对冲
3. 6月底以来人民币升势暂缓并进入盘整，为2026H2的海外利润结算提供了一些喘息窗口
4. **积极面**：人民币升值降低了公司进口原材料的成本（氧化铝等以美元计价的大宗商品），存在一定自然对冲

**2026年8月16日跟踪更新**：USD/CNY 8月上旬维持6.78-6.81窄幅盘整，8月14日中间价6.7878，较7月下旬（6.77附近）小幅走弱但仍在同一箱体内。汇率维持"非核心解释变量"判断：H1预告显示海外实际交付和产品结构改善已足以覆盖汇兑压力。H2风险仍在于人民币若跌破6.70并持续升值，海外利润折算会再次成为利润表扰动项。

### 1.2 利率与折现率：估值锚定影响

- 当前中国10年期国债收益率约2.7%，处于历史低位
- 美联储因中东战事推高通胀，降息预期推迟至2027年
- 低利率环境有利于DCF估值，但无风险利率下行空间已有限

**对估值的影响**：中性偏正面。低利率支撑成长股估值，但PE中枢的进一步抬升需要盈利增速配合。

### 1.3 通胀与成本传导

**原油/天然气价格**：
- 布伦特原油8月14日收于88.52美元/桶（周涨6.0%），较7月初高位（93-96美元/桶）有所回落但仍在高位（同比+34%）；战前约70美元
- EIA假设霍尔木兹海峡原油流量整个8月仍受明显限制、9月起逐步恢复，对应Q3均价约85美元/桶、Q4回落至78美元/桶附近；高盛判断美伊协议达成或冲突升级前布伦特维持80-90美元区间
- 8月上旬霍尔木兹日通行量仅5-12艘（战前130+艘），8月14日进一步降至2艘且无原油船（来源：汇通财经引述船舶追踪数据，未经权威来源交叉验证；AIS关闭可能造成低估，美国能源部长口径称海峡原油流量已回升至约900万桶/日），部分油轮关闭应答器规避监测，实际流量仍接近停滞；7月海湾产油国原油及凝析油出口约1,070万桶/日，较战前低约40%
- 天然气价格同步高企，直接推升公司燃料成本（天然气占悬瓷成本11.4%）
- 船用燃油成本与海运费仍处高位：公司8月3日互动易口径"受中东地缘局势影响，区域航运存在阶段性扰动，航运成本进一步提升"

**成本传导效率**：
- 年报已披露：2025年财务费用大幅增加，"利息费用增加及汇兑收益减少"
- 年报"中东战争风险"部分明确："全球油价上涨，预计未来海运成本会有所增加，库存商品短时间会增加"
- 公司通过光伏绿电（自发自用35-80%）部分对冲能源成本

## 二、地缘政治风险

### 2.1 美以-伊朗战争：伊阿航道协议达成，但海峡重开仍取决于美方条件

**冲突与谈判最新进展**（截至2026年8月16日）：
- **6月17日**：美伊在瑞士签署临时谅解备忘录，伊朗同意60天期限内允许船只免费通行霍尔木兹海峡
- **6月25-27日**：冲突短暂再起——油轮遭袭击、美军空袭伊朗军事设施、伊朗反击，但规模有限。双方紧急同意暂停军事行动
- **6月30日-7月1日**：美伊在多哈举行技术性会谈，讨论海峡航运秩序与伊朗财政激励；6月备忘录签署数日后即因对等袭击再度破裂
- **7月12日**：美军重启对伊朗空袭后，**伊朗宣布关闭霍尔木兹海峡**；美方单方面称靠近阿曼的南部航道仍可通行，但未获伊朗认可，实际安全风险高企（该关闭状态持续至8月中旬，与6月临时备忘录后的短暂重开形成反复）
- **8月5日**：伊朗外交部发言人巴加埃宣布，伊朗与阿曼已就霍尔木兹海峡拟定航道地理坐标达成一致，两国联合声明进入终审阶段（新华社）
- **8月6日**：伊朗国会委员会开始审议法案，考虑禁止美国、以色列及其他被视作敌对国家的船舶通过霍尔木兹海峡
- **8月8日**：阿联酋指控伊朗导弹袭击其国有石油公司ADNOC旗下油轮；英国UKMTO报告阿曼海岸附近一艘船被"不明炮火"击中
- **8月9日**：伊朗外长阿拉格奇称伊阿协议进入"最后阶段"，但重申海峡重开"取决于美国必须满足的其他条件"；阿曼称谈判积极（路透/BBC）
- **8月14日**：特朗普扬言"在我们彻底击败伊朗后，很快会宣布霍尔木兹海峡为美国领土"；美方证实维持对伊朗海上封锁并继续"航母接力"（林肯号→乔治·华盛顿号）；财政部长贝森特称将对伊朗实施"前所未有的经济措施"
- **8月15日**：伊朗宣布与阿曼就霍尔木兹海峡航道通行方案达成协议（央视新闻/新华社/AA/路透多源确认）。新通行模式要点：关闭现有北部（伊朗领海）与南部（阿曼领海）两条临时航道，商业船舶进入及驶离海峡的部分航程改经**伊朗领海**；新航道为**临时性质，预计可使用2-4个月**；协议细节（通行费安排等）尚待公布，有消息称可能涉及60天免费通航期与事后收费（伊朗此前索要货物价值5-7%过境费、阿曼讨论约3%、美方要求零收费），一名美国官员称任何临时航道不会对过往船只收费

**关键研判：协议≠海峡重开，风险从"临界升级"转为"长期僵持"（边际改善但未解除）**：
- 伊朗官方明确：与阿曼的协议**不会自动转化为海峡重新开放**。完全恢复通行取决于美国满足伊朗列出的六项条件——停止威胁、停止对伊朗及其盟友的战争、解除海上封锁并撤出部队、赔偿战争损失、解除制裁、释放被冻结资产（据BBC中文8月10日引述伊朗最高领袖顾问佐勒加德尔声明，伊朗官方IRIB播发；部分媒体口径为五项条件，系合并表述差异）
- 伊朗外长阿拉格奇（8月15日）："与阿曼的协议不会转化为海峡的重新开放，这是另一个问题"
- 美方未参与伊阿谈判，且持续以海上封锁（航母接力）、经济施压（财长表态）、主权宣言（特朗普言论）多线施压；伊朗以"海峡主权仅归伊朗"强硬回应——美伊直接谈判尚无重启时间表（卡塔尔/巴基斯坦担任传话人，伊朗明确"未决定恢复与美谈判"）
- 实际航运恢复极为缓慢：8月14日仅2艘船只通过海峡（战前130+艘/日），油轮遇袭事件仍频发（8月8日ADNOC油轮、UKMTO船只被击中），保险与通行安全风险未实质下降
- **与7月28日锚点的对比**：当时核心不确定性是"8月中旬60天免费通行到期后征收通行费vs冲突再升级"；当前该节点已平稳度过——既未出现大规模冲突升级，也未被伊朗单方面收费方案锁定，而是进入"伊阿技术性协议推进＋美伊政治条件僵持"的轨道。**尾部风险概率（冲突再度大幅升级）下降，但全面通航/成本回落均未实现，航运风险等级从"高"下调至"中高"**

**对公司沙特业务的考量更新**：
| 影响维度 | 7月28日评估 | 8月16日更新 |
| :--- | :--- | :--- |
| 沙特订单交付 | 交付修复已验证，H1存量订单有序交付 | 公司8月3日互动易确认：沙特在手订单履约整体平稳，未发生交付延期及合同违约；已与建设方、电力客户密切沟通并调整海运线路与物流方案 |
| 海运成本 | 仍居高但涨幅企稳 | 公司口径"航运成本进一步提升"（8月3日）；海峡通行量接近停滞，保险与绕行成本高企，短期无回落信号 |
| 中东新增订单 | 战后重建逻辑未变 | 地缘冲突尚未对当地项目招标及后续市场拓展产生实质性影响（公司8月3日口径）；沙特组装工厂项目稳步推进（7月29日互动易） |
| 地缘风险评级 | 8月中旬关键节点（征收通行费vs冲突再升级） | 8月15日伊阿航道协议达成，冲突升级尾部风险下降；但美方六项条件博弈、航母封锁、伊朗国会"禁美以船只"法案审议、油轮遇袭均提示风险未解除——评级从"高"下调至"中高" |

**辩证视角（维持）**：
- **短期利空（边际缓解）**：交付不确定性仍在但公司确认履约平稳；海运成本持续高企，尚未见回落
- **中长期利好**：高油价→中东国家财政充裕→电网投资加速→绝缘子需求增长。沙特"2030愿景"电网投资计划庞大，战后重建将释放更大需求；公司作为沙特最核心瓷绝缘子供应商且正推进本地化组装，长期受益逻辑未变
- **竞争格局优化**：中小出口商因运费/保险成本激增而退出，有利于龙头集中份额

**2026年8月16日再审计**：公司H1预告称"中东区域地缘冲突的影响逐步消退，该区域市场需求持续修复，公司存量订单实现有序交付"；8月3日互动易进一步确认沙特履约平稳、未发生违约，且"地缘冲突尚未对当地项目招标及后续市场拓展产生实质性影响"。8月15日伊阿航道通行方案协议为航运风险提供了一条制度化解法路径，但受制于美方条件博弈与封锁持续，全面通航与成本回落仍需时间。结论从"中东冲突短期压制海外交付"与"8月中旬关键节点不确定性"演进为"公司层面交付修复已验证＋伊阿协议推进降低尾部风险，但霍尔木兹航运恢复缓慢与高海运成本仍是H2利润表的现实压制项"。

### 2.2 全球供应链重构（China+1）

- 部分国家推动供应链多元化，但特高压设备领域中国具有绝对技术和产能优势
- 公司已通过沙特本地化生产（沙特设立子公司DACI SAUDI）应对"去中国化"趋势
- 美国FERC发布《Energized for 2026》，加快电网建设，但对中国产品存在关税和准入壁垒

### 2.3 贸易摩擦与关税

- 特朗普关税政策虽有反复（部分被最高法院裁定违宪），但对华加征关税趋势未根本逆转
- 公司出口以中东、东南亚为主（非美市场），受中美贸易摩擦直接影响有限
- 风险点：若美国进一步限制中国电力设备进口，将影响公司开拓美国市场的潜力（当前美国占中国绝缘子出口13.43%）

## 三、监管与产业政策

### 3.1 国家发展规划契合度：极高

大连电瓷处于国家能源战略的**核心受益位置**：

| 政策/规划 | 内容要点 | 对公司影响 |
| :--- | :--- | :--- |
| 十五五电网投资 | 国网4万亿（+40%），投产15项特高压直流。**2026年6月25日，《新型能源体系建设"十五五"规划》正式发布** | **极大利好**——直接拉动订单 |
| "西电东送" | 2030年规模超4.2亿千瓦 | 特高压线路建设→绝缘子需求 |
| 新型电力系统 | 新能源年均新增2亿千瓦 | 新能源并网配套→增量需求 |
| 零碳园区/绿电直连 | 84个绿电直连项目获批，3259万千瓦 | 配网升级→中低压绝缘子需求 |
| "两重""两新" | 电网基础设施更新改造 | 存量替换需求 |
| 南方电网 | 2026年固投1800亿元，更新投资≥506亿元 | 第二增长曲线 |
| **电网投资执行** | **2026Q1国网固投1290亿（+37% YoY），南网+国网合计1674.5亿（国网+37%、南网+49.5%），开局强劲** | **强验证**——十五五开局投资执行力超预期 |

### 3.2 环境监管：利好龙头出清

- 环保法规趋严：窑炉废气排放标准提升、高能耗产线受限
- 2025年已有15%以上小型绝缘子企业因环保不达标被关停
- 公司率先完成绿色工厂认证、碳足迹认证、ESG报告，形成"合规溢价"
- 欧盟CBAM（碳边境调节机制）实施，公司的碳足迹认证成为出口欧洲的"通行证"

### 3.3 行业准入：壁垒加固

- 国网供应商分级管理制度趋严，引入全生命周期成本（LCC）评估
- 对绝缘子的机械强度、污秽等级、使用寿命提出更高要求
- 特高压资质维持严格的"业绩闭环"，新进入者极难突破
- 结论：**政策方向持续利好龙头，加速行业集中度提升**

## 四、模块四核心结论

1. **汇率风险可控但需关注**：海外收入占比24%，人民币兑美元8月14日中间价6.7878，仍在6.78-6.81盘整通道，汇兑损失对利润影响约10%，公司需加强套保
2. **中东局势：伊阿航道协议达成但海峡重开未定**：8月5日伊阿就航道地理坐标达成一致，8月15日正式宣布达成航道通行方案协议（临时航道2-4个月、改经伊朗领海）；但协议不自动等同海峡重开——全面通行仍取决于美国满足伊朗六项条件，美方海上封锁与"航母接力"持续、8月14日海峡日通行量仅2艘。尾部冲突升级风险较7月末下降，风险评级从"高"下调至"中高"；公司8月3日确认沙特履约平稳、未发生违约，但"航运成本进一步提升"仍是H2利润表的现实压制项
3. **十五五是最大确定性且执行力验证强劲**：4万亿电网投资政策锁定，6月25日十五五规划正式发布；Q1固投+37%的执行数据验证了政策落地的决心和能力
4. **环保和准入政策持续利好龙头**：中小竞争者加速退出，合规溢价逐渐显现
5. **氧化铝成本边际利好延续**：SMM氧化铝现货8月12日约2,693元/吨，延续2,700-2,800元/吨偏弱震荡，直接材料成本压力较6月缓和，对H2毛利率形成支撑
6. **核心外部风险排序（更新）**：霍尔木兹通航恢复缓慢与高海运成本（伊阿协议落实+美方条件博弈） > 半年报海外交付与毛利率验证 > 人民币升值（若破6.70） > 油价与原材料反弹 > 贸易摩擦
