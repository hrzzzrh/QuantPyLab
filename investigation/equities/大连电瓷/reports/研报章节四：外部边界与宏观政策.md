# 研报章节四：外部边界与宏观政策

**研究日期**：2026年08月25日

---

## 前序模块核心结论继承

模块一发现：海外收入占比23.56%、毛利率高于国内，但客户集中度高
模块二发现：十五五4万亿确定性极强，全球电网投资共振

## 一、宏观环境变量

### 1.1 人民币汇率：升值趋势暂歇，但方向仍需观察

**当前汇率环境**：
- 2025年4月以来，人民币兑美元从7.35附近持续升值，至2026年6月底在6.79附近企稳，7月2日中间价6.8088
- 美元/离岸人民币（CNH）近期在6.78-6.81区间窄幅波动，大华银行判断原上升趋势已转为盘整
- 在岸人民币受央行中间价引导，波动相对克制

**对大连电瓷的传导分析**：

公司2025年海外收入4.19亿元，主要以美元报价和结算。年报明确将"汇率变动风险"列为经营风险之一。

**定量估算**：
- 假设海外收入中70%以美元结算（~2.93亿元）
- 当前汇率6.80与6月9日的6.82基本持平，近期汇率波动对2026Q2利润影响不大
- 人民币自7.35高位升值至6.80（累计7.5%），若全部发生在2026H1结算期，折算损失约2,200万元
- 占2025年归母净利润2.12亿元的约10.4%
- **影响可控但不可忽视**：2026Q1财务费用已从23万元飙升至877万元（+3568%），包含汇兑因素

**核心判断**：汇率风险对大连电瓷属中等影响，原因如下：
1. 海外收入占比约24%，低于纯出口型企业
2. 公司正推进海外本地化生产（沙特建厂），将形成"收入成本同币种"的自然对冲
3. 6月底以来人民币升势暂缓并进入盘整，为2026H2的海外利润结算提供了一些喘息窗口
4. **积极面**：人民币升值降低了公司进口原材料的成本（氧化铝等以美元计价的大宗商品），存在一定自然对冲

**2026年8月25日跟踪更新**：USD/CNY 8月下旬延续6.78-6.81箱体盘整。半年报已实际确认汇兑扰动：H1财务费用1,163万元（上年同期仅1.4万），其中**汇兑损失约888万元**（财务费用附注口径）。但关键结论是：**汇兑损失被毛利率跃升充分吸收，H1净利率仍创半年度新高17.91%**——验证了"汇率属非核心解释变量"的判断。H2风险仍在于人民币若突破6.70持续升值，海外利润折算将再次成为利润表边际压制项；公司已在半年报中明确将"积极运用结售汇、汇率对冲等专业化金融工具"纳入应对措施。

### 1.2 利率与折现率：估值锚定影响

- 当前中国10年期国债收益率约2.7%，处于历史低位
- 美联储因中东战事推高通胀，降息预期推迟至2027年
- 低利率环境有利于DCF估值，但无风险利率下行空间已有限

**对估值的影响**：中性偏正面。低利率支撑成长股估值，但PE中枢的进一步抬升需要盈利增速配合。

### 1.3 通胀与成本传导

**原油/天然气价格**：
- 布伦特原油8月22日收于94美元上方（周涨5.9%，五连阳），逼近96美元压力位；较7月初高位回落后的反弹再度确立，仍处战前约70美元的高位上方
- 霍尔木兹流量出现修复信号：美军护航下8月21日晚约40艘油轮经南部深水航道通过、单夜运出原油约1,600万桶（美官员口径）；瑞银测算过去一周海峡整体石油过境量略高于600万桶/日（含"暗流"运输500-600万桶/日），海湾非伊朗产油国装载量回升至1,020万桶/日。但可见油轮流量均值仅4.0艘次/日（7月6.4艘、战前130+艘），且8月18日仍有商船遇袭、一名海员死亡——通航恢复呈"脉冲式改善+结构性脆弱"特征
- **中东航线海运费突破1万美元/大柜创新高**：上海-吉达大柜运价10,200美元（8月20日报价，半月内自约7,000美元跳涨）、利雅得与达曼港均超1万美元，业内预计8月下旬继续攀升；霍尔木兹海峡"基本处于关闭状态"、货船遇袭频发仍是运力收缩主因
- 天然气价格同步高企，直接推升公司燃料成本（天然气占悬瓷成本11.4%）
- 氧化铝成本端延续友好：SMM现货8月中旬2,690元/吨附近，卓创口径同比-16.80%，供应宽松格局未改、低位震荡

**成本传导效率**：
- 年报已披露：2025年财务费用大幅增加，"利息费用增加及汇兑收益减少"
- 公司半年报确认地缘冲突的现实冲击："出口货运航线频繁调整、通航时效无法保障，大幅增加了海外订单内陆转运及物流调配成本"；"叠加公司短期海外库存有所增加，阶段性推高了海外订单履约成本"
- **但2026H1实际毛利率不降反升至38.69%（海外43.08%）**——产品结构升级与技术溢价对冲了海运与能源成本压力，成本传导能力得到实证
- 公司通过光伏绿电（自发自用35-80%）部分对冲能源成本

## 二、地缘政治风险

### 2.1 美以-伊朗战争：伊阿航道协议达成，但海峡重开仍取决于美方条件

**冲突与谈判最新进展**（截至2026年8月25日）：
- **6月17日**：美伊在瑞士签署临时谅解备忘录，伊朗同意60天期限内允许船只免费通行霍尔木兹海峡
- **7月12日**：美军重启对伊朗空袭后，**伊朗宣布关闭霍尔木兹海峡**；该关闭状态持续至8月中旬
- **8月5日**：伊朗与阿曼就霍尔木兹海峡拟定航道地理坐标达成一致，联合声明进入终审阶段（新华社）
- **8月15日**：伊朗宣布与阿曼就霍尔木兹海峡航道通行方案达成协议（央视新闻/新华社/路透多源确认）。新通行模式要点：商业船舶部分航程改经伊朗领海；新航道为临时性质，预计可使用2-4个月
- **8月18日**：两艘商船在海峡附近遇袭，一名海员死亡（UANI监测）——袭击风险未消除
- **8月21日晚**：约40艘油轮经海峡南侧深水航道通行、运出原油约1,600万桶（来源：新华社华盛顿8月22日电，转引美国媒体援引三名美国官员的说法；独立船舶追踪机构口径低于此——Kpler数据显示8月19-20日日均约7-9艘、瑞银Evidence Lab可见流量日均4.0艘次，多源存在量级张力，审慎取用）；瑞银测算周度过境量略超600万桶/日——美军护航下的流量修复信号最显著的一次，但可见油轮流量仍远低于战前130+艘
- **8月22日前后**：美伊和平协议到期，双方均未尝试重启谈判；伊朗称将对任何新威胁作出"毁灭性"回应；美方转向关税与制裁施压（对伊朗贸易伙伴的关税言论）

**关键研判：通航"脉冲式修复"但结构性脆弱未解，海运成本反而创新高（对公司呈"交付改善+成本承压"的双面格局）**：
- 40艘油轮/夜的通过量是护航机制下流量修复的积极信号，但瑞银数据显示可见流量仍处低位，且替代管道能力仅约470万桶/日（战前海峡约2,100万桶/日），供应脆弱性仍在
- **中东航线集装箱海运费突破1万美元/大柜创历史新高**且仍在攀升——公司沙特方向交付的物流成本压力较7月末进一步恶化而非缓解
- 美伊政治条件僵持（六项条件博弈）未变，全面重开无时间表；冲突升级尾部风险维持"中高"评级不变

**对公司沙特业务的考量更新**：
| 影响维度 | 8月16日评估 | 8月25日更新 |
| :--- | :--- | :--- |
| 沙特订单交付 | 履约平稳、未发生违约（8月3日互动易口径） | 半年报确认H1海外收入+106.15%、存量订单有序交付；但披露"出口货运航线频繁调整、通航时效无法保障"，交付效率受扰 |
| 海运成本 | "航运成本进一步提升"（公司口径） | 中东航线海运费破1万美元创新高且预计继续攀升——成本压制加剧 |
| 海外库存 | — | 半年报披露"短期海外库存有所增加，阶段性推高履约成本"（存货7.37亿较年初+20.3%的部分成因） |
| 地缘风险评级 | "中高" | 维持"中高"：通航脉冲式修复降低断供尾部风险，但海运费创新高+商船遇袭+美伊僵持，成本端恶化 |

**辩证视角（维持并强化）**：
- **短期**：交付确定性改善（护航流量回升）+成本压力上升（运价新高）并存；H1海外毛利率43.08%证明当前订单结构可吸收成本冲击，但H2新签订单的定价传导能力面临考验
- **中长期利好**：高油价→中东国家财政充裕→电网投资加速。沙特九条高压直流骨干线路（超587亿美元）建设周期覆盖2025-2030年，沙特-埃及互联已具备投运条件；公司作为沙特核心瓷绝缘子供应商且DACI Saudi子公司已注册落地（2026年2月，注册资本里亚尔3,000万），本地化组装工厂稳步推进
- **竞争格局优化**：中小出口商因运费/保险成本激增退出中东市场，有利于龙头集中份额

**2026年8月25日再审计**：半年报将地缘冲突列为明确风险项（航线调整、转运成本、海外库存增加），但同时以H1海外收入翻倍、毛利率43.08%的事实证明其盈利韧性。结论从"伊阿协议推进降低尾部风险"演进为"**交付端脉冲修复＋物流成本创新高的双面格局**；公司层面以产品结构升级对冲成本冲击的能力已被半年报验证"。折价解锁哨点调整为：霍尔木兹可见油轮流量恢复至日均30艘以上并持续4周、或中东航线运价自1万美元高位回落30%，届时地缘折价方可解除。

### 2.2 全球供应链重构（China+1）

- 部分国家推动供应链多元化，但特高压设备领域中国具有绝对技术和产能优势
- 公司已通过沙特本地化生产（沙特设立子公司DACI SAUDI）应对"去中国化"趋势
- 美国FERC发布《Energized for 2026》，加快电网建设，但对中国产品存在关税和准入壁垒

### 2.3 贸易摩擦与关税

- 特朗普关税政策虽有反复（部分被最高法院裁定违宪），但对华加征关税趋势未根本逆转
- 公司出口以中东、东南亚为主（非美市场），受中美贸易摩擦直接影响有限
- 风险点：若美国进一步限制中国电力设备进口，将影响公司开拓美国市场的潜力（当前美国占中国绝缘子出口13.43%）

## 三、监管与产业政策

### 3.1 国家发展规划契合度：极高

大连电瓷处于国家能源战略的**核心受益位置**：

| 政策/规划 | 内容要点 | 对公司影响 |
| :--- | :--- | :--- |
| 十五五电网投资 | 国网4万亿（+40%），投产15项特高压直流。**2026年6月25日，《新型能源体系建设"十五五"规划》正式发布** | **极大利好**——直接拉动订单 |
| "西电东送" | 2030年规模超4.2亿千瓦 | 特高压线路建设→绝缘子需求 |
| 新型电力系统 | 新能源年均新增2亿千瓦 | 新能源并网配套→增量需求 |
| 零碳园区/绿电直连 | 84个绿电直连项目获批，3259万千瓦 | 配网升级→中低压绝缘子需求 |
| "两重""两新" | 电网基础设施更新改造 | 存量替换需求 |
| 南方电网 | 2026年固投1800亿元，更新投资≥506亿元 | 第二增长曲线 |
| **电网投资执行** | **2026Q1国网固投1290亿（+37% YoY），南网+国网合计1674.5亿（国网+37%、南网+49.5%），开局强劲** | **强验证**——十五五开局投资执行力超预期 |

### 3.2 环境监管：利好龙头出清

- 环保法规趋严：窑炉废气排放标准提升、高能耗产线受限
- 2025年已有15%以上小型绝缘子企业因环保不达标被关停
- 公司率先完成绿色工厂认证、碳足迹认证、ESG报告，形成"合规溢价"
- 欧盟CBAM（碳边境调节机制）实施，公司的碳足迹认证成为出口欧洲的"通行证"

### 3.3 行业准入：壁垒加固

- 国网供应商分级管理制度趋严，引入全生命周期成本（LCC）评估
- 对绝缘子的机械强度、污秽等级、使用寿命提出更高要求
- 特高压资质维持严格的"业绩闭环"，新进入者极难突破
- 结论：**政策方向持续利好龙头，加速行业集中度提升**

## 四、模块四核心结论

1. **汇率风险已被H1实证为可控**：H1财务费用1,163万（其中汇兑损失约888万）被毛利率跃升吸收，净利率仍创半年度新高17.91%；人民币维持6.78-6.81箱体，若破6.70持续升值则重新成为边际压制项
2. **中东局势"交付改善+成本承压"双面格局**：8月21日约40艘油轮单夜通过海峡（护航流量修复最显著信号），但可见流量仍处低位、8月18日商船遇袭、美伊条件僵持——风险评级维持"中高"；中东航线海运费破1万美元创新高，是海外利润率的最大现实压制项；公司以产品结构升级（海外毛利率43.08%）实证了对冲能力
3. **十五五是最大确定性且执行力持续验证**：4万亿电网投资政策锁定；《新型电力系统建设"十五五"规划》8月3日正式印发；2026H1国网固投超3100亿（+12.6%）
4. **环保和准入政策持续利好龙头**：中小竞争者加速退出，合规溢价逐渐显现
5. **氧化铝成本友好延续**：SMM现货2,690元/吨附近、同比-16.8%，供应宽松低位震荡，对H2毛利率形成支撑
6. **核心外部风险排序（更新）**：中东航线海运费创新高与霍尔木兹通航结构性脆弱 > 第四次国网招标及Q3-Q4批次金额验证 > 人民币升值（若破6.70） > 油价反弹 > 贸易摩擦
