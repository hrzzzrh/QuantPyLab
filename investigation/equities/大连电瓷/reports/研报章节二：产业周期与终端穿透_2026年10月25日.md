## 一、产业生命周期与库存节奏

### 1.1 周期定位：成熟期内部的结构性升级

中国绝缘子行业整体处于**成熟期**，但内部呈现鲜明的二元分化：

| 市场层级 | 生命周期阶段 | 核心特征 | 对应大连电瓷定位 |
| :--- | :--- | :--- | :--- |
| 特高压瓷绝缘子（高端） | **成长中后期** | 寡头格局、高壁垒、需求增速>20% | 绝对龙头（40-50%，2026年约40%） |
| 中低压瓷绝缘子（中端） | **成熟期** | 充分竞争、价格承压、增速平缓 | 参与但非核心 |
| 复合/玻璃绝缘子（替代品） | **成长期** | 渗透率快速提升、替代瓷绝缘子中低压份额 | 公司复合产品起步晚、市占率低 |

**关键判断**：大连电瓷的核心价值锚定在"特高压瓷绝缘子"这一成长中后期细分市场，公司约80%+营收来自高壁垒悬瓷产品。行业的"成熟"标签是对整体而言，但公司所处的赛道仍在结构性扩张通道中。

### 1.2 库存周期动力学

**行业库存阶段**：当前处于**主动补库后的订单交付验证期**，尚未进入被动去库。

- **主动补库（2024-2026H1）**：2024年特高压招标放量，公司存货从3.58亿（2023末）→6.13亿（2025末）→6.79亿（2026Q1末）→7.37亿（2026H1末），彰显备货意愿
- **Q3边际变化**：存货7.62亿（较H1末+3.4%、较年初+24.4%），环比增速较H1明显放缓；合同负债1.60亿（较H1末+17.8%，但同比-2.1%），说明备货仍有在手订单支撑，但不宜解读为订单加速；更准确的定性是"主动补库后等待交付验证"。存货/TTM营收约36.3%，低于45%预警线，但绝对额仍高，Q4去化是验证订单交付节奏的关键。

**"牛鞭效应"辨析**：
电网投资的传导链条为：**国家规划→电网招标→设备商备货→原材料采购**。由于电网招标具有"批次性+大单量"特征，叠加公司备货周期（瓷绝缘子烧制周期约30-45天），订单波动的放大效应天然存在。当前时点需区分：2025年存货增长中，多少是真实在手订单的备货，多少是预期性库存。年报显示悬瓷绝缘子2025年产销率约94%，库存量40,378吨（+19.73%），基本属于合理范围。

## 二、终端需求穿透与跨期断层审计

### 2.1 最终产品画像

大连电瓷的绝缘子产品负载于以下**终端形态**：

| 终端产品 | 对应电力环节 | 绝缘子需求特征 | 增长驱动力 |
| :--- | :--- | :--- | :--- |
| 特高压直流/交流输电线路 | 跨区输电 | 大吨位（≥420kN）、高可靠性悬瓷绝缘子 | 新能源远距离外送 |
| 高压变电站/换流站 | 变电环节 | 支柱绝缘子、套管 | 电网升级改造 |
| 配电网线路 | 配电环节 | 复合/玻璃绝缘子为主 | 城市配网扩容 |
| 海外电网工程 | 国际输电 | 各类绝缘子，标准因地而异 | 全球电网投资周期 |
| 新能源升压站 | 发电侧 | 耐候型绝缘子 | 风光大基地建设 |

### 2.2 终端景气度审计：未来1-3年趋势

#### 2.2.1 国内特高压：十五五建设高峰确认，2026年招标放量已兑现

**投资规模确定性极高**：
- 国家电网"十五五"固定资产投资4万亿元，较"十四五"增40%，年均约8000亿元；国网明确"十五五期间特高压在建总体规模超过'十三五'与'十四五'总和"（科技日报8月1日）
- 南方电网2026年固定资产投资1800亿元，连续五年创新高
- 计划投运15项特高压直流工程，跨省区输电能力提升35%
- **2026H1国网完成固投超3100亿元（+12.6%）**（半年报引用口径；注：Q1累计增速为+37%，倒算Q2单季同比近零——投资节奏呈"前高后稳"，属电网投资年内正常分布特征）；新型电网/充换电/新型储能投资分别+13.5%/+21.8%/+74.3%
- **2026前三季度国网完成固投超4500亿元（+5.2%）**（国家电网10月23日披露）；按披露下限倒算，Q3单季投资约1400亿元，较2025年同期的约1525亿元下降约8%（"超3100/超4500"为下限，实际增速可能高于披露值，故取"持平至小幅下降"区间）。投资增速由H1的+12.6%回落至9M的+5.2%，与公司Q3单季营收+7.80%的换挡方向一致——但公司Q3 +7.80%相对行业投资仍属稳健，中国西电+16.27%更快，说明需求未消失、公司也未丢失份额，差异更多来自产品结构与交付节奏。国网累计建成"23交21直"44项特高压工程，跨区跨省输电能力超3.8亿千瓦。

**绝缘子直接受益逻辑——招标数据实测验证**：
- **2026年特高压项目前四批设备招标总额329.10亿元，已超2025年全年220.62亿元的49.2%**（2025年前四批仅37.80亿，同比+770%）；第三批单批108.72亿元创年内最大，第四批36.52亿元偏向变电+二次+配套材料
- 特高压材料招标144亿元；设备+材料合计436.6亿元，同比+97.7%
- 输变电项目前四批设备招标501.5亿元+材料209.5亿元；配网上半年公示1554亿元（+13%）
- 前期可研尚未核准的直流项目已达8条，蒙西扩建、长治—南阳等交流有望年内招标
- **2026年10月20-22日，疆电入川渝、陇电入川两项特高压直流工程获国家发改委核准**：合计总投资约543亿元（疆电入川渝306亿、陇电入川237亿），计划2027年开工、2029年建成投运，每年向川渝输送清洁电量约720亿千瓦时。这是继陕西—河南、攀西交流、赣江—赣南交流之后，2026年新增核准的又一批跨省区通道，直接锁定2027-2028年绝缘子招标需求。
- 绝缘子占特高压工程总投资约2-3%，按十五五年均特高压投资2000-3000亿元测算，绝缘子年市场空间约50-90亿元
- **用电侧验证（2026年10月21日国家能源局）**：1-9月全社会用电量8.07万亿千瓦时（+3.9%），9月单月8997亿千瓦时（+1.2%）；其中互联网数据服务用电+41.6%、充换电服务业+55.4%，新动能仍是电网扩容的结构性来源，但传统工业与居民用电增速放缓，整体需求从"高增"转向"温和增长"。

**政策与工程进度验证**：
- **2026年8月3日国家发改委、能源局印发《新型电力系统建设"十五五"规划》（发改能源〔2026〕942号）**——继6月25日《新型能源体系建设"十五五"规划》后，电力系统专项规划落地，明确特高压骨干网架、配网升级与新能源外送通道建设方向
- 公司H1供货的重点工程甘肃-浙江±800kV特高压直流（世界首条送受端均采用柔直技术）于8月上中旬实现陕1标、甘4标段等全线贯通，进入投运倒计时——公司产品交付质量经受了工程验证

**订单节奏研判**：7月18日第三次国网预中标合计约5,770万元（占2025营收3.24%）；9月4日第四次装置性材料候选人公示中，大连电瓷集团输变电材料有限公司瓷绝缘子两包合计约3,542万元（2390.004805万元+1152.021779万元，招标编号0711-26OTL09811049，候选人非定标；招标平台公示、未经公司公告确认，不得计入收入预测），环比第三次回落38.6%，单批次低于5,000万元预警线。10月12日，国网2026年输变电项目第五次线路装置性材料及特高压相关项目开标，公司确认已参与投标，截至10月25日仍处评标阶段、候选人公示尚未发布；按国网年度批次安排，11月为输变电/特高压第六批收尾窗口。三季报合同负债1.60亿元（较年初+41.6%、较H1末+17.8%，但较2025Q3末的1.64亿同比-2.1%）显示在手预收订单环比改善、同比基本持平，10月19日交流口径"在手订单体量充足、各基地满产"；但装置性材料小额批次向公司订单的传导仍未放大，Q4第六批与第五批定标结果是全年订单趋势的核心观察窗口。公司前三季度营收14.24亿元（+29.33%）、Q3单季5.60亿元（+7.80%），收入确认节奏已从H1的订单集中转化回归至国网投资节奏。

#### 2.2.2 算力驱动：AI数据中心对电网的拉动

**这是一个新增的、被低估的结构性驱动力**：
- 2025年中国全社会用电量首次突破10万亿千瓦时（10.37万亿kWh），同比+5.0%
- IDC预测AI数据中心IT能耗将从2025年78TWh增至2027年146TWh（CAGR 44.8%）
- 摩根士丹利2026年5月报告指出：2025-2028年美国AI数据中心面临约55GW电力供给缺口
- 中国政府明确"算电协同"战略，"东数西算"工程推动算力中心向西部能源丰富地区布局，进一步拉动特高压输电需求

**对大连电瓷的传导路径**：算力→电力需求增长→电网扩容→特高压线路建设→绝缘子需求增加。这一逻辑链条较长，传导时滞约1-2年，但方向明确且确定性高。

#### 2.2.3 全球电网投资共振

**国际能源署（IEA）《2026年中期电力更新报告》关键数据**（半年报引用）：
- 2026年全球电力需求预计+3.6%、2027年+3.8%，均超2025年3.0%——即便在霍尔木兹危机推高发电成本背景下，全球电力消费仍保持韧性
- 全球电网年投资需从当前4000亿美元增加约50%至6000亿美元
- 美国：三大区域电网运营商已获批750亿美元输电扩容项目，重点推进765kV超高压线路；数据中心用电占全美总用电量4-5%，预计2035年升至10-20%
- 欧洲：欧盟《欧洲电网一揽子计划》2040年前投资1.2万亿欧元（其中7300亿欧元专项用于配电网改造）
- 中东：沙特"2030愿景"九条高压直流骨干线路总投资超587亿美元（360亿输电骨干+227亿配电现代化）；**沙特-埃及3GW跨境直流互联线路调试完毕、具备投运条件**（截至2026年7月）；GCCIA与阿曼电网互联（7亿美元）
- 东南亚：预计2026-2030年电力需求年增5.3%，年均投资210亿美元

**中国绝缘子出口数据验证**：
- 2019-2025年中国绝缘子出口量从24.44万吨增至40.67万吨（CAGR 8.85%）
- 出口金额从5.57亿美元增至11.11亿美元（CAGR 12.20%）
- 前五大出口市场：美国（13.43%）、沙特（13.41%）、印度（6.00%）、巴西、越南
- 中国绝缘子占全球进口比重从22.88%（2019）升至27.45%（2024）

### 2.3 动能溯源与透支审计

#### 2.3.1 增长动能分类

| 增长动能 | 性质 | 可持续性评估 |
| :--- | :--- | :--- |
| 特高压建设加速 | **内生（政策驱动+刚需）** | 高，十五五规划已锁定 |

#### 2.3.2 跨期需求透支审计

**强制审计项一**：是否存在"十四五"末赶工导致的"十五五"需求前置？

**审计结论：风险可控但需警惕**。
- 2025年是"十四五"收官年，电网投资6395亿元（+5.1%），部分项目赶工属正常现象
- 但2025年底有6条特高压线路集中竣工投产，叠加5条新线路推迟至2026年招标，导致2025年特高压设备招标同比下降12%
- 2026年作为"十五五"开局年，年初市场预期投资加速（高盛曾预测特高压板块2026年增速24%）；实际前三季度国网固投+5.2%、Q3单季同比大致持平至小幅下降（按披露下限倒算约-8%，"超"字口径存在误差），投资节奏低于年初乐观预期，但特高压专项招标前四批329.10亿元已超2025全年，结构性强度仍在
- **核心判断**：十五五的4万亿投资规模远超十四五（2.8万亿），增幅40%，需求总量足以覆盖任何"赶工透支"效应

**强制审计项二**：是否存在补贴/政策刺激驱动的短期繁荣？

**审计结论：非典型刺激型增长**。
- 电网投资属于基础设施投资，具有长期性和计划性，与消费补贴等短期刺激有本质区别
- 特高压项目从规划到建成周期3-5年，投资释放具有持续性
- 风险在于：若宏观经济大幅下行，电网投资可能被作为"逆周期调节工具"提前释放，导致远期需求透支。当前宏观环境温和，该风险概率较低

## 三、供需边际与压力传导

### 3.1 供需平衡审计

**供给端：结构性过剩与高端紧平衡并存**（注：下表行业总量数据为前次调研存量估计，未经权威来源更新核验，仅作格局参考）

| 维度 | 数据 | 研判 |
| :--- | :--- | :--- |
| 行业总产能 | ~1.8亿只/年（存量估计） | 整体过剩约35% |
| 产能利用率 | 84-90% | 偏低，但高端产线接近满产 |
| 特高压资质企业 | 不足10家 | **高端供给高度集中，扩产壁垒极高** |
| 中低端企业数量 | 1200+家 | 充分竞争，平均毛利率<15% |
| 2025年并购 | 12起，涉及30亿元（存量估计） | 行业加速出清整合 |

**需求端：结构性高增长**

| 需求类别 | 2025年规模估算 | 2026年预计增速 |
| :--- | :--- | :--- |
| 特高压瓷绝缘子 | ~50-60亿元 | +20-25% |
| 输变电批次绝缘子 | ~25-30亿元（1-2批） | +10-15% |

**供需边际推演**：
- **特高压瓷绝缘子**：供给增量有限（资质壁垒+扩产周期3-5年），需求增速20%+，**供需维持偏紧**，有利于维持定价权
- **中低压瓷绝缘子**：供给过剩，复合/玻璃绝缘子加速替代，**竞争将持续恶化**
- **复合绝缘子**：新增采购中占比已超55%，但竞争主体多，毛利率承压

### 3.2 压力传导特征分析

#### 3.2.1 "剪刀差"困境

绝缘子行业当前面临典型的**成本-售价剪刀差**：

- **上游成本端**：高岭土+18%、天然气+9.8%、硅橡胶+6.2%（2024-2025年）
- **下游售价端**：国网集中招标中标均价同比下降4.8%（2025年）
- **结果**：行业平均毛利率从28.6%（2020）→14.2%（2025），净利率仅3.8%

**大连电瓷的相对优势**：
- 特高压产品具备技术溢价，受中低压价格战影响较小
- 2025年悬瓷毛利率32.02%虽同比下滑2.73pct，仍远高于行业均值
- 公司通过三基地协同、绿电应用（光伏自发自用35-80%）等手段对冲成本

#### 3.2.2 波动放大效应分析

电网采购具有**典型的"牛鞭效应"放大机制**：
- 电网公司集中招标→大单脉冲式释放→设备商集中备货→原材料需求放大
- 2024年大连电瓷营收暴增78%但现金流为负，正是此效应的体现
- 2025年现金流大幅转正，表明波动已从"放大"进入"收敛"阶段

#### 3.2.3 传导时滞与博弈筹码

| 压力来源 | 传导时滞 | 公司博弈筹码 |
| :--- | :--- | :--- |
| 原材料涨价 | 1-2个季度（库存缓冲） | 长协锁价、配方优化替代 |
| 国网招标压价 | 即时（中标即锁定） | 特高压技术壁垒→不可替代性 |
| 竞争对手扩产 | 2-3年（建设周期） | 先发优势+资质壁垒 |
| 海外地缘风险 | 即时到数周 | 多区域分散布局 |

**公司最核心的博弈筹码**：特高压瓷绝缘子的**不可替代性**。在±800kV及以上直流和1000kV交流领域，国内仅大连电瓷和少数企业具备批量供货能力。这种技术垄断性赋予了公司在面对国网压价时的一定议价空间——但需注意，模块一揭示的前两大客户占比57.9%，意味着这种博弈筹码存在上限。

## 五、模块二核心结论

1. **产业周期定位**：公司核心赛道（特高压瓷绝缘子）处于**成长中后期**，十年维度内仍有明确增长空间；2026年招标放量（前四批设备329.10亿超2025全年）标志景气从政策预期切换为订单兑现，但Q3国网投资增速回落至+5.2%提示节奏从"抢进度"转向"稳增长"
2. **终端需求确定性**：国内十五五4万亿电网投资+全球电网升级+AI算力电力需求，三重共振，确定性极高；《新型电力系统建设"十五五"规划》（8月3日）提供制度性保障
3. **供需格局有利**：特高压高端市场供给增量有限（资质壁垒+扩产周期），需求增速20%+，紧平衡格局持续
4. **压力传导可控**：公司受中低端价格战影响有限，原材料成本端（氧化铝10月23日现货2,662元/吨、同比约-16%）对毛利率形成支撑，中东运价高位企稳但仍是海外利润率的主要压制项（已在公司H1海外库存与履约成本中部分体现）
5. **跨期透支风险低**：十五五投资规模远超十四五，不存在显著的"寅吃卯粮"问题
6. **核心变量监控**：三季报进一步验证"高等级产品占比提升+满产+技改降本"的盈利逻辑（Q3单季毛利率40.58%、净利率22.71%），但Q3营收+7.80%确认了收入增速换挡；行业侧国网9M投资+5.2%（H1 +12.6%）、Q3单季投资同比大致持平至小幅下降（按披露下限倒算约-8%），需求从"抢进度"转向"稳节奏"。下一验证点是11月第六批招标与第五批定标金额、Q4收入能否重回两位数增长，以及2027年新核准的疆电入川渝/陇电入川（合计543亿元、2027年开工）能否转化为绝缘子订单
