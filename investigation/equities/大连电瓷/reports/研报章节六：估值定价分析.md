## 一、价值锚定：适配性方法选择

### 1.1 方法论工具箱选择

基于公司的**商业模式特征**（重资产制造+技术壁垒+订单驱动）及**生命周期阶段**（特高压赛道成长中后期），选择以下三种方法交叉验证：

| 方法 | 适用性理由 |
| :--- | :--- |
| **PE估值**（主） | 公司已稳定盈利，历史PE区间明确，利润增长可预见，是最直观的估值锚 |
| **PEG估值**（辅） | 当前处于成长加速期，PEG可弥补PE对增速反映不足的缺陷 |
| **PB-ROE**（参照） | 重资产属性，PB-ROE可判断资产回报效率是否匹配市场定价 |

**不采用DCF的原因**：电网投资政策周期性强，5年后的自由现金流预测不确定性高；公司尚在产能爬坡期，DCF易低估近期价值。

### 1.2 历史分位审计

| 维度 | 当前值 | 历史分位 | 研判 |
| :--- | :--- | :--- | :--- |
| PE_TTM | 29.66 | 近260个交易日约68.3% | TTM口径尚未纳入H1预告，静态估值不便宜，但Forward PE已降至约19.6x |
| PB | 3.29 | 近260个交易日约82.5% | PB已偏高，需靠H1兑现后的ROE上行消化 |
| PE band（2025年） | — | 16.45-25.95x | 2025年利润暴增后的估值压缩已基本完成，当前TTM PE高于2025年区间 |

**历史分位的局限性警示**：A股历史PE包含了2015年（PE均值262x）等极端非理性时期，2011-2014年上市初期的高PE也缺乏参考意义。真正可比的是2021年之后的"利润回归期"——PE区间16-34x。当前29.66x处于该区间的**中上位**，因此本轮上修更依赖盈利E的兑现，而非继续抬升PE倍数。

### 1.3 估值锚点选择

当前为Q3前（目标年份为2026年），锚定**2026年预期EPS**。当前价格14.31元对应的2026E Forward PE（中性0.73元）约**19.6x**，较旧版18.9x小幅抬升，主要来自8月以来股价自13.81元修复至14.31元（+3.6%）。

## 二、PE估值：基准市值测算

| 情景 | 2026E EPS | 合理PE倍数 | 目标价（元） | 目标市值（亿） | 理由 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **中性** | 0.73 | 22x | **16.06** | 70.52 | H1预告中值兑现，全年利润增速约51%，但第三次预中标偏小限制倍数上调 |
| **乐观** | 0.89 | 24x | 21.36 | 93.80 | 特高压超预期+海外共振，成长性获市场认可 |
| **保守** | 0.54 | 18x | 9.72 | 42.68 | H1低端兑现后H2交付放缓，估值回归防御水平 |

**基准市值（中性）**：**70.5亿元**，目标价 **16.06元**。

**交叉验证——PEG法**：
- 2025A→2026E EPS增速：约51.0%
- 若给予PEG=0.6（考虑PB分位偏高和客户集中折价，较旧版更保守），则PE=0.6×51.0=30.6x
- 目标价 = 0.73 × 30.6 = **22.34元**
- 若给予PEG=0.8，则PE=40.8x，目标价=29.78元
- **PEG方法仍指向高于PE历史分位法的价值区间**，说明盈利上修后成长属性更清晰；但考虑7月第三次中标仅5,770万元，暂不把PEG结果作为主目标价

**交叉验证——PB-ROE法**：
- 2026E ROE ≈ 3.20/21.2 = 15.1%
- 若给予PB=3.2（当前PB附近，需由ROE上行支撑），则目标市值=3.2×21.2=67.8亿，目标价=15.45元
- 与PE方法（22x→16.06元）基本一致，但PB法提醒当前股价已提前反映部分盈利修复

## 三、估值全变量对冲审计矩阵

**审计原则**：基准市值70.5亿元（~16.06元/股）为"底色"，通过五维审计计算修正目标市值。

### 3.1 估值影响力过滤（审慎思考）

在模块一到四识别的数十个因子中，经过审慎过滤，**仅有以下5个因子真正具备改变估值中枢的能力**：

| 审计维度 | 核心因子 | 审慎思考（估值影响力过滤） | 调节幅度 | 深度理由 |
| :--- | :--- | :--- | :---: | :--- |
| **内部：企业底层特质** | 特高压垄断地位+百年品牌 | 稀缺性确定，但国网作为唯一大客户削弱了定价权→溢价能力打折扣 | **+5%** | 50%+的市占率和不可替代性应给予一定垄断溢价，但受制于客户结构溢价有限 |
| **宏观：政策与战略对齐** | 十五五4万亿确定性+H1预告兑现 | 政策关联已从规划进入利润表验证阶段，但7月第三次预中标偏小，不能给过高溢价 | **+4%** | H1归母净利润预增200.55%-286.43%，降低了全年达标不确定性 |
| **宏观：地缘与外部约束** | 中东航运（伊阿协议推进但海峡未重开）+人民币升值 | 8月15日伊阿达成航道通行方案协议使冲突升级尾部风险下降，但协议不自动等于海峡重开——美方六项条件博弈、海上封锁持续、8月14日海峡日通行量仅2艘，公司8月3日确认"航运成本进一步提升"；风险等级从"高"降至"中高"，尚不足改变估值中枢折价。**折价解锁哨点：霍尔木兹日通行量恢复至战前水平30%（约40艘）以上并持续4周、或海运费自当前高位回落20%以上，届时重估折价** | **-3%** | 地缘风险从"8月中旬临界升级"降为"长期僵持下的高海运成本压制"，折价保留（边际改善不足以解锁折价） |
| **市场：流动性与风格** | 小市值+特高压成长主题 | 当前市值~60亿属小盘股，在市场"成长风格"中获得流动性溢价概率较高。但中证电网设备ETF已建仓1.72% | **+2%** | 小市值提供了一定流动性溢价，但电网主题ETF的配置说明风格匹配度已部分反映 |
| **逻辑纯净性校验** | 避免重复计算 | 毛利率回升、订单增长、产能释放等因素已在EPS预测中体现，不应再计入PE调节 | **0%** | 严格执行E/PE分离：可计算的钱进E，不可计算的信心因素进PE |

| **综合调节系数** | — | — | **+8%** | — |

### 3.2 修正目标市值

**修正目标市值** = 70.5亿 × (1 + 8%) = **76.16亿元**
**修正目标价** = 76.16亿 / 4.39亿股 = **17.35元**（不复权市价）

对应2026E PE = 17.35/0.73 = **23.8x**

### 3.3 锚点回测

| 检查项 | 结果 | 合理性判断 |
| :--- | :--- | :--- |
| 修正后PE（23.8x） vs 2021-2026年历史均值（~30x） | 略低于历史均值 | 合理，业务单一且客户集中，仍应折价 |
| 修正后PE（23.8x） vs 2025年PE区间（16.5-26x） | 偏上限 | 合理，H1预告确认2026年利润恢复增长 |
| 修正后PE（23.8x） vs 同业参考 | 低于特高压设备龙头30-40x | 合理，大连电瓷为纯绝缘子公司，业务单一性应给予适度折价 |

## 四、确定性与胜率矩阵

### 4.1 三态逻辑加权

| 情景 | 目标价（元） | 发生概率 | 加权目标价 | 潜在收益率（vs 14.31） |
| :--- | :--- | :--- | :--- | :--- |
| 中性 | 17.35 | 60% | 10.41 | +21.2% |
| 乐观 | 21.36 | 25% | 5.34 | +49.3% |
| 保守 | 9.72 | 15% | 1.46 | -32.1% |
| **加权** | **17.21** | **100%** | — | **+20.3%** |

### 4.2 盈亏比计算

**盈亏比** = (目标价 - 现价) / (现价 - 保守价) = (17.21 - 14.31) / (14.31 - 9.72) = 2.90 / 4.59 = **0.63**

**解读**：潜在上行空间~20.3%，下行风险（至保守价）约32.1%。盈亏比从0.87回落至0.63——口径说明：旧值0.87按旧版口径以中性目标价17.35元作分子（(17.35−13.81)/(13.81−9.72)=0.87），未符合框架"分子必须采用概率加权目标价"的强制性口径；若按现行加权口径复算旧值应为0.83（(17.21−13.81)/(13.81−9.72)），即本次实际收窄幅度为0.83→0.63，主要来自股价自13.81元修复至14.31元。**14.31元位置仍属底仓可接受区间，但赔率已明显下降，新资金追高的吸引力减弱；13元以下加仓与站稳MA60放量确认的右侧信号仍是更优入场点。**

## 五、极限压力测试与逻辑证伪

### 5.1 黑天鹅场景模拟

**场景：特高压投资大幅缩减+核心大客户流失**

触发条件：
- 国家突然调整十五五规划，特高压投资缩减50%+
- 国网供应商资格被取消（如因重大质量事故）或日本NGK大幅降价夺走主要份额

**极限支撑位审计**：
- 净现金价值：货币资金7.68亿 - 全部负债 = -3.88亿（净负债）
- 清算价值法（重资产）：固定资产净值6.72亿×0.5 + 存货6.79亿×0.3 + 应收5.01亿×0.5 + 现金7.68亿 = 3.36 + 2.04 + 2.51 + 7.68 = **15.59亿**
- 每股清算价值 ≈ 3.55元
- **地狱价格区间：3.5-5.0元**（不含壳价值）

### 5.2 逻辑证伪警报

以下信号出现即触发无条件止损：
1. 连续两个季度毛利率跌破28%（当前32-37%）
2. 特高压中标金额同比连续两次下降超30%
3. 经营现金流由正转负持续两个季度
4. 海外大客户（沙特等）订单取消且无替代

## 六、模块六核心结论

1. **基准估值**：中性目标价16.06元，修正后目标价17.35元（+21.2%上行空间）。当前14.31元的Forward PE约19.6x（基于中性EPS 0.73元），PEG约0.38
2. **估值方法交叉验证**：PE法16.06元、PB-ROE法15.45元、PEG法22.34元，主估值锚点上移但不采用PEG高值作为目标价
3. **全变量审计结果**：H1预告兑现与垄断地位提供适度溢价（+8%），地缘风险（伊阿协议推进但海峡未重开）和客户集中度构成折价（-3%净影响）
4. **当前价格安全边际较锚点收窄**：8月以来股价自13.81元修复至14.31元（+3.6%），盈亏比降至0.63（同口径旧值0.83）；14.31元距中性目标价仍有21.2%空间，但赔率已明显下降
5. **核心风险**：下行至保守估值9.72元的概率15%，主因是特高压后续招标节奏、H2交付质量与海运成本高企（海峡恢复缓慢）的不确定性
6. **近期变化**：8月15日伊阿航道通行方案协议达成（边际改善地缘尾部风险），国网输变电第四次装置性材料招标8月17日开标，8月25日半年报披露为下一验证点；估值中枢（17.35元）维持不变
7. **投资评级**：维持**谨慎买入/底仓配置**。13元以下可加仓，放量站稳MA60（约14.2元）可确认右侧修复；若半年报毛利率、海外收入或经营现金流低于预告隐含质量，则撤回评级
