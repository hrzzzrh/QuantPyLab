# 研报章节四：外部边界与宏观政策

**研究日期**：2026年10月25日

---

## 前序模块核心结论继承

模块一发现：海外收入占比23.56%、毛利率高于国内，但客户集中度高
模块二发现：十五五4万亿确定性极强，全球电网投资共振
模块三发现：公司在特高压领域护城河极深，但对国网议价能力弱

本章需评估：宏观变量（汇率、通胀）如何冲击盈利？地缘冲突如何影响海外战略？政策环境边际变化方向？

## 一、宏观环境变量

### 1.1 人民币汇率：升值趋势暂歇，但方向仍需观察

**当前汇率环境**：
- 2025年4月以来，人民币兑美元从7.35附近持续升值，至2026年6月底在6.79附近企稳，7月2日中间价6.8088
- 美元/离岸人民币（CNH）近期在6.78-6.81区间窄幅波动，大华银行判断原上升趋势已转为盘整
- 在岸人民币受央行中间价引导，波动相对克制

**对大连电瓷的传导分析**：

公司2025年海外收入4.19亿元，主要以美元报价和结算。年报明确将"汇率变动风险"列为经营风险之一。

**定量估算**：
- 假设海外收入中70%以美元结算（~2.93亿元）
- 当前汇率6.80与6月9日的6.82基本持平，近期汇率波动对2026Q2利润影响不大
- 人民币自7.35高位升值至6.80（累计7.5%），若全部发生在2026H1结算期，折算损失约2,200万元
- 占2025年归母净利润2.12亿元的约10.4%
- **影响可控但不可忽视**：2026Q1财务费用已从23万元飙升至877万元（+3568%），包含汇兑因素

**核心判断**：汇率风险对大连电瓷属中等影响，原因如下：
1. 海外收入占比约24%，低于纯出口型企业
2. 公司正推进海外本地化生产（沙特建厂），将形成"收入成本同币种"的自然对冲
3. 6月底以来人民币升势暂缓并进入盘整，为2026H2的海外利润结算提供了一些喘息窗口
4. **积极面**：人民币升值降低了公司进口原材料的成本（氧化铝等以美元计价的大宗商品），存在一定自然对冲

**截至2026年10月下旬**：人民币兑美元中间价10月23日6.7180，较6月末的6.79进一步升值约1.1%，6.70关口近在咫尺。前三季度财务费用1,535万元（上年同期347万元），其中H1汇兑损失约888万元；Q3单季财务费用约372万元、较Q2的约791万元明显回落，说明Q3人民币升值节奏放缓、汇兑扰动边际减轻。**关键结论仍是：汇兑损失被毛利率跃升充分吸收，9M净利率19.80%、Q3单季22.71%均创近年新高**——汇率不是当前利润表的主导变量。风险在于若人民币升破6.70并持续，Q4及2027年海外利润折算将重新成为边际压制项；公司已在半年报明确"积极运用结售汇、汇率对冲等专业化金融工具"，但套保规模尚未披露。

### 1.2 利率与折现率：估值锚定影响

- 当前中国10年期国债收益率约2.7%，处于历史低位；《宏观指标跟踪手册（2026-10-19）》显示2026年1-9月无政策利率/降准调整，1Y LPR 3.00%、5Y LPR 3.50%连续持稳
- 美联储因中东战事推高通胀，降息预期推迟至2027年
- 低利率环境有利于DCF估值，但无风险利率下行空间已有限；估值修复更依赖盈利兑现与风险溢价回落

**对估值的影响**：中性偏正面。低利率支撑成长股估值，但PE中枢的进一步抬升需要盈利增速配合。

### 1.3 通胀与成本传导

**原油/天然气价格**：
- 布伦特原油10月中旬仍在高位震荡，地缘风险溢价未完全消退；具体价位以公开期货报价为准，本报告不将其作为盈利预测的核心变量
- 霍尔木兹通航仍处"结构性关闭"：9月20日仅记录到1次商业集装箱通行（危机前日均约85艘），马士基10月8日《中东运营更新第51号》仍对海湾方向保留每柜1,000美元霍尔木兹通行附加费及1,800-3,800美元紧急运费；船公司普遍维持绕行与高附加费
- **中东航线运价高位企稳而非继续冲高**：SCFI上海至波斯湾基本港9月30日为6,489美元/TEU，周环比-1.5%，仍是SCFI主要航线中抗跌的一条；Drewry世界集装箱指数10月1日4,434美元/40尺柜，跌幅主要来自亚欧线。运价较8月的1万美元/大柜峰值有所回落，但仍远高于危机前，海外履约成本压力未解除（来源：GCC Freight对SCFI/马士基10月8日运营更新的引述，未经上海航交所/马士基原文逐项核验）
- 天然气价格高位，直接推升公司燃料成本（天然气占悬瓷成本约11.4%）
- 氧化铝成本端延续友好：10月23日全国现货均价2,662元/吨、期货主力2,566元/吨，较8月中旬2,690元/吨继续走弱，同比约-16%；广西新投产能爬坡、厂港库存累积，基本面偏空，对毛利率形成支撑

**成本传导效率**：
- 年报已披露：2025年财务费用大幅增加，"利息费用增加及汇兑收益减少"
- 公司半年报确认地缘冲突的现实冲击："出口货运航线频繁调整、通航时效无法保障，大幅增加了海外订单内陆转运及物流调配成本"；"叠加公司短期海外库存有所增加，阶段性推高了海外订单履约成本"
- **2026H1毛利率38.69%（海外43.08%）、Q3单季进一步升至40.58%**——产品结构升级与技术溢价对冲了海运与能源成本压力，成本传导能力得到两个季度实证
- 公司通过光伏绿电（自发自用35-80%）部分对冲能源成本

## 二、地缘政治风险

### 2.1 美以-伊朗战争：伊阿航道协议达成，但海峡重开仍取决于美方条件

**冲突与谈判最新进展**（截至2026年10月25日）：
- **6月17日**：美伊在瑞士签署临时谅解备忘录，伊朗同意60天期限内允许船只免费通行霍尔木兹海峡
- **7月12日**：美军重启对伊朗空袭后，**伊朗宣布关闭霍尔木兹海峡**；该关闭状态持续至8月中旬
- **8月5日**：伊朗与阿曼就霍尔木兹海峡拟定航道地理坐标达成一致，联合声明进入终审阶段（新华社）
- **8月15日**：伊朗宣布与阿曼就霍尔木兹海峡航道通行方案达成协议（央视新闻/新华社/路透多源确认）。新通行模式要点：商业船舶部分航程改经伊朗领海；新航道为临时性质，预计可使用2-4个月
- **8月18日**：两艘商船在海峡附近遇袭，一名海员死亡（UANI监测）——袭击风险未消除
- **8月21日晚**：约40艘油轮经海峡南侧深水航道通行、运出原油约1,600万桶（来源：新华社华盛顿8月22日电，转引美国媒体援引三名美国官员的说法；独立船舶追踪机构口径低于此——Kpler数据显示8月19-20日日均约7-9艘、瑞银Evidence Lab可见流量日均4.0艘次，多源存在量级张力，审慎取用）；瑞银测算周度过境量略超600万桶/日——美军护航下的流量修复信号最显著的一次，但可见油轮流量仍远低于战前130+艘
- **8月22日前后**：美伊和平协议到期，双方均未尝试重启谈判；伊朗称将对任何新威胁作出"毁灭性"回应；美方转向关税与制裁施压（对伊朗贸易伙伴的关税言论）

**关键研判：通航仍处"结构性关闭"，运价高位企稳但成本压力未解（对公司呈"交付受扰+成本承压"的双面格局）**：
- 8月21日约40艘油轮/夜的通过量是护航机制下的脉冲式修复，但9月下旬商业集装箱通行再度降至每周寥寥数艘（9月20日仅1次），说明修复不可持续
- **中东航线集装箱运价较8月峰值回落但仍处高位**：SCFI上海-波斯湾9月30日6,489美元/TEU、周环比-1.5%，马士基10月仍保留霍尔木兹附加费与紧急运费；公司沙特方向交付的物流成本压力较8月峰值边际缓解，但远未正常化
- 美伊政治条件僵持（六项条件博弈）未变，全面重开无时间表；冲突升级尾部风险维持"中高"评级不变

**对公司沙特业务的考量**：
| 影响维度 | 8月中旬评估 | 10月下旬现状 |
| :--- | :--- | :--- |
| 沙特订单交付 | 履约平稳、未发生违约（8月3日互动易口径） | H1海外收入+106.15%、存量订单有序交付；Q3未披露分区域，10月19日交流口径"在手订单充足、海外项目存在跨年结转" |
| 海运成本 | "航运成本进一步提升"（公司口径） | 中东航线运价较8月峰值回落（SCFI海湾线6,489美元/TEU，-1.5%周环比），但仍远高于危机前；马士基保留附加费，成本压制未解除 |
| 海外库存 | — | 半年报披露"短期海外库存有所增加"；Q3末存货7.62亿（较年初+24.4%、较H1末+3.4%），环比增速放缓 |
| 地缘风险评级 | "中高" | 维持"中高"：通航仍处结构性关闭，运价高位企稳但未正常化，美伊僵持 |

**辩证视角（维持并强化）**：
- **短期**：交付确定性改善（护航流量回升）+成本压力上升（运价新高）并存；H1海外毛利率43.08%证明当前订单结构可吸收成本冲击，但H2新签订单的定价传导能力面临考验
- **中长期利好**：高油价→中东国家财政充裕→电网投资加速。沙特九条高压直流骨干线路（超587亿美元）建设周期覆盖2025-2030年，沙特-埃及互联已具备投运条件；公司作为沙特核心瓷绝缘子供应商且DACI Saudi子公司已注册落地（2026年2月，注册资本里亚尔3,000万），本地化组装工厂稳步推进
- **竞争格局优化**：中小出口商因运费/保险成本激增退出中东市场，有利于龙头集中份额

**10月下旬再审计**：半年报与三季报均将地缘冲突列为明确风险项（航线调整、转运成本、海外库存增加），但公司以H1海外收入翻倍、毛利率43.08%以及Q3整体毛利率40.58%的事实证明其盈利韧性。当前格局是"**交付端受扰＋物流成本高位企稳**"；公司层面以产品结构升级与满产降本对冲成本冲击的能力已被两个季度验证。地缘折价解锁哨点维持：霍尔木兹可见油轮流量恢复至日均30艘以上并持续4周，或中东航线运价自1万美元高位回落30%。

### 2.2 全球供应链重构（China+1）

- 部分国家推动供应链多元化，但特高压设备领域中国具有绝对技术和产能优势
- 公司已通过沙特本地化生产（沙特设立子公司DACI SAUDI）应对"去中国化"趋势
- 美国FERC发布《Energized for 2026》，加快电网建设，但对中国产品存在关税和准入壁垒

### 2.3 贸易摩擦与关税

- 特朗普关税政策虽有反复（部分被最高法院裁定违宪），但对华加征关税趋势未根本逆转
- 公司出口以中东、东南亚为主（非美市场），受中美贸易摩擦直接影响有限
- 风险点：若美国进一步限制中国电力设备进口，将影响公司开拓美国市场的潜力（当前美国占中国绝缘子出口13.43%）

## 三、监管与产业政策

### 3.1 国家发展规划契合度：极高

大连电瓷处于国家能源战略的**核心受益位置**：

| 政策/规划 | 内容要点 | 对公司影响 |
| :--- | :--- | :--- |
| 十五五电网投资 | 国网4万亿（+40%），投产15项特高压直流。**2026年6月25日，《新型能源体系建设"十五五"规划》正式发布** | **极大利好**——直接拉动订单 |
| "西电东送" | 2030年规模超4.2亿千瓦 | 特高压线路建设→绝缘子需求 |
| 新型电力系统 | 新能源年均新增2亿千瓦 | 新能源并网配套→增量需求 |
| 零碳园区/绿电直连 | 84个绿电直连项目获批，3259万千瓦 | 配网升级→中低压绝缘子需求 |
| "两重""两新" | 电网基础设施更新改造 | 存量替换需求 |
| 南方电网 | 2026年固投1800亿元，更新投资≥506亿元 | 第二增长曲线 |
| **电网投资执行** | **2026Q1国网固投1290亿（+37% YoY），H1超3100亿（+12.6%），前三季度超4500亿（+5.2%）** | **前高后稳**——开局强劲，Q3单季投资同比大致持平至小幅下降（按披露下限倒算约-8%）；需Q4与2027年新核准项目接续 |
| **特高压核准** | **2026年10月20-22日疆电入川渝（306亿）、陇电入川（237亿）获国家发改委核准，合计543亿，2027年开工、2029年投运** | **2027-2028年订单增量**——直接对应绝缘子招标需求 |

### 3.2 环境监管：利好龙头出清

- 环保法规趋严：窑炉废气排放标准提升、高能耗产线受限
- 2025年已有15%以上小型绝缘子企业因环保不达标被关停
- 公司率先完成绿色工厂认证、碳足迹认证、ESG报告，形成"合规溢价"
- 欧盟CBAM（碳边境调节机制）实施，公司的碳足迹认证成为出口欧洲的"通行证"

### 3.3 行业准入：壁垒加固

- 国网供应商分级管理制度趋严，引入全生命周期成本（LCC）评估
- 对绝缘子的机械强度、污秽等级、使用寿命提出更高要求
- 特高压资质维持严格的"业绩闭环"，新进入者极难突破
- 结论：**政策方向持续利好龙头，加速行业集中度提升**

## 四、模块四核心结论

1. **汇率扰动边际减轻但6.70关口临近**：H1汇兑损失约888万被毛利率跃升吸收，Q3财务费用降至约372万；人民币中间价10月23日6.7180，若升破6.70并持续，Q4及2027年海外利润折算将重新成为边际压制项
2. **中东局势"交付受扰+成本高位企稳"双面格局**：霍尔木兹仍处结构性关闭，SCFI海湾线6,489美元/TEU较8月峰值回落但仍远高于危机前，马士基保留附加费——风险评级维持"中高"；公司以产品结构升级（Q3毛利率40.58%）实证了对冲能力
3. **十五五政策确定性未变，但2026年执行节奏前高后稳**：4万亿电网投资锁定、《新型电力系统建设"十五五"规划》8月3日印发；国网H1固投+12.6%、前三季度+5.2%，Q3单季同比大致持平至小幅下降（按披露下限倒算约-8%，"超"字口径存在误差）；10月新核准疆电入川渝/陇电入川合计543亿元，为2027-2028年订单接续
4. **环保和准入政策持续利好龙头**：中小竞争者加速退出，合规溢价逐渐显现
5. **氧化铝成本友好延续**：10月23日全国现货2,662元/吨、期货2,566元/吨，较8月继续走弱、同比约-16%，供应宽松，对Q4毛利率形成支撑
6. **核心外部风险排序**：中东航线运价高位与霍尔木兹结构性关闭 > 国网Q4/2027年投资节奏（9M +5.2%） > 人民币升破6.70 > 特高压核准与招标批次波动 > 贸易摩擦
