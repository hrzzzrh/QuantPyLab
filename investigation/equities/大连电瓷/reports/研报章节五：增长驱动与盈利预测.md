## 一、分业务 P×Q 模型的证据链锚定

### 1.1 悬瓷绝缘子（H1收入占比82.33%，核心利润来源）

**量（Q）——确定性评分：5/5**

| 证据维度 | 证据内容 | 证据来源 |
| :--- | :--- | :--- |
| 产能上限 | 江西二期2025年末全面达产（7月29日互动易确认为"产能全面释放"），大连技改收官后产能全面释放，三基地总产能~120,000吨 | 半年报/互动易 |
| 2026H1实际 | 悬瓷收入7.11亿（+59.59%），隐含销量约4.6万吨（ASP约1.54万元/吨，结构升级推高） | 半年报 |
| 在手订单 | 公司8月7日互动易："当前在手订单充足，生产有序"；合同负债1.36亿（较年初+20%）；半年报披露"前瞻性地锁定了下半年多条重点特高压储备项目" | 互动易/半年报 |
| 行业招标 | 特高压前三批设备292.61亿元（超2025全年），材料144亿元 | 国网电子商务平台统计 |

**2026E销量**：H1悬瓷收入+59.59%、特高压交付旺季集中于下半年（2025年H2营收占全年67%），叠加行业招标放量与公司在手订单支撑，**预计全年悬瓷收入20.5-22.0亿元（中性21.3亿/+44.7%；隐含H2约14.2亿、同比+38%）**——H2高增的支撑链：①2026年特高压材料招标大幅放量（前三批292.61亿）对应下半年集中交付；②大连技改+江西二期产能完整释放（上半年受排产爬坡约束）；③公司已锁定下半年多条重点特高压储备项目；④2025年H2本身即旺季基数（悬瓷H2约10.3亿）。风险点：若第四次招标及Q4批次金额持续偏弱，H2确认节奏将向区间下限回落。

**价（P）——确定性评分：3/5**

| 证据维度 | 分析 |
| :--- | :--- |
| 产品结构升级 | H1悬瓷ASP显著抬升（隐含约1.54万元/吨 vs 2025全年约1.34万元/吨），840kN大吨位与高等级产品占比提升是主因 |
| 国网招标压价 | 批次均价下行趋势未变，但公司以高等级产品占比提升对冲（H1悬瓷毛利率39.53%实证） |
| 海外均价更高 | 海外毛利率43.08%持续高于国内37.46% |

### 1.2 海外业务（H1收入占比21.92%，增速引擎）

**量（Q）——确定性评分：4/5**

- H1海外收入1.89亿（**+106.15%**），"海外高端订单集中释放"（半年报口径）；2025年新签海外订单超10亿提供结转支撑
- 7月1日调研纪要管理层指引："未来整体比例将有40%来自海外，60%来自国网系统"
- 制约因素：霍尔木兹通航结构性脆弱+中东航线运价破1万美元，H2交付节奏与物流成本存在扰动；半年报披露海外库存增加

**2026E海外收入**：4.5-5.0亿（+7%~+19%，较原假设5.5-6.0亿下调——H1占比21.92%显示全年难以达到此前预期的加速渗透，管理层5月亦指引"2026年海外占比与2025年基本持平"；中性取4.7亿，隐含H2约2.8亿）

**价（P）——确定性评分：3/5**

- H1海外毛利率43.08%（+22.65pct）源于高端项目集中交付，属结构性改善但含一次性集中确认因素；H2保守假设回落至38-40%（运价压力+新签订单定价传导）

## 二、三态逻辑情景推演

### 2.1 情景定义

| 情景 | 概率 | 核心假设 |
| :--- | :--- | :--- |
| **中性（Base）** | 60% | H1兑现质量（毛利率38.69%）部分回落但仍处高位（全年约37%），H2特高压交付旺季正常放量，第四次招标及Q4批次金额平稳，中东航线高运价持续但海外交付有序，人民币6.7-6.9箱体 |
| **乐观（Bull）** | 25% | 第四次招标及Q4批次显著放大，H2毛利率维持38%+，海外高端订单继续集中释放且运价高位回落，全年收入增速维持50%左右 |
| **保守（Bear）** | 15% | H2确认节奏放缓+后续批次金额偏弱，毛利率回落至33%以下，海运费与汇兑双重挤压，存货减值计提加大 |

## 五、证据链强度总结

1. **销量增长（Q）**：确定性极高（★★★★★），H1收入+48.59%落地验证，行业招标数据支撑
2. **价格趋势（P）**：确定性中高（★★★★☆），H1 ASP与毛利率双升证明结构升级对冲压价
3. **毛利率高位**：确定性较高（★★★★☆），连续两季抬升+成本端友好；H2保守假设回落
4. **海外增长**：确定性中等（★★★☆☆），H1翻倍兑现但运价与通航构成现实压制
5. **2026E EPS 0.75元（加权与中性一致）**，对应现价13.26元的Forward PE约**17.7x**；TTM PE（3.20亿口径）约18.2x
