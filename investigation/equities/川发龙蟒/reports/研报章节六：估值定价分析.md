## 二、PB-ROE 框架验证（2026H1更新）

使用经典 PB-ROE 关系：合理PB ≈ ROE / r

- 在无增长假设下（H1 ROE 2.33%，r=8%）：理论PB = 2.33% / 8% = **0.29x**（vs当前1.65x，+469%溢价）
- 在H1年化ROE 4.66%假设下：理论PB = 4.66% / 8% = **0.58x**
- 在中性恢复假设下（ROE恢复至7%，g=3%）：理论PB = 7% / 8% = **0.88x**（vs 1.65x仍高87%）

当前实际PB = **1.65x（8.43元，净资产96.70亿）**，较5月1.97x（10.03元）回落但仍远高于理论值。即使假设ROE恢复至2021年水平（12%），理论PB仅1.5x，**当前1.65x已透支ROE=13.2%的永续假设，明显高估**。

**PB-ROE结论更新：公司当前PB（1.65x）仍包含过多乐观假设，向下回归风险较大，但较5月1.97x已部分释放（-16%）。**

## 四、基准市值计算（PE方法，重估）

**核心逻辑**：给定2026E重估EPS 0.273元，给予合理PE倍数。

**合理PE倍数的确定（重估：新能源期权下调）**：

步骤一：可比公司PE均值12x
步骤二：ROE折价调整（H1 ROE 2.33% vs 行业13%，原4.35%已恶化）→ 减35%（vs原-30%扩大）
步骤三：工铵龙头溢价（行业第一，但供给回升）→ 加10%（vs原+15%收窄）
步骤四：新能源材料期权价值 → 加5%（vs原+10%减半，终止高压密后）
步骤五：硫磺风险折价（9100 vs 7300成本+7090 vs 5300）→ 减15%（vs原-10%扩大）
步骤六：白竹事故/安全生产折价 → 减5%（新增）

合理PE ≈ 12x × (1 - 0.35 + 0.10 + 0.05 - 0.15 - 0.05) = 12x × 0.60 ≈ **7.2x**

**基准市值（理性）** = EPS 0.273 × PE 7.2x × 18.88亿股 = **37.1亿元**

**基准目标价（不复权）** = 37.1亿 / 18.88亿股 = **1.96元**（极端理性，显示深度高估）

---

**但上述计算过于机械且市场对磷化工龙头实际给予更高溢价**。在实践中，A股市场对国有磷化工龙头在盈利稳定期的估值中枢为**15-20x PE**（考虑磷矿战略化溢价），但需对川发低ROE及高负债打折。采用**12-15x PE**作为合理区间（vs原15-20x下调一档）：

- 12x PE → 市值61.87亿，目标价**3.28元**
- 13x PE → 市值67.03亿，目标价**3.55元**
- 15x PE → 市值77.34亿，目标价**4.10元**

取区间**12-15x PE**，得到**基准市值62-77亿元**，**基准目标价3.28-4.10元**（vs原5.56-7.42元下修41%）。

**敏感性双表（审查补齐：极端理性锚 vs 市场实践锚）**：

## 八、逻辑证伪与极限压力测试（2026年8月更新）

### 8.1 黑天鹅场景模拟

**场景定义**："四重打击"同时发生——

1. **霍尔木兹海峡封锁持续至2027年H1**：硫磺维持9000-10000元/吨，保险200美元持续，川发综合成本+60亿/年无法传导
2. **白竹磷矿10/15复产不及预期，停产延长至2026年底**：再减净利3000万，全年磷矿外购成本+1亿
3. **磷酸铁/磷酸铁锂行业深度洗牌**：6万吨LFP产能利用率不足30%且四代产品认证失败，10万吨磷酸二氢锂延期，LFP板块全额计提减值（在建3.13亿+固定资产中约15亿新能源资产减值30%即4.5亿）
4. **资产负债率突破60%触发融资收缩**：货币资金45亿消耗，15亿中票到期无法续发，被迫变卖资产

**地狱价格评估（清算价值法，2026H1口径）**：
- 归母权益账面价值：96.70亿（2026H1）
- 减：商誉全额减值（12.67亿）
- 减：新能源材料资产减值（在建3.13亿+固定资产中约20亿新能源相关，减值30%即6.94亿）
- 减：存货跌价（21.88亿×15%≈3.28亿，因存货激增）
- 减：白竹事故额外损失+磷矿外购（0.5亿）
