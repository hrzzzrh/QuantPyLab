# 研报章节三：竞争格局与地位

**研究日期**：2026年08月29日

## 一、竞争格局全景扫描

### 1.1 光伏电池设备行业竞争地图

光伏电池设备行业围绕不同技术路线和工艺环节形成了高度分化的竞争格局。下表梳理了核心赛道与竞争参与方：

| 赛道 | 核心工艺环节 | 全球龙头 | 国内主要竞争者 | 进入壁垒 |
| :--- | :--- | :--- | :--- | :--- |
| TOPCon整线 | 全工序成套 | **捷佳伟创** | 拉普拉斯、北方华创、先导智能 | 极高（整线集成+工艺参数包） |
| TOPCon镀膜 | PECVD/LPCVD | **捷佳伟创/拉普拉斯** | 北方华创、微导纳米 | 高（工艺Know-how+客户验证周期） |
| TOPCon扩散 | 硼扩散 | **拉普拉斯** | 捷佳伟创、北方华创 | 高（热场设计+大产能） |
| HJT整线 | 全工序成套 | **迈为股份** | 捷佳伟创、金石能源 | 极高（70%+份额+学习曲线） |
| 钙钛矿设备 | RPD/PVD/涂布 | **捷佳伟创/迈为股份** | 德沪涂膜、众能光电 | 中高（多数处于中试/实验阶段） |
| 激光设备 | SE/消融/转印 | **帝尔激光** | 大族激光、海目星 | 高（激光+工艺专利壁垒） |
| 组件设备 | 串焊/层压 | **奥特维** | 先导智能、金辰股份 | 中（标准化程度较高） |

### 1.2 TOPCon设备：捷佳伟创的绝对根据地

捷佳伟创在TOPCon设备领域的市场地位难以撼动：

- **整线市占率**：58%-70%（根据行业调研），在TOPCon产线价值量占比70%-80%的核心品类中，除LPCVD外，公司在其余几大品类的市占率均超过50%
- **核心设备PE-Poly**：市占率超50%，其"三合一"工艺（隧穿层+Poly层+原位掺杂层）已成为TOPCon行业主流技术路线
- **客户覆盖**：直接供应隆基、通威、晶澳、晶科、天合等所有头部电池/组件厂商，参与全球超4000条电池产线建设
- **市场地位演变**：市占率从2023年的23%飙升至2024年的71.1%，核心驱动力是PE-Poly技术路线的行业主导地位确立

**但是**：TOPCon的"甜蜜陷阱"已经显现。当TOPCon产能从80GW暴增至800GW+后，扩张空间已近封顶。公司对TOPCon的高度依赖（2026H1工艺设备收入占比70.46%）正从"护城河"变成"风险敞口"——当整个赛道面临下行压力时，龙头地位无法提供下行保护，反而放大了业绩冲击。

**核心分歧点（H1验证）**：迈为股份H1降幅（营收-30.9%/归母-36.0%）显著优于捷佳（-67.4%/-79.5%），主因HJT并非2026年下行主赛道且海外占比高达68.21%（同比+140.64%）形成结构性对冲；捷佳作为"平台型"企业的规模优势在下行期反而因TOPCon赛道塌方而放大冲击。合同负债方面：捷佳H1止跌微增、迈为同比仍-20%但绝对额相近，二者均未出现如拉普拉斯的强劲订单回升，说明光伏设备整体仍处磨底，仅结构性分化。

**迈为的挑战**：研发费用率18.1%（2026H1达5.51亿同比+19.2%）、财务费用受汇兑拖累、高扣非与归母背离（公允价值变动11亿来自客户债务重组股票，占归母43.58%），盈利质量依赖非经常性支撑。

#### **拉普拉斯（688726）——隐形冠军的工艺卡位与订单韧性领跑**

| 2026H1归母/同比 | 3.75亿 / -79.53% | 3.16亿 / -20.36%（Q2环比+62.65%） |
| 2026H1扣非/同比 | 3.01亿 / -82.08% | 3.01亿 / -11.08%（Q2环比+64.73%） |

| 减值 | 信用0.32亿+资产0.155亿 | 信用及资产合计0.97亿（同比-45.8%，减值缓释） |

拉普拉斯通过LPCVD（550MW/年 vs 捷佳370MW/年）+硼扩散精准卡位TOPCon/XBC扩散瓶颈，深度绑定隆基、晶科等头部客户。**H1最显著的分化是订单**：拉普拉斯合同负债58.55亿较年初+79.9%、Q2单季营收13.42亿环比+38.65%且净利环比+62.65%，显示其在TOPCon存量技改（半片/多分片、边缘钝化EPD、激光Poly减薄、减银/去银）及海外需求中韧性显著强于捷佳；而捷佳虽止跌但未现强劲环比回升，相对份额承压。

#### **北方华创（002371）——光伏设备营收规模第一，但正加速向半导体切换，非直接可比**

北方华创2026H1营收201.61亿（+24.90%）、归母33.70亿（+5.05%）、OCF 37.74亿（+218%），毛利率40.07%（-2.10pct），研发26.77亿（+28.87%），电子工艺装备192.05亿占95.25%。其光伏设备（硅片炉等）对捷佳不构成直接竞争，但其业绩正增长与捷佳-67%形成强烈反差，核心在于其已全面转向半导体前道设备（刻蚀、薄膜、热处理、湿法、离子注入等）并受益于国产替代（SEMI预测2026全球半导体设备1659亿美元+23.2%）。

**启示**：北方华创证明半导体设备景气独立于光伏周期，而捷佳半导体子公司创微微电子H1尚未披露规模收入，仅有TGV清洗及卷绕镀膜2970万级小单，第二曲线尚处验证期，短期难以复刻北方华创的切换路径。

## 二、护城河识别

### 2.1 捷佳伟创的护城河结构分析

| 护城河类型 | 强度评级 | 关键证据（2026H1更新） | 可持续性评估 |
| :--- | :---: | :--- | :--- |
| **规模/成本壁垒** | ★★★★ | TOPCon整线交付能力，年产19,411管/台设备，中国电子专用设备行业前九名（1,158项专利）。海外马来西亚工厂投产。2026H1存货67.23亿+合同负债47.84亿规模仍领先但同比已大幅收缩 | 短期稳固，但产能扩张停止后规模优势消退，拉普拉斯在扩散环节单机产能领先 |
| **技术/专利壁垒** | ★★★★ | PE-Poly三合一工艺，1,158项专利（发明139项），唯一具备多技术路线整线解决方案。钙钛矿GW级设备出货及柔性HJT/钙钛矿叠层效率>28%，喷墨打印获SNEC双奖 | 在TOPCon路线具有持久性，但技术路线切换（如向HJT/BC）可能削弱；拉普拉斯在LPCVD的单机产能优势构成局部挑战 |
| **客户转换成本** | ★★★ | 整线交付+工艺参数包绑定，覆盖所有头部电池厂。但2026H1前五大客户占比42.52%的集中度未变，下游亏损期客户可完全停止采购 | 中等——设备属于资本品，下行期客户可完全停止采购，供应商融资余额25.14亿显示账期延长 |
| **品牌/声誉壁垒** | ★★★ | 连续9年行业前十，全球参与超4000条产线建设。 | 中等——品牌在行业下行期不足以驱动订单 |
| **网络效应** | ★★ | 通过多品类设备形成交叉销售能力。 | 弱——光伏设备行业不具备传统网络效应 |

**综合评价**：捷佳伟创的护城河主要建立在"技术+规模"层面，在TOPCon赛道具备深厚的竞争优势。但**光伏设备行业的护城河本质上是周期性的**——上行期的壁垒在下行期会迅速弱化。2026H1拉普拉斯以58.55亿合同负债超越捷佳47.84亿，说明在TOPCon技改细分需求中，工艺环节龙头的局部壁垒正在蚕食整线龙头的份额。

### 2.2 护城河的相对减损（H1验证）

与迈为、拉普拉斯相比，捷佳伟创在技术壁垒的"锐度"与订单韧性上已显不足：
- **HJT领域**：迈为70%+市占率且海外68%对冲，捷佳有布局但未形成主导，H1毛利率48.46% vs 捷佳30.30%差距拉大
- **TOPCon技改领域**：拉普拉斯LPCVD单机产能优势+EPD/减银等新设备快速获单，H1合同负债+79.9% vs 捷佳+3.78%，显示捷佳在该细分需求中未取得领先
- **研发强度**：迈为18.1%（5.51亿）、拉普拉斯7.1%（1.6亿） vs 捷佳8.28%（2.258亿绝对额回落），捷佳在下一代技术投入强度已落后于迈为
- **订单质量**：拉普拉斯Q2环比+38.6%已现拐点，捷佳Q2环比-17.7%仍处探底

**核心判断**：捷佳伟创在TOPCon赛道的护城河正在"老化"——技术壁垒仍在，但赛道本身正在萎缩且细分环节被对手蚕食。公司能否在新一代技术路线（HJT、钙钛矿）中复制TOPCon时代的成功，取决于钙钛矿喷墨打印、半导体湿法等第二曲线的商业化速度，目前仍处验证期。

## 三、产业链定价权评估

### 3.1 对上游的议价能力：较强（维持）

- 前五名供应商采购占比仅13.28%（2025年），分散度高
- 最大单一供应商采购占比3.37%
- 原材料以标准件（电子元器件、炉机柜等）+外协加工为主，供应链不依赖单一来源
- 2026H1应付账款64.23亿（较年初53.34亿+20.4%），其中供应商融资25.14亿（建信融通/工银E信），付款到期区间月结210-360天 vs 非融资可比30-90天，说明对供应商占款能力仍强

### 3.2 对下游的议价能力：弱化中但H1回款边际改善

- **正面信号**：
  1. 预收款模式（"3331"）仍存，合同负债47.84亿止跌且环比回升
  2. **2026H1应收账款33.56亿（-20.0% vs 年初）、合同资产6.70亿（-39.6%），合计40.26亿较年初53.06亿下降24.1%，回收明显改善**
  3. 广义应收回落带动信用减值仅0.32亿（vs H1 2025 1.97亿），占利润比7.95%显著回落
- **负面信号**：
  1. 绝对额仍高：广义应收约48亿（含票据6.25亿+融资1.75亿）占总资产18%+
  2. 客户集中度高——前五大客户占销售42.52%，单一客户可达12.13%，且重大合同通威280,273.97万、晶澳390,242.81万、某龙头257,267.11万合计927,783万占全年收入潜在权重高，客户议价仍强
  3. 下游客户全线亏损（2026H1龙头合计预亏超130亿），设备采购属"可选消费"性质，设备商议价空间仍受限
  4. 受限资金4.36亿+诉讼冻结4.18亿+短期借款激增至3.25亿显示流动性仍承压

### 3.3 定价权的动态演变

在下行周期中，捷佳伟创的定价权呈"剪刀差"修复分化：

```
上游（供应商）：议价权保持 → 应付64.23亿仍可占款，融资展期210-360天
下游（客户）：议价权仍强但回款边际改善 → H1 OCF 12.22亿修复 vs 2025 -12.04亿断裂
自身：夹在中间 → 毛利率30.30%韧性但收入-67%规模失速
```

**量化验证（2026H1更新）**：经营现金流12.22亿（+257%）、应收-20%+合同资产-39.6%双降、信用减值0.32亿同比-83.6%，显示公司通过多渠道回款及供应链金融工具阶段性修复了下游定价弱势，但收入67%下滑表明量价层面仍无定价权，且修复依赖收缩式支付减少，可持续性待Q3验证。

## 四、非财务竞争信号的交叉验证

### 4.1 订单层面：海外高毛利支撑但未扭转总量

公司2025年境外收入31.16亿元、同比增长79.13%，海外毛利率36.55%高于境内的26.16%，这是已披露的相对优势。**2026H1境外收入5.057亿元、毛利率53.09%（境内25.12%），境外占比18.55%较2025全年20.14%回落1.59pct，且绝对额较2025H1（推算约15-16亿）大幅下滑**，说明海外并未如自媒体“2026海外订单≥120亿”所渲染的爆发式增长，相对优势仅为结构性缓冲。

**特斯拉相关消息**：媒体曾援引知情人士称特斯拉可能采购中国光伏设备；公司并未对捷佳伟创的金额、技术路线、定金或交付时间作出正式确认，且2026H1中报及互动易均无相关进展披露，因此它只能属于乐观情景的可选催化，不能替代可验证订单。

**小额非光伏中标验证第二曲线早期**：2026H1唯一可验证重大中标为8-19珠海水发兴业双腔磁控溅射镀膜设备2970万元（车载智能调光玻璃ITO），另有7-23 TGV单片清洗获国内头部量产订单、8-20双腔卷绕磁控溅射中标（金额未披露），合计不足0.5亿，对全年收入贡献不足2%，尚处验证期。

### 4.2 招投标与产能信号（H1更新）

- 光伏设备招标：2025年组件招标198GW同比大幅收缩，2026H1主链产量同比-9.8%至-35.1%，设备商新签订单普遍萎缩。捷佳伟创H1披露“生产量同比下降72.41%（2025年报口径）延续至2026H1的存货+21%”，且重大合同仅披露通威/晶澳/某龙头存量合同的持续履行，无新增>10亿重大合同公告。
- 招标平台扫描：千里马/招标网仅命中客户内部物料单一来源公示（0.325元/W等），非设备对外中标，且供应商脱敏；央企/政府平台无捷佳设备中标候选人公示，验证新签动力不足。
- 竞对产能：拉普拉斯H1合同负债58.55亿（+79.9%）及迈为海外订单落地，显示对手在细分技术升级中抢得先机，捷佳整线模式在当前技改需求（边缘钝化、减银等）中未显优势。

### 4.3 技术路线竞争的风险敞口

TOPCon仍是当前主流（量产效率25.4%-25.7% vs 协鑫钙钛矿叠层26.5-28%已超越），但2026年钙钛矿GW级产线已进入小批量（协鑫昆山1GW、良率98%）、极电光能等6家龙头同台且叠层效率>30%（晶科34.82%），Tandem PV等海外企业已签署2.5GW意向。若未来2-3年钙钛矿叠层突破，捷佳伟创在TOPCon领域的产能和技术优势可能面临"价值重置"。公司虽对HJT和钙钛矿有所布局（H1交付柔性HJT/钙钛矿叠层效率>28%、钙钛矿整线及柔性整线），但在HJT领域市占远不如迈为（70%+ vs 未形成主导），在XBC领域不如拉普拉斯深耕。

### 4.4 竞争对手的跨越式演进（H1定量验证）

迈为与拉普拉斯在行业下行期实现了与捷佳的显著分化：

| 竞争指标 | 捷佳伟创 | 迈为股份 | 拉普拉斯 |
| :--- | :--- | :--- | :--- |
| H1营收同比 | -67.43% | -30.95% | -24.58% |
| H1归母同比 | -79.53% | -35.99% | -20.36% |
| Q2环比（营收/归母） | -17.7% / -61.5% | +17.6% / +13.6% | **+38.65% / +62.65%** |
| 合同负债 vs 年初 | +3.78% | -20.2% | **+79.9%** |
| H1毛利率 | 30.30% | 48.46% | 34.90% |

这表明在光伏设备行业的结构性分化中，**拉普拉斯（TOPCon技改设备）已率先实现Q2环比强劲修复，迈为（HJT+半导体）通过海外68%对冲实现跌幅收窄，而捷佳伟创作为TOPCon整线龙头仍处探底**，整线模式在当前市场对“技改降本”强于“新建扩产”的需求中处于劣势。

## 【逻辑继承：模块一/二的结论与模块三的交叉验证】

1. **M1发现的现金流修复（OCF 12.22亿）在M3的定价权分析中得到明确解释**：通过多渠道回款+供应链融资+采购收缩实现的收缩式修复，并非下游盈利改善驱动，需验证持续性

2. **M2判断的"行业下行期末段磨底"在M3的竞争格局分析中得到印证**：拉普拉斯合同负债+79.9%及Q2环比+62.65%表明结构性分化已经开始，HJT/海外及TOPCon技改赛道正在率先复苏，但捷佳伟创主场（TOPCon新建整线）尚未出现企稳信号，Q2环比仍负

3. **M1发现的风险（存货67.23亿、应收40.26亿）需要与M3的竞争地位结合看待**：公司H1合同负债47.84亿仅能提供47.84亿未来12个月收入天花板，显著低于拉普拉斯58.55亿，且存货中57.74亿发出商品需依赖客户验收，缓冲垫虽止跌但薄于同行；前期依赖的“280亿在手订单”未经公告核验，不能作为估值锚
