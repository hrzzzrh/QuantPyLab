# 研报章节四：外部边界与宏观政策

**研究日期**：2026年08月29日

---

## 一、宏观环境变量

### 1.1 利率与折现率：估值环境偏友好，但对实体传导有限

当前全球处于高利率逐步下行的过渡期，国内货币政策维持适度宽松。对捷佳伟创而言，利率环境的影响通过两条路径传导：

**路径一：DCF估值分母端**——偏正面。无风险利率中枢下行有利于成长性设备股的估值中枢抬升。但考虑到公司当前约17倍TTM PE（2026-08-28，基于TTM净利11.62亿已较7月末21.79亿腰斩）、Forward PE约31.1x（基于新中性EPS 1.87），估值折价主因在于盈利端的确定性崩塌而非利率环境，利率下行难以对冲67%的收入下滑。

**路径二：下游客户融资成本**——偏负面。光伏下游电站/制造业属于资本密集型行业。虽然国内利率下行，但海外（尤其是新兴市场）融资成本仍高企，这对海外光伏产能扩张的节奏形成抑制。此外，国内对光伏制造业的融资趋严——银行对亏损电池厂的信贷明显收紧，间接传导至设备采购需求。2026H1行业龙头合计预亏超130亿的背景下，信贷收缩已从预期变为现实。

### 1.2 汇率损益：双刃剑效应且权重上升

2025年，捷佳伟创财务费用从-1.38亿（净收益）恶化至-0.36亿（净收益收窄），主因利息收入减少和外币货币性项目汇率波动形成汇兑损失。**2026H1财务费用进一步恶化至3,048.80万（上年同期-5,903.24万），其中汇兑损益为4,872.53万损失（上年同期-1,935.33万收益），单项恶化681万元**，在归母3.75亿体量下占比12.9%，显著侵蚀利润。公司以外币计价的资产负债余额较大（2026H1末美元189,951,566.66、欧元799,119.07、日元40,233,037等）。

| 汇率变动方向 | 对捷佳伟创的影响 |
| :--- | :--- |
| 人民币升值 | 负面影响：境外收入折算后下降，汇兑损失增加（H1已兑现） |
| 人民币贬值 | 正面影响：境外收入折算后上升，汇兑收益增加 |
| 央行汇率市场化推进 | 增加波动性，需要持续的外汇对冲管理 |

2026H1境外收入5.057亿占比18.55%（2025全年31.16亿占比20.14%），但期末外币资产中美元货币资金12.94亿、欧元0.06亿、应收账款美元2.15亿等余额较大，叠加美元应付2,822万及美元其他流动资产3.4亿，敞口净额显著，H1汇兑损失已验证风险。公司虽运用外汇掉期、远期锁汇等衍生品，但H1公允价值变动中衍生金融工具-3,480.48万仍为亏损。

### 1.3 通胀传导与原材料成本

捷佳伟创的直接材料在营业成本中占81.26%（2025年），原材料以电子元器件、炉机柜、结构件等为主，对大宗商品价格的直接敏感度低于下游电池制造商。但近期银价高位震荡（TOPCon单瓦银耗9mg占非硅40%、银浆占电池成本50-62%）、铜铝等大宗商品价格上涨仍会通过以下路径间接传导：

```
大宗商品涨价 → 客户制造成本上升 → 利润空间收窄 → 
设备采购意愿下降 → 捷佳伟创订单增长受限
```

**银耗博弈最新进展（对上游成本边际影响）**：2026年行业正通过四条路径降银——晶科银包铜量产、百佳年代0BB低温焊接、通威铜互连100%无银（THC-G12达802W）、BC单瓦银耗降至8.2mg（铜电镀降65%）。银浆成本压力阶段性缓解有利于客户保现金流，但降银技术本身需要设备技改（边缘钝化、减银等），反而构成捷佳与拉普拉斯的技改订单来源，属结构性利好但总量有限。

## 二、地缘政治风险

### 2.1 美国贸易壁垒：从"堵产品"升级为"堵体系"

美国对华光伏贸易政策已经从针对终端产品（电池、组件）的双反关税，全面升级为对全产业链的系统性围堵。以下是核心政策的演变轨迹：

| 时间 | 事件 | 实质影响 |
| :--- | :--- | :--- |
| 2012年起 | 对中国光伏电池/组件征收双反关税 | 中国组件出口美国受阻，产能向东南亚转移 |
| 2022年 | 启动对东南亚四国（越/泰/马/柬）反规避调查 | 东南亚代工路径被封堵 |
| 2024-2025年 | 对东南亚四国征收惩罚性关税（柬埔寨3404%等） | 东南亚产能全线沦陷 |
| 2025年7月 | 针对印度、印尼、老挝发起反规避调查 | 第二波产能转移再次被堵 |
| 2026年3月 | 启动对TOPCon太阳能电池/组件的337调查 | 首次针对特定技术路线进行调查 |
| 2026年5月 | ITC对华光伏双反日落复审终裁，措施再延5年 | 对华光伏产品征税长期化 |
| 2026年5月 | 对埃塞俄比亚发起反规避调查 | 首次针对非洲大陆，追堵"中国供应链" |

**对捷佳伟创的具体影响（2026H1更新）**：

1. **正面但有限：设备出口美国目前享有关税豁免**。USTR已将包括太阳能制造设备在内的相关301豁免延长至2026年11月10日。这仅保留约2.5个月窗口（截至本报告日），并不构成已确认的公司订单或收入，且窗口期收窄风险上升。H1境外收入中美国占比未披露，但H1整体境外收入仅5.057亿同比大幅下滑，说明豁免并未转化为放量。

2. **负面：中国可能限制先进光伏设备对美出口**。2026年4月路透社报道，中国已与设备商初步磋商，考虑限制最先进光伏设备（包括HJT）向美国出口。虽然截至2026H1末尚未形成正式规则，但这一政策不确定性对捷佳伟创的美国业务构成重大风险——特别是钙钛矿等前沿设备可能面临管制。

3. **负面：海外产能扩张路径被封堵**。美国正在将贸易围堵从"中国制造"延伸到"中国供应链控制"——即使企业在非洲、拉美建厂，只要核心价值链仍由中国控制，就可能被征税。这对捷佳伟创的海外设备销售构成中长期隐忧。

4. **商务部反制**：中国商务部已于2026年3月27日对美国阻碍绿色产品贸易的做法启动贸易壁垒调查，贸易摩擦仍在升级中。

### 2.2 印度ALMM：本土化的加速与机遇（H1政策已生效）

印度光伏市场的政策取向对捷佳伟创喜忧参半：

- **ALMM List-I（组件清单）已生效**：政府项目只能用列表内的本土组件，已大幅限制中国组件出口印度
- **ALMM List-II（电池清单）2026年6月1日生效**：政府项目必须使用本土电池，电池片出口空间进一步收窄（H1电池片对印度3.62GW、印尼7.71GW后6月已因ALMM及美对印尼老挝AD/CVD初裁压缩）
- **ALMM List-III（硅锭/硅片清单）计划2028年6月执行**：倒逼硅片本土化

**但**，印度严重缺乏电池片制造设备能力。目前印度电池产能约27GW，而组件产能已达210GW，未来需要大规模补齐电池片制造能力。2026H1中国硅片、电池、组件出口额同比+24.3%（171.83亿）但6月电池片出口5.95GW同比-20%创年内新低，说明转口路径受限后，设备直接出口印度成为更确定的需求来源。这与美国对中国电池/组件的贸易壁垒形成反差——设备出口印度目前未受明显限制，但需本地化生产与服务体系（如捷佳马来西亚工厂+印度本地组装）。

### 2.3 欧盟NZIA：本土制造崛起，设备出海窗口收窄但仍存机会

欧盟《净零工业法案》（NZIA）要求2030年本土制造需满足40%的年度部署需求。欧盟基金补贴86亿欧元，成员国国家援助236亿欧元。在补贴驱动下，欧洲本土组件产能从5GW（2022年）跃升至15GW（2024年）。但电池片制造能力仍严重不足——这为捷佳伟创创造了设备出口欧洲的机会。H1调研显示欧洲、土耳其及日本客户均有明确HJT/高效设备需求（迈为披露），但欧洲市场更青睐HJT等差异化路线，捷佳TOPCon优势相对弱化。

### 2.4 出口退税取消：光伏产品端的冲击与设备端的相对免疫但传导仍存

2026年4月1日起，光伏产品（硅料、硅片、电池、组件、逆变器等249项）的增值税出口退税从9%降至0%。这一政策主要影响的是光伏产品（终端输出）出口，对光伏设备（捷佳伟创的主营产品）影响相对有限。但H1实证显示：

1. **客户成本上升**→利润空间被压缩→设备采购能力下降（H1电池组件出口额+14%但量-2.5%，量额背离表明价格博弈加剧）
2. **行业洗牌加速**→中小落后产能出清→短期加剧订单萎缩，长期利好龙头设备商（H1 TOPCon/硅片等环节已出现产能整合与资产处置案例）

## 三、监管与产业政策

### 3.1 136号文：新能源电价市场化改革的重磅冲击（H1实证强化）

2025年1月，国家发展改革委、国家能源局印发136号文，推动新能源上网电量全面市场化，2025年6月1日为存量/增量分界线。核心变化：

| 维度 | 改革前 | 改革后 |
| :--- | :--- | :--- |
| 定价机制 | 固定电价（燃煤基准价保障性收购） | 全电量市场交易形成电价 |
| 收益结构 | 保障性收入为主 | 市场交易收入 + 价差补偿 - 辅助服务分摊 |
| 投资确定性 | 高（固定电价保护） | 低（市场化波动） |
| 增量项目 | 享受同等保障 | 机制电价通过市场化竞价确定 |

**136号文对光伏设备需求链的传导（H1已兑现）**：

```
新能源电价市场化 
→ 投资收益率不确定性大幅上升（上海0.4155 vs 山东0.225极端分化）
→ 增量光伏项目开发趋于谨慎（H1新增72.07GW同比-66%，1-7月86.15GW同比-61.41%）
→ 电池片制造商的扩产意愿进一步下降（产量260.7GW -21.9%）
→ 光伏设备需求持续低迷（捷佳H1收入-67.43%显著陡于主链-21%至-35%）
```

各地竞价结果已显示出极端分化：上海机制电价0.4155元/kWh（接近上限）、山东光伏仅0.225元/kWh（接近下限）。西部"源多荷少"地区的低电价将显著抑制当地光伏投资，进而压缩设备采购空间。

**对捷佳伟创的直接影响**：国内下游客户的设备采购意愿在136号文后进一步恶化。即便7月单月装机同比+27.5%企稳，客户在面对不确定的电价前景时，仍将优先保护现金流而非扩大资本开支。136号文已成为2026年装机下降的核心政策驱动（与M2判断高度吻合）。

### 3.2 "反内卷"治理：从无序竞争到有序出清（H1效果分化）

2025年以来，国家层面持续推进光伏行业"反内卷"治理：

- **2024年底**：中国光伏协会设定组件中标价不低于0.68元/W的"地板价"（H1高频现货仍在0.68-0.69磨底，价格纪律未形成）
- **2025年7月**：中央财经委会议强调"依法依规治理企业低价无序竞争，推动落后产能有序退出"
- **2026年**：工信部将2026年定义为光伏行业治理的"攻坚期"，综合运用产能调控、标准引领、质量监督、价格执法等手段；三大规划首次提出全国风光平均置信出力达8%的可靠替代目标，标志从规模扩张转向系统支撑
- **2026年6月**：国家能源局公布2026年上半年各省光伏并网情况，前15省份占全国85%，集中度提升但整体规模大幅收缩

**政策效果评估（H1更新）**：
- 硅料环节"反内卷"成效较明显，库存31万吨但产能整合收购开始落地，然7月产量反增10.51万吨显示纪律不稳
- 电池/组件环节仍处于血拼阶段，2025年电池片均价0.289元/W、组件0.683元/W，2026H1虽产量收缩但价格仍在成本线附近
- 2026年预计从"全行业亏损"向"头部盈利、尾部出清"转变，但H1龙头合计预亏超130亿显示甚至头部仍深度亏损，出清进入深水区

对设备商的含义：**短期利空（出清过程中需求更弱），中长期利好（出清完成后龙头企业恢复采购能力）**。H1设备商合同负债分化（拉普拉斯+79.9%、捷佳+3.78%）验证龙头与尾部去化节奏不同步。

### 3.3 光伏设备出口管制风险：尚未落地但需高度警惕

2026年2月，中国相关部委已就先进光伏设备出口限制征求行业意见。核心关切在于：
- 中国光伏设备占全球超80%市场份额
- 限制先进设备出口可间接维护中国光伏产品的全球市场地位
- 保持光伏制造技术的"代际差"

潜在的管控方向可能是"建立设备分级目录"：≤26%效率的成熟技术设备鼓励出口，>26%的高端设备实施管控。若实施，对捷佳伟创的影响取决于其出口设备的技术代际。TOPCon设备（效率~25-26%）可能在豁免范围内，但HJT/钙钛矿等前沿设备可能面临限制。**H1该风险尚未落地，但需纳入地缘折价项；公司马来西亚工厂（SC NEW ENERGY MALAYSIA，资产12.33亿）可部分规避原产地限制**。

## 【逻辑继承：前序模块结论与模块四的交叉验证】

1. **M1发现的现金流修复（OCF 12.22亿）在M4中得到政策层面的阶段性解释**：一方面是136号文+反内卷导致下游资金紧张后的收缩式改善（采购收缩+多渠道回款），另一方面是汇率汇兑4,872万损失显示政策未形成正向拉动

2. **M2判断的"2026年装机回调-66%"与M4的136号文分析高度吻合且已实证**：新能源电价市场化改革是2026年装机下降的核心政策驱动，且H1数据与NEA 86.15GW/7月14.08GW企稳共同验证

3. **M3发现的"海外收入高增但占比仍低且H1回落至18.55%"在M4中面临政策不确定性**：中国设备出口管制若落地，将削弱海外增长的最大驱动力，马来西亚工厂仅为部分对冲

4. **美国进口设备关税豁免延长至2026-11-10仅剩2.5个月窗口**：H1境外收入并未放量验证窗口价值，特斯拉订单（若存在）必须在2026年秋季前完成交付，否则将面临关税重定价
