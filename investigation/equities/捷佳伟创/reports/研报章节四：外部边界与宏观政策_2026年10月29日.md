# 研报章节四：外部边界与宏观政策

**研究日期**：2026年10月29日

---

## 一、宏观环境变量

### 1.1 利率与折现率：估值环境偏友好，但对实体传导有限

当前全球处于高利率逐步下行的过渡期，国内货币政策维持适度宽松。对捷佳伟创而言，利率环境的影响通过两条路径传导：

**路径一：DCF估值分母端**——偏正面。无风险利率中枢下行有利于成长性设备股的估值中枢抬升。但截至2026-10-29，公司TTM PE已升至31.9x（TTM归母5.62亿，按Q3报告自算；统一视图仍显示15.42x，因其TTM分母停留在H1的11.62亿、Q3公告日2026-10-30晚于最后交易日，属于无穿越口径差异）、Forward PE约16.6x（2027E中性EPS 3.10元）、2026E Forward PE约19.7x（EPS 2.61元）。估值的主要矛盾已从"盈利崩塌"转为"盈利修复的可持续性"，利率下行是次要变量。

**路径二：下游客户融资成本**——偏负面。光伏下游电站/制造业属于资本密集型行业。虽然国内利率下行，但海外（尤其是新兴市场）融资成本仍高企，这对海外光伏产能扩张的节奏形成抑制。此外，国内对光伏制造业的融资趋严——银行对亏损电池厂的信贷明显收紧，间接传导至设备采购需求。2026H1行业龙头合计预亏超130亿的背景下，信贷收缩已从预期变为现实；Q3晶科单季亏损收窄至约5亿，但尚未恢复自我造血。

### 1.2 汇率损益：双刃剑效应且权重上升

2025年，捷佳伟创财务费用从-1.38亿（净收益）恶化至-0.36亿（净收益收窄），主因利息收入减少和外币货币性项目汇率波动形成汇兑损失。**2026前三季度财务费用0.639亿（上年同期-0.479亿），其中H1汇兑损失4,872.53万（上年同期-1,935.33万收益），前三季度利息收入3,158万（上年同期6,270万）**，在归母6.33亿体量下，汇兑与利息收入下降合计侵蚀约1.1亿。公司以外币计价的资产负债余额较大（2026H1末美元189,951,566.66、欧元799,119.07、日元40,233,037等）。

| 汇率变动方向 | 对捷佳伟创的影响 |
| :--- | :--- |
| 人民币升值 | 负面影响：境外收入折算后下降，汇兑损失增加（H1已兑现） |
| 人民币贬值 | 正面影响：境外收入折算后上升，汇兑收益增加 |
| 央行汇率市场化推进 | 增加波动性，需要持续的外汇对冲管理 |

2026H1境外收入5.057亿占比18.55%（2025全年31.16亿占比20.14%），但期末外币资产中美元货币资金12.94亿、欧元0.06亿、应收账款美元2.15亿等余额较大，叠加美元应付2,822万及美元其他流动资产3.4亿，敞口净额显著，H1汇兑损失已验证风险。公司虽运用外汇掉期、远期锁汇等衍生品，但H1公允价值变动中衍生金融工具-3,480.48万仍为亏损。**2026-10-29公司董事会审议、10-30公告《关于开展外汇衍生品交易业务的议案》，说明管理层已将对冲上升到制度层面；具体额度与方向待公告，短期不改变汇兑敞口。**

### 1.3 通胀传导与原材料成本

捷佳伟创的直接材料在营业成本中占81.26%（2025年），原材料以电子元器件、炉机柜、结构件等为主，对大宗商品价格的直接敏感度低于下游电池制造商。但银价高位震荡（TOPCon单瓦银耗9mg占非硅40%、银浆占电池成本50-62%）、铜铝等大宗商品价格上涨仍会通过以下路径间接传导：

```
大宗商品涨价 → 客户制造成本上升 → 利润空间收窄 → 
设备采购意愿下降 → 捷佳伟创订单增长受限
```

**银耗博弈最新进展（对上游成本边际影响）**：2026年行业正通过四条路径降银——晶科银包铜量产、百佳年代0BB低温焊接、通威铜互连100%无银（THC-G12达802W）、BC单瓦银耗降至8.2mg（铜电镀降65%）。银浆成本压力阶段性缓解有利于客户保现金流，但降银技术本身需要设备技改（边缘钝化、减银等），反而构成捷佳与拉普拉斯的技改订单来源，属结构性利好但总量有限。

## 二、地缘政治风险

### 2.1 美国贸易壁垒：从"堵产品"升级为"堵体系"

美国对华光伏贸易政策已经从针对终端产品（电池、组件）的双反关税，全面升级为对全产业链的系统性围堵。以下是核心政策的演变轨迹：

| 时间 | 事件 | 实质影响 |
| :--- | :--- | :--- |
| 2012年起 | 对中国光伏电池/组件征收双反关税 | 中国组件出口美国受阻，产能向东南亚转移 |
| 2022年 | 启动对东南亚四国（越/泰/马/柬）反规避调查 | 东南亚代工路径被封堵 |
| 2024-2025年 | 对东南亚四国征收惩罚性关税（柬埔寨3404%等） | 东南亚产能全线沦陷 |
| 2025年7月 | 针对印度、印尼、老挝发起反规避调查 | 第二波产能转移再次被堵 |
| 2026年3月 | 启动对TOPCon太阳能电池/组件的337调查 | 首次针对特定技术路线进行调查 |
| 2026年5月 | ITC对华光伏双反日落复审终裁，措施再延5年 | 对华光伏产品征税长期化 |
| 2026年5月 | 对埃塞俄比亚发起反规避调查 | 首次针对非洲大陆，追堵"中国供应链" |
| 2026年10月 | 美国对晶体硅光伏电池双反产业损害终裁落地 | 市场准入门槛系统性抬升，东南亚转口通道进一步收窄 |

**对捷佳伟创的具体影响（2026Q3）**：

1. **正面但即将到期：设备出口美国目前享有关税豁免**。USTR已将包括太阳能制造设备在内的178项301豁免延长至**2026年11月9日23:59（美东时间）/11月10日**。截至2026-10-29，**无任何官方延期公告**；USTR 2026-10-26联邦公报仅就"海事/物流行动"提议再暂停两个月至2027-01-09，与太阳能设备豁免不是同一事项。窗口仅剩约11天，若到期不续，美国设备进口将恢复301关税，捷佳美国TOPCon设备业务（市占率约60%）的交付成本将上升。H1境外收入仅5.057亿、同比大幅下滑，说明豁免并未转化为放量；Q3毛利率跳升若含美国订单，则窗口价值在Q3已部分兑现。

2. **负面：中国可能限制先进光伏设备对美出口**。2026年4月路透社报道，中国已与设备商初步磋商，考虑限制最先进光伏设备（包括HJT）向美国出口。截至2026Q3末尚未形成正式规则，但这一政策不确定性对捷佳伟创的美国业务构成重大风险——特别是钙钛矿等前沿设备可能面临管制。

3. **负面：海外产能扩张路径被封堵**。美国正在将贸易围堵从"中国制造"延伸到"中国供应链控制"——即使企业在非洲、拉美建厂，只要核心价值链仍由中国控制，就可能被征税。2026年10月双反终裁落地后，市场关注"反规避"是否跟进，这将决定印度/中东产能对美溢出的空间。对捷佳伟创的海外设备销售构成中长期隐忧。

4. **商务部反制**：中国商务部已于2026年3月27日对美国阻碍绿色产品贸易的做法启动贸易壁垒调查，贸易摩擦仍在升级中。

### 2.2 印度ALMM：本土化的加速与机遇（H1政策已生效）

印度光伏市场的政策取向对捷佳伟创喜忧参半：

- **ALMM List-I（组件清单）已生效**：政府项目只能用列表内的本土组件，已大幅限制中国组件出口印度
- **ALMM List-II（电池清单）2026年6月1日生效**：政府项目必须使用本土电池，电池片出口空间进一步收窄（H1电池片对印度3.62GW、印尼7.71GW后6月已因ALMM及美对印尼老挝AD/CVD初裁压缩）
- **ALMM List-III（硅锭/硅片清单）计划2028年6月执行**：倒逼硅片本土化

**但**，印度严重缺乏电池片制造设备能力。目前印度电池产能约27GW，而组件产能已达210GW，2026年印度新增电池产能以TOPCon为主、技术选型一步到位，对整线设备需求确定。2026H1中国硅片、电池、组件出口额同比+24.3%（171.83亿）但6月电池片出口5.95GW同比-20%创年内新低，说明转口路径受限后，设备直接出口印度成为更确定的需求来源。这与美国对中国电池/组件的贸易壁垒形成反差——设备出口印度目前未受明显限制，但需本地化生产与服务体系（如捷佳马来西亚工厂+印度本地组装）。**印度是捷佳2027年海外订单最可验证的增量来源，但单GW价值量与毛利率低于美国，且面临拉普拉斯/迈为的本地化竞争。**

### 2.3 欧盟NZIA：本土制造崛起，设备出海窗口收窄但仍存机会

欧盟《净零工业法案》（NZIA）要求2030年本土制造需满足40%的年度部署需求。欧盟基金补贴86亿欧元，成员国国家援助236亿欧元。在补贴驱动下，欧洲本土组件产能从5GW（2022年）跃升至15GW（2024年）。但电池片制造能力仍严重不足——这为捷佳伟创创造了设备出口欧洲的机会。H1调研显示欧洲、土耳其及日本客户均有明确HJT/高效设备需求（迈为披露），但欧洲市场更青睐HJT等差异化路线，捷佳TOPCon优势相对弱化。

### 2.4 出口退税取消：光伏产品端的冲击与设备端的相对免疫但传导仍存

2026年4月1日起，光伏产品（硅料、硅片、电池、逆变器等249项）的增值税出口退税从9%降至0%。这一政策主要影响的是光伏产品（终端输出）出口，对光伏设备（捷佳伟创的主营产品）影响相对有限。但H1实证显示：

1. **客户成本上升**→利润空间被压缩→设备采购能力下降（H1电池组件出口额+14%但量-2.5%，量额背离表明价格博弈加剧）
2. **行业洗牌加速**→中小落后产能出清→短期加剧订单萎缩，长期利好龙头设备商（H1 TOPCon/硅片等环节已出现产能整合与资产处置案例）

## 三、监管与产业政策

### 3.1 136号文：新能源电价市场化改革的重磅冲击（H1已兑现，Q3边际修复）

2025年1月，国家发展改革委、国家能源局印发136号文，推动新能源上网电量全面市场化，2025年6月1日为存量/增量分界线。核心变化：

| 维度 | 改革前 | 改革后 |
| :--- | :--- | :--- |
| 定价机制 | 固定电价（燃煤基准价保障性收购） | 全电量市场交易形成电价 |
| 收益结构 | 保障性收入为主 | 市场交易收入 + 价差补偿 - 辅助服务分摊 |
| 投资确定性 | 高（固定电价保护） | 低（市场化波动） |
| 增量项目 | 享受同等保障 | 机制电价通过市场化竞价确定 |

**136号文对光伏设备需求链的传导（H1已兑现，Q3边际修复）**：

```
新能源电价市场化 
→ 投资收益率不确定性大幅上升（上海0.4155 vs 山东0.225极端分化）
→ 增量光伏项目开发趋于谨慎（H1新增72.07GW同比-66%，1-9月110.83GW同比-53.87%）
→ 电池片制造商的扩产意愿进一步下降（H1产量260.7GW -21.9%）
→ 光伏设备需求持续低迷（捷佳Q3收入-72.19%，显著陡于主链）
→ 但9月单月装机13.64GW同比+41.2%、连续两月正增长，电价机制边际修复
```

各地竞价结果已显示出极端分化：上海机制电价0.4155元/kWh（接近上限）、山东光伏仅0.225元/kWh（接近下限）。西部"源多荷少"地区的低电价将显著抑制当地光伏投资，进而压缩设备采购空间。**2027年上半年四省竞价触底回升（甘肃0.2447元/度、新疆光伏0.259元/度）但机制电量保障比例下调（新疆80%→50%），属于"价格修复、电量保障下降"的结构性改善，对设备需求的传导仍需6-12个月。**

**对捷佳伟创的直接影响**：国内下游客户的设备采购意愿在136号文后进一步恶化。即便9月装机同比+41.2%，客户在面对不确定的电价前景时，仍将优先保护现金流而非扩大资本开支。136号文仍是2026年装机下降的核心政策驱动（与M2判断高度吻合）。

### 3.2 "反内卷"治理：从价格自律走向准入引导（Q4关键变化）

2025年以来，国家层面持续推进光伏行业"反内卷"治理：

- **2024年底**：中国光伏协会设定组件中标价不低于0.68元/W的"地板价"
- **2025年7月**：中央财经委会议强调"依法依规治理企业低价无序竞争，推动落后产能有序退出"
- **2026年**：工信部将2026年定义为光伏行业治理的"攻坚期"；三大规划首次提出全国风光平均置信出力达8%的可靠替代目标
- **2026年7月2日**：工信部、发改委、市场监管总局联合发布三项光伏能耗能效强制性国家标准
- **2026年7月27日**：中国光伏行业协会牵头编制的《光伏行业成本核算模型通则》实施，首次统一全产业链成本核算口径
- **2026年8月6日**：8家多晶硅龙头签署《反内卷倡议书》，承诺售价不低于完全成本
- **2026年10月11日**：8家龙头在杭州召开第三次闭门会，细化产能限制落地计划，提出硅料含税成本底线4.3万元/吨、TOPCon组件0.79元/W、BC组件0.86元/W的价格底线（无法律约束力）
- **2026年10月16日**：工信部发布《光伏制造行业规范条件（2026年本）》《光伏制造行业规范公告管理办法（2026年本）》征求意见稿（反馈截止11月15日）。核心变化：全面删除多晶及P型技术条目；新建电池效率门槛提至26.0%-26.6%、组件24.0%-24.4%；新建及改扩建最低资本金比例30%；多晶硅新建电耗按三氯氢硅法37kWh/kg、颗粒硅15kWh/kg，水耗30立方米/吨；行业自律结果首次成为进入规范公告名单的实质性参考
- **2026年10月20日**：工信部在国新办发布会表示"持续完善光伏新型储能等产能监测预警机制""深化重点领域无序非理性竞争综合整治"

**政策效果评估（Q3更新）**：
- 硅料环节"反内卷"成效初现：9月底库存57.2万吨、9月产量12.04万吨（环比+1.3%），10月预计降至10.5万吨（环比-12.9%），N型复投报价3.20-4.30万元/吨（口径差异），但库存去化仍需时间
- 电池/组件环节仍处血拼：2026H1电池产量260.7GW（-21.9%）、组件201.3GW（-35.1%），组件实际成交0.65-0.73元/W，低于全成本
- 机构测算：若规范条件2027年1月1日执行，电池组件尾部产能淘汰比例可达30%甚至更高；2027年全球需求约+10%、组件需求>600GW

对设备商的含义：**短期利空（出清过程中需求更弱），2027年转为结构性利好（合规置换+技改）**。Q3捷佳/迈为合同负债回升（捷佳60.15亿、迈为52.1亿，拉普拉斯Q3待验证）已提前反映这一预期；但收入确认要到2027年，2026Q4仍是"订单改善、收入探底"的组合。

### 3.3 光伏设备出口管制风险：尚未落地但需高度警惕

2026年2月，中国相关部委已就先进光伏设备出口限制征求行业意见。核心关切在于：
- 中国光伏设备占全球超80%市场份额
- 限制先进设备出口可间接维护中国光伏产品的全球市场地位
- 保持光伏制造技术的"代际差"

潜在的管控方向可能是"建立设备分级目录"：≤26%效率的成熟技术设备鼓励出口，>26%的高端设备实施管控。若实施，对捷佳伟创的影响取决于其出口设备的技术代际。TOPCon设备（效率~25-26%）可能在豁免范围内，但HJT/钙钛矿等前沿设备可能面临限制。**截至2026Q3末该风险尚未落地，但需纳入地缘折价项；公司马来西亚工厂（SC NEW ENERGY MALAYSIA，资产12.33亿）可部分规避原产地限制。**

## 四、外部变量的综合评估矩阵（2026Q3）

## 【逻辑继承：前序模块结论与模块四的交叉验证】

1. **M1发现的毛利率跃升（Q3 41.46%）在M4中得到部分政策解释**：海外高毛利订单（若含美国301豁免窗口内的交付）与国内技改订单（反内卷/规范条件预期）共同支撑；但汇兑损失0.639亿与利息收入下降仍是负面拖累。

2. **M2判断的"2026年装机深度回调、Q3边际修复"与M4的136号文分析吻合**：1-9月110.83GW（-53.87%）、9月13.64GW（+41.2%），政策冲击的边际影响在减弱，但电价市场化对项目IRR的压制仍在。

3. **M3发现的"海外收入占比H1回落至18.55%"在M4中面临政策不确定性**：美国301豁免11-09到期且无延期，中国设备出口管制未落地，马来西亚工厂仅为部分对冲；印度ALMM驱动的设备需求是2027年最确定的海外增量。

4. **行业研报复用与时效性评估**：复用《中国光伏行业深度研究报告_2026年10月17日》（数据截至2026-10-16），其核心判断"产能出清已开始、盈利反转尚未确认、价格未反转、136号文重定需求质量"与本章Q3实证一致，无相悖。该研报尚未纳入：①NEA 9月装机13.64GW（10-26发布）；②工信部规范条件2026本（10-16发布，晚于其数据截止日但同日）；③Q3设备商财报（10-27至10-29）。上述均为增量而非相悖，**当前无需发起行业研报更新；建议在11月行业研报例行更新时纳入9月装机与Q3设备商数据**。
