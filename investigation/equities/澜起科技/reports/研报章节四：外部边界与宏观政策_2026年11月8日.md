# 研报章节四：外部边界与宏观政策

**研究日期**：2026年11月8日 | **目标年份**：2027E | **本次更新**：纳入美联储10-28维持3.75-4%、BIS 50%规则暂缓至2027-01-10、美国中期选举后州级数据中心审批风险；前三季度汇兑损失2.38亿元

**前序模块核心结论回顾**：
1. 模块一：2026前三季度营收54.14亿（+33.4%）、归母32.37亿（+98.3%）、扣非23.27亿（+58.6%）；Q3单季五项指标创历史新高，Q4在手订单25.0-27.9亿元。
2. 模块二：2026Q4-2027年景气确定（服务器CPU +43%、DRAM紧缺延续），2028年面临产能释放与需求放缓双重风险。
3. 模块三：内存接口全球第一（36.8%），PCIe Retimer全球第二但Astera系统级领先扩大；CXL阵地出现Astera Leo系列正面竞争。

## 一、宏观环境变量

### 1.1 利率与折现率环境

**当前环境**：美联储2026年9月16日加息25bp至3.75%-4.00%（2023年7月以来首次），**10月28日会议以10-2维持不变**，两位委员（Cook、Hammack）主张再加25bp；声明将经济增长由"稳健"上调为"强劲"，强调通胀仍高、保留加息选项，市场预期12月可能再加息。全球利率环境对高估值成长股构成**逆风**：
- **美联储**：政策利率3.75-4.00%，年内已加息一次、年底前仍可能再加；10年期美债收益率在5%以上高位震荡。无风险利率上行对DCF远期现金流折现构成压制——对澜起这类大量价值在远期的成长股不利。
- **中国央行**：2025-2026年维持相对宽松（定向降准、LPR下调）以支持科技与制造业投资，流动性对科创板整体估值水位形成一定支撑。

**对澜起科技的具体影响**：公司估值弹性对利率敏感度高。当前PE TTM 47.70倍（视图实测，PB 8.27）、2027E Forward PE约38.2x；利率高位压缩高估值成长股估值中枢，11月5-6日AI硬件板块集体抛售（SOX单日-12.25%、澜起A股11-06 -8.36%至150.10元）即为利率、融资成本与政策预期共振的直接映射。

### 1.1.1 AI融资/信贷传导风险

本轮AI硬件抛售的核心新变量并非需求端，而是**融资端与政策端**：
- **融资端**：CoreWeave债券收益率仍处15%以上、价格低于面值80%；3Q26亚马逊/谷歌/Meta的资本开支已超过各自经营现金流，自由现金流恶化。高盛测算2027年超大规模云CapEx约1.2万亿美元、经营现金流约1.1万亿美元，至少35%建设开支需依赖发债（超4000亿美元）；高盛信用策略团队警示"信贷紧缩+资本成本抬升导致算力基建延期，半导体供应链2027-2028年恐直面订单断档"。
- **需求端**：3Q26四大云厂资本开支合计约2,170亿美元（同比+87%）、backlog达1.7万亿美元，且均指引2027年资本开支"显著/大幅"增长；摩根大通/UBS将2027年AI支出上修至1.4-1.5万亿美元。**但2026-11中期选举改变了美国州级监管地图**：得州、佐治亚、密歇根、俄亥俄、新墨西哥等新当选州长均主张暂停数据中心审批，高盛测算相关州约占美国规划容量40-45%（德州约25%），新州长最早2027-01-19就职。若审批冻结落地，美国2027-2028年数据中心投产节奏将被动延后——这是"总量上修、节奏下修"的组合，对澜起意味着2027年订单能见度仍高（Q4在手订单已锁定），但2027H2-2028年的斜率面临政策性下修。
- **对澜起的影响**：澜起位于AI资本开支传导链最上游（CSP CapEx→服务器→内存模组→内存接口芯片），若融资端收紧或州级审批推迟导致AI基建延期，公司2027H2-2028年订单存在断档风险——本报告2027E保守情景（37.4亿）已计入该风险，并将其列为S类（不可预测、不进入基准）。

### 1.2 汇率损益分析

| 维度 | 影响分析 |
|:---|:---|
| **收入端** | 公司营收以美元和韩元结算为主（主要客户为三星/SK海力士/美光），人民币贬值有利于收入端折算，人民币升值则侵蚀收入。2026年前三季度人民币升值致汇兑损失2.38亿元（上年同期0.17亿元），其中Q3单季约0.64亿元（H1为1.74亿元），敞口主要来自H股募集资金沉淀的外币资产。 |
| **成本端** | 晶圆代工费用以美元计价，与收入端币种基本匹配，形成自然对冲。 |
| **汇率风险敞口** | 公司2026Q3末持有货币资金157.99亿元（视图实测，与三季报一致）+交易性金融资产30.69亿元，其中美元/港元占比高。前三季度财务费用为-1.03亿元（净收益），主因利息收入3.43亿元部分对冲了汇兑损失；若人民币继续升值，汇兑损失仍是利润的负向扰动（188.7亿元外币资产、5%升值对应约9亿元潜在影响，公司已做部分结汇对冲）。 |

### 1.3 通胀传导效率

全球半导体产业链通胀压力正在缓解。2023-2024年经历过一轮晶圆代工涨价周期后，2025-2026年台积电等代工厂涨价幅度趋缓（约5-10%年涨）。澜起科技通过产品子代升级（ASP提升15-20%）和产品结构优化（高毛利运力芯片占比提升），有效对冲了上游成本上涨。**但2026Q3起出现新的成本侧信号：管理层明确提示"随着行业需求持续提升，供给端面临交期变长、成本增加等压力"。**这意味着2027年毛利率的进一步扩张需要以产品结构升级跑赢代工/封测涨价，不能简单外推Q3的68.4%。**通胀对公司的负面影响整体可控，但边际上由"顺风"转为"中性偏逆风"。**

## 二、地缘政治风险

### 2.1 美国对华半导体管制：系统性升级进行时

2026年，美国对华半导体管制进入"立法化+多边化"新阶段，是澜起科技面临的最核心外部风险：

| 管制工具 | 核心内容 | 对澜起科技的潜在影响 |
|:---|:---|:---|
| **MATCH法案**（2026年4月） | 强制盟友150天内对齐管制标准，禁运DUV光刻机及关键设备 | 间接影响：限制中国先进制程芯片制造能力，可能影响公司在中国本土的代工选择 |
| **EDA出口管制升级**（2026年5月） | 限制3D991/3E991类EDA软件对华出口 | 潜在影响：如果管制范围扩展至先进制程IP/PDK，可能限制公司向更先进工艺节点迁移的能力 |
| **《AI OVERWATCH法案》等6项法案** | 建立AI芯片出口"全域管制框架"，动态围堵中国算力获取 | 间接利好：管制越严，国产替代需求越强，作为国内唯一PCIe 5.0 Retimer供应商受益 |
| **BIS 50%关联方规则（暂缓中）** | 2025-09-29发布，将实体清单等限制自动适用于被列名方持股≥50%的外国实体；**2026-11-05 BIS将暂缓期延长至2027-01-10**（11-09刊登），规则未废止 | 中性偏正：暂缓延续降低短期供应链穿透审查风险；但2027-01-10后仍可能恢复，公司需保持股权穿透自查 |

### 2.2 公司的应对策略评估

澜起科技在地缘政治上的风险管理展现出较好的前瞻性：

1. **"绕开美国市场"的主动选择**：公司在北美市场的直接销售收入占比不足1%，主动避免了出口管制的直接冲击。核心客户集中于韩国（三星、SK海力士）和亚洲区域，有效规避了中美科技冲突的正面波及。

2. **暂缓AI芯片研发**：2024年Q4公司决定暂缓投入长达5年的AI算力芯片研发项目（IPO募投项目，原计划投入5亿元），将资源转移至PCIe Switch芯片。这一决策具有深刻的战略意义——AI芯片的先进制程（7nm以下）极度依赖台积电代工，在中美脱钩背景下存在供应链被切断的风险；而PCIe互连芯片可用更成熟的工艺节点实现，供应链安全性更高。

3. **A+H双平台架构**：2026年2月港股上市，不仅拓宽了融资渠道，更建立了"离岸资本平台"，为海外并购、引入国际人才、规避单一市场风险提供了战略弹性。

4. **新加坡亚太总部+首尔研发中心**："产业链跟随"策略使得公司在物理上嵌入韩国DRAM产业生态，即使中美关系进一步恶化，也不影响与核心客户的日常协作。

### 2.3 地缘风险的"双向不对称性"

经过审慎分析，澜起科技面临的地缘政治风险呈现**非对称性**——负面冲击可控，但正面受益可期：

**负面冲击（有上限）**：
- 最坏情况是中国芯片设计公司被全面限制使用美国EDA工具——这会影响先进制程设计，但澜起科技的内存接口芯片目前使用成熟工艺（台积电12nm/16nm等），受先进制程制裁的冲击有限；
- 晶圆代工被限制——公司Fabless模式下高度依赖台积电/中芯国际等代工厂，但内存接口芯片属于"非军事、非AI训练"的通用芯片品类，被直接列入实体清单的概率较低。

**正面受益（有空间）**：
- 信创/国产替代政策倾斜：在中国半导体自主可控的大背景下，澜起科技作为大陆唯一的PCIe 5.0 Retimer供应商和内存接口芯片全球龙头，将获得政策性采购优先；
- 中国大陆云厂商（阿里、腾讯、字节等）的AI资本开支增长，产生的国产替代需求直接利好澜起。

### 2.4 美国州级数据中心审批：需求侧政策风险（S类）

2026-11美国中期选举后，得州（Gina Hinojosa击败Abbott，承诺"暂停所有数据中心审批"至议会立法）、佐治亚、密歇根、俄亥俄、新墨西哥等新当选州长均以限制数据中心为竞选主张，纽约、俄勒冈拟延长既有暂停令。高盛测算相关州约占美国规划数据中心容量的**40-45%**，其中德州约25%；新州长最早2027-01-19就职，具体暂停范围（是否涉及已获许可/已签供电协议项目）尚未明确。

**传导路径**：州级审批暂停→数据中心投产延期→服务器采购订单后移→内存模组与接口芯片需求节奏放缓。对澜起的时点含义：2026Q4-2027H1订单已由在手订单和CPU平台升级锁定，风险主要集中在2027H2-2028年。**处理方式**：归入S类（material但不可预测），给30-40%发生概率，不进入P50基准，仅在保守情景与风险提示中体现，不在PE中重复折价。

## 三、监管与产业政策

### 3.1 中国半导体产业政策：持续加码

| 政策方向 | 具体措施 | 对澜起科技的影响 |
|:---|:---|:---|
| **"十四五"集成电路专项** | 重点扶持EDA、芯片设计、先进封装等环节 | 澜起作为科创板龙头设计公司，享受研发费用加计扣除、人才引进补贴等优惠 |
| **大基金三期** | 规模约3000亿元，重点投向设备和材料 | 间接利好：制造能力的提升为设计公司提供更稳定的本土代工选项 |
| **国产替代采购政策** | 国企/政府项目优先采购国产芯片 | 直接利好：加快PCIe Retimer等产品在国内政企市场的渗透 |
| **科创板支持** | 允许未盈利企业上市、放宽股权激励 | 澜起2019年首批上市受益，但当前影响边际递减（已盈利） |

### 3.2 行业准入壁垒

内存接口芯片行业存在天然的"JEDEC标准+客户认证"双重准入壁垒，政策端不构成额外的限制。相反，中国政府对集成电路设计行业的扶持政策（进口设备免税、人才落户、研发补贴等）持续降低了公司的运营成本。

## 四、模块四核心结论

1. **利率环境仍为逆风，但已进入"观察期"**：美联储10-28维持3.75-4.00%不变（10-2票、两位主张加息），市场预期12月仍可能再加；无风险利率高位压缩高估值成长股的估值中枢。澜起PE TTM已自10月中的64.7x压缩至47.7x，但2027E Forward PE仍约38.2x，利率敏感度依然高。

2. **地缘政治风险是公司长期最核心的外部变量，但短期边际缓和**：BIS"50%关联方规则"暂缓期延长至2027-01-10、本窗口无新增实体清单，贸易休战延续；澜起主动绕开美国市场（北美收入<1%）、暂缓AI芯片、A+H双平台、韩国生态嵌入，将负面冲击控制在可承受范围。公司产品使用成熟工艺，受先进制程制裁波及有限。

3. **更紧迫的外部变量是美国州级数据中心审批**：相比出口管制，这一政策风险直接作用于需求侧，且集中于2027H2-2028年；约40-45%的美国规划数据中心容量位于主张暂停审批的州，德州占约25%。该风险仅纳入保守情景，不进入P50基准，也不在PE中重复折价。

4. **国产替代是确定性利好**：中美科技脱钩越深，澜起作为大陆唯一PCIe 5.0 Retimer供应商和内存接口芯片全球龙头的战略价值越凸显。中国云厂商的国产化采购打开"政策红利+市场红利"的双重窗口，但短期对收入的边际贡献仍小于海外DRAM三巨头。

5. **需持续关注的四个政策变量**：①EDA工具出口管制是否扩展至IP授权；②美国是否将中国Fabless设计公司列入实体清单（概率低但非零）；③2027-01-10后"50%关联方规则"是否恢复；④美国州级数据中心暂停令的实际覆盖范围（是否追溯已批项目）。
