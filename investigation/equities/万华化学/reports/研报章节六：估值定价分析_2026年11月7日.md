**研究日期：2026年11月7日**

**参考价格**：不复权市价 **72.65 元（2026年11月6日收盘）**，后复权价 3,137.63 元 | 总市值约 **2,274.29 亿元** | 总股本 31.30 亿股

**目标年份：2027E**（框架Q4切换期自动滚算条款：2026年10月起，估值锚点由2026年EPS/BVPS切换至2027年EPS/BVPS）

## 一、价值锚定：适配性方法选择

### 1.1 方法选择理由

万华化学是一家**重资产、强周期、具备全球垄断地位的化工企业**，其业务特征决定了单一估值方法均有缺陷：

| 估值方法 | 适用性 | 局限性 | 权重 |
| :--- | :---: | :--- | :---: |
| **PE（市盈率）** | ★★★★ | 盈利波动剧烈，需结合多情景EPS预测 | **30%** |
| **PB-ROE（市净率）** | ★★★★ | 重资产结构适合PB估值，但需与ROE联动 | **25%** |
| **SOTP（分部估值）** | ★★★★ | 板块属性差异大，但需依赖分部盈利拆分假设 | **25%** |
| **EV/EBITDA** | ★★★☆ | 排除折旧政策干扰，适合重资产化工企业 | **20%** |

排除DCF的原因：万华处于地缘政治驱动的高度不确定性盈利环境，DCF对终值假设过于敏感。PS估值不适用（净利率低且波动大，仅用于亏损的电池板块作下限参照）。

**为何SOTP不作为主锚**：SOTP对石化净资产折价与电池板块PS倍数高度敏感（本节测算122.9元，较PE法高31%），且分部盈利本身来自模型分摊，误差会被倍数放大。故以PE为主锚、SOTP为上限参照。

### 1.2 估值锚点切换

当前为2026年11月（Q4），按框架规则**锚定2027年（次年）EPS/BVPS**。

## 二、PE估值：基于2027E三情景EPS的定价区间

### 2.1 历史PE分位参考（视图实测）

过去10年（2016-11至2026-11，视图实测2,299个交易日）：中位数PE=15.54x | P25=12.84x | P75=18.51x | P10=9.69x | P90=23.77x

**当前PE TTM=11.95x（T0归母190.28亿），处于近10年约P18.8分位**——较低位区域，但自10-12的P14随股价反弹小幅抬升。

**审慎评估历史分位的参考价值**：历史中位数15.54x代表2020-2024年化工品相对景气期+万华ROE高位期的估值中枢。当前ROE已从2021年的42.5%降至2026年的约18.4%，PE自然应有所折价；但MDI垄断溢价与"现金流转正+分红"属性提供了底部支撑。

### 2.2 目标PE区间推导（2027E锚定）

| PE倍数 | 逻辑支撑 | 对应目标价 |
| :---: | :--- | ---: |
| 11x（保守） | 周期底部估值，对应地缘溢价出清+ROE回落至11.8% | 51.23元（11×4.66，按市值÷股本取整） |
| 12.5x | 低于历史中位数，为周期高点盈利保留折价 | 83.63元（12.5×6.69） |
| **14x（中性目标）** | 较历史中位数15.54x折价约10%："周期股盈利高点低PE"纪律下的中枢倍数；仍高于P25的12.84x以反映MDI寡头格局与现金流质量 | **93.66元**（14×6.69） |
| 17x（乐观） | 接近P75分位，对应景气延续+新材料溢价 | 134.94元（17×7.94，按市值÷股本取整） |

**选择14x作为中性PE目标的理由**：
1. 2027年中性净利209.4亿，较2026年205亿仅增2.1%——盈利增速已从2026年的63.6%降至零增长附近，周期高点特征明确，不应给予中枢以上倍数
2. 三季报验证盈利质量（OCF/归母1.34x、FCF+70.62亿、应收账款回落），确定性评分维持中高，支持倍数不进一步下压
3. 科思创上海66万吨与TA'ZIZ产能落地前（2028-2030年），万华仍有2-3年份额窗口
4. 中期分红已实施（10派8.10元、25.36亿元），2027年年度分红率预期抬升，强化"分红型周期龙头"属性

### 2.3 PE定价结论（2027E）

- **基准市值区间（PE法）**：1,604~4,225亿元
- **中性目标价（PE法）**：**93.66元**（14x × 6.69），较现价72.65元上行空间约**28.9%**

## 三、PB-ROE估值：资产回报视角

### 3.1 历史PB分位

过去10年（视图实测）：中位数PB=4.49x | P25=3.14x | P75=5.82x | P10=2.21x
**当前PB=1.96x处于近10年约P4.4极低分位**，仍为历史最低区域。

### 3.2 公允PB推导（2027E）

根据戈登增长模型变形：**合理PB = (ROE - g) / (COE - g)**。BVPS按2027E末预计归母净资产1,375亿元（Q3末1,163.06亿 + 2026Q4约48亿 + 2027年209.4亿 - 分红约45亿）折算为**43.94元/股**：

| 情景 | 2027E ROE | 永续增长率g | COE | 合理PB | 对应目标价 |
| :--- | ---: | ---: | ---: | ---: | ---: |
| 保守 | 11.8% | 3% | 10% | 1.26x | 55.36元 |
| 中性 | 16.5% | 4% | 9.5% | 2.27x | 99.76元 |
| 乐观 | 19.3% | 5% | 9% | 3.58x | 157.31元 |

**关键结论**：中性情景合理PB 2.27x对应99.76元，高于当前股价72.65元且高于PE法中性价（93.66元）——PB-ROE框架显示深度低估。两法差异6.5%，主要因PB法按期末净资产（未扣除永续分红的时间价值）计算。

### 3.3 PB-ROE定价结论（2027E）

- **基准市值区间（PB-ROE法）**：1,733~4,924亿元
- **中性目标价（PB-ROE法）**：**99.76元**（2.27x×43.94元BVPS），较现价72.65元上行空间约**37.3%**

## 八、逻辑纯净性校验（Consistency Guardrails）

*准则：具体的、可计算的钱（增减）进E；不可计算的、关乎信心与不确定性的因素进PE。*

| 因子 | 进E还是PE？ | 理由 |
| :--- | :---: | :--- |
| MDI价格上涨/回落→利润变化 | **进E** | 已量化为2027年聚合MDI 17,600元/吨、纯MDI 20,800元/吨 |
| 乙烯双系列运行→石化扭亏 | **进E** | 已体现为石化毛利率4.75% |
| 纯苯远期曲线下行→价差修复 | **进E** | 已体现为聚氨酯毛利率27.0% |
| LFP价格战→第二曲线利润下修 | **进E** | 已体现为"其他"板块净利-6.5亿（而非+10.7亿） |
| 有效税率15%→17.2% | **进E** | 按Q3实际17.18%重算全部三情景 |
| MDI技术垄断带来的估值溢价 | **进PE** | 不可精确量化，增强长期确定性 |
| 地缘缓和的路径不确定性 | **进PE（-3%）** | 盈利影响已进E（30%保守档），PE只表达路径不可预测性，不重复扣减 |
| LFP 320亿投资的资本回报质疑 | **进PE（-3%）** | 资本配置机会成本，非当期利润 |
| CBAM风险下修 | **进PE（+2%政策项内）** | 远期压制解除 |
| 股东质押上升 | **进PE（治理项0%）** | 负面但未构成治理折价 |

**锚点回测**：修正后隐含PE = 2,960.9/209.4 ≈ 14.1x，略低于历史中位数15.54x、高于P25（12.84x）约10%；隐含PB = 94.58/43.94 ≈ 2.15x，仍低于P25（3.14x）约32%。在盈利零增长的年份给予中枢以下倍数、PB仍处历史低分位，定价具备商业逻辑支撑。

## 十、逻辑证伪与极限压力测试（2027E）

### 10.1 黑天鹅场景："一击毙命"事件

**情景定义**：美伊达成全面协议并快速执行→霍尔木兹完全复航→沙特Sadara复产、欧洲供给回归，叠加高油价积累的需求破坏集中释放。

在此情景下：
- MDI价格从18,333元/吨回落至14,000~15,000元/吨（跌幅约18~24%），石化产品价格同步回落，LFP随碳酸锂成本坍塌继续下行
- 2027年盈利降至约130亿（EPS约4.15元）——因产能扩张（450万吨）已落地，高产能利用率下的经营杠杆放大
- 盈利见顶预期+情绪逆转，估值倍数压缩至10x

**地狱价格计算**：
- EPS（压力测试）：4.15元
- PE：10x（接近P10历史分位）
- **压力测试目标价：41.50元（不复权）**，较现价72.65元跌幅约**42.9%**

### 10.2 资产价值参照（不构成"地板价"）

在最极端情境下，按资产负债表口径：
- 2027E末归母净资产约1,375亿元 ÷ 31.30亿股 = **43.94元/股**
- 重资产属性的另一面是**专用性强、清算折价大**：光气/MDI装置、乙烷裂解装置的二手价值通常仅为账面0.5-0.8x；工业用地与公用工程可按1.0-1.2x计
- 综合估算清算区间约**30-40元/股**

**因此本节不作"52-64元为终极地板"的表述**：黑天鹅目标价41.50元与账面净资产43.94元接近，若跌至该区间，市场已隐含对MDI长期盈利能力的根本性质疑。风险管理的纪律位应设为**保守目标价51.23元**（清仓线），而非用清算价值兜底。
