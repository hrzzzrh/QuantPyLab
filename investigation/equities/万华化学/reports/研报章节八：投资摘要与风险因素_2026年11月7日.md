## 一、投资摘要

### 1.1 投资逻辑（三段论）

**论一：三季报确认"量增+现金流"双主线，但毛利率环比回落揭示价格弹性见顶**

万华2026年前三季度营收1,858.67亿元（+28.87%）、归母净利156.58亿元（+70.99%），Q3单季归母55.95亿元（+84.38%），显著高于此前42亿元的中性预期。拆解超预期来源：**量增**——Q3聚氨酯销量184万吨（9M 510万吨，+11.4%）、石化品销量177万吨（9M 516万吨，+12.2%）；**费用摊薄**——Q3期间费用率降至4.02%（财务费用率0.60%，同比-1.09pct）；**而毛利率反向**——Q3综合毛利率15.41%，环比Q2的19.03%下降3.64pct，纯苯（Q3均价8,358元/吨，+41.54%）、石脑油（832美元/吨，+41.37%）、动力煤（791元/吨，+32.50%）涨幅快于MDI/TDI售价。**这意味着2026年的利润弹性主要来自"量"与"费用"，而非"价差扩张"——量增可持续，价差红利需靠成本回落接力。** 现金流是本期最硬的资产：9M OCF 209.20亿（1.34x）、CAPEX 138.58亿、FCF+70.62亿（Q3单季+60.18亿），应收账款自196.05亿回落至182.87亿，资产负债率降至63.38%。

**论二：MDI紧平衡延续但地缘溢价开始漏气；LFP第二曲线从"量价齐升"降级为"以量补价"**

MDI当前处于全年最强状态：11月6日生意社聚合MDI 18,333元/吨（60天+5.57%）、山东万华货18,500元/吨、北方大厂11月上旬PM分销一口价18,900元/吨且计划量已执行完毕、上海亨斯迈挂牌19,800元/吨；Q3行业均价聚合MDI 17,000/纯MDI 21,200/TDI 16,800元/吨。但宏观侧出现决定性变化：**布伦特原油自113.43美元/桶单周暴跌13.3%至98.32美元/桶**，民主党拿下两院后明确寻求结束冲突，彭博报道美伊接近潜在突破、伊朗正审议卡塔尔涉核方案，霍尔木兹通行量恢复至战前约75%。成本侧同步改善：华东纯苯11月6日8,370元/吨（9月峰值9,475），12月下/1月下远期报8,060/7,910元/吨。**结论：2027年MDI基准均价假设17,600元/吨（较当前-4%），价差因成本下行而修复，量的部分由450万吨产能与出口维持。** 第二曲线方面，LFP价格已跌至一年低位（生意社46,667元/吨、动力型43,800元/吨，较9月-23%；碳酸锂9.36万元/吨），2026年末82万吨新产能投放恰逢价格低谷，"量价齐升"逻辑证伪；电池科技子公司2026H1营收96.06亿但净利仅2.19亿（净利率2.3%），证明收入已规模化而盈利极薄，2027年按"薄利放量"建模（收入240亿、毛利率10%、模拟净利-6.5亿），估值从30x PE期权改为0.5x PS。

**论三：估值仍便宜（PE TTM 11.95x/P18.8、PB 1.96x/P4.4），但赔率已不便宜（盈亏比0.79:1）**

当前股价72.65元（2026-11-06收盘），PE TTM 11.95x处近10年约P18.8、PB 1.96x处约P4.4（历史最低区域），2027E中性Forward PE仅10.9x。PE法中性目标93.66元、PB-ROE法99.76元、EV/EBITDA法91.00元三法收敛于91-100元，审计修正后中性94.58元（+30.2%）。但**股价自10月22日低点已反弹10.3%、自10月12日锚点+5.0%，叠加税率口径修正（15%→17.2%）与保守档概率上调至30%，盈亏比自1.78:1降至0.79:1**。基本面的"正确"与价格的"便宜"已部分脱钩——这是持有者的市场，不是新建仓者的市场。

## 二、风险因素（按烈度排序）

### 🔴 高风险（足以改变投资评级）

**R1：美伊达成协议→MDI地缘溢价快速出清（概率已上调）**
- **烈度**：★★★★
- **当前状态**：布油单周-13.3%至98.32美元、民主党拿下两院寻求结束冲突、美伊"接近潜在突破"、霍尔木兹通行量恢复至战前75%。这是本轮最强的负面边际变化
- **量化冲击**：目标价体系切换至保守档51.23元（EPS 4.66）；极端情形见压力测试——2027年净利约130亿、EPS 4.15元、压力测试价41.50元（-42.9%）
- **监测信号**：伊朗对卡塔尔方案正式答复；制裁执行层面可核查松动；聚合MDI连续3周跌破17,000→16,000元/吨；布油跌破85美元

**R2：石化板块毛利率修复失败**
- **烈度**：★★★★
- **触发条件**：H1石化毛利率6.80%、Q3综合毛利率环比-3.64pct（石化为主要拖累）；乙烯-石脑油裂解价差-102.25美元/吨倒挂；乙烯二期检修推后Q4产量
- **量化冲击**：若2027年石化毛利率仅2.4%（保守档），中性档14.7亿净利归零，影响EPS约0.42元（14.7×(1-11.5%)÷31.30≈0.42元，归母口径）；若持续亏损，SOTP中石化净资产0.8x PB需下调至0.6x（-104亿市值）
- **监测信号**：Q4石化分部毛利率（年报）；乙烯二期12月复产时点；纯苯/石脑油比价

**R3：全球MDI产能军备竞赛→2028年后寡头默契弱化**
- **烈度**：★★★★
- **触发条件**：科思创上海66万吨（2030前后）+阿联酋可研+TA'ZIZ 2028年末投产+巴斯夫美国17万吨爬坡+亨斯迈-Olin合并后协同扩产
- **量化冲击**：2028年起聚氨酯毛利率中枢从27%回落至24%以下
- **监测信号**：科思创上海项目开工仪式；TA'ZIZ建设进度；行业新增产能公告

### 🟡 中等风险（可控但有影响）

**R4：LFP价格战延续，第二曲线价值归零**
- **烈度**：★★★☆
- **当前状态**：LFP 46,667元/吨（一年最低）、动力型43,800元/吨（较9月-23%）、碳酸锂9.36万元/吨；2026年末82万吨新产能投放
- **量化冲击**：板块模拟净利已按-6.5亿建模，若价格再跌10%，拖累扩大至-15亿（EPS -0.27元）；SOTP中120亿PS价值面临减值
- **监测信号**：季度LFP均价、加工费、行业开工率、万华LFP出货量

**R5：出口动能减弱**
- **烈度**：★★★
- **当前状态**：9月聚合MDI出口6.82万吨，环比**-21.38%**（7月10.20万吨、8月约8.7万吨），结束连续三个月10万吨级；9月进口1.96万吨（环比+34.75%）；9M累计出口77.13万吨
- **量化冲击**：若Q4出口维持6-7万吨/月（vs 上半年月均8.4万吨），聚氨酯销量增速从+11.4%降至+5%
- **监测信号**：10-12月海关出口数据；海外装置复产（Sadara、欧洲）

**R6：中美关税与301排除到期**
- **烈度**：★★☆
- **当前状态**：吉隆坡安排延至2027-01-10（24%对等关税暂停、50%穿透规则暂停）；**178项对华关税排除于11月9日到期、截至11月6日USTR未出续期文件**；美国MDI反倾销85.11%已落地
- **量化冲击**：排除项涉及品类出口成本抬升；对万华直接影响有限（对美MDI占比<8%、匈牙利基地对冲）
- **监测信号**：11月9日联邦公报；2027-01-10吉隆坡安排二次到期

**R7：应收账款与有息负债**
- **烈度**：★★☆
- **当前状态**：Q3已改善（AR 182.87亿/-6.7%、应收/营收7.47%、资产负债率63.38%）；但有息负债1,142亿（不含应付债券/租赁负债）、短期借款596.73亿仍高
- **量化冲击**：年化利息约30亿；若短债重回650亿以上，财务费用率将回升
- **监测信号**：Q4短期借款、财务费用率、应收/营收比

### 🟢 低风险（需关注但暂不影响核心逻辑）

**R8：股东质押比例上升**
- **烈度**：★☆
- **当前状态**：11月6日中凯信新增质押2,720万股（0.87%总股本），累计质押6,240万股（占其持股20.68%）；中诚3,600万股（10.90%）；一致行动人合计9,840万股（3.14%总股本），用途"债权类投资"。另三季报前十大股东中Prime Partner International质押5,845万股（占其持股66.7%），**全部前十大质押合计约1.57亿股（≈5.0%总股本）**
- **判断**：不构成控制权风险（国丰集团21.65%为国资第一大股东），但需纳入治理观察

**R9：欧盟CBAM扩围**
- **烈度**：★
- **当前状态**：本轮扩围草案指向约200项钢铝下游制品，**不含有机化学品**；三方谈判未完成
- **判断**：万华对欧出口的碳成本压力后移至2029-2030年后

**R10：安全生产与工艺风险（光气）**
- **烈度**：★（低频高损）
- **当前状态**：MDI核心工序涉及剧毒光气，任何泄漏或环保事故都将触发停产整改与区域舆情；2026年公司全球装置密集检修、老旧装置比例上升
- **监测信号**：装置非计划停车公告、环保处罚、地方应急管理局通报

**R11：技术替代（LFP路线）**
- **烈度**：★☆（远端）
- **当前状态**：LMFP、钠离子电池（公司自身"钠电三代定型"）、固态电池在储能/中低续航场景持续渗透，将压缩LFP长期需求增速；钠电已免征消费税至2028年底（LFP 2027年9月消费税升至4%）
- **监测信号**：钠电装机占比、固态电池量产时点、LFP消费税执行

## 三、研究结论象限图

基于**"确定性"与"预期收益空间"**两个维度：

```
                     预期收益空间 →
                     低              高
              ┌──────────────────┬──────────────────┐
         高   │  第三象限         │  第一象限         │
              │  ★万华化学★     │  High-Conviction │
              │  Defensive Value  │  Buy             │
              │                   │                   │
   确            │                   │                   │
   定  ──────────┼──────────────────┼──────────────────┤
   性            │                   │                   │
         低   │  第四象限         │  第二象限         │
              │  Avoid/Wait       │  Speculative     │
              │  (回避/观望)       │  Growth          │
              └──────────────────┴──────────────────┘
```

### 万华化学定位：**第三象限（Defensive Value，防御/底仓），评级"持有"**

| 维度 | 评分 | 变化 | 说明 |
| :--- | :---: | :---: | :--- |
| 确定性 | **高（7.5/10）** | — | 三季报验证量增与现金流、PB处历史极低位；但毛利率环比回落、LFP期权失效、地缘路径不确定 |
| 预期收益空间 | **中（5.5/10）** | ↓1.5 | 中性上行30.2%（上期44.2%）；盈亏比0.79:1（上期1.78:1） |
| 风险调整后吸引力 | **中** | ↓ | PE TTM 11.95x/P18.8、PB 1.96x/P4.4仍便宜，但赔率已低于1 |

**为何由第一象限下沿移至第三象限**：
1. **盈亏比0.79:1 < 1**：期望收益（89.65元 vs 72.65元，+23.4%）小于下行空间（72.65→51.23元，-29.5%），赔率结构不支持"增持"（第一/第二象限的必要条件是高预期收益）
2. 中性收益率自+44.2%降至+30.2%，税率口径修正与保守档概率上调共同压缩空间
3. 地缘溢价出清是"方向确定、节奏不定"的负面变量
4. 石化毛利率修复失败的风险上升、LFP第二曲线期权价值归零

**为何不是第四象限（回避）**：
1. 盈利与现金流已被财报硬验证（9M归母+70.99%、FCF+70.62亿），不存在基本面恶化
2. PB处近10年P4.4、PE TTM处P18.8，估值提供下行保护；中性目标隐含PB 2.15x仍低于P25的3.14x
3. 2027E中性Forward PE仅10.9x，相对ROE 16.5%仍有吸引力——属"好公司、不便宜的赔率"

### 投资建议

**评级：由"增持"下调为"持有（回调再评估）"。** 现价72.65元距保守目标价51.23元有29.5%缓冲，距中性目标价94.58元有30.2%上行空间，但盈亏比仅0.79:1。

- **已持仓者**：持有。减仓的理由不充分（估值PB低位、基本面验证通过），但应停止加仓
- **空仓/轻仓者**：**不追高**。等待两种情形之一：①回调至68.76元（MA20）以下或65.86-66.95元（双底上沿），届时盈亏比回升至1.1以上；②放量站上年线74.48元并突破78.87元颈线，右侧确认趋势反转后再评估
- **风控红线**：聚合MDI连续3周跌破16,000元/吨→减至≤5%；布油跌破85美元且MDI跌破17,000→减半；有效跌破65.86元（双底右底）→仓位减半；跌破51.23元（保守目标价）→清仓
- **核心观察期**：11月中下旬美伊协议"文本证据" → 12月上旬乙烯二期复产 → 12月莱州LFP投产 → 2027年1月业绩预告（全年205亿路径） → 2027年3-4月年报（Q4分部毛利率与2027年分部指引）
