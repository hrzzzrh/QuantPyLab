## 一、价值锚定：适配性方法选择

### 1.1 方法论适配分析

| 方法 | 适配度 | 理由 |
| :--- | :--- | :--- |
| **PE(市盈率)** | ★★★★★ 首选 | 公司盈利稳定、可预测(ROE 24-25%)，全球对标清晰，是市场最认可的方法 |
| **PB-ROE** | ★★★★☆ 辅助 | ROE超20%支撑PB溢价，适合与PE交叉验证 |
| **PS(市销率)** | ★★★☆☆ 参考 | 适用于利润率波动较大时作为下限锚定 |
| **DCF(现金流折现)** | ★★★☆☆ 参考 | 公司FCF强劲(OCF TTM 1,340亿)，但重资产周期性导致终端价值假设敏感 |
| **PEG** | ★★★☆☆ 参考 | 适合成长型公司，但需要通过增速预估来判断估值是否合理 |
| **SOTP(分部估值)** | ★★★☆☆ 辅助 | 多业务板块属性差异大，但分部数据颗粒度不足 |
| **EV/EBITDA** | ★★★☆☆ 参考 | 可排除折旧政策和资本结构影响，适合重资产行业 |

**选择组合**：PE(主) + PB-ROE(交叉验证) + DCF(底线验证) + PEG(增速调节)

### 5.3 核心矛盾辨析（修订）

**H1 2026业绩"冰火两重天"——营收增速+54.8%超预期 vs Q2毛利率~23.15%低于预期**

- **营收端大超预期**：H1营收2,769亿(+54.8%)，远超我们上一版报告的隐含全年节奏（H1约2,500亿）。Q2单季1,478亿(+56.9%)，国内装车份额46.7%(+5.6pct)、海外份额33.7%(+3.7pct)，需求侧没有任何减速迹象。
- **利润端低于预期**：Q2毛利率~23.15%较预期低约35-85bps，动力电池毛利率20.63%已触及跟踪手册黄灯阈值。这意味着CATL的利润对锂价的敏感度高于此前模型的假设——约每1万元/吨锂价波动对应毛利率0.2-0.3pct（此前估计0.15-0.25pct）。
- **H2改善逻辑反而增强**：锂价7月24日已跌至14.5万（较Q2均价17-18万有明显改善），叠加以旧换新等政策加码，H2毛利率确定性改善空间从150-200bps扩大至可能180-250bps。**H1毛利率越差，H2环比改善幅度越大**——这是当前估值的核心不对称性。
