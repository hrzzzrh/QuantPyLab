## 一、价值锚定：适配性方法选择

### 1.1 方法论适配分析

| 方法 | 适配度 | 理由 |
| :--- | :--- | :--- |
| **PE(市盈率)** | ★★★★★ 首选 | 公司盈利稳定、可预测(ROE 24-25%)，全球对标清晰，是市场最认可的方法 |
| **PB-ROE** | ★★★★☆ 辅助 | ROE超20%支撑PB溢价，适合与PE交叉验证 |
| **PS(市销率)** | ★★★☆☆ 参考 | 适用于利润率波动较大时作为下限锚定 |
| **DCF(现金流折现)** | ★★★☆☆ 参考 | 公司FCF强劲(OCF TTM 1,340亿)，但重资产周期性导致终端价值假设敏感 |
| **PEG** | ★★★☆☆ 参考 | 适合成长型公司，但需要通过增速预估来判断估值是否合理 |
| **SOTP(分部估值)** | ★★★☆☆ 辅助 | 多业务板块属性差异大，但分部数据颗粒度不足 |
| **EV/EBITDA** | ★★★☆☆ 参考 | 可排除折旧政策和资本结构影响，适合重资产行业 |

**选择组合**：PE(主) + PB-ROE(交叉验证) + DCF(底线验证) + PEG(增速调节)

### 5.3 核心矛盾辨析

**H1已兑现“量增利稳”但Q2毛利率瑕疵+新变量使H2进入“锂价×消费税×地缘”三因素拉锯**

- **营收端已兑现强劲**：H1营收2,769亿(+54.8%)，Q2单季1,478亿(+56.9%)，国内装车份额46.7%(+5.6pct)、海外33.7%(+3.7pct)，全球储能H1 486GWh+93%与EU纯电H1 122万辆+40.5%进一步验证需求。08月国内NEV零售虽-12.5%但出口+147.8%对冲，需求侧仍无系统性减速，但结构分化加剧。
- **利润端三重压制显现**：①Q2毛利率~23.15%已触及22%黄灯阈值，锂价敏感度实测0.33-0.42pct/万高于预期；②**8月锂价反弹至15.0-15.8万使H2锂价改善幅度由60-100bps收窄至30-60bps**；③**消费税09.01起2%新增税负约5-6亿净利(0.6%)等效毛利率-0.1pct**，需与下游50%分摊验证。H2毛利率修复由100-150bps预期收窄至60-100bps。
- **估值端回撤提供安全垫**：当前368.50元、PE 2026E 17.86x(回购后)较07.24的18.45x回落0.59x，PEG 0.61x仍处极低。若Q3证实毛利率回升至24.7%+且消费税传导≥50%+匈牙利健康问题闭环，则PE修复至20-22x（对应413-454元）概率较高；若Q3毛利率继续≤23%且锂价站稳16万+消费税零传导，则PE可能压缩至16-17x（对应330-351元）。
- **关键不对称性修正**：此前“H1毛利率越差，H2环比改善越大”的单因子逻辑，需修正为**“锂价改善幅度收窄+消费税对冲使H2改善的斜率放缓，但股价回撤已部分定价该预期”**——盈亏比由1.30→1.60的改善主要来自股价回撤而非盈利上修。
