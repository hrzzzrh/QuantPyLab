## 一、价值锚定：适配性方法选择

### 1.1 方法论适配分析

| 方法 | 适配度 | 理由 |
| :--- | :--- | :--- |
| **PE(市盈率)** | ★★★★★ 首选 | 公司盈利稳定、可预测(ROE 24-25%)，全球对标清晰，是市场最认可的方法 |
| **PB-ROE** | ★★★★☆ 辅助 | ROE超20%支撑PB溢价，适合与PE交叉验证 |
| **PS(市销率)** | ★★★☆☆ 参考 | 适用于利润率波动较大时作为下限锚定 |
| **DCF(现金流折现)** | ★★★☆☆ 参考 | 公司FCF强劲(OCF TTM 1,340亿)，但重资产周期性导致终端价值假设敏感 |
| **PEG** | ★★★☆☆ 参考 | 适合成长型公司，但需要通过增速预估来判断估值是否合理 |
| **SOTP(分部估值)** | ★★★☆☆ 辅助 | 多业务板块属性差异大，但分部数据颗粒度不足 |
| **EV/EBITDA** | ★★★☆☆ 参考 | 可排除折旧政策和资本结构影响，适合重资产行业 |

**选择组合**：PE(主) + PB-ROE(交叉验证) + DCF(底线验证) + PEG(增速调节)

### 5.3 核心矛盾辨析

**H1已兑现“量增利稳”但Q2毛利率瑕疵+新变量使H2进入“锂价×消费税×地缘×去宁德化”四因素拉锯**

- **营收端已兑现强劲但批发-零售剪刀差扩大**：H1营收2,769亿(+54.8%)，Q2单季1,478亿(+56.9%)，国内装车46.7%(+5.6pct)、海外33.7%(+3.7pct)，全球储能H1 486-467GWh+93-94%与德国8月BEV 6.89万+75.1%/法国3.61万+113%验证需求。但8月批发151万+16.4% vs 零售100.5万-10.1%/渗透率65.2%分化，批发-零售gap约50万辆，渠道库存去化仍待金九银十验证。
- **利润端三重压制边际缓解**：①Q2毛利率~23.15%已触及22%黄灯阈值，锂价敏感度实测0.33-0.42pct/万高于预期；②**9月锂价回落至14.3-15.2万使H2锂价改善幅度由30-60bps有望回升至40-80bps**（9月初回调提供成本 relief，但中期17万关口仍压制弹性）；③**消费税09.01起2%已生效且储能系统不征/出口退税**，电池簇征税约5-6亿净利(0.6%)等效毛利率-0.1pct，亿纬/力神调价函已落地但CATL差异化协商待Q4验证。H2毛利率修复维持60-100bps预期。
- **估值端极端低估**：当前301.95元、PE 2026E 14.64x(回购后)较09.09的16.26x再回落1.62x，PEG 0.50x已处历史极值。若Q3证实毛利率回升至24.7%+且消费税传导≥50%+匈牙利健康闭环，则PE修复至20-22x（对应413-454元）概率较高；若Q3毛利率继续≤23%且锂价站稳16万+消费税零传导，则PE可能压缩至14-15x（对应290-310元，逼近清算底），但当前已处14.64x下行空间有限。
- **关键不对称性修正**：由**“三因素拉锯”修正为“四因素拉锯”**——新增**去宁德化加速**（理想全系自研+入股欣旺达、小米引入中创新航为龙甲电池）对份额与议价的长期压制，但短期国内份额仍稳在46-47%，中期需跟踪Q4定点变化。盈亏比由1.60→3.36的改善主要来自股价超卖而非盈利上修，赔率已进入显著占优区间。
