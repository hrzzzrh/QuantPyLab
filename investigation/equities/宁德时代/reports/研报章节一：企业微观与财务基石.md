## 一、公司概览与产品矩阵

宁德时代新能源科技股份有限公司成立于2011年，2018年6月在深交所创业板上市（300750），2025年5月于香港联交所主板挂牌（H股代码：3770.HK），募集资金410亿港元。公司是全球领先的零碳新能源科技公司，主营业务涵盖**动力电池**、**储能电池**和**电池材料及回收**三大板块，并已将电动化延伸至低空经济（eVTOL）、船舶、换电网络、数据中心及零碳生态建设等新兴领域。

### 1.1 产品体系

| 产品板块 | 核心产品 | 应用领域 |
| :--- | :--- | :--- |
| **动力电池系统** | 磷酸铁锂、三元高压中镍、三元高镍、钠离子电池、凝聚态电池、超混电池、骁遥双核电池、神行Pro等 | 乘用车（BEV/REV/PHEV/HEV）、商用车（客车/重卡/物流）、船舶、航空器、电动两轮车 |

### 1.2 盈利模式

公司以自建生产基地为主、合资及技术授权为辅的产能扩张模式，通过销售动力电池、储能电池及电池材料获取收入。核心护城河来自：（1）**全链条自主研发能力**——覆盖材料、电芯、系统及回收的纵深研发体系；（2）**绿色极限制造**——超级拉线工艺持续迭代，降本增效；（3）**全球客户粘性**——与VW、BMW、Stellantis、Volvo、DMG等全球头部车企深度绑定。

### 2.2 盈利质量深度分析

#### （1）毛利率的U型反转（2022-2025）与2026H1的回撤（重大更新）

**2026H1毛利率23.92%，低于市场预期**：2026H1综合毛利率23.92%（上年同期25.02%，-1.10pct），其中Q1 24.81%、**Q2仅约23.15%**（计算值）。Q2毛利率环比下降约166bps，为2023年以来单季最低水平之一。核心原因：碳酸锂Q2均价约17-18万元/吨（较Q1的12-15万显著上升），叠加储能电池价格竞争加剧和三元电池需求结构性转弱。

**分业务毛利率全面下滑**：
| 业务板块 | H1 2026毛利率 | 上年同期 | 同比变动 |
| :--- | :--- | :--- | :--- |
| 动力电池系统 | 20.63% | 22.41% | **-1.78pct** |
| 储能电池系统 | 23.96% | 25.52% | **-1.56pct** |
| 境内业务综合 | 21.16% | 22.94% | **-1.78pct** |
| **境外业务综合** | **29.97%** | 29.02% | **+0.95pct** |

**关键发现**：
- 境外毛利率29.97%逆势提升，远高于境内21.16%（差距达8.81pct），进一步验证了海外市场的溢价能力和竞争格局优势。
- 动力电池毛利率20.63%已跌至4年低位，反映锂价传导滞后+终端价格战双重压力。
- 储能毛利率23.96%虽高于动力，但较2025年全年的26.7%下滑显著——储能市场竞争烈度正在上升。

**Q2毛利率低迷是否为一次性冲击？** 关键变量是碳酸锂价格。Q2均价17-18万/吨处于年内高位，而截至7月24日碳酸锂已跌至14.5万/吨（生意社基准价，较Q2均价-15~18%）。按每1万元/吨对应毛利率0.15-0.25pct的传导弹性测算，H2锂价降幅2.5-3.5万/吨对应毛利率改善约60-100bps，叠加海外占比提升与产品升级或达100-150bps（Q2实际环比降幅166bps对应锂价上行约4-5万/吨，实测弹性约0.33-0.42pct/万，高于此前假设，改善上限或达125-145bps）。但需注意Q2的20.63%动力电池毛利率已触及跟踪手册"黄灯"阈值（22%），若Q3继续低于22%，需重新评估全年毛利率中枢。

**历史回顾**：公司毛利率经历了从2021年26.3%下滑至2023年19.2%（底部），再到2025年26.3%（完全恢复）的完整周期。毛利率波动的核心驱动因素包括：

- **2022-2023年下行期**：上游碳酸锂价格高位运行（最高突破60万元/吨），叠加行业竞争加剧、价格战影响，公司毛利率承压。2023年全年毛利率仅19.2%，为上市以来最低水平。
- **2024年修复期**：碳酸锂价格从2023年底的10万元/吨进一步回落，叠加公司规模效应释放和降本增效，毛利率回升至24.4%（+5.2pct）。
- **2025年强劲恢复**：毛利率26.3%，已完全恢复至2021年水平。驱动力包括：（1）原材料价格低位运行带来的成本红利；（2）产品结构升级——高附加值的新产品（神行Pro、骁遥双核、天恒储能系统等）占比提升；（3）超级拉线工艺大规模应用带来的制造成本下降；（4**）海外业务毛利率31.44%，显著高于境内24.00%**，海外收入占比提升至30.6%拉高了综合毛利率。

**关键发现**：2025年毛利率回升至26.3%，但这是否存在"短期政策红利"成分？值得关注的是，扣非净利润率从2024年的12.4%提升至2025年的15.2%，增速（+43.4%）快于营收增速（+17.0%），说明利润增长高度依赖利润率扩张而非规模扩张。一旦原材料价格反弹或竞争加剧，利润率可能再度承压。

#### （2）净利率的飞跃式提升

净利率从2023年的11.7%提升至2025年的18.1%，提升幅度达6.4个百分点，远超毛利率改善幅度。核心驱动来自**财务费用的结构性转变**：

| 项目 | 2023 | 2024 | 2025 | 驱动因素 |
| :--- | :--- | :--- | :--- | :--- |
| 财务费用（亿元） | -42.1¹ | -41.3 | **-79.4** | 现金储备增长带来的利息收入大幅增加 |
| 投资收益（亿元） | 45.1 | 39.9 | **79.7** | 参股公司利润增长及H股募集资金投资收益 |
| 其他收益（亿元） | 68.4 | 99.7 | **106.0** | 政府补助及税收优惠持续增长 |

> ¹ 负值表示净收益

**财务费用贡献分析**：2025年财务费用-79.4亿元（净收益），较2024年-41.3亿元扩大38.1亿元，仅此一项就贡献了约1个百分点的净利率提升。这得益于：（1）H股上市募集410亿港元大幅增厚现金储备；（2）账面货币资金从2024年末的3,035亿增至2025年末的3,335亿，2026Q1进一步增至3,520亿。

**投资收益增长**：2025年投资收益79.7亿元（同比+100%），主要来自参股的锂矿、正极材料等上游企业利润改善。2026Q1投资收益26.9亿元（同比+100.7%），继续高增。

**风险提示**：非经常性损益对利润的贡献度在上升。2025年其他收益+投资收益+公允价值变动合计约195亿元，占利润总额的约20%。若扣除这些项目，主营业务利润质量需持续跟踪。

#### （3）ROE的稳定性与驱动因素分解

公司加权ROE过去四年始终维持在24%-25%的极高水平。杜邦分解如下：

| 年度 | ROE | 净利率 | 总资产周转率 | 权益乘数 |
| :--- | :--- | :--- | :--- | :--- |
| 2021 | 21.5% | 13.7% | 0.56 | 3.32 |
| 2022 | 24.7% | 10.2% | 0.72 | 3.40 |
| 2023 | 24.0% | 11.7% | 0.61 | 3.26 |
| 2024 | 24.1% | 14.9% | 0.48 | 2.88 |
| 2025 | 24.9% | 18.1% | 0.48 | 2.63 |

**关键趋势**：ROE的维持逻辑正在发生**结构性转型**——从"高杠杆+高周转"转向"高利润率+低杠杆"模式。权益乘数从2022年的3.40倍持续降至2025年的2.63倍，但净利率从10.2%升至18.1%，弥补了杠杆和周转率下降的影响。这种转型意味着：（1）资产负债率从70.6%降至61.9%，财务风险显著降低；（2）总资产周转率从0.72降至0.48，反映重资产扩张模式下资产增速快于收入增速；（3）未来ROE提升空间将更依赖利润率而非杠杆。

### 3.3 资产减值损失的隐忧

2025年资产减值损失高达86.6亿元（上年84.2亿），占营收的2.04%，是公司最大的非经营费用科目。该项主要包括：（1）存货跌价准备——锂电池行业技术迭代快，老旧型号产品可能面临减值；（2）固定资产减值——早期产线可能因技术落后而计提减值。虽然占比较小，但持续高额的减值计提暗示行业技术演进速度极快，资产淘汰风险不容忽视。

- **现金循环周期**：应收账款周转天数约54天 + 存货周转天数约97天 - 应付账款周转天数约155天 ≈ **-5天**（2026H1口径）。负的现金循环意味着公司用供应商的钱来运营，是制造业中最优质的商业模式特征之一。
- **有息负债率约12.8%**：在重资产制造业中仍属罕见低位。对比：LG Energy Solution有息负债率约15%-20%，比亚迪约12%-15%。宁德时代的低负债率不仅降低了财务风险，还为其海外大规模扩产储备了巨额财务弹性。

### 4.3 资本配置策略的重大升级——200-400亿注销式回购（2026.07.24 重大新增）

2026年7月24日，公司在披露H1半年报的同一日，发布了A股史上最大的回购方案：

| 项目 | 详情 |
| :--- | :--- |
| 回购金额 | **200-400亿元**（下限200亿/上限400亿） |
| 回购用途 | **注销并减少注册资本**（非股权激励/员工持股） |
| 价格上限 | **573元/股**（较公告日收盘价383元溢价+49.6%） |
| 回购期限 | 股东会审议通过后12个月内 |
| 资金来源 | 自有或自筹资金 |
| 占账面现金 | 5.4%-10.7%（期末现金3,721亿） |
| 历史地位 | **A股史上第一**，超越格力电器2021年150亿方案 |

**注销式回购的财务影响测算**（按上限400亿、均价400元/股）：

| 指标 | 回购前 | 回购后 | 变动 |
| :--- | :--- | :--- | :--- |
| 总股本 | 46.27亿股 | **~45.27亿股** | -2.2% |
| EPS 2026E | 20.32元 | **~20.76元** | +2.2% |
| 每股净资产 | ~82.0元 | ~75.0元¹ | -8.6% |
| ROE | ~24% | **~25%** | +1pct |

> ¹ 净资产因支付回购对价而减少（回购价400元/股显著高于每股净资产82元），注销后每股净资产摊薄约-8.6%；但EPS增厚+2.2%、ROE提升约+1pct，每股内在价值的盈利端改善大于账面净资产端摊薄。

**战略信号解读**：

1. **"注销"而非"激励"**：与2025年40-80亿回购（用于员工持股、不减少股本）截然不同。注销减资意味着每股内在价值将永久提升，是股东利益最大化的资本配置方式。
2. **573元价格上限=管理层隐含估值锚**：溢价49.6%，接近我们此前研报515元目标价区间。管理层以真金白银表达了"当前383元被低估"的判断。
3. **同日发布=对冲Q2毛利率负面**：H1半年报Q2毛利率~23.15%为本次最大瑕疵，同日抛出史上最大回购，意在向市场传递"Q2毛利率是暂时性冲击"的信号。400亿的资金承诺比任何管理层喊话都更有说服力。
4. **资本配置纪律的里程碑**：宁德时代历史上首次以注销为目的进行大规模回购，标志着公司从"高速扩张期"进入"高质量股东回报期"——在手现金3,721亿+年经营现金流1,300亿+，完全有实力在维持全球扩张的同时大规模回馈股东。

## 六、财务亮点与风险点总结

### 财务亮点

1. **规模与利润双增**：2026H1营收同比+54.8%、净利同比+42.0%，Q2单季净利225.46亿创历史次高（仅次于2025Q4）。
2. **市占率全面突破**：全球40.2%(+2.2pct)、国内装车46.7%(+5.6pct)、海外33.7%(+3.7pct)——三重份额提升同时发生，极为罕见。
3. **海外高毛利优势扩大**：境外毛利率29.97%，较境内高8.81pct。海外收入占比31.46%继续提升。
4. **现金流极其充沛**：货币资金3,721亿，经营现金流H1 602亿。
5. **资产结构优异**：有息负债率仅约12.8%，应付账款3,555亿体现超级话语权。
6. **股东回报提升**：中期分红14.11元/10股（分红率约15%），对应股息率约0.37%（单期）。

### 潜在风险点

1. **毛利率下滑超预期**：Q2综合毛利率~23.15%、动力电池仅20.63%，已触及跟踪手册黄灯阈值。若Q3动力电池毛利率继续低于22%，全年盈利预测面临下修风险。
2. **存货大幅攀升**：期末存货1,308亿(+363亿 vs 年末)，需关注是否存在滞销或跌价风险。
3. **资产减值持续性**：在锂价下行周期中，前期高价库存可能面临减值压力。
4. **海外扩张不确定性**：匈牙利工厂排污事件余波（许可证恢复进度）仍需跟踪。
5. **非经常性损益依赖**：其他收益及投资收益占利润总额约20%，若政策补贴退坡影响盈利弹性。
6. **经营现金流增速放缓**：H1经营现金流同比仅+2.6%，低于利润增速（+42%），反映应收账款和存货占用增加。
