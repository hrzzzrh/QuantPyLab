## 一、价值锚定：适配性方法选择

### 1.1 方法论适配分析

| 方法 | 适配度 | 理由 |
| :--- | :--- | :--- |
| **PE(市盈率)** | ★★★★★ 首选 | 公司盈利稳定、可预测(ROE 24-25%)，全球对标清晰，是市场最认可的方法 |
| **PB-ROE** | ★★★★☆ 辅助 | ROE超20%支撑PB溢价，适合与PE交叉验证 |
| **PS(市销率)** | ★★★☆☆ 参考 | 适用于利润率波动较大时作为下限锚定 |
| **DCF(现金流折现)** | ★★★☆☆ 参考 | 公司FCF强劲(OCF TTM 1,347亿)，但重资产周期性导致终端价值假设敏感 |
| **PEG** | ★★★☆☆ 参考 | 2027E增速+12.1%下PEG约1.06x，由2026E的0.47x抬升，极端低估叙事弱化 |
| **SOTP(分部估值)** | ★★★☆☆ 辅助 | 多业务板块属性差异大，但分部数据颗粒度不足 |
| **EV/EBITDA** | ★★★☆☆ 参考 | 可排除折旧政策和资本结构影响，适合重资产行业 |

**选择组合**：PE(主) + PB-ROE(交叉验证) + DCF(底线验证) + PEG(增速调节)

### 5.3 核心矛盾辨析

**2027E锚定下的四因素拉锯**（锂价×消费税×地缘×去宁德化）：

- **盈利端**：2027E中性1,047亿(+12.1%)，增速由2026E的+29.4%收敛——高基数常态化。锂价假设下修至12-13.5万为毛利修复主引擎（毛利率24.3%→25.0%），但消费税全年化净负担~55亿与财务费用转净支出部分对冲。匈牙利二期形式驳回→2027E海外本地化贡献有限，但西班牙50GWh年底投产为增量。
- **估值端**：切换至2027E后，现价对应PE 12.87x（低于P10约25%），PEG由0.47x抬升至1.06x——**"极低PEG"极端低估叙事弱化，转为"显著低估+增速常态化"**。加权目标价570元(+91.5%)，盈亏比∞+。
- **关键不对称性**：回购已启动（33.03亿元/下限16.5%）+管理层锚571.60元高于中性目标561元→下行有托底；上行需Q3毛利率≥24.7%+消费税传导≥50%+钠电交付验证。
- **与2026E对照**：目标价500→561元(+12.2%)、加权499→570元(+14.2%)，纯由盈利锚切换（934→1,047亿）与股价反弹（286.75→297.75元）驱动；估值纪律倍数（17x/24.24x/27x）与审计调节（+1%）维持不变。
