# 研报章节三：竞争格局与地位

> 研究日期：2026年09月09日
> 逻辑继承：章节二判定传统为成熟期分化（高端紧、中端松）、新兴为导入期放量。本章评估卧龙在分化格局中的份额、壁垒与定价权，回答传统能否守住30%毛利率、新兴能否从参股故事变为定点利润。
> 信源：年报/招股书/业绩说明会（公告级）、港交所招股书弗若斯特沙利文份额（辅助，未经审计交叉验证）、前瞻/中研普华/天下工厂份额（第三方，未经权威验证，保守引用）、客户/供应链侧写（宇树/智元/采埃孚/沃飞长空合作公告+WAIC签约+招标逻辑，凡未公告量化均不计入预测）

## 1. 竞争格局扫描：大市场、小份额，分化加剧

格局特征：

1. 全球与中国电机市场均呈“大市场、小份额、头部缓慢集中”，无绝对垄断；
2. 份额口径（整机/转定子/细分）差异大，凡第三方份额均标注来源与核实状态；
3. 量化假设仅采信公告级份额（防爆全球第一的定性+招股书定量辅助）。

| 细分 | 份额与排名 | 来源与核实状态 |
|---|---|---|
| 高端工业（国内） | 中电14.6%/卧龙13.1%/湘潭10.9%，卧龙高压同步12.8% | 中研普华转引，未经海关/协会交叉验证 |
| 转定子（国内） | 卧龙12.4%-14.3%第一、汇川9.7%-11.8%、方正9.6%，CR3约20%/CR5约58.7% | 豆丁/电器协会年报转引，口径含自用与ODM，仅作格局参考 |
| 全球低压 | WEG 16%首超ABB 15.5% | Omdia转引 |
| 外资在华 | 西门子/ABB从2020年14%降至2025年不足8%，集中于轨交/石化高可靠场景，成本高30%+响应慢 | 中研普华转引，方向与国产替代一致 |
| 防爆（卧龙） | 全球第一，但份额约4.5%即龙头（细分冠军逻辑） | 招股书定性+弗若斯特沙利文辅助 |

结论：

1. 卧龙在防爆（全球第一）、高压/高效工业（TOP5）、暖通（全球第五）、振动（OLI头部）均处第一阵营，但绝对份额均<15%，无定价垄断力，靠品牌矩阵+全球产能+认证壁垒维持溢价；
2. 中国工业电机参与者3700+（江苏）/3400+（山东），第二梯队卧龙/佳电/中电/湘电/江特中卧龙注册资本/营收/产量居前（前瞻2021年：卧龙电机营收百亿级、毛利率24.46%领先）。

新能源汽车驱动：

1. 格局：整车自制+第三方巨头（汇川联合动力160亿元+/联合电子/华为）主导，卧龙缺席主赛道（收入4.33亿元占2.8%，毛利率6.06%）；
2. 卧龙采埃孚合资（74%/26%，绍兴上虞）意图借背书切车规，但比亚迪/特斯拉/吉利自建+汇川深度绑定，卧龙仅获采埃孚/小鹏/吉利等部分定点（群益综述，未经定点公告逐一核实，不量化）；
3. 技术代差：2025年转定子扁线渗透率38%（2021年12.4%）、单车价值860→2000+元（转引未验证）；卧龙扁线占比42.1%低于汇川88.6%，研发费率5.79%与第一梯队均值5.8%持平但绝对额8.95亿元有规模差距，后发劣势明显；
4. 出路在矿卡/船舶/电摩差异化长尾，而非乘用车主赛道。

机器人关节：格局未定、多强并存，卧龙先发卡位但汇川错位追赶。

| 切面 | 现状 |
|---|---|
| 整机集中度 | CR5 58.7%-62.3%（宇树25%/智元24%领跑，2025年出货5500/5168台，中商/IIM未经公司公告验证，作背景） |
| 零部件降价曲线 | 2024-2026年成本分别-28%/-33%/-41%，整机均价8.7万→5.2万美元→2030年1.8万美元，价格年降15%-20%，要求零部件年降10%+ |
| 卧龙布局“三位一体” | 股东（金石间接持宇树0.083%、参股智元0.74%、智元增资希尔3.95%、合资智龙未来/杭绍创新中心）+核心供应商（宇树外购关节部分传闻，未经双方公告确认不计入预测；节卡深度合作已披露）+联合研发（WAIC与上纬新材签约、舜造GRP01垂域模型）；产品覆盖无框力矩/空心杯/控制器/关节模组/灵巧手/外骨骼，一体化五合一关节为主流量产形态 |
| 汇川威胁 | 产品重叠（无框/关节/驱控）但路径不同：卧龙直连主机厂+利益绑定先发，汇川工控集成基因+稳健利润支撑持续高研发，中长期或以系统集成商身份削弱卧龙直供（新浪财经深度分析，未经双方财报验证，作风险提示） |

短期（2026-2027年）行业容纳多家共存，中期（2028年后）供应链洗牌，卧龙窗口期约2年，需将参股关系转化为批量定点与利润，否则先发变先烈。

供应链生态穿透：

a）下游GKA（暖通全球十大、家电龙头、油气业主、设计院）评价为“交付稳、认证全、响应快”（年报“通过国际头部客户严苛审核”+“总对总”合作，公司口径，未经客户公告验证）；
b）上游硅钢/铜/磁材/电子元器件供应商集中度低（前五采购仅15.25%），但稀土/铜涨价时磁材/铜材厂优先保长协大客户，卧龙长协覆盖约50%（H1“全球双点+长协”口径），剩余敞口承压；
c）一线工程师/垂直论坛评价（Exa抓取有限，未获实测参数对比，声明局限）：卧龙高压/防爆口碑优于国产二线、与ABB/西门子差距在控制算法与全生命周期软件，机器人关节“有货、能用、便宜”但“精度与一致性待批量验证”，与汇川“精度优、系统强”形成差异化。

## 3. 护城河识别：认证+品牌+全球产能，而非成本规模

1. 成本规模：否。原材料占比70%+、毛利率防爆32%/工业30%虽高但非成本领先（暖通17.5%低于大洋成本杀手，机器人26%低于汇川系统溢价），规模（154亿元）小于汇川联合动力单体+卧龙自身分散45厂，规模效应弱，2025年制造费用暖通+9.87%、机器人+0.98%显示规模未降本。

2. 品牌溢价：部分是。百年品牌矩阵（BrookCrompton等）+GE 10年使用权+NEMA/核级认证，在油气/核电/船用/高端暖通有5%-10%溢价（毛利率30%+ vs 行业18.7%均值），但在家电/新能源等消费级市场溢价为零，靠性价比。

3. 转换成本：是，核心壁垒。防爆1-3年认证+核安全许可+设计院入围+业主总对总，一旦入围更换成本极高（停机风险），构成4.5%份额即龙头的细分垄断；工业GKA驱控一体+驻场服务+备件绑定，转换需重验产线，粘性强；机器人关节一旦定点（宇树/智元），切换需重做整机调参，粘性初现但尚未批量锁定。

4. 专利/特许：部分是。64项专利/H1（含发明13项）、省科技奖、高效/永磁/高速（储龙105号国际领先）有技术壁垒，但电机原理成熟，专利多为应用优化，非颠覆性，保护期短，需持续研发（5.79%费率）维持。

综合：

1. 护城河为“认证+转换成本+全球产能前置”复合型，宽而不深；
2. 足以守住传统30%毛利率（±1pp波动），不足以支撑新兴高溢价（机器人毛利率已-0.94pp，新能源仅6%）；
3. 新兴需靠成本曲线（五合一量产降本）+定点放量重建壁垒。

## 4. 产业链定价权：对上压款弱、对下议价分化（财报科目验证）

| 方向 | 科目证据（H1末） | 议价结论 |
|---|---|---|
| 对上（供应商） | 应付账款56.51亿（较年初51.88亿+8.9%）、应付票据近乎清零（票据背书）、预付款4.53亿（+23.3%）、存货37.75亿（+5.0%，原材料占比高） | 无定价权：铜/稀土/硅钢供应商集中、长协需预付，为保交付不敢压款，成本上涨只能部分转嫁（与格力/美的等链主相反） |
| 对下-防爆/工业 | 应收周转约180天（54亿/年化150亿×365），坏账少（央企/海外GKA信用好），部分产品价格联动 | 议价中等 |
| 对下-暖通/家电 | 账期90-120天、年降3%-5%刚性 | 议价弱 |
| 对下-新能源交通 | 账期120-150天、年降5%-8%+整车压价，毛利率6%为证 | 议价最弱 |
| 对下-机器人 | 试制小批量、账期短但单价年降10%+预期 | 议价暂弱，待批量后改善 |
| 总量信号 | 应收54.39亿（+7.8%半年）+应收款项融资4.11亿+合同负债2.73亿（-18.2%）+预收仅0.01亿，以赊销换份额、预收少 | 在手Cover不足，H2收入预测需保守 |

总评：

1. 卧龙处“两头受压、中端缓冲”链位，上游资源品定价、下游整车/GKA定价，自身靠认证与服务赚取中间溢价；
2. 定价权不足以对抗原材料+汇率双杀，此即2026H1毛利率-2pp的本质；
3. 后续盈利预测据此假设：传统以联动提价+1%~+2%对冲年降（净ASP约-1%~-5%）、新兴ASP -3%~-5%（以价换量），毛利率修复依赖原材料回调+海外高毛占比提升，而非提价。
