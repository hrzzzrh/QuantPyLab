# 研报章节二：产业周期与终端穿透

> 研究日期：2026年09月09日
> 逻辑继承：章节一确认传统三支柱占88.6%、毛利率30%/30%/17.5%，H1失速主因汇率+原材料+新兴爬坡。本章需回答传统终端是否企稳、新兴终端是否真实高增，供需边际向紧还是向松，为盈利预测提供量价证据链。

## 1. 产业生命周期与库存节奏：成熟期存量博弈+新兴期导入放量并存

卧龙横跨两类生命周期，需分开定位，不可笼统定为“成长期”或“衰退期”。

a）传统电机（防爆/工业/暖通合计136.9亿元）处成熟期存量博弈：

1. 总量逻辑：全球电机保有量32.7亿KW、年耗电超4.5万亿度占工业用电75%（工信部方案引述转引，方向可信），新增需求来自能效升级（IE3→IE4/IE5）、存量替换与新兴下游（数据中心液冷泵、储能空压机），而非总量扩张；
2. 格局佐证：中国工业电机CR5不足20%、全球低压WEG 16%首超ABB 15.5%（Omdia转引），“大市场、小份额、分散博弈”；
3. 库存动力学：2025年工业销量+6.52%/暖通产销+10%/防爆产销持平，2026H1存货37.75亿（+5.0%半年）/合同负债2.73亿（较年初3.33亿-18.2%，系统BS实测），呈“生产>销售、库存上行、预收下行”的被动补库尾声，非主动补库；
4. 订单拆分：约60%终端真实需求（能效改造、海外转产、欧洲热泵），约40%渠道牛鞭（经销商应对铜价上涨与关税提前备货，2025年末至2026年初铜从8.7万飙至10.5万元/吨，H1透支部分H2需求）；
5. 周期定位：成熟期弱复苏中的二次探底（2024年去库结束→2025年温和补库→2026H1再去库），H2看合同负债拐点与存货去化。

b）新兴业务（机器人5.16亿+新能源交通4.33亿+电动航空0.095亿，合计不足7%）处导入期向成长期切换：

1. 增速符合导入期指数特征（2025年机器人+14.13%/2026H1机器人+49.18%/电动航空+161.99%），但基数小、毛利率让步0.94pp（招股书前三季23%一线），尚未经历价格战与标准收敛，库存无意义（产线爬坡、在制为主）；
2. 新能源交通成长期分化：行业总量高增但第三方份额被整车自制挤压，卧龙销量+16.27%而生产-14.44%（去库），属“行业成长、公司份额收缩”的错位。

综合：公司整体处于“传统磨底+新兴点火”的哑铃型周期，传统决定估值底（PB/股息），新兴决定估值顶（PS/期权），两者节奏错位是2026H1增收（新兴+49%）不增利（传统-7%+费用刚性）的周期根源。

## 3. 供需边际与压力传导

| 维度 | 判断 |
|---|---|
| 供给端 | 头部扩产（越南/墨西哥/全自动叠压38条线+7条新增，豆丁转引未核实）与中小出清并存：二三线32%份额、平均毛利率仅11.2% vs 行业18.7%，GB 18613-2025倒逼超四成退出 |
| 需求端 | 传统总量+3%-6%、新兴+30%+但占比小，合计+4%-6% |
| 平衡结论 | 高端高效（IE4/永磁/驱控/关节）紧平衡、溢价维持；中低端过剩、价格战持续；卧龙（防爆/工业高端占比高、暖通中端占比大）“高端稳、中端挤”，由2024年紧平衡向2026年“高端紧、中端松”分化，非全面过剩 |
| 放大效应 | 新能源：整车降价10%-15%→电机年降5%-8%（占整车成本5%-8%，联动覆盖约50%产品、滞后1-2季），毛利率仅6.06% vs 防爆32%，放大显著；工业/防爆：认证壁垒（1-3年）+GKA粘性+服务费对冲，传导系数约0.3-0.5，放大弱 |
| 传导时滞 | 原材料涨价→成本约1季、提价→下游约1-2季，合计2-3季：2026H1即2025Q4-2026Q1铜稀土高点的集中体现；H2随铜从10.5万回落至9.77万元（-7%）+提价落地，毛利率有望修复0.5-1pp |
| 博弈筹码 | 防爆核级/船级认证+海外产能前置+驱控一体方案（非单体可比价）可延缓1-2季；暖通/新能源同质化高、传导快而充分 |

强制复核三问：

1. 是否已穿透并引用最终终端未来两年景气度？是（防爆稳、工业温和、暖通分化、新能源总量高增但份额分化、机器人指数级但基数小、数据中心高增但占比<2%），引用中汽协/百人会/IIM/SMM等多源并注明核实状态；
2. 是否审计跨期需求移位？是（购置税抢装、设备补贴、欧洲热浪补库均轻微前置，无系统性断层，假设中已正常化）；
3. 是否分析供需边际与压力传导？是（高端紧、中端松；新能源放大、工业/防爆衰减、时滞2-3季），结论用于盈利预测价格假设（传统以联动提价+1%~+2%对冲年降，净ASP约-1%~-5%；新兴ASP -3%~-5%以价换量）与毛利率修复节奏。
