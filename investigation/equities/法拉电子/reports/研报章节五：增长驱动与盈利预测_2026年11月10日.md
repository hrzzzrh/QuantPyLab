### 1.3 价格（P）趋势逻辑推演（2027E）

**2027年价格走势（涨价延续+结构升级+成本挤压三力交织）**：
- **高端产品（车规级/AI级）**：国巨2026年10月底至2027Q1全系列调价（含薄膜电容）提供传导窗口；AI级SST/SiC配套价值量更高，ASP上行3-5%
- **中端产品（工业级/储能级）**：储能总量持平、大功率PCS占比提升，价格持稳；但阳光电源等客户盈利恶化，年降压力上升
- **低端产品（光伏/消费级）**：光伏装机恢复但组件/逆变器价格战延续，ASP年降3%-5%
- **车规级**：整车厂价格战使年降谈判困难（Q3业绩交流口径），ASP仅+2%-3%，低于此前假设的+3%

**综合ASP影响**：
- 正贡献：工控/AIDC/电网占比提升（9M工控17%、+20%），AI级高ASP产品小批量
- 收敛项：光伏/储能年降、车规调价困难
- **净效果**：预计综合ASP+1.5%-2.5%（低于此前+3%-4%，反映客户盈利恶化与铜价传导受限）

## 四、EPS 预测与逻辑索引（2027E主口径 + 2028E延伸）

**加权预测EPS（2027E）** = 5.91 × 25% + 6.80 × 60% + 7.78 × 15% = **6.72元**

**2027E增速结构**：2026E三态EPS 5.42/5.64/5.78（加权5.61），2027E三态EPS 5.91/6.80/7.78（加权6.72）。2027E隐含增速Bear +4.7% / Base +20.5% / Bull +37.8%（vs 2026 Base 12.7亿），增速中枢较2026年（+6.6%）修复，主因工控/AIDC/电网（合计13.5亿、+35%）与光伏恢复（+7.5%），部分被NEV（1950万辆、+6.5%）与AI（3.5亿、2028年才规模化）压制。2027E Base单年PEG 1.17（24x/20.5%），但该口径建立在2027年增速高点之上，不能单独作为估值合理性的依据。

**2028E延伸口径（仅用于耐久性检验，非估值锚）**：三态归母净利14.25/16.58/20.11亿（EPS 6.33/7.37/8.94，概率25%/60%/15%），加权EPS 7.35元。2028E Base较2027E Base +8.4%，增速较2027E的+20.5%下台阶12.1pp，主因NEV购置税2028年恢复10%的跨期透支、AI仍处首批商用、马来西亚一期爬坡费用；详见下一节"五、2028E延伸预测"。据此，24x中性倍数对应2026→2028两年CAGR 14.3%的PEG为1.68、2025→2028三年CAGR 11.6%的PEG为2.07，均高于单年口径1.17。结论：2027E目标价锚不变，但24x已处"耐久性溢价"上沿而非折价区间，模块六下一次复核须把2028E减速作为压制倍数上沿的输入。

### 5.5 2028E 对2027E估值锚的含义

1. **增速台阶**：2026E +6.6% → 2027E +20.5% → 2028E +8.4%。2027E是增速高点，2028E回到个位数增长，符合"购置税退坡+AI首批商用"的跨期节奏；把2027E单年增速当作可持续中枢，会高估盈利耐久性。
2. **PEG口径**：24x对应2027E单年PEG 1.17、2026→2028两年CAGR 14.3%（2026E Base EPS 5.64元→2028E Base 7.37元）的PEG 1.68、2025→2028三年CAGR 11.6%（2025年实际EPS 5.30元→2028E Base 7.37元）的PEG 2.07。单年PEG低估了跨期透支，24x不是"便宜"，而是"耐久性溢价"；倍数越接近28x，越需要2028年AI规模化与NEV软着陆的双重兑现。
3. **目标价含义**：2028E不改变2027E三态EPS与106.4/166.4/217.8元目标价，但它把"中性24x"从"合理区间中部"推向"上沿"。若2028E Base兑现，中性目标价166.4元折算2028E约22.6x、对应2028E单年PEG 2.69，说明目标价已提前计入2028年部分增长；这也是本报告把2028E定位为"耐久性检验"而非"第二估值锚"的原因。
4. **模块六衔接**：下一次估值复核（2027年3-4月年报后）应把2028E减速作为压制倍数上沿的输入；若2027年报确认2028E Base路径（AI≥5.5亿、NEV未失速、毛利率≥33.3%），24x可维持；若2028E Bear路径提前显形（AI<4.5亿或NEV零售连续两季负增长），中性倍数应压至20-22x。

**（3）四重压力叠加**：AI 5.0亿+储能仅+5%+铜价10.9万元/吨+NEV销量-5%，2028E归母约15.5-15.8亿、EPS约6.9-7.0元，较2027E Base仅+2%-3%，接近"失去的一年"。这说明2028E的增长并非稳态，Base 16.58亿需要AI、储能、铜价、NEV四项中至少三项不出现负偏差；这也是把2028E定位为"耐久性检验"而非"第二估值锚"的核心原因。

**（4）结论**：当前2028E是"方向性锚定"，不是"可直接用于目标价的年度模型"。若要升级为可定价模型，至少需补：①法拉AI/SST客户订单或定点（公司未披露）；②中国储能2028年年度新增装机的权威预测；③2028年BOPP、铜价、汇率假设；④南海路与马来西亚分产线产能及折旧表；⑤2028年资本开支与营运资金。

### 5.7 2028E 证伪条件

- 2027Q4-2028Q1 NEV零售连续两季同比<-5%（购置税透支超预期）；
- 2028H1马来西亚一期未投产，或投产后单季毛利率<32.5%；
- 2028年AI收入<4.0亿（SST商业化延后）；
- 2028年国内光伏装机<240GW；
- 2028年铜价>11.5万元/吨且BOPP>1.35万元/吨（毛利率<32.3%）。

触发上述任两项，2028E Base下调至Bear区间，并将2027E中性倍数上限由24x压至20-22x；2028E不进入预测台账，其误差不按±3%裁决，建议以±15%或"方向性兑现/未兑现"跟踪，首个裁决点为2027年年报（2028年3-4月）与2028年一季报。

## 七、分部估值（SOTP）利润分配

法拉电子业务高度集中于单一品类（薄膜电容），不具备多业务板块的明显特征，SOTP分部估值法不适用。采用**整体PE估值法**更为合理。

若2027年AI数据中心业务放量至3.5亿（占比~5.1%）后仍不足独立分拆阈值；若2028年AI占比超10%且毛利率显著分化，可考虑分拆估值。本次维持整体法。
