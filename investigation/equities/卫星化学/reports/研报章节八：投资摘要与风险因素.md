## 一、投资摘要

### 1.1 一句话主题

**全球化工产能大迁移的最大受益者——H1业绩爆发验证，盈利上修36%至95亿。**卫星化学凭借不可复制的美国乙烷供应链+中国最低碳排的轻烃一体化，在海外高成本产能加速出清、碳市场2027年官宣、BIS 2025-07-02全面撤销乙烷许可的背景下，H1以62.27亿（+126.9%）/Q2单季41.10亿（+249.7%）/GM 30.73%实现质变，TTM 87.94亿创新高，PE TTM 10.16x处11.2%分位历史低位，估值与盈利剪刀差确立。

## 二、风险因素（按烈度优先级排序，H1后新增量价与价差两项）

### 🔴 P0级：可能推翻全部投资逻辑

**1. 中美乙烷贸易再收紧（BIS撤销后残余风险）**

- **触发条件**：美国BIS重新将乙烷列入对华出口管制并拒绝许可（推翻2025-07-02撤销决定）
- **历史先例**：2025-05-30至06-04三船被拒→07-02全面撤销→2026年4月进口创纪录100万吨，**有惊无险但制度记忆犹在**
- **影响烈度**：★★★★★（致命级→当前降至★★★★☆，残余）
- **影响量化**：乙烷断供→连云港250万吨乙烯无料→停工3-6个月→净利-15至-20亿（年化腰斩）→股价9-12元（PB极端0.8x）
- **对冲手段**：①Energy Transfer合资+政治游说；②掺烧丙烷/石脑油应急
- **当前估值折价**：-2%（原-8%修复6pp），**残余风险仍需在PE中扣除**

### 🟠 P1级：显著影响盈利预测（**新增两项**）

**2. 价差脉冲不可持续（AA 8,500溢价消退）【新增】**

- **触发条件**：AA价格从8,500回落至7,000以下（生意社）或Brent跌破75美元、地缘溢价快速出清
- **历史先例**：2025年AA 7,000→Q1 11,000→回落至8,500，Q2 30.73% GM隐含约4-5pp脉冲
- **影响烈度**：★★★★
- **影响量化**：AA每-1,000元/吨→年化净利-3至-5亿，GM -2至-3pp；若AA回落至6,500，全年或仅78-82亿（保守情景）
- **监测**：周度生意社AA报价+Brent/Henry Hub价差；Q3 GM若<26%则基准落空

**3. H2 20万吨精AA未如期投产（量证据链断裂）【新增】**

- **触发条件**：Q3无投产/转固公告且在建工程未结转（Q3在建仍≥50亿）
- **影响烈度**：★★★☆
- **影响量化**：0贡献则营收-10至-15亿、净利-3至-5亿，基准95亿→90-92亿
- **监测**：季报"在建工程转固"科目+公司投产公告；H2量增假设需硬证据，否则按保守78亿为底

**4. AA/PE价格大幅回落（原P1-2，保留）**

- **触发条件**：①中东和平→油价暴跌至50-60/桶；②国内PE新增615-729万吨投放超预期→价格战
- **影响烈度**：★★★★
- **影响量化**：同价差项，PE每-1,000元/吨→净利-1.5至-2亿

**5. 全球需求衰退**

- **触发条件**：全球经济衰退→终端包装/纺织/建筑/汽车走弱→量价齐跌
- **影响烈度**：★★★★
- **影响量化**：需求-5%→营收-25亿、净利-8至-10亿

### 🟡 P2级：中度影响

**6. 衍生品套保再现亏损**

- **触发条件**：原料价格剧烈波动→套保策略失效
- **历史先例**：2025年-9.81亿（已于H1收敛至+1.74亿）
- **影响烈度**：★★★→★★☆（下修，H1验证风控）
- **影响量化**：非现金，但报表利润与情绪冲击±5亿

**7. 乙烷成本优势收窄**

- **触发条件**：①北美乙烷出口激增→价涨；②万华/东明同步扩量→竞争性抢购
- **影响烈度**：★★★
- **影响量化**：十五五末到岸价+10%→吨成本+100-200元

**8. 碳市场政策不及预期**

- **触发条件**：2027年纳入延期或碳价<50元/吨
- **影响烈度**：★★→★★★（上修，因已官宣）
- **影响量化**：远期期权缩水，近期<1亿/年

### 🟢 P3级：低烈度但需关注

**9. 新产能投产延期/转固折旧冲击**
- 在建52.35亿若H2集中转固，新增折旧年化约3-4亿，短期摊薄净利。

**10. 人民币大幅升值**
- 出口竞争力下降但进口乙烷成本降低（自然对冲），影响有限；当前CNH 6.69附近。

## 三、研究结论象限图（H1后重定位）

基于"确定性"与"预期收益空间"双维度评估：

```

    高 ▲

  第二象限          │  第一象限 ★
  (Speculative)     │  (High-Conviction Buy)
  低确定性+高收益   │  高确定性+高收益
       │            │
       │            │  ★ 卫星化学 (第一象限核心，赔率极优)
       │            │     H1验证后确定性↑（4→4.5/5）、
       │            │     收益↑（3.5→4.5/5，+52.1%）
   ────┼────────────┼──────────► 确定性
       │            │
  第四象限          │  第三象限
  (Avoid/Wait)      │  (Defensive Value)
  低确定性+低收益   │  高确定性+低收益
       │            │
    低 ▼            │
```

**卫星化学精准定位**：**第一象限 (High-Conviction Buy)** 的**核心偏上位置（H1验证后上修）**。

- **确定性**：★★★★☆（4.5/5分，原4/5上修0.5）
  - 加分项（H1验证）：价差真实性（Q2 30.73%）、现金流（1.55x）、费用率超预期优化（5.52%）、BIS撤销（地缘从-8%→-2%）、碳市场官宣（+3%→+4%）
  - 扣分项：20万吨精AA未获转固硬证据（量）、AA 8,500含溢价（价）
  
- **预期收益**：★★★★☆（4.5/5分，原3.5/5上修1.0）
  - 基准+52.1%/加权+50.7%，较原+24.8%翻倍；Forward PE 9.33x显著低估

**综合结论**：卫星化学在26.51元（PE 10.16x处11.2%分位）为**年内首荐的"业绩爆发·赔率极优"标的**。H1 62.27亿（+126.9%）已为95亿提供65.5%硬支撑，OCF 1.55x与库存去化验证需求真实，BIS撤销与碳官宣优化估值溢价；**唯一需硬证据的是H2的量（20万吨是否投产）与价（AA 8,500是否含溢价消退）**，两者任一落空仍可守78亿底（-3.7%下行）。**操作：26.00-26.51支撑区积极配置（S1/MA60共振），放量收复27.06（MA20）右侧跟进，突破28.62真高（09-01）加仓，严格止损25.00（保守价下方0.52元）。**
