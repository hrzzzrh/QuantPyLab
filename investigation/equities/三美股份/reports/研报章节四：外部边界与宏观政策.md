# 研报章节四：外部边界与宏观政策

> **研究日期**：2026年07月27日
> **前序承接**：模块三确立了"纯制冷剂标的"的竞争定位。模块四评估外部变量——哪些宏观、政策、地缘因素可能改写三美的投资逻辑？

---

## 一、宏观环境变量

### 1.1 利率与折现率

- 当前中国10年期国债收益率约2.5-2.8%，处于历史低位，折现率的下降提升了DCF估值下的股权价值
- 美联储自2024年9月开启降息周期，2026年联邦基金利率约3.75-4.0%，全球流动性宽松有利于高盈利资产估值
- **对三美的影响**：低利率环境下，年利润20亿+的"现金牛"资产享受估值溢价。但需注意，三美的估值驱动力主要来自盈利增长（E）而非利率变化（r），E的变化远大于r的影响

### 1.2 汇率损益

- 三美股份约30-40%的产品出口（覆盖六大洲），以美元结算为主
- 2025年财务费用从-9,431万转为-3,786万（利息收入减少+汇兑损失增加），说明人民币汇率波动已对公司产生影响
- 2026年上半年人民币汇率在7.1-7.3区间震荡，中性影响
- **关键假设**：人民币升值1%→净利减少约0.5%（出口利润折算损失），影响有限但需持续跟踪

### 1.3 通胀传导

- 萤石粉：2025年均价3,183元/吨（-1.60%），总体平稳，但萤石矿资源稀缺性决定长期价格中枢上移
- 硫酸：2025年均价628元/吨（+68.24%），但绝对值极低，对成本影响微小
- 能源（电力/蒸汽）：占生产成本约5-8%，煤炭价格下行有利于成本控制
- **总体判断**：原材料成本传导风险可控，AHF自给+催化剂自制进一步对冲了上游波动

## 二、监管与产业政策

### 2.1 配额制度——最大的政策红利

| 时间节点 | 政策事件 | 对三美的影响 |
|:---|:---|:---|
| 2024.01 | HFCs配额制正式生效 | **根本性利好**：行业从过剩竞争→供给约束 |
| 2025.04 | 国家方案（2025-2030）发布，明确削减路线图 | **确定性强**：2029前供给不变 |
| 2026.01 | R141b受控用途生产配额清零 | 小幅负面影响（营收占比3.3%） |
| 2026.01 | 禁止生产以HFCs为制冷剂的冰箱冰柜 | 影响极小（冰箱制冷剂以R600a为主） |
| 2026年 | 2026配额方案：主流品种零增长，仅R245fa/R41微增 | 供给刚性持续 |
| 2027.01 | 禁止生产以HCFCs为制冷剂的多联式空调 | 推动R22→R32替换，利好 |
| 2029.01 | 首次削减HFCs基线10% | 第一个真正利空时点 |
| 2030.01 | HCFCs削减至基线2.5%，基本淘汰 | R22市场终结，但三美R22配额仅5.25% |

### 2.2 环保政策

- 欧盟F-Gas法规逐年收紧，推动R1234yf替代R134a（汽车空调）
- 中国2029年起新车禁止使用GWP>150的制冷剂，等同淘汰R134a在新车领域的应用
- **四代制冷剂替代风险**：R1234yf在汽车领域的渗透加速是中长期的确定趋势，但存量维修市场将确保R134a需求在未来10年不会归零

### 2.3 "以旧换新"补贴政策

- 2026年延续家电以旧换新补贴，但对空调的拉动效果边际递减（2024-2025已释放大部分需求）
- 欧盟碳关税（CBAM）对制冷剂出口影响有限——占出口价比例不足3%，且中国企业具备定价权实现转嫁

## 三、地缘政治风险

### 3.1 中美贸易摩擦

- 三美对美国直接出口比例不高（美国占中国空调出口约4.9%，制冷剂间接影响有限）
- 2025年制冷剂R32/R134a出口数据显示，东南亚、欧洲、中东为主要出口目的地
- 美国对华关税风险更多影响下游空调出口，间接影响制冷剂需求，但通过东南亚转口可实现部分规避

### 3.2 中东地缘冲突

- 2026年H1的中东航运冲突已影响制冷剂出口物流（R32出口1-5月同比-52%是明显信号）
- 若中东航线恢复，补库需求有望在H2集中释放，构成下半年催化剂

### 3.3 供应链重构

- 全球制冷剂产能高度集中于中国（R32/R134a全球份额超60%）
- 印度、东南亚国家在基加利修正案第二批基线期内可能增加进口备货
- 不存在显著的"China+1"风险——制冷剂是规模化重化工，门槛极高，短期无法在海外复制产能

## 四、综合评估

| 外部变量 | 影响方向 | 强度（1-5） | 研判 |
|:---|:---:|:---:|:---|
| 配额制度延续 | ✅利好 | 5 | 制度红利是公司最大的确定性来源 |
| 低利率环境 | ✅利好 | 2 | 温和利好，非核心变量 |
| 人民币汇率 | ⚠️中性 | 1 | 影响极小 |
| 原材料通胀 | ⚠️中性 | 2 | AHF自给对冲 |
| R141b配额清零 | ❌利空 | 1 | 短期小鼠，营收占比3.3% |
| 四代制冷剂替代 | ❌远期利空 | 3 | 2029年后才构成实质威胁 |
| 中美贸易摩擦 | ⚠️中性偏负 | 2 | 间接影响，可通过转口缓解 |
| 中东航运中断 | ⚠️短期利空→中期利好 | 3 | 压制出口→H2补库反弹 |
| 欧洲高温 | ✅短期利好 | 3 | 出口增量+长期结构机会 |

**总体结论**：外部政策环境对三美股份极为有利——配额制度是最大的制度红利，环保政策推动二代→三代切换进一步巩固HFCs需求，四代替代是确定但遥远的威胁。在2024-2028年的黄金窗口期内，外部变量偏多。
