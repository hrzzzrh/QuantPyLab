# 研报章节四：外部边界与宏观政策

**研究日期**：2026 年 08 月 29 日
**研究对象**：比亚迪股份有限公司（002594.SZ）

---

## 一、宏观经济环境：温和复苏中的结构性分化（H1验证）

### 1.1 GDP 与内需：增速稳健但消费仍弱——H1数据验证“供强需弱”

2025年GDP +5.0%完成目标，2026年机构预测4.8-5.0%。H1实际：全国汽车产销同比分别下滑4%和4.1%（中汽协上半年口径），国内乘用车零售1-7月1017.3万辆同比-20.3%（乘联会），家电消费等亦承压，验证“宏观与微观体感分化”。

**对比亚迪的影响评估（H1更新）**：

| 宏观变量 | 方向 | 影响机制 | 影响程度 | H1验证 |
| :--- | :---: | :--- | :---: | :---: |
| 实际GDP 4.8-5% | → | 汽车总需求托底 | 中性 | 托底失效：国内-15.2% |
| 名义GDP加速至6%+ | ↑ | 居民收入→购车意愿 | 偏正 | 未兑现：国内零售-20.3% |
| 固定资产投资负增长 | ↓ | 商用车/工程类需求 | 偏负 | 验证：重卡需求分化 |
| 消费增速3.7% | ↓ | 大宗消费弹性受制 | 偏负 | 验证：大宗可选消费弱 |

**核心判断（更新）**：宏观托底力度弱于预期，汽车消费的大宗可选属性在以旧换新透支+收入预期未改善下，自然增长动力为负。H1国内零售-20.3%已印证此前“增长更多依赖政策而非宏观”的判断，且政策托底亦不及预期。

### 1.2 利率与折现率：宽松延续但空间收窄——H1维持

- 政策利率：2025年降准50bp、降息10bp，2026年预计再降息10-20bp、降准50bp（KPMG预测维持）
- 10年期国债约1.7-2.0%

**DCF启示**：低利率压低WACC利好估值，但盈利端-20.54%（H1）的下行抵消折现率利好。H1筹资现金流入913亿（含借款566亿+债券149亿+永续债193亿），融资成本在低利率下受益但汇兑损失抵消。

### 1.3 人民币汇率：升值压力在H1集中兑现

- 2026年3月末6.9081（升值1.2%），H1财务费用汇兑损失51亿 vs 上期收益32.5亿， swing 83亿
- 华泰预测年末6.58（再升5%），招银7.02，东方6.40-6.50

**对比亚迪的双向影响（H1实测）**：

| 通道 | 方向 | H1影响实测 |
| :--- | :---: | :--- |
| 海外营收折算 | ↓ | 海外收入1812亿（+33.9%），但人民币升值使折算减少约18亿/每1%升值 |
| 海外利润汇回 | ↓ | 财务费用51亿损失，奇瑞20.92亿、吉利5.5亿、长城2.66亿同步验证行业性冲击 |
| 进口原材料成本 | ↑ | 锂、铜等以美元计价，升值降低成本，但碳酸锂15.8万高位抵消 |
| 海外资产估值 | ↓ | 巴西、匈牙利等60亿美元+工厂人民币计价价值下降 |

**综合判断（更新）**：H1已兑现“升值5%冲击155亿营收”的测算，且损失已计入利润表。若H2再升5%至6.58，海外收入按7500亿年化再损失约185亿，需通过海外本地化（巴西工厂、泰国工厂）自然对冲，短期汇兑波动仍是利润最大不确定性。

### 1.4 通胀传导：上游涨价在H1全面兑现

- 碳酸锂7.5万→15.81万（Mysteel 8/24均价158,050元/吨，+110%），电池级最低价150,400-156,600，库存去化6320吨/周但仓单4.13万手压制弹性
- 车规存储芯片 DDR5 +300%、DDR4 +150%
- PPI预计-1.0%→-0.2%

H1验证：比亚迪自产电池便宜20%的优势在15.8万高位仍有效（汽车毛利率+1.98pp），但电子业务毛利率-2.67pp显示芯片涨价对电子部件的冲击大于汽车。展望：碳酸锂“8月震荡、9月中下旬看涨”（Mysteel）、中信建投预计Q4缺口峰值，短期难回落至10万。

## 二、监管与产业政策：双刃剑的精准切割（H1细则落地）

### 2.1 以旧换新：从“定额”到“比例”的H1效果检验

2026年细则2025年12月30日发布（商务部等8部门），核心调整：

| 补贴类型 | 新能源车 | 燃油车 | 变化 |
| :--- | :--- | :--- | :--- |
| 报废更新 | 车价12%（最高2万） | 车价10%（最高1.5万） | 从定额2万改为比例，封顶不变 |
| 置换更新 | 车价8%（最高1.5万） | 车价6%（最高1.3万） | 同上 |

**H1效果**：2025年以旧换新超1150万辆（带动1.6万亿），H1国内销量-15.2%显示政策效应递减且透支前期需求。资金按月均衡使用、各地把握节奏导致Q1冲击集中，Q2随政策落地边际缓解。对比亚迪：10-20万主力车型补贴比例最高，但高端品牌（腾势/仰望）补贴弹性降低，结构上不利于高端化。

### 2.2 购置税减免：退坡冲击在H1实测

2024-2025全免（上限3万）→2026-2027减半（上限1.5万），消费者多付4,425-11,549元。H1国内收入-30.68%验证冲击已至，且比亚迪10万级海鸥/海豚弹性最大（销量占比较高）。

### 2.3 「反内卷」政策：行业出清加速但盈利未修复

2025-2026年政策体系：

1. 《汽车行业稳增长工作方案（2025-2026）》八部委
2. 《汽车行业价格行为合规指南》2月施行
3. 供应商账期强制60天
4. 「十五五」新兴支柱产业

**H1验证**：Q1行业利润率3.2%历史最低，H1比亚迪国内-30.68%显示反内卷未转化为盈利，碳酸锂与芯片涨价抵消政策效果。但行业出清逻辑仍成立：7月排产296GWh创历史新高但60%中小厂商产能利用率<40%、亏损，头部产能利用率>85%（宁德时代96.9%），出清将利好比亚迪份额。

### 2.4 技术标准升级：抬高准入门槛（H1无变化）

- GB 38031-2025电池安全7月实施，L3准入2025年12月首批，2026年商业化
- 比亚迪刀片电池超新国标、璇玑A3量产，标准提升将加速竞品淘汰

## 三、地缘政治与贸易摩擦：出海的边界约束（H1重大进展：价格承诺框架落地）

### 3.1 欧盟关税：从硬对抗到软博弈——框架落地但个案未解

**关税结构**：基础10%+反补贴17%（比亚迪，总27%）vs 吉利18.8%、上汽35.3%，2024年10月30日起五年。

**H1重大进展（更新）**：

1. **2026年1月12日**中欧发布《关于提交价格承诺申请的指导文件》，允许中国出口商单独或联合提交价格承诺（最低进口价MIP+销量配额+欧盟投资承诺），替代反补贴税，已获商务部与欧委会共同确认
2. **2026年2月**欧委会首次批准大众安徽Tavascan的价格承诺申请（20.7%税豁免，需满足MIP与配额），成为首例
3. **截至2026年8月**未检得比亚迪获同类豁免的可核验证据，谈判仍在进行中
4. **2026年4月29日**商务部王文涛会见德国VDA，呼吁欧方加快安排中国车企谈判，落实一视同仁
5. **潜在风险**：传闻欧盟拟对插混（PHEV/增程）加征关税（覆盖比亚迪DM-i主力），《工业加速器法案》（IAA）在公共采购中排斥中国产品（电池、电动汽车等），风险从“关税”扩展至“采购壁垒”

**对比亚迪的实质影响（更新）**：
- 价格承诺框架为欧盟提供了**制度性缓冲**，但比亚迪尚未获得个案豁免，2026年出口仍按27%执行，盈利能力取决于匈牙利工厂Q4投产后的本地化规避
- 若插混被纳入征税，比亚迪DM-i出口（占PHEV 660万辆预测中的主力）将受冲击

### 3.2 美国市场：结构性关闭（无变化）

100%关税（2024年5月），无直接销售。USMCA 2026年7月重谈是关键变量，若收紧原产地规则，墨西哥曲线路径将被封堵。

### 3.3 其他关键市场（H1更新）

| 市场 | 关税/壁垒 | 比亚迪应对（H1进展） | 风险评级 |
| :--- | :--- | :--- | :---: |
| 巴西 | 35%+，2027年前50%本地化 | 巴西工厂第10万辆下线（5500人，15万→60万辆），H1巴西销量近10万辆（+107%） | ⚠️⚠️ |
| 土耳其 | 40%附加税 | 10亿美元工厂+研发中心（在建） | ⚠️⚠️ |
| 东南亚（泰国） | 相对友好 | 罗勇工厂15万辆已投产，辐射东盟 | ⚠️ |
| 匈牙利（欧盟） | 规避27%关税 | Q4启动整车装配（15万辆），零关税 | ⚠️⚠️ |
| 印度 | 高壁垒 | 规划中 | ⚠️⚠️⚠️ |
| 俄罗斯 | 报废税提高 | 出口为主 | ⚠️ |

### 3.4 供应链脱钩风险（H1无新增但需警惕）

- 美国：特斯拉等2027年剔除中国零部件
- 欧盟：《外国补贴条例》+ 《新电池法》2028年碳足迹阈值
- 若东南亚效仿美国推出原产地限制，海外建厂有效性将打折

### 3.5 中欧贸易摩擦最新（2026年1-8月）

- 2026年1月价格承诺框架发布，6月技术团队北京五轮磋商达成“技术性共识”，但欧盟成员国意见仍不一致
- 2026年5月欧盟拟推IAA法案，精准瞄准中国优势产业（电池、电动汽车等）
- 中国商务部认定欧盟相关做法构成贸易投资壁垒，保留反制权利

## 四、政策与战略对齐度评估

### 4.1 与「十五五」规划的战略契合

| 政策方向 | 比亚迪现状（H1更新） | 对齐度 |
| :--- | :--- | :---: |
| 智能网联新能源汽车→新兴支柱产业 | H1全球销量冠军+储能双冠 | ★★★★★ |
| AI+制造全链条融合 | 璇玑A3量产+闪充网络破万座 | ★★★★☆ |
| 双碳目标/绿色转型 | 100%新能源+储能全球第一 | ★★★★★ |
| 产业链自主可控 | 垂直整合+芯片/电池自供90%+ | ★★★★★ |
| 深化使用管理转变 | 闪充站+海外本地化 | ★★★★☆ |

### 4.2 政策红利的时间窗口

- **2026年**：购置税减半+以旧换新比例补贴——H1验证为“减量版红利”（国内-30.68%）
- **2027年**：购置税最后一年+以旧换新是否延续不明——存量红利末期
- **2028年起**：若政策完全退出，需纯市场驱动——裸泳期

## 五、模块小结：外部边界的核心矛盾（H1更新）

1. **宏观托底失效**：GDP 5%未能对冲国内-15.2%的塌陷，宏观与微观背离加剧
2. **政策红利从“扩张”转为“收缩”**：以旧换新改为比例、购置税减半，H1国内-30.68%显示红利收缩已产生真实冲击
3. **汇率从“潜在变量”转为“已兑现风险”**：H1汇兑损失51亿，海外52.57%占比使敞口成为利润主导变量
4. **欧盟从“单一关税”转为“关税+采购+投资”立体壁垒**：价格承诺框架提供缓冲但比亚迪个案未解，IAA法案与插混征税传闻是新灰犀牛
5. **反内卷+技术标准→行业出清→龙头受益**：H1中小厂商亏损60%、产能利用率<40%验证出清逻辑，但盈利修复仍需时滞

**对模块一、二、三核心红线的外部边界维度验证（更新）**：
- 「存货1899亿」的风险部分源于海外建厂的地缘“被迫选择”与国内需求塌陷的叠加
- 「国内份额被蚕食」在反内卷下有望边际改善，但H1国内-30.68%显示改善尚未兑现
- 「海外高增长」在价格承诺框架下获得制度性缓冲，但汇率与插混征税是次生风险
