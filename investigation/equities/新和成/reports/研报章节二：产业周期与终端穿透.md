# 研报章节二：产业周期与终端穿透

**研究日期**：2026年07月19日  
**股票代码**：002001（新和成）  
**前序核心结论继承**：  
> 新和成以营养品（营收占比66.45%）为核心利润引擎，其中维生素与蛋氨酸是两大支柱；公司正处于CAPEX周期尾声的自由现金流收获期（2025年OCF 87.97亿远超投资支出44.24亿）；2025年毛利率44.67%创近五年新高。2026年H1维生素和蛋氨酸价格经历了地缘驱动的脉冲式暴涨后快速回落，5月26日以来市场格局发生剧变，本模块将对此进行深度穿透。

## 一、产业生命周期与库存节奏

### 1.1 维生素行业：成熟但格局重塑

维生素行业是典型的**成熟期产业**，全球年需求增长约3%-5%，与饲料产量增速高度相关。中国已占据全球维生素产量的89%（2025年约49.1万吨），是全球绝对供给中心。

**生命周期特征**：
- **技术成熟度极高**：VA合成路径以Roche路线和BASF路线为主，VE以异植物醇+三甲基氢醌路线为主，核心技术壁垒集中在上游关键中间体（柠檬醛、异植物醇）。这些中间体的制备能力是真正的行业准入壁垒。
- **行业格局正在剧烈重塑**：万华化学1万吨VA产能于2024年底投产，产能跃居全球第二；天新药业、花园生物等新进入者加入VA竞争；巴斯夫2024年爆炸事故及后续复产不确定性使得供给格局持续动荡。
- **淘汰赛逻辑**：环保法规趋严（如2025年VOC排放新规），行业落后产能正在被挤出，市场份额向具备原料自供能力和全产业链配套的龙头企业集中。

**库存动力学**：
- 2024年受巴斯夫断供冲击，下游厂商恐慌性超买，渠道库存累积。2025年上半年，随着巴斯夫宣布复产，渠道商开始去库存，维生素价格从2024年高点（VA 300元/kg）急跌至60元/kg以下的历史低位。
- **2025年下半年至2026年初**：行业库存降至近五年低位（仅够1.5个月使用），叠加成本推升和供给检修，行业进入**被动去库→主动补库**的切换阶段，价格强势反弹。VA从63元/kg涨至105元/kg（+67%），VE从55.5元/kg涨至105元/kg（+89%）。
- **2026年Q2以来：补库结束+巴斯夫复产**，进入**被动去库消化阶段**。截至7月15日，VA主流价格57-62元/kg，VE主流价格68-70元/kg，较4月高点（VA/VE均曾至105-116元/kg）已大幅回落45%-46%。

### 1.2 蛋氨酸行业：成长期末段，产能竞赛白热化

蛋氨酸行业正处于**成长期向成熟期过渡**的关键节点。

**全球供需全景（2025年）**：
- 全球名义产能约230-260万吨/年，有效运行产能约200万吨/年
- 全球需求约185万吨/年，需求增速5%-6%（年增量10万吨以上）
- 中国产能107.4万吨/年（占全球41%），同比暴增47.3%
- CR3（赢创、安迪苏、新和成）产能占比74%

**行业结构性特征**：
- **高壁垒**：蛋氨酸化学合成工艺（海因法/氰醇法）极为复杂，资金和技术壁垒双高，历史上由赢创、安迪苏、诺伟司、住友四大国际巨头垄断。
- **中国实现进口替代到净出口**：2025年中国净出口蛋氨酸约28-32万吨，从净进口国转为净出口国，产业话语权显著提升。
- **需求结构性增量**：中国持续推进豆粕减量替代政策，饲料配方中豆粕比例下降需要用更多合成氨基酸补充——这是蛋氨酸需求的长期结构性驱动力。

**库存与价格动力学——2026年剧烈的过山车**：
- 2026年初固蛋价格18.5元/kg（1.8%历史分位）。
- 2月28日美以对伊朗发动军事打击→伊朗封锁霍尔木兹海峡→能源/原料成本飙升+赢创新加坡和住友化学先后宣布不可抗力停产（合计影响全球产能约20%）→蛋氨酸3个月内暴涨至52元/kg（+195%）。
- 4月中旬美伊停火谈判→5月中旬价格回落至39-40元/kg。
- **6月14日**：特朗普宣布与伊朗达成和平协议，6月19日签署。
- **6月20日**：以色列攻击黎巴嫩→伊朗以违反协议为由重新封锁海峡。此后美伊围绕海峡控制权反复拉锯。
- **7月6-7日**：伊朗攻击海峡商船→美恢复大规模空袭→7月7日特朗普宣布停火"结束"。
- **7月12日**：伊朗宣布霍尔木兹海峡**无限期关闭**。
- **7月14日**：美国恢复对伊朗港口及沿海的海上封锁。双方连续交战，截至7月16日美军已6晚连续空袭。
- **最新价格**：蛋氨酸7月初约33.7元/kg（Mysteel），远低于Q1峰值52元/kg但较年初18.5元/kg仍有82%涨幅。

**核心辨析（重大更新）**：此前5月26日研报判断"美伊和平协议即将达成→蛋氨酸地缘溢价全面消退"。**这一判断被事实推翻**：协议虽签署但在25天内即告破裂，当前霍尔木兹海峡的封锁状态比5月时更加严峻。这意味着：
1. 蛋氨酸的地缘溢价并未如预期消退，而是经历了一轮"签协议→破裂→重启战争"的剧变。
2. 海峡无限期关闭意味着赢创新加坡+住友化学的产能恢复遥遥无期，全球约20%的蛋氨酸产能继续受困。
3. Q1式的供给冲击可能在Q3重演——若中国厂家集中检修+战争持续→蛋氨酸价格可能在H2再度脉冲式上涨。
4. **但这并非可以定价的确定性**：战争烈度和持续时间完全不可预测，将蛋氨酸涨价纳入估值模型是不审慎的。需将其视为"不确定性向上期权"而非基准假设。

**当前处于**：地缘溢价消化后的低位→但战争重启提供新的供给不确定性→蛋氨酸价格获得底部支撑（33-34元/kg远高于年初18.5元/kg），且存在向上的尾部风险（若战争升级+检修季叠加）。

### 1.3 香精香料行业：成熟稳健，结构性升级

香精香料行业是**成熟稳健型**产业。全球市场约411亿美元（2025年），年化增速约6.8%（至2029年达534亿美元）。中国市场约800亿元（2025年），预计2030年达1100亿元，CAGR约6.5%。

**行业特征**：
- 国际巨头（奇华顿、芬美意、IFF、德之馨）主导高端市场，国内企业在大宗合成香料领域具备国际竞争力。
- 天然化、功能化、定制化趋势明确：天然香料占比从30%（2024）提升至目标45%（2030）。
- 新和成是全球第三大柠檬醛生产商，在芳樟醇、柠檬醛、覆盆子酮等关键香料中间体领域具备显著话语权。

### 1.4 高分子新材料（PPS）：成长期，结构性高景气

- 全球PPS市场约17亿美元（2024），预计2032年达32-37亿美元，CAGR 6.6%-10.15%。
- **核心驱动力**：新能源汽车轻量化（占PPS需求40%+）、电子电气（连接器、绝缘件）、航空航天。
- 新和成是国内唯一能稳定生产纤维级、注塑级、挤出级、涂料级PPS全系列的企业，且正在建设从己二腈到尼龙66的全产业链。

## 二、终端需求穿透与跨期断层审计

### 2.1 终端产品画像

新和成的产品最终负载于以下终端形态：

| 产品线 | 直接下游 | 最终终端形态 |
|:---|:---|:---|
| 维生素（VA/VE等） | 饲料预混料 | 猪肉、鸡肉、鸡蛋、牛奶 → 人类动物蛋白消费 |
| 蛋氨酸 | 饲料添加剂 | 同上 |
| 香精香料 | 日化/食品配方 | 洗发水、洗衣液、饮料、零食 → 消费者日用品 |
| PPS/PPA | 汽车/电子零部件 | 新能源车、5G基站、手机连接器 → 工业与消费电子 |

### 2.2 饲料终端景气度审计（2026-2028年）

**核心数据**（来源：全国畜牧总站"十五五"规划分析）：
- 2025年中国工业饲料总产量3.42亿吨（+8.6%）
- 猪饲料1.66亿吨（+15.6%），肉禽饲料1.01亿吨（+3.5%），蛋禽饲料3282万吨（+1.4%）
- 中国人均动物蛋白消费量2025年为25.0kg/天，预计2028年达峰25.85kg/天
- 人均肉类消费预计2028年达峰77kg，之后随老龄化下降
- **饲料总需求预计2028年前后达峰**（约5.09-5.2亿吨），此后逐年下降

**对维生素/蛋氨酸需求的影响**：
- **短期（2026-2028年）**：饲料产量仍处高位且缓慢增长，维生素和蛋氨酸需求有支撑。
- **中期（2028年后）**：饲料总量见顶回落，需依赖单位饲料添加剂价值量提升（低蛋白日粮配方推动氨基酸添加比例提升）来对冲。
- **结构性利好**：豆粕减量替代政策使得蛋氨酸添加量有持续提升空间（当前中国肉鸡饲料蛋氨酸添加比例约0.1%，理论可提升至0.25%）。

### 2.3 跨期断层审计：需求前置风险识别

**强制审计项一：是否存在"需求前置"导致跨期断层？**

1. **2024年维生素超买风险**：2024年巴斯夫爆炸事故后，下游厂商超量购买VE/VA（价格飙升至300元/kg），导致2025年上半年需求被透支、价格大幅回撤。**2026年呈现更短促的周期**：Q1 VA/VE快速冲高后，Q2价格已回落至年初水平以下（VA 57-62 < 年初63），说明下游消化库存速度极快且补库意愿极弱。

2. **蛋氨酸地缘溢价风险（重大更新）**：Q1蛋氨酸暴涨195%的核心驱动是中东地缘冲突。5月26日研报判断"和平协议即将达成，地缘溢价将消退"——协议确实在6月19日签署，但在25天内即告破裂。当前（7月19日）**霍尔木兹海峡无限期关闭，美伊战火重燃，局势比5月时更加恶化**。蛋氨酸价格在H1的回落（52→33.7元/kg）主要源于市场对和平的预期定价+巴斯夫VA复产减轻焦虑，**而非供给实质性恢复**。战争重启意味着H2蛋氨酸供给不确定性再次升高。

3. **饲料总量达峰风险**：中国饲料需求预计2028年达峰，这是维生素/蛋氨酸行业未来面临的**最核心的长期需求断层风险**。届时行业将从"增量博弈"转入"存量博弈"，只有具备成本优势的龙头企业能够存活。

**结论**（修订）：短期（2026年H2）维生素价格已回到低位区间，下行空间有限但上行催化不足；蛋氨酸价格已消化地缘乐观预期，但战争重启提供了远超5月预期的上涨尾部风险。

### 2.4 动能溯源与透支审计

**本轮增长动能拆解**：

| 增长动力 | 类型 | 可持续性评估 |
|:---|:---|:---|
| 维生素价格反弹 | 外生（供给冲击）+ 内生（补库周期） | **已终结**（补库完全结束，价格已从高点-45%，低于年初水平） |
| 蛋氨酸量价齐升 | 外生（地缘冲击）为主 | **不确定性大幅上升**（地缘溢价已消退但战争重启——向上尾部风险） |
| 蛋氨酸产能释放 | 内生（公司产能建设完成） | **高**（CAPEX已完成，产能是硬资产） |
| PPS/新材料增长 | 内生（需求升级）+ 产业政策 | **高**（新能源/5G长期趋势确定） |
| 香精香料稳健增长 | 内生（消费升级） | **高**（长期稳健） |

## 三、供需边际与压力传导

### 3.1 供需平衡审计

**维生素**：
- 全球VA产能约5-6万吨/年。供给端：巴斯夫VA 6月24日**已正式解除不可抗力**（这是5月26日以来最大的供需变化）、新和成8,000-10,000吨、万华化学10,000吨（爬坡中）、帝斯曼7,500吨。巴斯夫复产+万华扩产意味着VA远期供给将显著宽松。但短期：新和成/浙江医药/北沙/天新多厂仍在集体检修中，VE供给仍偏紧。新和成VE最新报价78元/kg（7月13日），新发药业7月17日提价至70元/kg。
- **预判**：VA供需边际从紧平衡加速滑向宽松（巴斯夫复产+万华爬坡）；VE短期紧平衡（多厂检修），中期关注巴斯夫VE不可抗力何时解除。

**蛋氨酸**：
- 全球产能260万吨 vs 需求185万吨，**名义产能已严重过剩**（过剩率约40%）。但实际有效运行产能约200万吨。
- **战争重启带来的供给新格局（重大更新）**：霍尔木兹海峡无限期关闭意味着赢创新加坡+住友合计约20%全球产能的恢复遥遥无期。这改变了5月时的预判——当时假设和平协议将使这20%产能在Q3恢复。现实是：这20%产能不仅未恢复，其恢复时间表完全取决于不可预测的战争走向。
- **检修季叠加**：新和成固蛋6月10日-7月15日检修已完成；液蛋7月中旬起检修6-7周（正在进行）；赢创Q3检修7-8周。检修+战争双重供给收缩可能使H2蛋氨酸供给偏紧。
- **关键预判（修订）**：蛋氨酸价格中枢较5月预判上移。中性假设下H2蛋氨酸均价35-38元/kg（vs 5月预判H2回落至25-30）。若战争持续+检修叠加→乐观场景H2均价40-45元/kg。整体蛋氨酸价格中枢从25-35元/kg上移至30-40元/kg。

**PPS/新材料**：
- 全球需求增速6%-10%，中国需求增速更高。新和成是国内唯一全系列PPS供应商，且正在建设尼龙66产业链，**供需处于成长期的健康状态**，尚无过剩风险。

### 3.2 压力传导特征分析

**维生素**：维生素在饲料成本中占比仅0.15%-0.51%，下游对涨价的敏感度极低。这意味着：
- **波动放大效应**：即使维生素价格翻倍，对饲料成本的影响也不足1%，不会遭遇下游强烈抵制。
- **传导时滞短**：涨价可直接传导至饲料企业，博弈阻力小。
- **定价权**：供给收缩期维生素企业拥有极强的短期定价权。但在当前供给宽松期（巴斯夫VA复产+万华爬坡），定价权明显变弱。

**蛋氨酸**：蛋氨酸在饲料中添加比例约0.1%-0.3%，但因是动物**必需氨基酸**（不可替代），下游刚性需求支撑涨价的传导。战争重启+集中检修背景下，蛋氨酸厂家挺价能力增强。

**PPS**：PPS在汽车/电子领域面对的客户是大型OEM，议价能力相对较弱，但PPS的技术壁垒（国内唯一全系列供应商）赋予新和成一定的供给稀缺性溢价。

## 四、强制复核项确认

1. **终端产品未来两年景气度预测** ✅ 已穿透：饲料总产量预计2028年前后达峰，2026-2027年仍处高位；PPS受益于新能源车和5G持续高景气；香精香料稳健增长（CAGR 6.5%）。

2. **刺激政策导致的"跨期需求移位"审计** ✅ 已审计：豆粕减量替代政策对蛋氨酸需求是渐进式结构性利好。

3. **供需边际演变与压力传导分析** ✅ 已完成并修订：维生素中期趋于宽松（巴斯夫复产+万华爬坡）；蛋氨酸名义产能过剩但战争造成的有效供给收缩改变了短期格局；PPS处于健康成长期。

4. **美伊战争影响重新评估** ✅ 已完成：5月26日"地缘溢价消退"的判断被证伪。战争重启使蛋氨酸供给不确定性上升，H2蛋氨酸价格中枢上移。
