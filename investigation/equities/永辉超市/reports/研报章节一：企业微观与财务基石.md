## 一、公司概况与商业模式

永辉超市（601933.SH）成立于2000年，总部位于福州，曾是中国生鲜超市赛道的标杆企业。公司以"生鲜为王"起家，通过产地直采、冷链物流和低价策略，在传统大卖场时代建立了独特的生鲜供应链护城河。2024年9月，名创优品（MINISO）旗下广东骏才国际以约62.7亿元受让牛奶公司（21.08%）、京东系（8.32%）合计29.40%股份，成为第一大股东，公司进入无实控人状态。2024年5月起，公司启动对标胖东来模式的"品质零售"战略调改，从"规模扩张"全面转向"质量增长"。

### 商业模式演变

**调改前（2021-2024年初）**：传统KA大卖场模式——依靠规模效应获取供应商进场费、堆头费、促销服务费等"后台费用"作为主要利润来源，前台商品毛利较低。SKU高达16,000个以上，追求"全品类一站式购齐"。该模式在电商冲击和社区团购分流下逐渐失效。

**调改后（2024年5月起）**：
- **商品结构**：SKU从16,000+压缩至8,000-10,000个，生鲜及3R（即食/即烹/即热）占比从30%提升至55%，食品用品等标品占比从70%压缩至45%
- **盈利模式**：废除"后台费用"模式，转为"裸价直采"——供应商以最低出厂价供货，公司自主承担库存跌价风险，前台毛利全额归属公司
- **供应链**：汰换56%-65%的尾部供应商，聚焦200家核心供应商建立直采合作，生鲜直采比例提升至60%以上，采购成本下降10%-15%
- **自有品牌**：2025年8月启动"品质永辉"自有品牌，已推出60支单品，计划2026年推出200支，中长期目标销售占比达30%-40%

### 当前门店网络

截至2026年6月30日，公司全国已开业门店总数382家（2024年末775家），覆盖全国24个省和直辖市，其中已完成胖东来模式调改门店331家，另有已签约未开业门店28家（储备面积20.52万平方米）。2025年全年新开9家、关闭381家（年末403家）；2026年上半年新开3家、净减21家（其中Q1净减11家至392家、Q2净减10家至382家）。公司2026年计划闭店约24家、调改64家（问询函回复口径）——大规模"瘦身"已近尾声。

### 2.2 分季度利润波动——2025年极端分化的根源

2025年各季度归母净利润分别为：Q1 1.48亿 → Q2 -3.88亿 → Q3 -4.69亿 → Q4 -18.43亿。Q4巨亏占到全年亏损的72%，其背后是多重压力的集中释放：

| 因素 | Q4影响额(亿) | 说明 |
|:---|:---:|:---|
| 调改一次性费用 | ~4.5 | 全年调改一次性费用8.40亿，Q4加速（调改93家+闭店50家） |
| 资产减值 | 1.65 | 调改效果不及预期门店+2026年拟闭店门店的长期资产减值 |
| 金融资产公允价值变动 | -1.82 | Advantage Solutions股票下跌+万达商管股权估值调整 |
| 云金科技股权减值 | 0.91 | 拟转让云金科技65%股权 |
| 存货跌价 | 0.42 | 裸价采购模式下Q4白酒价格普跌 |
| 闭店损失 | ~1.0 | 租赁违约金、人员赔偿、资产报废 |

若剔除以上合计约10.3亿的一次性/非现金损失，2025年核心经营亏损约15亿量级，较2024年（约10亿量级）有所恶化，反映调改阵痛期的真实经营压力。

**2026年调改影响大幅收窄**：2026年预计仅闭店24家、调改64家（公司问询函回复口径），两项对税前利润的影响预计从2025年的-11.13亿收窄至约-2.13亿。在不考虑已调改门店业绩增长的情况下，仅"不再折腾"就释放约9亿税前利润。

### 2.3 H1 2026半年报正式数据——扭亏踩线达标

2026年8月20日晚公司披露半年度报告：H1营业收入237.91亿元（-20.56%），归母净利润2.53亿元（上年同期-2.41亿，扭亏为盈），扣非归母净利润0.39亿元（上年同期-8.02亿）。与7月14日业绩预告（归母2.5亿/扣非0.3亿）基本一致，属"踩线达标"。结合Q1实际归母2.87亿元倒推：

**Q2单季归母净利 ≈ -0.34亿元（再陷亏损），扣非单季约-2.08亿元**

这一数据揭示了关键隐忧：
- Q1为零售传统旺季（春节因素），Q2为淡季，季节性回落属正常——但Q2再次转亏且扣非亏损幅度（-2.08亿）远大于归母口径，说明核心业务盈利基础仍不牢固
- H1综合毛利率22.52%（同比+1.71pct，其中Q2单季约22.25%仅较Q1的22.77%小幅回落）；期间费用率21.83%，同比-1.75pct——毛利率韧性与费用优化确在推进
- 扣非净利仅0.39亿 vs 归母2.53亿，差额约2.14亿为非经常性损益：非流动资产处置收益0.87亿、金融资产公允价值变动及处置收益1.06亿（含Advantage Solutions股票公允价值变动收益0.89亿）、政府补助0.31亿等——核心业务盈利质量一般
- **所得税费用1.17亿元**（部分盈利主体缴税而亏损主体无法抵扣），对利润表形成实质性侵蚀
- 公司明确2026年不再进行大范围闭店调改，进入"休养生息"阶段，意味着H2盈利改善更多依赖存量调改门店的稳态经营释放；下半年将在北京、广州、成都、呼和浩特等城市推进第二阶段调改门店亮相

### 3.2 净资产大幅缩水的成因与最新修复

公司2021年末每股净资产约1.17元（归母权益约106.59亿），到2026H1末仅0.24元，四年蒸发约79%。核心原因：

1. **累计巨亏侵蚀**：2021-2025年累计归母亏损约120.53亿元，直接削减未分配利润
2. **关店资产出表**：2024年以来大规模关店（775→382家）导致使用权资产和租赁负债同时大规模减少，但资产处置损失（装修残值报废、租赁违约赔偿）加速了净资产缩水
3. **回购注销**：公司累计回购1.50亿股已全部注销（均价3.258元），回购成本约数亿元

**积极信号**：2026H1归母净资产回升至21.68亿元，较2025年末18.59亿增加3.09亿（+16.6%）——盈利积累开始重建安全垫。若公司按2026E中性预测盈利4.0亿，年末净资产约26亿——2026年内不存在净资产转负的紧迫风险。真正触发退市风险的路径是：①定增持续失败+公司连续数年每年亏损5-10亿量级；②审计师出具"持续经营重大不确定性"意见。

**定增的重要性**：公司计划定增募资不超过31.14亿元，若成功实施，每股净资产将大幅回升至约0.6元左右，显著增强财务安全垫，为转型赢得2-3年时间窗口。**最新进展偏负面：定增自2025年10月申报以来审核近10个月未获上交所通过，公司已于8月21日公告将股东会决议有效期延长12个月至2027年9月17日（尚需临时股东会审议）**。若定增持续失败，公司需依靠银行信贷和经营现金流维持运营——在H1经营现金流仅1.99亿、现金净流出7亿的背景下，长期可持续性面临考验。

### 3.3 负债端的几点关注

1. **租赁负债85.70亿（非流动）+一年内到期部分**：仍是最大负债科目，对应382家门店的长期租约。随着闭店推进和租约到期，租赁负债将持续缩减——这是天然的"去杠杆"过程
2. **短期借款34.62亿**：较年初下降但绝对额仍高。2026年度申请银行授信额度146.6亿元，反映公司仍维持银行渠道融资能力
3. **合同负债38.87亿**：主要为预收顾客的购物卡余额，一方面是无息负债（零资金成本），另一方面反映消费者对永辉品牌的信任基础仍在
4. **应付账款52.51亿**：较2024年末81.21亿、2025年末67.56亿持续下降，与关店后采购规模缩减一致。应付账款周转天数是观察供应商信心的关键指标

## 五、核心财务识别——调改门店单位模型

### 5.1 调改门店的经济学

根据公司公告和公开披露数据：

| 指标 | 调改前 | 调改后 | 变化 |
|:---|:---:|:---:|:---|
| 坪效(月均，元/㎡) | 2,800（基准） | 3,182（2025年调改满6个月的123家门店实测） | +13.6% |
| 毛利率 | ~18% | ~22.1%（调改满6个月） | +4.1pct |
| 客流 | - | +80%（初期） | - |
| SKU数 | 16,000+ | 8,000-10,000 | -37%-50% |
| 生鲜+3R占比 | ~30% | 55% | +25pct |
| 单店员工数 | ~80-100人 | ~120-150人（含加工人员） | +50% |
| 员工薪酬 | 行业平均 | 提升20%-30% | - |

调改门店的门店升级改造项目税后IRR为21.57%，回收期4.84年（公司定增测算，216家门店改造完成后T+3年合计营收328.17亿、税前利润6.74亿）。3,182元/㎡月坪效距离胖东来门店（约4,500-5,000元/㎡）仍有较大提升空间。

### 5.2 盈利复苏路径的数学推导

假设2026年末约375家门店中331家已调改门店全部进入稳态（调改满6个月）：

- 调改门店年均单店营收：假设坪效3,182元/㎡、单店面积约5,000㎡（调改后实际经营面积），年化营收约1.91亿元/店 → **331家调改店年营收满产约632亿**
- 但实际2025年营收仅535亿、2026H1仅237.91亿——因大量门店在2024-2025年才完成调改（运营时间不足全年），且未调改尾部门店持续亏损收缩

**营收预测的关键约束**：门店数已从775家骤降至382家，即使单店坪效提升，总营收很难回到700亿以上。中性假设2026年全年营收约455亿（H1实际237.91亿+同比法推演的H2约217亿，详见章节五推导）。

## 八、小结：财务基石的定性与定量锚

永辉超市正处于一场"不成功便成仁"的深度变革中。财务层面呈现"至暗时刻已过但曙光尚弱"的格局：

**积极信号**：
- H1实现归母盈利2.53亿（扭亏踩线达标），归母净资产回升至21.68亿（较年初+16.6%）
- 毛利率趋势性回升（19.83%→22.52%），供应链改革初见成效且Q2韧性（22.25%）好于季节性预期
- 自有品牌销售占比达10.07%（6月单月11.47%），大幅超出此前市场预期
- 大规模闭店接近尾声，一次性费用2026年预计大幅降至约2.13亿（vs 2025年11.13亿）
- 生鲜及加工品类营收仅-3.97%（基本盘稳固），验证客流向调改店迁移

**核心隐忧**：
- 资产负债率93.04%、每股净资产0.24元——财务安全垫极薄，若中长期持续亏损可能累积触发退市风险
- Q2再次亏损（归母-0.34亿、扣非-2.08亿），全年扣非盈利确定性不足
- 经营现金流急剧恶化（H1仅1.99亿、-83.5%，Q2转负），现金净流出7.01亿——造血能力与利润表背离
- 定增审核近10个月未获批，决议有效期被迫延长12个月——融资时间窗口后移
- 万达仲裁36.39亿执行生变，潜在流动性补充存在重大不确定性

**财务基石的定价含义**：公司的财务脆弱性决定了其不适用于传统PE/PB估值框架。PB因净资产极薄而失真（12.64倍），PE因TTM仍亏损而无效。PS TTM约0.58倍处于近5年PS中枢（0.39倍）上方约48%位置——给定营收仍在收缩（H1 -20.56%），当前PS并非极端低估。估值逻辑必须建立在"2026年全年能否实现扣非盈利"这一核心假设之上。
