## 二、核心竞争对手深度对比

### 2.1 山姆会员店——品质零售的"天花板"

**竞争优势**：
- 自有品牌Member's Mark贡献约30%销售，全球供应链议价能力无与伦比
- 前置仓"小时达"网络覆盖核心城市（云仓500多个），线上销售占比近50%
- 会员续卡率极高（中国约80%+），付费会员模式形成持续收入流
- 2025年销售超1,400亿（同比约+40%）、付费会员超1,070万；FY27Q2沃尔玛中国净销售（固定汇率）+20.7%、可比销售+13.1%、山姆中国会员数创历史新高
- 扩张提速：2026年计划新开13家（首进石家庄/济南/青岛/佛山/台州，年末达76家），并下沉至江阴等百强县

**对永辉的威胁程度：★★★（中等，上调）**
- 价格带差距大（客单价200-400 vs 80-120），客群重叠有限
- 山姆76家vs永辉382家的门店覆盖度差异仍显著，但其"百店计划"正加速向三四线及县域渗透——开始侵蚀永辉腹地的高消费客群
- 山姆的品质标准和自有品牌能力是永辉努力追赶的"终局目标"

### 2.2 盒马——全渠道最接近的竞争对手

**竞争优势**：
- 盒马鲜生+超盒算NB双业态覆盖中端和折扣两端（鲜生约500家+超盒算NB约500家，全业态2026年末目标超1,100家）
- 线上占比60%+，数字化能力和用户数据远超永辉；前置仓已超520个、2026年底目标1,000个以上
- 自有品牌和联名款开发成熟，"盒马工坊""盒马有机"等系列深入人心
- FY27Q1阿里即时零售业务收入532.95亿（同比+45%），盒马订单与收入保持强劲增长并向新兴市县拓展；GMV冲击千亿且FY2025已实现经调整EBITA转正
- 超盒算NB开放华东加盟后加速下沉至县域市场（2026年覆盖300+县域）

**对永辉的威胁程度：★★★★（中高）**
- 盒马鲜生与永辉调改店在客群、价格带、SKU深度上直接竞争
- 超盒算NB以折扣模式切入社区和县域，抢夺永辉社区生鲜客群——其扩张重心（70-80%在三四线及县域）与永辉腹地正面重叠
- 盒马线上运营能力显著领先——永辉线上占比仅19.35%，而即时零售行业正以12.6%的增速扩张，线上短板被进一步放大

### 2.3 胖东来——"精神标杆"与"无法复制的传奇"

胖东来的数据令人震撼：14家门店（许昌/新乡13家+2025年末新增三胖店）、2025年集团销售235.31亿（同比+38.71%），其中超市业态126.43亿。2026年上半年集团累计销售139.5亿元（+24.23%），其中超市业态75.03亿。时代广场店单店年销约60亿元。2025年净利润约15亿、8,000多名员工税后平均月薪9,000元。

**关键变化——郑州店10月开业**：于东来已确认胖东来郑州店（首个异地项目）预计2026年10月开业。这是胖东来首次走出许昌/新乡，将直接检验其模式在省会市场的复制能力；郑州亦是永辉调改的重点城市之一。

**胖东来为何"不可复制"**：
1. **创始人IP**：于东来的个人声誉和价值观贯穿整个组织，是"企业文化护城河"
2. **极致员工福利**：税后平均月薪9,000元、拟推行"亲人离世带薪假"等极致福利——这在劳动密集型的零售业是天文数字
3. **区域深耕**：长期仅深耕河南许昌、新乡两市（郑州店是首次试探性外延）——供应链管理和品质控制的难度呈指数级增长
4. **不追求利润最大化**：于东来公开表示"赚合理的钱"，将利润大量分配给员工和消费者

**永辉从胖东来学到了什么（可复制的）**：
- 商品结构（精选SKU、生鲜占比提升）
- 裸价直采（废除后台费用）
- 门店场景化（十大健康场景）
- 员工关怀（利润分享、薪酬提升）

**永辉难以学到什么（难以复制的）**：
- 创始人驱动的企业文化内核
- 不追求利润最大化的经营哲学（上市公司面临盈利压力）
- 极致的区域密度带来的供应链效率（14家店集中豫南 vs 382家店遍布全国）

**判断**：永辉学胖东来，学到的是"术"（商品、陈列、定价），但"道"（文化、哲学、组织）的转化需要更长时间。这不是不可行，而是需要持续迭代。胖东来郑州店的经营表现将成为品质零售赛道天花板的重要观察样本。

### 2.4 奥乐齐/超盒算NB——折扣业态的降维打击

**竞争优势**：
- 奥乐齐自有品牌占比90%+，SKU仅1,500-2,000个，极致单品效率
- 价格低至传统超市的50%-70%，对价格敏感客群有"不可抗拒"的吸引力
- 2026年Q1奥乐齐门店突破100家，从上海扩展至长三角——增速惊人
- 超盒算NB近500家门店（2026年5月），开放加盟后加速下沉至县域市场

**对永辉的威胁程度：★★★（中等）**
- 折扣店的核心客群（价格极度敏感）与永辉调改店的核心客群（追求质价比）有一定重叠但不完全一致
- 折扣店的购物体验（简装修、少服务）与品质零售（场景化、高标准服务）是两种不同的价值主张
- **真正的威胁是：如果经济下行压力持续加大，消费者"降级"可能从折扣店蔓延至品质零售——即永辉的客群可能被"向下吸走"**

### 2.5 即时零售平台——看不见的对手

朴朴超市、叮咚买菜、美团买菜/小象超市、淘宝闪购等前置仓/即时零售平台，是永辉最"看不见"却最致命的竞争者。它们：
- 30分钟达的时效碾压线下超市
- 前置仓模式损耗率更低（不用陈列展示）
- 用户数据和推荐算法精准
- 正在从"生鲜电商"扩展到"即时零售全品类"

行业背景：2026年即时零售市场规模突破1.2万亿元（+12.6%），县域下沉市场增速62%；阿里FY27Q1即时零售收入+45%并宣布加速整合盒马/天猫超市发展非餐饮品类即时零售——行业处于爆发期。

**永辉线上业务的防御**：2026H1线上销售额48.68亿（占比19.35%，同比提升1.0pct），其中自营"永辉线上超市"25亿（日均18万单）、第三方平台23.68亿（日均17.3万单），APP注册用户1.24亿。媒体报道永辉重庆41个前置仓已实现区域盈利（来源：虎嗅网援引报道，未经公司公告确认）。但线上能力仍是永辉的短板。

## 三、护城河识别——永辉还剩什么？

### 3.1 正在消亡的旧护城河

| 旧护城河 | 描述 | 瓦解原因 |
|:---|:---|:---|
| 生鲜供应链 | 产地直采+冷链物流（曾是最强壁垒） | 社区团购/前置仓的供应链效率更高，生鲜直采不再是差异化优势 |
| 门店规模 | 全国1,090家门店（峰值） | 大规模关店后仅剩382家，规模效应大幅削弱 |
| 价格优势 | 低价生鲜引流 | 折扣店和社区团购价格更低 |

### 3.2 正在构建的新护城河

| 新护城河 | 当前状态 | 护城河深度评估 | 可持续性 |
|:---|:---|:---:|:---:|
| **品质零售的规模化网络** | 331家调改店+28家签约储备，全国范围 | ★★★★ | 一旦建成，竞争对手难以短期复制300+店的品质零售网络 |
| **自有品牌"品质永辉"** | 综合矩阵H1销售25.33亿、占比10.07%（永辉定制7.58%+品质永辉2.32%），12支亿元级单品 | ★★★☆ | 占比提升速度超预期，但距离公司2026年20%、长期40%的目标仍有差距；需要持续的大单品供给能力验证 |
| **核心供应商联盟** | 200家核心供应商直采（汰换56%不达标供应商） | ★★★ | 供应商关系存在黏性但非独占 |
| **十大健康场景** | 已落地标杆门店（市井小吃街、卤味食集、现烤烘焙馆等） | ★★ | 场景可被模仿，但与商品力的结合需要时间 |
| **员工忠诚度/服务文化** | 利润分享机制启动 | ★★ | 刚起步，尚未形成如胖东来般的强文化；调改核心高管流失增添不确定性 |
| **购物卡预收款（合同负债38.87亿）** | 稳定 | ★★★ | 体现了存量消费者的品牌信任——这是"信任资产" |

**护城河的核心结论**：永辉的旧护城河（规模、低价、生鲜供应链）已被瓦解，新护城河（品质零售网络+自有品牌+核心供应商+场景体验）正在构建中。当前处于"护城河真空期"——旧的不在、新的未成。这是投资的最大不确定性来源。

## 四、产业链定价权分析

### 4.1 对上游的议价能力

**供应商关系正从"博弈"转向"联盟"**：

调改前的零供关系是博弈型——供应商缴纳进场费/堆头费/促销费换取货架位置，零售商靠"后台费用"盈利。这种模式下，永辉对供应商有较强议价权（不交费就下架），但后果是商品结构被"谁交钱多谁占好位置"扭曲，消费者利益受损。

调改后的零供关系转向联盟型——裸价直采、共担库存风险、联合开发定制商品。这种模式下：
- 永辉的**应付账款**从2024年末81.21亿降至2026H1末52.51亿——供应商占款能力下降（供应商减少→单个供应商的谈判筹码上升）
- 但**核心200家供应商的联盟关系**一旦稳定下来，将形成比"收进场费"更健康的合作基础
- 应付账款周转天数需持续跟踪，若从当前约60天大幅缩短至30天以内，则说明供应商信心增强、主动给予更优账期

**大单品打造的验证**：H1已培育销售额千万级单品240余支、亿元级单品12支（永辉定制精选鲜鸡蛋1.36亿、刺身冰鲜挪威三文鱼肉1.06亿、鲜榴莲3.54亿、蓝莓3.29亿等）——"零售商定义商品、供应商按标准生产"的新模式已从个案验证进入批量产出阶段。

### 4.2 对下游的定价能力

| 指标 | 数据 | 判断 |
|:---|:---|:---|
| 客单价 | 80-120元 | 处于大众消费可接受区间，涨价空间有限 |
| 调改店价格感知 | 部分消费者反映"变贵了" | 说明调改后的商品品质升级被部分价格敏感客群感知为"涨价"——这是客群筛选的自然过程 |
| 毛利空间 | 22.52%（H1 2026） | 较传统20%有改善但仍低于山姆（25%+）和胖东来（约25%） |
| 竞争约束 | 同商圈3公里内通常有1-2家竞品 | 超市行业的消费者转换成本极低——步行5分钟就能换一家 |

**定价权判断**：超市行业天然缺乏强定价权——消费者转换成本极低，价格透明度极高。永辉的定价权更多来自"品质差异化"带来的溢价能力（即消费者愿意为"品质永辉"认可的食品安全和购物体验多付5-10%），而非真正的垄断定价权。

## 五、竞争格局的综合定位

### 5.1 SWOT矩阵

| 优势(S) | 劣势(W) |
|:---|:---|
| 331家调改店是全国唯一规模化品质零售网络 | 财务极度脆弱（净资产0.24元/股、负债率93.04%） |
| 生鲜供应链基因（产地直采60%+，H1生鲜品类营收仅-3.97%） | 营收持续萎缩（门店数减半） |
| 品牌认知度高（"国民超市"定位） | 线上能力薄弱（线上占比19.35% vs 盒马60%+） |
| 名创优品系的零售运营经验和资源 | 组织文化转型未完成（减员5万人+调改核心高管流失） |
| 合同负债38.87亿→消费者信任基础仍在 | 自有品牌占比10.07%起步加速但距目标仍远 |

| 机会(O) | 威胁(T) |
|:---|:---|
| 传统大卖场加速出清→释放优质商圈物业 | 净资产转负→触发退市风险（2026年报是生死线） |
| 品质零售赛道需求旺盛→先发优势 | 定增失败→流动性危机 |
| 自有品牌高毛利空间（H1已达10.07%，公司目标2026年20%、长期40%） | 盒马/山姆/胖东来三面夹击且同时下沉加密 |
| 胖东来模式验证可行，永辉是唯一规模化践行者 | 消费者"降级"→从品质零售滑向折扣店 |
| 供应链改革降本效应持续释放 | 大股东70%质押+股价远低于质押线；万达仲裁36.39亿回收生变 |

### 5.2 竞争定位总结

永辉的核心竞争定位：**中国唯一具备全国性网络布局的品质零售转型标的**。

这不是一个"已经赢了的公司"，而是一个"正在打一场胜算中等偏上的翻身仗"的公司。竞争分析的关键不在于永辉比山姆/盒马/胖东来"更好"，而在于：
1. 331家调改店形成了先发优势和网络效应——竞对即使想做，也需要2-3年时间

3. 竞争对手各有边界但边界在松动——山姆下沉县域、超盒算NB覆盖300+县域、胖东来进驻郑州，2026H2起永辉腹地的竞争烈度将显著上升
