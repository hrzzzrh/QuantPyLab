# 研报章节六：估值定价分析

**研究日期**：2026年08月23日
**当日不复权收盘价**：3.07元（2026-08-21） | **总市值**：274.00亿（总股本89.25亿股）

## 一、价值锚定——适配性方法选择

### 1.1 方法适用性评估

永辉超市当前处于"亏损→扭亏"的临界点，传统估值方法面临挑战：

| 方法 | 适用性 | 理由 |
|:---|:---:|:---|
| **PE（市盈率）** | ❌ 当前不可用 / ✅ 前瞻可用 | TTM PE为负（亏损），无法使用；但2027E正常化PE可用作前瞻锚定 |
| **PB（市净率）** | ❌ 严重失真 | 每股净资产仅0.24元，PB=12.64倍无实际参考意义 |
| **PS（市销率）** | ✅ **核心方法** | 近盈亏平衡的零售企业，PS是最稳定的估值锚，不受短期盈亏波动干扰 |
| **DCF（现金流折现）** | ⚠️ 参考 | 经营现金流极弱（2025年仅6.46亿），未来现金流预测误差大 |
| **PEG（成长性估值）** | ⚠️ 参考 | 增长率为负（营收下滑），PEG逻辑不适用 |
| **EV/EBITDA** | ⚠️ 参考 | EBITDA虽为正但受租赁负债影响大 |

**方法论选择**：以**PS法为核心估值锚**（权重60%），以**2027E前瞻PE法为交叉验证**（权重40%）。PB和DCF不作为主要定价依据。EV/EBITDA因租赁负债对EBITDA的影响（使用权资产折旧+租赁利息约占EBITDA的40-50%）导致该指标失真，仅作定性参考，不纳入综合权重。

## 二、三态市值与目标价推导

### 2.1 PS法核心估值

采用2026E营收 × 情景化PS倍数：

| 情景 | 2026E营收(亿) | PS倍数 | 逻辑 | 市值(亿) | 目标价(元/股) |
|:---|:---:|:---:|:---|:---:|:---:|
| **保守(Bear)** | 438 | 0.32x | H2降幅未收窄、定增失败、退市风险上升——定价为"困境企业" | **140** | **1.57** |
| **中性(Base)** | 455 | 0.55x | 扭亏为盈但盈利薄、转型取得进展——定价为"恢复中企业" | **250** | **2.80** |
| **乐观(Bull)** | 473 | 0.78x | 盈利加速、自有品牌放量、定增成功——定价为"品质零售成长股" | **369** | **4.13** |

PS倍数的情景逻辑：
- **保守0.32x**：接近历史P25分位（0.33x），对应约140亿市值——这是市场对"可能退市"企业的底线定价。低于0.30x意味着市场开始定价破产风险
- **中性0.55x**：略低于当前估值水平（0.58x）——假设公司"不恶化也不显著改善"，向恢复中枢小幅回归。PS 0.55x对应约2.80元，与当前股价3.07元存在约-9%差距——现价隐含了比中性情景更乐观的营收预期
- **乐观0.78x**：接近PS历史P90分位（0.75x）之上——假设市场开始按"品质零售成长股"给估值溢价。对比国际对标：Costco PS约1.2-1.5x、Walmart PS约0.7-0.9x——永辉乐观情景的PS 0.78x对应"中国版品质零售"的初步定价

## 三、全变量对冲审计矩阵（强制性）

### 3.1 估值影响力过滤

以**中性情景市值225亿（约2.52元/股）**为"底色"，通过审计以下维度进行定性转量化调节：

| 审计维度 | 核心审计因子 | 审慎思考（估值影响力过滤） | 调节建议 | 深度理由 |
|:---|:---|:---|:---:|:---|
| **内部：企业底层特质(DNA)** | 名创优品系的零售运营基因 | 名创优品在供应链管理、自有品牌开发、门店标准化方面具有成熟经验，但超市业态与自有品牌零售有本质差异——**能否真正赋能永辉尚待验证**；调改核心高管（CFO及两位副总裁）相继离任增添组织不确定性 | **-5%** | 无实控人结构（名创系29.4%但非控股）存在治理不确定性；创始人减持退出、管理层大幅换血——组织稳定性折价 |
| **内部：资本配置效率** | 关店381家、调改331家的资本决策 | 壮士断腕式的战略收缩是**正确的资本配置决策**，避免了"温水煮青蛙"式的持续消耗。H1扭亏与毛利率韧性初步验证了决策有效性。但过去五年142亿亏损反映了历史上糟糕的资本配置记录 | **+3%** | 新管理层（名创系主导）展现了果断的资产出清决心，这是治理改善的信号——给予轻微溢价 |
| **宏观：政策与战略对齐** | 零售业创新发展政策 + 食品安全监管趋严 + 农超对接政策 | 商务部等9部门2026年7月《关于加快零售业创新发展的意见》明确借鉴胖东来等经验——政策风向对品质零售转型友好。但"促消费"政策对超市的拉动极为间接 | **+2%** | 政策环境对品质零售"中性偏友好"，非核心定价因子但提供温和顺风 |
| **宏观：地缘与外部约束** | 无直接地缘风险（纯内需）；万达仲裁执行风险属公司个体事项 | 超市是地缘免疫型行业——中美贸易摩擦、供应链脱钩对其业务无直接影响 | **0%** | 无地缘溢折价 |
| **市场：流动性与风格** | 日均成交约4-5亿（近期），市值274亿 | 当前日均成交约4.7亿（换手率约1.7%），流动性尚可。但财务脆弱性（93.04%负债率、0.24元/股净资产）将限制机构投资者参与；定增审核悬而未决抑制增量资金 | **-3%** | 财务脆弱性限制机构配置意愿——流动性折价 |
| **市场：风格契合度** | "消费降级"叙事 vs "品质零售"叙事 | 社零增速降至1.2%的背景下，市场主流叙事仍为"消费降级/折扣化"，永辉的"品质零售"叙事与之存在张力——但自有品牌放量与毛利率韧性提供了叙事支撑的证据 | **+2%** | 若消费数据企稳回暖，"品质零售"叙事可能成为风格切换的受益者——给予轻微的风格溢价预期 |

### 3.2 综合调节结果

| 项目 | 幅度 |
|:---|:---:|
| DNA（治理+组织） | -5% |
| 资本配置改善 | +3% |
| 政策对齐 | +2% |
| 地缘 | 0% |
| 流动性 | -3% |
| 风格契合 | +2% |
| **Σ综合调节幅度** | **-1%** |

**修正目标市值（仅中性档）** = 225 × (1 - 1%) = **223亿**
**修正目标价（仅中性档）** = **2.50元/股**

综合调节幅度仅-1%，近乎中性。本质原因是：治理折价（-5%）和流动性折价（-3%）被资本配置改善（+3%）、政策顺风（+2%）和风格溢价预期（+2%）基本抵消——永辉处于"坏的不够坏、好的不够好"的平衡态。

## 四、确定性与胜率矩阵

### 4.1 三态逻辑加权

| 情景 | 目标价(元/股) | 情景市值(亿) | 发生概率 | 概率加权贡献 |
|:---|:---:|:---:|:---:|:---:|
| 保守(Bear) | 1.57（未调节） | 140 | 30% | 0.47元 |
| 中性(Base) | **2.50（调节后）** | **223（调节后）** | 55% | 1.38元 |
| 乐观(Bull) | 3.77（未调节） | 337 | 15% | 0.57元 |
| **概率加权目标价** | - | - | **∑P=100%** | **2.41元** |

**概率加权目标价 = 2.41元/股**（对应市值约215亿）

### 4.2 盈亏比计算（框架公式，强制性）

```
盈亏比 = (概率加权目标价 - 现价) / (现价 - 保守情景目标价)
       = (2.41 - 3.07) / (3.07 - 1.57)
       = (-0.66) / (1.50)
       = -0.44
```

**分子为负（概率加权目标价 < 现价）**：当前股价3.07元高于概率加权目标价2.41元，期望收益为负（约-21.5%）。盈亏比负值意味着，以当前价格买入，即使考虑到乐观情景的可能性，整体期望回报仍显著为负。

## 六、逻辑证伪与极限压力测试

### 6.1 黑天鹅场景——"一击毙命"事件

**情景**：2026年年报审计净资产转负 → 触发上交所退市风险警示（*ST）

**触发条件**（三选一）：
1. 2026年亏损远超Bear情景（需亏损超21亿才致净资产转负，概率较低；2025年亏损25.52亿为此量级）
2. 定增持续失败+连续数年每年亏损5-10亿量级（按2026H1归母权益21.68亿倒推，约需3-4年）
3. 审计师出具"持续经营重大不确定性"的审计意见

**在此情景下**：股价可能跌至1.0-1.5元区间（净资产为负后PB失去锚定，仅靠清算价值和壳价值支撑）

### 6.2 极限支撑位审计——"地狱价格"

**基于清算价值的极限压力测试**：

- 总资产276.32亿 - 总负债257.08亿 = 净资产19.23亿（含少数股东）
- 归母净资产21.68亿（每股0.24元）
- 但资产中：使用权资产69.14亿不可变现（租赁合同），其他非流动金融资产30.51亿（含万达商管股权）变现价值高度不确定，存货26.23亿可按50-60%清算
- **可变现净资产估算**：货币资金27.43+交易性金融资产10.90+存货×55%(14.43)+固定资产净值约14-17亿+长期股权投资折价约9亿-总负债257 = 约-180亿（负值！）

这意味着：**永辉超市在清算场景下已经资不抵债**，普通股股东权益为负。股价的底部支撑并非来自资产价值，而是来自：
1. **持续经营价值**（going concern）——只要公司能产生正向经营现金流，债权人就不会强制清算；但H1经营现金流仅1.99亿且Q2转负，此安全垫正在变薄
2. **壳价值**——A股上市地位本身有价值（约10-20亿）
3. **定增预期**——若定增成功，净资产将大幅回升

**极端情形"地狱价格"估计**：若持续经营假设被打破（审计师出具无法表示意见或否定意见），股价可能跌至**0.8-1.2元**——对应壳价值+最低限度的业务残值。

## 七、估值定价结论

| 项目 | 数值 |
|:---|:---|
| 现价（不复权） | **3.07元** |
| 当前市值 | **274亿** |
| 保守目标价（Bear） | **1.57元**（-48.9%） |
| 中性修正目标价（Base） | **2.50元**（-18.6%） |
| 乐观目标价（Bull） | **3.77元**（+22.8%） |
| 概率加权目标价 | **2.41元**（-21.5%） |
| **盈亏比（框架公式）** | **-0.44** |
| 2027E隐含PE（中性修正目标价） | **26.3x** |
| 当前PS(TTM) | **0.58x** |

**核心定价判断**：
1. 当前股价3.07元显著高于概率加权目标价2.41元——市场对永辉的定价已透支转型预期：H1扭亏兑现后，现金流恶化与定增延期不仅未能推动盈利预测上修，反而迫使情景概率与营收预测同步下修
2. 保守情景下行空间-48.9%（至1.57元） vs 乐观情景上行空间+22.8%（至3.77元）——**收益-风险明显不对称偏向下行**
3. 公司价值的核心不确定性在于"定增是否成功"、"H2扣非能否转正"与"经营现金流能否修复"——这三个变量的结果将决定股价走向保守或乐观情景
4. 当前价位没有安全边际（中性修正目标价2.50元 < 现价3.07元），不是买入时机
5. 若股价回落至2.4元以下（约PS 0.49x），盈亏比开始转正，逐步具备安全边际

**与模块一至五的逻辑一致性校验**：
- 模块一的"现金流急剧恶化+净资产微薄"→对应保守情景的严重下行风险（-48.9%）
- 模块二的"品质零售成长早期但竞争烈度上升"→对应乐观情景PS 0.78x的成长溢价逻辑及概率下调
- 模块三的"护城河真空期+竞对围剿"→对应审计矩阵中DNA -5%和流动性 -3%的折价
- 模块四的"定增延期是关键变量+宏观逆风加重"→对应Bear概率上调至30%
- 模块五的"盈利薄如纸、扣非承压"→对应中性修正目标价较现价-18.6%的现实
