# 研报章节四：外部边界与宏观政策

**研究日期**：2026年08月23日

---

## 一、宏观环境变量

### 1.1 消费周期——"消费降级"还是"消费分级"？

永辉超市的终端需求直接绑定中国居民消费，尤其是食品生鲜等刚性消费支出。当前宏观消费环境呈现以下特征：

**2026年消费数据（最新实测）**：
- 2026年1-7月社会消费品零售总额287,744亿元，同比仅+1.2%；7月单月仅+0.6%且环比走弱——消费复苏力度显著弱于此前预期（2025年全年+3.7%）
- 商品零售额1-7月+1.1%，餐饮收入+2.6%，服务零售额+5.0%——消费重心向服务迁移
- 结构性亮点：限额以上超市零售额+3.8%、粮油食品类+7.2%、饮料类+5.6%——超市业态与食品刚需跑赢大盘
- 消费者信心指数持续在低位徘徊，储蓄意愿强于消费意愿

**对永辉的影响路径**：
- **刚性消费（食品生鲜）具有防御属性**——无论经济好坏，人总要吃饭。超市的食品生鲜品类在经济下行期反而体现出防御价值（永辉H1生鲜及加工品类营收仅-3.97%，验证了这一点）
- **但"消费分级"效应显著**：
  - 高收入群体 → 涌向山姆/盒马等中高端渠道
  - 中等收入群体 → 是永辉"质价比"定位的核心客群（最关键变量）
  - 低收入群体 → 涌向折扣店、社区团购

**核心判断**：当前宏观消费环境对永辉的影响是"中性偏负面"——总量蛋糕增长几近停滞（社零仅+1.2%），结构性分化加剧，中等收入群体的消费意愿是关键变量。若经济持续低迷，消费者可能进一步"降级"，从永辉（质价比）滑向折扣店（极致低价），这是最大的宏观风险。

### 1.2 就业与收入——超市员工端的成本压力

超市是劳动密集型行业。中国的劳动力市场变化直接影响永辉的成本端：

- 2025年全国最低工资标准持续上调（多数省份上调5-10%）
- 胖改模式下员工薪酬需提升20-30%以匹配服务标准（员工工资是服务质量的"成本"）
- 2025年末永辉员工49,427人，若人均薪酬年增5%，每年新增薪酬成本约2-3亿元

**但反直觉的是**：提升员工薪酬在品质零售模式中是"投资"而非"成本"——胖东来的实践证明，高薪酬→低流失→高服务质量→高顾客满意度→高复购率→高坪效，是一条正向循环链。永辉从"低薪—高流失—低服务"的恶性循环中跳出来，薪酬提升是必要条件。

### 1.3 通胀/通缩——超市是"通胀受益"还是"通缩受益"？

**温和通胀（CPI 1-3%）**：对超市最有利——商品价格小幅上涨直接推升营收（同店销售额增长），而租金/人工等固定成本不受短期通胀影响

**通缩/低通胀（CPI <1%）**：对超市不利——商品价格走平或下跌压低客单价，同店营收增长承压，而租金/人工持续刚性上涨

2026年7月CPI同比+0.5%（1-7月平均+0.9%），其中食品价格-1.5%、猪肉-13.3%、蛋类+14.4%——食品类处于结构性通缩。低通胀环境对永辉的营收端形成压制——调改店的同店增长更多是"客流量恢复"驱动而非"价格提升"驱动；但另一方面，采购成本下行也部分解释了毛利率的提升（裸价直采+食品通胀下行双重利好成本端）。

### 1.4 利率环境——对高负债企业的"绞索"

永辉2025年财务费用约8.14亿元（含租赁负债计提利息），短期借款34.62亿元（2026H1末）。当前中国处于低利率环境（LPR处于历史低位区间，具体报价以央行每月公布为准）：

降息对永辉是温和利好：
- 短期借款34.62亿，每降息50bp，年化节省利息约1,731万元——杯水车薪
- 租赁负债85.70亿按折现率计算，降息会降低新增租赁负债的现值，但存量合同影响有限
- 定增若成功，部分资金（4亿）用于偿还银行贷款，可节省的利息在降息后减少

**判断**：利率下行对永辉财务费用的改善幅度有限（影响在千万级），不是影响投资逻辑的核心变量。

## 二、产业政策与监管环境

### 2.1 食品安全监管——品质零售的"政策顺风"

近年来中国食品安全监管持续趋严：
- 2025年修订的《食品安全法》加重了对流通环节的处罚力度
- "日管控、周排查、月调度"制度对大型连锁超市提出更高合规要求
- 生鲜农产品的追溯体系建设（从产地到货架）正在成为行业标配

**对永辉的影响：正面**
- 更严格的监管抬高了行业门槛，淘汰不合规的小型零售商——**监管成本对小企业是不成比例的负担**
- 永辉的"品质零售"定位（食品安全溯源、自有品牌品控）在趋严的监管环境下成为差异化优势
- 裸价直采模式下，永辉对商品质量控制有更强的掌控力（绕过中间商直接对接产地）

### 2.2 电商/即时零售监管——线下零售的"政策保护"？

目前中国对即时零售/社区团购的监管态度是"规范发展"而非"打压限制"：
- 2025年《即时零售服务规范》征求意见稿出台，对前置仓的食品安全/消防/环保提出要求
- 社区团购"烧钱补贴"行为已被遏制（反不正当竞争）
- 但没有出现"保护线下零售、限制线上扩张"的强政策信号

**判断**：政策不会"拯救"线下零售，线下零售必须靠自身竞争力生存。对永辉而言，这意味着线上短板必须自己补齐，"永辉生活"APP和即时配送能力是生存必需品而非可选项。

### 2.3 农产品流通政策——产地直采的政策基础

国家持续推进"农超对接"政策，鼓励大型连锁超市直接对接农产品产地：
- 2025年商务部继续支持农产品冷链物流基础设施建设
- 永辉的五个物流园区升级改造项目（重庆、四川、陕西、河南、福州）与政策方向一致
- 农产品流通环节的"降本增效"是政府支持方向——永辉的供应链改革符合政策导向

### 2.4 定增政策环境——再融资审核趋严

永辉的定增计划需要经过上交所审核+证监会注册。当前监管环境：
- 2025年以来A股再融资审核整体趋严，亏损企业的再融资受到更严格的审视
- 永辉连续五年亏损，是审核中的"重点关注对象"
- **最新进展（2026年8月21日公告）**：定增自2025年10月申报、11月收到审核问询函以来，历经多轮问询回复与财务数据更新，至今已近10个月仍未获上交所审核通过；因股东会决议有效期即将届满（原至2026年9月17日），董事会已审议通过将决议有效期及授权有效期延长12个月至2027年9月17日，尚需提交2026年第三次临时股东会审议——**定增进度低于预期，"生死线"变量的落地时间窗口后移**

**定增可能被否决的理由**（风险点）：
1. 连续五年亏损，持续经营能力存疑
2. 资产负债率93.04%，偿债能力堪忧
3. 募投项目（门店升级改造）的效益测算依赖于乐观假设（IRR 21.57%），且与"休养生息不再大范围调改"的公开表述存在张力
4. 大股东质押率70%且股价远低于质押线

**定增可能获批的理由**（支持因素）：
1. 保荐机构中信证券+安永审计，材料规范性强
2. 募资用途符合国家"促进消费"政策导向；商务部等9部门2026年7月印发《关于加快零售业创新发展的意见》（商流通函〔2026〕306号，7月9日专题发布会），明确借鉴胖东来等企业经验——政策风向对品质零售转型友好
3. 2026年H1已实现扭亏为盈（归母+2.53亿）——经营拐点信号
4. 门店升级改造项目的税后IRR 21.57%具有一定的说服力
5. 公司测算2026-2028年资金缺口43.73亿，定增31.14亿是填补缺口的合理规模

**定增影响量化**：
- 若成功：募资31.14亿→每股净资产从0.24元回升至约0.6元→暂时解除退市风险→为转型争取2-3年时间窗口
- 若失败：公司需要依靠银行信贷+自有资金维持运营→杠杆进一步上升→退市风险加剧

## 三、地缘与外部约束——有限影响但不可忽视

### 3.1 汇率风险——间接影响有限

永辉以内需为主，海外业务占比极低（无海外门店），直接汇率风险不大。但间接影响存在：
- 部分进口商品（进口水果、海鲜、红酒等）的采购成本受汇率波动影响——但占比不超5%
- 公司持有的Advantage Solutions（美股）股票价值受人民币兑美元汇率影响——2025年已确认公允价值变动损失2.36亿元

### 3.2 贸易摩擦——超市行业几乎免疫

与制造业出口型企业不同，超市是纯内需消费行业，中美贸易摩擦对永辉的业务几乎无直接影响。食品生鲜的进口也不在贸易摩擦的主要关税清单中。

### 3.3 供应链安全——"去全球化"下的食品供应链韧性

全球地缘政治动荡（俄乌冲突持续、中东局势紧张）可能影响：
- 大宗农产品价格（小麦、玉米、大豆）→影响食品加工原料成本
- 航运中断→影响进口食品的供应链稳定性
- 但对永辉而言，生鲜以国内产地直采为主（60%+），进口依赖度低，供应链安全风险有限

## 四、外部变量的综合评估

### 4.1 宏观PEST矩阵

| 维度 | 关键变量 | 方向 | 影响程度 | 确定性 |
|:---|:---|:---:|:---:|:---|
| **政治/政策** | 定增审核（已延期12个月，仍未获批） | 待定 | ★★★★★ | 低 |
| **政治/政策** | 零售业创新发展政策（9部门意见点名胖东来经验） | 正面 | ★★★ | 高 |
| **政治/政策** | 食品安全监管趋严 | 正面 | ★★★ | 高 |
| **政治/政策** | 农超对接政策支持 | 正面 | ★★ | 高 |
| **经济** | 居民消费增速（1-7月社零仅+1.2%） | 负面 | ★★★★ | 高 |
| **经济** | CPI/通胀水平（食品-1.5%结构性通缩） | 中性偏负（营收压制vs成本利好对冲） | ★★★ | 高 |
| **经济** | 利率下行 | 温和正面 | ★★ | 高 |
| **经济** | 劳动力成本上升 | 负面 | ★★★ | 高 |
| **社会** | 消费分级（中产承压） | 负面 | ★★★★ | 中 |
| **社会** | 食品安全意识提升 | 正面 | ★★★ | 高 |
| **技术** | 即时零售/电商冲击（行业+12.6%，县域+62%） | 负面（但不可逆） | ★★★★★ | 高 |
| **地缘** | 人民币汇率 | 间接（有限） | ★ | 中 |

### 4.2 外部变量的核心结论

**最大的外部变量不是宏观、不是地缘、不是政策——而是定增能否获批。**

永辉面临的宏观环境整体"逆风加重"：消费增速降至1.2%、食品通缩、劳动力成本上升、即时零售加速分流。但政策端出现积极信号——商务部等9部门2026年7月发布《关于加快零售业创新发展的意见》明确借鉴胖东来等企业经验、强化商品与服务能力建设，永辉的"品质零售"转型与政策导向同频。

**定增的结果将在很大程度上决定永辉的生死**。定增成功=获得转型的时间窗口（2-3年）；定增失败=财务灵活性大幅受限，退市风险显著上升。监管层对"亏损企业再融资"的态度是最大的政策不确定性，而决议有效期延长至2027年9月的安排显示公司仍在推进，但也意味着审核周期可能比市场预期更长。

## 五、与前三模块的逻辑一致性校验

| 模块 | 核心发现 | 本模块的呼应 |
|:---|:---|:---|
| 模块一（财务基石） | 净资产濒临转负，定增是"生死线" | 定增审核是本模块最大的政策变量 |
| 模块二（产业周期） | 传统大卖场衰退，品质零售成长 | 消费分级趋势下，品质零售需求被宏观验证 |
| 模块三（竞争格局） | 护城河真空期，新老交替 | 行业监管趋严→加速尾部淘汰→利好头部品质零售 |

**核心逻辑链一致**：永辉的投资命运取决于三个变量的交叉——①内部经营改善（毛利率回升+调改店放量）②定增获批（财务安全垫）③宏观消费环境（不至于进一步恶化）。三者缺一不可。
