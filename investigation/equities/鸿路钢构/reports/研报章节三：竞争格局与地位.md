# 研报章节三：竞争格局与地位

**研究日期**：2026年07月20日

---

## 前序核心结论回顾

模块一：吨扣非净利从195元/吨腰斩至86元/吨，Q1 2026回升至123元/吨。模块二：终端需求呈现"K型分化"——锂电池/半导体/造船等高端制造业资本开支持续旺盛，但传统制造业投资已转负。

**本模块核心问题**：这种"K型需求"的受益者是谁？鸿路钢构的竞争优势是否构成了真正的护城河？

---

## 一、竞争格局扫描：极度分散中的极化趋势

### 1.1 行业集中度变迁

| 年份 | 鸿路钢构 | 杭萧钢构 | 精工钢构 | 东南网架 | 富煌钢构 | CR5合计 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| 2017 | 1.55% | - | - | - | - | 4.32% |
| 2022 | 3.46% | - | - | - | - | ~7% |
| 2023 | 4.01% | 1.42% | 1.09% | 0.59% | 0.36% | 7.46% |
| 2024 | 4.14% | - | - | - | - | ~8% |

**关键趋势**：
- CR5从2017年的4.32%提升至2023年的7.46%，6年提升3.14个百分点
- 其中鸿路钢构独占了2.46个百分点的增量（1.55%→4.01%），贡献了CR5提升的78%
- 这意味着**其他四家合计份额几乎没有增长**——鸿路钢构是在蚕食中小企业的份额，而非与上市公司竞争

### 1.3 核心洞察：商业模式分野决定命运

2025年的业绩分化非常清晰地揭示了行业的结构性规律：

- **精工钢构**：营收和净利双增长（+12.69%/+18.23%），但增长引擎是**海外EPC业务**（海外订单72亿，+140%），而非国内制造业内生增长。扣非净利同比下降5.06%，说明国内主营业务的盈利能力同样承压。
- **东南网架**：营收-16.58%，净利-74.28%，钢结构产量-37.6%。这是最惨烈的案例——传统EPC模式在需求收缩中遭遇重创。
- **鸿路钢构**：营收微增但净利下滑，营收规模仍居行业第一。扣非净利-9.76%的降幅小于东南网架（-74%）和杭萧钢构，也优于富煌钢构。

**结论**：在行业下行周期中，纯制造模式（鸿路钢构）展现出更强的韧性。这不是因为利润率更高（实际上鸿路的毛利率9.85%是上市公司中最低的），而是因为**规模优势和成本控制能力在逆周期中发挥了"减震器"作用**。

## 二、护城河识别：四道防线

### 护城河一：规模效应带来的采购成本优势

这是鸿路钢构最坚固的护城河。

- 2025年前五大供应商采购额69.01亿，占采购总额37.23%
- 单是最大供应商的采购额就有17.24亿（9.30%）
- 与宝钢、马钢、沙钢、宝武钢铁、安阳钢铁建立长期战略合作关系
- 据测算，公司钢材采购单价约3459元/吨（2024年），低于市场均价3633元/吨，更显著低于精工钢构的3991元/吨

**为什么竞品无法复制**：鸿路钢构月均采购钢材超40万吨，单一钢厂的年采购规模可达17亿以上。精工钢构（年产量172.6万吨）即使想获得同样的折扣，采购量也差了近3倍。规模采购的议价优势具有**自增强效应**——规模越大→采购成本越低→竞争力越强→份额越大→规模更大。

### 护城河二：智能制造的先发优势

截至2026年6月，鸿路钢构已投入约**3300台焊接机器人工作站**和自主研发的"鸿路铆大师检测机器人"。这是钢结构行业独一无二的智能制造基础设施：

- **自研能力**：公司自主研发"弧焊机器人控制系统"，而非简单采购第三方设备。已取得64项软著、42项专利。
- **规模落地**：3300台机器人分散在十大基地，形成规模化应用能力。焊接机器人已从2024年4月的首批800台快速增长至3300台（+312%）。
- **外销验证**：从2025年9月开始对外销售焊接机器人，已远销越南、墨西哥、以色列等国家，累计出口435台。外销收入证明了自研技术的产品质量。
- **降本空间**：据长江证券测算，单吨焊工成本约319元。若机器人替代率达到50%，焊接环节成本可下降超100元/吨；若产量从500万吨提升至800万吨，单吨固定成本还可再降25-30元。

**关键判断**：智能化改造的降本效应尚未充分释放。公司明确表示"目前降低成本还较少"。这意味着**2026-2027年可能是吨利改善的拐点窗口**——当3300台机器人的学习曲线完成、产能爬坡实现时，成本端的改善将开始显现。

### 护城河三：多基地协同的快速交付能力

鸿路钢构拥有十大生产基地，分布在安徽（合肥、下塘、涡阳、金寨、宣城、颍上、蚌埠）、河南（汝阳）、重庆（南川）、湖北（团风）。这不是简单的"点多面广"，而是构建了一套**多基地协同制造**的独特能力：

- **统一调度**：总部统一排产、统一下料，大项目可以同时在多个基地生产然后组装
- **快速交货**：2025年承接的3万吨项目制作工期仅45天，2.6万吨项目60天，3万吨项目60天——这种速度在行业中是碾压级的
- **专业化分工**：将非标准化的工程材料细分为标准化部品部件（气楼、系杆、箱形柱等），实现工厂化生产

### 护城河四：信息化管理系统构建的运营壁垒

公司自主研发的"项目管理平台"整合了OA、HR、NC系统，开发了报工质检和鸿路智造小程序：
- 每根构件每道工序可追溯（谁生产、谁检验）
- 自动核算计件工资
- 客户可通过手机实时查询工厂生产进度、出入库数据、物流位置

这套系统构成了**管理上的不可复制性**——竞品可以建工厂、买机器人，但无法在短期内复刻这套经过多年打磨、与生产流程深度耦合的信息化系统。

## 三、产业链定价权分析

### 3.1 对上游：显著议价优势

| 指标 | 数值 | 解读 |
| :--- | :--- | :--- |
| 前五供应商占比 | 37.23% | 采购集中，但单一最大仅9.3%，不依赖任何单一供应商 |
| 应付票据及账款 | 50.06亿（Q1 2026） | 较2024末的44.30亿增长13%，**对上游占款能力增强** |
| 钢材采购折价 | ~5% vs 市场均价 | 规模化采购带来的直接成本优势 |
| 采购单价(2024) | ~3459元/吨 | 低于竞品精工钢构的3991元/吨(价差532元/吨) |

### 3.2 对下游：议价能力正在改善但有限

| 指标 | 数值 | 解读 |
| :--- | :--- | :--- |
| 应收账款 | 25.56亿（Q1 2026） | 较2024末的34.92亿大幅下降，**回款能力增强** |
| 合同负债 | 11.49亿 | 持续增长，预收款增加说明**需求端愿意付订金** |
| 前五大客户占比 | 30.61%（2024年） | 客户集中度中等偏高（主要为中建、中冶等央企） |
| 毛利率 | 9.85% | 在制造业中偏低，**定价权有限** |

**定价权判断**：鸿路钢构在材料制造环节拥有"成本端绝对优势+交付端绝对优势"，但面向强大的央企客户（中建、中冶等），议价空间有限。9.85%的毛利率天花板本质上是**行业模式决定的**——作为材料供应商而非EPC总包商，利润空间天然受限。

## 四、外部数据交叉验证

### 4.1 真实订单验证

从2026Q1公开的大单列表验证：
- 船舶领域：多个"分段车间钢结构"项目（1.6亿、1.59亿、1.91亿、1.58亿、1.91亿）→ **造船业需求强劲，确认**
- 新能源：光伏示范项目、动力电池项目、新能源电池产业基地 → **锂电/储能需求确认**
- 半导体/电子：芯电产业园、存储器基地、动力电池项目 → **半导体需求确认**
- 数据中心：云数据中心一期项目 → **AI算力需求确认**

订单结构高度吻合我们在模块二中识别的"火焰"赛道（锂电/半导体/造船），验证了终端穿透分析的结论。

### 4.2 供应链生态穿透

- 大客户（中建、中冶等央企）的海外项目增加 → 鸿路钢构"借船出海"，间接出口至30+国家
- 公司已取得AISC（美标）、EN1090（欧标）、UKCA（英标）等认证 → 海外直接出口蓄势待发
- 2025年完成近三百个海外项目 → 海外路径已验证

### 4.3 实物产能校验

- 十大基地全部建成投产，2025年末产能520万吨
- 2025年产量502万吨，产能利用率96.56%→ 产线已接近满产
- 在建工程仅0.67亿 → 短期内无大规模新增产能
- 未来产量增长将更多依赖**智能化改造提升产能利用率**（而非新建工厂）

## 五、模块三核心结论

**鸿路钢构的护城河不是单一的，而是一个"规模×智能制造×快速交付×信息化管理"四位一体的复合体系**。这四个要素之间存在极强的相互增强关系：

```
规模化采购 → 低成本优势 → 更多订单 → 更大规模
                                    ↓
                              更多资源投入智能化
                                    ↓
                              更高产能利用率 → 更快速交付
                                    ↓
                              更高客户粘性 → 更多订单
```

这个飞轮一旦转起来，竞争对手极难打破。精工钢构可以走EPC+海外路线（不同的赛道），东南网架可以收缩战线，但**在纯钢结构制造这个赛道上，鸿路钢构已经建立了代际级领先优势**。

**但护城河的质量需要经受一个关键检验**：当3300台机器人真正释放降本效应时，吨利能否突破100元/吨并向200元/吨回归？如果能，则护城河有效且深远；如果不能，则说明这些"护城河"只是成本竞赛中的军备竞赛，并未真正转化为超额利润。
