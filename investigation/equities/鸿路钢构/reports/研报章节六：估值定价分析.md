### PB-ROE交叉验证

2026H1 ROE（年化=4.38*2/102.29≈8.56%），2026E基准ROE约12.8%（8.8亿/68.7亿归母权益均值化）。合理的PB = ROE / (r - g)，取r=10%，g=3%：
- 基准PB = 12.8% / 7% = 1.83倍（ROE上修驱动，PB实测1.35→隐含修复空间+35%）
- 每股净资产2026E ≈ 14.05元（102.29/7.5346最新股本+留存收益，稀释约-8.4%）
- 目标股价 = 14.05 × 1.83 = 25.71元（显著高于PE中值，反映PB在ROE跃升期的敏感性，需折价使用，稀释后仍高）

PB-ROE验证显示ROE上修后PB逻辑指向更高估值（25.71元），但鉴于高存货及杠杆的清算风险，**仍以PE 20.45中值为基准，PB 25.71作为乐观弹性验证而不纳入加权**。

### 5.2 盈亏比计算

```
盈亏比 = (加权目标价 - 现价) / (现价 - 保守情景价格)
加权 19.54 - 18.36 = 1.18
现价 - 保守 18.36 - 14.67 = 3.69
盈亏比 = 1.18 / 3.69 = 0.32
基准单算： (20.45-18.36)/(18.36-14.67)=2.09/3.69=0.57
```

**盈亏比0.32（加权）/0.57（基准）**——较08-31的0.07/0.27显著抬升并首次突破0.3阈值（基准破0.5）。核心矛盾逆转：**上行+11.4%（基准）/+6.5%（加权）>下行-20.1%，风险回报转正**。驱动：①09-30回调至18.36增厚安全边际（较08-31 -12.7%）；②股本稀释使保守价-8.2%但现价-12.7%更快，剪刀差改善盈亏比；③H1已锁定49.8%全年利润，PE TTM 17.70较7月23.85已释放6.15倍。

**操作含义**：现价已从"合理偏高"转为"合理偏低"，盈亏比0.32/0.57已突破基础配置线——**18.00-18.50可试探建仓（盈亏比>0.25），跌破14.67保守价止损，突破20.45加仓，目标23.12**。若Q3新签验证全年580万吨中枢且吨扣非维持160+，加权有望随2027年外推上移至22+（+20%）。
