### 2.1 PE（TTM）历史分位

基于实测TTM（7.81亿）对应PE 18.57倍，较7月23.85倍回落5.28倍，历史分位从约60%回落至约45%（2011年上市至今区间10-40倍中枢约18倍）：

| 时期 | PE范围 | 特征 | 当前对比 |
| :--- | :--- | :--- | :--- |
| 2017-2020（产能建设期）| 10-20倍 | 市场给予"制造业"低估值 | 当前18.57处于区间上沿 |
| 2021-2022（高速增长期）| 20-40倍 | 产量CAGR 30%+，成长溢价 | 仍低于该阶段 |

**分位警示修正**：H1业绩超预期后，PE(TTM)已从"隐含较大反转预期"（23.85倍）修复至"兑现部分反转"（18.57倍）。考虑到2026E基准PE 16.4倍（21.03/1.28）较TTM基本持平，说明市场对2026年增长已部分定价，但相比2025年PE 24.7倍保守情景的高位已大幅收敛。

**基准PE倍数上修逻辑（14-18x → 15-19x）**：
- **下限15倍**：H1吨毛利+1.98pp及费率-0.6pp验证降本兑现，给予比精工（约18倍但扣非负增长）更低的下限但较7月提升1倍以反映拐点确定性提升

**基准目标股价中值**：21.76元（目标市值150亿，对应17.0倍PE，原21.55元微升0.21元）——**中值与现价21.03基本持平，但区间上移反映确定性提升**

### PB-ROE交叉验证（H1更新）

2026H1 ROE（年化=4.38*2/102.29≈8.56%），2026E基准ROE约12.8%（8.8亿/68.7亿归母权益均值化）。合理的PB = ROE / (r - g)，取r=10%，g=3%：
- 基准PB = 12.8% / 7% = 1.83倍（原1.40，ROE上修驱动）
- 每股净资产2026E ≈ 15.35元（102.29/6.90 + 留存收益）
- 目标股价 = 15.35 × 1.83 = 28.09元（显著高于PE中值，反映PB在ROE跃升期的敏感性，需折价使用）

PB-ROE验证显示ROE上修后PB逻辑指向更高估值，但鉴于高存货及杠杆的清算风险，**仍以PE 21.76中值为基准，PB 28.09作为乐观弹性验证而不纳入加权**。

### 5.2 盈亏比计算（H1后改善但仍偏低）

```
盈亏比 = (加权目标价 - 现价) / (现价 - 保守情景价格)
加权 21.37 - 21.03 = 0.34
现价 - 保守 21.03 - 15.98 = 5.05
盈亏比 = 0.34 / 5.05 = 0.07
基准情景单算： (22.41-21.03)/(21.03-15.98)=1.38/5.05=0.27
```

**盈亏比0.07（加权）/0.27（基准）**——较7月0.22（基准）微升但仍低于1.0阈值。核心矛盾未变：**上行空间+6.6%显著小于下行-24%**。但边际改善在于：①现价回调-5.3%使安全边际增厚；②PE TTM从23.85→18.57释放部分估值压力；③H1已锁定49.8%全年利润，保守情景下行-24%较7月-27%收窄。

**操作含义**：现价仍属"合理但不诱人"，盈亏比未突破重仓线，但已从"尴尬"转为"等待右侧确认"。若Q3新签维持+12%以上且吨扣非维持160+，盈亏比有望在Q3后突破0.5。

## 七、模块六核心结论（H1审计版）

1. **基准估值**：15-19倍PE（原14-18上修），对应目标价19.20-24.32元，中值22.41元（含+3%审计调节，未调节21.76）。概率加权21.37元，与现价21.03基本持平（+1.6%）。

2. **H1后核心变化**：EPS基准从1.48→1.28下修（约-13.5%），但PE基准从15.8→17.5上修（+10.8%）且现价回调-5.3%形成对冲，**估值中枢基本保持稳定但内含逻辑从"预期拐点"升级为"兑现拐点"**，确定性评分4.0/5支撑PE上限提升。

3. **盈亏比仍不理想但边际改善**：加权0.07/基准0.27 vs 7月0.22，仍低于1.0重仓线，但下行-24%较7月-27%收窄且PE TTM已释放5.28倍压力。现价不构成重仓买点，但已进入"回调后可试探"区间。

4. **真正的价值锚已前移**：若Q3维持H1节奏（吨扣非160+），2026年全年8.8亿可实现则2027年10.5-12.5亿（EPS 1.52-1.81）在17.5倍PE下目标26.6-31.7元（较现价+26% to +51%）——**2027年弹性较7月估算（27-30元）上修**，Q3验证后估值切换将成为下一主逻辑。
