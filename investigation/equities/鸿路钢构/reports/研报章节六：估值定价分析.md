# 研报章节六：估值定价分析

**研究日期**：2026年07月20日

**基准价格**：22.20元（不复权市价，2026年7月20日收盘价）  
**总股本**：6.90亿股 | **当前市值**：153.18亿元  
**当前PE(TTM)**：23.85倍 | **当前PB**：1.51倍 | **当前PS(TTM)**：0.68倍

## 一、价值锚定：适配性方法选择

### 1.1 方法选择与理由

| 方法 | 选择理由 | 权重 |
| :--- | :--- | :--- |
| **PE（市盈率）** | 公司稳定盈利，PE为市场广泛接受。用于主估值锚。 | **70%** |
| **PB-ROE** | 重资产特征明显（固定资产+存货占比>70%），PB有辅助参考价值。 | **20%** |
| **EV/EBITDA** | 高负债（有息负债~91亿），EV能更全面反映企业价值。 | **10%** |
| 不选PS | 9.85%毛利率过低，PS估值不具备稳定性 | — |
| 不选DCF | 自由现金流持续为负，CAPEX周期中DCF无效 | — |

### 1.2 估值锚点

当前为2026年Q3（7月），按照框架规则，估值锚定**2026年全年**预测业绩。

## 二、历史分位审计

### 2.1 PE（TTM）历史分位

基于v_daily_valuation数据（2011年上市至今），PE(TTM)的历史分布：

| 时期 | PE范围 | 特征 |
| :--- | :--- | :--- |
| 2017-2020（产能建设期）| 10-20倍 | 市场给予"制造业"低估值 |
| 2021-2022（高速增长期）| 20-40倍 | 产量CAGR 30%+，成长溢价 |
| 2023（业绩峰值）| 12-18倍 | 盈利最高但增长放缓 |
| 2024（业绩滑铁卢）| 15-25倍 | 盈利下滑但估值抬升（利润跌更快） |
| 2025至今 | 20-30倍 | 当前23.85倍 |

**历史分位的警示**：当前23.85倍的PE(TTM)在历史中处于中等偏上水平（约60分位）。考虑到2025年归母净利同比-18.27%而股价并未同步下跌，**当前估值中已隐含了相当程度的"反转预期"**。简单地以"历史分位偏低"作为买入理由是不成立的——PE的高企恰恰是因为E在快速萎缩。

### 2.2 可比公司估值

| 公司 | 市值(亿) | PE(TTM) | PB | 2025营收增速 | 商业模式 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **鸿路钢构** | 153 | 23.9 | 1.51 | +2.6% | 纯制造 |
| 精工钢构 | ~90 | ~15 | ~1.0 | +12.7% | EPC+海外 |
| 东南网架 | ~35 | ~70 | ~0.8 | -16.6% | EPC+化纤 |
| 杭萧钢构 | ~30 | ~50 | ~1.2 | 下行 | 制造+EPC |

注：可比公司PE数据为估算，受利润大幅波动影响，当前TTM PE参考价值有限。

**鸿路钢构的PE高于精工钢构但低于其他同行**，这反映了市场对其"龙头地位+成长预期"的定价，但也隐含了"低毛利率=低估值天花板"的结构性约束。

## 三、基准市值区间（PE法）

| 情景 | 2026E EPS | 合理PE倍数 | 目标市值(亿) | 目标股价(元) | 上涨空间 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 保守 | 0.90 | 16-20x | 99-124 | 14.35-17.97 | -35% to -19% |
| **基准** | **1.48** | **14-18x** | **142-183** | **20.58-26.52** | **-7% to +20%** |
| 乐观 | 1.96 | 12-16x | 162-216 | 23.48-31.36 | +6% to +41% |

**基准PE倍数的确定逻辑**：
- **下限14倍**：与精工钢构当前估值水平接近，假设鸿路的"制造模式"无法获得溢价，且吨利改善不及预期
- **上限18倍**：给予确定性改善的适度溢价，考虑到2026E扣非净利增长64%的PEG支撑
- **为何不给更高PE**：9.85%的毛利率天花板+高负债率+政府补贴依赖，这三个结构性问题限制PE上限

**基准目标股价中值**：21.55元（目标市值163亿，对应15.8倍PE）

### PB-ROE交叉验证

2025年ROE 6.46%，2026E ROE约9.8%（基准）。合理的PB = ROE / (r - g)，取r=10%，g=3%：
- 基准PB = 9.8% / 7% = 1.40倍
- 每股净资产2026E ≈ 15.2元
- 目标股价 = 15.2 × 1.40 = 21.28元

PB-ROE框架给出的目标价与PE法中值（21.55元）高度吻合，形成交叉验证。

## 四、核心：估值全变量对冲审计矩阵

### 4.1 审慎思考框架

在进行调节之前，先排除"伪因子"（看似相关但实际不能改变估值中枢的因素）：
- 装配式建筑渗透率提升 → 行业趋势，已体现在长期增长假设中，**不再重复计入PE调节**
- 政府补贴 → 已计入E（利润预测），**不再重复计入PE调节**
- 订单增长 → 已体现在Q预测中，**不再重复计入PE调节**

真正能影响PE倍数的，是那些**无法量化为利润改善、但关乎信心与确定性的因素**。

### 4.2 全变量审计矩阵

| 审计维度 | 审计因子 | 审慎思考（估值影响力过滤） | 调节幅度 | 深度理由 |
| :--- | :--- | :--- | :---: | :--- |
| **内部：企业底层特质** | 智能化制造领先（自研机器人、3,300台部署） | 这是真正的稀缺性。中国制造业中仅有极少数企业具备"自研核心装备并规模化部署"的能力。这赋予公司长期成本下降的确定性。 | **+3%** | 智能化增加了长期盈利能力的可预见性，应享受确定性溢价。但需兑现，目前降本效果"还较少"。 |
| **内部：企业底层特质** | 管理层战略定力（15年专注钢结构制造） | 值得肯定但非稀缺。大量制造业企业都有专注主业的历史。"平庸的优秀"不等于估值溢价。 | **0%** | 不能因为管理层"不犯错"就给溢价。 |
| **内部：企业底层特质** | 高负债率（64.48%）+ 存货风险（120亿） | 财务脆弱性是真实的折价因素。64.48%的负债率在制造业中偏高。如果钢价大跌或需求骤降，存货减值+偿债压力将同时爆发。 | **-3%** | 高杠杆在顺风时放大收益，在逆风时放大风险。当前宏观环境不确定性上升，应给予风险折价。 |
| **宏观：政策与战略对齐** | 双碳+装配式建筑政策 | 方向确定、力度不确定。装配式建筑30%目标大概率未达成，政策实际推动力有限。 | **0%** | 政策关联不等于定价权。绝大多数政策红利对具体公司估值影响为零——钢铁/水泥/玻璃同样受益于绿色建筑政策，但并无估值溢价。 |
| **宏观：政策与战略对齐** | "十五五"先进制造投入 | 可能带来边际增量。制造业投资正在从"广撒网"转向"精准投"，公司下游（锂电/半导体/造船）是精准投放方向。 | **+2%** | 结构性政策倾斜使需求质量更高，提升了确定性。 |
| **宏观：地缘与外部约束** | 钢铁出口贸易摩擦+中东地缘风险 | 冲击极小。公司99%收入在国内，海外业务仅初起步。中东风险传导路径为"间接客户项目延期"，实际影响微乎其微。 | **0%** | 不能将"可能发生的坏事"都折价。只有具备实质性、长期性影响的风险才值得扣减PE。 |
| **市场：流动性与风格** | 中小市值（153亿）+ 机械/基建风格 | 当前市场风格偏向科技成长（AI、半导体），传统制造业估值受压。153亿市值在A股属于中小盘，流动性不构成问题。 | **-2%** | 短期风格不契合，但可持续性存疑——风格是轮动的。给予轻微折价而非大幅扣减。 |
| **综合调节系数** | —— | —— | **Σ = 0%** | |

**最终结论**：经过全变量审计后，**基准PE倍数不作调整**。各项利好与利空因素在审慎过滤后基本对冲。基准PE区间维持在**14-18倍**。

## 五、确定性与胜率矩阵

### 5.1 三态加权目标价

| 情景 | 概率 | 目标股价 | 现价 | 收益空间 |
| :--- | :--- | :--- | :--- | :--- |
| 保守 | 25% | 16.16元（16x EPS 0.90 × 1.12修正）| 22.20 | **-27%** |
| **基准** | **55%** | **23.55元（16x EPS 1.48）** | 22.20 | **+6.1%** |
| 乐观 | 20% | 27.44元（14x EPS 1.96） | 22.20 | **+23.6%** |

**概率加权目标价**：16.16×25% + 23.55×55% + 27.44×20% = **22.49元**

### 5.2 盈亏比计算

```
盈亏比 = (目标价 - 现价) / (现价 - 保守情景价格)

基准情景：盈亏比 = (23.55 - 22.20) / (22.20 - 16.16) = 1.35 / 6.04 = 0.22
```

**盈亏比仅0.22倍**——这是一个尴尬的数字。以基准情景来看，上涨空间（+6.1%）显著小于下跌空间（-27.2%）。即使考虑概率加权后目标价22.49元也仅略高于现价。

## 六、逻辑证伪与极限压力测试

### 6.1 黑天鹅场景

**"一击毙命"事件**：制造业固定资产投资在2026H2加速恶化，叠加锂电行业产能严重过剩引发投资断崖（2022-2025年锂电投资已超2万亿，部分产能利用率已跌至30%以下）。

**连锁反应**：
1. 鸿路钢构新签订单骤降 → 产量增速归零甚至转负
2. 120亿高库存面临钢价下跌+需求萎缩双重打击 → 存货减值10-20亿
3. 银行收紧信贷 → 91亿有息负债面临续贷压力
4. 可转债（鸿路转债128134，2026年10月到期）无法转股 → 需偿还15.7亿本金

**地狱价格**：在这种极端情景下，给予清算/困境估值：
- 净营运资产（流动资产-总负债）= 约-20亿（负值！）
- 固定资产清算价值 ≈ 81亿×50% = 40.5亿
- 归属于股东权益 = 101亿（账面）
- 考虑存货减值20亿后的实际净资产 = 81亿
- 每股清算价值 = 81亿/6.90亿 = **11.74元**
- 给予PB 0.8-1.0倍 = **9.40-11.74元**

| 基准目标价 | 23.55 | +6.1% | 制造业投资温和放缓 |

## 七、模块六核心结论

1. **基准估值**：14-18倍PE，对应目标价20.58-26.52元，中值23.55元。概率加权目标价22.49元，与现价22.20元基本持平。

2. **估值纠结的核心原因**：当前PE(TTM) 23.85倍已经隐含了相当程度的反转预期。即使2026E EPS增长61%（基准），前瞻PE也只降到15倍。这个估值水平说贵不贵、说便宜不便宜——**典型的"合理但不诱人"**。

3. **盈亏比不理想**：基准情景上涨仅6.1%，保守情景下跌27.2%，盈亏比0.22倍。除非对乐观情景（+23.6%）有极强信心，否则现价买入的安全边际不足。

4. **真正的价值在哪里**：如果2026年年报确认吨利拐点（扣非净利>7亿），市场将forward-looking至2027年（潜在EPS 1.80-2.00元），届时在15倍PE下目标价可达27-30元——**2027年的估值逻辑可能完全不同**。
