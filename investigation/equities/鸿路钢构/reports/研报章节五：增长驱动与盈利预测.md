# 研报章节五：增长驱动与盈利预测

**研究日期**：2026年07月20日

---

## 前序核心结论回顾

- **模块一**（财务基石）：吨扣非净利86元/吨（2025），Q1 2026回升至123元/吨。存货120亿，负债率64.48%。
- **模块二**（终端穿透）：K型需求——锂电/半导体/造船资本开支强劲，传统制造业投资转负。
- **模块三**（竞争格局）：四重护城河（规模×智能×交付×信息化），但毛利率天花板仅9.85%。
- **模块四**（宏观边界）：中性偏友好，但制造业投资加速下行是核心风险。

## 一、分业务 P×Q 模型的证据链锚定

鸿路钢构96.95%收入来自钢结构制造业务，因此采用**吨钢经济模型**（P=吨价，Q=销量）作为核心分析框架。其他业务（配套产品等约7亿收入）假设保持平稳。

### 1.1 销量（Q）确定性溯源

**历史轨迹**：
| 年份 | 产量(万吨) | YoY | 销量(万吨) | 产销率 | 产能(万吨) | 产能利用率 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| 2021 | 338.67 | +35.2% | 317.96 | 93.9% | - | - |
| 2022 | 349.54 | +3.2% | 325.83 | 93.2% | - | - |
| 2023 | 448.80 | +28.4% | 425.65 | 94.8% | 500 | 89.8% |
| 2024 | 451.07 | +0.5% | ~428 | 95.0% | 520 | 86.8% |
| 2025 | 502.07 | +11.3% | ~482 | 96.1% | 520 | 96.6% |

**2026年销量推演——三重证据交叉验证**：

| 证据来源 | 信号 | 确定性 |
| :--- | :--- | :--- |
| **Q1实际数据** | 产量120.38万吨(+14.75%)，新签合同74.12亿(+5.10%) | ★★★★★（已实现） |
| **产能上限硬约束** | 名义产能520万吨，但3300台机器人可突破名义上限（多班倒） | ★★★★☆ |

| **券商测算** | 长江证券估算机器人替代后极限产能可达800万吨 | ★★★☆☆（理论推演） |

**2026年产量预测**（核心假设）：

Q1已实现120.38万吨。Q2通常为生产旺季（2025年Q2产量约127万吨，Q2同比+15%约146万吨），Q3-Q4因为机器人效率爬坡和基数效应，增长逐渐回归。综合：

- **保守**：Q2 140 + Q3 155 + Q4 155 = 全年570万吨（+13.5%），隐含Q2-Q4平均增长约12%
- **基准**：Q2 148 + Q3 165 + Q4 167 = 全年600万吨（+19.5%），隐含Q2-Q4平均增长约22%
- **乐观**：Q2 155 + Q3 175 + Q4 180 = 全年630万吨（+25.5%），隐含机器人效率大幅释放

### 1.2 价格（P）趋势逻辑推演

| 影响因子 | 方向 | 幅度判断 |
| :--- | :--- | :--- |
| 钢价（热卷~3341元/吨，下半年震荡偏弱）| 吨价被动跟随钢价 | 基准ASP约4450元/吨（+4.4% vs 2025） |
| 订单结构优化（高端制造占比提升）| 推升均价 | 新能源/半导体订单精度更高，加工费更高 |
| 产能紧张 → 议价能力增强 | 推升加工费 | 产能利用率96.6%，接近满产，选择性接单 |
| 竞争压制 | 压制均价 | 中小企业仍在价格竞争，提价空间有限 |

**2026年ASP预测**：
- 2025年实际ASP：4437元/吨（钢结构营收213.95亿/销量482万吨）
- **保守**：4400元/吨（-0.8%）——钢价下行+竞争压力
- **基准**：4480元/吨（+1.0%）——订单结构改善+选择性接单
- **乐观**：4550元/吨（+2.5%）——产能紧张推升加工费

### 1.3 机器人降本曲线——吨利改善的核心引擎

**现有成本结构（2025年）**：

| 成本项 | 每吨金额 | 占吨成本比 |
| :--- | :--- | :--- |
| 钢材原材料 | ~3,500元 | ~88% |
| 人工（焊接） | ~320元 | ~8% |
| 人工（其他）+ 制造费用 | ~142元 | ~4% |
| **吨成本合计** | **~3,962元** | **100%** |

**机器人降本路径**：

| 阶段 | 机器人数量 | 替代率 | 焊接成本节省 | 产量效应摊薄固定成本 | 总降本效应 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 2024（起步） | ~800台 | ~10% | ~30元/吨 | 0 | ~30元/吨 |
| 2025（爬坡） | ~2,500台 | ~30% | ~95元/吨 | ~15元/吨 | 尚未释放（学习曲线中） |
| 2026E（规模化） | 3,300台+ | ~50% | ~160元/吨 | ~25元/吨 | 开始释放 |
| 2027E（成熟期） | 4,000台+ | ~70% | ~220元/吨 | ~30元/吨 | 全面释放 |

**公司调研确认**：截至2026年6月已有3,300台焊接机器人和铆大师检测机器人投入使用，但"目前降低成本还较少"——公司管理层原话。这意味着**降本效应是前置投入、滞后释放的**，2026年下半年到2027年是关键的释放窗口。

## 三、分部估值（SOTP）利润分配

鸿路钢构业务高度集中（钢结构制造96.95%），不适合传统SOTP。但公司正在开拓两个具有独立估值逻辑的新业务板块：

### 3.1 机器人外销业务

- 2025年9月开始外销，累计出口435台
- 假设2026年外销1,000台，均价25万元/台 → 收入2.5亿
- 毛利率50%（估算）→ 毛利1.25亿
- 期间费用分摊（K=1.2，高研发强度）→ 净利约0.5-0.8亿
- **对整体利润贡献约5-8%，尚不能支撑独立估值**

### 3.2 海外直接出口业务

- 正在执行韩国、沙特、阿曼、马来西亚订单
- 2026年直接出口占比预计约2-3%（约5-8亿收入）
- 海外订单毛利率通常高出国内3-5pct
- **处于起步期，2026年利润贡献有限但方向积极**

### 3.3 板块利润勾稽

| 板块 | 2026E收入 | 毛利率 | 模拟净利 |
| :--- | :--- | :--- | :--- |
| 国内钢结构制造 | ~246亿 | 9.9% | ~9.2亿 |
| 机器人外销 | ~2.5亿 | 50% | ~0.6亿 |
| 海外直接出口 | ~6亿 | 13% | ~0.4亿 |
| **合计** | **~255亿** | **10.2%** | **~10.2亿** |

勾稽校验：∑模拟净利 ≈ 预测总净利10.2亿 ✓

## 六、2027年初步展望

基于2026年基准情景的外推，给出2027年方向性预测（不作精确估值）：

- 产量：650-700万吨（机器人效率进一步释放）
- 吨扣非净利：150-180元/吨（降本效应全面兑现）
- 扣非净利：10-13亿
- 归母净利：13-16亿（考虑政府补贴维持）
- 方向性PE：10-12倍

**这是鸿路钢构投资价值的核心**：如果2026年确认吨利拐点，2027年将是利润爆发年。
