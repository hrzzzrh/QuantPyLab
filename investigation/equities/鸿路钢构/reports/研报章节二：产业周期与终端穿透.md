# 研报章节二：产业周期与终端穿透

**研究日期**：2026年07月20日

---

## 前序核心结论回顾（模块一）

在模块一中，我们识别出鸿路钢构的核心矛盾：**吨扣非净利从195元/吨暴跌至86元/吨（-56%），但产量以年均10%+的速度持续扩张，2025年产量突破500万吨**。这种"量增价跌、以量换价"的模式是否可持续，根本上取决于：行业需求能否支撑持续的量增？吨利是否已经触及底部？

---

## 一、产业生命周期与库存节奏

### 1.1 行业生命周期定位

中国钢结构行业正处于**成长期向成熟期的过渡阶段**：

| 判断维度 | 证据 | 结论 |
| :--- | :--- | :--- |
| 渗透率 | 钢结构占粗钢产量仅11%（2023），发达国家30%+ | **成长空间充裕** |
| 行业增速 | 2017-2023 CAGR 10.49%，但2024年首次-2.7% | **增速换挡，步入中速增长** |
| 集中度 | CR5仅7.46%，龙头市占率4.14% | **远未到成熟期寡头格局** |
| 政策驱动 | "十四五"目标1.4亿吨，2035年2亿吨 | **政策托底明确** |
| 技术变革 | 智能化焊接正在重塑生产函数 | **技术驱动的二次成长** |

综合判断：行业处于**"总量中速增长 + 结构剧烈分化 + 集中度加速提升"**的三重叠加态。这不是一个处于风口的新兴行业（2026年制造业投资已转负），但也不是陷入存量残杀的夕阳产业——钢结构对混凝土的替代逻辑仍在持续，渗透率提升空间明确。

### 1.2 库存动力学的"牛鞭效应"辨析

鸿路钢构2026Q1存货暴增至120.24亿（较2023年末+53.3%），市场有理由担忧这是"牛鞭效应"——终端需求放缓但上游仍在拼命生产。

**我们的判断：当前库存积累更多是主动策略而非被动积压**：

| 信号 | 解读 |
| :--- | :--- |
| 合同负债11.49亿（+33.6% YoY） | 预收款增长，在手订单充盈 |
| Q1产量120.38万吨（+14.75%）| 生产端仍在加速 |
| Q1新签合同74.12亿（+5.10%）| 订单端同步增长 |
| 钢价低位运行（热卷~3341元/吨）| 此时加大备货有成本优势 |

但需警惕：**如果终端固定资产投资持续加速下行（H1已降至-5.7%），高库存将从"利器"变为"毒药"**。需密切跟踪Q2库存变化。

## 二、终端需求穿透与跨期断层审计

### 2.1 最终产品画像

鸿路钢构的产品（钢结构构件）不是直接面向消费者的终端产品，而是**工业建筑的"骨架"**。其最终负载形态包括：
- **工业厂房**（占比最大，约55-60%）：新能源汽车工厂、锂电池工厂、半导体晶圆厂、光伏工厂、数据中心
- **大型公建**（约20-25%）：机场、火车站、体育场馆、会展中心
- **设备装置/能源基础设施**（约10-15%）：石化管廊、电厂钢结构、海上风电平台
- **高层/超高层建筑**（约5-10%）：写字楼、酒店

核心洞察：**鸿路钢构的本质是"制造业固定资产投资的可选消费品"**。其需求取决于：制造业企业是否在建新工厂、扩产能。这与房地产和基建的关系反而较弱。

### 2.2 终端景气度审计：结构性分化是核心叙事

#### 亮面（高景气赛道——鸿路钢构的核心增长引擎）

**1. 锂电池/新能源制造：超级资本开支周期**

2026年上半年，电池新能源全产业链新增投资项目219个，总投资额4149亿元，创三年新高。仅Q1锂电产业链就披露85个扩产项目，总投资超2200亿元。锂离子电池制造业投资增长24.9%（1-5月）。

这直接对应鸿路钢构的工业厂房需求：宁德时代、亿纬锂能、楚能新能源、海辰储能等头部电池企业正密集建设新生产基地。鸿路钢构2025年年报和2026Q1经营简报中，多次出现"楚能新能源150GWh锂离子电池高端智能制造项目"、"***时代新能源电池产业基地"、"磷酸铁锂储能动力电池建设项目"等大单。

**2. 半导体/电子制造：先进工艺扩产潮**

集成电路制造业投资增长11%（1-5月），电子电路制造业投资增长50.9%。长鑫科技募资295亿、长电科技资本开支上调至100亿。鸿路钢构订单中已出现"临港12英寸晶圆代工生产线项目"、"FAB1-生产厂房建设项目"、"存储器基地项目"等——晶圆厂对钢结构的精度和交付速度要求极高，恰好是鸿路钢构的优势领域。

**3. 造船业：百年一遇的超级景气**

2026上半年，中国船企接单1131艘、3100万CGT，同比+113%。手持订单排至2030年。造船业固定资产投资+24.7%（1-6月），是所有行业中增速最快的。恒力重工上半年接单超150艘。每一艘新船的建设都需要大量钢结构（船体分段车间、船坞配套等），鸿路钢构订单中已频繁出现"造船有限公司分段车间"、"曲面分段车间"等项目。

**4. AI算力/数据中心：新兴增量**

高工锂电峰会和公开数据均提到"AI算力中心配套"对钢结构的需求。鸿路钢构2026Q1大单中已出现"云数据中心一期项目"，这一领域有望成为结构性的新增量。

#### 暗面（下行赛道——对鸿路钢构影响有限但仍需关注）

**1. 传统制造业：整体转负**

1-6月制造业固定资产投资同比-1.2%（较Q1的+4.1%大幅恶化）。化学原料（-6.5%）、医药（-9.2%）、专用设备（-8.6%）、汽车（-4.2%）等传统制造领域投资收缩。这些是钢结构传统需求来源，若持续恶化，将侵蚀鸿路钢构的"基本盘"。

**2. 房地产开发：深不见底**

房地产开发投资-16.2%（1-5月），新开工-22.6%。钢结构住宅（装配式建筑）的推进远低于预期——住宅领域钢结构渗透率仍极低（<5%），与发达国家30%+差距悬殊。

**3. 基建：温和托底，不足以驱动增长**

道路运输投资-7.7%，水利-9.9%，公共设施-6.2%。传统基建对钢结构拉动有限（钢结构主要用在工业建筑而非基建）。

### 2.3 动能溯源与透支审计

**核心问题：当前的锂电池/半导体/造船投资热潮，是否属于"需求前置"，会在1-3年后出现断崖？**

| 终端领域 | 增长动能类型 | 透支风险评估 |
| :--- | :--- | :--- |
| 锂电池 | 内生（电动化+储能刚需）+ 外生（政策驱动） | **中等**。储能需求是确定的长期趋势（全球储能出货2026年+60%），但动力电池存在产能过剩隐忧。需区分"储能"与"动力"的投资持续性。 |
| 半导体 | 内生（AI驱动+国产替代）+ 外生（国家战略） | **较低**。国产替代是十年维度的长期工程，AI算力需求才刚开始。 |
| 造船 | 内生（船队更新+环保新规）+ 外生（地缘重构海运格局） | **较低**。手持订单已排至2030年，短期不会出现断崖。 |
| 光伏 | 内生（能源转型）+ 外生（政策补贴） | **较高**。光伏产能已严重过剩，2025-2026年仍有大量扩产——这是典型的"需求前置"领域，需警惕2027年后投资断崖。 |

**关键判断**：光伏相关订单（鸿路钢构大单中多次出现的"光伏示范项目"、"年产100GW光伏铝边框项目"）存在明显的跨期透支风险。但锂电池（特别是储能）、半导体、造船三大领域的资本开支持续性较强，可以为鸿路钢构提供至少2-3年的需求支撑。

## 三、供需边际与压力传导

### 3.1 供需平衡审计

**行业供给端**：
- 2024年全国钢结构加工量约1.09亿吨（同比-2.7%），行业首次下滑
- 中小企业加速出清：钢材价格波动+环保趋严+资质门槛提高
- 鸿路钢构逆势扩产：产量502万吨（+11.3%），产能利用率97%
- CR5从2017年的4.32%提升至2023年的7.46%，集中度在上升

**需求端（我们对2026-2027年的预判）**：
- "K型分化"将是主旋律
- 高端制造（锂电+半导体+造船+AI）投资维持高位 → **结构性增量**
- 传统制造业投资转负 → **结构性减量**
- 房地产/基建持续低迷 → **长期拖累**

**供需边际结论**：行业整体处于**弱平衡偏松**状态，但**高端产能（能承接大单、急单、高精度订单）供不应求**。鸿路钢构凭借520万吨产能和快速交付能力，位于供给曲线的"紧俏"一端。

### 3.2 压力传导特征分析

**钢价与吨利的传导机制**：

鸿路钢构的定价模式为"钢材成本+加工费"，理论上钢价波动可以向下游传导。但实际中：

1. **钢价下行期**（如2024-2025）：公司原材料库存采用移动加权平均法，账面成本下行慢于售价下行 → **毛利率承压**。这解释了为什么2024-2025年钢价下降但公司盈利反而恶化。

2. **钢价平稳/微涨期**（如2026H1）：钢价低位震荡，公司可享受低成本库存红利，同时若需求改善带来加工费回升 → **吨利改善的最佳窗口**。2026Q1扣非吨利回升至123元/吨正是在此背景下实现。

3. **钢价急涨期**：若"反内卷"政策推动钢价上涨，公司因庞大库存（120亿），成本采用移动加权平均 → 售价涨得快但成本涨得慢 → **吨利弹性极大**。据券商测算，钢价每波动1%，吨净利同向波动约5元。

**2026下半年钢价展望**：Mysteel预计热卷均价环比降0.5%、同比降0.9%，整体以区间震荡为主。这意味着公司面临的原材料价格环境**中性偏有利**——不会出现2024年的钢价急跌（导致库存减值），也不会出现成本端的急剧上升。

## 四、强制复核项确认

| 复核项 | 确认结论 |
| :--- | :--- |
| 是否穿透了终端产品未来两年景气度？ | **是**。锂电池、半导体、造船三大终端需求未来2-3年景气度明确向上，但光伏领域存在透支风险。制造业整体投资转负需持续警惕。 |
| 是否审计了"跨期需求移位"风险？ | **是**。光伏领域需求前置风险较高；储能、半导体、造船领域透支风险可控。 |
| 是否分析了供需边际演变及压力传导？ | **是**。行业整体供需偏松但结构性紧俏。钢价平稳震荡有利于公司吨利修复，Q1 2026的吨利改善趋势有望延续。 |

## 五、模块二核心结论

鸿路钢构的终端需求呈现**"一半海水、一半火焰"**的剧烈分化格局：

1. **"火焰"侧（约占营收50-60%）**：锂电池、半导体、造船、AI数据中心等领域正处于史诗级资本开支周期。这些领域对钢结构的需求不仅量大，而且对精度、工期要求极高——正是鸿路钢构的差异化优势所在。

2. **"海水"侧（约占营收30-40%）**：传统制造业、房地产、基建投资持续收缩，这部分需求呈现长期下行趋势。

3. **关键胜负手**：鸿路钢构能否凭借其规模、技术和快速交付优势，将订单结构从"海水"向"火焰"方向持续优化？从2025年大单方向和2026Q1数据看，这一趋势正在发生——但速度决定估值。
