## 一、投资摘要

### 1.1 核心投资逻辑

大博医疗是中国骨科植入耗材行业**全品类覆盖、效率领先的国产龙头**。2023 年为利润底部（归母净利润 0.59 亿），2024-2025 年业绩 V 型反转，2025 年归母净利润 6.00 亿（+68%）。**2026H1 半年报揭示盈利结构质变**：营收 +10.69%（Q2 单季仅 +5.8%）收入引擎降档，但毛利率 74.45%、归母净利 +44.65% 大超预期——公司已切换至"利润率驱动"模式。运动医学 +72.5% 接棒关节成为第三增长引擎，而关节品类 -10.35% 证伪了原"多引擎共振"叙事。

公司的商业模式本质仍是**"研发-VBP赛跑"**——三类注册证达 310 张（半年净增26张），护城河以速度型为主。行业总量增速换挡已被竞对中报集体证实（威高 -4.9%、春立 Q1 -5.6%、爱康 +10%），大博的相对份额地位仍在强化，但绝对增速中枢系统性下移。

## 三、研究结论象限图

基于"确定性"与"预期收益空间"双维度评估：

```
        预期收益空间
             ↑
    高       |    第二象限              |    第一象限
             |  (Speculative Growth)    |  (High-Conviction Buy)
             |                          |  
             |                          |   
     ————    +—————————————————————————+————————→ 确定性
             |                          |
    低       |    第四象限              |    第三象限
             |  (Avoid/Wait)            |  ★ 大博医疗(2026-08)
             |                          |  (确定性: 中高, 收益空间: 中低)
```

**定位：第三象限（Defensive Value）边缘**（自"一/二象限交界偏二"下调）

- **确定性**：中高。利润底部抬高（保守情景净利从 6.28 亿上移至 7.20 亿）、利润率优势验证、创伤基本盘稳固
- **预期收益空间**：中低。加权目标价 +13.0%，低于资金成本加合理风险溢价的重仓门槛
- **最终评级**：**Hold（持有/观望）**，自 Buy 下调一档

**核心判断**：这是一家"好公司遇上赔率变差"的典型案例——质量因子全面改善（毛利率、注册证、平台对冲能力），但收入减速使盈利弹性收敛，而市场已提前定价了部分乐观预期。存量仓位持有不动，新增资金等待两类信号之一：① 价格信号——回踩 42-43 元均线簇；② 事件信号——脊柱接续采购温和落地。
