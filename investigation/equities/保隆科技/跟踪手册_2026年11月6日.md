## 三、逻辑证伪警报（Invalidation Triggers）

### 3.1 致命信号（出现任一项即刻清仓）

- [ ] **智能悬架毛利率连续两季低于15%** → 规模效应破产（Q3未披露，反推约13-15%，**已进入触发边缘**）
- [ ] **公司宣布大规模股权融资（定增/配股）** → 流动性危机确认
- [ ] **核心客户（蔚来/比亚迪/理想）流失空悬定点给竞对** → 市场地位动摇
- [ ] **年报/半年报审计意见为非标** → 财务可信度崩塌
- [ ] **美国将保隆科技列入实体清单** → 全球化封堵

### 3.2 严重恶化信号（出现两项以上→清仓/大幅减仓）

- [x] **综合毛利率跌破20%（单季口径）** → **已触发（Q3单季19.53%；累计21.39%、TTM 20.98%仍在线上）**
- [ ] **经营现金流连续两季为负** → Q3 +0.43亿，未触发
- [x] **短期借款/货币资金>4倍** → **已触发（29.91/7.43=4.02x，H1为3.81x）**
- [ ] **空悬市占率跌破20%** → 30.7%，未触发
- [ ] **在手订单总额<80亿元** → 未披露，无法核验
- [ ] **连续两个季度营收增速<5%** → +29.96%，未触发
- [ ] **扣非净利连续两季环比下滑超20%** → Q2 0.475→Q3 0.517（+8.9%），未触发

**口径声明（重要）**：上期手册以“半年累计口径”判定毛利率（H1 22.47%“暂安全”）。本期改用**单季口径**判定“跌破20%”，理由：毛利率的恶化是Q3单季事件，累计口径会滞后两个季度才反映，失去预警功能。为避免“事后凑信号”，同时披露：若沿用累计口径（9M 21.39%>20%），则仅“短债/货币4.02x”一项触发，按规则应为“负面信号、重新评估”。**但即便只有一项，结合“2027E盈利依赖2/5确定性的毛利修复”与“中性价已低于现价”，下调至减仓/回避仍成立**——评级决策不以信号计数为唯一依据。

### 3.3 负面信号（出现需重新评估仓位和评级）

- [x] **存货增速持续>营收增速** → **Q3首次触发（存货+14.2% QoQ vs 营收+11.5%）**
- [ ] **应收账款同比增幅>营收增幅10pct** → 未触发（+9.2% vs +22.5%）
- [ ] **研发人员数量连续两季下降** → 946专利维持
- [ ] **核心管理层减持超持股5%** → 未触发
- [ ] **公允价值连续两季为负** → Q3 -0.725亿，若Q4再负则触发
