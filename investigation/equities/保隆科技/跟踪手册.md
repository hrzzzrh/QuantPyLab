## 三、逻辑证伪警报（Invalidation Triggers）

以下信号出现时，必须承认当前投资逻辑已被证伪，无条件触发止损或下调评级：

### 3.1 致命信号（出现任一项即刻清仓）

- [ ] **智能悬架毛利率连续两季低于15%** → 规模效应破产（2026H1综合22.47%暂未触发，但空悬自身未披露需警惕）
- [ ] **公司宣布大规模股权融资（定增/配股）** → 流动性危机确认（70.55%+26.38亿短债，风险上升）
- [ ] **核心客户（蔚来/比亚迪/理想）流失空悬定点给竞对** → 市场地位动摇（2026H1新增宝马优选+比亚迪云辇，反向验证）
- [ ] **年报/半年报审计意见为非标** → 财务可信度崩塌
- [ ] **美国将保隆科技列入实体清单** → 全球化封堵

### 3.2 严重恶化信号（出现两项以上→清仓/大幅减仓）

- [ ] **综合毛利率跌破20%** → 盈利拐点无望（H1 22.47%暂安全，但扣非净利率仅2.95%）
- [ ] **经营现金流连续两季为负** → 造血枯竭（H1 1.77亿但Q2仅0.20亿，Q3若转负触发）
- [x] **短期借款/货币资金>4倍** → 流动性风险急剧上升（**已触发：26.38/6.93=3.81x，接近4倍；2026Q1为3.23x，恶化中**）
- [ ] **空悬市占率跌破20%** → 竞争恶化（H1 25.3%暂安全）
- [ ] **公司在手订单总额<80亿元** → 中期成长逻辑动摇（未披露，待核实）
- [ ] **连续两个季度营收增速<5%** → 增长熄火（H1 18.59%暂安全）
- [ ] **扣非净利连续两季环比下滑超20%** → 经营恶化（Q2 0.47亿vs Q1 0.90亿已下滑47%，若Q3再跌触发）

### 3.3 负面信号（出现需重新评估仓位和评级）

- [ ] **应收账款同比增幅持续>营收增幅10pct以上** → 议价恶化（H1已改善，增速4.8%<18.6%解除）
- [ ] **存货增幅持续>营收增幅** → 渠道积压（H1已改善）
- [ ] **研发人员数量连续两季下降** → 长期竞争力不足（946专利维持）
- [ ] **核心管理层减持超持股5%** → 内部人信心动摇（实控人反而增持28万股，需持续跟踪）
