## 三、逻辑证伪警报（Invalidation Triggers）

以下信号出现时，必须承认当前投资逻辑已被证伪，无条件触发止损或下调评级：

### 3.1 致命信号（出现任一项即刻清仓）

- [ ] **智能悬架毛利率连续两季低于15%** → 规模效应逻辑破产，空悬业务沦为"卖得越多亏得越多"
- [ ] **公司宣布大规模股权融资（定增/配股）** → 流动性危机确认，现有股东权益大幅摊薄
- [ ] **核心客户（蔚来/比亚迪/理想）流失空悬定点给竞对** → 市场地位根本性动摇
- [ ] **年报/半年报审计意见为非标（保留意见/否定意见/无法表示意见）** → 财务可信度崩塌
- [ ] **美国将保隆科技列入实体清单（Entity List）** → 全球化战略被封堵

### 3.2 严重恶化信号（出现两项以上→清仓/大幅减仓）

- [ ] **综合毛利率跌破20%** → 盈利拐点无望，最低容忍线
- [ ] **经营现金流连续两季为负** → 造血能力枯竭
- [ ] **短期借款/货币资金>4倍** → 流动性风险急剧上升
- [ ] **空悬市占率跌破20%** → 竞争地位严重恶化
- [ ] **公司在手订单总额<80亿元** → 中期成长逻辑动摇
- [ ] **连续两个季度营收增速<5%** → 增长引擎熄火

### 3.3 负面信号（出现需重新评估仓位和评级）

- [ ] **应收账款同比增幅持续>营收增幅10pct以上** → 议价能力恶化
- [ ] **存货增幅持续>营收增幅** → 渠道积压问题
- [ ] **研发人员数量连续两季下降** → 长期竞争力投资不足
- [ ] **核心管理层（董事长/CEO/CTO）减持超持股5%** → 内部人信心动摇
