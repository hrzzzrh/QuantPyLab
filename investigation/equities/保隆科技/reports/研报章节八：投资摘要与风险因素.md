## 一、投资摘要

### 1.1 核心结论

保隆科技（603197）是一家**盈利拐点初现但盈利质量与财务风险仍待验证**的汽车零部件平台型公司。2026H1实现营收46.84亿（+18.59%）、归母2.64亿（+95.79%）、扣非1.38亿（+40.29%），Q2单季1.92亿（+386%）创2023年来单季新高，毛利率22.47%（Q1 22.09%→Q2 22.81%）连续两季修复，合肥保隆亏损收窄34%，显示“增收不增利”剪刀差在经营层面出现拐点。全球化落地（泰国8/21开园、匈牙利二期建成、美国TPMS在建）+新获3.8+2.7亿ADAS定点+宝马优选供应商，为长期逻辑提供支撑。

**但拐点的“成色”需审慎**：H1净利2.64亿中1.16亿为琻捷电子上市公允价值收益（占比44%），扣非仅1.38亿且Q2扣非净利率仅1.94%，经营改善幅度远弱于报表；财务费用0.835亿（+389%汇兑损失）+资产减值0.40亿持续侵蚀；70.55%资产负债率+26.38亿短债（+49.87%）+担保141%净资产，流动性风险在扩张关键期未缓解。**当前市值64.12亿（29.96元）较07-13的57.64亿（26.93元）已price in约60%盈利修复（PE 27.1→18.76含非经常，扣非PE仍38.8x）**，若不能在H2兑现扣非1.86亿（H2需较H1 +35%），估值将承压。

**估值锚（重估，B-1更正后）**：Base 96.15亿营收/4.60亿归母（扣非3.24亿）→EPS 2.15元（扣非1.51元）→18x PE→基准市值82.8亿→全变量-7%（全球化+2%/-5%/-4%）→修正市值77.0亿→修正目标价36.0元，三态22.4/36.0/50.1（仅中性调节），加权35.42元（+18.2%），盈亏比0.72；扣非锚1.51×22-25x=33.2-37.8元交叉验证，36.0已price in公允（27.0%→16.9%上行收窄，下行30.6%扩大）。

## 三、研究结论象限图

基于“确定性 × 预期收益空间”二维评估：

```
            高确定性(★★★★★)
                 │
    第三象限     │    第一象限
  Defensive      │  High-Conviction
   Value         │      Buy
   (防御/底仓)   │   (核心重仓)
                 │
 ────────────────┼─────────────────
            低   │              高
   预期收益      │          预期收益
                 │
    第四象限     │    第二象限
  Avoid/Wait     │  Speculative
   (回避/观望)   │    Growth
                 │   (黑马/期权)
                 │
            低确定性(★)
```

**保隆科技的定位（重审）**：

- 确定性：★★★（2.8/5，量增4/5但利润率2.5/5，扣非质量弱）
- 预期收益空间：★★★（2.5/5，加权+16.9%<25%，扣非-9%）
- **盈亏比0.72<1**，安全边际不足

**结论：从“二/四象限交界（观望等待）”调整为“第三象限边缘（持有/观望，不追高）”**。

- 以当前29.96元介入→**第三象限偏防御**（低赔率+中等确定性），适合持有但不加仓，等待回调或Q3验证。
- 若回调至22-24元→可升级为**第二象限赔率型**（盈亏比布1.5+），积极建仓。
- 若Q3扣非>0.6亿+经营现金流>0.5亿+毛利≥22.5%→确定性提升至3.5/5，无论价格均可加仓至标准。

**最终建议（更新）**：**持有/观望，不追高；目标买入区仍为22-24元，短期支撑28.5-29.5分批，跌破25.3止损，放量突破30.41（MA60）右侧加仓**。07-13的“小仓位试探”在8月反弹13%后已兑现，当前不宜加仓。
