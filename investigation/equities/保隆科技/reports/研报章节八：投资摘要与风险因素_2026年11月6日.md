## 一、投资摘要

### 1.1 核心结论

保隆科技（603197）2026年三季报**证伪了“毛利率修复”这一核心投资逻辑**。Q3营收27.26亿（+29.96%）创单季新高、扣非0.52亿（+53.41%），但**综合毛利率19.53%（同比-1.81pct、环比-3.28pct）为2024年以来最低**，归母-0.12亿（-119.08%）系琻捷电子股价下跌带来-0.725亿公允价值损失；9M营收74.10亿（+22.53%）、归母2.52亿（+27.14%）、扣非1.90亿（+43.64%）、毛利率21.39%（低于上年同期21.65%）。

**三条相互印证的负面证据**：①**份额与毛利反向**——空悬1-8月份额升至30.7%（+7.8pct、反超拓普），但单价被压至2000元区间（公司联合创始人公开称“已到底”），份额是用价格买来的；②**同业对照**——拓普Q3毛利率仅-0.33pct、中鼎Q3毛利率23.20%，同样受公允价值拖累，但毛利率稳定，说明保隆-3.28pct是个体问题；③**财务约束收紧**——资产负债率72.86%（历史新高）、短债29.91亿、短债/货币4.02x、净负债/归母权益1.48x、存货单季+14.2%。

**估值锚（2027E）**：Base 118.0亿营收/3.99亿归母（扣非3.69亿）→EPS 1.86元→15x PE→59.7亿→全变量-7%（DNA+1%/治理-4%/地缘-4%）→55.5亿→**25.94元**；三态**13.44/25.94/65.93元**，加权**30.82元**（+18.4%），**盈亏比0.38**（<1）。**中性目标价与现价基本相当（-0.3%），现价已处合理区间中枢，不存在显著低估**。

## 三、研究结论象限图

基于"确定性 × 预期收益空间"二维评估：

```
             高确定性(★★★★★)
                  │
     第三象限     │    第一象限
   Defensive      │  High-Conviction
    Value         │      Buy
    (防御/底仓)   │   (核心重仓)
                  │
  ────────────────┼─────────────────
             低   │              高
    预期收益      │          预期收益
                  │
     第四象限     │    第二象限
   Avoid/Wait     │  Speculative
    (回避/观望)   │    Growth
                  │   (黑马/期权)
                  │
             低确定性(★)
```

**保隆科技的定位（2027E重锚定）**：

- 确定性：**★★（2.2/5，中低）**——收入端3.5/5（份额30.7%、Q3营收+30%），利润率端1.5/5（毛利率连续三季低于预期、Q3创新低）
- 预期收益空间：**★（1.5/5，加权+18.4%、中性-0.3%）**
- **盈亏比0.38<1**，安全边际为负

**结论：由“第二象限（积极建仓）”直接下调至“第四象限（Avoid/Wait，回避/观望）”**。依据：①中性目标25.94元已低于现价26.03元；②盈亏比0.38<1；③跟踪手册两项严重恶化信号同时触发（Q3单季毛利率19.53%<20%、短债/货币4.02x>4x），按手册3.2条应“清仓/大幅减仓”；④2027E盈利依赖空悬毛利率+3.0pct（确定性2/5）。

**最终建议**：**减仓/回避（原“积极建仓/分批加仓”下调两级）**；持仓者在28.62元（MA20）下方逢反弹减仓至≤1%，跌破25.30元（2024年1月低点）清仓；空仓者不参与，**目标买入区15.00-17.00元**（对应2027E 8.1-9.1x、PB 0.99-1.12x，按2026E BVPS 15.2元），届时需同时满足“Q4毛利率≥20.1%（F1 P50）+短债/货币≤3.8x（F5 P50）+空悬价格企稳”三项方可建仓。
