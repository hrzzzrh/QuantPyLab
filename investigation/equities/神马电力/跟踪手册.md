## 三、逻辑证伪警报 (Invalidation Triggers)

以下信号一旦出现，必须**立刻重新评估投资逻辑并触发止损/降级**：

| 级别 | 触发条件 | 行动 |
| :---: | :--- | :--- |
| 🔴🔴🔴 | **核心产品批量质量事故**，被国网/南网暂停投标 | **无条件清仓**——逻辑基石崩塌 |
| 🔴🔴🔴 | **季度营收增速 <5%**（剔除一次性因素） | **立即减仓50%**——增长引擎熄火 |
| 🔴🔴 | **毛利率连续两季 <40%** | **减仓30%**——定价权或成本控制出现结构性恶化 |
| 🔴🔴 | **海外营收连续两季负增长** | **减仓30%**——出海核心逻辑证伪 |
| 🔴🔴 | **大股东（马斌/陈小琴）减持 >5%** | **减仓20%**——内部人信心信号 |
| 🟡 | **控股股东新增质押、质押比例上升或未来到期集中** | **核验质押余额与到期结构**——不得用无减持迹象替代质押风险判断 |
| 🔴 | **特高压年度核准项目 <3条** | **降级至观察**——行业景气度下修 |
| 🔴 | **大连电瓷等在复合绝缘子领域获得重大中标** | **审慎评估**——竞争格局或生变；H1预告不等同中标或份额变化 |
| 🔴 | **H2需实现营收12.0648亿元、归母净利润3.6721亿元但交付/回款连续不达标** | **重建盈利预测**——全年基准兑现度下降 |
| 🟡 | **应收、存货与借款继续上升而经营现金流转弱** | **降低盈利质量评价**——复核回款、账龄与资金占用 |
| 🟡 | **NG/Elia框架未转为可核验下单、交付或收入确认** | **维持预测不变**——不得将框架金额计入H2 |
| 🟡 | **越南/美国项目出现可核验的产能、投产或收入信息** | **更新海外产能假设**——目前仅记录IRC/ERC、搭线和厂房租赁状态 |
| 🟡 | **经营现金流连续四季为负** | **密切追踪**——资金链风险 |
| 🟡 | **美国/越南工厂建设进度延期 >6个月** | **重新评估增长假设**——产能释放推迟 |
| 🟡 | **后复权价重新跌破MA20/MA250，或持续无法收复MA60/MA120** | **当前部分缓解**——8月12日50.63元已高于MA20 47.01和MA250 48.98，但中期确认未完成 |
