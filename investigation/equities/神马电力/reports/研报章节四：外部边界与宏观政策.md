# 研报章节四：外部边界与宏观政策

**研究日期**：2026年11月7日  
**研究对象**：神马电力 (603530.SH)  
**章节继承**：模块一识别47%海外收入占比、Q3单季毛利率44.27%与前三季度财务费用0.2370亿元（汇兑压力），模块二确认需求端强而交付节奏弱、模块三确认竞对加码复合路线；本章复核外生变量：硅橡胶/有机硅DMC小幅上行、人民币偏强使汇兑由收益转为费用、14421号行政令细则仍待12月24日。

## 一、贸易摩擦与地缘政治——可对冲的风险，非致命的威胁

### 1.1 美国关税影响评估

2024年起美国对华关税持续升级。神马电力在2025年5月业绩说明会上**官方表态**："美国关税对公司业务影响有限"。

**为什么影响有限？**

| 应对措施 | 进展 | 对冲效果 |
| :--- | :--- | :--- |
| **美国本地工厂** | 已完成厂房租赁协议签署，正在做产能规划；投资额、设计产能和投产日期未披露 | 形成潜在本地化对冲，实际效果待项目推进验证 |
| **越南工厂** | 已获IRC投资许可证和ERC营业执照，正在搭建产线；符合原产地资质、价值增量工序在当地实施（注射、成型、装配、检测）；一期总投资不超过1.22亿元 | 具备本地化与原产地资质基础，关税与交付效果逐步可量化但仍需投产验证 |
| **14421号行政令专项** | 2026年9月初调研明确：该政令主要针对具备控制/远程访问能力的设备与系统，神马产品为结构性被动硬件（不搭载控制芯片与通讯模块），不属于重点规制范围；能源部需120日内出台细则，当前属跟踪期 | 电网设备特殊性+被动硬件属性提供政策豁免逻辑，但细则未出前保留不确定性 |
| **供应链本地化** | 公司明确"通过供应链本地化、区域化提升抗风险能力"；越南/美国投产后可实现本地化生产交付缩短周期、首次销售规则优化成本 | 原材料本地采购进一步降低贸易摩擦冲击 |
| **渠道优势** | 通过Hitachi Energy/Siemens Energy等设备商间接出口，不以成品直接出口为主；北美变电设备已交付部分765kV样件在当地配合整机试验 | 关税征收对象是设备商而非神马，变电侧先行 |

**核心逻辑**：公司9月初调研对14421号行政令给出被动硬件豁免判断，并披露越南工厂原产地资质与工序本地化细节，美国工厂产能规划进展；但细则未落地、项目产能与收入贡献仍未量化，设备商渠道和产品价值占比只能作为结构性背景，不能据此把贸易摩擦影响认定为已经被完全对冲。新增2.35亿元中国电气装备集团集采中标显示国内主网需求对冲海外不确定性的能力。

### 1.2 贸易摩擦对电网设备的特殊性

电力设备有特殊属性：**电网安全事关国家安全，具备"刚需豁免"特征**。美国即便加征关税，也无法阻止电网公司采购必需设备——因为美国本土变压器产能仅能满足需求约20%，高压设备排期已到2030年。美国政府2026年批准的750亿美元输电网扩建计划（765kV线路从2000英里扩至10000英里）意味着**即使关税壁垒存在，中国电力设备（尤其是具备不可替代性的产品）仍然面临强劲需求**。

### 1.3 中东市场——地缘政治的意外红利

地缘冲突重塑了全球能源设备贸易流：
- **沙特**：2025年中国出口沙特电力变压器超60亿元（同比+100%），成为最大出口目的地
- **神马中标**：2025年中标中电装备沙特中南/中西柔直换流站项目（全球除中国外最大柔直项目），为中东首个重大项目
- **地缘逻辑**：中东国家在美欧地缘政治摇摆中加速向中国开放能源基建市场，中国电力设备全产业链（变压器→开关→绝缘子）集体受益

### 1.4 供应链重构 (China+1) 与神马的应对

行业层面"China+1"趋势确实存在（欧美设备商寻求多元化供应），但绝缘子环节具有特殊性：
- **认证壁垒**：新供应商认证周期12-24个月，电网公司不可能为"去中国化"而牺牲安全性
- **技术壁垒**：神马的HTV硅橡胶配方+30年免维护承诺，海外竞争者短期无法复制
- **先发优势**：神马已在新加坡、美国、巴西、荷兰、越南建立全球化布局，本身就是"China+1"趋势的受益者

**风险评估**：地缘政治风险仍是中度外部变量。美国项目已进入厂房租赁阶段，但投产日期、产能和收入贡献未披露，不能把它视为已经落地的终极对冲；关税与本地化效果需结合后续项目文件、订单和交付核验。

## 二、宏观环境——三重利好共振

### 2.1 利率与折现率

2025-2026年全球利率环境已进入降息通道。欧洲央行2024年10月至今多次降息，中国LPR持续下行。对于神马：
- **融资成本**：公司2025年末有息负债4.63亿（短期2.50亿+长期2.13亿），降息直接降低财务费用
- **DCF估值**：折现率下行提升远期价值（PE扩张逻辑）
- **设备投资**：下游电网公司投资意愿因低利率而增强（全球电网投资超级周期的金融基础）

### 2.2 汇率损益

2026年前三季度财务费用为0.2370亿元，上年同期为-0.0790亿元，同比多支出约0.316亿元，其中Q3单季0.0754亿元；H1汇兑损失约0.1524亿元，说明人民币在三季度延续偏强（Q3即期一度至6.64附近）。公司披露外汇衍生品以套期保值为目的，但套保无法完全抵消资产负债表折算与结算时点差。**含义：汇率已从2023-2025年的"财务费用为负（增益）"转为"持续费用项"；2026E财务费用率按+1.55%建模（9M已达1.78%，Q4约0.07亿元、即约1.0%-1.2%收口；全年合计约0.307亿元），2027E按+0.8%、2028E按+0.7%，不再假设汇兑增益。**

### 2.3 通胀与原材料传导

有机硅产业链价格自8月低点温和上行：生意社有机硅DMC基准价11月4日14,600元/吨（8月中枢约13,300-13,500元/吨），华东市场主流报盘13,800-14,800元/吨（隆众11月5日）；生胶华东成交价14,800-15,300元/吨（有机硅商城11月3日），较8月末14,000-15,000元/吨上行约5-7%。公司9月调研已明确通过前置锁价、批量备货对冲，3月涨价未造成明显不利影响；但连续两个季度的成本抬升叠加Q3交付结构恶化，意味着Q4毛利率难以自动修复至47%以上。**处理原则：原材料属于可计算因子，进入E（2026E综合毛利率46.4%、2027E综合毛利率46.2%，变电站分部假设47.5%），不在PE中二次扣减。**

## 三、监管与产业政策——最确定的顺风

### 3.1 国内政策：顶层设计与底层落地共振

| 政策/规划 | 时间 | 核心内容 | 对神马的影响 |
| :--- | :--- | :--- | :--- |
| 国家发改委 | 2026年5月 | "十五五"新型电网投资超5万亿 | **直接驱动**：绝缘子作为电网核心器件，需求确定性极强 |
| 国家电网 | 2026年1月 | 4万亿固投计划，跨区输电能力+30% | 特高压绝缘子需求集中释放 |
| 国家能源局 | 2025年 | 《新型电力系统发展指导意见》 | 电网复合化、智能化趋势利好复合材料绝缘子 |
| 双碳目标 | 2030/2060 | 碳达峰/碳中和 | **长周期逻辑**：新能源并网需要大规模电网扩张 |
| 《电力装备行业稳增长工作方案》 | 2024年 | 鼓励电力装备出口 | 出海政策利好 |
| 设备更新政策 | 2025-2026 | 国网大规模设备更新 | 存量替换需求释放 |

### 3.2 行业准入壁垒——神马的政策护城河

绝缘子行业进入需要：
1. **型式试验认证**：国家电网/南方电网的入网许可，耗时1-2年
2. **特高压资质**：仅极少数企业具有特高压等级产品的供货资质
3. **IEC标准**：国际认证周期长（5-10年），神马通过TC36主席地位天然具备先发优势

**从行业准入角度**，神马面临的不是"政策收紧风险"，而是"政策强化壁垒"——更高的标准有利于龙头出清中小企业。

### 3.3 海外政策的双刃剑

**正面：**
- 欧美"Buy America/Buy European"政策推动本地化制造——神马已披露美国厂房租赁、越南IRC/ERC和搭线进展，但产能与投产日期仍未披露
- 英国废除风电组件进口关税（2026年4月生效），示范效应可能扩展至电网设备

**风险面：**
- 美国301关税：若扩大至电网设备，短期内增量订单可能受影响；美国项目的本地化对冲效果待投产和交付材料验证
- 欧洲碳边境调节机制(CBAM)：当前覆盖水泥、钢铁等，未来若扩展至电力设备，将增加出口合规成本。但神马的产品具有"减排效益"（零维护=减少运维碳排放），反而可能成为加分项

## 五、小结：政策与需求顺风未变，执行节奏与汇率成本是新增边际压力

神马电力面临的外部环境中，**宏观利率下行、政策扶持和全球电网投资加速**构成顺风，且本期获得强化证据：2026年前三季度电网投资4,594亿元/+4.9%、变压器出口612.2亿元/+18%（对北美+48%）、特高压四批招标329.10亿元/+62%。最大的外部风险仍是**中美贸易摩擦**，9月调研对14421号行政令给出被动硬件豁免逻辑，越南IRC/ERC+产线搭建与美国厂房租赁提供本地化路径，但细则（12月24日）未出前不能视为已闭环。

**新增的两项边际压力**：①有机硅DMC由8月中枢约13,300-13,500元/吨升至11月14,600元/吨、生胶14,800-15,300元/吨，成本端由"温和"转为"温和上行"，已进入E的毛利率假设；②人民币偏强使财务费用由2025年的-0.0521亿元转为前三季度+0.2370亿元，2026E财务费用率按+1.55%建模（9M已达1.78%，Q4约0.07亿元、约1.0%-1.2%收口；全年合计约0.307亿元，与章节五一致），不再假设汇兑增益。此外，国网Q3投资执行放缓（隐含单季约-8%至-3%）已被证明可直接传导为设备商单季收入下滑，属于"已实现的节奏风险"而非尾部风险。

**核心判断**：外部变量的**配置方向（Direction）总体顺风**（电网投资扩张、降息和政策支持），但成本与汇率已转为负向贡献，交付节奏成为新的外生约束；**尾部风险（Tail Risk）仅有潜在对冲路径**（全球化布局、标准制定权和设备商渠道），在项目投产、订单和交付闭环前不能视为已消除。

> **跨模块线索（供后续模块继承）**：
> 1. 有机硅DMC/生胶较8月上行5-7%→ 模块五2026E综合毛利率按46.4%、2027E 46.2%建模（变电站分部毛利率假设47.5%），不假设综合毛利率继续上行
> 2. 前三季度财务费用+0.2370亿元（上年同期-0.0790亿元）→ 模块五财务费用率按正贡献成本建模，不预设汇兑增益
> 3. 美国项目仅披露厂房租赁与样件整机试验、越南项目仅披露IRC/ERC与搭线→ 模块五不得将未披露的产能、投产日期或收入贡献量化入模型
> 4. 贸易摩擦与汇率属可计算因子→ 进入E；模块六PE仅保留治理与执行不确定性折价
> 5. 国网Q3投资节奏放缓已被证明可传导至单季收入→ 模块五2026E必须以Q4补交付收口，并设Q4收入增速为关键裁决点
