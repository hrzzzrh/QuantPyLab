## 一、方法论选择与适配性论证

神马电力是一家**高增长（25%+）、高ROE（24%+）、轻资产（固定资产/总资产~27%）、全球布局**的高端电力设备制造商。考虑其商业模式、现金流特征与生命周期，选用以下方法交叉验证：

### 1.1 方法筛选

| 方法 | 适用性 | 选择理由 |
| :--- | :---: | :--- |
| **PE估值（主锚）** | ★★★★★ | 盈利稳定增长，行业可比性强，市场认知度高 |
| **PEG估值（辅助）** | ★★★★ | 高增长阶段，PEG能合理平衡估值与增速 |
| **PB-ROE模型** | ★★★ | 高ROE驱动高PB，作为估值天花板参考 |
| **DCF估值** | ★★ | 现金流不稳定（OCF<NP），高度依赖远期假设 |
| **SOTP分部估值** | ★★★ | 线路业务当前不盈利但有期权价值 |
| **PS估值** | ★★ | PS 11.29x仍高，参考意义有限 |

**选择**：(1) **PE估值**作为主锚（锚定2027E EPS），(2) **PEG估值**作为合理性校验，(3) **PB-ROE模型**判断估值溢价可持续性。

### 1.2 估值锚点切换

2026年半年报于8月13日公告，但本次可复核的最后交易日为8月12日，点时估值仍以2026Q1 TTM ASOF记录。按框架规则锚定当年（2026E）EPS，同时保留2027E作为PE主锚；H1实绩及H2桥接用于更新盈利兑现置信度，不直接替换公告前估值记录。

## 三、估值全变量对冲审计矩阵（强制性输出）

### 3.1 审慎思考：哪些因子真正影响估值中枢？

基于第四模块的宏观分析和第三模块的竞争分析，筛选出**真正具有估值影响力**的因子：

> **过滤器逻辑**：绝大多数"利好/利空"仅是市场噪音，不能改变估值中枢。只有能改变长期确定性、现金流质量或增长天花板的因子，才配得上估值调整。

### 3.4 逻辑纯净性校验

| 因子 | 归入E还是PE | 理由 |
| :--- | :--- | :--- |
| 特高压订单增长 | **归入E** | 具体的、可量化的营收/利润增量 |
| 毛利率改善 | **归入E** | 具体体现在利润表中 |
| 全球电网投资趋势 | **双面** | 增量订单→E；远期确定性提升→PE小幅溢价 |
| 技术壁垒/标准制定权 | **归入PE** | 不可量化为具体利润数字，但增加了长期确定性和护城河溢价 |
| 地缘政治/关税风险 | **归入PE** | 无法精确量化为具体金额，但影响风险溢价 |
| 小流通盘 | **归入PE** | 流动性溢价，与基本面无关 |

**校验通过**：不存在"双杀"或"双重计算"的漏洞。E中的增长已通过P*Q模型体现，PE中的调整仅针对确定性/不确定性。

## 五、逻辑证伪与极限压力测试

### 5.1 黑天鹅场景："一击毙命"事件

**场景定义**：核心产品出现重大质量事故，导致国家电网/南方电网暂停神马电力所有产品的投标资格（参照过往电力行业类似事件，整改周期6-18个月）。

**影响评估**：
- 短期内收入断崖下滑（国网+南网占境内营收~70%，约6亿）
- 毛利率因产能空置而恶化（固定成本无法消化）
- 海外客户信心受影响（Hitachi Energy等可能暂停新订单）

**地狱价格计算（2026H1资产口径）**：
- 重资产清算价值：固定资产净额8.2186亿×70% + 存货4.0705亿×60% + 货币资金2.4222亿 + 应收账款净额8.6141亿×50% = 5.7530 + 2.4423 + 2.4222 + 4.3071 = **14.9246亿元**，按统一视图有效股本4.31404377亿股折合约 **3.46元/股**。
- 净现金价值：货币资金2.4222亿 - 短长期借款合计5.713亿 = **-3.2908亿元**（净债务，约-0.76元/股）；这只是偿债压力口径，不是目标价。
- **最保守经营恢复值（30%收入恢复）**：年净利1亿元×PE12x=12亿元，按统一视图有效股本折合约 **2.78元/股**；该值与清算值分属不同压力测试口径，不混合使用。

**PB压力带（独立于清算值）**：在“神马品牌崩塌”的最极端场景下，若市场仅给予约1.5-2.0x PB，15-20元可作为压力带观察区间，但它不是上述清算价值的推导结果。以当前41.22元（09-30实测）计，至该压力带的潜在跌幅约 **51-64%**（09-09 47.75元时约58-68%），仅用于极端风险管理，不作为正式支撑位或目标价。
