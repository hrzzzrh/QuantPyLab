## 一、投资摘要 (Investment Summary)

### 核心投资逻辑

东方电气是全球最大的发电设备制造商，当前处于**"利润率驱动的盈利改善期"**——半年报确立了新的基本面叙事：煤电高毛利交付+费用率下行推动净利高增，但风电深度调整、核电交付后移、订单蓄水池水位回落使收入引擎减弱。

**三大核心驱动力（按2026H1实测重新校准）**：
1. **煤电交付高峰（唯一五星级确定性）**：2026H1煤电收入149.56亿（+15.95%）、毛利率19.88%（+1.49pct）双双兑现；CREA/GEM数据显示全国上半年投产30GW创2016年以来新高，在建204GW锁定2026-2027年交付。华能库布齐31.2亿三大主机大单补充订单储备。
2. **燃机出海第二曲线（全球紧缺持续确认，变现延后）**：GE Vernova Q2燃气backlog 100→116GW（年底指引≥125GW、2031槽位开订）、西门子能源Q3 FY26 GS单季订单€100亿创纪录/backlog 69GW/交期3年+——全球供不应求至2030年后。G50累计运行超1.5万小时、完成第一轮优化设计、核心产能提升项目开工。但国内气电毛利率降至8.55%，加拿大20台高毛利订单（40-50%）2027年才进入确认期——第二曲线是"确定性推迟"而非"确定性消失"。
3. **水电/抽蓄放量+电站服务提质**：H1水电收入+54.16%（扎拉500MW冲击式+抽蓄集中确认）；电站服务收入+18%、毛利率36.16%（小浪底改造创纪录）。"十五五"抽蓄新增投产1亿千瓦目标下景气延续。

**已被证伪/弱化的原逻辑**：
- ❌ 风电量价齐升：H1收入-33.72%、毛利率3.68%、子公司东方风电净亏3.02亿——份额优势未转化为盈利
- ⚠ 核电加速放量：H1仅+2.04%，主设备交付后移至2027-2030（49台核准的长期逻辑不变）
- ⚠ 营收高增长：全年+20.7%假设证伪，下修至+5.6%；合同负债连续两季下降至453亿是最大前瞻警示

**2026年业绩预测**：
- 营收830亿（+5.6%），归母净利51亿（+33.1%），EPS 1.47元（三态45/51/58亿）
- 卖方一致预期47.18亿（14家），本预测高出约8%，分歧收敛

**最大亮点**：利润率改善的广度超预期——综合毛利率16.86%（+0.27pct）、期间费用率降至8.58%（H1实测）、减值收敛至5.48亿（同比-1.18亿）；煤电+电站服务+水电三板块盈利能力全面上行。

**最大隐忧**：①经营现金流恶化（H1 -17.22亿，同比多流出11.66亿）+短期借款骤增至17.18亿，营运资金循环变紧；②合同负债453亿连续两季下降，距450亿警戒线一步之遥；③CREA数据显示2026H1煤电核准仅8.6GW（-63%），2028年后新订单能见度显著恶化。

## 三、研究结论象限图 (Final Evaluation Matrix)

```
        高确定性
            │
    第三象限 │ 第一象限 ← 东方电气（边缘）
   (防御价值) │ (高确信买入)  ★
             │
 低收益 ─────┼───── 高收益
             │
    第四象限 │ 第二象限
    (回避)    │ (投机成长)
             │
        低确定性
```

**定位**：维持**第一象限（高确信买入区）**但移至象限边缘，整体确定性自★★★★☆下调至**★★★☆（3.5/5）**：

- **确定性上调项**：煤电交付（★★★★★，实测兑现）；费用率下行（★★★★☆）；水电抽蓄（★★★★）
- **确定性下调项**：风电盈利修复（★★→证伪）；核电节奏（★★★→交付推迟）；现金流（恶化）；煤电新订单（★★→核准断崖）
- **预期收益空间**：概率加权+45.7%（中性档+53%），仍满足第一象限"高预期收益"标准

**投资建议**：
- **当前位置（25.43元）**：2026E PE 17.3x，PEG 0.52，盈亏比1.96:1——增持区间但不再重仓
- **操作策略（自"金字塔分批建仓"降级）**：
  - 存量持仓：持有，S2（23.3-24.5元）上方不止损
  - 新增仓位等待右侧信号：①25元区域地量企稳阳线；②三季报合同负债≥440亿+单季营收增速回升至+10%
  - 加仓触发：G50海外新大单公告 / 加拿大首批交付确认
- **观望/减仓信号**：连续3日收盘<23.3元 + 三季报合同负债<430亿（双重确认后降至防守仓位）；全年OCF为负（触发二级警报）
- **核心催化剂日历**：哈电正式半年报（8/26）→ 公司半年度业绩说明会（待公告）→ 三季报（10月末）→ G50加拿大首批交付（2026年底）→ 2026年报（2027年3-4月）
