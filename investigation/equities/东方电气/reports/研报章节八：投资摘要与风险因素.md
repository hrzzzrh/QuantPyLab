## 一、投资摘要 (Investment Summary)

### 核心投资逻辑

东方电气是全球最大的发电设备制造商，当前处于**"利润率改善、收入停滞、结构剧烈分化"**的阶段。三季报确立了新的基本面坐标：Q3单季毛利率17.98%、环比+2.29pct、扣非+22.68%、合同负债466.74亿环比+3.03%、经营现金流同比少流出14.25亿——盈利质量与订单蓄水池同步改善；但营收近两季增速降至-2.1%/+1.2%，三个季度整体低位徘徊（+5.6%/-2.1%/+1.2%）（Q3 +1.17%）、风电产量-63.4%、中标份额跌出前五、存货单季+12.70%——收入引擎与风电逻辑同步弱化。**2027E的盈利增长不再依赖"风电修复"，而依赖核电/气电/水电的交付加速与费用率下行。**

**三大核心驱动力（2027E 口径重新校准）**：
1. **核电交付加速（确定性最高）**：公司口径十五期间每年核准8-10台、年新增订单60-80亿、交付峰值2028年前后、年交付4-6套核岛发电机组对应营收约80亿元（中信证券2026.8.26纪要）。2027E核电收入72亿（+20%），向峰值靠拢；2026年7月31日首批8台核准+常态化审批锁定长期能见度。2026H1仅+2.04%的低基数提供加速空间。
2. **燃机出海第二曲线（从示范到批量）**：全球燃机供需缺口延续至2030年后，GE backlog+slot 122GW（年底≥130GW、定价+50%）、西门子排产至2032年；G50累计运行超1.5万小时、2027年底一期产能30台/年。**加拿大客户将采购规模由10台扩至30台（2026.10.26客户侧公告+新华财经双源）**，哈萨克斯坦2台9/30新签——2027E气电收入88亿（+22%），加拿大30台的增量主要在2028-2029年。
3. **水电/抽蓄放量+电站服务提质**：十五五抽蓄新增投产1亿千瓦、2027-2030年集中投产期；国网"十五五"新开工/新投产均超3000万千瓦、2026年投资310亿。1-9月水轮发电机组产量+29.3%已验证；2027E水电收入60亿（+20%）。电站服务H1收入+18%、毛利率36.16%（小浪底改造创纪录）。

**已被证伪/弱化的原逻辑**：
- ❌ **风电份额与盈利修复**：1-9月产量-63.4%、央国企定标份额从1-6月第2（14.76%）跌至1-9月前五之外（<12.19%）、9月陆上不含塔筒均价1,533.18元/kW跌破1,550预警线、大唐10GW框采报价最低。2027E风电收入从165亿下调至145亿、毛利率从5.5%下调至4.0%，**风电不再是增长极，而是拖累项**。
- ❌ **营收高增长**：2026年1-9月营收+1.22%、Q3单季+1.17%，原2026E 830亿下修至805亿、2027E 895亿下修至861亿；"电力装备稳增长方案10%增速"目标连续两年无法兑现。
- ⚠ **合同负债趋势性回落**：Q3环比+3.03%至466.74亿，此前"跌破430亿"的悲观情景未兑现，但1-9月新签增速降至+5.52%（Q3单季+2.17%），"高增长"已切换为"低位企稳"。

**2027年业绩预测（目标年份）**：
- 营收861亿（+7.0%），归母净利51.0亿（+14.6%），EPS 1.47元（三态41.3/51.0/63.4亿，EPS 1.19/1.47/1.83元）
- 卖方一致预期2027E约56亿（查股网口径26-28年45/56/64亿），本预测低约8.9%，分歧来自收入增速（本研报861亿 vs 卖方隐含约900亿）与费用假设

**最大亮点**：Q3单季毛利率17.98%、环比+2.29pct、扣非+22.68%、合同负债环比+3.03%、OCF同比少流出14.25亿——利润率与现金流质量同步改善；加拿大30台协议把G50从"单台示范"推进到"批量可复制"，第二曲线能见度延长至2028-2030年。

**最大隐忧**：①营收三个季度低位徘徊（+5.6%/-2.1%/+1.2%）（Q3 +1.17%），风电产量-63.4%、份额跌出前五，收入端缺少接续引擎；②存货312.61亿单季+12.70%、应收165.66亿较年初+9.03%，营运资金压力未解；③Q4减值传统集中计提（2025Q4单季9.95亿），2026E减值上调至15.5亿，若Q4再提10亿级，全年归母将落至42亿附近。

## 三、研究结论象限图 (Final Evaluation Matrix)

```
         高确定性
             │
     第三象限 │ 第一象限 ← 东方电气
    (防御价值) │ (高确信买入)
              │
  低收益 ─────┼───── 高收益
              │
     第四象限 │ 第二象限
     (回避)    │ (投机成长)
              │
         低确定性
```

**定位**：维持**第一象限（高确信买入区）但下移至象限下沿**，整体确定性由3.5/5下调至**3.2/5**（按F节点归母影响加权：F1毛利率30%×3.5 + F2费用20%×3.0 + F3减值25%×2.8 + F4核气15%×3.8 + F5订单10%×3.2 ≈ 3.24）：

- **支撑项**：煤电交付长尾（★★★★，在建204GW锁定2027）；核电交付加速（★★★★，公司口径年交付4-6套对应72亿）；燃机海外确认（★★★★，加拿大30台协议+哈国2台+全球排产至2032年）；水电抽蓄（★★★★，1-9月水轮产量+29.3%）
- **拖累项**：风电份额与盈利（★★，产量-63.4%、份额跌出前五、价格跌破预警线）；收入增长（Q3 +1.17%、三个季度低位徘徊（+5.6%/-2.1%/+1.2%））；存货/现金流（存货单季+12.70%，OCF仍为负）；煤电新订单（★★，核准断崖）
- **预期收益空间**：概率加权+68.7%（中性档+68.3%），盈亏比4.06:1，仍满足第一象限"高预期收益"标准，但安全垫从"极厚"回归"正常偏厚"

**评级调整的非对称条件**：
- **上调至买入（需同时满足）**：①2026Q4合同负债≥470亿；②2027Q1营收增速≥+8%；③加拿大30台协议获公司公告并明确交付时间表。
- **下调至持有（任一满足）**：①2026Q4合同负债<450亿；②2026全年减值>18亿；③风电份额继续跌出前五且东方风电全年亏损>6亿；④连续3日收盘<20.25元且无基本面改善。
- **当前状态**：三条上调条件均未满足（Q4数据未出、加拿大协议未公告），四条下调条件中"风电份额跌出前五"已触发但尚未伴随亏损扩大，故维持增持而非下调。

**投资建议**：
- **当前位置（21.56元）**：2027E PE 14.7x，PE TTM 15.85x，盈亏比4.06:1——增持区间，股价已进入S2（20-22元）核心支撑区
- **操作策略**：
  - 存量：持有，20.25元S2上方不止损
  - 新增等待右侧：①20.2-21.4元缩量止跌+放量阳线收复22.25元；②2026Q4合同负债≥460亿+2027Q1营收增速回升至+5%
  - 加仓触发：加拿大30台协议获公司公告确认/G50海外新大单/加拿大首批交付
- **观望/减仓**：连续3日<20.25元 + 2026Q4合同负债<450亿→防守仓位；全年OCF为负触发二级警报；风电份额继续跌出前五且亏损扩大→下调评级
- **核心催化剂日历**：2026-11-05三季度业绩说明会→2027年3-4月年报（Q4减值、合同负债、存货去化）→加拿大30台协议公司公告与首批交付（2027年）
