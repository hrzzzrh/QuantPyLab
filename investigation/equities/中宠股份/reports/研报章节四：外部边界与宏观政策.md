# 研报章节四：外部边界与宏观政策

**研究日期：2026年08月28日**

---

## 一、宏观环境变量

### 1.1 汇率损益：双刃剑效应（2026-08-28重估·已兑现为报表冲击）

中宠股份境外收入占比65.18%（2026H1，65%+），结算币种以美元为主。2025年至2026年5月，人民币对美元维持在7.2-7.35的贬值区间，对境外收入产生正面贡献。但**2026年5月以来，人民币对美元出现一轮显著升值并维持高位**：从5月的约7.25快速升值至7月17日的6.7934、**8月28日的6.7811（较前日上调29基点，累计升值约6.4%）**，创2023年2月以来最强水平并于8月下旬维持6.78-6.79高位震荡（8月25日6.7852/26日6.7829/27日6.7840/28日6.7811）。

**2026H1已兑现的冲击（报表验证）**：
- 财务费用0.32亿（+1,235.56%），其中**汇兑损失0.27亿（2025H1为收益0.09亿，剪刀差0.36亿）**，直接吞噬H1归母净利约28.4%（0.36/1.27）；
- 境外毛利率19.37%（-8.58ppt，同比27.95%→19.37%），境外毛利额4.14亿（-5.9%）在收入+35.78%下不增反降，显示汇率对"收入折算+成本结算"的双重挤压；
- 其他综合收益中"外币财务报表折算差额" -7,367万、"权益法下可转损益的其他综合收益" -627万，合计-7,994万计入综合收益，资产负债表已显性化；
- 远期合约公允价值波动-43.15万（7,447万初始投资，期末-43.15万），套保对冲效果有限（仅覆盖2%净资产）。

**对冲手段与有效性评估**：
- 自然对冲：美国（American Jerky H1收入5.1亿/净利2,169万，净利率4.3%下滑）、加拿大、墨西哥工厂的本土收入形成部分对冲，但H1境外毛利率坍塌显示对冲不完全；
- 金融对冲：2026年5月15日年度股东会已批准5,000万美元套保额度，2026H1实际开展7,447.35万远期合约，产生实际损益-45.04万，套保规模与汇兑损失（0.27亿）相比覆盖率约58%，但公允价值波动-43万显示对冲成本与基差风险仍存。

**综合评估（2026-08-28重估）**：人民币升值已从7月19日评估时"最显著的宏观负面变量（预期）"升级为"**已兑现的报表冲击（实损）**"，且8月维持6.78高位震荡显示压力未缓解。若人民币进一步升值至6.60，汇兑损失将再增0.15-0.20亿，全年财务费用可能突破0.70亿；若贬值至6.90-7.00，则有0.20-0.30亿回冲空间。该变量已在盈利预测（财务费用0.65亿）与估值审计（-10%折价，Σ-8%时-8%）中足额体现。

### 1.2 利率与折现率（2026H1更新）

当前中国处于降息周期（1年期LPR 3.10%，5年期LPR 3.60%，2026年5月），低利率环境理论上有利于降低有息负债成本与提升DCF折现值。但**2026H1有息负债结构已显著恶化**：短期借款15.84亿（占总资产24.67%，+6.69ppt vs 年初）+长期借款1.21亿+租赁负债1.29亿，合计有息负债约18.34亿，较2025Q1的14.82亿+1.12亿（合计15.94亿）进一步扩张2.4亿。即便LPR维持低位，**利息费用0.17亿（H1，+3.5%同比）已显性化，年化利息约0.35亿将吞噬全年中性净利（3.26亿）的约10.7%**，财务杠杆的"低利率红利"被"高负债规模"完全对冲。

公司2022年发行的7.69亿可转债（票面0.3-2.0%，余额约4.55亿，对应长期债券4.55亿）仍属优质低息负债，但2026H1资本公积+4.37亿显示部分转股已发生，若股价维持28-30元，转股稀释与利息节省的权衡需动态评估。

### 1.3 通胀传导（2026-08-28·成本已兑现）

公司核心原材料鸡肉价格受白羽鸡养殖周期与中美关税影响较大。2026年H1白羽鸡价格呈**窄幅震荡、稳中伴小幅下跌**：8月26日Mysteel数据显示，山东滨州社会棚前收购价3.20元/斤（-0.02）、全国主产区3.20-3.55元/斤，年内价格同比约+3.4%（窄幅上行），但**显著低于40%的市场传闻**，且8月下旬呈现"稳中伴跌"（0.01-0.05元/斤跌幅）。2026年上半年白羽鸡产业链整体稳中向好：种蛋+18.35%/鸡苗+12.50%/肉鸡+3.42%/分割品+4.52%，但屠宰端二季度已进入亏损，显示供给宽松压力仍存。公司公告亦明确"鸡肉采购价格整体上扬，环比先涨后降"，但全年若维持3.20-3.35元/斤区间，成本底部有托底但上行空间有限。豆粕（饲料主要原料）受进口大豆关税影响存在涨价压力，但2026H1豆粕基差稳定，未现大幅上行。

**传导效率分析（2026H1实测）**：
- 公司毛利率由29.54%（2025）→25.88%（2026H1，-5.5ppt），其中宠物食品及用品毛利率27.11%（-5.38ppt）、宠物零食23.64%（-6.99ppt）、主粮34.68%（-1.95ppt）全线下滑，**远超1-3ppt的预判**，显示成本传导的滞后（1-2季度）已集中兑现，营业成本+45.69%跑赢营收+34.88%（+10.8ppt）；
- 战略储备制度（提前囤货）在H1未能平滑波动，反因"高库存+成本上行"导致存货8.20亿（+18.4%）与成本同步抬升，若H2鸡价回落至3.10-3.20元/斤，存货跌价风险将显现；
- 若H2鸡价维持3.20-3.35元/斤窄幅震荡，全年毛利率27.0%（预测）的修复需依赖产品结构（境内38.06%高毛利占比提升）与提价传导，单纯成本回落难以独立驱动毛利率修复。

## 二、地缘政治风险：产业链重构与关税冲击

### 2.1 中美贸易摩擦：核心外部变量

2025-2026年中美关税战升级至历史最高水平：
- 美国对华加征关税叠加至**145%**
- 中国对美反制关税叠加至**125%**

这对宠物食品行业的影响是**结构性的而非周期性的**：

**（1）出口端影响：出口美国通道基本关闭（对无海外产能的企业）**

中国产宠物食品经由海运出口至美国，若叠加145%关税，终端价格将翻倍以上，完全丧失竞争力。这对纯国内产能的出口企业（如部分中小代工厂）是毁灭性打击。

**但中宠股份受到的实际冲击有限**，原因在于：
- 美国工厂（2015年投产，最大宠物零食工厂之一）：销往美国市场的产品可**直接从美国工厂出货**
- 加拿大工厂（2018年投产）：产品通过USMCA（美墨加协定）进入美国市场享受优惠关税
- 墨西哥工厂（2025年建成）：同样可通过USMCA对美出口
- 柬埔寨工厂：东南亚出口不受中美关税影响

**关税战对中宠的主要影响路径不再是"出口受阻"，而是"全球订单重新分配"**——美国客户将更多订单转向中宠的北美工厂，这实际上可能**增强中宠在北美市场的竞争地位**（因为竞争对手的中国产能被关税排除在外）。

**（2）进口端影响：原材料国产替代加速**

中国对美国鸡肉粉（宠物食品核心原料）进口依赖度极高——年消耗60-65万吨鸡肉粉中，进口超20万吨，其中98%来自美国。125%的对美关税将迫使行业加速寻找国内替代或转向新西兰等替代来源。

中宠股份的应对优势：
- 全球采购体系：美国工厂可就地采购美国产鸡肉粉（不受中国关税影响）
- 中国工厂：与国内白羽鸡屠宰企业建立长期供应关系，逐步替代进口鸡肉粉
- 短期阵痛：国产鸡肉粉在蛋白质含量和品质上可能不及美国产品，可能影响部分高端产品品质

**（3）行业格局重塑：中宠的"关税免疫"优势**

当前中美关税战的极端环境，实质上加速了宠物食品行业的**产能替代**进程：
- 无海外产能的企业 → 丢失美国市场份额 → 被迫降价在国内/东南亚/欧洲市场抢单 → 行业价格战加剧
- 有海外产能的企业（中宠、部分乖宝泰国厂、佩蒂越柬厂）→ 受益于竞争减少 → 获得更多美国订单

中宠股份凭借6国23工厂的全球网络，是中国宠物食品行业中**最具备"关税免疫"能力的企业**。这一优势在当前环境下具有极高的战略价值，且竞争对手在3-5年内难以复制。

**（4）关税环境最新动态（2026年7月更新）**

2026年2月24日起实施的Section 122全球10%附加税将于**2026年7月24日到期**。该关税已被美国联邦法院裁定不合法（5月7日），但上诉法院暂缓裁决。替代方案为USTR针对60个国家的"强迫劳动"301调查提案：拟对54个国家加征12.5%关税，6个国家加征10%关税，中国（含香港）被列入12.5%税率档。

对中宠股份的实际影响分析：
- **宠物食品（HS 230910）**：WTO最惠国基础税率为0%，中国仅占美国宠粮进口约5%（泰国42%、加拿大17%），中国产宠粮并非美国关税打击重点
- **宠物用品（HS 4201）**：基础税率约2.4-11%，叠加Section 301后中国商品税率可达17.5-52.6%，但中宠北美工厂可规避此风险
- **核心判断不变**：中宠的全球产能布局（美/加/墨/柬工厂）使其在关税博弈中保持"关税免疫"优势，新301关税反而可能增强其相对竞争力（因竞争对手的中国产能面临更高关税）
- **中长期利好**：中美7月初已互相下调约300亿美元商品的关税，表明贸易关系边际改善的窗口正在打开，但宠物食品暂未明确被列入降税清单

### 2.2 供应链重构（China+1）

全球宠物食品采购正在经历"China+1"转移：
- 国际品牌商（如玛氏、雀巢）要求供应商在东南亚/美洲建立备份产能
- 泰国、越南、柬埔寨成为主要的产能转移承接地

中宠的柬埔寨工厂（2019年投产，东南亚最大宠物零食工厂之一）和第二工厂（在建）恰好处于这一转移趋势的中心。公司在东南亚的布局时机具有显著先发优势。

### 2.3 欧盟准入：潜在的增量空间

中国宠物食品进入欧盟市场需要企业通过海关推荐并获得欧盟官方注册。2025年，仅4家山东宠物食品企业申请欧盟准入，其中3家获批。虽然中宠股份尚未在公开信息中确认其欧盟准入状态，但山东作为中国宠粮出口第一大省（占全国45%+），中宠作为行业龙头企业，获得欧盟准入的可能性较高。一旦打开欧盟市场，将为公司海外业务贡献可观的增量。

## 三、监管与产业政策

### 3.1 行业规范化：利好头部，加速出清

2025-2026年，宠物食品行业迎来密集的政策规范：
- 2025年农业农村部公告第20号：一次性发布多项宠物饲料专项规范，**监管进入系统化阶段**
- 2026年5月1日起：实施《全价宠物食品处方粮通用要求》（NY/T4838）和《冻干宠物食品通用要求》（NY/T4839）
- 《宠物饲料标签规定》：2020年3月1日起执行，标签合规要求趋严

**政策影响分析**：
- 合规成本上升 → 中小品牌加速退出 → 行业集中度提升 → **利好头部企业**
- 中宠股份作为全国饲料工业标准化技术委员会宠物饲料分技术委员会副主任委员单位，**直接参与标准制定**，享有规则制定的话语权
- 公司已通过20项全球权威认证（ISO、BRCGS、HACCP、SMETA、BSCI等），政策趋严几乎不产生新增合规成本

### 3.2 产业政策契合度

宠物食品行业与国家战略方向高度契合：
- **内需消费**：宠物消费是内需消费的重要组成部分，符合"扩大内需"战略
- **乡村振兴**：宠物食品产业可带动禽类养殖、农产品深加工等上游农业价值链
- **品牌出海**："中国质造"宠物食品走向全球，符合"一带一路"和"双循环"战略

不存在显著的产业政策压制风险。

### 3.3 环保与动物福利

- 公司已通过ISO14001环境管理体系认证
- 宠物营养与健康研究院拥有300余只犬猫的实验基地，符合动物福利标准
- 暂无重大环保处罚或负面记录

## 四、核心结论

中宠股份面临的外部宏观环境呈现**"利空出尽、利好上行"**的结构：

**利空因素（已在价格中部分定价）**：
- 中美关税战已升级至极端水平（145%/125%），进一步恶化的空间有限
- 原材料价格周期性波动是行业常态，2026年的涨价压力可控
- 汇率的双向波动可通过全球产能自然对冲

**利好因素（市场可能低估）**：
- 关税战下的"产能替代"效应：中宠的北美工厂将从竞争对手手中抢得更多订单
- 监管趋严加速行业出清：中小品牌退出释放的市场份额将被头部企业瓜分
- 欧盟市场准入：一旦获批，将打开新的增长空间

**最大的外部风险（需持续监控）**：
- 关税战如何"结束"：若中美突然达成协议、关税大幅下调，中宠的"关税免疫"溢价将消失，但从竞争角度看这不改变公司的长期优势
- 全球供应链突发中断（如新的出口管制或制裁）
