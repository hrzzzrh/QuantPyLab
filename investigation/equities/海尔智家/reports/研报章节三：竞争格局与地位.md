## 二、核心竞争对手分析

### 2.1 美的集团（全球最强对手）

| 指标 | 美的集团 | 海尔智家 | 差距 |
| :--- | :---: | :---: | :--- |
| 2025营收 | 4,585亿（+12.1%） | 3,023亿（+5.7%） | 美的1.52x |
| 2025归母净利 | 439.5亿（+14.0%） | 195.5亿（+4.4%） | 美的2.25x |
| 净利率 | 9.8% | 6.7% | -3.1pct |
| ROE（加权） | 19.7% | 16.98% | -2.7pct |
| 合同负债 | 469.9亿 | 85.4亿（2025末）/52.1亿（2026Q1） | 5.5x/9x |
| 海外收入占比 | 42.9% | 51.5% | 海尔更高 |
| 研发投入 | 177.9亿 | 107.2亿 | 美的1.66x |

**竞争态势**：美的在规模、盈利、渠道话语权全面领先，且2026Q1空调内销出货+18.18%逆势扩张。但两者差异化定位：**美的=效率型全品类+ToB转型（楼宇/机器人/工业技术），海尔=品牌价值型全球化+智慧家庭场景**。海尔的核心竞争位势在冰箱/洗衣机/高端（卡萨帝）与全球化深度（海外占比更高、本土化制造超60家工厂），这些领域美的尚难撼动；而空调、小家电、ToB领域海尔落后。**判定：两者是"双龙头错位竞争"而非正面绞杀，海尔在自身强势品类的份额地位稳固。**

### 2.2 格力电器（空调单一品类陷阱）

- 2025年营收1,704亿（-9.9%）、归母净利290亿（-9.9%），三巨头中唯一下滑者；
- 空调占收入约78%，2026Q1空调零售-13%背景下承压最大；线上空调份额已被小米超越（部分月份）、线下仍第二（30.21%）；
- 海外收入占比<20%，缺乏全球对冲；多元化（光伏、钛新能源）未见效；
- **对海尔威胁最小**：格力在冰箱/洗衣机/海外均不构成实质竞争，且行业下行期份额被蚕食。

### 2.3 惠而浦（北美正面战场，正在败退）

| 指标 | 惠而浦2026年表现 |
| :--- | :--- |
| 2026Q1 | EPS -0.56美元（预期+0.62），北美大家电EBIT从1.49亿→600万美元（-96%） |
| 2026Q2 | 营收35.2亿美元（-6.6%），由盈转亏（EPS -0.21） |
| 全年指引 | EPS从7美元下调至2.5-3美元；暂停七十年来首次股息派发 |
| 美国份额 | 六大核心品类份额从第一跌至第四（观察家网/2026.07） |
| 经营动态 | 阿马纳冰箱厂裁员过半（3,000→<1,000人）、产线南迁墨西哥、7月提价4% |

**对海尔的含义**：惠而浦的困境（本土化成本高+渠道库存高+定价混乱）正是GEA份额与利润修复的对手盘。GEA凭借本地制造（80%本土供应）+墨西哥基地（USMCA零关税）+高端品牌（Café/Monogram）在美国市场处于"此消彼长"的有利位置。**惠而浦的败退是海尔北美中长期份额提升的核心外部动能。**

### 2.4 三星/LG（日韩双雄，高端与智能化强敌）

- **三星**：2026Q2家电（VD/DA）营业亏损100亿韩元，家电业务持续失血，战略重心转向半导体；但其高端AI家电与嵌入式产品仍在北美/欧洲高端市场占据优势；
- **LG**：2026Q2家电业务经营利润翻倍至1.14万亿韩元（HS分部利润率6.6%→9.7%），通过成本削减+新兴市场扩张（印度/拉美/中东）+高端嵌入式产品线逆转；LG以JDM方式与中企合作推出500美元级产品下沉欧洲；
- **竞争启示**：LG的盈利改善证明"全球家电在下行期仍有利润修复空间"，而三星收缩家电战线减轻了高端价格压力。海尔与三星/LG的竞争集中在高端嵌入式厨电、智能家电与新兴市场，属于"共谋高端+争夺新兴"的长期消耗战。

### 2.5 小米（侧翼威胁，短期难撼格局）

| 维度 | 小米家电2025-2026表现 | 对海尔的影响评估 |
| :--- | :--- | :--- |
| 空调 | 2025年出货850万台（+24%），线上份额13.5%第三，均价2,452元 | **冲击格力/美的平价段**，海尔空调份额本身较小，直接威胁有限 |
| 冰箱 | 2025年出货280万台（+4%），线上份额6.94%（-3.18pct） | 冲击有限——海尔+统帅线上合计34.19%，均价带远高于小米（海尔系覆盖1,500-19,000元全价位） |
| 洗衣机 | 2025年出货230万台（+18%） | 海尔32-33%份额稳固，小米主要冲击二三线品牌 |
| 自产 | 武汉工厂2025年11月投产、2026年大规模量产（700万套/年） | 中期产能瓶颈解除，但高端化与售后（投诉量为三巨头之和两倍）仍是短板 |

**小米威胁判断**：小米的进攻集中在2000-2500元平价空调市场与线上渠道，对美的（华凌防御）、格力冲击最大；对海尔冰箱/洗衣机/高端基本盘威胁有限（海尔通过Leader品牌+统帅子品牌已形成下沉防御阵型）。但**小米的"生态+性价比"模式在中低端市场持续吞噬增量，是行业价格中枢下移的推手之一，对海尔国内毛利率构成间接压力**（2025年海尔国内毛利率-1.03pct部分源于此）。

## 三、护城河识别

### 3.1 品牌矩阵护城河（★★★★★，海尔最强壁垒）

| 品牌 | 定位 | 2025年进展 |
| :--- | :--- | :--- |
| 卡萨帝 | 超高端（1万元以上） | 收入双位数增长；冰箱1万+份额43-44%、洗衣机1万+份额75-76%、空调1.5万+份额53-60.8%；品牌价值928亿连续5年高端第一 |
| 海尔 | 大众主力 | 2025年零售额+8%；智家APP月活1,100万（+35%） |
| Leader | 年轻化 | 收入首破百亿（+30%）；懒人三筒洗衣机销量超30万台 |
| GE Appliances | 北美龙头 | 高端品牌收入+7%；洗碗机份额26.8%、烤箱41.6%、洗衣机26.7%（AHAM） |
| Candy | 欧洲大众 | 2025年扭亏为盈；欧洲整体份额12.5% TOP2 |
| Fisher & Paykel | 澳新高端 | 11系超高端热泵新品 |
| AQUA | 日本 | 双品牌份额17.7% TOP2 |

**护城河本质**：海尔是全球家电业罕见的"七个全球性品牌矩阵"，实现从1万元以下到10万元+的价位全覆盖与跨国文化适配。卡萨帝在高端市场（1万元以上冰箱43%、洗衣机76%）建立的价格带壁垒，短期无任何竞品能复制（COLMO聚焦1-3万元、美诺聚焦超高端，中间地带卡萨帝独占）。

### 3.2 全球本土化护城河（★★★★☆）

- 海外超60家工厂、163个制造中心、126个营销中心、近23万个销售网点（全球10+N创新生态）；
- 本土化"研发-制造-营销"三位一体：GEA（美国本土制造80%）、Candy（欧洲研产销一体）、FPA（澳新/新西兰）、AQUA（日本）；
- 供应链重构能力：泰国春武里空调厂（600万台/年）投产、泰国冰箱厂100%承接对美出口、墨西哥基地USMCA零关税、欧洲产能转移土耳其/东南亚；
- **关税免疫结构**：相比纯出口企业（美的/格力部分品类），海尔海外收入51.5%中大部分由海外本地化主体产生，关税冲击显著小于同行（2026Q1海尔海外收入-3.2%，惠而浦北美-9.6%、美的出口同样承压）。

### 3.3 高端技术护城河（★★★★☆）

- 研发投入107.2亿、研发人员25,913人（行业最多）；累计专利11.2万项（发明7.3万）；
- 全球智慧家庭发明专利连续14次第一；主导国际标准110+项；
- 技术标签：AI之眼2.0（视觉认知）、Uhome大模型、静压气悬浮离心机组（750RT全球单机最大）、可变分流空调技术、全球最节能X11洗衣机（单型号销量80万台）；
- 具身智能先发：2026年3月发布海娃家务/清洁/陪伴三类家庭机器人（全自研）+UHomeOS操作系统。

### 3.4 渠道护城河（★★★★☆，国内）

- 国内专卖店体系+TC统仓模式（2026Q1全域TC订单占比65%，+8pct）：物流降本3.4亿/年、24小时配送覆盖1,944个区县、送装一体率97%；
- 2026年计划新建3,000家县区专卖店、升级6,000家门店、新增1,000家厨房体验店；
- 下沉市场深度（镇级门店覆盖）是小米/纯线上品牌无法短期复制的基础设施。

**审计结论**：
1. **对上游**：应付账款783亿+应付票据构成强大的无息运营杠杆（应付周转天数130.5天），压款能力处于家电一流水平；

3. **对终端**：2026年提价验证——空调等行业性提价3%-10%（美的率先+6%），海尔跟随提价且618仍实现冰箱/洗衣机/热水器/冷柜四品类份额第一，说明**海尔在高份额品类具备需求刚性支撑的转价能力**。

## 【外部数据交叉验证】

1. **份额交叉验证**：海尔中国冰箱47.7%线下份额（公司年报）vs 奥维线上26.28%（1-4月）——口径不同（线下/线上），但均为行业第一，方向一致；洗衣机海尔系32-33%（奥维2026H1）与公司口径一致；GEA北美16-18%（Sourceready）与公司"美国第一"表述存在口径差（公司按品牌零售额、第三方按出货量），保守标注为"北美第一梯队、四强中份额唯一逆势提升"。
2. **供应链生态穿透**：惠而浦（北美最大对手）2026年由盈转亏、份额跌至第四、暂停派息——侧面验证GEA在美国的竞争地位与份额动能。
3. **技术代差实证**：LG 2026Q2家电利润翻倍（HS分部9.7%）证明下行期家电盈利可修复；三星家电亏损说明高端价格带竞争烈度有限。
4. **实物产能校验**：小米武汉工厂2025年11月投产（700万套/年）——平价空调供给冲击将持续，但海尔高端/冰洗基本盘无直接冲击；海尔泰国春武里工厂投产（600万台/年）+美国洗衣机/热水器基地在建——北美关税对冲的物理进度明确。

## 五、模块三核心结论

1. **海尔是全球白电双龙头之一**（欧睿零售量第一；全球大家电份额10-11%第一档），在中国冰箱（47.7%）、洗衣机（47.4%）、热水器（32.5%）具备绝对统治力，在北美（GEA第一梯队）、欧洲（前三）、日本（TOP2）、巴基斯坦（第一）建立全球第一梯队地位。
2. **最强护城河=品牌矩阵+全球本土化**：卡萨帝高端价格带（1万+冰箱43%、洗衣机76%）与七大品牌矩阵无可复制；60+海外工厂+墨西哥/泰国基地构成关税免疫结构，是"全球化白电"中最深的壁垒。
3. **最大短板=渠道话语权（合同负债85亿 vs 美的470亿）与空调弱势品类**：对下游预收款能力不足、空调国内第三，这两点决定了海尔在国内"提价弹性"与"渠道资金池"弱于美的。
4. **竞对格局净判断**：惠而浦败退（北美对手盘）、格力单品类承压、三星收缩家电、小米聚焦平价空调——海尔所在的高端+全球化+冰洗核心赛道，竞争烈度相对可控；美的与LG是仅有的两个"强而不亡"的长期对手，但分别处于错位赛道与不同区域。
