## 一、产业生命周期与库存节奏（三季报校准）

### 1.1 周期定位：国内存量博弈进入"补贴退出后的第二次探底"

**中国市场（2026E约占营收45.7%）——成熟期后半段，Q3二次探底：**

- 空调城市百户拥有量161.8台、冰箱106.6台、洗衣机100.3台（国家统计局2025年），渗透率饱和；增长动力已完全切换为更新换代（8-12年周期）；
- 2026Q3全品类零售额1,791亿元（-10%，奥维云网AVC），Q1 -6.2%／Q2 -12.4%／Q3 -10%，连续三季双位数附近下滑；
- 家用空调：前三季度行业总销量1.5亿台（-8.4%），Q1 -2.8%／Q2 -9.3%／**Q3 -15.1%**，9月内销-23.7%、出口+7.96%；
- 冰箱：9月产量+8.0%、销量+9.7%，内销-3.59%、出口+21.17%（出口独撑）；
- 洗衣机：9月产量-1.6%、销量-0.3%，内销-11.82%、出口+9.53%；
- 白电三强（美的/海尔/格力）集中度维持约74%，中小品牌出清，存量博弈加剧。

**海外市场（2026E约占营收54.3%）——分化收敛为"普遍弱、新兴强"：**

- 北美：Q3行业出货量-4%（AHAM；惠而浦口径-3.3%），全年行业指引约-5%；利率高企+地产低迷，空调库存偏高（CLSA）；
- 欧洲：前三季度冰洗零售额基本持平、销量低个位数增长（GfK，意西英法），消费者偏好高性价比、高能效与ESG；
- 新兴：南亚、东南亚、拉美受益城镇化与人口红利保持较快增长（印度行业3倍、越南份额第一）；
- 全球家电已从"中国单边下滑、海外对冲"转为"中国与北美同步弱、只有新兴市场增长"。

### 1.2 库存动力学：渠道去库延续至Q4，厂商排产分化

| 信号 | 最新验证 | 解读 |
| :--- | :--- | :--- |
| 2026年9月空调内销出货 | -23.7%（降幅较8月扩大） | 厂商主动大幅降出货，去渠道库存 |
| 2026年11月空冰洗排产 | 合计2,850万台（+3.9%）；空调1,223万台（+15.6%，内销476万/+17.5%、出口747万/+16.0%）；冰箱815万（-1.3%）；洗衣机812万（-5.6%） | 空调高增源于2025年11月近十年低基数，**非需求回暖** |
| 2026年12月／2027年1月空调排产 | +2.1%／-2.5% | 排产由强转弱，工厂对国内备货保守 |
| 海尔存货 | 460.77亿（较年末-1.6%），周转天数79.7天（+5.6天） | 备货大宗涨价与大促，去化慢于收入 |
| 海尔合同负债 | 76.33亿（环比+14.8%，连续两季回升） | 渠道打款意愿修复，与Q4国内转正指引一致 |
| 行业出口 | 空调9月出口+7.96%、冰箱+21.17%、洗衣机+9.53% | 出口是唯一亮点，但价格竞争激烈、毛利率承压 |

**核心辨析——牛鞭效应已转为"反向牛鞭"**：2025年国补期间渠道超额备货，2026年进入去库存，终端零售降幅（-10%）小于厂商出货降幅（空调内销Q3 -15.1%），说明渠道在主动压缩库存，**厂商报表收入降幅被放大**。海尔Q3收入-10.13%、应收+20.1%、合同负债回升，三者组合指向"公司主动降出货保渠道健康"，而非单纯需求流失。**判断：渠道库存去化已进入后半程，Q4低基数下收入有望转正，但2027年国补到期后仍有一次需求断层。**

### 2.2 终端景气度审计——2026-2028年趋势

#### 2.2.1 中国终端：Q3 -10%，2027年面临"补贴真空"

| 来源 | 品类 | 2026Q3／9M实际 |
| :--- | :--- | :--- |
| 奥维云网AVC | 全品类零售额 | Q3 1,791亿（-10%）；9M约6,041亿（-9.9%） |
| 产业在线 | 家用空调总销量 | 9M 1.5亿台（-8.4%），Q3 -15.1% |
| 产业在线 | 9月空调内销/出口 | -23.7%／+7.96% |
| 海尔 | 1-9月零售额份额 | 线上20.6%（+2.9pct）／线下25.0%（+1.7pct） |
| 商务部 | 家电以旧换新 | 2026年以来超10,099万台；全年2,500亿资金已全部下达 |

**国内核心判断**：
1. **2026全年行业零售额约-9%~-10%**（H1 -9.9%、Q3 -10%），此前"全年-8%~-10%"判断兑现；
2. **Q4是低基数窗口**：2025Q4行业已因国补退坡下滑，2026Q4在双十一+第四批625亿资金支撑下有望同比转正，管理层指引国内收入Q4恢复增长；
3. **2027年是真正的风险点**：国补按惯例2026-12-31到期，2027年尚无接续政策文件，政策表述转向"常态化、精准化"。若2027年无新补贴，2026Q4-2027Q1存在"抢补贴透支→需求断层"的跨期移位，行业可能再下一个台阶；
4. **海尔份额韧性仍在**：行业-10%背景下线上/线下份额+2.9/+1.7pct，冰箱+4.2/+2.4pct，说明集中度提升逻辑未破。

#### 2.2.2 北美终端（二次探底，恢复推迟至2028）

- Q3行业出货量-4%（AHAM），惠而浦口径-3.3%、全年指引-5%；
- 美联储9月加息25bp至3.75%-4.00%，10-28按兵不动但2票主张再加息，市场预期仍有一次以上加息；30年按揭维持高位，地产"锁定效应"未解；
- 惠而浦Q3北美MDA收入-8.3%、EBIT margin 3.0%（-1.9pct），并宣布Q4再提价7%（12月3日美国生效），说明行业靠提价而非销量；
- **判断**：2026年北美行业-5%，2027年0~-2%，地产后周期修复推迟至2028年；此前"2027年+3%"的假设证伪。

#### 2.2.3 欧洲终端（量平价平，F-gas窗口是2027年唯一确定性增量）

- 前三季度冰洗零售额基本持平、销量低个位数增长（GfK）；海尔核心市场本币中高单位数增长，制冷/洗涤份额+0.9/+0.4pct，暖通收入双位数；
- **2027-01-01欧盟F-gas修订生效**：≤50kW单体机、≤12kW分体机新投放须GWP<150，R32（GWP 675）被排除，R290成为主流选项；德国2028年起BEG补贴仅限天然工质热泵；
- **判断**：欧洲2027年+7%（本币），增量主要来自R290空调/热泵替换与商用暖通，而非总量扩张。

#### 2.2.4 新兴市场（唯一高增引擎）

- 印度：收入增速达行业3倍，洗涤推出印度首款彩屏滚筒F9、12万卢比以上价位段份额第一；
- 巴基斯坦：冰洗空份额第一，太阳能空调销量翻番；
- 东南亚：越南洗衣机年累份额第一、IRIS系列占高端1/4；泰国/马来/印尼/菲律宾制冷份额提升；
- 中东非：Q3单季美元口径稳健增长；
- **判断**：2027年新兴市场+11%，是海尔收入端唯一确定性增长源，但体量仅占营收约14%，不足以扭转全局。

### 2.3 动能溯源与透支审计

| 驱动因素 | 类别 | 最新验证 | 对海尔影响 |
| :--- | :--- | :--- | :--- |
| 以旧换新国补（2024-2026） | 外生-政策 | 2026年2,500亿全部下达、10,099万台；2026-12-31到期，2027无接续文件 | 2026Q4托底、2027H1透支风险 |
| 全球高温/气候 | 外生-自然 | 欧洲夏季高温脉冲，但Q3冰洗零售额仍持平 | 脉冲有限 |
| 新兴城镇化 | 内生-结构 | 印度3倍行业、越南第一 | 核心增长引擎（+11%） |
| 美国地产后周期 | 外生-宏观 | 美联储加息、行业-4%、恢复推迟至2028 | 2027年不贡献增长 |

**【强制审计：跨期需求移位】**
- 2025年国补1.29亿台透支→2026年行业-10%，已完成一次透支兑现；
- **2026Q4第四批625亿+双十一，可能形成第二次"抢补贴"脉冲，把2027Q1需求前移**；这是2027年收入预测的最大下行风险，已计入保守情景（国内-1%）；
- 海尔份额+2-3pct可部分对冲总量下滑，但无法逆转行业β。

## 三、供需边际与压力传导（三季报校准）

### 3.1 供需平衡审计

| 维度 | 2025 | 2026Q3 | 趋势 |
| :--- | :--- | :--- | :--- |
| 中国终端需求 | 国补刺激超常增长 | 零售额-10%，空调内销出货-15.1% | ↓二次探底 |
| 渠道库存 | 高位积累 | 去化后半程（合同负债回升、厂商降出货） | ↓→企稳 |
| 厂商排产 | 高排产 | 11月空调+15.6%（低基数）、12月+2.1%、2027年1月-2.5% | ↑后回落 |
| 出口需求 | 温和增长 | 空调+7.96%、冰箱+21.17%、洗衣机+9.53% | ↑但价格竞争 |
| 原材料（铜） | 7-9万/吨 | LME 14,154（9-10曾14,875历史新高）、沪铜10.9-11.1万 | ↑↑↑历史极值 |
| 行业集中度 | CR3约70% | 约74%，海尔份额+1.7~2.9pct | ↑ |

**供需格局判断**：国内从"阶段性过剩"进入"去库存后半程"，但2027年国补到期可能带来新一轮需求下台阶；成本端铜价未见回落（UBS预测2027年15,500美元/吨），行业进入"需求弱+成本高"的双杀阶段。唯一缓冲是集中度提升与出口，但出口价格竞争激烈，毛利率难以提升。

### 3.2 压力传导特征分析

**传导路径一：国补退坡→终端-10%→渠道去库存→厂商出货-15%→价格内卷**
- 时滞1-2季度，Q3验证：行业零售-10%、空调内销出货-15.1%，海尔收入-10.13%；
- 海尔缓冲：份额提升（线上+2.9pct）、统仓ToC上线率85%（缩短链路、降低渠道库存）、合同负债回升。

**传导路径二：铜价+36%→成本↑→提价3-10%→需求抑制**
- 铜占空调成本20%-25%，铜价+35%理论压降毛利率4-5pct；格力Q3毛利率-5.62pct验证；
- 海尔Q3毛利率-0.81pct，靠海外退税（一次性14.93亿）+高端结构+套保对冲；**剔除退税后约24.9%（-3pct），与行业成本压力一致**；
- 传导时滞约1季度，2027年若铜维持15,000以上，毛利率难以回到27%。

**传导路径三：美联储加息→北美地产弱→GEA收入持平→海外从"增长引擎"变"持平项"**
- Q3北美行业-4%，GEA跑赢但收入仅持平；232改为整件计征，墨西哥/东南亚转口失效，GEA本土80%产能的相对优势被削弱；
- 2027年海外增速由+6%下修至+4%，北美由+3%下修至+1%。

**波动放大效应评估**：三重压力（国内-10%、北美-4%、铜历史高位）下，海尔Q3收入-10.13%、扣非-32.17%（成本+非经常性基数）。**分区域看**：公司未披露Q3分地区收入，按2025年国内/海外约48.5/51.5的结构与"国内双位数下滑、海外本币基本持平"的管理层表述推算，国内人民币口径约-15%~-19%、海外人民币口径约-3%~-5%（本币持平，人民币升值折算约-5%），两者加权后约-10.1%，与报表一致。**因此，"与行业同步"是区域组合的结果：国内降幅大于行业零售额（-10%），系主动降出货去库存；海外本币仍跑赢行业，但被汇率折算抵消。收入端α并未完全消失，而是从"总量抗跌"退化为"国内去库存更彻底+海外本币跑赢"。**

## 四、模块二核心结论（三季报校准）

1. **行业坐标再次下修**：中国2026年零售额约-9%~-10%（H1 -9.9%、Q3 -10%），空调内销出货Q3 -15.1%；2027年国补到期后可能再下台阶。海外从"分化"收敛为"北美弱、欧洲平、新兴强"，海外整体仅+0.8%。
2. **库存去化进入后半程但未结束**：厂商主动降出货（空调内销-15.1%）、渠道库存压缩，海尔合同负债连续两季回升（52.08→66.51→76.33亿）是积极信号；但11月空调排产+15.6%是低基数假象，12月+2.1%、2027年1月-2.5%才是真实趋势。
3. **成本端是2027年最大压制**：铜14,154-14,875、UBS预测2027年15,500，旧模型"回落至13,000"的假设证伪；海尔Q3毛利率的"韧性"主要来自14.93亿一次性退税，剔除后约24.9%。
4. **对海尔的净判断**：行业β从-6.7%（年初）→-9.9%（H1）→-10%（Q3），2027年国内仅低个位数恢复；海尔α从"总量抗跌"退化为"国内去库存更彻底+海外本币跑赢+份额提升"，但三者都被汇率折算与一次性退税放大/掩盖。**这是模块五将2026E/2027E分别下修至170.4亿/162亿（扣非148.6亿→157亿）的需求侧依据。**
