# 研报章节四：外部边界与宏观政策

**研究日期**：2026年11月6日

---

## 一、宏观环境变量：利率、汇率与通胀（三季报校准）

### 1.1 美联储路径：9月加息、10月暂停但鹰派，降息叙事彻底逆转

**关键事实链**：
- 2026年9月16日：美联储加息25bp，联邦基金利率升至**3.75%-4.00%**（此前市场预期降息）；
- 2026年10月28日：FOMC以10-2维持不变，**两位委员（Cook、Hammack）主张再加息25bp**；声明称"通胀仍然高企"，需"积累更多信息"；
- 市场预期：年内仍有一次以上加息可能；美联储主席Warsh表示2027年某次会议将专门讨论货币政策框架；
- 美元指数在101附近，10年美债高位；美国中期选举后美元一度走弱（民主党横扫两院），但利率路径未变。

**对海尔的影响（双重通道，均为负向）**：

1. **财务费用通道（负向且持续）**：GEA美元借款利息高企，9M利息费用13.94亿（2025年同期21.02亿，因债务结构优化下降），但汇兑损失主导财务费用；2027年若利率维持3.75-4.00%，利息节省空间有限。
2. **北美需求通道（负向，恢复推迟至2028）**：30年按揭高位、地产"锁定效应"，Q3北美行业出货-4%（AHAM），惠而浦全年指引行业-5%；此前"2027年降息→地产后周期修复"的假设**已证伪**，本期将2027E北美收入增速由+3%下调至+1%。
3. **估值通道（负向）**：全球无风险利率上行压制低增长消费股的估值中枢，海尔PE从12-15x下移至10-12x，部分是利率环境的永久性重定价。

### 1.2 人民币汇率：持续升值，双重侵蚀

| 时期 | 人民币兑美元 | 对海尔影响 |
| :--- | :--- | :--- |
| 2025H1 | 7.279（均值） | 汇兑净收益8.82亿 |
| 2026H1 | 约6.93 | 汇兑净损失7.04亿（swing 15.86亿） |
| 2026Q3 | 约6.75-6.80 | 汇兑损失5.02亿、套保收益1.38亿，净损3.64亿（2025Q3净收益1.34亿，多损4.98亿） |
| 2026-11-05 | **即期6.67**，中间价6.7168 | 年内升值约4.9%；9M净损约10.7亿，swing约20.8亿 |
| 2027E | 6.6-6.8（基准6.70） | 基准假设汇兑净损5-6亿（不再假设"中性"） |

**政策动作**：2026-11-03央行上调外汇风险准备金率，意在"控速"而非逆转升值；中间价连续偏弱于市场预测（11-03偏弱660点、11-05收窄至373点），说明央行不希望人民币过快升值。**判断：升值趋势未改、斜率放缓，海尔2027年仍面临汇兑损失，但幅度小于2026年。**

**双重侵蚀**：
- 利润表：9M财务费用15.75亿（汇兑净损约10.7亿），拖累归母约9亿；
- 资产负债表：其他综合收益-35.99亿（外币报表折算-35.90亿），侵蚀归母权益约2.9%，BVPS增厚受阻。

### 1.3 通胀与成本传导：铜价历史极值，2027年看不到回落

- **铜**：LME 9-10创14,875美元/吨历史新高，10月末14,154.5；COMEX 6.57美元/磅；沪铜10.9-11.1万元/吨（较2025年9月起点+36%）。UBS预计全球铜缺口由2026年21.9万吨扩大至2027年37.9万吨，**2027年铜价预测15,500美元/吨（新高）**；
- **制冷剂**：R32从2025年初2.8万元/吨涨至年末6.2-6.3万元/吨（+125%），2026年高位坚挺；
- **塑料/钢/海运费**：ABS累计涨约三成，海运费上涨（公司明确提及）；
- **终端价格**：空调/洗衣机均价下滑，冰箱/冷柜因成本敏感提价；行业提价3-10%但被终端内卷抵消；
- **净判断**：全球"再通胀+铜短缺"使成本端在2027年仍是压制项，旧模型"铜回落至13,000→毛利率+0.2pct"的假设彻底证伪，本期改为"铜14,000-15,500→可持续毛利率26.2%"。

## 二、地缘政治与贸易政策：232整件计征是结构性变化

### 2.1 中美关税全景（截至2026-11-06）

| 时间 | 事件 | 对海尔影响 |
| :--- | :--- | :--- |
| 2025.04 IEEPA 145% | 极端压力 | — |
| 2025.10 吉隆坡休战至30% | 缓和 | — |
| 2026.02.20 最高法院裁定IEEPA违宪失效 | 关税重构、退税 | 2026年一次性退税（9M非经常性"税收调整"20.05亿，其中Q3 14.93亿） |
| 2026.04 家电25%固定关税 | 再收紧 | 成本+ |
| 2026.07.24 301"强迫劳动"对华12.5% | 替代关税 | 大家电被232覆盖不重复征收，影响小家电 |
| **2025-2026 232改为"整件计征"** | **结构性变化** | **冰箱/洗衣机无论自中国、墨西哥或东南亚出口，均按整件计征同一道税，转口避税失效** |
| 2026.09.28 中美"300亿对300亿"对等降税 | 小家电利好 | 电动剃须刀、微波炉、咖啡机等11个税则超九成免除301附加税，回到最惠国税率（海尔小家电代工部分受益，体量小） |
| 2026.10.28 232机器人与工业机械调查 | 暂不加征，180天谈判 | 对海尔影响中性 |

**对海尔的具体影响**：
1. **退税是一次性、不可持续**：2026年9M 20.05亿"税收调整"非经常性收益（美国关税退税，冲减营业成本），管理层在业绩交流中表示Q4或2027年仍可能确认追加退税（来源：UOB Kay Hian 2026-10-30 研报引述管理层，未经公告原文确认），但**不进入2027E基准**；若后续被追征或回拨，2026年报表利润存在回冲风险；
2. **整件计征削弱GEA本土化优势**：此前"墨西哥USMCA零关税+泰国转口"可规避部分关税，整件计征后路径失效；GEA北美本土80%产能仍是最大缓冲，但成本优势下降；
3. **小家电对等降税利好有限**：海尔小家电以代工贴牌为主，收入占比低。

### 2.2 中东地缘与供应链

- 中东非Q3单季美元口径收入稳健增长，较H1"承压"改善；埃及二期投产提供本地化支撑；
- 铜供应链地缘（刚果金禁令、智利减产、Codelco产量下滑）是铜价高企的底层原因，短期无解；
- 红海/海运费：公司明确"海运费上涨"是海外毛利率的压力项。

### 2.3 欧盟政策：F-gas 2027年是唯一确定性利好

- **2027-01-01欧盟F-gas修订生效**：≤50kW单体热泵、≤12kW分体空气-水热泵新投放须GWP<150；R32（GWP 675）被排除，R290（GWP 3）成为主流；
- 德国自2028年起BEG补贴仅限天然工质热泵；英国暂不跟进（北爱遵循欧盟）；
- 海尔已布局R290空调与热泵，欧洲暖通收入2026年双位数增长；欧洲核心市场冰洗份额+0.9/+0.4pct；
- **判断**：F-gas是2027年欧洲暖通的确定性增量，但欧洲冰洗总量持平，只能支撑+7%的收入增速，无法扭转全局。

## 三、国内政策环境：国补进入"最后一季"，2027年政策真空

### 3.1 2026年消费品以旧换新（收官）

| 维度 | 2025年 | 2026年 | 变化 |
| :--- | :--- | :--- | :--- |
| 家电品类 | 12类 | 6类（冰箱/洗衣机/电视/空调/热水器/电脑） | 收缩 |
| 补贴比例 | 20% | 15%（仅1级能效） | 下调 |
| 单件上限 | 2,000元 | 1,500元 | 下调 |
| 每人限制 | 空调3件 | 每类1件 | 收紧 |
| 资金规模 | 3,000亿 | **2,500亿**（四批全部下达，第四批625亿于9-30下达） | 缩减 |
| 执行进度 | 1.29亿台 | 截至10月超10,099万台 | — |
| 截止时点 | 2025-12-31 | **2026-12-31（按惯例）** | — |

**政策判断**：
1. **Q4是"最后一季"**：第四批625亿+双十一，10月以来家电销量不错（央视调查），Q4行业有望同比转正；
2. **2027年无接续文件**：商务部等7部门《关于推动商品消费扩容升级的实施意见》强调"常态化、精准化、动态化"，未明确2027年资金规模；政策基调从"普惠刺激"转向"长效机制"；
3. **对海尔**：①一级能效占比高（H1 42.5%）受益；②Q4低基数+补贴收官，国内收入有望转正（管理层指引）；③2027Q1存在"抢补贴透支→需求断层"风险，已计入保守情景。

### 3.2 房地产与消费

- 全国地产新开工/竣工双降未改，家电新增需求（新房配套）贡献持续弱化；
- 2026年1-9月家用电器和音像器材类零售额5,437亿（H1，-7.4%），9月社零家电类仍负增长；
- 存量更新占比提升至主导（百户保有量：冰箱106.6、洗衣机100.3、空调161.8台），更新周期8-12年；
- **对海尔**：国内需求只能靠"更新+结构升级+份额集中"，2027年国内收入仅给+1.5%。

## 五、模块四核心结论（三季报校准）

1. **宏观范式逆转：从"降息+弱美元"到"加息+强人民币"**。美联储9月加息、10月鹰派暂停（2票主张再加息），人民币升至6.67（年内+4.9%），海尔同时承受"利息高+汇兑损+折算损"三重压力；旧模型"2027年汇兑中性"的假设证伪，本期财务费用由8亿上调至14亿。
2. **铜价是2027年最大压制**：LME 14,154（9-10曾14,875）、UBS预测2027年15,500，旧模型"回落至13,000"证伪；2027E可持续毛利率由27.2%下调至26.2%，对应毛利减少约30亿。
3. **232整件计征是结构性新利空**：墨西哥/东南亚转口避税失效，GEA本土80%产能的优势从"成本套利"退化为"交付服务"；叠加关税退税一次性，2027年北美利润率承压。
4. **国内政策"短多长空"**：Q4第四批625亿+双十一支撑国内收入转正，但2026-12-31后政策真空，2027Q1存在需求断层；这是2027E国内仅给+1.5%的核心原因。
5. **唯一确定性利好是欧盟F-gas**：2027-01-01 GWP<150生效，海尔R290空调/热泵布局领先，欧洲暖通双位数增长可延续，但欧洲营收占比仅13%，不足以改变全局。
