# 研报章节四：外部边界与宏观政策

**研究日期**：2026年08月07日

---

## 一、宏观环境变量：利率、汇率与通胀

### 1.1 美联储政策路径：降息周期意外终结，鹰派转向主导2026H2

**关键事实链（2025-2026）**：
- 2025年美联储累计降息75bp至3.50%-3.75%，市场曾普遍预期2026年继续降息2次、利率降至3%附近；
- **2026年6月美联储新主席沃什（Warsh）上任后首次议息会议彻底转鹰**：点阵图显示18位官员中9位预计2026年至少加息1次（其中5位预计加息2次），仅1位预计降息；PCE通胀预测从2.7%大幅上修至3.6%（核心PCE至3.3%），通胀回归2%目标推迟至2028年；取消前瞻指引、设立5个工作组重塑货币政策框架；
- 市场预期2026H2美联储有1-2次**加息**（而非降息）；美元指数突破100关口，上看103-104；
- 背景：美国5月CPI同比4.2%（能源项拉动1.5pct），中东冲突（2026年2月底美以联合攻击伊朗）推高油价与通胀，AI投资热潮系统性抬升中性利率。

**对海尔的影响（双重通道）**：

1. **财务费用通道（负向）**：海尔海外借款（GEA美元借款等）利息与美国政策利率高度正相关。此前降息预期下财务费用有压缩空间（国联民生研报观点），加息预期反转后，2026H2-2027年美元利息成本将上行。参考：2025年财务费用为净收益-0.51亿元，2026Q1因汇兑损失转正至+7.35亿元。

2. **北美需求通道（负向，时滞）**：美国30年期按揭利率6.55%（11个月高点），地产复苏被推迟。此前"2026H2降息→美国地产后周期→家电需求修复"的乐观路径已失效，北美家电需求修复时间点从2026H2后移至**2027年甚至更晚**。这是对海尔估值最重要的宏观利空修正。

3. **人民币汇率通道（转为中性偏正向）**：

| 时期 | 人民币兑美元 | 对海尔影响 |
| :--- | :--- | :--- |
| 2025Q1 | 平均7.279 | 2025年汇兑收益10.01亿元 |
| 2026Q1 | 平均6.927（升值~5%） | 汇兑损失，财务费用+7.35亿元 |
| 2026H2-2027E | 市场预期向7.0附近回归（升值结束） | 汇兑压力缓解，若美元走强则反向形成收益 |

   人民币单边升值已基本结束（2026H1升值主要受结汇潮+关税缓和驱动，美联储转鹰后动能衰减），机构预测人民币向7.0关口回归。**对海尔是边际利好**：2026Q1的汇兑损失（约9.6亿元，贡献了Q1归母净利降幅的主要部分）在H2-2027年大概率不会重演，甚至可能转为汇兑收益。

### 1.2 通胀与成本传导

- 美国5月CPI 4.2%高位，欧洲央行2026年6月加息25bp至2.25%（重启加息），全球"再通胀"压力下家电终端提价具备外部合理性；
- 国内PPI低位、消费需求疲弱（社零转负），国内提价空间受限——2026年Q1国内家电均价上调约5-7%（空调+6.7%），但主要反映铜价成本推动而非需求拉动；
- 对海尔的净判断：全球通胀环境利好海外提价（GEA已实现提价），国内通胀温和限制内销提价弹性，整体成本传导"海外顺、国内逆"。

## 二、地缘政治与贸易政策：关税博弈进入"休战-反覆"拉锯

### 2.1 中美关税全景（多源核验）

| 时间 | 事件 | 影响 |
| :--- | :--- | :--- |
| 2025年4月 | 美国IEEPA"解放日"关税，对华一度高达145% | 行业极端压力 |
| 2025年10月 | 吉隆坡谈判+韩国元首会晤，设定对华关税上限约20%、一年期休战 | 实际对华关税降至约30% |
| 2026年2月 | **美国最高法院裁定IEEPA关税违宪失效**（122附加费到期） | 关税体系重构，市场定价混乱（惠而浦称同行预期关税退税后降价抢市） |
| 2026年4月 | 美国对进口家电总值征收25%固定关税（新规） | 家电品类关税环境再收紧 |
| 2026年5月 | 特朗普访华，确立"中美建设性战略稳定关系"、成立贸易理事会/投资理事会 | 机制化缓和 |
| 2026年7月23日 | **301条款（强迫劳动调查）对60经济体加征10%-12.5%关税，对华12.5%**，7月24日生效 | 对华替代关税12.5%（美方承诺不超过20%） |
| 2026年7月 | 中美推进各自**300亿美元对等降税框架**，9月习近平拟访华盛顿 | 边际缓和 |

**对海尔的具体影响评估**：

1. **结构免疫性强**：海尔海外收入1,558亿元中，美国市场主要由GEA本土制造（80%本土供应）+墨西哥蒙特雷基地（USMCA零关税）+泰国工厂（100%承接对美大冰箱出口）供应，**中国直供美国比例很低**；对华12.5%新关税主要冲击低金属含量小家电（海尔小家电代工部分涉及），大家电已被232条款覆盖、不重复征收。关税对海尔的实际冲击显著小于纯出口型同行（对比：惠而浦Q1北美EBIT降96%、美的/格力出口业务承压）。
2. **关税政策反复的成本**：最高法院裁决+新关税衔接造成北美渠道价格策略混乱（经销商观望、促销加剧），短期压制北美收入与利润率——这与2026Q1海尔北美承压、惠而浦北美销量下滑的背景一致。
3. **缓和趋势确立**：中美贸易理事会机制+对等降税框架+关税上限承诺，2026-2027年关税系统性恶化的概率下降。但"休战脆弱"（中方警告超7.5%即可能报复）意味着不确定性溢价长期存在。

### 2.2 中东地缘冲突（2026年2月底美以联合攻击伊朗）

- 直接冲击：油价飙升（3月涨超30%）→塑料粒子/制冷剂/发泡料等石化衍生品成本暴涨；国际运费上行；铜价中枢上移（美伊僵局+供应紧张）；
- 对海尔的传导：2026Q1铜价均价9.9万/吨（+33%）、制冷剂涨价80%——这是2026年毛利率承压的核心外因之一；
- 中期看：若地缘缓和，油价回落将缓解石化成本（6月美国CPI环比-0.4%已有体现）；若恶化，成本压力延续。

### 2.3 欧盟政策环境（中性偏正向）

- 能效标签升级+F-Gas制冷剂法规（2027年收紧）驱动产品迭代：海尔欧洲白电平均单价+10%以上、份额提升至12.5% TOP2——法规升级利好高能效产品占优的头部企业；
- 欧盟对华电动汽车关税不涉及白电，家电品类无直接贸易壁垒；
- 欧洲央行加息至2.25%（2026年6月）小幅压制欧洲消费，但幅度有限。

## 三、国内政策环境：国补收缩但结构性托底

### 3.1 2026年消费品以旧换新政策（发改委/商务部官方文件核验）

| 维度 | 2025年 | 2026年 | 变化 |
| :--- | :--- | :--- | :--- |
| 家电品类 | 12类 | **6类**（冰箱/洗衣机/电视/空调/热水器/电脑） | 大幅收缩 |
| 补贴比例 | 20% | **15%**（仅1级能效/水效） | 下调 |
| 单件上限 | 2,000元 | **1,500元** | 下调 |
| 每人限制 | 空调可3件 | **每类1件** | 收紧 |
| 资金规模 | 1,500亿+ | **2,500亿超长期特别国债**（3月政府工作报告确认） | 总盘子反超 |
| 实际执行 | 2025年补贴约827亿 | 截至5月4日带动3,473.5万台、销售额1,415.4亿 | 力度弱化 |

**政策判断**：2026年国补政策"品类收缩、力度下调、总盘子扩大"，从"普惠刺激"转向"精准提质"。对海尔的净影响中性偏正向：①一级能效门槛利好海尔（高能效产品占比高，2025年海尔一级能效产品结构优于行业）；②总盘子2,500亿超预期提供需求托底（家电社零避免深度下滑）；③补贴向AI智能终端倾斜（"人工智能进万家"）与海尔AI家电战略契合；④但补贴覆盖品类收缩（剔除厨电/洗碗机/净水器/电饭煲等）对海尔厨电/水家电内销形成边际拖累。

### 3.2 房地产政策与消费刺激

- 国内地产持续筑底（新开工/竣工双降），家电新增需求（新房配套）贡献持续弱化，更新需求（存量替换）占比提升至主导地位；
- 2026年政府工作报告：促进商品消费扩容升级，安排1,000亿元财政金融协同促内需专项资金；家电下乡、县域消费体系政策延续；
- 对海尔：国内更新需求受国补节奏影响大，2026年国内收入大概率个位数下滑（与行业-6.7%同步），但TC模式+套系化提升单位用户价值（618套系销额+44%），以价补量。

## 五、模块四核心结论

1. **最大宏观变量修正：美联储从降息转向鹰派**。这意味着北美家电需求的"地产后周期修复"从2026H2推迟至2027年，海尔北美（790亿收入）的复苏节奏需要下修；同时海外美元利息成本上升。但**人民币升值压力同步解除**，2026Q1的汇兑损失（归母净利-15%的主要构成）在H2大概率消退甚至反转，两者部分对冲。
2. **关税环境进入"机制化缓和期"**：对华关税锁定在12.5%（上限20%承诺）+300亿美元对等降税框架+贸易理事会，系统性升级概率下降；海尔凭借"海外本地化制造（GEA本土80%+墨西哥+泰国）"的关税免疫结构，是关税博弈中受影响最小的中国白电龙头。
3. **国内政策"精准提质"**：2,500亿国补总盘子提供需求底，一级能效门槛+AI终端倾斜与海尔产品结构契合；品类收缩对厨电/水家电内销有边际拖累。
4. **通胀环境"海外顺、国内逆"**：全球再通胀支撑海外提价（GEA已落地），国内PPI低位限制内销弹性——海尔海外占比51.5%的结构在此环境中相对受益。
