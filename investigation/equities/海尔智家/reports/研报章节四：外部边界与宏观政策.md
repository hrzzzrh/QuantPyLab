## 一、宏观环境变量：利率、汇率与通胀（H1校准）

### 1.1 美联储政策路径：H1鹰派担忧延续，但9月降息预期升温

**关键事实链（2026H1后更新至8月）**：
- 2025美联储降息75bp至3.50%-3.75%，市场曾预期2026继续降息2次；
- **2026年6月美联储主席沃什首次议息转鹰**：点阵图9/18预计加息1次（5位预计2次），PCE从2.7%上修至3.6%，通胀回归推迟至2028年，市场预期H2加息1-2次，美元指数破100上看103-104，30年按揭6.65%（7月）11个月高点；
- **8月边际缓和**：LME铜8-27升至9,448美元（+1.72%）、美元指数回落至99附近，市场重燃9月降息预期（鲍威尔Jackson Hole鸽派言论），LME铜6周高点显示降息预期升温；但7月新屋开工-12.4%（1,239k vs 预期1,350k）与销售-10.5%（60.7万）显示地产仍弱，降息必要性上升；
- 背景：5月CPI 4.2%（能源1.5pct），中东2月底冲突推高油价30%+，但6月CPI环比-0.4%显示通胀短期回落。

**对海尔的影响校准（双重通道）**：

1. **财务费用通道（负向→边际缓和）**：H1财务费用11.03亿（+14.54亿 YoY）已兑现加息压力（GEA美元借款利息964M），但8月降息预期升温（LME铜因降息预期上涨1.72%）显示H2利息或见顶。惠而浦利息从86→63（Q2）但全年指引300-350→?上修因发债，提示利息仍高。
2. **北美需求通道（负向，时滞，H1验证企稳）**：30年按揭6.65%压制地产（7月开工-12.4%/销售-10.5%/供应9.6个月），H1 AHAM -3.4%（Q2）验证需求弱，但9月降息预期若兑现（9/17议息），地产后周期或从2027H1提前至2027Q1，期权价值边际提升。
3. **人民币汇率通道（已兑现利空，H2中性）**：
| 时期 | 人民币兑美元（推算） | 对海尔影响H1验证 |
| :--- | :--- | :--- |
| 2025H1 | 7.279（H1均值） | 收益8.82亿 |
| 2026H1 | 约6.93（估算，升值约4.8%） | **损失7.04亿，swing 15.86亿** |
| 2026H2-2027E | 向7.0-7.1回归（8月CFD预期） | H2汇兑中性或小幅收益（与2025H2损失3亿比改善） |

   H1汇兑已兑现最大利空（7.04损 vs 8.82益），H2大概率收敛（公司称“倘若排除汇兑，税前利润降幅大幅缩小”），8月人民币贬值预期升温（美元走弱+降息预期）对海尔是边际利好。

### 1.2 通胀与成本传导（H1铜历史新高验证）

- 美国5月CPI 4.2%高位→6月环比-0.4%回落，欧洲6月CPI后加息至2.25%后通胀放缓，全球“再通胀”压力短期缓解但结构性仍存；
- **铜价H1验证历史新高**：LME 8-28盘中14,535美元/吨创历史新高（收盘14,415，vs 年初9,500），沪铜108,590元/吨（+33% YoY），较8/07预期9.5-11万上修32%，库存234k吨（LME 8-28）注销仓单50%深度Back（现货升水478美元/吨5年新高），对海尔成本端压力从“高位”升级至“历史极值”；
- 国内PPI低位+社零转负，国内提价空间受限（空调+6.7%均价提升但销量-13.1%），海外提价（GEA >10%）已兑现但Q2后需求抑制风险上升；
- **净判断校准**：全球通胀“海外顺（提价兑现+毛利率持平）、国内逆（PPI低+份额战）”分化加剧，铜历史新高使“海外顺”可持续性存疑，H2若铜维持14,500则全年27.0%毛利率承压。

## 二、地缘政治与贸易政策：关税缓和但铜供应链地缘加剧

### 2.1 中美关税全景（H1后更新，多源核验）

| 时间 | 事件 | H1验证影响 |
| :--- | :--- | :--- |
| 2025.04 IEEPA 145% | 极端压力 | — |
| 2025.10 吉隆坡休战至30% | 缓和 | — |
| 2026.02 最高法院裁定IEEPA违宪失效 | 关税重构，退税预期 | **H1退税兑现**：LG获3000亿韩元（~15亿）退税，海尔海外毛利率持平受益1-2亿美元（7-15亿）一次性 |
| 2026.04 家电25%固定关税 | 再收紧 | H1成本+ |
| 2026.05 特朗普访华确立稳定关系 | 机制化缓和 | — |
| 2026.07.23 301对60经济体10-12.5%（对华12.5%） | 替代关税12.5% | H1已生效，但大家电被232覆盖不重复征收，影响小家电 |
| 2026.07 300亿对等降税框架，9月习近平拟访华盛顿 | 边际缓和 | 预期 |

**对海尔的具体影响校准**：
1. **结构免疫性H1验证有效**：GEA本土80%+墨西哥USMCA零关税+泰国冰箱100%承接对美，12.5%新税主要影响小家电（海尔小家电代工部分），大家电已被232覆盖，H1关税成本可控（海外毛利率持平）；
2. **退税一次性贡献**：最高法院裁决后，H1海外毛利率持平“受益一次性退税”，但H2无同等一次性，利润弹性不可持续；
3. **缓和趋势延续但铜地缘取代关税成主要风险**：中美贸易理事会+降税框架使关税系统性恶化概率下降（海尔受影响最小），但刚果（金）铜精矿出口禁令+智利二季度产量20年新低+加工费-182美元/吨历史极低+COMEX-LME价差驱动资源涌入美国，使铜供应链地缘风险取代关税成为主要外部约束。

### 2.2 中东地缘冲突（H1验证供应链扰动）

- H1验证：中东非收入承压（海尔披露“受该地区冲突短期影响，收入有一定承压”），埃及二期冰箱产线下半年投产为对冲；
- 油价3月+30%→6月回落，但铜价因中东+铜矿扰动（Cobre Panama审计88%合规待Q4恢复）维持历史新高；
- **传导校准**：地缘对海尔从“油价→塑料”转为“铜精矿禁令→加工费-182极低→库存234k吨50%注销→现货升水478”供应链地缘，H1已体现（东南亚/非洲供应链优化提及），H2若Cobre Panama Q4恢复则缓和但短期仍高压。

### 2.3 欧盟政策环境（H1验证中性偏正向但增速不及预期）

- F-gas/能耗标签驱动海尔欧洲暖通>50%西班牙/法国复苏，但H1欧洲整体+4.9% vs 预期+15%显示政策驱动兑现弱于预期；
- 欧盟对华白电无壁垒，家电品类受益F-gas但H1验证“量平价升”幅度有限；
- 欧洲央行6月加息至2.25%后，8月通胀回落，政策紧缩边际放缓。

## 三、国内政策环境：国补H1验证退坡幅度超预期

### 3.1 2026年消费品以旧换新政策（H1验证）

| 维度 | 2025年 | 2026年H1验证 | 变化 |
| :--- | :--- | :--- | :--- |
| 家电品类 | 12类 | **6类**（冰箱/洗衣机/电视/空调/热水器/电脑） | 收缩 |
| 补贴比例 | 20% | **15%**（仅1级能效） | 下调 |
| 单件上限 | 2,000元 | **1,500元** | 下调 |
| 每人限制 | 空调3件 | **每类1件** | 收紧 |
| 资金规模 | 1,500亿+ | **2,500亿超长债**（3月确认） | 总盘子扩大 |
| H1实际 | 补贴827亿（1-11月） | **H1零售-9.9%（4,250亿）显示托底有限** | 力度弱化验证 |

**政策判断校准**：H1 -9.9%（Q2 -12.4%）显示“品类收缩+力度下调”利空大于“总盘子2,500亿”托底利好，政策从“普惠刺激”转向“精准提质”但效果不及预期。对海尔：①一级能效42.5%（+28.9pct）利好持续（卡萨帝高端受益）；②总盘子2,500亿提供需求底但H1未显；③剔除厨电/净水等品类对海尔厨电/水家电H1内销（厨电9.4%/净水19.5%份额提升但行业-9.9%）形成边际拖累，H2若Q4国补加码则边际改善。

### 3.2 房地产政策与消费刺激（H1验证低迷延续）

- 全国地产新开工/竣工双降未改，7月新屋开工-12.4%（123.9万）、销售-10.5%（60.7万）、供应9.6个月，家电新增需求（新房配套）贡献再弱化；
- 2026政府工作报告1,000亿促内需专项资金H1未显效；
- **对海尔校准**：国内更新需求占比提升至主导，H1 -9.9%显示存量替换亦受国补退坡+地产拖累，海尔H1国内-4%~-5%跑赢行业但全年仍承压，TC 64%以价补量（套系+44%）对冲有限。

## 五、模块四核心结论（H1校准）

1. **最大宏观变量切换：从“关税”转向“铜供应链地缘”**。H1验证美联储鹰派压力已部分price-in（财务费用11.03亿兑现），但LME铜14,535历史新高（+33% YoY，加工费-182极低，库存234k吨50%注销，现货升水478）使成本端从“高位”升级至“历史极值”，取代关税成为主要外部约束（关税H1验证免疫+退税对冲）。
2. **关税环境“机制化缓和”验证**：12.5%新税对海尔影响可控（H1海外毛利率持平），但铜精矿禁令（刚果金）+智利减产+Cobre Panama待Q4恢复+COMEX溢价驱动资源涌向美国，使铜价短期难回落，H2毛利率27.0%假设面临挑战。
3. **国内政策“托底有限”**：H1 -9.9%（Q2 -12.4%）显示2,500亿国补总盘子未能对冲品类收缩（6类/15%/1,500元/每类1件）的退坡，内销全年-8%~-10%（vs -6.7%预期）超预期下滑，但海尔一级能效42.5%（超行业23.7pct）+AI终端倾斜仍结构性受益。
4. **通胀环境“成本历史新高”**：全球铜历史新高使“海外顺（提价兑现）”可持续性存疑，H1毛利率27.2%（+0.4pct）超预期但H2若铜维持14,500则全年27.0%承压，利好兑现与成本新高博弈为H2核心变量。
