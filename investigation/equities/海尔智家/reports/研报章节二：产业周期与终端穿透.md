## 一、产业生命周期与库存节奏（H1校准）

### 1.1 周期定位：国内成熟期存量博弈加剧 + 海外分化，新兴韧性

海尔智家的业务横跨中国与全球，其产业周期位置必须分市场判断：

**中国市场（约占营收46.7% H1推算）——成熟期后半段，H1验证加速下滑：**
- 空调城市百户拥有量已超160台、冰箱/洗衣机接近100台/百户，渗透率饱和；
- 增长动力已从地产驱动切换为更新换代驱动（8-12年周期）；
- 2026H1全品类零售额4,250亿元（-9.9%，Q1 -6.2%/Q2 -12.4%），家用空调总销量-6.2%（产业在线）、零售量-13.1%/额-15.9%（奥维），行业总量负增长幅度较年初预测-6.7%扩大3.2pct；
- 白电三强（美的/海尔/格力）集中度约74%，格力H1主营-2.56%收缩、中小品牌出清，存量博弈加剧。

**海外市场（约占营收53.3% H1）——分化：欧洲平稳、新兴高增、北美底部：**
- 全球核心家电零售额2025 2,983亿美元（+3.3%），2026H1海尔海外基本持平（欧洲+4.9%/南亚+17.1%/日本+9.9%/澳洲+4.3%/东南亚双位数 vs 中东非承压、北美微负）；
- 新兴市场仍处渗透率爬坡期（印度/巴基斯坦/非洲渗透率<40%），人口+城镇化驱动首次购置；
- 发达市场（北美/欧洲/日本）存量更新主导，欧洲F-Gas/能耗标签驱动迭代（海尔欧洲ASP延续提升）。

### 1.2 库存动力学：H1验证主动去库延续，去化放缓

| 信号 | 2026H1验证 | 解读 |
| :--- | :--- | :--- |
| 2026年6月空冰洗排产 | 3,004万台（-11.8%），空调-18.9% | 厂商主动控产 |
| 2026年8月排产 | 2,833万台（-6.3%），空调-16.7% | 去库延续但降幅收窄 |
| 2026H1空调零售 | 量-13.1%、额-15.9% | 终端需求大幅回落，符合预期 |
| 2026H1海尔存货 | 453.17亿（-3.27% vs 468.49） | 海尔去化快于行业-?，周转天数约75天（Q1 78.3天改善） |
| 2026H1行业出口 | 冰箱/洗衣机出口双位数（海关总署1-5月+13.7%/+10.6%延续） | 出口对冲内销 |
| 渠道库存 | 空调2025末1,441万台（-16.5%）→H1继续去化但Q2补库（海尔合同负债环比+27.7%） | 去化接近尾声 |

**核心辨析——牛鞭效应边际收敛**：H1终端-9.9%与海尔营收-2.8%剪刀差从Q1的-13% vs -6.9%收窄至H1 -9.9% vs -2.8%（差7.1pct vs Q1 6.1pct持平），反映去库节奏放缓。2025国补透支（1.28亿台/827亿）后，2026补贴收缩至6类/15%/1,500元，每类1件，Q2 -12.4%验证透支兑现。**判断：行业去库进入尾声，2026H2-2027初有望企稳，但铜14,500历史新高+地产低迷压制补库意愿，去化速度慢于年初“2-3季度”预期。**

### 2.2 终端景气度审计——2026-2028年趋势（H1校准）

#### 2.2.1 中国终端：H1 -9.9%证实收缩幅度超预期，但海尔份额韧性

**2026H1多源交叉**：

| 来源 | 品类 | 2026H1实际 |
| :--- | :--- | :--- |
| 奥维云网 | 全品类 | -9.9%（4,250亿，Q1 -6.2%/Q2 -12.4%） |
| 产业在线 | 家用空调总销量 | -6.2% |
| 奥维 | 空调零售 | -13.1%/-15.9% |
| 海尔H1 | 冰箱/洗衣机/热水器份额 | +1.7~+3.7pct提升 |
| 海关总署 | 冰箱/洗衣机出口1-5月 | +13.7%/+10.6%（H1延续） |
| 格力H1 | 内销+1.90%/外销-21.98% | 印证出口承压分化 |

**国内核心判断校准**：
1. **内销总量超预期下滑**：年初预测-6.7% vs H1实际-9.9%（Q2 -12.4%），全年有望-8%至-10%（vs -6.7%下修1.3-3.3pct）；
2. **海尔份额韧性验证**：冰箱线上41.9%（+3.7pct）、线下42.2%（+2.1pct）、洗衣机48.8%（+2.4pct）、空调20.6%（+0.8pct）、热水器43.3%（+5pct）均逆势提升，套系+44%验证高端化对冲；
3. **出口对冲有限**：格力外销-21.98%显示并非所有企业能通过出口对冲，海尔凭泰国/埃及/越南园区实现双位数增长，但总量不足以覆盖内销下滑。

#### 2.2.2 北美终端（H1验证逐季企稳，但地产仍弱）

**美国地产与消费（Census/房地美，H1后更新至7月）**：
- 7月新屋销售60.7万套（-10.5% MoM，58万→60.7万波动）、供应9.6个月、库存48.8万套；
- 7月新屋开工123.9万套（-12.4% MoM，1,415k→1,239k）、单户开工80.8万套（-9.9%）、许可144.3万套（+5.0% MoM，乐观信号但开工-12.4%显示转化弱）；
- 30年按揭6.65%（7月，+7bps MoM），MBA 30年6.65%、15年5.93%，仍处高位；
- AHAM行业需求Q2 -3.4%（vs Q1 -10%收窄6.6pct），海尔GEA美元计Q2转正，验证行业最差已过。

**北美判断校准**：与年初“-10%”一致，H1验证最差Q1 -10%后Q2 -3.4%收窄，符合“逐季企稳”路径。7月开工-12.4%虽弱但许可+5.0%提供前瞻分化，**2026全年北美行业-5%~-3%（vs 年初-6%~+2%中性-3%基本一致），2027年若9月降息落地（当前预期升温），地产后周期修复仍为最大期权但时点仍为2027H2。**

#### 2.2.3 欧洲终端（H1 +4.9%验证平稳但增速不及预期）

- 2025欧洲销量+2.1%/额-1.0%（GfK）→2026H1海尔+4.9%（制冷10.8%/洗涤14.7%第二），低于年初+12%~+20%预期；
- 欧盟F-gas/能耗标签驱动ASP提升（海尔欧洲单价+?），但上半年消费受中东冲突+ECB加息至2.25%压制；
- 高温脉冲：德国6月空调+133%为短期，未持续拉动H1整体至双位数；
- **判断校准**：欧洲“量平价升”但增速从高增（+15%预期）下修至平稳（+6%中性），F-gas仍为中期利好但2026兑现弱于预期。

#### 2.2.4 新兴市场（南亚+17.1%/东南亚双位数/日本+9.9%/澳新+4.3%验证高增）

- 印度2025 -0.4%（GfK）但海尔卢比>20%/巴>30%，份额提升，Gravity高端第三；
- 巴基斯坦2025 +10%（空调+15%）→H1海尔>30%份额第一延续；
- 东南亚越南21.2%第一、泰国春武里600万台/年投产支撑；
- 中东非H1承压（冲突），埃及二期下半年投产，中期潜力仍存但2026增速从+30%下修至+5%。

## 三、供需边际与压力传导（H1校准）

### 3.1 供需平衡审计

| 维度 | 2025 | 2026H1 | 趋势 |
| :--- | :--- | :--- | :--- |
| 中国终端需求 | 国补刺激超常增长 | -9.9%（4,250亿） | ↓超预期 |
| 渠道库存 | 高位积累 | 去化延续但Q2合同负债环比+27.7%显示补库边际 | ↓→企稳 |
| 厂商排产 | 高排产 | 6月-11.8%/8月-6.3% | ↓收敛 |
| 出口需求 | 温和增长 | 双位数（海尔东南亚/南亚），但格力外销-21.98%分化 | ↑分化 |
| 原材料（铜） | 7-9万/吨 | LME 14,500美元/吨历史新高（+33% YoY，沪铜108,590） | ↑↑↑ |
| 行业集中度 | 白电CR3约70% | 74%（618海尔四品类第一） | ↑ |

**供需格局判断校准**：国内从紧平衡滑向阶段性过剩幅度超预期（-9.9% vs -6.7%），过剩压力通过“控产去库+出口转移+份额集中”消化，但铜历史新高（14,500 vs 8/07 9.5-11万/吨上修40%）加剧成本端过剩传导，价格战风险从空调（-13.1%）蔓延至全品类，但海尔通过高端化（卡萨帝52%）与TC效率（64%）缓冲。

### 3.2 压力传导特征分析（H1验证）

**传导路径一：国补退坡→终端-9.9%→渠道去库存→排产-11.8%→价格竞争**
- 时滞2-3季度，H1验证终端-9.9%→海尔-2.8%（传导系数0.28，缓冲强于行业）；
- 海尔缓冲：TC统仓64%（+7pct）缩短链路，库存453亿（-3.27%）去化快于行业。

**传导路径二：铜14,500历史新高+关税12.5%→成本↑→提价3-10%→需求抑制**
- 铜每吨+1万元→单台空调+200-300元，H1铜均价约10.85万（沪铜108,590）较年初+33%且创历史新高，但海尔毛利率27.2%（+0.4pct）显示提价+成本对冲部分成功，传导时滞约1季度，Q2已验证（H1毛利率↑）。

**传导路径三：北美关税+地产弱→GEA收入微负→海外增速5%→3.5%下修**
- H1验证：美国行业-3.4%（Q2）+关税12.5%+铜历史新高，但GEA美元计Q2转正、份额提升，显示免疫结构有效但不足以对冲总量，海外增速从+5%下修至+3.5%。

**波动放大效应评估校准**：H1三重压力（铜历史新高+国内-9.9%+北美地产弱）下，海尔营收-2.8%大幅跑赢行业-9.9%（缓冲系数0.28），毛利率+0.4pct逆势提升，验证“全球化54%+本土化60+工厂+高端化52%+TC 64%”缓冲垫有效，但铜14,500新高若持续至H2，缓冲垫边际递减。

## 【模块二强制复核项】

1. ✅ **终端产品景气度穿透**：H1校准覆盖中国-9.9%（奥维4,250亿）、北美-3.4%（AHAM Q2，Census 7月开工-12.4%/销售-10.5%/按揭6.65%）、欧洲+4.9%（海尔H1，GfK制冷10.8%/洗涤14.7%）、新兴市场南亚+17.1%/东南亚双位数/日本+9.9%/澳洲+4.3%（海尔H1），多源实测。
2. ✅ **跨期需求移位审计**：H1 -9.9%（Q2 -12.4%）验证2025国补透支兑现，最悲观-19.4%风险仍存但海尔份额+2-3pct对冲。
3. ✅ **供需边际与压力传导**：供需表H1校准（需求↓超预期/库存↓但合同负债环比+27.7%企稳/排产↓收敛/出口↑分化/成本↑↑↑/集中度↑），三条路径时滞与缓冲垫H1验证（毛利率+0.4pct）。

## 四、模块二核心结论（H1校准）

1. **行业坐标下修**：中国白电总量从年初-6.7%预期下修至H1 -9.9%（全年-8%~-10%），存量博弈+份额集中（CR3 74%）加剧；海外新兴（+17%）与欧洲（+4.9%）增速不及预期（年初+15%），但仍为结构性增长。
2. **终端需求分化验证**：国内更新需求超预期承压但海尔份额韧性（+2-3pct）+套系+高端对冲；北美Q2 -3.4%收窄验证企稳（2027降息期权不变）；欧洲平稳（+4.9%）而非高增；新兴高增延续但中东非承压。
3. **供需与传导**：2026从紧平衡滑向过剩幅度超预期，但海尔去化（存货-3.27%）快于行业，成本传导（铜14,500历史新高）1季度时滞在H1已部分验证（毛利率+0.4pct），Q3-Q4为关键验证窗口（铜价能否从14,500回落决定全年27.0%假设）。
4. **对海尔的净判断下修**：行业β从-6.7%下修至-9.9%（-3.2pct），海尔α从“持平微增”下修至“微降-0.1%”（3,026亿 vs 3,070亿 -1.4%），但α韧性（跑赢行业7.1pct+毛利率+0.4pct）验证，为模块五下修提供需求侧基准。
