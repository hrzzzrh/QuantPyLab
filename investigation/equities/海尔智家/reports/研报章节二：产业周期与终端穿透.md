# 研报章节二：产业周期与终端穿透

**研究日期**：2026年08月07日

---

## 一、产业生命周期与库存节奏

### 1.1 周期定位：国内成熟期存量博弈 + 海外新兴市场成长期，双轨并行

海尔智家的业务横跨中国与全球，其产业周期位置必须分市场判断：

**中国市场（约占营收48.5%）——成熟期后半段：**
- 空调城市百户拥有量已超160台、冰箱/洗衣机接近100台/百户，渗透率饱和；
- 增长动力已从地产驱动切换为更新换代驱动（冰箱/洗衣机更新周期8-12年、空调8-10年）；
- 2025年全品类（不含3C）零售额8,931亿元（-4.3%），2026Q1全渠道零售额同比-6.2%（奥维云网），2026年全年预测-6.7%——行业总量进入负增长通道；
- 白电三强（美的/海尔/格力）集中度已攀升至约74%，中小品牌空间被持续挤压，存量博弈特征显著。

**海外市场（约占营收51.5%）——分化成长期：**
- 全球核心家电零售额2025年2,983亿美元（+3.3%，欧睿），2026年延续温和复苏；
- 新兴市场（南亚/东南亚/中东非）仍处渗透率爬坡期：印度、巴基斯坦、非洲等市场空调普及率显著低于全球均值，人口红利+城镇化驱动首次购置需求；
- 发达市场（北美/欧洲/日本）进入存量更新主导阶段，但欧洲能效法规升级（F-Gas、能耗标签）驱动产品迭代换代，属于政策催化的结构性需求。

### 1.2 库存动力学：全行业主动去库，出货-零售剪刀差收敛中

| 信号 | 数据 | 解读 |
| :--- | :--- | :--- |
| 2026年6月空冰洗排产 | 3,004万台（-11.8%），其中空调-18.9% | 厂商主动控产，生产极度谨慎 |
| 2026年8月空冰洗排产 | 2,833万台（-6.3%），空调-16.7% | 去库延续，旺季备货谨慎 |
| 2026Q1空调零售 | 量-13%、额-13.8%（奥维） | 终端需求大幅回落 |
| 2026Q1中国空调内销出货 | 海尔+7.78%、美的+18.18%、格力+1.61% | 龙头出货好于零售，渠道补库+份额集中 |
| 空调行业库存 | 2025年末1,441万台（-16.5% YoY） | 渠道库存高位去化中 |

**核心辨析——牛鞭效应评估**：2026年终端需求收缩通过渠道链条被显著放大。2025年国补刺激创造的"超额消费"（2025年1-11月家电以旧换新超1.28亿台、补贴827亿、带动消费4,395亿）在2026年补贴缩减后集中回落，属于典型的"需求前置后的跨期断层"。终端零售-13%与龙头出货+7.8%之间的剪刀差，反映旺季前渠道补库行为（经销商对高温预期与提价预期的备货），而非真实需求反转。**判断：行业处于主动去库阶段，预计持续2-3个季度，2026H2-2027年初有望趋于稳定。**海尔自身2026Q1存货周转天数78.3天（+4.2天）部分为战略备料（对冲铜价上涨），与行业主动去库逻辑并存。

### 2.2 终端景气度审计——2026-2028年趋势

#### 2.2.1 中国终端：需求收缩确认，但结构升级托底

**2026年行业预测汇总（多源交叉验证）：**

| 来源 | 品类 | 2026年预测/实际 |
| :--- | :--- | :--- |
| 奥维云网 | 全品类（不含3C） | 零售额-6.7%（2026Q1实际-6.2%） |
| 产业在线 | 6月空冰洗排产 | -11.8%（空调-18.9%、冰箱-4.1%、洗衣机-1.9%） |
| 产业在线 | 8月空冰洗排产 | -6.3%（空调-16.7%） |
| 奥维云网 | 2026H1洗衣机零售 | 量-4%~-5%，618期间销量-0.9% |
| 奥维云网 | 618蓄水期全渠道 | 零售额-8.3% |
| 海关总署 | 冰箱出口1-5月 | 3,824万台（+13.7%） |
| 海关总署 | 洗衣机出口1-5月 | 5月单月+10.6% |

**国内终端核心判断**：
1. **内销量价双承压**：2026年"国补"政策持续但力度收缩（12类→6类、补贴20%→15%、每件上限2,000→1,500元、空调每人3件→1件），叠加2024-2025年透支，2026年全品类零售额预计-6%至-7%；
2. **结构性亮点在高端与套系**：2026年618海尔7大品类套系销额+44%，卡萨帝万元+高端份额第一——存量市场中"换新升级"替代"新购"成为主战场，高端化是唯一确定的正增长赛道；
3. **出口成为对冲引擎**：冰箱出口+13.7%、洗衣机出口+10.6%，"内弱外强"格局延续，海外本土产能收缩+人民币汇率优势+欧洲补库支撑订单回流中国。

#### 2.2.2 北美终端（海尔最大海外市场，约790亿收入）：需求底部徘徊，地产拐点未至

**美国地产与消费数据（美国人口普查局/Census、房地美）：**
- 2026年5月新屋销售58万套（-7.3% MoM、-6.8% YoY），供应月数10.3个月（2009年以来最高）；
- 2026年6月新屋开工142.7万套（+19% MoM，但完全由波动剧烈的多户住宅拉动：多户+76.3%，独栋-0.2%）；营建许可136.7万套（-3.0%，创3月以来新低，独栋创10个月低点）；
- 30年期抵押贷款利率6.55%（11个月高点，中东冲突自2026年2月以来推高利率约60bp）；
- 2026Q1北美家电行业需求-10%（AHAM，暴风雪+消费信心不足）；
- 积极边际：2025年12月成屋销售435万套（处于2005年以来28%分位），若美联储进入降息通道，地产存在26%-38%的修复空间（550-600万套为中枢）。

**北美终端判断**：北美家电需求与美国地产强相关（滞后2-3个季度）。当前利率高企+高库存压制新屋销售，家电需求2026年内大概率维持低位（AHAM口径2026Q1行业-10%，Q2-Q3随天气与库存修复或收窄至-5%~-3%）。**2027年若降息落地，美国地产后周期将带来家电需求的实质性修复——这是海尔北美业务最大的期权价值，但时间点在2027年而非2026年。**

#### 2.2.3 欧洲终端（385亿收入）：能效法规驱动的结构升级

- 2025年欧洲家电销量+2.1%、销额-1.0%（GfK），缓慢复苏；
- 欧盟能效新政（能耗标签迭代、F-Gas制冷剂法规2027年进一步收紧）驱动产品迭代，白电ASP提升（海尔欧洲2025年平均单价+10%以上）；
- 2026年入夏欧洲多国极端高温，中国空调欧洲热销（海尔西班牙自有品牌销量销额双第一、德国6月空调+133%），叠加PortaSplit便携空调热卖（美的口径，欧洲高温为行业性利好）；
- 欧洲家电整体处于"量平价升"的成熟市场，但能效升级+高温刚需提供结构性增长。

#### 2.2.4 新兴市场（南亚142亿/东南亚75亿/中东非42亿）：高增长延续

- 印度2025年行业-0.4%（Gfk）但海尔收入+15%以上，份额提升（GRAVITY系列带动4星5星份额12%，高端升至行业第三）；
- 巴基斯坦2025年行业+10%（空调+15%），海尔份额超40%第一；
- 东南亚：越南、泰国白电份额持续提升（海尔越南洗衣机市占21.2%），泰国春武里空调厂投产（600万台/年）支撑本土化供应；
- 中东非：埃及生态园一期投产，南非Kwikot整合后利润+10%、税前利润率12%；
- 新兴市场逻辑：人口红利+城镇化+空调渗透率低（<40%）+本土化产能，未来1-3年双位数增长确定性高（证据：海尔新兴市场2025年收入+24%）。

### 2.3 动能溯源与透支审计

| 驱动因素 | 类别 | 持续性评估 | 对海尔影响 |
| :--- | :--- | :--- | :--- |
| 以旧换新国补（2024-2025） | 外生-政策 | **已消退**（2026缩至6类/15%/1件） | 2025年透支国内需求，2026内销承压 |
| 2026年国补（2,500亿超长期国债） | 外生-政策 | 弱化中但仍有托底 | 一级能效补贴利好海尔高端产品结构 |
| 全球高温/气候变暖 | 外生-自然 | 持续增强 | 空调刚需，欧洲/北美热销 |
| 新兴市场城镇化 | 内生-结构 | 长期确定 | 南亚/东南亚/中东非高增长核心 |
| 美国地产后周期 | 外生-宏观 | 尚未启动（利率6.55%） | 2027年潜在最大弹性 |
| 欧洲能效法规 | 外生-政策 | 持续收紧 | 产品迭代、ASP提升、洗牌利好头部 |
| 产品结构升级（高端/套系/AI） | 内生-创新 | 持续 | 卡萨帝+Leader增长引擎 |

**【强制审计：跨期需求移位确认】**
- 2025年中国家电以旧换新补贴创造"需求前置"：2025年1-11月以旧换新1.28亿台、带动消费4,395亿元，远超正常更新节奏；
- 2026年补贴收缩（首批资金625亿，同比-23%）后，2026Q1空调零售-13%、冰箱-5.3%，验证透支效应兑现；
- 券商测算最悲观情景：若2027年国补完全退坡，四大家电更新需求或同比-19.4%、内销量-15.4%；
- **对海尔的影响**：国内收入占比48.5%中约6-7成与更新需求相关，2026-2027年国内收入可能经历-5%~+2%的区间波动；但海尔的"套系化+高端化+全渠道TC效率"使其在国内下行期的份额与利润率韧性优于行业（618白电三强集中度74%）。

## 三、供需边际与压力传导

### 3.1 供需平衡审计

| 维度 | 2024-2025 | 2026H1 | 趋势 |
| :--- | :--- | :--- | :--- |
| 中国终端需求 | 国补刺激下超常增长 | 零售额-6.2%（Q1） | ↓ |
| 渠道库存 | 高位积累 | 主动去化 | ↓ |
| 厂商排产 | 高排产 | 6月排产-11.8% | ↓ |
| 出口需求 | 温和增长 | 冰箱+13.7%/洗衣机+10.6% | ↑ |
| 原材料（铜） | 7-9万/吨 | 9.5-11万/吨（+33% YoY） | ↑↑ |
| 行业集中度 | 白电CR3约70% | 74% | ↑ |

**供需格局判断**：国内白电从紧平衡滑向阶段性过剩（需求收缩+高库存+新产能投放），但过剩压力正通过两条路径消化：①厂商主动控产去库（6月排产-11.8%）；②出口转移（冰箱出口+13.7%）。海外新兴市场供需边际仍偏紧（渗透率提升+本土产能不足）。**整体判断：2026年是"库存消化+份额集中"之年，价格战风险集中在空调品类（库存最高），冰箱/洗衣机格局更稳。**

### 3.2 压力传导特征分析

**传导路径一：国补退坡→终端需求收缩→渠道去库存→排产下调→价格竞争**
- 时滞约2-3个季度；终端需求下降1%→出厂量放大3-5%（牛鞭效应）；
- 海尔缓冲垫：TC统仓模式（2026Q1全域TC订单占比65%，+8pct）缩短渠道链路、降低库存占用，抗牛鞭效应能力提升。

**传导路径二：铜价高位+关税→制造成本↑→终端提价→需求抑制**
- 铜占空调整机成本20-30%，每吨+1万元→单台空调成本+200-300元；
- 2026年美的率先提价6%、海尔等跟进3%-10%，行业性提价2026Q1-Q2集中体现；
- 成本传导存在约1个季度时滞，2026Q1-Q2是验证窗口；
- 海尔对冲：供应商量价对赌+套保+战略备料（Q1应付周转+4.3天）+空调技术降本8%/年。

**传导路径三：北美关税+暴风雪→GEA收入利润承压→海外整体增速下修**
- 2026年1月美国对华加征关税（叠加此前301/232），GEA本土制造+墨西哥基地（USMCA零关税）规避主要关税，但中国进口组件成本上升；
- 2026年7月24日美国301条款对华新增10%-12.5%关税（家电未豁免，但高金属含量大家电已被232条款覆盖、不重复征收，主要影响低金属小家电）；
- 北美需求-10%（AHAM）叠加暴风雪，2026Q1海外收入-3.2%；
- 对冲：泰国冰箱厂100%承接对美大冰箱出口、墨西哥空调基地扩产、美国本土洗衣机/热水器基地建设。

**波动放大效应评估**：海尔面临"全球制造业成本上升（铜/铝/制冷剂）+ 国内需求收缩 + 北美关税冲击"的三重压力传导，但其缓冲垫（海外51.5%收入占比、本土化制造率、高端化溢价、TC渠道效率）使其在压力传导中处于行业相对有利位置——2026Q1剔除北美影响后经营利润仍增长10%以上即是证据。

## 【模块二强制复核项】

1. ✅ **终端产品景气度穿透**：已覆盖中国（-6.7%预测/Q1实际-6.2%）、北美（AHAM行业-10%、地产数据Census实测）、欧洲（GfK+高温）、新兴市场（印度/巴基斯坦/东南亚）四大区域的2026-2027年需求趋势，引用奥维/产业在线/海关总署/AHAM/美国人口普查局等多源数据。
2. ✅ **跨期需求移位审计**：明确识别2024-2025年国补创造的"需求前置"及其2026年兑现（Q1空调零售-13%），最悲观情景下2027年更新需求-19.4%的风险已量化。

## 四、模块二核心结论

1. **行业坐标**：中国白电处成熟期主动去库阶段，2026年总量-6~-7%负增长，存量博弈+份额集中（CR3=74%）；全球维度，新兴市场（海尔收入占比近10%且增速20-65%）与欧洲能效升级提供结构性增长。
2. **终端需求**：国内更新需求受国补退坡压制但高端/套系/AI升级托底；北美处地产底部（2027年降息修复为最大期权）；欧洲高温+能效法规双驱动；新兴市场高增长确定。
3. **供需与传导**：2026年行业从紧平衡滑向阶段性过剩，空调品类价格战风险最高；成本传导（铜+33%、关税）1个季度时滞，Q1-Q2为验证窗口。
4. **对海尔的净判断**：行业β整体为负（国内-6.7%、北美-10%），但海尔的结构α（高端卡萨帝、欧洲提效、新兴市场高增、TC渠道降本、出口对冲）足以支撑2026年营收持平微增（+0%~+3%）——这为模块五盈利预测提供需求侧基准。
