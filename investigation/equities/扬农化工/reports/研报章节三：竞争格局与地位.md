## 二、竞争格局扫描

### 2.1 行业金字塔与扬农化工的位置

全球农药行业呈清晰的三梯队格局：

| 梯队 | 代表企业 | 2025年植保营收 | 核心优势 |
| :--- | :--- | :---: | :--- |
| 第一梯队（国际巨头） | 先正达、拜耳、科迪华、巴斯夫、UPL | $80-170亿 | 创制药专利+种子+数字农业生态 |
| 第二梯队（中国龙头） | 安道麦、润丰股份、扬农化工、利尔化学 | ¥100-330亿 | 非专利药规模化+全品类+全球化渠道 |
| 第三梯队（区域/单品类） | 江山股份、利民股份、泰禾股份等 | ¥10-70亿 | 特色品种+成本优势 |

**关键发现**：扬农化工2025年营收118.70亿（+13.8%），增速在百亿级企业中位列第一，正在拉近与润丰股份的差距。

### 2.2 行业集中度演变

2025年农药行业CR10从34%快速提升至45%，规模以上企业数量持续缩减但平均产能规模扩大。核心驱动力：

1. **"一证一品"政策**（2026年1月实施）：同一登记证产品须标注同一商标，直接打击"借证"、"套证"的灰色产能，中小代工企业加速出清。
2. **"反内卷"三年行动**：中国农药工业协会主导，推动行业从"价格战"转向"有序竞争"。
3. **环保合规成本攀升**：江苏省2025年本《化工产业结构调整限制和淘汰目录》将草甘膦等27种农药列为限制类，地方政府严控新产能审批。
4. **并购整合提速**：利尔化学收购山东汇盟、泰禾股份收购瑞德丰、利民股份收购巴西登记证——头部企业通过并购加速做强。

**对扬农化工的影响**：行业集中度提升有利于龙头企业。扬农化工作为CR10核心成员，有望在"剩者为王"的淘汰赛中获取份额红利。

**2026Q3核心发现**：
1. **扬农是唯一实现Q3利润正增长的龙头**：润丰-37.28%、利尔-12.72%、新安转亏0.66亿、安道麦净亏1.15亿美元。扬农Q3净利率10.51%为同业最高（润丰5.16%、利尔4.23%、新安-1.74%、安道麦-12.8%），**在价格底部与成本冲击叠加期，菊酯/卫药的结构性定价权与中间体自供的护城河得到最直接验证**。
2. **但收入端扬农降幅最大（-13.51%）**：这是主动取舍的结果——收缩低毛利贸易（Q3贸易及其他6.19亿 vs 上年10.16亿，-39%）+ 保价保回款（应收-6.36亿、OCF+141.95%）。润丰Q3营收-7.12%归因"巴西旺季推迟+严格信用风险管控"，利尔/新安收入正增长但利润被汇兑与成本吞噬。**同业的共同选择是"以量换份额"，扬农选择"以份额换质量"**，孰优需2027年验证。
3. **汇兑是行业共性，扬农暴露最小**：润丰9M汇兑损失4.02亿（占其归母的56.5%）、利尔0.86亿（占其归母24.8%）、扬农财务费用恶化0.81亿（占其归母7.7%）。差异源于扬农境外收入中贸易占比高（可用美元采购自然对冲）与套保安排，这是被市场低估的相对优势。
4. **润丰的ToC转型仍在推进但短期承压**：9M Model C（ToC）占比47.63%（+6.24pp）、毛利率32.64%（+1.76pp），北美+欧洲收入占比由13.60%升至18.41%；但Q3归母-37.28%、扣非-52.04%，说明高毛利结构优化尚未能对冲汇率与巴西需求推迟。**竞争侧含义：润丰的渠道优势（9,700+登记证）仍是扬农制剂出海的长期压力，但短期其盈利波动性远高于扬农。**
5. **安道麦恶化、新安转亏，二三线产能出清加速**：安道麦Q3净亏扩大至$1.15亿、CEO将于11月离任、欧洲天气与需求疲弱；新安Q3归母-0.66亿（草甘膦Q3均价2.60万为全年低点+有机硅拖累）。**需求侧含义：全球龙头与国内二线同步亏损，说明Q3是行业盈利的最底部；竞争侧含义：亏损产能退出将加速，2027年供给格局改善的确定性提高。**
6. **利尔化学是草铵膦涨价的最大受益者（对扬农为间接利好）**：Q3营收+3.81%但归母-12.72%（汇兑0.43亿），草铵膦9月均价5.41万（+10.01% MoM/+21.63% YoY）、10-26报价7万、11-02报价8万；中金上调其2027年盈利预测22%至8.19亿。扬农自身不产草铵膦，受益路径为①行业涨价氛围外溢至除草剂整体定价 ②草甘膦2.60→2.90-3.00万（扬农3万吨产能）③草铵膦替代草甘膦对扬农草甘膦业务为结构性利空（需跟踪巴西禁用诉讼）。

### 3.2 分品类竞争格局

**① 杀虫剂（菊酯类）——扬农化工的"护城河"**

| 企业 | 菊酯产能 | 市占率（中国） | 技术特征 |
| :--- | :---: | :---: | :--- |
| **扬农化工** | 农用菊酯产能占全国23%（功夫菊酯）+18%（联苯菊酯），卫药2600吨 | 卫药~70%，农用~25% | 从基础化工到原药全链条，唯一自主中间体合成 |
| 印度企业（Tagros, Meghmani, Heranba） | 合计产能较大 | 全球~30% | 成本优势（劳动力），但中间体依赖中国进口 |
| 跨国公司（FMC, Syngenta, BASF, Bayer） | 专利菊酯品种 | 高端市场 | 品牌+登记壁垒 |
| 国内其他（北京颖泰等） | 产能较小 | <5% | 非全链条，成本劣势 |

**菊酯竞争壁垒的本质**：
- **工艺壁垒**：拟除虫菊酯合成路径长（10-15步反应），涉及贲亭酸甲酯、功夫酸、醚醛等关键中间体。2025年底贲亭酸甲酯因上游供应缩减涨至6万元/吨，功夫酸涨至11.5万元/吨，中间体自主供应成为核心竞争分水岭。
- **登记壁垒**：卫生用药需各国卫生部/农药管理部门的严苛审批，通常耗时3-5年，先发优势极强。
- **品牌壁垒**：扬农化工卫生用药"是国内外众多下游企业的首选品牌"——年报原话，品牌黏性高。

**② 除草剂——"被动参与者"，利润贡献有限**

| 品种 | 扬农化工产能 | 全球/中国排名 | 竞争烈度 |
| :--- | :---: | :---: | :---: |
| 草甘膦 | 3万吨 | 中国第6-8位 | ★★★★★（极度激烈） |
| 麦草畏 | 2.5万吨 | 全球第一 | ★★★（供给集中） |
| 烯草酮 | 产能不详 | — | ★★★★ |
| 硝磺草酮 | 收购中化作物获得 | — | ★★★ |

除草剂是扬农化工的"规模补充器"而非"利润发动机"。草甘膦面临兴发集团（磷矿一体化）、新安股份（有机硅协同）、福华通达等低成本竞争对手的挤压。麦草畏和硝磺草酮等差异化品种提供了一定的缓冲。

**③ 杀菌剂——"战略增长极"**

扬农化工通过自建优嘉项目+收购宝叶化工，形成了代森锰锌+吡唑醚菌酯+丙环唑三大全球前15品种组合，并在SDHI类杀菌剂（琥珀酸脱氢酶抑制剂）等新型方向布局。杀菌剂毛利率通常高于除草剂，是公司品类升级的重要方向。

## 四、护城河识别（Moat Analysis）

依据晨星护城河框架，扬农化工的五大竞争壁垒：

### 4.1 无形资产（品牌+专利+监管许可）——★★★★☆（宽护城河）

1. **卫生用药品牌**：国内+东南亚市占率~70%，全球第二大卫药供应商，客户黏性极强。该品类属于"类消费品"，下游对价格敏感度低，品牌溢价显著。
2. **农药登记证壁垒**：拥有数百个国内外农药登记证，海外登记（尤其是巴西5-8年审批周期）构成极高的时间壁垒。
3. **创制专利**：两个创制品种获ISO通用名（四氯虫酰胺、乙唑螨腈），全新机理创制药氟螨双醚预计2026年上市。氯氟醚菊酯等自主创制品种市占率稳中有升。
4. **国家级平台**：创成农业农村部杀虫剂智能创制重点实验室，入选国资委"科改"企业——这些机构的隐性价值在于优先获取政策资源、行业标准制定话语权。

### 4.2 成本优势——★★★★☆（宽护城河）

1. **中间体一体化**：国内唯一从基础化工原料到菊酯原药全链条企业，关键中间体（贲亭酸甲酯、功夫酸）自供比例高。2025年底中间体价格上涨时，竞争对手被迫高价采购，而扬农化工享受成本锁定优势。
2. **规模效应**：原药产能>10万吨/年，品类近70个，劳动生产率国际领先。
3. **制造工艺Know-How**：连续11种高危工艺工程化能力，本质安全水平行业领先；2025年降本9105万元，原药工厂大部分消耗指标同比持平或下降。
4. **绿色工厂集群**：4家原药工厂均为工信部绿色工厂（江苏优士、江苏优嘉、沈阳科创、辽宁优创），在环保监管趋严时代构成合规成本优势。

### 4.3 转换成本——★★★☆☆（中等护城河）

1. 农药原药客户切换需重新登记、做药效试验，时间成本1-3年。跨国农化公司对供应商稳定性要求极高，合作关系一旦建立不易更换。
2. 制剂端品牌效应：农户对"扬农"品牌认知度高，渠道和终端黏性较好。
3. 但大宗品种（如草甘膦）属于标准化产品，转换成本较低。

### 4.4 网络效应——★★☆☆☆（不适用）

农药行业不具备典型的网络效应（用户越多价值越大），但卫生用药在东南亚的渠道密度构成一定的"覆盖壁垒"。

### 4.5 有效规模——★★★☆☆（中等护城河）

中国农药行业严格的环保和安全生产监管形成了新进入者壁垒。江苏等核心省份限制新产能审批，存量优质产能具备稀缺性价值。

**综合护城河评级：宽护城河（Wide Moat）**。菊酯品类的技术壁垒+卫生用药的品牌垄断性+全链条成本优势，构成了竞争对手难以在短期内复制的综合竞争壁垒。

## 五、产业链定价权分析

### 5.1 对上游：议价能力强

| 指标 | 数值 | 解读 |
| :--- | :---: | :--- |
| 应付票据+应付账款 | 49.00亿（2026Q3） | 对上游占款能力突出 |
| 应付 vs 应收 | 49.00亿 vs 45.14亿（+3.86亿） | 净占用上游资金，OPM策略成功 |
| 前五大供应商集中度 | 19.4%（含关联方，2025年报口径） | 供应链分散，无单一依赖风险 |
| 中间体自供率 | 菊酯关键中间体自成体系 | 降低对外部供应商的依赖（Q3氯化亚砜+117%仍侵蚀毛利，说明自供并非全覆盖） |

关联方（先正达、中化国际等）采购占总采购额的12.35%，构成稳定的战略供应关系。

### 5.2 对下游：品类分化明显

| 品类 | 议价能力 | 证据 |
| :--- | :---: | :--- |
| 卫生用药（菊酯） | ★★★★★ 极强 | 市占率70%，客户首选品牌，定价权显著 |
| 农用菊酯 | ★★★★ 较强 | 品种齐全（50+种），技术壁垒高 |
| 草甘膦等大宗除草剂 | ★★ 较弱 | 标准化产品，跟随市场价格 |
| 制剂（品牌） | ★★★★ 较强 | 品牌溢价，渠道掌控力较强 |
| 贸易业务 | ★ 极弱 | 通道业务，毛利率仅7.27% |

**客户集中度风险与对冲**：
- 对控股股东先正达集团体系的关联销售36.98亿元（占营收31.2%，含同一控制下企业），存在较高的关联客户依赖度。由于双方同属中国中化体系，合作关系具有战略性质，集中度风险被关联属性部分对冲。
- 前五大客户合计销售37.47亿元（占31.57%），其中关联方36.98亿元、其余四家合计仅约0.49亿元，客户结构高度集中于中化体系。集中度较高但尚在可控范围（<50%红线），代价是议价独立性弱。

## 六、行业供给侧出清与扬农化工的受益路径

### 6.1 中小产能出清加速

"一证一品"+"反内卷"三年行动+出口退税取消三重政策叠加，正在系统性清除行业"劣币"：

- 依赖出租/借用登记证的中小企业面临合规困境，过渡期后将被清退
- 环保不达标产能加速关闭（江苏限制目录2025年本）
- 出口退税取消（草铵膦等）挤压低附加值出口商利润空间

### 6.2 扬农化工的受益逻辑

1. **市场份额提升**：落后产能退出→市场供给缺口→龙头填补。2025年扬农化工原药产量11.38万吨（+17.4%），远超行业产量增速（+12%），已在收获份额红利。**但2026Q3原药销量-1.64%（首次转负）表明份额提升在价格底部阶段性停顿，公司转向保价保回款；2027年份额逻辑需以优创二期放产为前提重启。**
2. **价格环境改善**：低效产能出清→价格竞争烈度下降→毛利率中枢上移。2026年8月至11月草铵膦+57%（5.1→8.0万元/吨）、草甘膦+12-15%（2.60→2.90-3.00万元/吨）、中农立华指数+4.5%并同比转正，是本轮出清首次在价格端兑现的实证；但传导至扬农菊酯主导的产品结构仍需时间（Q3联苯菊酯12.51万，-1.91% YoY）。
3. **政策资源倾斜**：作为"科改"企业+农业农村部重点实验室+中化央企体系，在行业标准制定、项目审批、环保豁免等方面享有"制度红利"。

| 品牌壁垒 | ★★★★★ | 卫药市占率70%，全球第二 |
| 成本优势 | ★★★★ | 中间体自供+10万吨规模+绿色工厂 |

**外部机构验证（2026年11月更新：三季报后一致下修）**：
- **摩根士丹利（6月18日）**首次覆盖，给予"增持"（Overweight），目标价71元（基于18x 2026E PE），认为"估值处十年低谷，当前交易于约14x 2026E PE、1.8x PB，接近十年底部，下行风险有限"。Q3业绩后尚未见更新。
- **东吴证券（10月30日）**点评三季报：下调2026-2028归母至13.84/15.39/17.58亿（原16.05/18.62/21.36），维持"买入"，核心逻辑为"农药价格底部彰显盈利韧性+创制新品有序推进、力争未来5年每1-2年推出1个新产品"。
- **国金/华创系（10月27-28日）**点评：①归母2026-2028年13.4/15.3/17.2亿（原16.8/19.3/20.9），维持"买入"，强调Q3毛利率稳定、减值转回、经营现金流改善；②另一家给出2026-2028收入122.21/137.92/148.46亿、归母13.79/17.96/20.60亿（EPS 3.40/4.43/5.08），维持"买入"，强调优创产能释放。

- **历史下调轨迹**：光大8/25 下调2026-2028至14.61/16.96/19.13亿（原16.54/19.31/21.01）；华泰8/25 下调至14.0/18.7/22.5亿（原17.5/21.3/24.0）、目标价62.64元（原77.76）；Q3后再下修一轮，**卖方一致预期已从"2026年15-16亿"降至"13.4-13.8亿"，两轮下修累计约-13%~-15%**。

**综合评分：在A股农药板块中，扬农化工的竞争壁垒位列第一梯队。** Q3单季同业普遍亏损而扬农逆势正增长（且增长质量有瑕疵），是护城河从"定性描述"转为"定量验证"的关键证据；但渠道端（润丰9,700+登记证、ToC 47.63%）与草铵膦品类（利尔）的比较劣势未改变。

在"剩者为王"的行业淘汰赛中，扬农化工凭借菊酯技术垄断+全品类布局+中化体系资源，具备穿越周期的综合竞争优势。其竞争地位将在行业复苏中转化为利润弹性——这也是下一模块（盈利预测）的关键嵌入变量。
