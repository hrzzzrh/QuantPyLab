# 研报章节四：外部边界与宏观政策

**研究日期**：2026年10月16日
**目标年份**：**2027年**（Q4切换期，框架「估值锚点切换」条款；2026E口径降格为对照）

---

> **目标年份切换说明**：本章宏观变量框架不变，但**油价、碳酸锂、关税、消费税与产业政策**五项关键变量已整体更新至2026年10月最新实测值，并重估其对**2027年**的传导方向与烈度。核心变化：油价自09-30的89.66美元升至10-14的95.09美元（**原"2026年基准75—90美元"假设已被现实证伪**）；碳酸锂跌至10.7万元/吨（利好锂电成本、削弱钠电经济性）；锂电消费税2027-09-01起升至4%、钠电免征至2028年底。

## 一、宏观环境变量

### 1.1 原油价格——改性塑料成本的"达摩克利斯之剑"

**当前状态**（截至2026年10月15日）：
- **WTI原油：2026年10月14日结算价95.09美元/桶（+1.01%）；10-15盘中约96.56美元，YTD +72.73%；布伦特10-14结算约105.35美元、盘中105—107美元，52周区间58.72—126.41美元。** 10月上行主因中东供给风险与俄罗斯柴油流向扰动（来源：每经2026-10-15、汇通网2026-10-15、Markets Insider）。[EIA](https://www.eia.gov/petroleum/supply/weekly/pdf/wpsrall.pdf)
- IEA 6月报告预计2026年全球石油需求同比下降1.1百万桶/日，**2027年供给可能增加约8百万桶/日**；短期供给扰动与中期供给过剩并存。[IEA](https://www.iea.org/reports/oil-market-report-june-2026)
- 核心驱动：霍尔木兹通行、停火执行和库存重建仍决定成本端波动。**本报告在09-30曾按"9月WTI 89.66美元"记录，10月已进一步上行至95.09美元，原"2026年基准75—90美元"假设被现实证伪**，2027年油价情景因此整体上移。

**2027年油价情景**（外部预测未经本地验证）：

| 机构/情景 | 2027年均价预测 | 逻辑 |
|:---|:---|:---|
| 短期压力情景（保守，对普利特） | **95—105美元** | 海峡风险与地缘溢价延续，库存偏低，成本压力不缓解 |
| 基准情景 | **80—90美元** | 运输恢复、IEA 2027年供给增加约8百万桶/日逐步兑现，价格高位回落 |
| 中期缓解情景（乐观，对普利特） | **70—80美元** | 供给过剩预期提前交易、需求走弱 |

**对普利特的影响机制**：

```
油价上涨10% → PP/ABS单体上涨15-20% → 改性料成本上涨8-12% → 毛利率压缩3-5pct
```

定量测算：普利特改性材料业务年营业成本约54亿元（2025年），其中原材料成本占70%即~38亿元。若油价中枢从60美元升至90美元（+50%），原料成本可能上升15-20%，即增加5.7-7.6亿元，对应毛利率压缩6-8个百分点（若无涨价传导）。

**2027年关键判断**：**油价是2027E盈利预测中权重最高的外部变量**。2027E基准（改性材料毛利率14.0%）建立在WTI回落至80—90美元的中性假设上；若WTI维持95—105美元（当前水平的延续），基准毛利率应下移至12.0—12.5%，对应2027E基准归母从3.40亿元降至1.5—2.0亿元（见章节五保守情景）。**这是本次目标年份切换后最重要的单一敏感性**。

### 1.2 碳酸锂价格——电池业务的双刃剑（2027E方向已反转）

**当前状态**（截至2026年10月14日）：
- **电池级碳酸锂现货约10.7万元/吨**（生意社10-14基准价111,000元/吨、工业级108,000元/吨；Mysteel 10-09晚盘电池级118,500—122,000元/吨后继续下行）；**期货主力合约10-14报103,500元/吨（-1.88%），10-12单日-10.59%首次跌破11万元关口**。[生意社](https://m1.100ppi.com/sf/pic-1162-碳酸锂-1275.html)
- 较09-30的约12.0万元/吨下跌约10.8%，较08-31的15.6万元/吨下跌约31%。
- 矛盾结构："强现实（Q4去库加速、10月排产环增、库存天数或降至15天）、弱预期（远期供给宽松+需求旺季证伪）"，定价由远期悲观预期主导。

**2027年预期**：

| 情景 | 价格区间 | 触发条件 |
|:---|:---|:---|
| 基准 | **10—13万元/吨** | 储能需求高增对冲供给释放，成本曲线托底 |
| 乐观（对锂盐企业） | 13—18万元/吨 | 供给扰动+补库 |
| 悲观 | **8—10万元/吨** | 澳矿复产+津巴布韦到港+需求不及预期（当前盘面已部分定价） |

**对普利特的三重影响（2027E口径）**：

1. **锂电业务（成本端利好）**：碳酸锂占电芯成本约40—50%，价格从15万+降至10.7万显著降低材料成本。**但这一利好被两项因素对冲**：① 314Ah电芯价格竞争充分，成本下行同步传导至售价；② **锂离子蓄电池消费税2027-09-01起升至4%**（2026-09-01起为2%），对薄利的锂电业务构成直接侵蚀。2027E基准电池毛利率因此仅按6.8%（2026E为6.2%、H1实测6.92%）。

2. **钠电业务（成本优势收窄，方向反转）**：**碳酸锂越贵，钠电相对成本优势越突出**。锂价从15万+跌至10.7万，使"钠电经济性临界点"被推远。国金证券测算当碳酸锂突破16万元/吨时锂电池规模化成本优势显著收窄，而当前价格远低于该阈值（二手线索）。**2027年钠电的核心支撑从"成本平价"转为"消费税免税+宽温域+长循环"的非价格优势**：锂电2027-09起税负4%、钠电免征至2028年底，形成2—4个百分点的税负剪刀差。此外，河北任丘100MW/400MWh混合储能项目钠电系统中标价1.035元/Wh，约为磷酸铁锂标段两倍，说明钠电在大型项目上仍存价格溢价。

3. **改性材料业务（中性）**：锂价通过新能源汽车销量间接影响需求。当前锂价处于低位，不构成对NEV销量的抑制。

### 1.3 汇率——对出海产能的隐性影响

普利特有马来西亚、墨西哥、德国、美国等海外基地。人民币汇率波动影响：
- 人民币贬值（如2025年趋势）：利好出口竞争力，海外收入折算人民币增加
- 人民币升值：压缩海外基地利润

2026年人民币在7.1—7.3区间波动，总体稳定，汇率风险可控。

## 二、地缘政治与贸易壁垒

### 2.1 中美贸易战：电池出口的"定向狙击"

**关税升级路径**（2025-2026年）：

| 时间节点 | 事件 | 储能电池关税 |
|:---|:---|:---|
| 2025年初 | 基础关税 | 10.9% |
| 2025年4月 | 对等关税125% + 芬太尼20% | **114.9%** |
| 2026年1月 | 301条款储能电池关税生效（25%） | **139.9%** |
| 2026年4月 | 再加征50% | **173%** |

**对普利特的具体影响**：

1. **直接出口**：海四达对美国直接出口储能电池的比例不详，但整个行业对美出口占比已从25%（2024年）降至9.7%（2026年1-2月）。高关税已基本关闭美国市场大门。

2. **转口贸易**：马来西亚基地（2.5GWh，2026年3月投产）仍有供应链分散价值，但美国2026年7月针对包括马来西亚在内的经济体提出10%的Section 301关税安排，且具体产品税负叠加和原产地认定仍需逐项核实，不能再按“低关税通道”直接计入期权价值。[白宫文件](https://www.whitehouse.gov/presidential-actions/2026/07/actions-by-the-united-states-in-the-investigations-under-section-301-of-the-trade-act-of-1974-of-the-acts-policies-and-practices-of-60-economies-related-to-the-failure-of-each-economy-to-impose-and-effectively-enforce-a-prohibition-on-the-importation-of-goods-produced-with-forced-labor/)

3. **市场替代**：欧洲电池产业政策正在强化本地制造。欧盟2026年6月设立最高15亿欧元Battery Booster，项目需位于欧洲经济区且最低产能10GWh；这对中国电池企业是需求机会，也是本地化竞争门槛。[欧盟委员会](https://climate.ec.europa.eu/news-other-reads/news/new-battery-booster-set-inject-eu15-billion-european-battery-industry-2026-06-09_en)

4. **改性材料出口**：汽车用改性材料未被单独针对，但汽车零部件（含材料）出口若受到整车关税波及，间接受影响。目前普利特改性材料以内销为主，出口敞口较小。

### 2.2 地缘政治：中东冲突的"蝴蝶效应"

2026年Q1-Q2的中东冲突对普利特构成了一系列间接但深刻的影响链：

```
中东冲突 → 霍尔木兹海峡中断 → 原油供给缺口
    ├─→ 油价飙升 → 改性材料原料涨价 → 毛利率压缩（直接利空）
    ├─→ 能源安全焦虑 → 欧洲加速新能源部署 → 储能需求增加（间接受益）
    ├─→ 石脑油涨价 → 化工品全线上涨 → PP/ABS成本全面抬升（直接利空）
    └─→ 航运保险费飙升 → 全球贸易成本增加 → 出口竞争力受损
```

**净影响评估**：对普利特而言，中东冲突的利空因素（原料涨价）远大于利好因素（储能需求）。公司是原料的消费者而非生产者，高油价周期天然不利。

### 2.3 China+1与供应链重构

"去中国化"的供应链转移趋势对普利特而言是**双面效应**：

- **威胁**：若汽车主机厂（宝马、奔驰等）要求供应链本地化（如欧洲本地采购改性材料），普利特可能失去部分出口订单。
- **机遇**：普利特已在德国（Pret Europe GmbH）和美国（PRET Advanced Materials, LLC）布局产能，具备跟随客户本地化生产的能力。马来西亚、墨西哥等基地进一步分散了地缘风险。

## 三、监管与产业政策

### 3.1 "十五五"新材料规划——LCP的国家级背书

"十五五"规划纲要（2026年3月发布）将新材料列为**战略性新兴产业的核心方向**，明确提出：

> "聚焦战略必争领域和产业链关键薄弱环节，采取超常规措施，全链条推动……关键材料……攻关取得决定性进展。"

**LCP直接受益的政策条款**：

| 政策方向 | 具体措施 | 对普利特LCP的影响 |
|:---|:---|:---|
| 关键材料自主可控 | 国产替代率目标80%+ | LCP作为"卡脖子"材料，享受采购优先 |
| 首批次应用保险补偿 | 国产新材料首批次应用享受政策保险 | 降低下游客户试用风险，加速验证 |
| 重大工程优先采购 | 政府采购和重大工程支持国产创新产品 | 5G基站、卫星等项目可能指定国产LCP |
| 研发专项支持 | 100个研发专项，每个2000-8000万元 | LCP产业化可能获得直接资金支持 |
| 时间表 | 2027-2028突破关键技术，2029装备国产化 | 与普利特LCP放量时间节奏吻合 |

**政策确定性评估**：★★★★★。新材料国产替代是中国"十五五"最明确、最不可逆的政策方向之一，LCP作为被美日垄断的"卡脖子"材料，政策加持持续性极高。

### 3.1.1 电池消费税调整——2027年"锂负钠正"的税负剪刀差

财政部、海关总署、税务总局联合发布《关于调整部分电池消费税政策的公告》（**财政部 海关总署 税务总局公告2026年第20号，2026-07-16**）：**锂离子蓄电池自2026-09-01起按2%税率征收消费税，2027-09-01起升至4%**；**钠离子电池、固态电池、燃料电池免征，免税窗口覆盖2026-09-01至2028-12-31**。同时，钠离子蓄电池自2026-09-01起获得独立海关商品编号（经新京报2026-07-17公告全文、上海证券报2026-07-18、国家税务总局山西省税务局2026-07-22热点问答双源交叉核验；征管细则见国家税务总局公告2026年第16号，2026-07-31）。

**对普利特的量化影响（2027E）**：
- 锂电业务：按2027E锂电营收约55亿元估算，消费税全年加权约2.7%（1—8月2%、9—12月4%），**直接成本约1.5亿元**（占2027E基准归母3.40亿元的44%）。本报告已将该税负计入电池分部毛利率（6.8%，较无税情形低约0.5—0.7pct），**不再在估值矩阵中重复扣减**（见章节六逻辑纯净性校验）。
- 钠电业务：免征至2028年底，相对锂电形成2—4个百分点的成本优势，是2027年唯一明确有利于普利特的行业级政策变化。
- **净效应**：普利特钠电体量（6GWh规划、一期2GWh）远小于锂电（15.32GWh+新增6GWh），**税负剪刀差对公司整体是净负向**——免税红利难以覆盖锂电的增税成本。

### 3.1.2 新型电池产业"十五五"规划（2026-09-29）

工业和信息化部、国家发展改革委等**七部门联合印发《新型电池产业发展"十五五"规划》**，明确提出构建"以锂电池为主，钠电池、液流电池等协同发展"的新型电池产品供给体系，强调充分发挥钠电池成本、安全性和资源保障优势，加快关键材料研发与应用，开发高安全、高经济性、长循环寿命储能电池（来源：行家说储能2026-09-29转述）。

**对普利特的含义**：钠电首次被写入国家级产业规划，政策确定性由"储能政策顺风"升级为"国家产品体系定位"，有利于普利特（海四达）钠电的客户导入与地方政府配套（内江已出台《钠电产业发展工作方案（2026-2030年）》与九条措施）。但**政策无法替代订单**——截至08-18互动易，公司钠电业务"整体销售额占营业收入比例较小，短期内难以对经营业绩产生重大影响"。

### 3.2 新能源汽车补贴退坡——双刃剑

2026年新能源汽车购置税从0%提高至5%，国补政策存在退坡可能。影响：
- **利空销量端**：可能抑制2026年NEV销量增速（中汽协预计+15.2%，但部分券商预测仅+6-11%）
- **利好格局端**：补贴退坡加速行业洗牌，头部车企（普利特的主要客户比亚迪、吉利等）市占率提升
- **净影响**：若NEV销量增速放缓至个位数，改性材料的需求增量将收窄，产能消化压力增大

### 3.3 新型储能政策——钠电的政策顺风

《新型储能制造业高质量发展行动方案》等政策明确：
- 到2027年累计装机达1.8亿千瓦（180GW）以上
- 培育3-5家生态主导型企业
- 支持钠离子电池等多元化技术路线

普利特（海四达）的钠电池储能业务处于"政策顺风+技术差异"叠加的有利位置。南网30MWh标杆项目的落地也获得了电网侧的政策认可。

### 3.4 环保与安全约束

- 改性塑料行业面临日益严格的VOC排放标准和阻燃剂环保要求
- 电池行业面临安全生产检查和危化品管理趋严
- 这些约束对头部合规企业是利好（淘汰不规范小厂），但合规成本也在上升

### 3.5 储能产业规范与数据合规

国家能源局发布的《中国新型储能发展报告（2026）》确认储能和算电协同仍处于政策支持方向，但行业正在从单纯扩产转向安全、长寿命、低成本和系统集成能力竞争。欧盟2026年7月启动电池数字产品护照注册测试，部分大型电池的首个实施节点为2027年2月18日；欧盟净零工业法的公共采购和新能源拍卖还将纳入韧性、网络安全、数据安全和交付能力等非价格标准。对普利特而言，这些政策支持储能长期需求，却会提高其海外产品认证、追溯和本地化交付成本。[国家能源局](http://www.nea.gov.cn/20260730/0a1e9823b7a14e8ba16e82c34b3bea2b/c.html) [欧盟委员会](https://single-market-economy.ec.europa.eu/news/digital-product-passport-registry-now-live-2026-07-20_en)

## 四、综合宏观风险矩阵

| 变量 | 对普利特的影响方向 | 影响烈度 | 确定性 | **2027E展望** |

## 五、章节结论

**宏观环境对普利特构成"短期压力再起、中长期政策利好与竞争门槛并存"的不对称格局（2027E口径）**：

- **短期（6-12个月）**：**油价在10月逆向上行**（WTI由09-30的89.66升至10-14的95.09美元，Brent 105—107美元），使2026H2毛利率修复情景进一步弱化，2026E基准（归母1.15亿）面临下修压力；碳酸锂跌至10.7万元/吨利好电池成本但削弱钠电经济性，两者方向对冲。
- **中期（1-3年）**：十五五新材料政策、新型电池"十五五"规划（09-29七部门印发）与钠电免税窗口支持LCP与钠电需求，但CATL/比亚迪钠电规模化、全球电池产能过剩、锂电消费税4%（2027-09起）与欧盟本地化/数字护照规则同步抬高竞争与合规门槛。
- **核心矛盾（2027E）**：**原材料成本与资本开支压力即时兑现，LCP国产替代和钠电政策红利需要订单、利用率和现金流验证**。2027年的宏观环境比2026年更"不对称"——油价上行是已发生的利空，钠电免税是已公告的利好，但利空的体量（锂电消费税约1.5亿元、油价压制改性毛利1—2pct）大于利好的可兑现体量（钠电营收占比仍小）。公司未来12个月应先经历"三季报（10-29）确认→年报验证→新增产能建设与订单核验"，再讨论估值修复。

在下一模块的盈利预测中，我们将把这些宏观变量量化为具体的毛利率假设、营收增速预期和利润弹性。**本次已量化为2027E三态：基准改性材料毛利率14.0%（WTI 80—90美元）、电池毛利率6.8%（含消费税）、LCP毛利率36%。**
