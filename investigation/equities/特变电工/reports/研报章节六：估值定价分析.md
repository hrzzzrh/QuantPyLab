## 一、价值锚定：适配性方法选择

### 1.1 估值方法选择理由

特变电工作为多元化能源装备制造企业，具备以下特征：
- **商业模式**：四大产业协同，涵盖输变电、多晶硅、煤炭、新材料
- **资产属性**：重资产型企业，固定资产和在建工程占比较高
- **现金流特征**：经营现金流较为稳定，但受多晶硅周期影响波动较大
- **生命周期**：输变电处于成长期，煤炭处于成熟期，多晶硅处于调整期

基于上述特征，选择以下估值方法进行交叉验证：

| 估值方法 | 适用性 | 选择理由 |
|:---------|:-------|:---------|
| **PE（市盈率）** | 主要方法 | 盈利可预测性较强，适合成熟期企业估值 |
| **PB-ROE** | 辅助方法 | 重资产型企业，净资产是重要参考 |
| **SOTP（分部估值）** | 辅助方法 | 四大产业属性差异大，分部估值更准确 |
| **PEG** | 参考方法 | 反映成长性估值 |

## 二、估值全变量对冲审计矩阵

### 2.1 审计矩阵

| 审计维度 | 核心审计因子 | 审慎思考（估值影响力过滤） | 调节建议 | 深度理由 |
|:---------|:-----------|:-------------------------|:---------|:---------|
| **内部：企业底层特质** | 四大产业协同效应、自主创新能力强、管理层稳定 | 四大产业协同是真正的稀缺性，能够抵御单一行业周期波动，但并非独有优势 | +3% | 协同效应增加了长期确定性，但溢价空间有限 |
| **宏观：政策与战略对齐** | 国家电网十五五4万亿元、全国电网投资5万亿元以上、15回左右特高压直流、西电东送>4.2亿千瓦；**H1证伪：多晶硅“反内卷+能耗新标”尚未转价格（N型5.92→3.28万-44.59%），时滞12-18个月** | 电网投资政策直接利好输变电业务且已在利润预测中体现；多晶硅政策利好中期但2026年不计入PE（避免重复计算） | **+1%** | 政策确定性提升估值中枢，但多晶硅政策时滞扣减1% |
| **宏观：地缘与外部约束** | 中东冲突推升油价、贸易摩擦、汇率波动 | 中东冲突短期利好能源业务，但属不可持续因素 | -2% | 地缘风险带来不确定性，需适度折价 |
| **市场：流动性与风格** | 机构持股集中度适中、当前市场偏好成长股 | 公司兼具成长和价值属性，风格契合度较高 | +2% | 流动性溢价适中 |
| **综合调节系数** | - | - | **+4%** | 修正目标市值 = 中性情景市值 * 1.04（原+5%中政策+2%→+1%） |

> **调节适用范围说明**：审计调节仅应用于**中性情景市值**（1,500亿→1,575亿）。保守/乐观情景保持各自情景市值（1,000亿/2,000亿），避免在情景假设中已包含的极端情形上重复叠加调节——保守情景已按60亿净利的悲观假设定价，乐观情景已按100亿净利与22倍PE的高景气假设定价，审计因子（协同溢价、政策对齐、地缘折价、流动性）只对估值中枢（中性）生效。

### 2.2 逻辑纯净性校验

**已在利润预测（E）中体现的因素**：
- 电网投资增长带来的输变电业务增长
- 多晶硅行业出清带来的毛利率回升
- 规模效应带来的费用率下降

**需在估值倍数（PE）中体现的因素**：
- 四大产业协同效应的稀缺性溢价
- 政策确定性带来的估值中枢提升
- 地缘风险带来的不确定性折价

**校验结论**：未发现重复计算

### 2.3 锚点回测（2026-08-22裁决修正）

修正后隐含PE（中性情景）：
- 修正后市值 = 1,500亿 * 1.04 = 1,560亿（原1,575亿按+5%计，本次政策下修1%至+4%）
- 隐含PE = 1,560亿 / **63亿** = **24.8倍**（原20.2倍按78亿计已作废）
- 近5年PE均值：12.13倍（中位数11.03倍）
- 偏离幅度：+104%（实测PE-TTM 19.03已处高位，中性24.8倍需以特高压高成长消化）

**偏离理由**：
1. 当前处于盈利回升期，PE理应高于历史中枢
2. 2022-2023年多晶硅暴利导致PE极低，拉低了历史中枢
3. 十五五电网投资超预期，行业景气度显著提升
4. 公司四大产业协同效应提供了估值支撑

**加权目标价** = 19.92 * 25% + 31.07 * 55% + 39.84 * 20% = 4.98 + 17.0885 + 7.968 = **30.04元**（原30.20按78亿/1,575计已作废；现按63亿/1,560计，中性隐含PE 24.8x）

**上行空间**：**49.8%**（20.05→30.04）；旧50.6%按30.20计已作废。

### 3.3 盈亏比计算（裁决修正）

**盈亏比（07-29口径作废）** = (30.20 - 20.65) / (20.65 - 19.92) = 9.55 / 0.73 = 13.08

**盈亏比（08-20旧口径作废）** = (30.20 - 20.05) / (20.05 - 19.92) = 10.15 / 0.13 = 78.08

**盈亏比（08-22新口径）** = (30.04 - 20.05) / (20.05 - 19.92) = 9.99 / 0.13 = **76.85**

> 按框架公式，盈亏比分子必须采用三态概率加权目标价，分母采用未调节保守目标价19.92元；当现价≥保守价时直接计算。现价20.05元距保守价仅0.13元，比值对分母极度敏感，**绝对价差仅0.13元（-0.6%下行空间）不构成安全垫**，数值76.85仅作赔率刻画，**现价距保守价<1%不构成买入安全边际，需等待63亿盈利锚定与08-26业绩会再定仓位**。

**评估（裁决修正）**：盈亏比由13.08→76.85仍因股价贴近保守价而非盈利上修；实测PE-TTM 19.03已处高位、中性24.8x需高成长消化，技术面全空头（跌破MA5/10/20/60/120/250）、H1归母-19.84%显示盈利质量仍弱，**追高风险>赔率诱惑**，仓位应以半年报正式披露与08-26业绩会为分水岭，控制底仓、等待盈利预测二次验证后再定加仓节奏。
