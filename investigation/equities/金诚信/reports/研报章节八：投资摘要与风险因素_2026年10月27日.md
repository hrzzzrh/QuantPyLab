## 三、研究结论象限图

基于全维研究，将金诚信定位如下：

```
预期收益空间
    ↑ 高
    |
|  第二象限                第一象限
|  (Speculative Growth)    (High-Conviction Buy)
|
|
|                              ↑
|                              |
|  第四象限 ★              第三象限
|  (Avoid/Wait)            (Defensive Value)
|       金诚信(603979)
|       确定性: 3.5/5.0
|       预期收益: +15.3%(概率加权)
+--------------------------------→ 确定性
    低                              高
```

**最终评级**：**第四象限——Avoid/Wait（持有/观望，由"增持"下调；确定性3.5/5.0低于4.0高确定性阈值，概率加权收益+15.3%低于20%高收益阈值，盈亏比0.34不占优）**

**评级依据（10-26价57.13元）**：

1. **确定性（3.5/5.0，由4.2下调）**：Q3铜产量2.53万吨、销量2.38万吨低于旺季预期，全年计划完成率72.08%/67.13%，Q4兑现压力上升；**Q3铜业务毛利率约50.4%，较H1约57.7%下滑7.3pct，铜单位成本由3.65升至4.30万元/吨**；Dikulushi储量仅39万吨，2028年后产量下滑；汇兑损失2.3亿元、自由现金流仅1.25亿元、H股进度停滞。仍维持3.5分（而非更低）的理由：矿服毛利率26.69%、Lonshi西区稳产、铜价中期缺口、181亿元在手合同。
2. **预期收益（+15.3%概率加权/ +8.4%中性，赔率不佳）**：中性61.9元（+8.4%）、概率加权65.9元（+15.3%）；2027E Forward PE 11.0倍（57.13/5.18）+PEG约0.63；**盈亏比仅0.34，较10-12的4.61大幅回落，上行期望远小于下行风险**。
3. **下行风险（-46.1%至地狱30.8元，-45.4%至保守31.2元）**：下行风险显著，尤其铜价跌破11,500美元或Q4销量不及2.8万吨时。

**核心判断**：金诚信的"矿服+资源"双轮驱动逻辑未破，2026年1-9月归母+41.83%、矿服毛利率修复至26.69%，基本盘仍扎实；但Q3的边际走弱（铜销量、**铜主业毛利率环比-7.3pct**、汇兑、现金流）与盈利预测下修37.9%使"深度低估"叙事失效——**10月股价-23.9%，但盈利下修-37.9%，下修幅度大于股价跌幅，估值并未因下跌而变得更便宜；当前是"估值处于历史底部、但赔率不占优"**。**操作：不追跌、不抄底**——现价57.13元已跌破原63-68元止损观察区（原止损触发，按纪律应已减仓），等待①Q4铜销量回补至3.0万吨以上、②放量收复59-62元（第一阻力）并进而收复63-68元（MA20/120/250密集区）、③H股备案/递表落地三者至少两项，再考虑分批试探；已持有者以52.39元（52周低点）为最后止损线；核心跟踪为Q4产销数据（2027年1月业绩预告）、2027年产量指引、H股监管核准、刚果（金）专项合规方案。
