## 一、价值锚定——适配性方法选择

### 1.1 方法论选择与理由

安琪酵母作为重资产消费品龙头，采用以下方法交叉验证；本次调整了权重结构：

| 方法 | 适用理由 | 权重 | 权重设定理由 |
|:---|:---|:---:|:---|
| **PE估值法**（主） | 盈利可预测，行业龙头有明确可比PE区间 | **70%** | 公司进入CAPEX密集投放期，DCF被终值与资本开支路径主导、对参数极度敏感；PE更贴近市场实际定价，且盈利下修已由E承担 |
| **PB-ROE法**（辅） | 重资产属性，ROE与PB存在理论映射关系 | **30%** | 净利率波动加大（Q3单季6.6%），PB-ROE对利润噪音不敏感，可对PE形成资本回报约束 |
| **DCF法**（交叉验证，不计入目标价） | 现金流与资本开支周期需建模 | 0%（参考） | 2027-2028年CAPEX约17-20亿元/年使自由现金流接近零，DCF价值约80%来自终值；且Bear情景DCF已低于清算底价，不具备情景定价功能，仅作合理性校验 |

**权重设定说明**：本报告核心矛盾是"ROIC 8.91%低于WACC + CAPEX密集"，而PE恰是不反映资本消耗的方法，因此该风险不以降低PE权重的方式表达，而是以中性档审计矩阵中的"资本配置折价-3%"显式扣除（见§六）。PB-ROE（30%）从资产回报角度提供第二重约束：其Base参考价31.30元显著低于PE法44.95元，两者差距即"利润率能否修复"这一核心不确定性。DCF仅作合理性校验（Base 38.69元，与现价38.20元几乎重合），不作为定价输入。

### 1.2 历史估值分位审计——点时口径

**11-06快照（`v_daily_valuation`实测）**：

| 指标 | 当前值 | 10年分位（参考） | 说明 |
|:---|---:|---:|:---|

| PB | 2.59x | 约2.8% | 同一样本（PB<20x过滤）；PB分位已降至10年最低区间 |

**价格路径与估值含义**：
- 10-14收盘39.01元 → 三季报（10-29盘后/10-30公告）后10-29收35.95元（-2.8%）、10-30盘中最低33.14元（-7.8%）收35.56元；随后11-02至11-05连续四日反弹至38.65元，11-06收38.20元。**即：三季报的利空在10-30单日被完全定价（盘中33.14元对应约18.0x PE TTM），随后市场按"Q3是运费/汇兑/补助一次性冲击、糖蜜红利仍在"的逻辑修复**。

**PE倍数选择逻辑（盈利已下修约11%，倍数不再叠加折价，风险由审计Σ承担）**：

## 三、PB-ROE法——交叉验证（2027E口径）

### 3.1 理论基础与参数设定

合理PB = (ROE − g) / (r − g)，r为权益资本成本，g为永续增长率。

**参数设定**：
- 2027E ROE采用Bear/Base/Bull工作值10.34%/13.85%/17.25%（分母为2027年初与年末归母权益均值，年初权益已含2026Q4留存利润）
- g（永续增长）= 3.5%，r（权益成本）= 9%
- 年末BPS按Q3末归母权益128.0146亿元 + 2026Q4留存 + 2027E利润留存（分红率30%工作假设）推算：
  - Bear：128.0146 + 3.27×0.7 + 13.99×0.7 = 140.10亿元 → BPS约16.14元
  - Base：128.0146 + 4.22×0.7 + 19.07×0.7 = 144.32亿元 → BPS约16.63元
  - Bull：128.0146 + 5.39×0.7 + 24.19×0.7 = 148.72亿元 → BPS约17.14元

注：分红率30%依据公司2026-2028年股东回报规划（现金分红与回购合计不低于年净利润30%），该规划经高盛2026-09-24研究摘要转述，本轮未取得公司公告原文，属待核验假设；若分红率提升至40%，BPS下降约0.2元（影响PB价格不足1%）。

### 3.2 PB-ROE综合结论（2027E）

| 情景 | 稳态ROE | 合理PB | 合理股价 |
|:---|:---|:---|:---|
| 保守 | 10.34% | 1.25x | 20.09元 |
| 中性 | 13.85% | 1.88x | 31.30元 |
| 乐观 | 17.25% | 2.50x | 42.83元 |

PB-ROE给出的估值显著低于PE法，原因是资产周转与现金流尚未证明ROE能回到16%以上，且CAPEX/折旧持续压制。当前实际PB 2.59x高于Base合理PB 1.88x，说明市场仍在为"ROE将修复"付费。若2027年ROE实现13.85%，PB的合理中枢为1.88x（对应31.30元）；PE法给出的44.95元隐含PB约2.70x。

**该分歧本身是核心信号**：PE法假设盈利可延续，PB-ROE假设资产回报回归。两者差距（40.86 vs 31.30）反映"利润率能否修复"的核心不确定性。综合目标取70/30加权，即偏向PE但保留PB-ROE约束。

## 四、DCF估值法（交叉验证，2027E口径，不计入目标价）

### 4.1 关键假设

| 参数 | 假设值 | 逻辑 |
|:---|:---|:---|
| 预测期 | 2027-2031（5年） | 覆盖产能投放与折旧周期 |

| CAPEX路径（Base） | **20/17/10/8/8亿元** | 按已公告项目（宜昌9.70亿+可克达拉8.45亿+白洋二期10.61亿+复配1.35亿+水解糖1.01亿+印尼/俄罗斯尾款+维护性capex）测算；2026年实际CAPEX约17亿元为起点 |

| **概率加权** | **2.044元（摊薄后）** | **39.18元** | **+2.6%** | — | **340.0亿元** |

### 7.2 盈亏比计算（2027E口径）

```
盈亏比 = (概率加权目标价 - 现价) / (现价 - 保守价)
        = (39.18 - 38.20) / (38.20 - 25.96) = 0.98 / 12.24 = 0.08
```

现价高于Bear目标价，框架盈亏比适用，为**0.08**（上版0.39）。含义：每承担1元下行风险，仅对应0.08元期望收益；赔率已接近失效但未转负。

**当前结论**：2027E产能投放（印尼2万吨+酵母蛋白1.2万吨）仍提供盈利增量（Base归母较2026E +19.6%），但毛利率失守使增量质量下降；Base修正目标37.18元已低于现价38.20元2.7%，概率加权目标39.18元仅高出2.6%。评级由"中性偏积极（第三象限边界）"下调至**"中性/观望（第三象限下沿，接近第四象限）"**：等待11-10三季度业绩说明会、26/27榨季首轮糖蜜拍卖、以及Q4毛利率能否站上23.5%后再评估是否上调。

## 八、逻辑证伪与极限压力测试

### 8.1 "一击毙命"黑天鹅场景

**定义**：单一事件"埃及核心工厂因外汇/物流或地缘冲击停产6个月且利润汇回受阻"。埃及子公司H1净利润2.1256亿元，但合并口径海外利润占比未取得，因此不把停产损失机械外推为集团净利润点估计。

**可复核压力桥**：事件发生时先暂停海外利润和汇兑修复假设，使用可核验的归母有形净资产作为极限锚。按Q3末归母权益128.0146亿元、商誉2.0229亿元、无形资产7.7461亿元按20%折价：

```
极限参考价 = (128.0146 - 2.0229 - 7.7461×20%) / 8.67815671 ≈ 14.34元/股
```

该数值是清算/极端资产折价参考，不是对单一停产事件的盈利损失预测。

### 8.2 清算价值锚定（终极底线）

- 净资产（归母）采用2026Q3末128.0146亿元
- 扣除商誉2.0229亿元 + 无形资产重估折价20%（约1.55亿元）
- 有形净资产约124.4亿元 / 8.68亿股
- **清算底价 ≈ 14.34元/股**（因Q3利润留存上移）

这代表了"公司破产清算"级别的终极安全垫，几乎不可能触发，但提供了极端风控参考。注意：DCF Bear参考价16.26元已接近该底线，说明Bear情景的现金流假设接近"永续低回报"状态。

## 九、逻辑纯净性校验

### 9.1 "E"与"PE"边界清晰化

| 已体现在"E"（利润预测）中的因素 | 应体现在"PE"（估值倍数）中的因素 |
|:---|:---|
| 糖蜜成本（甘蔗蜜800元下方、甜菜蜜预售反升） | 全球化消费品牌稀缺性溢价 |
| 海运费与汇率的2026实际冲击、2027缓和假设 | 管理层资本配置能力的信任度（本次转为折价） |
| 酵母蛋白1.2万吨投产的方向性贡献 | 埃及/俄罗斯地缘不确定性 |
| 政府补助与税率的正常化 | A股消费板块整体估值水位 |
| 制糖业务负毛利的结构性拖累 | 可转债摊薄与治理透明度 |

**关键校验**：本次毛利率下修（-1.15pct）与PE维持22x不构成双重计提——前者是已实现的具体成本与结构变化，后者未因同一因子再降倍数；新增的-4pct审计折价对应的是"资本配置效率"与"埃及宏观逆转"两项不可计算风险，与E中的成本项不重叠。

### 9.2 隐含PE回测

| 情景 | 目标价 | 隐含2027E PE（摊薄后） | 与历史比较 | 与同业比较 |
|:---|:---|:---|:---|:---|
| 保守 | 25.96元 | 17.3x（综合隐含） | 反映糖蜜红利耗尽/海外成本上行/蛋白不及预期 | 低于多数消费龙头 |

| 乐观 | 56.40元 | 21.8x（综合隐含） | 需运费、汇率、提价、蛋白同时改善 | 接近消费龙头中枢 |

**当前估值结论**：现价38.20元对应PE TTM 20.73x（10年7.4%分位）、PB 2.59x（2.8%分位）、2027E Forward PE 18.7x。Base修正目标37.18元、概率加权39.18元，收益率-2.7%/+2.6%，盈亏比0.08。**估值已在合理区间，缺乏安全边际**；向上需要Q4毛利率≥23.5%与运费/汇率继续改善的实证，向下有PB 2.59x与清算底价14.34元提供缓冲。
