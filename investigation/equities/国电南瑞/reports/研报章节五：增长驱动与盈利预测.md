# 研报章节五：增长驱动与盈利预测

**研究日期**：2026年8月1日
**标的**：国电南瑞 (600406.SH)
**目标年份**：2026年（当年锚定，Q2适用）
**前序模块红线继承**：
- 模块一：毛利率下行（26.88%→25.84%）→需在本模块验证修复拐点；应收账款高企（312.5亿）→需量化对营运资金的影响
- 模块二：电网投资"十五五"5万亿超级周期（国网4万亿+南网1万亿）→营收增长的底线确定性极高；供需边际向供不应求偏移
- 模块三：反内卷价格修复（+5-30%）→毛利率向上驱动力；多领域技术壁垒→盈利可持续性；海外+储能+特高压三增长极
- 模块四：外部环境"五对二"正向不对称格局（电网投资+六张网+低利率+反内卷+全球设备短缺 vs 原材料成本+芯片管制）→收入侧极强、成本侧承压

## 一、分业务 P×Q 模型与证据锚定

### 1.1 销量（Q）确定性溯源

#### 核心驱动力一：国网2026年H1固定资产投资超3,100亿元（证据强度：5/5）

国网Q1完成投资超1,290亿元（同比+37%，配网568亿占比55%），H1累计超3,100亿元（同比+12.6%），绝对额刷新历史同期高位；南方电网H1同比+49.5%。增速从Q1高斜率回落至稳健执行，但"十五五"4万亿（年均8,000亿）的公开承诺与"六张网"战略优先级未变，2026年全年预算7,200-7,800亿元。

**传导逻辑**：国网投资↑→设备招标↑（2025年输变电招标918.8亿，+25.3%；2026年特高压前三批设备约292.6亿元）→南瑞中标→收入确认（招标后6-12个月，特高压12-18个月）。2026年H1的稳健投资进度，对应2026H2-2027H1的营收确认节奏。

**量化锚定**：
- 南瑞在国网设备采购中的份额约8-10%（基于网内营收约420亿/国网设备总投资约4,500亿）
- 2025年末在手订单520.31亿元（约0.79x年营收），2026年新签合同目标850-900亿，订单/收入比维持扩张区间

#### 核心驱动力二：在手订单520亿提供极高可见度（证据强度：5/5）

2025年末在手订单520.31亿元，其中本年新签331.92亿元；全年新签合同758.68亿（+14.4%），Book-to-Bill=1.15。520亿在手订单相当于2025年营收的78.6%，叠加2026Q1合同负债86.4亿元（同比+24.2%）的蓄水池验证，2026年Q1-Q3收入有极强的订单保障。

**量化锚定**：
- 520亿在手订单中约70%将在2026年内转化为收入 → 约365亿确定性营收
- 剩余约385亿来自2026年新签（预计全年新签850-900亿）→ 6-12个月转化

#### 核心驱动力三：海外业务"从1到10"的爆发（证据强度：3/5）

2025年海外营收60.38亿（+84.13%），2026年预计继续高增长至约90亿（+50%）。沙特（储能+STATCOM）、巴基斯坦（默拉直流）、巴西（控保）、智利（保护及自动化）持续交付，坦桑尼亚、马达加斯加等5国为2025年新开拓市场，贡献主要在2026-2027年体现。全球变压器交付周期拉长至36-60个月、缺口约30%，中国设备商处于"卖方市场"。

**量化锚定**：
- 2026E海外+50%（约90亿），2027E +35%（约122亿），2028E +30%（约158亿）
- 证据支撑：2025H2新增海外产品认证50+项、BNEF Tier1储能认证连续三个季度
- 风险提示：海外增速基数抬高后能否维持50%存不确定性，且毛利率仅19.2%（低于国内约7pp），扩张对综合毛利率构成结构性稀释（见1.2）

#### 核心驱动力四：新能源+储能+特高压三箭齐发（证据强度：4/5）

- 特高压："十五五"计划投运15条特高压直流，2026年Q1开工攀西特高压交流、皖鄂直流背靠背，续建甘肃-浙江、大同-怀来-天津南、闽赣直流等；年内前三批设备招标约292.6亿元，南瑞体系在换流阀/控保相关包持续取得订单（累计口径龙头，单批份额随线路结构波动）
- 储能：构网型储能渗透率从12.8%跃升至19.2%（2026Q1），南瑞继保独占约90%构网份额
- 新能源：2026年光伏新增装机预计180-240GW（较2025年回落），但累计18.8亿千瓦装机的消纳改造需求持续释放，驱动变量是存量积压而非当年新增

### 1.2 价格（P）趋势逻辑推演

**正面驱动力**：
1. **国网反内卷**：招标价格权重下降、技术权重提升，2026年起价格回升5-30%，电网智能/数能融合受益最显著
2. **构网型储能技术溢价**：南瑞继保"三倍10秒"过载能力、百兆瓦级黑启动实测，享有明确的技术溢价
3. **海外报价灵活性**：海外项目报价空间大于国内集采

**负面压力**：
1. **原材料成本（7月13日、7月28日两轮下修的核心变量）**：铜价维持$13,600-13,700/吨高位盘整；英飞凌7月1日第二轮涨价落地（IGBT+10-20%，单管IGBT+30%、SiC+50%），叠加首轮（5-15%）累计对毛利率拖累约1.0-1.5pp，其中第二轮额外拖累约0.3-0.5pp
2. **能源低碳板块毛利率结构性偏低（20.2%）**：板块占比扩大（25%→30%）压制综合毛利中枢
3. **海外毛利率拖累**：海外收入占比9.1%，对综合毛利率拖累约0.6pp；若2027-2028年占比升至15%，拖累扩大至约1pp

**净预判（2026年8月1日终版）**：综合毛利率2025年25.84% → 2026E 25.5%（下修，中枢较6月14日26.0%下移）→ 2027E 26.5%（反内卷价格修复+海外毛利收敛至22-24%）→ 2028E 27.0%。

## 四、分部估值（SOTP）利润模拟

国电南瑞具备多个不同属性的业务板块，适用分部估值。根据框架算法规范：

`板块模拟净利_i = 板块营收_i × [板块毛利率_i - (总期间费用率 × K_i)] × (1 - 有效税率)`

### 2026E SOTP 模拟

| 板块 | 营收 | 毛利率 | K系数 | 费用率11.3%×K | 模拟净利 | 说明 |
|:---|---:|---:|---:|---:|---:|:---|
| 电网智能 | 384亿 | 30.5% | 1.0 | 11.3% | 66.4亿 | 成熟业务，标准K=1.0 |
| 能源低碳 | 218亿 | 21.0% | 1.3 | 14.7% | 12.4亿 | 高研发/出海投入，K=1.3 |
| 数能融合 | 133亿 | 23.0% | 1.2 | 13.6% | 11.3亿 | 研发驱动数字业务，K=1.2 |
| 工业互联 | 33亿 | 22.0% | 1.4 | 15.8% | 1.8亿 | 孵化期业务，K=1.4 |
| 集成及其他 | 4亿 | 26.0% | 0.6 | 6.8% | 0.7亿 | 轻资产，K=0.6 |
| **板块合计** | **772亿** | | | | **92.6亿** | |
| 加：财务净收益 | | | | | 6.1亿 | 利息/汇兑净收益 |
| **模拟净利润（含少数股东）** | | | | | **98.7亿** | |
| 减：少数股东损益 | | | | | 6.1亿 | |
| **模拟归母净利** | | | | | **92.6亿** | |

**勾稽校验**：板块合计92.6亿 + 财务净收益6.1亿 = 98.7亿 ≈ 利润表预测净利润98.7亿 ✓；减少数股东损益6.1亿后归母92.6亿 ≈ 整体预测92.6亿 ✓。

SOTP分析表明，**电网智能贡献约72%的归母净利**，是公司盈利的"压舱石"；**能源低碳**尽管营收增速最快（+30%），但利润贡献仅约13%，印证模块一"增收不增利"的结构性隐忧——该板块的利润弹性将在规模跨越300亿营收（预计2027-2028年）后显著释放。

## 五、证据链强度与确定性评分

| 增长驱动力 | 评分 | 证据支撑 |
|:---|:---:|:---|
| 国网投资高增长（2026E +15%） | **5/5** | H1已实现超3,100亿（+12.6%），国网年度目标7,200-7,800亿公开文件，"六张网"顶层设计 |
| 在手订单520亿转化 | **5/5** | 2025年报披露在手订单520.31亿、新签758.68亿（+14.4%）、合同负债78亿（+21%） |
| 特高压密集开工→换流阀放量 | **4/5** | 甘肃-浙江、攀西等已开工采购，年内前三批约292.6亿，南瑞体系累计口径龙头（2026年批次口径约49%） |
| 海外50%+增长 | **3/5** | 2025年+84%已兑现，但基数抬高后能否维持50%存不确定性，受地缘与毛利率拖累影响 |
| 毛利率回升至25.5%兑现 | **3/5** | 国网反内卷机制明确（价格回升5-30%），但英飞凌两轮涨价+铜价高位对冲，净效果需Q2半年报（8月27日）验证 |
| 费用率下降（规模效应） | **3/5** | 趋势确定但程度温和，研发费用率大概率维持5-5.5%不下行 |
| 构网型储能爆发 | **4/5** | 渗透率19.2%（Q1），南瑞已入选BNEF Tier1，但行业竞争窗口在收窄 |
| IGBT自主替代加速 | **2/5** | 晶圆制造已终止，设计+封测模式需要验证长期良率与成本竞争力 |

**综合确定性评分：3.75/5（中高确定性）**

核心逻辑（国网投资增长→订单→收入）的确定性极高（4-5分），但利润率的弹性（毛利率回升幅度、费用率下降速度）存在一定不确定性（3分），综合给出中高确定性评级。8月27日半年报的Q2毛利率（≥25.5%则利润弹性逻辑有效）与新签合同数据是2026年下半年的核心验证节点。
