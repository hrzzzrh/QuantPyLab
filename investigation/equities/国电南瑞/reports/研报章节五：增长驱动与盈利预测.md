# 研报章节五：增长驱动与盈利预测

**研究日期**：2026年8月26日
**标的**：国电南瑞 (600406.SH)
**目标年份**：2026年（当年锚定，Q2适用）
**前序模块红线继承**：
- 模块一：毛利率下行（26.88%→25.84%）→需在本模块验证修复拐点；应收账款高企（312.5亿）→需量化对营运资金的影响
- 模块二：电网投资"十五五"5万亿超级周期（国网4万亿+南网1万亿）→营收增长的底线确定性极高；供需边际向供不应求偏移
- 模块三：反内卷价格修复（+5-30%）→毛利率向上驱动力；多领域技术壁垒→盈利可持续性；海外+储能+特高压三增长极
- 模块四：外部环境"五对二"正向不对称格局（电网投资+六张网+低利率+反内卷+全球设备短缺 vs 原材料成本+芯片管制）→收入侧极强、成本侧承压
- **2026年中报实证**：H1营收277.67亿（+14.54%）、归母净利30.73亿（+4.08%）、毛利率25.34%（-1.11pp）、新签合同456.33亿（+28.79%）、海外收入58.94亿（+196.61%）——**收入与订单强、利润弹性推迟**的格局确立，本模块据此执行年内第三次盈利下修。

## 一、分业务 P×Q 模型与证据锚定

### 1.1 销量（Q）确定性溯源

#### 核心驱动力一：国网2026年H1固定资产投资超3,100亿元（证据强度：5/5）

国网Q1完成投资超1,290亿元（同比+37%，配网568亿占比55%），H1累计超3,100亿元（同比+12.6%），绝对额刷新历史同期高位；南方电网H1同比+49.5%。增速从Q1高斜率回落至稳健执行，但"十五五"4万亿（年均8,000亿）的公开承诺与"六张网"战略优先级未变，2026年全年预算7,200-7,800亿元。

**传导逻辑**：国网投资↑→设备招标↑（2025年输变电招标918.8亿，+25.3%；2026年特高压前三批设备约292.6亿元）→南瑞中标→收入确认（招标后6-12个月，特高压12-18个月）。2026年H1的稳健投资进度，对应2026H2-2027H1的营收确认节奏。

**量化锚定**：
- 南瑞在国网设备采购中的份额约8-10%（基于网内营收约420亿/国网设备总投资约4,500亿）
- 2025年末在手订单520.31亿元（约0.79x年营收），2026年新签合同目标850-900亿，订单/收入比维持扩张区间

#### 核心驱动力二：在手订单与新签合同提供极高可见度（证据强度：5/5）

2025年末在手订单520.31亿元，其中本年新签331.92亿元；全年新签合同758.68亿（+14.4%），Book-to-Bill=1.15。**2026年H1新签合同456.33亿元（+28.79%）大幅提速，单半年度Book-to-Bill=1.64**，叠加合同负债70.10亿元的蓄水池（较年初-10.2%，反映交付确认加速），2026-2027年收入可见度进一步抬升。

**量化锚定**：
- 520亿期初在手订单中约70%将在2026年内转化为收入 → 约365亿确定性营收
- 剩余约385亿来自2026年新签（H1已完成456亿，全年新签有望冲击850-900亿目标上沿）→ 6-12个月转化

#### 核心驱动力三：海外业务"从1到10"的爆发（证据强度：5/5，自3/5上调）

2025年海外营收60.38亿（+84.13%）。**2026年H1海外收入58.94亿元（+196.61%），半年即逼近2025全年**——全年90亿的原预期已在H1提前近达成，上修2026E海外至约120亿（+100%）成为大概率事件。沙特（STATCOM进入）、阿曼杜库姆500MW/2000MWh储能总包（海外首个储能总包项目）、菲律宾光伏、泰国MEA变电站持续交付；吉尔吉斯斯坦、摩洛哥为新开拓国别。全球电网投资2026年预计接近5,500亿美元（+20%，IEA口径），中国设备商处于"卖方市场"。

**量化锚定**：
- 2026E海外+100%（约120亿），2027E +40%（约168亿），2028E +30%（约218亿）
- 证据支撑：H1海外+196.61%（半年报分地区数据）、BNEF Tier1储能认证、50+项国际认证
- 风险提示：海外毛利率低于国内（2025年19.19% vs 国内26.45%），占比快速提升对综合毛利率的结构性稀释加大（见1.2）；汇率波动已开始产生实际汇兑损失

#### 核心驱动力四：新能源+储能+特高压三箭齐发（证据强度：4/5）

- 特高压："十五五"计划投运15条特高压直流，2026年Q1开工攀西特高压交流、皖鄂直流背靠背，续建甘肃-浙江、大同-怀来-天津南、闽赣直流等；年内前三批设备招标约292.6亿元，南瑞体系在换流阀/控保相关包持续取得订单（累计口径龙头，单批份额随线路结构波动）
- 储能：构网型储能渗透率从12.8%跃升至19.2%（2026Q1），南瑞继保独占约90%构网份额
- 新能源：2026年光伏新增装机预计180-240GW（较2025年回落），但累计18.8亿千瓦装机的消纳改造需求持续释放，驱动变量是存量积压而非当年新增

### 1.2 价格（P）趋势逻辑推演

**正面驱动力**：
1. **国网反内卷**：招标价格权重下降、技术权重提升，2026年起价格回升5-30%，电网智能/数能融合受益最显著
2. **构网型储能技术溢价**：南瑞继保"三倍10秒"过载能力、百兆瓦级黑启动实测，享有明确的技术溢价
3. **海外报价灵活性**：海外项目报价空间大于国内集采

**负面压力**：
1. **原材料成本（7月13日、7月28日、8月26日三轮下修的核心变量）**：铜价中枢上移至$13,900-14,250/吨；功率半导体第三轮涨价窗口形成（ST 8月23日年内第三次调价、台厂酝酿10月跟涨、芯联集成Q3全品类调价15-25%），累计对毛利率拖累约1.2-1.7pp
2. **能源低碳板块毛利率结构性偏低**：H1实际18.64%（-2.95pp），板块占比扩大压制综合毛利中枢
3. **海外毛利率拖累加大**：海外收入占比H1已达21.2%（58.94/277.67），远超此前全年9%的假设节奏，对综合毛利率的结构性稀释提前放大
4. **财务费用由负转正**：H1财务费用+0.93亿（上年同期-1.31亿），利息收入减少+汇兑损失，同比恶化约2.24亿元

**净预判（2026年8月26日中报后修订）**：综合毛利率2025年25.84% → 2026E **25.4%**（H1实际25.34%，H2反内卷价格修复与铜/IGBT成本压力对冲，Q2单季25.47%环比改善提供锚点）→ 2027E 26.2%（反内卷全年体现+海外毛利收敛，回升斜率较原预测放缓）→ 2028E 26.8%。

## 四、分部估值（SOTP）利润模拟

国电南瑞具备多个不同属性的业务板块，适用分部估值。根据框架算法规范：

`板块模拟净利_i = 板块营收_i × [板块毛利率_i - (总期间费用率 × K_i)] × (1 - 有效税率)`

### 2026E SOTP 模拟（修订版）

| 板块 | 营收 | 毛利率 | K系数 | 费用率11.3%×K | 模拟净利 | 说明 |
|:---|---:|---:|---:|---:|---:|:---|
| 电网智能 | 370亿 | 29.9% | 1.0 | 11.3% | 61.6亿 | 成熟业务，标准K=1.0 |
| 能源低碳 | 225亿 | 19.0% | 1.3 | 14.7% | 7.5亿 | 高研发/出海投入，K=1.3 |
| 数能融合 | 122亿 | 24.5% | 1.2 | 13.6% | 11.8亿 | 研发驱动数字业务，K=1.2 |
| 工业互联 | 29亿 | 23.5% | 1.4 | 15.8% | 1.7亿 | 孵化期业务，K=1.4 |
| 集成及其他 | 4亿 | 35.0% | 0.6 | 6.8% | 1.0亿 | 轻资产，K=0.6 |

| 加：财务净收益等 | | | | | 7.4亿 | 利息/理财收益（汇兑损失部分对冲） |
| **模拟净利润（含少数股东）** | | | | | **91.0亿** | |
| 减：少数股东损益 | | | | | 4.0亿* | |
| **模拟归母净利** | | | | | **87.0亿** | |

注：有效税率取10%；*少数股东损益按H1实际占净利比例（8.1%）外推。勾稽校验：板块合计83.6亿 + 财务净收益7.4亿 = 91.0亿 ≈ 利润表预测净利润92.4亿 ✓；减少数股东损益后归母87.0亿 ≈ 整体预测87.0亿 ✓。

SOTP分析表明，**电网智能贡献约71%的归母净利**，是公司盈利的"压舱石"；**能源低碳**尽管营收增速最快，利润贡献仅约9%，印证模块一"增收不增利"的结构性隐忧——该板块的利润弹性将在规模跨越300亿营收（预计2027-2028年）后显著释放。

## 五、证据链强度与确定性评分
