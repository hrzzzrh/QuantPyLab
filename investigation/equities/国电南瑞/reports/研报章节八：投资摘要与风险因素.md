## 一、投资摘要

### 1.1 一句话投资逻辑

**"十五五"电网投资从2.85万亿跃升至5万亿元（+75%），叠加反内卷利润修复与海外/储能双增长极，国电南瑞进入2016年以来最强的3年盈利增长窗口。当前PE TTM 21.1x已降至近10年P14分位（仅2018贸易战、2020疫情时更低），PB 3.31x处于P17分位。股价21.70元较年内高点31.52元累计回撤-31.2%，但基本面（电网5万亿+特高压招标翻倍+国网投资Q1 +37%）不仅未被证伪反而持续强化。市场因IGBT二次涨价和铜价高企而过度恐慌，创造了A股罕见的"戴维斯双击"机会。**

### 1.4 三大核心驱动力

1. **国网"十五五"4万亿投资落地（确定性5/5）**：2026年Q1国网投资同比+37%，配网投资占比55%。特高压招标年内前两批已达180亿（超2025全年），第三批（110亿）7月6日开标。南瑞在特高压设备中占14.6%份额（77亿+），换流阀市占率52%，订单确定性极高。

2. **毛利率触底回升+费用率下行=利润弹性释放（确定性3-4/5）**：国网反内卷机制落地（价格回升5-30%），但英飞凌7月1日第二轮IGBT涨价（+10-20%）延缓了毛利率修复斜率。预计毛利率从25.84%先微降至25.5%再回升至2027年26.5%+。费用率从11.2%降至10.8%以下的过程仍在推进。

3. **海外+储能+特高压三增长极（确定性4-5/5）**：海外营收60亿→2026E 90亿（+50%），构网型储能市场份额~90%，特高压换流阀市占率52%。特高压招标年内翻倍是新增的超预期利好。

## 二、风险因素（按对股价影响烈度降序排列）

### R1：电网投资执行不及预期（烈度：★★★★★，概率：极低）

**触发条件**：国网年度投资实际完成额低于6,500亿元，或"十五五"4万亿计划在执行中逐年缩水。

**影响**：南瑞网内营收增速从+15%骤降至+5%，2026E净利从93亿下修至82亿（-12%），目标价下修至21元（-3%）。

**判断**：当前Q1已实现37%增长，特高压招标翻倍，在"六张网"政策加持下概率极低（<10%）。上半年国网投资完成数据（预计8月披露）将是关键验证点。

### R2：毛利率回升被原材料涨价完全吞没（烈度：★★★★，概率：中）

**触发条件**：铜价突破$15,000/吨，IGBT继续第三轮涨价，且国网反内卷价格回升幅度不足。

**影响**：毛利率从25.5%进一步降至24.8%，净利增速降至5%以下，"利润弹性"逻辑完全落空。目标价下调至23-25元。

**判断**：英飞凌已实施两轮涨价，短期内第三轮概率较低。铜价维持$13,400高位但上行空间有限（基准情景H2 $10,000-12,000）。**Q2毛利率（8月27日半年报）是验证此风险的终极窗口**。若Q2毛利率≥25.5%，利润弹性逻辑有效；若<25.0%，需进一步下修。

### R3：中美芯片出口管制超预期升级（烈度：★★★，概率：中低）

**触发条件**：MATCH法案扩展至成熟制程晶圆代工，或全面禁止IGBT/DSP/FPGA对华出口。

**影响**：南瑞IGBT外协代工受限，自主设计无法落地。营收增速降至5-8%，目标价下修至22-24元。

**判断**：南瑞已主动终止晶圆制造，规避了核心火力区。IGBT自主中压10万只/年交付验证了设计+封测模式的可行性。此风险为行业性风险，南瑞相对韧性最强。

### R4：海外业务遭遇重大地缘事件（烈度：★★★，概率：中）

**触发条件**：中东地缘冲突升级、美国二级制裁波及"一带一路"国家。

**影响**：海外收入增速从+50%骤降至+10%，净影响利润1-2个百分点。但因海外占总营收不到10%，对整体业绩冲击有限。

**判断**：南瑞多元化市场布局（140+国家）提供天然风险分散。沙特、巴基斯坦、巴西等核心市场地缘风险可控。

### R5：应收账款信用风险（烈度：★★，概率：中低）

**触发条件**：电网客户出现大规模拖欠，或新能源电站客户信用违约。

**影响**：信用减值损失从4亿扩大至10亿+，直接冲击利润10%。

**判断**：国网/南网为央企，违约概率极低。网外新能源客户存在一定信用风险但占比有限。

### R6：IGBT成本持续恶化（烈度：★★★，概率：中）【7月13日新增】

**触发条件**：英飞凌/PI第三轮涨价、国内代工厂同步提价、南瑞IGBT自研良率不达预期。

**影响**：IGBT成本占材料比从~5%升至~7-8%，额外拖累毛利率0.5-1.0pp。

**判断**：英飞凌两轮涨价后进入观察期，Q3合约重新议价结果将决定2027年成本基线。南瑞中压IGBT自供+高压设计外协模式可对冲约30-40%的外部涨价影响。

## 三、研究结论象限图

```text
                    预期收益空间
                   高 ▲          低
               ┌──────────┬──────────┐
         高    │ 第一象限  │ 第三象限  │
         │    │ ★ 国电南瑞│ 防御价值  │
 确      │    │ (21.70元) │          │
 定     │    │ 重仓建议  │ 底仓建议  │
 性     │    ├──────────┼──────────┤
        │    │ 第二象限  │ 第四象限  │
         │    │ 投机成长  │ 回避观望  │
         低   │          │          │
               └──────────┴──────────┘
```

**定位：第一象限——High-Conviction Buy（高确定性 + 高预期收益）**

**理由**：

- **确定性（高）**：国网4万亿投资为国家战略级公开承诺，2026Q1已执行+37%。南瑞在电网调度/控保/换流阀三大核心领域的绝对垄断地位提供铁底。750亿营收目标对应520亿在手订单提供极高可见度。综合确定性评分3.75/5。

- **预期收益（高）**：基准目标价29.90元（+37.8%），乐观目标价36.68元（+69.0%），盈亏比4.81:1。当前21.70元已低于保守情景目标22.44元。在18.9x 2026E PE（近10年P14分位）的极端低位，是极少数兼具"高收益+低回撤"特征的标的。

- **仓位建议**：**核心重仓配置（建议占投资组合比重8-15%）**。21.70元处于极端低估区间，短期仍可能探底至MA250（20.10元），但从12-18个月维度几乎确定性地提供20-50%的回报空间。建议在20-22元区间分批建仓，20.10元（MA250）为终极重仓价位，29.90-33.06元为目标兑现区间。
