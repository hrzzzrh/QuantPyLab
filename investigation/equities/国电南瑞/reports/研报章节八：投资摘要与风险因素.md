## 一、投资摘要

### 1.1 一句话投资逻辑

### 1.4 三大核心驱动力

1. **国网"十五五"4万亿投资落地（确定性4.5/5）**：2026年Q1国网投资同比+37%，H1累计超3,100亿元、同比+12.6%，说明首季高斜率回归稳健但绝对投资仍强。特高压前三批设备约292.6亿元，第三批约108.7亿元中南瑞体系继续取得换流阀/控保相关包，订单确定性仍高，但单批份额存在波动。

2. **毛利率触底回升+费用率下行=利润弹性释放（确定性3-4/5）**：国网反内卷机制落地（价格回升5-30%），但英飞凌7月1日第二轮IGBT涨价（+10-20%）延缓了毛利率修复斜率。预计毛利率从25.84%先微降至25.5%再回升至2027年26.5%+。费用率从11.2%降至10.8%以下的过程仍在推进。

3. **海外+储能+特高压三增长极（确定性4-5/5）**：海外营收60亿→2026E 90亿（+50%），构网型储能市场份额~90%，特高压换流阀累计份额约45-50%（2026年批次口径约49%）。特高压招标年内翻倍是新增的超预期利好。

## 二、风险因素（按对股价影响烈度降序排列）

### R1：电网投资执行不及预期（烈度：★★★★★，概率：极低）

**触发条件**：国网年度投资实际完成额低于6,500亿元，或"十五五"4万亿计划在执行中逐年缩水。

**影响**：南瑞网内营收增速从+15%骤降至+5%，2026E净利从93亿下修至82亿（-12%），目标价下修至21元（对应EPS约1.02元×PE 20-21x，较保守情景22.44元再降约6%）。

**判断**：当前H1已实现超3,100亿元、同比+12.6%，增速低于Q1但绝对额仍处高位；特高压前三批约292.6亿元，在"六张网"政策加持下，年度低于6,500亿元的概率仍较低。后续跟踪重心从"H1是否高增"切换到"H2预算是否加速、南瑞订单是否兑现"。

### R2：毛利率回升被原材料涨价完全吞没（烈度：★★★★，概率：中）

**触发条件**：铜价突破$15,000/吨，IGBT继续第三轮涨价，且国网反内卷价格回升幅度不足。

**影响**：毛利率从25.5%进一步降至24.8%，2026E净利约88亿、增速降至约6%（若毛利率跌破24.5%则增速可能降至5%以下），"利润弹性"逻辑大幅落空。目标价下调至23-25元。

**判断**：英飞凌已实施两轮涨价，短期内第三轮概率较低。铜价维持$13,400高位但上行空间有限（基准情景H2 $10,000-12,000）。**Q2毛利率（8月27日半年报）是验证此风险的终极窗口**。若Q2毛利率≥25.5%，利润弹性逻辑有效；若<25.0%，需进一步下修。

### R3：中美芯片出口管制超预期升级（烈度：★★★，概率：中低）

**触发条件**：MATCH法案扩展至成熟制程晶圆代工，或全面禁止IGBT/DSP/FPGA对华出口。

**影响**：南瑞IGBT外协代工受限，自主设计无法落地。营收增速降至5-8%，目标价下修至22-24元。

**判断**：南瑞已主动终止晶圆制造，规避了核心火力区。IGBT自主中压10万只/年交付验证了设计+封测模式的可行性。此风险为行业性风险，南瑞相对韧性最强。

### R4：海外业务遭遇重大地缘事件（烈度：★★★，概率：中）

**触发条件**：中东地缘冲突升级、美国二级制裁波及"一带一路"国家。

**影响**：海外收入增速从+50%骤降至+10%，净影响利润1-2个百分点。但因海外占总营收不到10%，对整体业绩冲击有限。

**判断**：南瑞多元化市场布局（140+国家）提供天然风险分散。沙特、巴基斯坦、巴西等核心市场地缘风险可控。

### R5：应收账款信用风险（烈度：★★，概率：中低）

**触发条件**：电网客户出现大规模拖欠，或新能源电站客户信用违约。

**影响**：信用减值损失从4亿扩大至10亿+，直接冲击利润10%。

**判断**：国网/南网为央企，违约概率极低。网外新能源客户存在一定信用风险但占比有限。

### R6：IGBT成本持续恶化（烈度：★★★，概率：中）【7月13日新增，7月28日延续跟踪】

**触发条件**：英飞凌/PI第三轮涨价、国内代工厂同步提价、南瑞IGBT自研良率不达预期。

**影响**：IGBT成本占材料比从~5%升至~7-8%，额外拖累毛利率0.5-1.0pp。

**判断**：英飞凌两轮涨价后进入观察期，Q3合约重新议价结果将决定2027年成本基线。南瑞中压IGBT自供+高压设计外协模式可对冲约30-40%的外部涨价影响。

## 三、研究结论象限图

```text
                    预期收益空间
                   高 ▲          低
               ┌──────────┬──────────┐
         高    │ 第一象限  │ 第三象限  │
         │    │ ★ 国电南瑞│ 防御价值  │
 确      │    │ (23.56元) │          │
 定     │    │ 重仓建议  │ 底仓建议  │
 性     │    ├──────────┼──────────┤
        │    │ 第二象限  │ 第四象限  │
         │    │ 投机成长  │ 回避观望  │
         低   │          │          │
               └──────────┴──────────┘
```

**定位：第一象限——High-Conviction Buy（高确定性 + 高预期收益）**

**理由**：

- **确定性（高）**：国网4万亿投资为国家战略级公开承诺，2026H1已完成超3,100亿元、同比+12.6%。南瑞在电网调度/控保/换流阀三大核心领域的绝对垄断地位提供铁底。750亿营收目标对应在手订单与特高压招标持续释放，综合确定性评分3.75/5维持。

- **预期收益（中高）**：中性目标价29.40元（+24.8%），乐观目标价36.68元（+55.7%），加权目标价29.12元（+23.6%），盈亏比4.96:1。当前23.56元已高于保守情景目标22.44元，赔率较7月13日明显压缩，但20.5x 2026E PE仍低于公司合理中枢。

- **仓位建议**：**持有/买入（建议占投资组合比重6-10%，中报验证后再上调）**。23.56元已完成一轮估值修复，短期若回踩22.85元不破可低吸；若半年报Q2毛利率≥25.5%且新签合同兑现，再恢复进攻性加仓。29.40-36.68元为目标兑现区间。
