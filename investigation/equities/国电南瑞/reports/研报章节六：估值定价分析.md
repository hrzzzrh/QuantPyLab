## 一、价值锚定：适配性方法选择

### 1.1 方法论选择理由

国电南瑞的商业模式特征是：**高ROE（16%）+ 稳定增长（10-20%）+ 强现金流 + 低资本开支**。适用以下估值方法：

| 方法 | 适用性 | 权重 | 选择理由 |
|:---|:---:|:---:|:---|
| **PE估值**（主力） | ★★★★★ | 50% | 盈利稳定、扣非占比>96%，PE是可比的行业通用语言 |
| **PEG修正** | ★★★★ | 15% | 增长差异大，PEG可修正单纯PE的静态缺陷 |
| **PB-ROE** | ★★★★ | 20% | 净资产定价有锚，ROE>15%应享有PB溢价 |
| **DCF** | ★★★ | 15% | 现金流优秀（OCF/NP历史1.5x），但电网投资周期性强，远期假设敏感 |

**不适用方法**：PS（净利率稳定，PS冗余）、EV/EBITDA（无显著带息负债，杠杆中性）

### 1.2 历史分位审计

基于近10年（2016年以来）交易数据：

|:---|---:|---:|---:|---:|---:|---:|---:|---:|---:|:---:|
| PE TTM | 13.14 | 19.83 | 22.20 | **25.26** | 28.14 | 31.36 | 34.71 | **22.35** | 22.86 | **P24.6** |
| PB | 3.05 | 3.17 | 3.58 | **4.14** | 4.62 | 5.16 | 6.12 | **3.48** | 3.59 | **P4.8** |

注：当前分位为2016年以来全样本中"指标≤当前值"的交易日占比（≤口径），基于系统视图 `v_daily_valuation` 实测计算。

**近年PE中位趋势**：2021: 30.9x → 2022: 31.3x → 2023: 28.0x → 2024: 26.9x → 2025: 23.5x。PE中枢逐年下移反映了市场对电网投资增速放缓的持续担忧——但2026年"十五五"4万亿的官宣完全打破了这一叙事。

**最新坐标解读**：股价8月上旬冲高24.54元后缩量回落至23.15元，PE TTM降至22.35x（P24.6）；**PB降至3.48x，处于近10年P4.8的极低分位**——PB分位远低于PE分位的剪刀差源于ROE持续上行（16%+）与净资产快速积累，是本轮周期中"盈利能力未被定价"的最直接证据。半年报落地后，市场焦点将从"Q2毛利率是否证伪"转向"H2反内卷价格修复与特高压交付兑现"，估值锚的重估依赖三季报毛利率验证。

**核心论点（维持但强调利润验证）**："十五五"电网投资从2.85万亿跃升至5万亿（+75%）、《新型电力系统建设"十五五"规划》纲领落地、反内卷→利润率修复、海外+储能打开全新空间——四重逻辑未变。PE法合理倍数取26x（近10年P50-60区间），PEG修正（20x）与PB-ROE（3.5x）交叉验证后中性情景综合倍数约24x。**中报将利润弹性推迟了一个季度级别，但订单与海外的超预期强化了2027年弹性释放的确定性，估值策略维持"持有等待拐点确认"。**

## 二、多方法交叉估值

### 2.1 PE估值（权重50%）

```
目标市值 = 2026E归母净利润 × 合理PE
```

**合理PE确定**：
- 近5年PE中位：27x（各年波动中枢的均值）
- 近10年PE中位：25.3x
- 行业可比（电力二次设备龙头+15%增速）：25-30x
- 综合取：**26x**（处于近10年P50-P60之间，保守但不过度保守）

**2026E PE估值**：87.0亿 × 26 = **2,262亿** → 目标价 **28.16元**（+21.6%）

**2027E前瞻PE估值**（Q4滚算时适用）：108.5亿 × 24 = 2,604亿 → 32.42元

### 2.2 PEG修正（权重15%）

```
2026E增速 = 5.1%（归母净利，中报后自11.9%下修）
2027E增速 = 24.7%（毛利率回升+海外规模效应）

两年复合增速 ~14.5%；剔除2026年汇兑损失、减值上修等一次性偏压项
（合计压制约1.5-2pp增速）后，可持续复合增速约18%
取PEG = 1.0-1.2（南瑞确定性溢价）
合理PE = 1.1 × 18 ≈ 20x
```

**PEG估值**：87.0亿 × 20 = **1,740亿** → 目标价 **21.66元**（-6.4%）

PEG口径低于PE法的原因：即便还原一次性偏压，18%的复合增速对应20x仍属保守定价；其价值在于提供"若市场仅按线性成长给价"的安全边际参考，不作主要定价依据。

### 2.3 PB-ROE模型（权重20%）

```
合理PB = (ROE - g) / (COE - g)
        = (16.0% - 5%) / (9% - 5%)
        = 2.75x

历史PB中位4.14x，当前PB 3.48x（P4.8极低分位）。
取3.3-3.8x（低于历史中位，保守起见）。
```

模型输出2.75x系COE 9%、g 5%的严苛参数假设。考虑南瑞ROE仍处16%+平台且低利率环境（10年期国债1.6-1.8%）压降股权成本，按COE 8.5%、g 5%复算：合理PB = (16.5% - 5%) / (8.5% - 5%) = **3.29x**，故取值区间锚定3.3-3.8x并取保守下沿3.5x（仅为历史中位4.14x的85%）。

2025年末BVPS = 6.55元。按60%分红率估算2026E每股派息约0.65元（中期0.153元已预案+年度预计约0.50元），2026年末BVPS ≈ 6.55 + 1.08 - 0.65 = 6.98元。

**PB-ROE估值**：6.98元 × 3.5 = 24.43元/股 → 市值 **1,962亿**

### 2.4 DCF估值（上限参考，不参与合成）

核心假设：
- 自由现金流 = OCF - CAPEX（FCF为正常化经营年份口径；2026H1经营现金流因采购付款增加阶段性走弱至5.91亿，属节奏性波动）。2025年OCF 127.7亿，CAPEX（购建固定资产支付）21.1亿，FCF ≈ 106.6亿
- 2026-2028年FCF增速：20%/18%/15%（与利润增速匹配）
- 2029-2030年FCF增速：12%/10%
- 永续增长率g=3%（通胀+电网自然增长）
- WACC=8.5%（无风险利率1.7%+股权风险溢价6.8%，β=1.0）

经DCF模型计算（简化版）：

| 年份 | FCF（亿） | PV（亿，折现率8.5%） |
|:---|---:|---:|
| 2026E | 128 | 117.9 |
| 2027E | 151 | 128.2 |
| 2028E | 174 | 135.9 |
| 2029E | 194 | 140.3 |
| 2030E | 214 | 142.2 |
| 终值 | 4,004 | 2,662.7 |
| **企业价值** | | **3,327.2** |
| 加：现金 | | +73 |
| 减：带息债务 | | -10 |
| **股权价值** | | **3,390亿** |

**DCF估值**：3,390亿 → **42.21元/股**

DCF显著高于PE/PB估值，原因是永续增长部分（3%）对长生命周期电网龙头给予了过高权重；且2026H1经营现金流大幅走弱（5.91亿，-78.95%，采购付款增加）提示短期FCF质量波动。鉴于电网投资周期性强、2030年后增长能见度低，**DCF仅作上限参考，不参与目标价合成**（权重0%）。

## 四、确定性与胜率矩阵

### 4.1 三态逻辑加权

基于模块五的情景分析（三态目标价 = 情景市值 ÷ 股本；中性情景采用调节后的修正目标市值，保守/乐观采用未调节情景市值）：

| 情景 | 概率 | 2026E EPS | 估值倍数 | 情景市值（亿） | 目标价 | 备考 |
|:---|---:|---:|---:|---:|---:|:---|
| **保守（Bear）** | 25% | 0.98元 | 22x | 1,732 | **21.56元** | H2毛利率跌破24.6%+IGBT第三轮涨价落地 |
| **中性（Base，修正后）** | 55% | 1.08元 | 24x（交叉验证，修正后约25.8x） | 2,248（未调节基准2,101） | **28.00元** | 核心假设；含+7%审计调节 |
| **乐观（Bull）** | 20% | 1.20元 | 28x | 2,699 | **33.60元** | H2交付放量+毛利率26.2%兑现 |

**加权目标价** = 0.25×21.56 + 0.55×28.00 + 0.20×33.60 = **27.51元**（较现价23.15元+18.8%）

**盈亏比（框架口径）**：当前价23.15元已高于保守情景目标21.56元（高7.4%），公式适用：
**盈亏比** = (27.51 - 23.15) / (23.15 - 21.56) = 4.36 / 1.59 = **2.74:1**。赔率正向但较中报前进一步收窄，配置价值依赖Q3毛利率拐点确认。

> **口径说明**：盈亏比分母必须采用未调节的保守情景目标价21.56元。技术面关键位仅作为极端情形提示，不参与盈亏比计算。

### 4.2 核心结论

以当前价23.15元：
- **乐观情景**（+45.1%上行至33.60元）
- **保守情景未被击穿**（23.15 > 21.56），安全边际存在但变薄
- **不对称性仍正向**：加权目标价27.51元，上行空间4.36元（+18.8%），保守情景下行空间1.59元（-6.9%）

## 五、逻辑证伪与极限压力测试

### 5.1 "一击毙命"黑天鹅定义

最能推翻当前所有看涨逻辑的事件：**国家电网在未来3年内实质性削减设备采购预算，或因电力体制改革被迫将核心调度/控保系统开放竞标**。

### 5.2 极端场景审计

| 压力维度 | 极端假设 | 对南瑞影响 |
|:---|:---|:---|
| 国网投资削减 | 年投资从7,500亿降至5,000亿（-33%） | 网内营收下降至~280亿，总营收~550亿，净利~58亿，EPS=0.72元 |
| 调度/控保系统开放竞争 | 市占率从70%降至40% | 电网智能毛利率从30%降至22%，营收降至~250亿 |
| 重大产品事故 | 核心产品召回/赔偿 | 一次性损失50-100亿，品牌信誉永久损伤 |
| 中美全面脱钩 | IGBT/DSP/FPGA对华全面禁运 | 电网智能和能源低碳业务产能受限，毛利率断崖式下跌 |

### 5.3 "地狱价格"估算

最坏情况下（国网投资削减+竞争开放+中美脱钩同时发生）：
- 营收降至400亿，净利润30亿，EPS=0.37元
- PB定价：BVPS 7.00元 × 1.5x（清算折价50%）= **10.50元**
- PE定价：0.37元 × 15x = 5.55元

**综合极限支撑位**：取PB定价，约 **10-12元**。概率趋近于零。

更现实的"软下限"（温和熊市+增速放缓）：EPS 0.98元 × 21x = **20.60元**，下行空间约-11%，仍属可控。
