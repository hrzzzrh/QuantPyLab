**标的**：国电南瑞 (600406.SH)

**前序模块红线继承**：模块五基准预测2026E EPS 1.15元（7月13日下修：原1.20元，-4.2%）、2027E EPS 1.44元（原1.47元）、2028E EPS 1.75元（原1.78元）。**下修原因**：英飞凌7月1日第二轮IGBT涨价（+10-20%）额外拖累2026E毛利率约0.5pp，综合毛利率从26.0%下修至25.5%，归母净利从96亿下修至92.6亿。**7月13日至7月28日期间，股价从21.70→23.56元（+8.6%），市值回升约149亿元。当前价已高于保守情景目标22.44元（+5.0%），但仍低于中性目标价29.40元约19.9%，较年内高点31.52元累计回撤-25.3%。12家机构一致预期2026E净利93.24亿、EPS 1.16元——仍略高于我们的基准预测。市场定价从"低于Bear case"修复为"介于Bear与Base之间"，风险收益仍正向，但不再是7月13日的极端错杀状态。**

## 一、价值锚定：适配性方法选择

### 1.1 方法论选择理由

国电南瑞的商业模式特征是：**高ROE（16%）+ 稳定增长（10-20%）+ 强现金流 + 低资本开支**。适用以下估值方法：

| 方法 | 适用性 | 权重 | 选择理由 |
|:---|:---:|:---:|:---|
| **PE估值**（主力） | ★★★★★ | 50% | 盈利稳定、扣非占比>96%，PE是可比的行业通用语言 |
| **PEG修正** | ★★★★ | 15% | 增长差异大，PEG可修正单纯PE的静态缺陷 |
| **PB-ROE** | ★★★★ | 20% | 净资产定价有锚，ROE>15%应享有PB溢价 |
| **DCF** | ★★★ | 15% | 现金流优秀（OCF/NP=1.54x），但电网投资周期性强，远期假设敏感 |

**不适用方法**：PS（净利率稳定，PS冗余）、EV/EBITDA（无显著带息负债，杠杆中性）

### 1.2 历史分位审计

基于近10年（2016-2026年）交易数据：

| 指标 | P5 | P10 | P25 | **P50** | P75 | P90 | P95 | **当前(7/28)** | **前值(7/13)** | 当前分位 |
|:---|---:|---:|---:|---:|---:|---:|---:|---:|---:|:---:|
| PE TTM | 13.14 | 19.83 | 22.20 | **25.26** | 28.14 | 31.36 | 34.71 | **22.86** | 21.1 | **P28.9** |
| PB | 3.05 | 3.17 | 3.58 | **4.14** | 4.62 | 5.16 | 6.12 | **3.59** | 3.31 | **P24.5** |

**近年PE中位趋势**：2021: 30.9x → 2022: 31.3x → 2023: 28.0x → 2024: 26.9x → 2025: 23.5x。PE中枢逐年下移反映了市场对电网投资增速放缓的持续担忧——但2026年"十五五"4万亿的官宣完全打破了这一叙事。

**7月28日更新**：股价反弹（21.70→23.56，+8.6%）使PE TTM从约21.1x升至22.86x，分位从P14回到P28.9；PB从约3.31x升至3.59x，分位回到P24.5。估值仍低于近10年中位数，但已不属于"仅危机时刻才出现"的极端低位。换言之，市场已对7月中旬的恐慌进行一轮修复，后续赔率更依赖半年报毛利率、国网投资执行和特高压订单确认。

**核心论点（维持但降温）**：当前南瑞面临的环境已发生质变——1）"十五五"电网投资从2.85万亿跃升至5万亿（+75%），增长率而非存量规模决定了PE；2）反内卷→利润率修复，盈利质量改善；3）海外+储能打开全新市场空间；4）特高压招标年内前三批约292.6亿元、已显著超过2025全年节奏。**估值仍低于历史中位，但"极端背离"已部分修复。PE法合理倍数取26x（近10年P50-60区间），PEG修正（20x）与PB-ROE（3.5x）交叉验证后中性情景综合倍数约24x；加仓纪律应从"无条件左侧"转为"等待MA60/MA120修复或半年报验证"。**

## 二、多方法交叉估值

### 2.1 PE估值（权重50%）

```
目标市值 = 2026E归母净利润 × 合理PE
```

**合理PE确定**：
- 近5年PE中位：27x（各年波动中枢的均值）
- 近10年PE中位：25.3x
- 行业可比（电力二次设备龙头+15%增速）：25-30x
- 综合取：**26x**（处于近10年P50-P60之间，保守但不过度保守）

**2026E PE估值**：92.6亿 × 26 = **2,408亿** → 目标价 **29.98元**（+27.2%）

**2027E前瞻PE估值**（Q4滚算时适用）：115.8亿 × 24 = 2,779亿 → 34.60元

### 2.2 PEG修正（权重15%）

```
2026E增速 = 11.9%（归母净利，较6月14日16.0%下修）
2027E增速 = 25.0%（毛利率回升加速）

取两年复合增速 ~18%，合理PEG = 1.0-1.2（南瑞确定性溢价）
合理PE = PEG × G = 1.0~1.2 × 18 = 18~22x
```

**PEG估值**：取中值20x → 92.6亿 × 20 = **1,852亿** → 目标价 **23.06元**（-2.1%）

PEG估值显著偏低的原因：2026E增速仅11.9%（受毛利率压制），拉低了复合增长率。但2027E增速跳升至25%反映的是毛利率修复带来的利润弹性，PEG的线性外推低估了这一弹性。作为安全边际参考，不作主要定价依据。

### 2.3 PB-ROE模型（权重20%）

```
合理PB = (ROE - g) / (COE - g)
        = (16.0% - 5%) / (9% - 5%)
        = 11.0% / 4%
        = 2.75x

历史PB中位4.14x，当前PB 3.59x（P24.5分位）。
取3.3-3.8x（低于历史中位，保守起见）。
```

模型输出2.75x系COE 9%、g 5%的严苛参数假设。考虑南瑞ROE仍处上行通道（2026E约16.5%）且低利率环境（10年期国债1.6-1.8%）压降股权成本，按COE 8.5%、g 5%复算：合理PB = (16.5% - 5%) / (8.5% - 5%) = 11.5% / 3.5% = **3.29x**，故取值区间锚定3.3-3.8x并取保守下沿3.5x（仍显著低于历史中位4.14x）。

2025年末BVPS = 6.55元。按60%分红率估算2026E每股派息约0.69元（92.6亿×60%÷80.32亿股），2026年末BVPS ≈ 6.55 + 1.15 - 0.69 = 7.01元。

**PB-ROE估值**：7.01元 × 3.5 = 24.54元/股 → 市值 **1,971亿**

### 2.4 DCF估值（上限参考，不参与合成）

核心假设：
- 自由现金流 = OCF - CAPEX。2025年OCF 127.7亿，CAPEX（购建固定资产支付）21.1亿，FCF ≈ 106.6亿
- 2026-2028年FCF增速：20%/18%/15%（与利润增速匹配）
- 2029-2030年FCF增速：12%/10%
- 永续增长率g=3%（通胀+电网自然增长）
- WACC=8.5%（无风险利率1.7%+股权风险溢价6.8%，β=1.0）

经DCF模型计算（简化版）：

| 年份 | FCF（亿） | PV（亿，折现率8.5%） |
|:---|---:|---:|
| 2026E | 128 | 117.9 |
| 2027E | 151 | 128.2 |
| 2028E | 174 | 135.9 |
| 2029E | 194 | 140.3 |
| 2030E | 214 | 142.2 |
| 终值 | 4,004 | 2,662.7 |
| **企业价值** | | **3,327.2** |
| 加：现金 | | +73 |
| 减：带息债务 | | -10 |
| **股权价值** | | **3,390亿** |

**DCF估值**：3,390亿 → **42.21元/股**

DCF显著高于PE/PB估值，原因是永续增长部分（3%）对长生命周期电网龙头给予了过高权重。鉴于电网投资周期性强、2030年后增长能见度低，**DCF仅作上限参考，不参与目标价合成**（权重0%）。

（DCF因永续假设过度慷慨仅作上限参考，剔除后PE/PEG/PB-ROE按85%权重重归一化；现价自7月13日21.70元反弹至23.56元，基准口径上行空间已明显压缩）

```
修正目标市值 = 中性情景市值 × (1 + Σ调节)
             = 2,207亿 × (1 + 7%) = 2,361亿
修正目标价 = 2,361亿 / 80.32亿股 = 29.40元
```

**修正后2026年中性目标价：29.40元（不复权），较现价23.56元，潜在升幅 24.8%。**

## 四、确定性与胜率矩阵

### 4.1 三态逻辑加权

基于模块五的情景分析（三态目标价 = 情景市值 ÷ 股本；中性情景采用调节后的修正目标市值，保守/乐观采用未调节情景市值）：

| 情景 | 概率 | 2026E EPS | 估值倍数 | 情景市值（亿） | 目标价 | 备考 |
|:---|---:|---:|---:|---:|---:|:---|
| **保守（Bear）** | 25% | 1.02元 | 22x | 1,802 | **22.44元** | 国网执行不力+IGBT继续涨价 |
| **中性（Base，修正后）** | 55% | 1.15元 | 24x（交叉验证，修正后约25.6x） | 2,361（未调节基准2,207） | **29.40元** | 核心假设；含+7%审计调节 |
| **乐观（Bull）** | 20% | 1.31元 | 28x | 2,946 | **36.68元** | 超预期兑现 |

**加权目标价** = 0.25×22.44 + 0.55×29.40 + 0.20×36.68 = **29.12元**（较现价23.56元+23.6%）

**盈亏比（框架口径）**：当前价23.56元已高于保守情景目标22.44元（高5.0%），公式适用：
**盈亏比** = (29.12 - 23.56) / (23.56 - 22.44) = 5.56 / 1.12 = **4.96:1**。赔率仍正向，但已从7月13日的"极端不对称"回归到"可配置但需等待验证"。

> **口径说明**：盈亏比分母必须采用未调节的保守情景目标价22.44元。技术支撑位MA250（20.42元，较现价约-13.3%）仅作为极端情形提示，不参与盈亏比计算；7月13日现价21.70元低于保守价22.44元时公式不适用（保守情景下行空间为负）。

### 4.2 核心结论

以当前价23.56元：
- **乐观情景**（+55.7%上行至36.68元）
- **保守情景不再被击穿**（23.56 > 22.44），7月中旬低估错杀已部分修复
- **不对称性仍正向但显著收窄**：加权目标价29.12元，上行空间5.56元（+23.6%），保守情景下行空间1.12元（-4.8%）；极端情形参考：若跌破MA250（20.42元），较现价下行约-13.3%

## 五、逻辑证伪与极限压力测试

### 5.1 "一击毙命"黑天鹅定义

最能推翻当前所有看涨逻辑的事件：**国家电网在未来3年内实质性削减设备采购预算，或因电力体制改革被迫将核心调度/控保系统开放竞标**。

### 5.2 极端场景审计

| 压力维度 | 极端假设 | 对南瑞影响 |
|:---|:---|:---|
| 国网投资削减 | 年投资从7,500亿降至5,000亿（-33%） | 网内营收下降至~280亿，总营收~550亿，净利~60亿，EPS=0.75元 |
| 调度/控保系统开放竞争 | 市占率从70%降至40% | 电网智能毛利率从30%降至22%，营收降至~250亿 |
| 重大产品事故 | 核心产品召回/赔偿 | 一次性损失50-100亿，品牌信誉永久损伤 |
| 中美全面脱钩 | IGBT/DSP/FPGA对华全面禁运 | 电网智能和能源低碳业务产能受限，毛利率断崖式下跌 |

### 5.3 "地狱价格"估算

最坏情况下（国网投资削减+竞争开放+中美脱钩同时发生）：
- 营收降至400亿，净利润30亿，EPS=0.37元
- PB定价：BVPS 7.01元 × 1.5x（清算折价50%）= **10.52元**
- PE定价：0.37元 × 15x = 5.55元

**综合极限支撑位**：取PB定价，约 **10-12元**。概率趋近于零。

更现实的"软下限"（温和熊市+增速放缓）：EPS 1.02元 × 20x = **20.40元**，接近MA250（20.42元），构成强支撑。下行空间13.4%，仍属可控但不再极小。
