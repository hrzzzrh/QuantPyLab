## 一、价值锚定：适配性方法选择

### 1.1 方法论选择理由

国电南瑞的商业模式特征是：**高ROE（16%）+ 稳定增长（10-20%）+ 强现金流（但2026年受账期政策扰动）+ 低资本开支**。适用以下估值方法：

| 方法 | 适用性 | 权重 | 选择理由 |
|:---|:---:|:---:|:---|
| **PE估值**（主力） | ★★★★★ | 50% | 盈利稳定、扣非占比>96%，PE是可比的行业通用语言 |
| **PEG修正** | ★★★★ | 15% | 增长差异大，PEG可修正单纯PE的静态缺陷 |
| **PB-ROE** | ★★★★ | 20% | 净资产定价有锚，ROE>15%应享有PB溢价 |
| **DCF** | ★★ | 0% | 现金流优秀（历史OCF/NP 1.5x），但2026年账期政策化缩短使FCF基线不可比，仅作下限参考 |

**不适用方法**：PS（净利率稳定，PS冗余）、EV/EBITDA（无显著带息负债，杠杆中性）

**核心论点（2027E目标年份重锚定）**："十五五"电网投资从2.85万亿跃升至5万亿（+75%）、《新型电力系统建设"十五五"规划》纲领落地、反内卷→利润率修复、海外+储能打开全新空间——四重逻辑未变，但2026年国网投资增速回落至+5.2%、Q3利润转负、人民币升值，使2027E利润弹性从"+24.7%"下调至"+20.8%"。PE法合理倍数取26x（近10年P50-P60区间），PEG修正（20.4x）与PB-ROE（3.5x）交叉验证后中性情景综合倍数约24x。

## 二、多方法交叉估值

### 2.1 PE估值（权重50%）

```
目标市值 = 2027E归母净利润 × 合理PE
```

**合理PE确定**：
- 近5年PE中位：27x（各年波动中枢的均值）
- 近10年PE中位：25.1x（与§1.2表内P50 25.12一致）
- 行业可比（电力二次设备龙头+15%增速）：25-30x
- 综合取：**26x**（处于近10年P50-P60之间，保守但不过度保守）

**2027E PE估值**：103.7亿 × 26 = **2,696亿** → 目标价 **33.57元**（+43.8%）

### 2.2 PEG修正（权重15%）

```
2027E增速 = 20.8%（归母净利）
2028E增速 = 19.3%（归母净利）

两年复合增速 ~20.0%；剔除2027年汇兑损失、减值上修等一次性偏压项
（合计压制约1.5pp增速）后，可持续复合增速约18.5%
取PEG = 1.1-1.2（南瑞确定性溢价）
合理PE = 1.1 × 18.5 ≈ 20.4x
```

**PEG估值**：103.7亿 × 20.4 = **2,115亿** → 目标价 **26.34元**（+12.9%）

PEG口径低于PE法的原因：即便还原一次性偏压，18.5%的复合增速对应20.4x仍属保守定价；其价值在于提供"若市场仅按线性成长给价"的安全边际参考，不作主要定价依据。

### 2.3 PB-ROE模型（权重20%）

```
合理PB = (ROE - g) / (COE - g)
         = (16.0% - 5%) / (9% - 5%)
         = 2.75x

历史PB中位4.77x，当前PB 3.57x（P9低分位）。
取3.3-3.8x（低于历史中位，保守起见）。
```

模型输出2.75x系COE 9%、g 5%的严苛参数假设。考虑南瑞ROE仍处16%+平台且低利率环境（10年期国债1.6-1.8%）压降股权成本，按COE 8.5%、g 5%复算：合理PB = (16.5% - 5%) / (8.5% - 5%) = **3.29x**，故取值区间锚定3.3-3.8x并取保守下沿3.5x（仅为历史中位4.77x的73%）。

2025年末BVPS = 6.55元。按60%分红率估算2026E每股派息约0.64元（中期0.153元已实施+年度预计约0.49元），2026年末BVPS ≈ 6.55 + 1.069 - 0.64 = 6.98元。2027年末BVPS ≈ 6.98 + 1.291 - 0.70 = 7.57元。

**PB-ROE估值**：7.57元 × 3.5 = 26.50元/股 → 市值 **2,129亿**

### 2.4 DCF估值（下限参考，不参与合成）

核心假设：
- 2026年经营现金流受账期政策化缩短一次性拖累（前三季-29.20亿元、应付票据及应付账款较年初-58.43亿元），FCF按45亿元计；这隐含2026全年OCF约63亿元（capex约18亿元），Q4单季需+92亿元（2025Q4为+80.6亿元，+14%），依赖Q4集中回款。2027年起应付账款水平稳定，FCF恢复至90亿元，2028-2030年105/120/135亿元
- 永续增长率g=3%（通胀+电网自然增长）
- WACC=8.5%（无风险利率1.7%+股权风险溢价6.8%，β=1.0）

经DCF模型计算（简化版）：

| 年份 | FCF（亿） | PV（亿，折现率8.5%） |
|:---|---:|---:|
| 2026E | 45 | 41.5 |
| 2027E | 90 | 76.5 |
| 2028E | 105 | 82.2 |
| 2029E | 120 | 86.6 |
| 2030E | 135 | 89.8 |
| 终值 | 2,528 | 1,681.4 |
| **企业价值** | | **2,057.9** |
| 加：货币资金及交易性金融资产 | | +129 |
| 减：带息债务 | | -10 |
| **股权价值** | | **2,176.9亿** |

**DCF估值**：2,176.9亿 → **27.10元/股**

DCF显著低于PE/PB估值，原因是2026年账期政策化缩短使FCF基线永久性下移（应付票据及应付账款从297亿降至239亿，类金融浮存贡献消失），且2030年后增长能见度低。**DCF仅作下限参考，不参与目标价合成**（权重0%）；它传递的信号是：即便按保守现金流，当前23.34元仍低于DCF值27.10元约13.9%，市场已计入较悲观的现金转化假设。但该结论对2026Q4回款高度敏感：若Q4 OCF低于70亿元，DCF将降至24元附近，与现价基本重合。

## 四、确定性与胜率矩阵

### 4.1 三态逻辑加权

基于模块五的情景分析（三态市值 = 三态EPS × 情景估值倍数；三态目标价 = 情景市值 ÷ 股本；中性情景采用调节后的修正目标市值，保守/乐观采用未调节情景市值）：

**三态市值计算**：
- 保守：89.7亿（归母净利）× 22x = 1,973亿
- 中性（未调节）：103.7亿 × 24x = 2,489亿
- 中性（修正后）：2,489亿 × (1+7%) = 2,663亿
- 乐观：115.9亿 × 28x = 3,245亿

**三态目标价计算**（股本80.31756亿股）：
- 保守：1,973亿 ÷ 80.31756亿股 = 24.57元
- 中性（修正后）：2,663亿 ÷ 80.31756亿股 = 33.16元
- 乐观：3,245亿 ÷ 80.31756亿股 = 40.39元

| 情景 | 概率 | 2027E EPS | 估值倍数 | 情景市值（亿） | 目标价 | 备考 |
|:---|---:|---:|---:|---:|---:|:---|
| **保守（Bear）** | 25% | 1.117元 | 22x | 1,973 | **24.57元** | 国网投资7,200-7,500亿+毛利率25.2% |
| **中性（Base，修正后）** | 55% | 1.291元 | 24x（交叉验证，修正后约25.7x） | 2,663（未调节中性情景2,489） | **33.16元** | 核心假设；含+7%审计调节 |
| **乐观（Bull）** | 20% | 1.443元 | 28x | 3,245 | **40.39元** | 国网投资>8,300亿+毛利率26.6% |

**加权目标价** = 0.25×24.57 + 0.55×33.16 + 0.20×40.39 = 6.14 + 18.24 + 8.08 = **32.46元**（较现价23.34元+39.1%）

**盈亏比（框架口径）**：当前价23.34元**低于**保守情景目标24.57元（低5.0%），公式不适用：
**盈亏比记 ∞+**（含义为下行空间为负，并非真实盈亏比无穷大）。

> **口径说明**：盈亏比分母必须采用未调节的保守情景目标价24.57元。现价23.34元 < 保守价24.57元，分母为负、公式不适用，一律表述为"保守情景下行空间为负"，投研汇总（note.md）按项目惯例记 **∞+**。需注意：现价距保守价仅-5.0%，安全垫较10月初（-18.2%）明显收窄，∞+的"下行保护"含义弱化，不能据此放大仓位。

### 4.2 核心结论

以当前价23.34元：
- **保守情景**（+5.3%上行至24.57元）——现价低于保守价，下行空间为负，但仅-5.0%，安全垫薄

## 五、逻辑证伪与极限压力测试

### 5.1 "一击毙命"黑天鹅定义

最能推翻当前所有看涨逻辑的事件：**国家电网在未来3年内实质性削减设备采购预算，或因电力体制改革被迫将核心调度/控保系统开放竞标**。

### 5.2 极端场景审计

| 压力维度 | 极端假设 | 对南瑞影响 |
|:---|:---|:---|
| 国网投资削减 | 年投资从8,000亿降至5,000亿（-37%） | 网内营收下降至~280亿，总营收~600亿，净利~62亿，EPS=0.77元 |
| 调度/控保系统开放竞争 | 市占率从70%降至40% | 电网智能毛利率从30%降至22%，营收降至~250亿 |
| 重大产品事故 | 核心产品召回/赔偿 | 一次性损失50-100亿，品牌信誉永久损伤 |
| 中美全面脱钩 | IGBT/DSP/FPGA对华全面禁运 | 电网智能和能源低碳业务产能受限，毛利率断崖式下跌 |
| **账期进一步政策化** | 应付账款再降50亿、OCF连续两年<0 | 现金流折价扩大，DCF降至20元以下，分红能力受限 |

### 5.3 "地狱价格"估算

最坏情况下（国网投资削减+竞争开放+中美脱钩同时发生）：
- 营收降至400亿，净利润30亿，EPS=0.37元
- PB定价：BVPS 7.57元 × 1.5x（清算折价50%）= **11.36元**
- PE定价：0.37元 × 15x = 5.55元

**综合极限支撑位**：取PB定价，约 **10-12元**。概率趋近于零。

更现实的"软下限"（温和熊市+增速放缓）：EPS 1.117元 × 21x = **23.46元**，较现价23.34元高约0.5%，二者基本重合。**这意味着市场当前定价已接近保守情景，进一步下跌需要"保守情景被证伪"（如2027年国网预算<7,000亿、毛利率跌破25%）**；但同时也说明，现价缺乏10月初那种"低于保守价18%"的厚安全垫。
