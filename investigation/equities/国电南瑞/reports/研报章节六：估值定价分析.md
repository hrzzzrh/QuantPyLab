## 一、价值锚定：适配性方法选择

### 1.1 方法论选择理由

国电南瑞的商业模式特征是：**高ROE（16%）+ 稳定增长（10-20%）+ 强现金流 + 低资本开支**。适用以下估值方法：

| 方法 | 适用性 | 权重 | 选择理由 |
|:---|:---:|:---:|:---|
| **PE估值**（主力） | ★★★★★ | 50% | 盈利稳定、扣非占比>96%，PE是可比的行业通用语言 |
| **PEG修正** | ★★★★ | 15% | 增长差异大，PEG可修正单纯PE的静态缺陷 |
| **PB-ROE** | ★★★★ | 20% | 净资产定价有锚，ROE>15%应享有PB溢价 |
| **DCF** | ★★★ | 15% | 现金流优秀（OCF/NP=1.54x），但电网投资周期性强，远期假设敏感 |

**不适用方法**：PS（净利率稳定，PS冗余）、EV/EBITDA（无显著带息负债，杠杆中性）

### 1.2 历史分位审计

基于近10年（2016-2026年）交易数据：

| 指标 | P5 | P10 | P25 | **P50** | P75 | P90 | P95 | **当前(7/13)** | **前值(6/14)** | 当前分位 |
|:---|---:|---:|---:|---:|---:|---:|---:|---:|---:|:---:|
| PE TTM | 13.14 | 19.83 | 22.20 | **25.14** | 28.14 | 31.36 | 34.71 | **~21.1** | 22.5 | ~P14 |
| PB | 3.05 | 3.17 | 3.58 | **4.13** | 4.62 | 5.16 | 6.12 | **~3.31** | 3.55 | ~P17 |

**近年PE中位趋势**：2021: 30.9x → 2022: 31.3x → 2023: 28.0x → 2024: 26.9x → 2025: 23.5x。PE中枢逐年下移反映了市场对电网投资增速放缓的持续担忧——但2026年"十五五"4万亿的官宣完全打破了这一叙事。

**7月13日更新**：股价进一步下挫（23.24→21.70，-6.6%）使PE TTM从P26降至P14（低于历史中位近1.5个标准差），PB从P23降至P17。当前21.1x PE TTM处于近10年仅高于13%交易日的极端低位——过去10年中，只有在2018年贸易战恐慌、2020年3月疫情恐慌等系统性危机时刻，南瑞才达到或低于当前估值水平。

**核心论点（维持且强化）**：当前南瑞面临的环境已发生质变——1）"十五五"电网投资从2.85万亿跃升至5万亿（+75%），增长率而非存量规模决定了PE；2）反内卷→利润率修复，盈利质量改善；3）海外+储能打开全新市场空间；4）特高压招标年内已超180亿（同比翻倍+）。**在基本面为2016年以来最强、估值却为2016年以来最低的极端背离下，合理PE应显著高于当前水平。保守取近5年P50（27.4x）作为合理PE中枢。**

## 二、多方法交叉估值

### 2.1 PE估值（权重50%）

```
目标市值 = 2026E归母净利润 × 合理PE
```

**合理PE确定**：
- 近5年PE中位：27x（各年波动中枢的均值）
- 近10年PE中位：25.4x
- 行业可比（电力二次设备龙头+15%增速）：25-30x
- 综合取：**26x**（处于近10年P50-P60之间，保守但不过度保守）

**2026E PE估值**：92.6亿 × 26 = **2,408亿** → 目标价 **29.98元**（+38.2%）

**2027E前瞻PE估值**（Q4滚算时适用）：115.8亿 × 24 = 2,779亿 → 34.60元

### 2.2 PEG修正（权重15%）

```
2026E增速 = 11.9%（归母净利，较6月14日16.0%下修）
2027E增速 = 25.0%（毛利率回升加速）

取两年复合增速 ~18%，合理PEG = 1.0-1.2（南瑞确定性溢价）
合理PE = PEG × G = 1.0~1.2 × 18 = 18~22x
```

**PEG估值**：取中值20x → 92.6亿 × 20 = **1,852亿** → 目标价 **23.06元**（+6.3%）

PEG估值显著偏低的原因：2026E增速仅11.9%（受毛利率压制），拉低了复合增长率。但2027E增速跳升至25%反映的是毛利率修复带来的利润弹性，PEG的线性外推低估了这一弹性。作为安全边际参考，不作主要定价依据。

### 2.3 PB-ROE模型（权重20%）

```
合理PB = (ROE - g) / (COE - g)
        = (16.0% - 5%) / (9% - 5%)
        = 11.0% / 4%
        = 2.75x

历史PB中位4.13x，当前PB仅3.31x（P17分位）。
取3.3-3.8x（低于历史中位，保守起见）。
```

2025年末BVPS = 6.55元。2026年末BVPS ≈ 6.55 + 1.15 - 0.48（全年分红约0.48元）= 7.22元。

**PB-ROE估值**：7.22元 × 3.5 = 25.27元/股 → 市值 **2,030亿**

### 2.4 DCF估值（权重15%）

核心假设：
- 自由现金流 = OCF - CAPEX。2025年OCF 127.7亿，CAPEX约8亿（购建固定资产），FCF ≈ 120亿
- 2026-2028年FCF增速：20%/18%/15%（与利润增速匹配）
- 2029-2030年FCF增速：12%/10%
- 永续增长率g=3%（通胀+电网自然增长）
- WACC=8.5%（无风险利率1.7%+股权风险溢价6.8%，β=1.0）

经DCF模型计算（简化版）：

| 年份 | FCF（亿） | PV（亿，折现率8.5%） |
|:---|---:|---:|
| 2026E | 144 | 132.7 |
| 2027E | 170 | 144.4 |
| 2028E | 196 | 153.5 |
| 2029E | 219 | 158.0 |
| 2030E | 241 | 160.2 |
| 终值 | 4,517 | 3,001.5 |
| **企业价值** | | **3,750.3** |
| 加：现金 | | +73 |
| 减：带息债务 | | -10 |
| **股权价值** | | **3,813亿** |

**DCF估值**：3,813亿 → **47.48元/股**

DCF显著高于PE/PB估值，原因是永续增长部分（3%）对长生命周期电网龙头给予了过高权重。鉴于电网投资周期性强、2030年后增长能见度低，**DCF仅作上限参考，不参与目标价合成**。

## 三、核心：估值全变量对冲审计矩阵

### 3.1 估值影响力过滤（审慎思考）

在众多利好利空中，经由审慎辨析，**只有以下因子真正具备改变南瑞估值中枢的能力**：

| 审计维度 | 核心因子 | **审慎思考（估值影响力过滤）** | 调节 | 深度理由 |
|:---|:---|:---|:---:|:---|
| **DNA：战略定力** | "设计+封测"不搞晶圆制造的克制 | **留存**。这种战略精准预判在MATCH法案落地半年来持续被验证。IGBT自主中压10万只交付、高压挂网运行。 | **+5%** | 战略克制→资本配置效率↑→长期ROE韧性→PB估值溢价。 |
| **DNA：内生孵化能力** | 南瑞继保（构网储能全球领先）+ 科东（调度系统） | **留存**。持续孵化出行业第一的能力是极少数公司具备的"估值溢价基因"。 | **+3%** | 内生孵化→增长可持续性↑→长期CAGR预期↑→PE估值溢价。 |
| **宏观：政策与战略对齐** | "六张网"政策优先级+4万亿投资 | **过滤**。政策红利已充分体现在利润预测（E）中。 | **0%** | E已体现。 |
| **宏观：地缘与外部约束** | 中美芯片出口管制长期风险 | **留存但折价温和**。南瑞IGBT设计+封测模式已证明有效性。 | **-3%** | 地缘约束→长期PE折价，但幅度有限。 |
| **市场：流动性溢价** | 机构重仓+高分红+市值约1,743亿 | **过滤**。南瑞已是沪深300核心成分股。 | **0%** | 现有估值已反映流动性属性。 |

| **综合调节系数** | | | **+8%** | |

```
修正目标市值 = 2,459亿 × (1 + 8%) = 2,656亿
修正目标价 = 2,656亿 / 80.32亿股 = 33.06元
```

**修正后2026年目标价：33.06元（不复权），较现价21.70元，潜在升幅 52.4%。**
（6月14日修正目标价35.48元，下调源于盈利预测下修；上行空间从52.7%基本持平）

## 四、确定性与胜率矩阵

### 4.1 三态逻辑加权

基于模块五的情景分析：

| 情景 | 概率 | 2026E EPS | 简化PE | 目标价 | 备考 |
|:---|---:|---:|---:|---:|:---|
| **保守（Bear）** | 25% | 1.02元 | 22x | **22.44元** | 国网执行不力+IGBT继续涨价 |
| **基准（Base）** | 55% | 1.15元 | 26x | **29.90元** | 核心假设 |
| **乐观（Bull）** | 20% | 1.31元 | 28x | **36.68元** | 超预期兑现 |

**加权目标价** = 0.25×22.44 + 0.55×29.90 + 0.20×36.68 = **29.39元**（较现价21.70元+35.4%）

**7月13日重新计算盈亏比**：当前价21.70元低于保守情景目标22.44元（低3.3%），意味着市场定价已隐含比Bear case更悲观的预期。以极限支撑位MA250（20.10元）作为下行锚点：
**盈亏比** = (29.39 - 21.70) / (21.70 - 20.10) = 7.69 / 1.60 = **4.81:1**，不对称性依然显著。

### 4.2 核心结论

以当前价21.70元：
- **乐观情景**（+69.0%上行至36.68元）
- **保守情景当前已被市场价格向下击穿**（21.70 < 22.44），市场定价隐含的悲观程度已超出Bear case假设
- **不对称性维持高位**：加权目标价29.39元，上行空间7.69元（+35.4%），以MA250（20.10元）计算下行风险仅1.60元（-7.4%）

## 五、逻辑证伪与极限压力测试

### 5.1 "一击毙命"黑天鹅定义

最能推翻当前所有看涨逻辑的事件：**国家电网在未来3年内实质性削减设备采购预算，或因电力体制改革被迫将核心调度/控保系统开放竞标**。

### 5.2 极端场景审计

| 压力维度 | 极端假设 | 对南瑞影响 |
|:---|:---|:---|
| 国网投资削减 | 年投资从7,500亿降至5,000亿（-33%） | 网内营收下降至~280亿，总营收~550亿，净利~60亿，EPS=0.75元 |
| 调度/控保系统开放竞争 | 市占率从70%降至40% | 电网智能毛利率从30%降至22%，营收降至~250亿 |
| 重大产品事故 | 核心产品召回/赔偿 | 一次性损失50-100亿，品牌信誉永久损伤 |
| 中美全面脱钩 | IGBT/DSP/FPGA对华全面禁运 | 电网智能和能源低碳业务产能受限，毛利率断崖式下跌 |

### 5.3 "地狱价格"估算

最坏情况下（国网投资削减+竞争开放+中美脱钩同时发生）：
- 营收降至400亿，净利润30亿，EPS=0.37元
- PB定价：BVPS 7.22元 × 1.5x（清算折价50%）= **10.83元**
- PE定价：0.37元 × 15x = 5.55元

**综合极限支撑位**：取PB定价，约 **10-12元**。概率趋近于零。

更现实的"软下限"（温和熊市+增速放缓）：EPS 1.02元 × 20x = **20.40元**，接近MA250（20.10元），构成强支撑。下行空间6.0%，为有限风险。
