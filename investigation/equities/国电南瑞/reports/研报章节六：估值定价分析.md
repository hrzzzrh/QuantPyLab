## 一、价值锚定：适配性方法选择

### 1.1 方法论选择理由

国电南瑞的商业模式特征是：**高ROE（16%）+ 稳定增长（10-20%）+ 强现金流 + 低资本开支**。适用以下估值方法：

| 方法 | 适用性 | 权重 | 选择理由 |
|:---|:---:|:---:|:---|
| **PE估值**（主力） | ★★★★★ | 50% | 盈利稳定、扣非占比>96%，PE是可比的行业通用语言 |
| **PEG修正** | ★★★★ | 15% | 增长差异大，PEG可修正单纯PE的静态缺陷 |
| **PB-ROE** | ★★★★ | 20% | 净资产定价有锚，ROE>15%应享有PB溢价 |
| **DCF** | ★★★ | 15% | 现金流优秀（OCF/NP历史1.5x），但电网投资周期性强，远期假设敏感 |

**不适用方法**：PS（净利率稳定，PS冗余）、EV/EBITDA（无显著带息负债，杠杆中性）

## 二、多方法交叉估值

### 2.1 PE估值（权重50%）

```
目标市值 = 2027E归母净利润 × 合理PE
```

**合理PE确定**：
- 近5年PE中位：27x（各年波动中枢的均值）
- 近10年PE中位：25.3x
- 行业可比（电力二次设备龙头+15%增速）：25-30x
- 综合取：**26x**（处于近10年P50-P60之间，保守但不过度保守）

**2027E PE估值**：108.5亿 × 26 = **2,821亿** → 目标价 **35.12元**（+56.8%）

### 2.2 PEG修正（权重15%）

```
2027E增速 = 24.7%（归母净利）
2028E增速 = 20.7%（归母净利）

两年复合增速 ~22.7%；剔除2027年汇兑损失、减值上修等一次性偏压项
（合计压制约1.5-2pp增速）后，可持续复合增速约20%
取PEG = 1.0-1.2（南瑞确定性溢价）
合理PE = 1.1 × 20 ≈ 22x
```

**PEG估值**：108.5亿 × 22 = **2,387亿** → 目标价 **29.72元**（+32.7%）

PEG口径低于PE法的原因：即便还原一次性偏压，20%的复合增速对应22x仍属保守定价；其价值在于提供"若市场仅按线性成长给价"的安全边际参考，不作主要定价依据。

### 2.3 PB-ROE模型（权重20%）

```
合理PB = (ROE - g) / (COE - g)
         = (16.0% - 5%) / (9% - 5%)
         = 2.75x

历史PB中位4.14x，当前PB 3.45x（P4极低分位）。
取3.3-3.8x（低于历史中位，保守起见）。
```

模型输出2.75x系COE 9%、g 5%的严苛参数假设。考虑南瑞ROE仍处16%+平台且低利率环境（10年期国债1.6-1.8%）压降股权成本，按COE 8.5%、g 5%复算：合理PB = (16.5% - 5%) / (8.5% - 5%) = **3.29x**，故取值区间锚定3.3-3.8x并取保守下沿3.5x（仅为历史中位4.14x的85%）。

2025年末BVPS = 6.55元。按60%分红率估算2026E每股派息约0.65元（中期0.153元已预案+年度预计约0.50元），2026年末BVPS ≈ 6.55 + 1.08 - 0.65 = 6.98元。2027年末BVPS ≈ 6.98 + 1.35 - 0.70 = 7.63元。

**PB-ROE估值**：7.63元 × 3.5 = 26.71元/股 → 市值 **2,145亿**

### 2.4 DCF估值（上限参考，不参与合成）

核心假设：
- 自由现金流 = OCF - CAPEX（FCF为正常化经营年份口径；2026H1经营现金流因采购付款增加阶段性走弱至5.91亿，属节奏性波动）。2025年OCF 127.7亿，CAPEX（购建固定资产支付）21.1亿，FCF ≈ 106.6亿
- 2026-2028年FCF增速：20%/18%/15%（与利润增速匹配）
- 2029-2030年FCF增速：12%/10%
- 永续增长率g=3%（通胀+电网自然增长）
- WACC=8.5%（无风险利率1.7%+股权风险溢价6.8%，β=1.0）

经DCF模型计算（简化版）：

| 年份 | FCF（亿） | PV（亿，折现率8.5%） |
|:---|---:|---:|
| 2026E | 128 | 117.9 |
| 2027E | 151 | 128.2 |
| 2028E | 174 | 135.9 |
| 2029E | 194 | 140.3 |
| 2030E | 214 | 142.2 |
| 终值 | 4,004 | 2,662.7 |
| **企业价值** | | **3,327.2** |
| 加：现金 | | +73 |
| 减：带息债务 | | -10 |
| **股权价值** | | **3,390亿** |

**DCF估值**：3,390亿 → **42.21元/股**

DCF显著高于PE/PB估值，原因是永续增长部分（3%）对长生命周期电网龙头给予了过高权重；且2026H1经营现金流大幅走弱（5.91亿，-78.95%，采购付款增加）提示短期FCF质量波动。鉴于电网投资周期性强、2030年后增长能见度低，**DCF仅作上限参考，不参与目标价合成**（权重0%）。

## 四、确定性与胜率矩阵

### 4.1 三态逻辑加权

基于模块五的情景分析（三态市值 = 三态EPS × 情景估值倍数；三态目标价 = 情景市值 ÷ 股本；中性情景采用调节后的修正目标市值，保守/乐观采用未调节情景市值）：

**三态市值计算**：
- 保守：100亿（归母净利）× 22x = 2,200亿
- 中性（未调节）：108.5亿 × 24x = 2,604亿
- 中性（修正后）：2,604亿 × (1+7%) = 2,786亿
- 乐观：118亿 × 28x = 3,304亿

**三态目标价计算**（股本80.31756亿股）：
- 保守：2,200亿 ÷ 80.31756亿股 = 27.39元
- 中性（修正后）：2,786亿 ÷ 80.31756亿股 = 34.69元
- 乐观：3,304亿 ÷ 80.31756亿股 = 41.13元

| 情景 | 概率 | 2027E EPS | 估值倍数 | 情景市值（亿） | 目标价 | 备考 |
|:---|---:|---:|---:|---:|---:|:---|
| **保守（Bear）** | 25% | 1.25元 | 22x | 2,200 | **27.39元** | 国网投资执行低于预期+毛利率修复推迟 |
| **中性（Base，修正后）** | 55% | 1.35元 | 24x（交叉验证，修正后约25.8x） | 2,786（未调节基准2,604） | **34.69元** | 核心假设；含+7%审计调节 |
| **乐观（Bull）** | 20% | 1.47元 | 28x | 3,304 | **41.13元** | 国网投资加速+毛利率27.0%兑现 |

**加权目标价** = 0.25×27.39 + 0.55×34.69 + 0.20×41.13 = 6.85 + 19.08 + 8.23 = **34.15元**（较现价22.40元+52.4%）

**盈亏比（框架口径）**：当前价22.40元**低于**保守情景目标27.39元（低18.2%），公式不适用：
**盈亏比记 ∞+**（含义为下行空间为负，并非真实盈亏比无穷大）。

> **口径说明**：盈亏比分母必须采用未调节的保守情景目标价27.39元。现价22.40元 < 保守价27.39元，分母为负、公式不适用，一律表述为"保守情景下行空间为负"，投研汇总（note.md）按项目惯例记 **∞+**。

### 4.2 核心结论

以当前价22.40元：
- **保守情景**（+22.2%上行至27.39元）——现价低于保守价，下行空间为负
- **中性情景**（+54.9%上行至34.69元）
- **乐观情景**（+83.6%上行至41.13元）
- **不对称性极强**：加权目标价34.15元，上行空间11.75元（+52.4%），保守情景下行空间为负（现价已低于保守价），盈亏比∞+

## 五、逻辑证伪与极限压力测试

### 5.1 "一击毙命"黑天鹅定义

最能推翻当前所有看涨逻辑的事件：**国家电网在未来3年内实质性削减设备采购预算，或因电力体制改革被迫将核心调度/控保系统开放竞标**。

### 5.2 极端场景审计

| 压力维度 | 极端假设 | 对南瑞影响 |
|:---|:---|:---|
| 国网投资削减 | 年投资从8,000亿降至5,000亿（-37%） | 网内营收下降至~280亿，总营收~600亿，净利~62亿，EPS=0.77元 |
| 调度/控保系统开放竞争 | 市占率从70%降至40% | 电网智能毛利率从30%降至22%，营收降至~250亿 |
| 重大产品事故 | 核心产品召回/赔偿 | 一次性损失50-100亿，品牌信誉永久损伤 |
| 中美全面脱钩 | IGBT/DSP/FPGA对华全面禁运 | 电网智能和能源低碳业务产能受限，毛利率断崖式下跌 |

### 5.3 "地狱价格"估算

最坏情况下（国网投资削减+竞争开放+中美脱钩同时发生）：
- 营收降至400亿，净利润30亿，EPS=0.37元
- PB定价：BVPS 7.63元 × 1.5x（清算折价50%）= **11.45元**
- PE定价：0.37元 × 15x = 5.55元

**综合极限支撑位**：取PB定价，约 **10-12元**。概率趋近于零。

更现实的"软下限"（温和熊市+增速放缓）：EPS 1.25元 × 21x = **26.25元**，下行空间约-16.7%，仍属可控。
