# 研报章节二：产业周期与终端穿透

**研究日期**：2026年10月28日
**标的**：国电南瑞 (600406.SH)
**前序模块红线继承**：模块一发现毛利率环比企稳（Q3 25.63%）、利润单季转负（Q3归母-3.37%）、经营现金流因账期政策化缩短而流出29.20亿元三大边际，本模块将穿透终端需求验证这些隐忧的演变方向。

---

## 一、产业生命周期与周期定位

### 1.1 周期坐标：电网投资的"超级周期"确认

中国电网设备行业正处于**继2009-2012年（坚强智能电网）、2014-2018年（特高压第一轮）之后的第三轮大规模投资上行期**。与前两轮不同，本轮的核心驱动力并非单纯的电网扩容，而是新能源消纳需求倒逼的"源网协同"——发电侧风光装机大爆发后，输电和配电侧的瓶颈效应日益突出。

2026年1月15日，国家电网正式宣布"十五五"期间（2026-2030年）固定资产投资预计达到**4万亿元**，较"十四五"2.85万亿元增长**40%**，年均规模8,000亿元。叠加南方电网预计1万亿元，全国电网"十五五"总投资将**逼近5万亿元**（年均超1万亿元），较"十三五"2.64万亿和"十四五"2.85万亿实现量级跃升。

这一投资规模的确认，标志着电网设备行业正式进入**5年的确定性高景气周期**。

**关键边际变化**：
- 2026年Q1验证：国家电网完成固定资产投资超1,290亿元，同比+37%，配电网投资568亿元占各级电网投资比重55%，均创历史同期新高。南方电网同比+49.5%。
- 2026年H1再验证：国家电网上半年累计完成固定资产投资超3,100亿元，同比+12.6%。增速较Q1的+37%明显回落，说明首季抢开工斜率不可线性外推；但绝对投资额继续刷新高位，且15项特高压工程与37座抽水蓄能电站同步推进，结论从"高斜率爆发"修正为"高基数稳健推进"。
- **2026年1-9月第三次验证（本轮最重要边际）**：国家电网累计完成固定资产投资超4,500亿元，同比仅+5.2%（10月23日披露）；按H1超3,100亿元倒算，Q3单季约1,400亿元、同比约-8%至-3%，为2026年首次单季转负。国网全年预计突破7,000亿元（2025年6,500亿元），Q4需完成约2,500亿元。**"前高后稳"已从判断变为事实：2026年是"总量创新高、增速回归中个位数"的一年，而非+20%以上高增。** 这一变化不改变"十五五"4万亿的五年中枢，但会拉长订单→收入确认的时滞，并使2027年收入增速的起点落在+13%附近。
- 2026年国网全年预算：7,200亿元（过审版）/7,800亿元（争取版），实际执行预计7,000亿元出头，低于预算下限约200亿元；2027年预算尚未公布，按4万亿扣除2026年后的倒算均值为8,000-8,300亿元，12月为直接裁决点。
- "六张网"顶层设计：2026年4月政治局会议和5月国务院常务会议明确将"新型电网"列为"六张网"之一，赋予电网投资超越传统基建的政治优先级。
- **《新型电力系统建设"十五五"规划》落地（2026年8月3日发布，发改能源〔2026〕942号）**："十五五"电力顶层纲领文件，量化2030年指标——非化石能源发电量占比50%、总装机54亿千瓦、西电东送>4.2亿千瓦、配电网承载分布式新能源9亿千瓦（2025年5亿千瓦）、**新型储能装机3亿千瓦**（2025年1.36亿千瓦）、**虚拟电厂最大调节能力>5,000万千瓦**（2025年1,685万千瓦）、车网互动聚合可调充电规模5,000万千瓦、省间电力互济能力1.2亿千瓦。该规划将电网投资、储能、虚拟电厂、配网改造从"方向性表述"升级为"约束性/预期性指标"，直接对应公司调度自动化、构网型储能、虚拟电厂聚合调控、配电自动化四大业务线。
- **特高压核准端（2026年10月15日）**：国家电网"一交两直"三项特高压工程获核准——长治—南阳第二回1000千伏交流、疆电（南疆）送电川渝±800千伏直流、甘肃巴丹吉林沙漠基地送电四川±800千伏直流，总投资约591亿元、新增线路约3,900公里、换流容量3,200万千瓦；2026年以来累计核准"三直四交"。两直计划2027年开工、2029年投运，主设备招标大概率落在2027年，为2027-2029年订单提供补充，但对2026年内订单贡献有限。

**结论**：产业仍处于**成长期的后半程——渗透率提升+结构性升级双轮驱动**，并非简单的成熟期存量博弈。但2026年国网投资增速从Q1的+37%回落至前三季的+5.2%、Q3单季转负，说明"十五五"开局年的斜率被高估；五年中枢（4万亿/年均8,000亿）未变，**变化的是节奏而非方向**。对南瑞的含义是：2026年营收增长更多依赖2025年结转订单与海外/网外，2027年增长则取决于2026年新签合同（H1 +28.79%、合同负债Q3回补至79.94亿元）与2027年预算能否回到8,000亿元以上。

### 1.2 库存动力学：从"主动去库"到"被动补库"的拐点

电网设备行业的库存周期与一般制造业不同，其核心"库存"并非产成品，而是**招标-交付的时间差**。2025年是行业库存周期的一个微妙转折点：

- **2024年Q4-2025年H1：主动去库末期**。配网和电表领域因集采新标准切换（新国标电表）及价格战，供应商主动压低库存；国网2025年计量设备招标额同比-49%，配网区域联合招标中价格权重过高导致低价竞争。
- **2025年H2-2026年H1：被动补库开启**。2025年12月《关于促进电网高质量发展的指导意见》发布后，2026年Q1招标大幅放量，供应商进入交付高峰。国网明确反内卷机制——2026年起价格回升5%-30%，评分体系强化技术/安全性权重，"壳公司/代工型"供应商出清。

**牛鞭效应辨析**：存在一定程度的订单前置——2025年国网输变电设备招标额918.8亿元（+25.3%），2026年Q1新能源接网工程投资+50%，部分反映了"十五五"首年抢装效应。但差异在于：本轮订单波动的底层是**结构性物理需求**（风光装机历史高位→消纳需求真实存在），而非渠道投机。新能源大基地"发得出、送不出"的消纳瓶颈已在2025年集中暴露（如甘肃、新疆弃风弃光率回升），电网投资具有刚性补课属性。

## 二、终端需求穿透与跨期断层审计

### 2.1 最终产品画像

国电南瑞的产品/服务最终负载于以下终端形态：

| 最终产品/场景 | 对应公司业务板块 | 占营收比（估） |
|:---|:---|:---:|
| 国家级/区域级电网调度控制系统 | 电网智能 | ~20% |
| 变电站/配电站自动化与继电保护 | 电网智能 | ~30% |
| 特高压输电（换流阀/控保） | 能源低碳 | ~8% |
| 新能源场站（风/光/储）并网控制 | 能源低碳 | ~10% |
| 储能系统（构网型/电化学） | 能源低碳 | ~5% |
| 电力信息通信/网络安全/数字化 | 数能融合 | ~18% |
| 轨道交通/工业DCS/PLC | 工业互联 | ~5% |
| 充电桩/电动汽车充换电 | 能源低碳 | ~2% |
| 海外电网（亚非拉/欧洲） | 全板块 | ~9% |

**核心终端 → 电网投资（约80%收入间接或直接与两大电网资本开支挂钩）**。因此，对终端景气度的审计本质上就是对国网+南网"十五五"投资执行度的审计。

### 2.2 终端景气度审计：2026-2028年电网投资确定性

#### 结论：极高确定性（Evidence Score: 5/5）

**五重证据锚定**：

1. **政策顶层设计已就位**。2025年12月31日发布的《关于促进电网高质量发展的指导意见》明确到2030年目标：西电东送规模>4.2亿千瓦（2025年末3.4亿）、跨区输电能力+35%、接纳分布式新能源9亿千瓦、支撑充电设施4000万台。该文件是"十五五"电网投资的纲领性文件，相当于"开工令"。

2. **国网4万亿元为公开承诺（非预测）**。与2021-2022年市场对电网投资的"猜测"阶段不同，2026年初4万亿已由国网以新闻稿形式正式宣告，权威层级极高。2026年一季度已交付37%的增长，执行确定性得到初步验证；但前三季度累计仅+5.2%、Q3单季转负，说明**"五年总额确定"不等于"年度斜率线性"**，年度执行节奏受项目审批、设备交付与资金拨付影响，存在明显的季度波动。

3. **物理瓶颈倒逼投融资**。截至2026年8月底，全国风光累计装机19.92亿千瓦，2025年"沙戈荒"大基地集中并网后，特高压外送通道成为最大瓶颈——截至2026年10月23日国网"跨区跨省"输电能力超3.8亿千瓦（"十五五"目标5亿千瓦）vs 潜在送出需求>5亿千瓦，输配电价空间已打开。这不是"要不要投"的问题，而是"不投就弃风弃光"的硬约束。

4. **"六张网"赋予电网超越传统基建的战略优先级**。2026年4月政治局会议首次将"新型电网"列入六张网战略，与算力网、5G网并列，意味着电网投资在宏观经济下行期将获得财政和货币政策的双重护航。

5. **特高压密集开工是先行指标**。2026年Q1开工攀西特高压交流、皖鄂直流背靠背等工程，续建甘肃-浙江、大同-怀来-天津南、闽赣直流等，项目储备极其饱满。国网计划"十五五"投运15项特高压直流工程。2026年前四批特高压设备招标合计329.10亿元，已超2025年全年220.62亿元；10月15日"一交两直"再获核准591亿元，核准端延续。

### 2.3 动能溯源与透支审计

**内生vs外生动能判别**：

本轮增长的终极驱动力是**内生性的**——新能源发电成本下沉（光伏LCOE已降至0.15-0.25元/度）使风光成为最便宜电源，而与之配套的电网基础设施建设严重滞后。它不是"刺激出来的需求"，而是"被压抑多年的刚性需求"的集中释放。

**跨期需求前置审计（强制复核）**：

- **是否存在需求前置？** 是，部分存在。2026年增速37%（Q1）并非稳态增速，"十五五"首年存在追赶效应。但需要区分：首年放量并非透支，而是对过去三年"规划期"审批较慢的补偿性加速。
- **是否存在"悬崖效应"？** 不存在传统意义上的需求悬崖。电网投资的特殊性在于：项目周期长（特高压3-5年）、资金连续拨付（年度预算制）、在建规模惯性大（累计在建抽蓄超9,400万千瓦）。即便2027-2028年增速回落至10-15%，绝对投资规模仍将维持万亿级高位。
- **政策补贴透支审计**：电网设备行业不依赖财政补贴（与光伏制造端的补贴逻辑不同），不存在补贴退坡引发的需求断崖。反内卷机制带来的价格修复是结构性的，不会导致需求萎缩。

**结论**：本轮增长动能以内生刚性需求为主，跨期透支风险较低。唯一需警惕的是2028年后特高压集中投运完毕后的"投资真空期"，但考虑到配电网和数字化的投资周期更长（需要持续10年+的改造），这一风险在2026-2027年的投资视野内不构成实质威胁。

## 三、供需边际与压力传导

### 3.1 供需平衡审计

**供给侧：集中度提升，竞争态势改善**

- 国网正式推行"反内卷"机制：2026年起价格权重下调，技术/安全/商务多维评估，供应商数量控制，"壳公司/代工型"企业出清。
- 特高压换流阀领域：国电南瑞、许继电气、中国西电三足鼎立（CR3>85%），新进入者几乎没有。
- 电网调度/自动化：国电南瑞近乎垄断（市占率约70%，省级及以上调度系统约75%），南瑞继保（子公司）补充。
- 储能（构网型）：技术壁垒高，当前有能力规模交付的企业<5家，南瑞位列第一梯队。
- 配网设备：相对分散，但反内卷将加速集中度提升，南瑞在一二次融合、配电自动化等高端领域优势显著。
- IGBT自主替代：南瑞4500V/3000A IGBT已实现小批量，中压IGBT年交付10万只，是重要的供给侧"卡脖子"解除信号。

**需求侧：增速斜率超前于供给侧产能扩张**

- 年均电网投资较"十四五"显著抬升：国网单家从约5,700亿/年增至约8,000亿/年（+40%），叠加南网万亿计划后两网合计年均接近1万亿元。
- 在反内卷、去低端产能的背景下，有效供给（能拿到订单的合格产能）反而在收缩。
- 结论：**供需边际正由弱平衡向供不应求偏移**，优质供应商的议价权有望阶段性提升。

### 3.2 压力传导特征分析

**终端波动向公司传导的路径与弹性**：

1. **正向传导（电网投资↑→南瑞营收↑）**：
   - 传导系数高。国网投资每增加100元，电网设备采购约增加40-50元，南瑞凭借综合龙头地位可获得约8-10元份额（市占率估测）。
   - 传导时滞：招标到确认收入约6-12个月（特高压更长，约12-18个月）。2026年前三季国网投资仅+5.2%、Q3单季转负，其收入影响将在2027年上半年逐步显现；但南瑞2026Q3营收仍+12.41%、前三季+13.75%，说明当期收入主要由2025年结转订单（2025年末在手520.31亿元）与海外/网外交付驱动，**投资增速回落与公司收入增长之间的时滞约2-4个季度**。
   - 2025年末在手订单520.31亿元≈0.79x年营收；2026H1新签合同456.33亿元（+28.79%），Q3合同负债回升至79.94亿元（环比+14.0%），意味着2026-2027年营收的可见度仍高，但2027年增速的斜率取决于2026年全年新签能否达到850-900亿元目标。

2. **负向传导（光伏装机下滑→储能/新能源控制需求？）**：
   - 2026年光伏新增装机预计下滑至180-240GW（2025年315GW），表面上对南瑞新能源控制业务构成负面压力。
   - **但这是伪命题**：电网设备需求的驱动变量并非当年新增装机，而是**累计装机规模**（消纳压力与存量成正比）和**电网投资本身**。存量18.8亿千瓦风光装机的消纳改造需求和新增新能源的并网需求是叠加而非替代关系。
   - 换句话说：装机增速放缓（今年325GW→明年250GW）并不等于消纳改造需求放缓，后者是由存量的"积压效应"决定的。2026年1-8月新增光伏9,719万千瓦（同比-57.9%）、风电5,326万千瓦（同比-7.9%），但南瑞能源低碳板块H1仍+46.98%，验证了"存量消纳+海外"而非"当年装机"才是驱动变量。

3. **原材料成本传导**：
   - 直接材料占成本71%（2025年），铜、钢、IGBT芯片等价格波动对毛利率的边际影响显著。
   - 传导滞后：集采合同中价格锁定期通常3-6个月，原材料短期波动无法及时转嫁。
   - 2026年10月28日LME铜$14,462/吨，较10月9日的$14,680历史峰值回落约1.5%，但仍处历史高位；功率半导体涨价延续——安森美10月10日年内第二轮调价生效、瑞萨2027年1月1日接棒、台系厂商Q4对非合约产品提价10-15%，交期拉长至30周以上。**成本端压力从"2026Q4"延长至"2027H1"**，与反内卷价格修复形成对冲。Q3毛利率25.63%环比回升，说明价格修复暂时占优，但2027年能否维持取决于Q4合约重议价。

4. **海外传导（高增长+低毛利率的拉扯）**：
   - 海外业务增速84%但毛利率仅19.2%，与国内26.5%的差距约7个百分点。
   - 当前海外收入占比H1已达21.2%（58.94/277.67），对综合毛利率的结构性拖累提前放大；2026H1海外毛利率12.68%（同比-7.15pp），低于2025年19.2%的全年水平，说明海外EPC/储能总包占比上升正在稀释海外自身毛利率。
   - 若海外占比提升至25%（可能发生于2027），拖累将进一步放大；海外毛利率能否从12.68%修复至18-20%，是2027年综合毛利率能否达到26.0%的关键变量之一。人民币升值（10月27日中间价6.7171，年内+4.36%）使海外收入折算与汇兑损失进一步承压。

## 四、强制复核项确认

在进入模块三（竞争格局）之前，以下三项强制复核已完成：

1. **终端产品景气度预测已引用**：已穿透至电网投资（4万亿/5年，2026年实际约7,000亿元、同比+7.7%）和新能源装机（累计19.92亿千瓦）两大终端指标，2027-2028年景气度仍高，但2026年增速已从年初预期的+20%回落至+5.2%，**"五年高确定性、年度中速增长"是更准确的表述**。

2. **跨期需求移位已审计**：不存在补贴断崖风险；2026年增速回落不是"透支-断崖"，而是项目审批与交付节奏的回归；两直特高压2027年开工、2029年投运，订单窗口延续至2029年。光伏装机2026年大幅下降（1-8月-57.9%）未对南瑞能源低碳收入构成实质冲击，验证"存量消纳+海外"逻辑。

3. **供需边际与压力传导已分析**：供给侧受反内卷出清，有效供给收缩；需求侧年均万亿，但2026年实际执行仅+5.2%，供需"紧平衡"的程度低于年初预期。毛利率的正向（价格修复、Q3 25.63%）与负向（铜价$14,462、功率半导体第四轮涨价、海外毛利率12.68%、人民币升值）力量并存，需在模块五定量分解。

**网外增量（四网增值盘）**：公司披露水网（滇中引水闸控）、管网（国家管网6省能碳平台）、交通网（南京北站、无锡地铁5号线）、算力网（陕西、西藏十余个智算中心）处于"技术同源向规模化落地加快转变"阶段，未提供可计价订单金额，暂不改变本章"电网投资5万亿超级周期"主逻辑，作为网外订单的外延补充跟踪。2026年三季报显示Q3营收161.12亿元（+12.41%）、合同负债79.94亿元（环比+14.0%），在国网Q3投资单季转负的背景下仍保持双位数增长，验证"收入由2025年结转订单与海外/网外驱动、投资时滞2-4个季度"的判断；但Q3归母转负、前三季OCF-29.20亿元，说明"收入强、利润与现金流弱"的格局尚未扭转。
