# 国电南瑞 (600406.SH) 2030 战略目标与长期净利预测

**研究日期**：2026年8月26日
**核心结论**：2030E归母净利183亿（基准）、182亿（加权），相比2025年82.8亿增长约1.21倍，5年CAGR ~17.2%。8月26日中报后复核按"主报告为统一基准"原则同步重派生：2026E-2028E逐年预测与章节五/六完全一致（750/860/980亿营收，87.0/108.5/131.0亿归母净利——中报利润弹性推迟引发年内第三次下修）。短中期估值与交易纪律同步至最新章节六/七：现价23.15元（8月25日收盘），中性目标价28.00元（含+7%审计调节，未调节基准26.16元），加权目标价27.51元，盈亏比2.74:1。

## 六、操作建议框架

```
当前价位: 23.15元（2026-08-25收盘）
┌──────────────────────────────────────────────────────┐
│  21.68元(7月低点)←── 年内通道证伪线（连续5日破位重审） │
│  21.56元(保守情景)←── 深度价值区                      │
│  23.00元(双针区)  ←── 多空生命线                      │
│  23.15元         ←── 当前价位（持有）                 │
│  23.91元(MA250)   ←── 年线簇=中期修复启动线           │
│  24.85元(MA120)   ←── 趋势修复确认                    │
│  28.00元         ←── 2026E中性目标（部分兑现）        │
│  33.60元         ←── 2026E乐观目标（余仓兑现）        │
│  50.2元(2030E)   ←── 5年长期目标（需5年持有）         │
└──────────────────────────────────────────────────────┘
```

**基本原则**：
1. 21.56-23.00元区间：PB极低分位+回购资金托底的价值缓冲带，可分批吸纳
2. 持有周期：至少3-5年（覆盖"十五五"全周期）
3. 短期回撤容忍：跌破23.00元生命线暂停左侧动作；21.68元为通道证伪线
4. 关键兑现：2026年10月三季报Q3毛利率+12月国网年度预算（确认2027年增长方向）
5. 进攻性加仓触发：Q3毛利率≥25.4% 或 放量收复年线簇（满足其一）
6. 退出时机：
   - 2027年：若Q3/Q4毛利率未回升至26%轨道 → 提前减仓
   - 2028年：若海外占比未达15%（H1已达21%）→ 复核模型而非机械减仓
   - 2030年：达到50.2元（5年CAGR约17%目标）→ 兑现主仓

- 国网年度工作会议（1月）
- 半年报/年报披露

## 九、最终投资判断

**评级（2026年8月26日）**：**买入/持有（第一象限维持，等待Q3毛利率拐点或收复年线簇后再进攻加仓）**

| 情景 | 价格区间 | 操作 |
|:---|:---|:---|
| <21.68元 | 深度低估 | **分批重仓**（通道证伪除外） |
| 21.56-23.00元 | 价值缓冲区 | 积极配置 |
| 23.00-24.85元 | 年线拉锯区 | 持有，站稳23.91元小幅加仓 |
| 24.85-28.00元 | 估值修复中 | 持有+观望 |
| 28.00-33.60元 | 接近中性/乐观目标 | 减仓兑现部分 |
| >33.60元 | 中短期超涨 | 兑现主仓 |

**5年视角（2030E）**：
- 加权目标净利182亿，对应5年CAGR ~17.2%
- 理论目标价约50.2元（PE 22x × EPS 2.28，基准净利口径）
- 现价23.15元 → 5年潜在回报约+117%
- 加约2.7%股息率 = 5年总回报率约+130%

**风险提示**：
- 短期（6-12个月）：功率半导体第三轮涨价+毛利率拐点推迟（10月末三季报验证）；国内传统业务失速（H1国内-1.89%）
- 中期（1-3年）：海外高基数后的增速换挡与汇率波动（H1财务费用已转正）
- 长期（3-5年）：地缘政治+技术封锁+电网投资节奏
