# 国电南瑞 (600406.SH) 2030 战略目标与长期净利预测

**研究日期**：2026年10月28日
**核心结论**：2030E归母净利183亿（长期战略目标情景，基准）、181亿（加权），相比2025年82.8亿增长约1.21倍，5年CAGR ~17.2%。短中期估值与交易纪律同步至最新章节六/七（10-28坐标）：现价23.34元（10-28视图实测，PE TTM 22.49x/PB 3.57x/市值1,875亿，总股本80.31756亿股视图口径，23.34元 vs 22.40元（10-09，+4.2%）），中性目标价33.16元（2027E口径，含+7%审计调节，未调节基准30.99元），加权目标价32.46元，盈亏比∞+（现价23.34元低于保守价24.57元，但仅-5.0%，约P26/约P9，2,517日样本重算阈值，详见章节六）。**口径：本文件短中期坐标采用2026-10-28主报告口径（23.34元/33.16/32.46元/∞+）；2027E以章节五103.7亿/1.291元为准，2030E 183亿为长期目标情景，不代表2027E线性外推路径。**

## 六、操作建议框架

```
当前价位: 23.34元（2026-10-28视图实测，10-09 22.40元，+4.2%）
┌──────────────────────────────────────────────────────┐
│  21.68元(7月低点)←── 年内通道证伪线（连续5日破位重审） │
│  21.95元(9月箱体下沿)←── 强支撑                       │
│  22.18元(10-14低点)←── 本轮反弹起点                   │
│  22.79元(MA20)   ←── 突破有效性第三支撑              │
│  22.96元(MA60)   ←── 突破失败线                       │
│  23.30元(MA120)  ←── 突破有效性线                     │
│  23.34元（10-28）←── 当前价位（年线下方2.4%）         │
│  23.91元(MA250)  ←── 中期反转确认（10-26曾单日站上）  │
│  24.57元         ←── 2027E保守目标                    │
│  30.99元         ←── 2027E中性情景价（未调节）        │
│  33.16元         ←── 2027E中性目标（部分兑现）        │
│  40.39元         ←── 2027E乐观目标（余仓兑现）        │
│  50.2元(2030E)   ←── 5年长期目标（需5年持有）         │
└──────────────────────────────────────────────────────┘
```

**基本原则**：
1. 22.79-23.30元区间：突破后的第一支撑带，回踩不破可持有/分批吸纳
2. 持有周期：至少3-5年（覆盖"十五五"全周期）
3. 短期回撤容忍：跌破23.30元（MA120）暂停左侧动作；22.96元（MA60）为突破失败线；21.68元为通道证伪线
4. 关键兑现：2026年11月3日三季度说明会+12月国网2027年年度预算（确认2027年增长方向）
5. 进攻性加仓触发：Q4经营现金流环比转正 + 2027年国网预算≥8,000亿元 + 股价站稳23.91元（三者同时满足）
6. 退出时机：
   - 2027年：若Q4/2027Q1毛利率未回升至26%轨道 → 提前减仓
   - 2028年：若海外占比未达20% → 复核模型而非机械减仓
   - 2030年：达到50.2元（5年CAGR约17%目标）→ 兑现主仓

## 九、最终投资判断

**评级（2026年10月28日，已同步主报告10-28坐标）**：**买入/持有（第一象限维持，确定性3.6/5；Q3毛利率25.63%触发条件已满足，但利润/现金流未确认，等待Q4现金流与年线23.91元确认后再进攻加仓）**

| 情景 | 价格区间 | 操作 |
|:---|:---|:---|
| <21.68元 | 深度低估 | **分批重仓**（通道证伪除外） |
| 21.95-22.79元 | 强支撑区 | 积极配置 |
| 22.79-23.91元 | 突破确认区 | 持有，站稳23.91元小幅加仓 |
| 23.91-33.16元 | 估值修复中 | 持有+观望 |
| 33.16-40.39元 | 接近中性/乐观目标 | 减仓兑现部分 |
| >40.39元 | 中短期超涨 | 兑现主仓 |

**5年视角（2030E）**：
- 加权目标净利181亿，对应5年CAGR ~17.0%
- 理论目标价约50.2元（PE 22x × EPS 2.28，基准净利口径）
- 现价23.34元（10-28）→ 5年潜在回报约+115%（50.2/23.34-1）
- 加约2.7%股息率 = 5年总回报率约+120%

**风险提示**：
- 短期（6-12个月）：功率半导体第四轮涨价+人民币升值+Q4现金流能否回补（三季报Q3毛利率25.63%已部分验证毛利率拐点）；国内传统业务失速（H1国内-1.89%）
- 中期（1-3年）：海外高基数后的增速换挡与汇率波动（前三季财务费用+1.52亿元）；2027年国网预算
- 长期（3-5年）：地缘政治+技术封锁+电网投资节奏
