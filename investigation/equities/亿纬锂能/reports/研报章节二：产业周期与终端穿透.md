# 研报章节二：产业周期与终端穿透

**研究日期**：2026年08月20日  
**公司名称**：惠州亿纬锂能股份有限公司（300014.SZ）  
**关联前序模块核心结论**：2026H1综合毛利率14.31%（YoY -3.02pp）量增价跌延续，Q2环比仅微升0.5pp；经营现金流-3.88亿、存货154.2亿暴露资金占用；ROIC回升至4.51%但仍<资本成本，本章将从产业周期和供需角度解释该困境的结构性根源，并纳入IEA/BNEF最新全球EV预测（23M，+10%）与InfoLink全球储能H1数据（467.84GWh，+94.76%）。

## 一、产业生命周期与阶段性定位

亿纬锂能横跨三大电池赛道，各自处于不同的生命周期阶段，需分层审视：

### 1.1 动力电池：成长后期→成熟早期过渡（2026H1验证）

| 指标 | 数据 | 来源 |
|:---|:---|:---|
| 2025全球新能源汽车销量 | 2,260万辆（+23.7%YoY） | GGII |
| 2025全球电动化渗透率 | 23.7% | GGII |
| **2026全球EV销量预测（最新）** | **23.0M（+10-11%YoY），欧洲+20-30%、亚太（除中）+50-80%、拉美+45-75%，中国与去年持平~13.2M但出口+65%** | **IEA/BNEF 2026.6-8更新（较GGII此前2,650万下修）** |
| 2025全球动力电池出货量 | 1,495.1GWh（+42.2%YoY） | EVTank |
| 2025全球乘用车动力电池装机量 | 1,039.6GWh（+24.9%YoY） | SNE Research |
| **2026H1全球动力电池装机量** | **608.5GWh（+20.0%YoY）** | **SNE Research 2026H1** |
| 2029出货量预测 | 3,548.3GWh | 弗若斯特沙利文 |

**生命周期判断**：动力电池处于**成长后期**，**2026H1呈现"全球分化+结构性高增"**。核心依据：
1. 渗透率23.7%仍处于S曲线加速段，但IEA/BNEF最新预测显示增速进一步分化：欧洲+20-30%、亚太（除中）+80%、拉美+75%高增对冲中国/美国政策退坡（美国销量-19%预期）后的放缓，**全球总量+10%仍为成长但不及此前GGII +17%乐观预期**。
2. 2026H1全球装机608.5GWh（+20%）低于电池产量增速（6月单月产量206GWh +59.5%），显示**产量-装机剪刀差**存在，产能利用率分化加剧。
3. **中国领先、欧美追赶、新兴市场起步**的三层结构强化，新兴市场（澳、巴、印、泰等）销量接近翻倍，成为边际增量核心来源。

### 1.2 储能电池：高速成长期

| 指标 | 数据 | 来源 |
|:---|:---|:---|

| 2025全球储能电池出货量增速 | +80%（YoY） | GGII |
| **2026H1全球储能电池出货量** | **467.84GWh（+94.76%YoY），连续三季>200GWh/季** | **InfoLink 2026.8.11 / SMM 486GWh / SNE 461.3GWh交叉验证** |
| **2026全球储能出货预测（上修）** | **1,026GWh（InfoLink，B/B 1.2+延续数月） / >900GWh（EVTank）** | **2026.8上修** |

**生命周期判断**：储能电池处于**高速成长期且景气度超预期**，2026H1 +94.76%远超此前80%预期，InfoLink上修全年至1,026GWh。但需警惕：虽短期供需紧平衡（B/B>1.2），全年1,026GWh对应的H2约558GWh（vs H1 468GWh）仍需环比+19%兑现，且**价格战未缓解**（储能电池毛利率普遍下滑：亿纬12.51% -1.36pp，CATL储能23.96% -1.56pp）。

### 1.3 消费电池：成熟期中的结构性机会

消费电池整体处于**成熟期**（CAGR约15-16%），但其中锂原电池为亿纬锂能的现金牛（连续9年国内第一），新兴应用（机器人、BBU/AIDC备电、低空经济、医疗植入式电池）提供了结构性高增长点。具体而言：
- **人形机器人**：2025年全球出货量约1.8万台（+508%YoY），IDC数据
- **低空经济**：2026年中国市场规模预计10,645亿元（+24%YoY），赛迪智库
- **BBU电池**：2030年全球需求预计超6亿只，EVTank数据

## 二、库存周期与供应链动力学

### 2.1 当前库存阶段判断

| 信号维度 | 观察 | 判断 |
|:---|:---|:---|
| 亿纬锂能存货周转天数 | 从78天（2023）→50天（2025） | **主动去库完成，库存回归健康** |
| 储能出货量增速 | 80%YoY（2025），满产满销 | **被动去库/主动补库早期** |
| 动力电池价格趋势 | 持续走低 | **竞争性降价而非库存出清** |
| 上游碳酸锂价格 | 从60万/吨→8万/吨企稳 | **成本端已去泡沫，价格传导压力转至制造端** |
| 终端车企库存 | 大部分正常化 | **牛鞭效应风险较低** |

**综合判断**：经历2022-2023年的剧烈去库后，产业链库存已回归健康水平。当前产品价格的持续下行并非库存出清驱动，而是**产能过剩竞争**的结果。这一点至关重要——传统的"去库→补库"周期无法解决当前行业的结构性价格压力。

### 2.2 牛鞭效应辨析

亿纬锂能的主要客户为整车厂和大型储能集成商（Wärtsilä、ABB、台达电子等），属于**B2B直供模式**，渠道层级少，牛鞭效应的放大风险相对有限。真正的需求信号失真风险在于：
- **车企竞争性备货**：为争夺市场份额，车企可能下过剩订单
- **储能项目"抢装潮"**：政策窗口期前的集中采购可能导致需求前置

## 三、终端需求穿透与跨期断层审计 (MANDATORY)

### 3.1 最终产品画像

| 亿纬锂能产品 | 最终终端形态 | 需求驱动因子 |
|:---|:---|:---|
| 动力电池（方形LFP/NCM） | 新能源乘用车/商用车/工程机械 | 电动化渗透率、排放法规、TCO经济性 |
| 储能电池（大方形LFP） | 电网侧储能电站/工商业储能/户储 | 可再生能源装机、电力市场化、电网调节需求 |
| 消费电池（锂原/小锂电/圆柱） | 智能表计/汽车电子/电动工具/TWS/机器人/无人机 | 智能化渗透、消费电子周期、新兴应用 |

### 3.2 终端景气度审计（未来1-3年）

#### A. 新能源汽车（1-3年展望）: ★★★☆☆（谨慎乐观，H1验证）

**正向因素（2026H1验证）**：
- 全球EV销量H1约9-11.22M（+13%YoY，6月单月238万 +25%），IEA最新预测23M（+10%）较年初谨慎但仍成长
- 商用车电动化加速验证：2026H1全球商用车装车亿纬全球第二（+65.3%），国内新能源重卡渗透率5月突破40%（+17pp YoY，十一部门2030年40%目标）
- 欧洲+30%、亚太（除中）+80%、拉美+75%高增构成新引擎，中国出口+65%对冲内需放缓
- 单车带电量提升（国内65.4kWh +29.3%，全球61.4kWh +13.8%）驱动电池出货弹性>BEV销量弹性

**负向因素（2026H1强化）**：
- **中国/美国双拖累**：中国H1电动车销量同比接近持平（IEA：H1全球EV仅-1%因中国-20%拖累），BNEF下调中长期预期（中国激励收紧+美国联邦支持全面撤回，2026美国销量-19%）
- 美国政策逆转已兑现：废除排放法规+放松燃油经济性目标，BNEF 2040年美国电动化率仅24%预期下调
- 全球汽车销量H1 -5%（中美-20%+拖累），存量市场压力传导至电池议价

**核心矛盾**：行业出货量增速（~25%）远超终端车辆销售增速（~5%），这中间的差额意味着**单车带电量提升、海外市场拓展和库存补库**是主要驱动力，而非单纯的终端销量增长。

#### B. 全球储能（1-3年展望）: ★★★★★（高度景气，H1 сверх预期）

**正向因素（2026H1验证）**：
- 6月动力+储能产量206GWh（+59.5% YoY），储能62.6GWh（+67.5%）占比31.9%创历史进程，出口36.2GWh（+48.7%）储能占比29.7%
- InfoLink H1 467.84GWh（+94.76%）、SNE 461.3GWh（+71%）交叉验证，B/B>1.2连续数月，全年上修至1,026GWh；中东北欧（保加利亚/罗马尼亚RESTORE窗口、中东项目4月后恢复）、北欧FCR/aFRR频率服务、印度强制并网驱动GWh级交付
- AI数据中心（AIDC）备电需求已落地：亿纬覆盖BBU/UPS/园区/场站四层级，圆柱BBU适配>100kW机柜
- 国内136号文+容量电价落地+“十五五”2027年不低于3亿千瓦目标，政策闭环
- 亿纬H1储能44.46GWh（+54.88%）全球前三，年初至今订单>130-152GWh（ESIE 50GWh + SNEC 67GWh + 欧洲13.5GWh），订单保障度高

**风险因素（2026H1显现）**：
- **增收不增利延续**：亿纬储能毛利率12.51%（-1.36pp）、CATL储能23.96%（-1.56pp），价格战未缓解；EPC中标价1.00元/Wh（4月加权）、系统0.53元/Wh，成本增速（亿纬储能成本+71.82% > 营收+69.15%；CATL储能成本+91.46% > 营收+87.54%）均快于收入
- 产能利用率分化：行业总量产能3000GWh vs 需求~1500GWh（<60%利用率），但头部（CATL 94.86%满产、亿纬满产满销）紧缺，低端闲置矛盾突出
- 出口退税退坡（4月1日9%→6%，2027年取消）+ 消费税2%（9月1日）双挤压，中小厂商“出口越多越亏”显现

**核心判断**：储能是亿纬锂能三大板块中**确定性最高的增长赛道**，但利润端的兑现取决于产能规模优势向成本优势的转化效率。

#### C. 消费电池新兴应用（1-3年展望）: ★★★★☆（结构性强劲）

人形机器人2025年出货量同比增长508%，低空经济2026年市场规模超万亿，BBU电池2030年需求超6亿只——三大新兴赛道为消费电池业务提供了远超传统消费电子增速的新增量。亿纬锂能在机器人（已与头部客户建立合作）、医疗植入式电池（国内唯一实现能力）、无人机（首家通过AS9100D航天认证）的先发布局，有望在消费电池板块开辟第二增长曲线。

### 3.3 动能溯源与跨期透支审计

#### 增长动能拆解：

| 增长来源 | 性质 | 持续性评估 |
|:---|:---|:---|
| 全球电动化渗透率提升 | **内生**（技术迭代+成本下降） | 可持续，但增速边际递减 |
| 中国"双碳"政策 | **外生**（政策驱动） | 2030年前方向确定，但力度可能边际调整 |
| 欧盟碳排放法规 | **外生**（监管驱动） | 长期确定，2035年禁燃目标 |
| 储能电价市场化 | **外生/内生**（政策+经济性） | 盈利模式正从政策依赖转向市场驱动 |
| 美国补贴（IRA） | **外生**（短期刺激） | 高度不确定，政策风险大 |
| AI数据中心备电 | **内生**（技术需求） | 强持续性，刚需属性 |
| 机器人/低空经济 | **内生**（新兴技术） | 早期，爆发力强但基数低 |

#### 跨期需求透支审计（强制项）：

**（1）新能源汽车**：存在**局部透支风险**。
- 中国2025年新能源商用车渗透率已达26.9%（+63.7%YoY），部分由政策考核驱动
- 全球数据：EV-Volumes显示PHEV增速从55.2%骤降至11.1%，表明补贴退坡后真实需求显露
- **结论**：短期内（2026-2027）不会出现整体性需求断层，但增速放缓已是确定趋势。亿纬锂能若能维持商用车和大圆柱技术领先，可在增速放缓中通过份额提升对冲

**（2）储能**：存在**"政策抢装"型透支**。
- 2025年储能出货量同比+80%，部分由各地容量电价政策窗口期前的"抢装潮"驱动
- 多地取消固定分时电价后，部分项目的经济性将重新评估
- 海外订单366GWh（+144%）的增长中，部分为长期框架协议而非常态化交付
- **结论**：2026年储能增速将从80%显著回落至合理水平（预计30-50%），但由于行业渗透率仍极低，不构成需求断层

**（3）消费电池**：**基本无透支风险**。消费电子需求随换机周期自然波动，新兴应用（机器人、低空经济）仍处于早期供给创造需求阶段。

## 四、供需边际与压力传导审计

### 4.1 供需平衡预判

#### 动力电池：从紧平衡滑向结构性过剩（2026H1分化加剧）

| 维度 | 判断（2026H1更新） |
|:---|:---|
| **需求端** | 2025-2029 CAGR 26.7%维持，但2026H1全球装机608.5GWh（+20%）低于电池产量1068.9GWh（+53.3%），装车仅335.6GWh（+12%），出口+储能成为蓄水池 |
| **供给端** | 产能3000GWh vs 需求1500GWh（全年），CATL在建764GWh（2年翻倍）、亿纬新增110GWh（启东50+上杭60）持续投放 |
| **产能利用率** | 行业<60%（官方）vs 头部满产（CATL 94.86%产498GWh，亿纬满产满销）→ **结构性过剩+高端紧缺并存** |
| **结构性分化** | 高端/大圆柱（46系列量产交付宝马）、商用车（渗透率40%+）、AIDC备电供给不足；低端LFP产能闲置 |
| **预判** | **中低端过剩持续恶化，高端差异化溢价但盈利弹性被成本（碳酸锂151k）侵蚀** |

**对亿纬锂能的影响**：大圆柱率先量产（2026H1规模化交付宝马新世代）与商用车TOP10覆盖率90%（全球第二+65.3%）在过剩中卡位优势验证；但动力电池毛利率16.19%（-2.97pp）与CATL动力20.6%（-1.8pp）同步下滑，显示结构性溢价未能完全抵消成本与价格压力。

#### 储能电池：高增长对冲出清中，价格战白热化但短期紧平衡（2026H1更新）

2026H1全球出货467.84GWh（+94.76%）暂时消化产能，但**毛利率下行印证过剩压力未除**：2025年~526GWh → 2026年~1,026GWh（InfoLink），而中国企业规划2026-27>1000GWh，**短期B/B>1.2紧平衡仅是旺季+政策抢装（退税窗口、保加利亚RESTORE 7.31截止）叠加，H2需环比+19%才能兑现全年，拐点仍可能2027年**。

### 4.2 压力传导特征分析

```
终端市场波动 → 电池价格 → 电池企业利润（2026H1验证）
    ↓              ↓              ↓
  EV销量增速   ASP持续下降   毛利率持续压缩
  +10%（23M）  （储能EPC 1.00/  （16.17%→14.31% H1，综合-3.02pp；
              系统0.53元/Wh，  储能12.51% -1.36pp，动力16.19% -2.97pp；
              仍低于2023）    消费22.64% -4.04pp）
```

#### 波动放大效应（2026H1验证）：
- **下游整车降价→电池降价**：H1 CATL动力成本+57.06% >营收+54.8%、亿纬动力成本+58.95% >营收+53.31%，显示价格压力放大至成本端；6月产量206GWh（+59.5%）vs装车76.5GWh（+31.5%）-产量增速2倍于装车，议价权向整车厂倾斜
- **储能招标价格走低**：4月EPC加权1.00元/Wh、系统0.53元/Wh，仍处历史低位。亿纬储能12.51%（-1.36pp）与CATL储能23.96%（-1.56pp）双双下滑，印证放大效应持续

#### 传导时滞与弹性：
- **压力传导约滞后1-2个季度**：电池企业与整车厂的年度价格谈判通常发生在Q4或Q1，价格锁定后执行一个周期
- **亿纬锂能的博弈筹码**：
  - **优势**：大圆柱电池产能稀缺（率先量产），具备一定议价权；商用车市场份额领先（全国第二），客户粘性较强；全产业链布局（镍钴锂→电池→回收）提供成本缓冲
  - **劣势**：储能电池面临海辰储能、比亚迪等强劲对手的低价竞争，差异化程度有限（628Ah大电芯虽有技术优势，但终端客户更看重价格）

## 五、强制复核项确认

### ✅ 复核项1：终端产品景气度预测
已穿透并引用了：
- 新能源汽车：2025年2,260万辆 → 2026年2,650万辆（GGII），2025年21.6M→2026年22.7M（EV-Volumes）
- 储能：2025年+80%（GGII），2029年CAGR 23-26%（弗若斯特沙利文）
