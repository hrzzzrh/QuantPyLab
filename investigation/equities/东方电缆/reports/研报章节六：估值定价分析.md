## 一、价值锚定：适配性估值方法选择

### 1.1 方法论选择与理由

| 方法 | 适用性 | 选择理由 |
|------|--------|---------|
| **PE（市盈率）** | ★★★★★ **主锚** | 东方电缆是盈利稳定、增长可见度高的制造业龙头，PE是最直接、最广泛使用的估值工具。2026E EPS可预测性强（在手订单锁定） |
| **PB-ROE** | ★★★★ **交叉验证** | 公司ROE 16.83%且处于回升通道，PB-ROE框架可验证PE倍数的合理性 |
| **PEG** | ★★★ **辅助参考** | 预期3年净利润CAGR约25%，PEG有助于判断成长性是否被充分定价 |
| **DCF** | ★★ **不采用** | 海缆企业现金流受项目交付节奏影响波动大（Q1经营现金流-9.73亿），DCF对假设极度敏感，不适合作为主锚 |
| **SOTP** | ★★★ **辅助参考** | 已在模块五完成分部利润模拟，可用于验证整体估值 |

### 1.2 PE估值——主锚

**2026E EPS**：2.30元/股（基准情景，详见模块五）

**合理PE区间推演**：

| 参考维度 | PE区间 | 依据 |
|----------|--------|------|
| 近5年历史分位 | 28-40x（中位33x） | 但2021年抢装期PE曾达60x，当前环境已不同 |
| 当前PE TTM | 26.5x | 处于近5年约20%分位，接近底部 |
| 同业对比（中天/亨通） | 71x/101x | 但两家含光通信估值溢价，不可直接对比 |
| 成长性匹配（PEG=1） | ~25x | 2026-2028E净利CAGR约21%，PEG=1对应21x |
| 行业龙头合理溢价 | 20-25x | 海缆寡头+高ROE+高增长，20-25x合理 |
| **综合判断** | **20-25x** | 取中位22.5x |

**PE估值结果**：

| PE假设 | 目标价（元） | 对应市值（亿元） | 相对当前涨跌 |
|--------|------------|----------------|------------|
| 20x（保守） | 46.0 | 379 | +5.1% |
| 22.5x（基准） | **51.8** | **427** | **+18.4%** |
| 25x（乐观） | 57.5 | 474 | +31.4% |

### 1.3 PB-ROE交叉验证

| 指标 | 2025年（实际） | 2026E（预测） |
|------|-------------|-------------|
| 归母净资产（亿元） | 82.83 | ~95（+留存收益+转增） |
| BVPS（元/股） | 10.04 | ~11.52 |
| ROE | 16.83% | ~20%（利润高增+净资产温和增长） |
| 合理PB（ROE 20%时） | — | 4.5-5.0x |

**PB-ROE验证结论**：PB 4.5-5.0x对应目标价51.8-57.6元，与PE估值（51.8元基准）高度一致。

### 1.4 PEG辅助验证

| 指标 | 数值 |
|------|------|
| 2026E PE | 22.5x（基准） |
| 2026-2028E净利CAGR | ~21% |

PEG≈1.0x，处于合理区间（0.8-1.2x），说明成长性尚未被充分定价。

### 1.5 基准市值区间

## 二、估值全变量对冲审计矩阵

### 2.1 审计原则

基准市值429亿为"底色"。以下对每个可能影响估值倍数的因子进行**估值影响力过滤**——只有真正能改变估值中枢的因子才纳入调节，大部分市场杂音的影响为零。

### 2.2 审计矩阵

| 审计维度 | 核心审计因子 | 审慎思考（估值影响力过滤） | 调节幅度 | 深度理由 |
|----------|------------|------------------------|---------|---------|
| **内部DNA** | 海缆纯度最高（49%）+毛利率行业第一（33.36%）+管理层战略定力（20年专注主业） | **有效**。海缆纯度是东方电缆区别于中天/亨通的核心稀缺性。市场目前按"电缆公司"定价（PE 26.5x），而非"海缆龙头"（应享PE溢价）。随着海缆占比继续提升，市场认知差将收敛。 | **+5%** | 海缆纯度带来的利润质量溢价尚未被市场充分认知。这是真正能改变估值中枢的稀缺性。 |
| **内部DNA** | 家族企业治理（夏崇耀实控+夫妻持股40%+） | **有限**。家族企业治理在A股是普遍现象，不构成独特折价。实际控制人与公司利益高度一致。 | **0%** | 平庸的关联，不是定价锚点。 |
| **政策对齐** | 十五五海风100GW+法定目标 | **已在E中体现**。政策红利已通过订单→收入→利润的链条计入EPS预测。对PE倍数的额外影响有限——因为政策确定性已在利润预测的高确定性评分（5分）中反映。 | **0%** | 具体的钱进E，不进PE。 |
| **政策对齐** | 深远海化推动单GW价值量翻倍 | **部分在E中体现，部分在PE中体现**。量价齐升的确定性已在EPS中反映，但"抗通缩"属性的稀缺性应享有PE溢价——这是风电产业链中极少数"量价齐升"的环节。 | **+3%** | 抗通缩属性改变了市场对风电产业链"通缩"的刻板印象，有助于估值中枢上移。 |
| **地缘约束** | 欧洲FSR/本地化壁垒 | **有限**。海缆政治敏感度远低于风机。东方电缆已成功交付Inch Cape，欧洲收入仅占12%。即使欧洲完全关闭（极端情景），影响也有限。 | **-2%** | 地缘风险是真实但有限的折价因子。海缆不是风机，被针对的概率低。 |
| **地缘约束** | 中美贸易摩擦 | **几乎无影响**。东方电缆不向美国出口海缆。 | **0%** | 市场杂音。 |
| **市场风格** | 机构持仓+流动性 | **有限**。东方电缆是沪深300成分股，机构持仓适中。当前市场风格偏向红利+AI，海缆不在风口。但随业绩兑现，资金关注度将提升。 | **0%** | 风格契合是短期博弈，不改变长期估值中枢。 |
| **市场风格** | 认知差收敛潜力 | **有效**。当前PE 26.5x远低于中天（71x）和亨通（101x），但海缆纯度最高。市场存在"电缆公司"vs"海缆龙头"的认知差。随海缆占比继续提升+业绩高增长兑现，认知差有望收敛。 | **+3%** | 认知差收敛是真正的估值催化剂，但需要时间（1-2个季度业绩验证）。 |
| **综合调节** | — | — | **+9%** | — |

### 2.3 修正目标市值

**修正目标市值 = 基准市值 × (1 + Σ调节幅度)**

= 429亿 × (1 + 9%)
= **468亿元**

**修正目标价 = 468亿 / 8.248亿股 = 56.7元**

## 三、逻辑纯净性校验

### 3.1 严禁重复计算

| 因子 | 已在E中体现？ | 已在PE中体现？ | 校验结果 |
|------|-------------|-------------|---------|
| 十五五海风装机翻番 | ✅ 已计入收入增长 | ❌ 不重复 | 通过 |
| 500kV交付高峰 | ✅ 已计入收入+毛利率 | ❌ 不重复 | 通过 |
| 海外高毛利订单 | ✅ 已计入毛利率38.5% | ❌ 不重复 | 通过 |
| 铜价高位 | ✅ 已计入成本 | ❌ 不重复 | 通过 |
| 海缆纯度稀缺性 | ❌ 不可量化为具体金额 | ✅ PE溢价+5% | 通过 |
| 抗通缩属性 | ❌ 不可量化 | ✅ PE溢价+3% | 通过 |
| 认知差收敛 | ❌ 不可量化 | ✅ PE溢价+3% | 通过 |
| 欧洲地缘风险 | ❌ 不可量化 | ✅ PE折价-2% | 通过 |

**校验结论**：所有可量化的利好/利空已进入E（利润预测），所有不可量化的信心/不确定性因素进入PE（估值倍数），无重复计算。

### 3.2 锚点回测

| 指标 | 数值 | 合理性检验 |
|------|------|----------|
| 修正后隐含PE（2026E） | 56.7 / 2.30 = **24.7x** | 处于近5年20-25%分位附近，合理 |
| 修正后隐含PE（2027E） | 56.7 / 2.85 = **19.9x** | 低于20x，对2027年盈利来说偏低估 |
| 修正后隐含PB | 56.7 / 11.52 = **4.92x** | 处于近5年25-30%分位，合理 |
| 隐含PEG | 24.7 / 21 = **1.18x** | 合理区间（0.8-1.2x） |

**回测结论**：修正后的隐含PE/PB/PEG均处于合理区间，未显著偏离历史中枢或同业水平。

## 四、确定性与胜率矩阵

### 4.1 三态逻辑加权

| 场景 | 概率 | 2026E净利（亿元） | 2026E EPS（元） | 给予PE | 目标价（元） | 加权目标价 |

| 乐观（Bull） | 25% | 24.0 | 2.91 | 28x | 81.5 | 20.38 |
| **概率加权目标价** | **100%** | — | — | — | — | **58.33元** |

### 4.2 最终目标价

| 指标 | 数值 |
|------|------|
| 概率加权目标价 | **58.3元** |
| 修正目标价（审计矩阵法） | **56.7元** |
| **综合目标价（取均值）** | **57.5元** |
| 当前价（不复权市价） | **43.75元** |
| **预期上涨空间** | **+31.4%** |

### 4.3 盈亏比计算

**盈亏比 = (目标价 - 现价) / (现价 - 保守场景价格)**

= (57.5 - 43.75) / (43.75 - 33.8)
= 13.75 / 9.95
= **1.38**

**解读**：盈亏比1.38，处于可接受区间（>1.0）。但考虑到保守场景价格（33.8元）是基于极端悲观假设（海风装机仅10GW+PE仅18x），实际下行风险可能更小。若以"温和悲观"价格38元作为下行锚点：

盈亏比 = (57.5 - 43.75) / (43.75 - 38) = 13.75 / 5.75 = **2.39**

**结论**：盈亏比2.39（温和悲观锚点），具有较高的投资性价比。

### 5.1 黑天鹅场景模拟

| 黑天鹅事件 | 概率 | 影响 | 应对 |
