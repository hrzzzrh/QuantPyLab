## 一、投资摘要 (Investment Summary)

### 1.1 核心投资逻辑

东方电缆是中国海缆行业纯度最高、盈利能力最强的龙头企业，正处于"量价齐升"的战略机遇期。核心投资逻辑可概括为**"三重驱动+六重壁垒+估值洼地"**：

**三重驱动**：
1. **量的驱动**：十五五海风累计装机目标100GW+（较十四五翻番），年均新增10.6-15GW，海缆需求量翻倍增长
2. **价的驱动**：深远海化推动单GW海缆价值量从~17亿跃升至~30亿+（+76%），500kV AC/±500kV DC高电压等级产品占比持续提升
3. **海外驱动**：欧洲海风加速（英国AR7拍卖8.4GW、TenneT 230亿欧元），公司海外收入12.53亿（+70.83%），毛利率高达38.50%

**六重壁垒**：码头资源+立塔产线+技术软接头+历史业绩+施工资质+产能区位，六大壁垒叠加使CR3≈87%的寡头格局3-5年内不可撼动。

**估值洼地**：当前PE 26.5x处于近5年约20%分位，远低于中天科技（71x）和亨通光电（101x），但海缆纯度最高（49%）、毛利率最高（33.36%）、ROE最高（16.83%）。市场存在"电缆公司"vs"海缆龙头"的认知差。

## 三、研究结论象限图

### 3.1 象限定位

基于前序七个模块的全维度研究，将东方电缆定位于以下象限：

```
                    高预期收益
                        |
    第二象限            |          第一象限
  (Speculative Growth)  |    (High-Conviction Buy)
  低确定性+高收益       |    高确定性+高收益
                        |
                        |    ★ 东方电缆
  ──────────────────────┼──────────────────────
                        |       确定性: 高
    第三象限            |    预期收益: +31.4%
  (Defensive Value)     |    盈亏比: 2.39
  高确定性+低收益       |
                        |          第四象限
                        |    (Avoid/Wait)
                    低预期收益
```

### 3.2 象限定位理由

**确定性评估：高**
- 在手订单193亿（1.78倍年收入覆盖），锁定2-3年营收
- 十五五海风100GW+法定目标，需求端确定性极高
- CR3≈87%寡头格局，3-5年内不可撼动
- 存货+合同负债双翻倍，2026年高增长前瞻信号明确
- 南部基地已投产，产能瓶颈打开

**预期收益评估：高（+31.4%）**
- 综合目标价57.5元，当前价43.75元，上涨空间31.4%
- 盈亏比2.39（温和悲观锚点38元），投资性价比优秀
- 2026E PE仅19x，处于历史低位，估值修复空间大
- 认知差收敛（"电缆公司"→"海缆龙头"）将催化估值重估

### 3.3 最终评级

**第一象限 (High-Conviction Buy)：高确定性 + 高预期收益 → 核心重仓建议**

东方电缆具备"确定性高+预期收益高"的双重优势，是海风产业链中性价比最优的投资标的。核心逻辑为：海缆纯度最高（49%）× 毛利率最高（33.36%）× 海外扩张最快（+70.83%）× 估值最低（PE 19x/2026E），四重优势叠加形成独特的投资价值。
