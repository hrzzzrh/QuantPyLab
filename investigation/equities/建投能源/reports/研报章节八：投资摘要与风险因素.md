# 研报章节八：投资摘要与风险因素

**研究日期：2026年08月31日**
**标的：河北建投能源投资股份有限公司（000600.SZ）**
**当前股价：7.57元（不复权市价，2026年08月31日收盘）**

## 一、投资摘要

建投能源是河北区域火电与供热龙头，控股火电装机约1,177万千瓦，热电联产机组占比近90%。其核心不是把电价或煤价单方向押对，而是在电量电价、燃料成本、容量补偿和供热之间维持足以覆盖高固定成本的价差。容量电价提升至165元/千瓦、80%以上中长期交易电量和长协煤高比例签约，是该价差的三道缓冲；但市场化电价下行、利用小时下降与煤价高位震荡仍会直接影响利润弹性。

### 1.3 投资驱动与执行原则

1. **政策底座边际弱化**：容量电价H1+3.19亿实测仅为理论19.42亿的82%兑现，且现货08-01转正使电量电价竞争制度化，政策从“利好对冲”转为“部分对冲+竞争加剧”。
2. **经营缓冲失效**：H1量价双降且Q2恶化，OCF-35.71%与短债缺口扩大显示长协缓冲未抵消煤价高位（现货861），不能再以Q1“成本下降覆盖”线性外推。
3. **资产兑现延后**：定增16.88亿到位且权益装机（秦电/沧东/定州已投）与储能/虚拟电厂（70MW）落地，但2026年增量有限，2027年方放大；关注衡丰二期前期与海上风电年内并网。
4. **交易纪律转防御**：技术面已放量跌破7.66核心支撑与全部均线（MA20 8.27/MA60 8.80/MA120 9.29），**空仓或极小仓等待右侧（放量收复7.66/8.27）**，不抄底。

| :--- | :--- | :--- | :--- | :--- |
| 1 | 煤价高位与成本失控 | 燃料67.87%占比，现货861 vs 750假设超110元 | **现货861持稳高位**，H1营业成本仅-7.73%未跑赢营收-7.94% | 综合标煤若全年>760且电价再降，继续下修中性至<15亿 |

## 三、研究结论象限图

### 3.1 象限定位

建投能源由第二象限（Speculative Growth）**维持第二象限但赔率下移至第二象限下沿、靠近第三象限**。2026H1验证量价双杀与现金流恶化，确定性进一步降低；预期收益因盈利下修与摊薄从43.1%收敛至备考19.3%（旧35.1%）。

| 维度 | 当前判断（08-31） |
| :--- | :--- |
| 确定性 | **低**：H1量-6.83%（Q2 -11%）、价-15.81元、OCF-35.71%且现金缺口扩大，行业性利空获竞对验证 |
| 预期收益 | **中等偏低**：备考加权9.03元较现价7.57高19.3%，旧口径10.23高35.1%但亦<原43.1%；备考盈亏比0.55<1 |
| 评级 | **试探性关注→空仓/极小仓等待右侧**（原试探性关注/小仓验证下调） |
| 累积区间 | 6-8元仍为高安全边际区间，但**7.57仅允许极小仓或空仓**；放量收复7.66/8.27（MA20）才恢复试探仓 |
| 下次强制更新 | **2026年三季报（预计10月下旬）**；重点核对Q3电量/电价/利用小时是否修复、综合标煤单价、OCF/净利润、容量电费月度结算、项目进度与定增股上市流通冲击 |

**结论**：基本面已出现使模型部分失效的坏消息（H1-13.41%与Q2-68%），价格虽回调11.4%但赔率已收窄（盈亏比0.55），技术破位使风险收益不对称加剧。策略从“小仓等待H1连接估值与利润”转为**“空仓等待Q3修复或更低平台（7.0-7.5）”**，不因低PE或单次反弹追高。
