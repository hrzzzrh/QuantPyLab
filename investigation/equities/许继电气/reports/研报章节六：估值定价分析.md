## 二、适配性估值方法选择

### 2.1 方法论选择与理由

| 估值方法 | 是否选用 | 选择理由 |
|:---|:---|:---|
| **PE（市盈率）** | ✅ **主选** | 公司盈利稳定、PE为正且历史区间可参考，电力设备行业通用估值方法 |
| **PB-ROE** | ✅ **辅选** | 公司ROE稳定在9-10%，PB-ROE框架有助于判断估值与盈利能力的匹配度 |
| **DCF（现金流折现）** | ❌ 不适用 | 公司业务高度依赖电网投资政策周期，自由现金流波动极大（2024 OCF 13亿 vs 2025 27亿），长期增长率难以合理估计 |
| **SOTP（分部估值）** | ✅ **辅选** | 公司六大板块盈利能力差异显著（直流32.7% vs 新能源13.8%），SOTP能揭示业务分拆的潜在价值 |
| **PEG** | ❌ 不适用 | 公司处于成熟期，非稳定成长期企业，PEG参考意义有限 |
| **EV/EBITDA** | ✅ **参考** | 公司几乎无有息负债，EBITDA≈净利润+折旧，可用于交叉验证 |
| **PS（市销率）** | ❌ 不适用 | 净利率波动大（5.3%-10.2%），PS无法反映盈利质量的改善 |

**核心估值路径**：PE为主锚（给予70%权重），PB-ROE为交叉验证（20%权重），SOTP为情景测试（10%权重）。

### 4.2 锚点回测

修正后隐含PE = 35.96 / 1.80 = **20.0x**

对比：
- 历史PE中值：24.5x（当前显著低于历史中值）
- 可比公司PE均值：约21x（略低于均值）
- 当前PE-TTM：18.96x（已低于25分位21.8x）

20.0x的隐含PE处于历史区间的**中低位置**，略低于可比公司均值，与国电南瑞（22x）存在合理折价。考虑到：①十五五电网投资锚点升级至5万亿+提供了更强的长期确定性；②许继ROE（10%）低于南瑞（16%）和思源（16%），估值折价是合理的。**整体来看，当前估值不是"极度低估"，但却是"基本面改善预期尚未被定价"的不对称机会。**

## 五、PB-ROE 交叉验证

**PB-ROE 公式**：合理PB = (ROE - g) / (r - g)，其中r为股权要求回报率

| 参数 | 假设 | 说明 |
|:---|:---|:---|
| 可持续ROE | **9.5%** | 取近3年均值（9.4%/10.1%/9.9%），略低于当前 |
| 永续增长率g | **3%** | 电网行业自然增长+通胀 |
| 股权要求回报率r | **8%** | CAPM：无风险利率1.8% + β×ERP(1.0×6.2%) |

合理PB = (9.5% - 3%) / (8% - 3%) = 6.5% / 5% = **1.30x**

当前净资产（归母）= 121.51亿元
合理市值 = 121.51 × 1.30 = **158亿元**

目标价 = 158亿 / 10.19亿股 = **15.51元**

**PB-ROE估值明显低于PE估值**，这是因为：
1. ROE仅9.5%，低于股权成本8%，价值创造能力有限
2. 电力设备行业的重资产属性限制了ROE的上行空间
3. PB-ROE模型假设永续增长率3%，若增速提升至5%，合理PB将升至(9.5%-5%)/(8%-5%)=1.50x，市值=182亿

PB-ROE方法揭示了许继电气的**深层价值局限**：以当前ROE水平，公司并未创造显著的超额股东价值。PE估值方法之所以给出更高的目标价，是因为隐含了对2026年利润大幅增长（+57%）的预期，但这是**周期性修复而非结构性趋势**。一旦利润增速回归常态（10-15%），估值将向PB-ROE锚点收敛。

## 八、逻辑证伪与极限压力测试

### 8.1 黑天鹅场景模拟

**"一击毙命"事件：国网采购政策重大调整——全面转向最低价中标**

如果国家电网从当前的"技术+价格综合评估"转向"最低价中标"：
- 许继电气在二次设备和特高压领域的技术溢价将完全消失
- 民营竞争者（思源电气等）在成本控制上的优势将被放大
- 所有高毛利板块（直流32.7%、变配电29.5%）将面临断崖式下滑

**极限压力测试**：

## 九、模块六核心结论

1. **综合估值目标价32.96元（不复权市价，概率加权）**，较当前21.72元有**+51.7%的上行空间**。基准情景目标价32.40元对应18.0x的2026E PE。Forward PE（当前价/2026E EPS）仅为12.07x，显著低于可比公司均值~21x。

2. **盈亏比11.0:1**，较6月26日的16.6:1小幅收窄（主因股价微涨1.8%），但仍是A股电力设备板块中极为优异的非对称结构。当前下行空间仅-4.7%（至保守情景目标价20.70元），而上行空间+51.7%。

3. **估值向上催化剂**（较6月26日新增项）：十五五电网投资锚点从4万亿上调至5万亿+（6月26日）——这是本报告期间最大的政策利好；国网特高压第三批设备招标108.72亿定标（7月22日），许继电气中标12.45亿元；2026年前三批特高压采购292.61亿已超去年全年，行业爆发力持续验证；半年报8月20日——若Q2毛利率修复到21%以上，将正式确认底部确立。

4. **估值向下风险**（较6月26日更新）：铜价趋势反转（13,235→13,905,+5.1%），成本端压力加剧而非缓解；半年报Q2毛利率若仍低于21%，"毛利率修复"核心逻辑将受到严重挑战；国电南瑞特高压份额持续扩张（最新招标~50%+），许继定价权持续受侵蚀。

5. **核心判断**：6月26日以来的四周，出现了"基本面重大利好（电网投资锚点升级+订单暴增）vs 铜价边际恶化"的混合信号。综合评估，利好因素（政策+订单）的权重和烈度显著大于利空（铜价），因为电网投资5万亿+锚定了行业未来5年的需求底线，而铜价在13,000-14,000区间的高位震荡是已经被市场定价的已知风险。**估值-基本面剪刀差较6月26日进一步扩大。**
