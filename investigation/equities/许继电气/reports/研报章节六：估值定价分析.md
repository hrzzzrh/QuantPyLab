**历史分位解读及审慎思考**：

PE-TTM处于2021年以来约18%的历史低分位（6月26日约5.3%，7月22日约6.4%，7月31日约10.3%；8月19日PE 21.24x较7/31抬升因TTM净利润下滑），当前PE（21.24x）仍低于25%分位（21.8x）但已接近。估值被压缩到历史极端水平的背景下，6月26日以来却出现了一系列重大利好：
1. **十五五电网投资锚从4万亿上调至5万亿+**（国家能源局6.26宣布），政策确定性的天花板被大幅打开
2. **特高压前三批采购292.61亿已超2025全年**，产业需求爆发的实际数据远超年初预期
3. **许继电气已公告特高压中标25.2亿元**（5月12.75+7月12.45），在手订单确定性极强

这意味着：**估值处于历史底部区间，而基本面正在发生实质性的积极变化。** 这种"估值-基本面的剪刀差"是投资机会的核心来源。A股的局限性在于：历史上2018-2021年PE冲高至40-57x包含了新能源概念炒作的非理性成分；但当前PE-TTM 21.24x（H1后）已因TTM下滑而抬升，Forward PE 18.0x（22.33/1.24）已高于基准15x，不再低估。

**分位审计的双向解读（审慎思考）**：PE低分位存在两种解释——"结构错杀型"（市场过度悲观）与"周期修复型"（ROE 9.9%平庸+2025年营收-12.3%+Q1利润崩塌使市场合理下修估值中枢）。结合PB-ROE交叉验证（模块六第五节）的结论，当前低估更可能属于"周期修复型"——上行空间的兑现依赖2026年利润修复的真实落地，而非单纯的情绪修复，这限制了三态目标价的乐观偏移。

## 二、适配性估值方法选择

### 2.1 方法论选择与理由

| 估值方法 | 是否选用 | 选择理由 |
|:---|:---|:---|
| **PE（市盈率）** | ✅ **主选** | 公司盈利稳定、PE为正且历史区间可参考，电力设备行业通用估值方法 |
| **PB-ROE** | ✅ **辅选** | 公司ROE稳定在9-10%，PB-ROE框架有助于判断估值与盈利能力的匹配度 |
| **DCF（现金流折现）** | ❌ 不适用 | 公司业务高度依赖电网投资政策周期，自由现金流波动极大（2024 OCF 13亿 vs 2025 27亿），长期增长率难以合理估计 |
| **SOTP（分部估值）** | ✅ **辅选** | 公司六大板块盈利能力差异显著（直流32.7% vs 新能源13.8%），SOTP能揭示业务分拆的潜在价值 |
| **PEG** | ❌ 不适用 | 公司处于成熟期，非稳定成长期企业，PEG参考意义有限 |
| **EV/EBITDA** | ✅ **参考** | 公司几乎无有息负债，EBITDA≈净利润+折旧，可用于交叉验证 |
| **PS（市销率）** | ❌ 不适用 | 净利率波动大（4.7%-9.8%），PS无法反映盈利质量的改善 |

**核心估值路径**：PE为主锚（给予60%权重），PB-ROE为交叉验证（25%权重），SOTP为情景测试（15%权重）。

## 五、PB-ROE 交叉验证

**PB-ROE 公式**：合理PB = (ROE - g) / (r - g)，其中r为股权要求回报率

| 参数 | 假设 | 说明 |
|:---|:---|:---|
| 可持续ROE | **9.5%** | 取近3年均值（9.4%/10.1%/9.9%），略低于当前 |
| 永续增长率g | **3%** | 电网行业自然增长+通胀 |
| 股权要求回报率r | **8%** | CAPM：无风险利率1.8% + β×ERP(1.0×6.2%) |

合理PB = (9.5% - 3%) / (8% - 3%) = 6.5% / 5% = **1.30x**

当前净资产（归母）= 123.63亿元（H1末，2025末为121.51亿）
合理市值 = 123.63 × 1.30 = **160.7亿元**

目标价 = 160.7亿 / 10.19亿股 = **15.77元**

**PB-ROE估值明显低于PE估值**，这是因为：
1. ROE仅9.5%，仅略高于股权成本8%，超额价值创造能力有限
2. 电力设备行业的重资产属性限制了ROE的上行空间
3. PB-ROE模型假设永续增长率3%，若增速提升至5%，合理PB将升至(9.5%-5%)/(8%-5%)=1.50x，市值=182亿

PB-ROE方法揭示了许继电气的**深层价值局限**：以H1年化ROE约6.8%及中性ROE 9.9%（较2025A 9.94%回落）测算，合理PB从1.30x（ROE 9.5%）下修至1.10x（ROE 7.5%）时合理市值仅135亿，目标价13.25元。PE估值之所以高于PB-ROE，是因隐含H2修复后ROE回到9-10%，但若全年仅7-8%，估值将向PB-ROE下限收敛。

## 九、模块六核心结论

1. **综合估值目标价19.72元（不复权市价，修正市值法/中性情景，H1后）**，较当前22.33元（8月19日收盘）有**-11.7%的下行**，三态概率加权目标价20.02元（-12.4%）已低于现价。该目标价由基准市值189.5亿×（1+6%）审计调节=200.9亿、除以10.19亿股得出，对应15.9x的2026E PE（1.24元）。Forward PE 18.0x（22.33/1.24）已高于基准15x，估值不再低估。

2. **盈亏比-0.21:1（安全垫消失）**，按框架口径（分子=加权目标价20.02元、分母=保守价11.28元）计算，现价已高于加权目标价，下行风险-49.5%（至保守价11.28元）远大于上行空间至中性19.72元的-11.7%，非对称结构转为**负向**。

3. **估值催化剂证伪**：十五五电网5万亿+政策红利仍在，但H1业绩（营收+1.2% vs 国网固投+12.6%）显示传导失效；特高压前四批293亿虽超2025全年，但许继综合份额仅10.4%（第6）且H1直流营收-4.05%未兑现；半年报毛利率19.90%（Q2 20.41%）大幅不及21%修复目标，底部未确立。

4. **估值向下风险兑现**：铜价14,850（YTD+18%，超预警）成本高压；半年报Q2毛利率20.41%仍<21%且直流毛利率23.14%（-17.62pp）崩塌，"毛利率修复"逻辑证伪50%；国电南瑞综合份额领先且思源/西电H1业绩（+13%/+15%）显著跑赢许继（-34.4%），定价权与竞争力担忧加剧。

5. **核心判断（8月19日重构）**：H1验证显示"行业景气（国网投资+12.6%、特高压293亿）vs 公司业绩掉队（营收+1.2%、净利-34%）"的剪刀差反向扩大，公司α显著弱于行业β。政策底与估值底仍在，但公司业绩底未至。中期目标价从34.25元大幅下修至19.72元（-42.4%），评级从"核心配置（第一象限）"下调至"持有/观望（第三象限偏防御）"，等待Q3毛利率与直流交付的二次验证。
