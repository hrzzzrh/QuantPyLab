**历史分位解读及审慎思考**：

PE-TTM处于2021年以来约10.3%的历史低分位（6月26日为约5.3%，7月22日约6.4%；7月下旬股价自21.72元反弹至22.80元后分位有所回升，估值压缩仍处于历史极端水平），当前PE（19.90x）仍低于25%分位（21.8x）。估值被压缩到历史极端水平的背景下，6月26日以来却出现了一系列重大利好：
1. **十五五电网投资锚从4万亿上调至5万亿+**（国家能源局6.26宣布），政策确定性的天花板被大幅打开
2. **特高压前三批采购292.61亿已超2025全年**，产业需求爆发的实际数据远超年初预期
3. **许继电气已公告特高压中标25.2亿元**（5月12.75+7月12.45），在手订单确定性极强

这意味着：**估值处于历史底部区间，而基本面正在发生实质性的积极变化。** 这种"估值-基本面的剪刀差"是投资机会的核心来源。A股的局限性在于：历史上2018-2021年PE冲高至40-57x包含了新能源概念炒作的非理性成分；但当前PE-TTM被压缩至19-20x，显然是市场对Q1利润暴跌的过度悲观定价。即使考虑到铜价反弹削弱了成本端改善预期，17-18x的Forward PE（基于我们保守情景EPS 1.30）仍然处于不合理的低位。

**分位审计的双向解读（审慎思考）**：PE低分位存在两种解释——"结构错杀型"（市场过度悲观）与"周期修复型"（ROE 9.9%平庸+2025年营收-12.3%+Q1利润崩塌使市场合理下修估值中枢）。结合PB-ROE交叉验证（模块六第五节）的结论，当前低估更可能属于"周期修复型"——上行空间的兑现依赖2026年利润修复的真实落地，而非单纯的情绪修复，这限制了三态目标价的乐观偏移。

## 二、适配性估值方法选择

### 2.1 方法论选择与理由

| 估值方法 | 是否选用 | 选择理由 |
|:---|:---|:---|
| **PE（市盈率）** | ✅ **主选** | 公司盈利稳定、PE为正且历史区间可参考，电力设备行业通用估值方法 |
| **PB-ROE** | ✅ **辅选** | 公司ROE稳定在9-10%，PB-ROE框架有助于判断估值与盈利能力的匹配度 |
| **DCF（现金流折现）** | ❌ 不适用 | 公司业务高度依赖电网投资政策周期，自由现金流波动极大（2024 OCF 13亿 vs 2025 27亿），长期增长率难以合理估计 |
| **SOTP（分部估值）** | ✅ **辅选** | 公司六大板块盈利能力差异显著（直流32.7% vs 新能源13.8%），SOTP能揭示业务分拆的潜在价值 |
| **PEG** | ❌ 不适用 | 公司处于成熟期，非稳定成长期企业，PEG参考意义有限 |
| **EV/EBITDA** | ✅ **参考** | 公司几乎无有息负债，EBITDA≈净利润+折旧，可用于交叉验证 |
| **PS（市销率）** | ❌ 不适用 | 净利率波动大（4.7%-9.8%），PS无法反映盈利质量的改善 |

**核心估值路径**：PE为主锚（给予60%权重），PB-ROE为交叉验证（25%权重），SOTP为情景测试（15%权重）。

### 4.2 锚点回测

修正后隐含PE = 34.25 / 1.73 = **19.8x**

对比：
- 历史PE中值：24.5x（当前显著低于历史中值）

## 五、PB-ROE 交叉验证

**PB-ROE 公式**：合理PB = (ROE - g) / (r - g)，其中r为股权要求回报率

| 参数 | 假设 | 说明 |
|:---|:---|:---|
| 可持续ROE | **9.5%** | 取近3年均值（9.4%/10.1%/9.9%），略低于当前 |
| 永续增长率g | **3%** | 电网行业自然增长+通胀 |
| 股权要求回报率r | **8%** | CAPM：无风险利率1.8% + β×ERP(1.0×6.2%) |

合理PB = (9.5% - 3%) / (8% - 3%) = 6.5% / 5% = **1.30x**

当前净资产（归母）= 121.51亿元
合理市值 = 121.51 × 1.30 = **158亿元**

目标价 = 158亿 / 10.19亿股 = **15.51元**

**PB-ROE估值明显低于PE估值**，这是因为：
1. ROE仅9.5%，仅略高于股权成本8%，超额价值创造能力有限
2. 电力设备行业的重资产属性限制了ROE的上行空间
3. PB-ROE模型假设永续增长率3%，若增速提升至5%，合理PB将升至(9.5%-5%)/(8%-5%)=1.50x，市值=182亿

PB-ROE方法揭示了许继电气的**深层价值局限**：以当前ROE水平，公司并未创造显著的超额股东价值。PE估值方法之所以给出更高的目标价，是因为隐含了对2026年利润大幅增长（+57%）的预期，但这是**周期性修复而非结构性趋势**。一旦利润增速回归常态（10-15%），估值将向PB-ROE锚点收敛。

## 七、确定性与胜率矩阵

## 九、模块六核心结论

1. **综合估值目标价34.25元（不复权市价，修正市值法/中性情景）**，较当前22.80元（7月31日收盘）有**+50.2%的上行空间**。该目标价由基准市值317亿×（1+10%）审计矩阵调节=349亿、除以10.19亿股得出，对应19.8x的2026E PE。三态概率加权目标价33.29元（+46.0%）作为胜率矩阵参考。Forward PE（当前价/2026E中性EPS）仅为13.2x，显著低于可比公司均值（约39x）。

2. **盈亏比3.2:1**，按框架口径（分子=概率加权目标价33.29元、分母=未调节保守目标价19.50元）计算，较修正前13.6:1显著收窄（分子口径合规化+其他收益假设审慎下调+股价自7/22反弹5%三重因素），但仍是A股电力设备板块中显著高于1.5门槛的非对称结构。当前下行空间-14.5%（至保守情景目标价19.50元），上行空间+50.2%。

3. **估值向上催化剂**（较6月26日新增项）：十五五电网投资锚点从4万亿上调至5万亿+（6月26日）——这是本报告期间最大的政策利好；国网特高压第三批设备招标108.72亿定标（7月22日），许继电气中标12.45亿元；2026年前三批特高压采购292.61亿已超去年全年，行业爆发力持续验证；半年报8月20日——若Q2毛利率修复到21%以上，将正式确认底部确立。

4. **估值向下风险**（较6月26日更新）：铜价趋势反转（13,235→13,905,+5.1%），成本端压力加剧而非缓解；半年报Q2毛利率若仍低于21%，"毛利率修复"核心逻辑将受到严重挑战；国电南瑞特高压份额持续扩张（最新招标~50%+），许继定价权持续受侵蚀。

5. **核心判断**：6月26日以来的四周，出现了"基本面重大利好（电网投资锚点升级+订单暴增）vs 铜价边际恶化"的混合信号。综合评估，利好因素（政策+订单）的权重和烈度显著大于利空（铜价），因为电网投资5万亿+锚定了行业未来5年的需求底线，而铜价在13,000-14,000区间的高位震荡是已经被市场定价的已知风险。**估值-基本面剪刀差较6月26日进一步扩大。**
