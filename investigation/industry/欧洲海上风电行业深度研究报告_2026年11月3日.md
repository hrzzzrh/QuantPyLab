# 欧洲海上风电行业深度研究报告

**日期**：2026年11月3日  
**研究覆盖**：2018-2035年装机规模、拍卖机制与FID节拍、供应链产能缺口、中国企业出海路径及贸易壁垒  
**数据截至**：2026年11月3日（装机数据截至2026年6月末欧洲口径、2026年9月末德国口径；公司经营数据截至2026年9月30日，即A股三季报口径，Sif三季报待2026年11月6日披露；拍卖/FID/项目事件截至2026年11月3日——英国AR8于2026年10月15日确认改走标准时间表、密封投标窗口2026年12月3-9日、结果2027年2月15-17日；法国AO10已于2026年10月12日截标、CRE评估后授标待2027年2月；荷兰IJmuiden Ver Gamma-A/B于2026年11月26日-12月10日招标；德国WindSeeG修正案2026年10月8日完成Bundestag一读、10月28日联邦政府就参议院意见作出反声明，尚未表决）

## 一、摘要 (Executive Summary)

- **核心判断**：欧洲海上风电的长期供给缺口依然成立，但"累计拍卖约59GW、约42GW未FID"不能再被直接等同于未来两三年的订单密集释放。Sif于2026年7月31日披露，其MV2新厂已实现每周4-5根单桩的计划产出，然而因近年到达FID的项目偏少，公司明确判断2027-2028年单桩生产需求偏低；其190kt独家谈判项目仍待开发商FID，目标生产窗口为2027年5-8月。截至2026年11月3日该190kt项目仍无转为正式订单的公告（Sif 2026年三季度交易更新定于2026年11月6日发布），但Sif的交付端在8-9月连续兑现：8月20日完成Bałtyk 2&3共100根单桩+100个过渡段的最终发运，9月1日实现OranjeWind（53根无过渡段单桩）首批发运。这验证了当前主矛盾是**需求/FID节拍断层**，而非单纯的制造能力不足。这一判断已被全行业数据放大：Aegir Insights 2026年10月20日统计显示，2026年前三季度中国以外海上风电FID仅约2GW、涉及3个项目，不足2023年创纪录年份的五分之一，为2022年以来最低；TGS 4C（2026年9月21日）口径为2.1GW、Q3单季仅Gennaker一个项目FID、全年预计5.6GW（2020年以来第二低）。丹麦于2026年8月4日以两向CfD成功授予Vattenfall 1.8GW（Hesselø 800MW €72.5/MWh、Nordsøen Midt 1GW €67.4/MWh），验证了CfD替代负补贴后拍卖机制的修复；与此同时德国WindSeeG修正草案于2026年9月2日经联邦内阁通过后，10月8日完成Bundestag一读、10月28日联邦政府就参议院意见作出反声明（拒绝补做2026年拍卖量、坚持两阶段模式、仅承诺审查指数化），截至11月3日尚未表决，法案确认2026年无拍卖、2027年起转向"两阶段（市场定价优先、CfD备选）"模式，显示拍卖节奏仍不均匀。2026年10月的拍卖端出现三件并行事件：①法国AO10（11个项目、7浮4固、合计约9.7-11.1GW）已于2026年10月12日12时截标，CRE按12-14周完成报价排序、授标待2027年2月，项目投运窗口2035-2038年；②英国AR8（固定+漂浮+ODOW全技术路线）已于2026年7月20日-8月7日完成申请、8月10日-9月16日完成资格审核，约20个海风项目约17.1GW潜在合格容量；2026年10月15日DESNZ确认AR8不适用“待定申请”加速程序、改走标准时间表（五条分支中最长一条），NESO招标通知与DESNZ合同预算通知均定于2026年11月19日，密封投标窗口2026年12月3-9日，结果公布2027年2月15-17日、合同签署2027年3月4-17日；③德国2027年拍卖管线N-10.1/N-10.2/N-12.4/N-12.5/N-13.1/N-13.2共6个区块（RWE与Masdar - **装机现状**：截至2026年H1，欧洲累计海上风电装机约40.9GW（WindEurope 2026年中统计），较2025年底39GW新增约1.9GW。2025年新增仅2.0GW（为2016年以来最低），主因施工延误；2026年H1已并网2.3GW（182台、9个风场，为H1 2025的3倍），德国单国H1新增1.08GW（84台，Borkum Riffgrund 3与EnBW He Dreiht合计1.92GW中的已并网部分）。德国截至2026年6月末在运达10.8GW（1,764台）；据德国行业统计（2026年10月），2026年前三季度德国海上风电新投运130台、1,760MW，即在运规模已升至约11.9GW。Borkum Riffgrund 3（913MW）于2026年8月底进入商业运营、9月22日举行开业仪式；He Dreiht（960MW）9月17日投运仪式后仍处分批并网阶段。2026全年WindEurope仍预期约6GW并网。WindEurope 2026年秋季口径预计2026-2030年累计新增约33.5GW、年均约6.7GW（较2021-2025年年均2.84GW大幅提速；含加速情景最高约41GW），2030年累计达73GW。2030年后欧洲各国目标激进——北海九国《汉堡宣言》提出2050年跨境海风100GW、区域总目标300GW。

- **开发节拍（最重要的量化框架）**：欧洲海风全周期约7-10年（vs 中国4-7年），核心前瞻指标为**拍卖量（领先4-7年）**和**FID量（领先2-3年）**，这也是研判中国供应链订单释放窗口的核心依据。**2026年前三季度数据确认"拍卖→FID→订单"转化效率远低于预期：H1海上FID仅0.6GW、前三季度中国以外仅约2.0-2.1GW（vs 2022-2026累计拍卖约59GW），H1海上风机订单仅2.8GW（同比-77%），印证Sif关于2027-2028年单桩需求偏低的预警。**

- **2022年转型意义**：2022年俄乌冲突后，欧洲海风从“碳中和叙事”切换为“能源安全叙事”，各国政府加速拍卖规模。2022-2025年按公布年度累计拍卖约48.8GW；加上2026年1月公布结果的AR7 8.4GW与丹麦1.8GW，2022年以来累计拍卖约59GW，远超此前任何时期；但Sif H1 2026与Aegir/TGS 4C的FID统计共同表明，拍卖到FID的转化及其到供应链生产的传导显著慢于原先预期，项目池应视为中长期可选订单，而非短期确定收入。2026年8月丹麦1.8GW成功授予与德国暂停拍卖并存，显示“拍卖→CfD可融资性”是决定转化效率的关键变量。2026年H2的拍卖端由“单极依赖英国”转向“多极并行”，但英、法、荷三项授标时点全部后移至2027年一季度，2026年实际只完成10.2GW，意味着2026-2028年的订单真空被进一步拉长；2027年一季度约29-30GW的集中授标将成为判断下一轮FID斜率的关键观测点。

- **核心产能缺口**（长期决定中国企业机会大小）：
  - **单桩基础**：欧洲本土产能仅满足2030目标需求的56%，大型单桩（>12m直径）欧洲仅Euskal能供法兰；但2027-2028年的实际生产需求取决于FID，不能以2030目标缺口外推为当期满产。
  - **海缆**：欧洲排产已至2030年，供需缺口极大（东方电缆表述）。
  - **风电安装船(WTIV)**：2025年起已出现短缺，2029-2030年预计缺口达14.9GW/年。
  - **风机大型化**：欧洲OEM集中在15MW级，中国已量产16-20MW，但认证和业主信任仍是核心壁垒。
  - **塔筒/叶片**：部分欧洲供应商取消扩产计划（Vestas波兰叶片厂、SGRE丹麦机舱厂），缺口扩大。

  2. **拍卖流标**：2025年丹麦3GW+荷兰1GW+德国2.5GW拍卖无人投标，负补贴机制正在被CfD替代但过渡期不确定。
  3. **认证周期长**：DNV/GL认证通常需2-3年，业主验厂门槛高。
  4. **地缘政治**：中国投资欧洲的审查趋严（明阳苏格兰工厂面临政治博弈）。
  5. **FID到并网转化率不足**：历史上拍卖→FID→并网存在较高折损率。

## 二、背景与行业定义

### 2.1 欧洲海上风电的全球定位

欧洲是全球海上风电的起源地与第二大市场。2025年底全球累计海上风电92.3GW，中国占52%（~48GW），欧洲占42%（~39GW），亚太其他地区（台湾、越南、韩国、日本等）占剩余6%。

与中国的"政府主导+大型基地"模式不同，欧洲海上风电的核心特征是**市场化拍卖机制主导、CfD差价合同为核心收益工具、各国独立监管但EU协调目标**。

### 2.2 欧洲海风开发全流程（与中国的对应关系）

```
欧洲： [场地租赁] → [许可审批] → [CfD拍卖] → [FID] → [建设施工] → [并网COD]
       Leasing     Permitting    Auction     FID     Construction  Commissioning
       3-5年        2-4年        核心节点    关键决策    2-3年          ≈0

中国： [核准] → [招标] → [定标] → [建设施工] → [并网]
       核准+路条   EPC+风机   中标+开工   2-3年        并网确认
       4-7年（总周期）
```

**关键差异**：

| 维度 | 中国 | 欧洲 |
|------|------|------|
| 总周期 | 4-7年 | 7-10年 |
| 开发权+电价确定 | 分步：核准→招标 | **合二为一**：Auction/CfD |
| 最关键的开工信号 | 招标完成/定标 | **FID**（融资关闭+管理层批准） |
| 前瞻指标领先时间 | 核准/招标 → 并网：2-4年 | Auction → 并网：4-7年；FID → 并网：2-3年 |
| 供应链订单释放窗口 | 招标定标后 | **FID后**（此时供应链已基本锁定） |
| 政府角色 | 主导规划、分配指标 | 监管拍卖规则、提供CfD框架 |

### 2.3 发展阶段划分

| 阶段 | 时期 | 核心特征 | 年均新增 |
|------|------|---------|---------|
| 起步期 | 1991-2010 | 丹麦/英国率先示范，首个风场Vindeby(1991) | <0.5GW |
| 规模化起步 | 2011-2018 | 5国主导(UK/DE/DK/NL/BE)，固定电价补贴 | 1-3GW |
| 市场化转型 | 2019-2021 | CfD主导，零补贴出现，Hollandse Kust Zuid | 3-4GW |
| 能源安全驱动 | 2022-2025 | 俄乌冲突后目标大幅上调，拍卖放量但建设滞后 | 2-4GW |
| 加速交付期 | 2026-2030 | 存量已拍项目集中FID→建设释放，中国供应链深度参与 | 6-10GW |
| 深远海时代 | 2030-2035 | 漂浮式商业化，北海能源中心，300GW愿景 | 10-15GW |

**WindEurope 2026年秋季统计验证**：H1 2026欧洲仅0.6GW海上风电完成FID（vs 4.5GW陆上），海上FID仅占FID总量的12%；H1 2026海上风机订单仅2.8GW（同比-77%，vs H1 2025的12GW），为近年最低。Aegir Insights（2026年10月20日）与TGS 4C（2026年9月21日）的前三季度口径进一步确认：中国以外海上FID约2.0-2.1GW、仅3个项目，为2022年以来最低，不足2023年记录年的1/5；TGS 4C同时预计全年FID约5.6GW（2020年以来第二低），而2026年获最终许可（consent）容量预计达22.2GW、为历史第二高——**许可端在放量、投资端在收缩**，这一剪刀差是当前最清晰的行业特征。全球在运海上风电约92.7GW、在建41.2GW、已FID待建7.1GW。该组数据确认：**欧洲海风当前核心矛盾是FID/订单断层而非拍卖量不足**——2022-2026年累计拍卖约59GW但2026年前三季度仅约2GW完成FID、H1仅2.8GW获得风机订单，拍卖→FID→订单的转化效率远低于预期。

**关键解读**：
1. **2022年为拍卖放量元年**：俄乌冲突前，2020年仅0.76GW拍卖；冲突后，2022年跃升至9.5GW，2023-2024年持续加速至13.6-19.9GW。
2. **2025年"拍卖小年"有特殊原因**：8国计划拍卖17.3GW但仅成交5.8GW——丹麦3GW、荷兰1GW、德国2.5GW出现**流标/无人投标**，根因是负补贴/零补贴机制设计缺陷（开发商不愿支付"开发权费用"）。这恰恰催生了政策改革——丹麦已于2026年8月以两向CfD成功重启（Hesselø竞价5家、Nordsøen Midt 2家），德国亦拟从负补贴转向两向CfD。
3. **2026年拍卖锁定10.2GW，授标高峰后移至2027年一季度**：UK AR7已授予8.44GW（创纪录）；丹麦8月再增1.8GW，证明CfD机制修复有效。德国在2025年2.5GW（N-10.1/N-10.2）零投标后，联邦内阁于2026年1月28日批准WindSeeG修正、取消2026年剩余拍卖并将N-10.1/N-10.2（合计2.5GW）移入2027年；2026年8月11日BMWE发布草案细则，2027年起年拍卖量改为2-4.8GW弹性区间、引入“负补贴优先、CfD备选”两阶段模式（含NZIA标准），运营期延至35年、保留70GW（2045/2050年）目标；2026年9月2日联邦内阁通过修正草案，9月4日提交联邦参议院、**9月28日进入Bundestag（Drs. 21/8238）、10月8日完成一读并交付经济与能源委员会、10月16日联邦参议院出具意见（要求将2026年未拍容量补做到2030年、直接采用CfD-only并加成本指数化）、10月28日联邦政府反声明（Drs. 21/8825）拒绝补量要求、坚持两阶段模式、仅承诺审查规划建设期指数化**；截至2026年11月3日法案尚未表决，11月专家听证后进入二读三读。荷兰IJmuiden Ver Gamma-A/B两个各约1GW站点（合计2GW、共用一座2GW直流平台、单场最多76台≥15MW机组、可超额装机至1.15GW）确定于**2026年11月26日-12月10日17:00招标**，Gamma-A上限€117/MWh、补贴上限€47.58亿，Gamma-B上限€116/MWh、补贴上限€46.98亿（合计约€94.56亿），许可预计2027年一季度批复、2032年投运，NZIA要求作为资格预审条件。法国AO10（11个项目、约9.7-11.1GW、7浮4固，合并AO9/AO10）于2026年6月11日启动、**10月12日12时截标**，CRE需12-14周完成排序、能源部长授标预计2027年2月，25年CfD，投运窗口2035-2038年；PPE3（2026年2月12日法令）设2035年15GW在运、2030-31年累计授标26GW目标，AO10后仍余约8GW留待后续轮次。英国AR8（固定+漂浮+ODOW）于2026年7月20日-8月7日完成申请（约20个项目、约17.1GW潜在合格容量）、8月10日-9月16日完成资格审核；**2026年10月15日DESNZ确认AR8不适用Pending Applications加速程序**，NESO招标通知与合同预算通知定于11月19日，密封投标窗口12月3-9日、结果2027年2月15-17日、合同2027年3月4-17日签署。
4. **2022-2026累计拍卖约59GW**，其中约42GW尚未FID，仍是2029年后供应链订单的重要项目池；但Sif H1 2026的生产排程与Aegir/TGS 4C的FID统计共同提示，项目池并未在2027-2028年形成足够的已签生产需求。拍卖应继续作为领先指标，但必须以FID、基础合同和实际生产排期验证，不能直接以拍卖量推导近期订单。供给端的时间错配同样明显：据Rystad Energy（经媒体转引，未获原始报告核实），欧洲超大直径单桩名义产能将从2024年约120万吨升至2027年约270万吨，但项目延迟使需求不同步到达，欧洲工厂2026-2027年产能利用率预计仅约32%、2028年进一步降至19%——这与Sif的订单空档预警相互印证，“长期产能缺口”与“当期产能闲置”可以并存。2026年H2拍卖端的推进（法国AO10约9.7-11.1GW截标、荷兰2GW定档11-12月、英国AR8进入投标前最后程序）并未改变转化节奏：三项授标全部落在2027年一季度，Vanguard East/West虽已签署约£132亿融资但仍待交割与FID，说明拍卖→FID的转化并非自动完成。

### 4.2 CfD机制详解

**Contract for Difference（差价合同）**是欧洲海风的核心收益工具：

| 要素 | 内容 |
|------|------|
| 机制 | 政府与开发商约定**执行价(Strike Price)**，当市场电价低于执行价时政府补差，高于时开发商返还差额 |
| 类型 | 两向CfD（双向补差）为主流，部分国家曾用单向CfD或FiT |
| 期限 | 英国AR7起延长至**20年**（此前15年），波兰/France类似 |
| 通胀调整 | 英国CfD执行价与CPI挂钩（自AR4起），波兰/法国也在引入指数化 |
| 授予方式 | 竞标——开发商报价最低执行价/最高负补贴金额 |

### 4.3 负补贴机制缺陷与CfD转型

2023-2024年，德国、荷兰、丹麦等国推行**负补贴拍卖**（开发商向政府付费获取开发权），曾被视为"海风平价"的里程碑。但2025年暴露严重问题：

- **丹麦**：3GW拍卖收到零出价 → 2025年宣布转向CfD模式 → **2026年8月4日以两向CfD成功重启**，Vattenfall以DKK504/MWh（€67.4）与DKK542/MWh（€72.5）包揽Nordsøen Midt 1GW与Hesselø 0.8GW（分别2家、5家竞价，含Ørsted、RWE参与），合同期20年、并网目标2032年、三区域合计补贴上限DKK552亿（含增值税），验证机制修复有效；但丹麦下一轮Nordsøen Syd投标截止为2028年10月，**2027-2028年丹麦无海上拍卖**，WindEurope已就Pipeline空档对本地供应链的影响发出警告
- **荷兰**：IJmuiden Ver/Nederwiek 2GW零补贴流标 → 2026年拟改革
- **德国**：2026年1月28日联邦内阁批准WindSeeG修正、取消2026年剩余拍卖并将N-10.1/N-10.2（合计2.5GW）移入2027年管线；**2026年8月11日BMWE发布WindSeeG修正草案细则**：维持70GW（2045年）目标、年拍卖量改为2-4.8GW弹性区间、标准运营期延至35年、引入**两阶段拍卖**（第一阶段检验无补贴意愿、动态升价确定付款额；无人愿无补贴建设时进入第二阶段、以最低"适用值"竞价两向CfD，通过EEG市场溢价+再融资贡献执行，CfD仅为备选而非默认，且不含指数化），落实NZIA对2GW/年集中式预勘区块的非价格标准。**2026年9月2日联邦内阁正式通过修正草案**（新增电网连接最多20%超额建设、更灵活场址布局、降低尾流/阴影损失等配套条款），9月28日以Drs. 21/8238进入Bundestag、10月8日完成一读并交付经济与能源委员会，10月16日联邦参议院出具意见（要求把2026年未拍容量补做到2030年、改为单阶段CfD-only并加入成本指数化、为2023-2025年已授项目设退回重拍机制），10月28日联邦政府反声明（Drs. 21/8825）拒绝补量要求、坚持两阶段模式、仅承诺审查规划与建设期指数化；法案**截至2026年11月3日尚未表决**，11月委员会专家听证后进入二读三读。行业侧（BWO、VDMA、BDEW、IG Metall、ZDS）一致要求改为单阶段CfD-only+指数化，并批评"统一20%超额建设"不应一刀切；政府立场与行业诉求仍有明显缺口，意味着2027年德国拍卖规则在二读前仍可能变动。RWE与Masdar于2026年9月11日在柏林签署谅解备忘录、拟联合竞标德国2027年海上风电拍卖（意向投资超€30亿，以中标与FID为前提，非约束性承诺）；2027年拍卖管线包括N-10.1/N-10.2/N-12.4/N-12.5/N-13.1/N-13.2共6个区块。德国行业协会（Offshore Stiftung等）对草案表示欢迎但认为仍需强化成本指数化和通胀/融资成本变动保护

**对中国供应链的影响**：CfD模式回归后，项目收益率可预测性增强 → FID意愿提升 → 订单释放更可预期。此前负补贴下开发商"先交钱再赚钱"的模式导致大量项目在拍卖后延迟FID。德国" CfD备选"的设计被BWO等行业协会批评为仍不足以提供融资确定性（主张CfD应为默认且需指数化），若最终文本维持备选定位，2027年后拍卖的FID转化斜率仍存不确定性。

5. **客户关系**：已与RWE、Ørsted等头部开发商建立长期战略合作

**Sif H1 2026带来的跟踪修正与三季报验证**：Sif的判断不改变大金已签订单或其交付能力的事实，但削弱了用欧洲长期单桩产能缺口直接推演2027-2028年新签订单的逻辑。2026年三季报的双向验证更为清晰：一方面前三季度海外海工交付近15万吨创同期新高、综合毛利率升至35.6%、经营现金流20.43亿元（+35.39%），说明已签订单的高价与自有船增厚真实有效；另一方面Q3出口海风确收仅约2.8万吨、单桩占比下降使单季毛利率回落至30.1%，且全年尚未新签欧洲海工订单，显示新签节拍仍受FIT→CfD切换、FID延迟与项目排期后移制约。即"交付端兑现、订单端空窗"同时成立——前者支撑2026-2027年收入，后者决定2028年后的弹性。大金的关键验证项应增加海外基础订单的签约时间、客户项目FID状态及工厂排产，而非只跟踪欧洲拍卖容量。

### 6.4 订单释放时间窗口推演

```
2022-2026年累计拍卖约59GW
  ├── ~17GW 已FID（2023-2026年，2026年前三季仅约2GW）
  │   └── 供应链已锁定，2025-2028年并网
  └── ~42GW 未FID（大部分）
      ├── 2026-2027年：项目收益、融资及许可继续影响FID；Sif观察到2027-2028年单桩生产需求偏低
      │   └── 已拍卖项目并不自动转化为同期的基础订单（Vanguard 3.09GW已于2026.10融资签署，FID待交割）
      ├── 2027年一季度：AR8/AO10/荷兰Gamma合计约29-30GW集中授标
      │   └── 按2-3年FID周期，对应2028-2030年FID与2030-2032年并网
      └── 2028-2029年：招标转化与基础合同落地，决定2029年后生产节奏
```

**Sif H1 2026对框架的校正**：Sif的190kt独家谈判项目仅在开发商作出FID后才进入正式制造，当前目标窗口为2027年5-8月；公司同时将现有订单的生产尽量延至2027年，以避免在项目间缩产后重启。该案例说明应把独家谈判、获拍容量和FID后的基础合同分层跟踪，不能以任何单一口径替代订单收入判断。

**中国供应商的关键FID催化节点（2026-2027年）**：
- 英国AR7中标项目（8.4GW，包括Norfolk Vanguard West/East, Berwick Bank, Mona, Morgan等）→ 关注融资关闭和基础合同，而非仅以CfD获授判断订单；**Vanguard East/West已于2026.10.28签署约£132亿债务包（NWF追加约£10亿、40余家银行），金融交割在数日内完成、随后KKR受让各50%权益，FID与交割绑定**，两项目合计3.09GW、2029/2030年投运（Vestas各92台15MW机型已锁定）；Morgan（1.5GW）/Morecambe（480MW）联合输电资产已于2026.9.14获开发许可（输电端许可扫障不等于FID）
- 英国AR8（约17.1GW潜在合格容量）→ 2026年12月3-9日密封投标、2027年2月15-17日出结果；其FID窗口按2-3年周期落在2029-2030年，是本轮周期中最重要的单次订单催化
- 波兰已拍项目（3.4GW）→ 部分已FID，更多在2026年（Cadeler与Ocean Winds的BC-Wind 390MW基础安装合同已签、2028年起执行，属波兰管线兑现样本；大金BC Wind首批单桩已发运）
- 法国2024-2025年拍卖项目 → 2026-2027年FID；AO10（11个项目、约9.7-11.1GW、7浮4固）已于2026.10.12截标、授标待2027年2月，投运窗口2035-2038年，对2029年前供应链订单贡献有限

## 七、贸易政策、认证壁垒与风险

### 7.1 Net-Zero Industry Act (NZIA) ——2025年12月30日生效

**核心条款**：

| 条款 | 内容 | 生效时间 |
|------|------|---------|
| 非价格标准(NPC) | 可再生能源拍卖须纳入"韧性/可持续性"等非价格评审标准 | 2025.12.30 |
| 最低应用比例 | 各成员国每年至少30%拍卖容量（或6GW）须应用NPC | 2025.12.30 |
| 中国特定限制 | ≥**75%**风机不得源自中国；对另外25%，关键部件不得超过4件来自中国；**传动链不得来自中国** | 2025.12.30 |
| 永磁体限制 | 风机永磁体来自中国的比例不得超过**85%** | 2025.12.30 |
| 评审权重 | 韧性与可持续性标准合计须占评分**15%-30%**（其中韧性≥5%） | 2025.12.30 |

**实际影响**：
- **整机出口欧洲难度急剧增大**——NZIA直接锁死了中国整机的路径（除非本地化建厂）；**2026年3月26日英国政府声明不支持在英项目中使用明阳风机即系该逻辑的极端体现**
- **部件层面影响相对温和**——单桩/塔筒/海缆未被列为"高度依赖中国"的部件（欧盟在风电领域相对自给）
- 比利时Princess Elisabeth Zone(PEZ1, 700MW)拍卖为首个全面受NZIA约束的案例；德国2026年WindSeeG草案已落实NZIA对2GW/年集中式预勘区块的非价格标准（去碳、能源安全、降噪、法兰技术与技能贡献等）

### 7.2 Industrial Accelerator Act (IAA) ——2026年3月提案、立法程序中

NZIA后欧盟仍不满足，2026年3月4日欧盟委员会发布IAA提案（COM(2026)100）：

| 条款 | 内容 | 当前状态（截至2026.11.3） |
|------|------|--------------------------|
| **欧盟原产地/低碳要求** | 在公共采购和可再生能源拍卖中要求"Made in EU"和/或低碳比例，适用于风电（含固定与漂浮）、光伏、电池等净零技术 | 立法程序中，拟将非价格标准覆盖面由现行"30%或6GW/年/成员国"提高至**40%或8GW/年**，并扩大成本豁免阈值 |
| **风电拍卖新增要求** | 对全部年拍卖量（而非30%）适用网络安全/数据安全预审，并对风电等技术引入"欧盟原产地"预审或授标标准 | 同上，部分风电行业（WindEurope 2026.3立场文件）呼吁简化而非复杂化 |
| **FDY/加速区** | 要求成员国划定至少一个工业制造加速区，简化高耗能/净零项目许可，对"战略项目"加速环评 | 同上；欧洲议会三个主管委员会（内部市场、国际贸易、工业）投票定于2026年12月1日，理事会拟11月底形成总立场，谈判预计延续至2027年 |
| **风电适用边界** | IAA把海上风电与光伏/电池/电动车/关键原材料并列为战略领域，对公共采购与拍卖引入欧盟原产地、低碳与网络安全要求 | 生效后1年至少1个主要部件须源自欧盟、3年后至少2个；欧洲议会拟要求欧盟本土增值≥50%，理事会倾向对GPA/FTA伙伴国给予等效认定，双方立场均未定案 |

### 7.3 各国本地化政策

- **英国**：CfD拍卖中已纳入**供应链计划(Supply Chain Plan)**评审，鼓励本地就业和制造。AR7进一步放宽了供应链准入门槛；但**2026年3月对明阳风机的"不支持使用"声明**显示英国在整机环节的国家安全审查已实质收紧
- **德国**：WindSeeG法案要求在拍卖中评审"可持续性"和"供应链韧性"；2026年WindSeeG草案进一步将NZIA非价格标准制度化于集中式预勘区块招标，并提出TSO成本疏导与海工/渔业分成机制
- **法国**：历史上有较强的本地化倾向（如要求风机在法国港口组装）；已启动AO10 10GW招标（5GW固定+5GW漂浮，最高限价€100/MWh、25年CfD），漂浮部分为全球最大单次承诺
- **波兰**：本土化要求包括使用波兰港口和船厂（大金已通过与Wulkan合作应对）

### 7.4 认证壁垒

- **DNV/GL认证**：欧洲海风项目必须通过DNV或GL的型式认证，周期通常2-3年
- **业主验厂**：头部开发商（Ørsted/RWE/Vattenfall/SSE）有独立的供应商审核体系，周期6-18个月
- **业绩记录**：欧洲开发商极度重视"成功交付履历"——大金之所以能持续拿单，2022年以来的批量交付记录是关键

### 7.5 关税与贸易

- **欧盟对中国风电产品的平均关税仅约1.3%**（Ghent大学研究），低于中国对EU风电产品征收的6-10%
- **塔筒反倾销将于2026年12月17日到期**：欧盟2020年10月21日对华钢制风塔立案、2021年12月16日终裁，税率7.2%-19.2%；该措施将于2026年12月17日到期，期终复审申请的关键截止节点（2026年9月17日）已过且未见复审立案，按现行程序到期后措施终止（企业口径、媒体核对欧盟TDI数据库后一致）。天顺风能已于2021年后停止全部对欧塔筒出口，故该品类敞口有限
- **2026年10月"双反"传闻已被证伪**：10月9日市场流传"欧盟对原产中国的风机塔筒及关键结构件发起反倾销与反补贴立案调查"，当日大金重工、天顺风能、海力风电跌停；经查欧盟委员会贸易防御数据库、EUR-Lex与中国贸易救济信息网均无新立案记录，传闻实为2020年旧案重炒，大金重工10月12日公开否认。该事件显示市场对"塔筒税延伸至单桩"高度敏感
- **钢铁保障措施是单桩环节最现实的下一道壁垒**：成品单桩目前不在欧盟钢铁保障措施范围内（钢板、部分钢管受保护，成品基础不受同等保护），形成"原料被保护、成品不设限"的缺口；IndustriAll Europe与欧洲海上风电基础联盟（OWFA）于2026年10月23日联名致函欧委会贸易与经济安全委员，要求把单桩等海风基础纳入保障措施范围，理由为欧洲7家单桩厂"至2024年供应了欧洲全部需求"、进口价格显著偏低。若被采纳，将直接改变中国单桩出海的成本与准入条件
- **美国232风机调查（2026年10月22日）**：总统公告认定进口风机及零部件"威胁国家安全"，但**不加征新税**，改为指示商务部与USTR与贸易伙伴谈判、180天内（2027年4月20日前）汇报进展；钢/铝/铜既有232关税不变，若谈判失败仍可加税。对欧洲整机与部件供应链构成中期不确定性
- **FSR（外国补贴条例）路径**：欧委会2026年2月3日对金风科技启动深入调查，欧盟普通法院2026年7月20日驳回其临时措施申请，实质审查仍在进行；大金重工目前不在FSR立案范围内
- **反倾销风险**：目前仍无针对中国海风基础（单桩/导管架）的反倾销、反补贴措施（天顺风能2026年10月31日投资者关系答复亦确认“欧盟目前暂未针对中国海上风电基础产品单独设置反倾销、反补贴等贸易限制措施”），但光伏与塔筒的前车之鉴、以及OWFA的保障措施诉求，说明该风险正在从"传闻"转向"程序"

### 7.6 地缘政治审查

- 英国对明阳智能苏格兰Ardersier港15亿英镑投资的审查已从“进行中”转为**实质不支持**：英国能源事务大臣2026年3月26日议会声明称不支持在英项目中使用明阳风机；明阳3月27日公告称尚未收到正式回复、尚未投入资金，项目存在终止风险。2026年11月2日英国下议院BIST委员会报告批评该决定“反应式、不一致、不透明”，指出政府未说明法律依据、未充分征询苏格兰政府，并建议以红/黄/绿三分法明确对华经贸边界；该报告不具约束力，英方立场截至11月3日未变，但为后续复议保留了政治空间
- 欧盟外资审查机制(FDI Screening)日益严格，2025年约80%的申报被审查；IAA提案拟进一步加强对"新兴战略领域"FDI的条件性审查
- 数据安全：德国《能源行业IT安全法》禁止"威胁国家安全的国家"远程管理新能源设施

| 维度 | 中国 | 欧洲 |

**核心差异解读**：
1. **中国强在制造与建设速度**，欧洲强在技术原创与金融机制设计
2. **中国产能过剩溢出** vs **欧洲产能不足缺口** → 双向的贸易驱动力
3. **中国海风LCOE已低于欧洲**（成本优势约30-50%），这构成了中国企业出口的根本竞争力
4. **欧洲利用小时更高**（北海/波罗的海风资源优于中国近海）→ 项目IRR有优势

### 9.3 牛/熊情景

#### 牛情景（概率30%）
- 2026年H2起英国及北海项目加速FID，Sif所见2027-2028年空档被新签基础合同明显缩短
- 欧洲本土产能扩张继续滞后
- NZIA/IAA仅影响整机而不波及基础和电缆 → 中国企业出货量持续高增
- 大金重工2027年海外收入突破100亿，东方电缆海外订单突破50亿
- 明阳苏格兰工厂投产，开辟"本地化建厂"第二增长曲线

#### 基准情景（概率50%）
- 2026-2028年FID放量偏慢，单桩环节存在阶段性需求空档，2028-2029年后再改善
- 中国基础/海缆企业仍可凭已签项目持续受益，但新签和收入确认的斜率趋缓
- IAA逐步扩至风电部件，2028年后中国出口份额增长受限
- 大金重工海外收入CAGR~30-40%，2027年约80-100亿

#### 熊情景（概率20%）
- 地缘政治急剧恶化：欧盟出台全面中国风电禁令或高额反倾销税
- NZIA+IAA全面堵截中国供应链参与
- 欧洲利率回升、并网和收益机制问题使FID继续冻结，Sif所预警的2027-2028年空档扩大
- 大金重工被迫退出欧洲市场或转为合资模式

> **情景概率判断**：三情景概率维持30%/50%/20%不变。支持牛情景的新证据是Vanguard 3.09GW完成约£132亿融资签署、AR8与AO10将于2027年2月集中授标；支持基准/熊情景的新证据是Aegir与TGS 4C确认中国以外FID仅约2GW、大金Q3出口确收降至约2.8万吨、Green Volt联合开发商寻求退出、以及OWFA要求把单桩纳入欧盟钢铁保障措施。情景分化的关键观测点为Vanguard交割后的FID、Sif 11月6日交易更新与2027年2月两项授标结果。

### 9.4 核心风险

1. **政策风险（最高权重）**：NZIA已生效（细则指引2026.7.22发布），IAA立法推进中且风电已在适用范围内，欧盟保护主义趋势明确；FSR已对金风立案，2026年10月OWFA正式要求把单桩纳入钢铁保障措施——壁垒正从"整机"扩散到"基础结构件"。中国光伏产业在欧洲的遭遇（反倾销+反补贴+强迫劳动审查）是风电行业的前车之鉴。
2. **需求节奏风险**：拍卖→FID→并网管线的转化率并非100%。2025年流标潮（6.5GW无人投标）与2026年中国以外FID仅约2GW（2022年以来最低）共同表明，开发商在高成本/高利率环境下极度谨慎，且这一谨慎并未因拍卖量恢复而缓解。
3. **竞争风险**：韩国(SeAH)、印度、越南供应商正在扩产，3-5年后可能改变供需格局。
4. **欧洲经济风险**：利率环境、欧元汇率、通胀水平直接影响项目FID决策。
5. **地缘政治风险**：台海/南海局势若升级，中国企业在欧洲的经营环境可能急剧恶化。

## 十、核心结论

1. **欧洲海上风电并非线性地处于"订单释放前夜"**：2022-2026年累计拍卖约59GW、约42GW未FID仍构成巨大的中长期项目池；但Sif H1 2026显示，欧洲头部单桩厂已达到计划产出后，仍因FID偏少而预期2027-2028年需求偏低。**WindEurope 2026年秋季统计进一步量化了这一断层：H1 2026海上FID仅0.6GW（vs陆上4.5GW）、海上风机订单仅2.8GW（同比-77%）**，说明拍卖量与实际投资决策之间的转化率处于近年低位。丹麦2026年8月1.8GW成功授予与德国2026年无拍卖并存，2026年9月He Dreiht 960MW投运仪式与Morgan/Morecambe输电许可获批则验证存量FID管线的兑现仍在推进，显示拍卖→CfD可融资性→FID的断层使2026-2028年成为验证期，较高确定性的生产窗口更应后移至2029年前后，前提是项目融资和合同转化兑现。Aegir与TGS 4C的前三季度统计把断层量化到全行业：中国以外海上FID仅约2.0-2.1GW、3个项目，为2022年以来最低，而同期获最终许可容量预计达22.2GW、为历史第二高——许可端放量、投资端收缩的剪刀差说明瓶颈已从"有没有项目"转为"项目能不能融资"。2026年拍卖端的"多极并行"（法国AO10截标、荷兰定档11-12月、英国AR8进入投标前最后程序）并未改变这一节奏：三项授标全部落在2027年一季度；Vanguard East/West虽已签署约£132亿债务包、仍待交割与FID，再次印证拍卖→FID转化并非自动完成。

2. **长期产能缺口与短期订单空档并存**：欧洲单桩产能仅满足2030目标需求的56%，海缆排至2030年，安装船2029年起严重短缺；但这些长期缺口不能替代项目级需求验证——据Rystad Energy（媒体转引），欧洲超大直径单桩名义产能2027年将升至约270万吨，而产能利用率2026-2027年仅约32%、2028年降至19%。中国供应商的核心竞争力仍从"便宜"升级为**"能交付"**，但订单判断必须以FID、正式基础合同和工厂排期为准。2026年三季报的镜像更为清晰：大金前三季度海外海工交付近15万吨创同期新高、毛利率升至35.6%，而Q3出口海风确收仅约2.8万吨、全年未新签欧洲订单——交付在兑现、新签在空窗。

3. **赛道分化明确**：单桩/海缆/安装是确定性最高的出海赛道（贸易壁垒相对低、缺口最大），整机出口壁垒极高（NZIA直接限制），明阳"本地化建厂"模式在英国已遭实质否定（2026年3月英政府不支持使用明阳风机），整机出海短期难有路径。

4. **贸易政策是最大变量**：NZIA已生效（2025.12.30），欧委会2026年7月22日发布实施细则指引；IAA已于2026年3月提案并明确将风电纳入适用、计划将非价格标准覆盖面提至40%或8GW且对全量拍卖引入网络安全/原产地预审，欧洲议会三委员会12月1日投票、理事会拟11月底形成立场，立法大概率延至2027年。FSR已对金风立案深入调查，2026年10月23日OWFA要求把单桩纳入欧盟钢铁保障措施——壁垒正从整机扩散至基础结构件，风电重复光伏路径的风险进一步显性化。中国企业需要通过**欧洲建厂/合资/认证前置**等方式规避壁垒，但建厂本身亦面临FDI与国家安全审查（如明阳案例）。反向的边际改善是：欧盟对华风塔反倾销税将于2026年12月17日到期且未启动复审，美国232风机调查暂不加税、转为180天谈判——短期关税压力小于市场担忧，中期程序性风险高于市场认知。

5. **2026年是"拍卖延续、授标后移、FID收缩"之年**：UK AR7的8.4GW与丹麦新增1.8GW改善长期项目储备，2026年可确认拍卖量因此锁定在10.2GW；法国AO10（约9.7-11.1GW）已于2026.10.12截标、授标待2027年2月，荷兰IJmuiden Ver Gamma-A/B（2GW）定于2026.11.26-12.10招标并于2027年一季度批复，英国AR8（约17.1GW）于2026.10.15改走标准时间表、密封投标12月3-9日、结果2027年2月15-17日——三项授标叠加构成2027年一季度约29-30GW的授标高峰。德国WindSeeG修正案2026.9.2经联邦内阁通过后，10.8完成Bundestag一读、10.28政府反声明坚持两阶段模式，截至11.3尚未表决（2026年无拍卖、2027年两阶段模式）。因此，"2026年是订单放量年"的判断不成立，"2027年一季度是授标年、2028-2029年是订单年"是更贴合数据的时间结构。Sif对2027-2028年需求偏低的预警，要求把跟踪重心前移至FID、基础合同和工厂产能利用率；Vanguard的融资落地（£132亿）与Sif 190kt项目FID是短期两个关键验证点，AR8/AO10授标后的融资关闭才是中国供应链订单斜率重新上行的真正起点。
