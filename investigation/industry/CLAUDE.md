# 行业研报目录说明（CLAUDE.md）

本目录存放行业研究报告（Markdown 为唯一真源）及精读版 HTML。

## 1. 目录结构

- `*.md`：行业研报原文，**唯一真源**。更新研报只改 md。
- `html/`：精读版 HTML（CDN 版 ECharts，需联网看图；离线版见 workspace 备份）。
  - 中国风电 / 中国海上风电 / 欧洲海上风电 / 中国海缆 / 端侧 AI 芯片（各与同名 md 对应）。

## 2. html 版本创作指南

- 规范全文见 `workspace/industry_html/_shared/规范_生产流程.md`（8 阶段、9 条硬标准，必读）。
- 要点：驾驶舱 + 长文双层结构；长难句按 R1–R7 重写（结论 + bullets + 脚注），事实零丢失；
  核心表用 ECharts 可视化（tooltip + 轴单位 + 图例三件套），其余原表折叠备查；
  ECharts 走 CDN（`cdn.jsdelivr.net/npm/echarts@5.6.0`），内联离线版留 `.inline-bak` 备份。
- 工作区：`workspace/industry_html/<篇目录>/`（总纲 00_总纲.md + 片段 + 构建脚本 + 成品 index.html）。

## 3. 同步铁律

- **更新 md 研报后，必须同步更新对应的 html**：按规范走阶段 2（改对应片段）→ 3（重组装）→ 4（如有新图）→ 5（Playwright 三态实测）；
  小改可只改片段重组装，大改（新增章节/表格）需修订总纲后再改。
- **P0 未清零不得归档**：改完后派未参与改写的子代理独立审查（事实抽查 ≥20 锚点 + 三态实测），
  P0（事实错误/功能坏）必须清零；P1 修完或书面不采纳（附理由）。
- **文件名同步**：md 按研报文件名同步规则改名时，html 同名跟进（见项目 CLAUDE.md 第 6 节）。
- **提交**：`git add` 精确到文件，归档 `html/` 下对应文件；workspace 中间产物不提交。
