# 功率半导体行业：投资标的深度分析

**日期：2026年8月29日** | **基于公司法定披露的2026年半年报（统计截止2026-06-30，公告发布时间2026-08-10至2026-08-25）及行业公开信息**

## 一、核心结论

**首选投资标的：华润微（688396）—— 业绩拐点已验证、涨价兑现最充分的IDM龙头**

理由：唯一实现“营收、归母、扣非、毛利率、经营现金流”五项同向显著改善的标的。2026H1营收61.28亿元（+17.44%）、归母7.22亿元（+113.23%）、扣非4.14亿元（+51.48%），单季Q2营收32.71亿元创历史新高、毛利率27.61%同比+1.67pp环比+2.13pp，彻底扭转2023—2025年利润三连降（14.79→7.62→6.61亿元）。SiC业务同比+148%、产能利用率接近满载、年内已执行两轮涨价（2月、7月）且管理层在8月25日业绩会明确不排除下半年第三轮，经营现金流13.91亿元同比+95.13%质量高，重庆12英寸线6月已达2万片/月并加速爬坡，财务稳健（资产负债率17.9%为板块最低）。在功率半导体从“成本传导”切换至“AI供电结构性紧缺”的新周期中，IDM模式的制造定价权兑现最为直接。

**次选：士兰微（600460）—— 最纯的SiC弹性标的，但2026H1盈利质量显著弱于华润微，需降权观察**

士兰微H1营收72.62亿元（+14.62%）、归母5.16亿元（+94.84%）表面高增，但扣非仅2.71亿元（+0.67%），Q2扣非1.13亿元同比-8.81%环比转弱，非经常性损益2.45亿元（占归母47.5%，其中持有安路科技、昱能科技及限售期联讯仪器公允价值变动贡献税后约1.94亿元）。综合毛利率18.56%同比-1.86pp为板块最低，经营现金流2.92亿元同比-12.08%，资产负债率53.28%为板块最高。6英寸SiC月产1万片接近满载、8英寸5000片/月向1万片扩充，年内两次提价（3月1日起约10%、7月1日起15%起）尚未修复毛利率。弹性仍在但需证伪：若Q3涨价不能传导至扣非与毛利率，前瞻PE（按市场预期净利7—8亿元）将失去支撑。

**时代电气（688187）维持深度价值底仓，斯达半导（603290）继续回避。** 时代电气H1 130.71亿元（+7.01%）、归母17.12亿元（+2.44%）增速放缓至个位数，新能源板块收入3.67亿元同比骤降64.99%拖累，财务费用由-1.78亿元收窄至-0.52亿元侵蚀1.27亿元利润，经营现金流14.81亿元同比-21.18%但分红（10派4.6元，合计6.12亿元占归母35.75%）与H股回购2724.5万股体现股东回报。斯达半导H1 19.28亿元（-0.41%）、归母0.65亿元（-76.40%）、扣非0.46亿元（-82.29%），毛利率20.58%同比-9.16pp，资产负债率43.13%同比+9.53pp，尽管7月1日起对IGBT及SiC MOSFET模块/分立器件提价15%以上，但H1未体现、且新能源业务10.2亿元同比-16.02%未企稳。

## 二、行业背景速览

| 维度 | 现状（截至2026-08-29） |
|------|------|
| 全球市场 | ~$755亿（2025 Omdia），中国占约39%（~$291亿）；Yole预测2025—2031电力电子CAGR 7.1%至$413亿，AI基础设施为核心驱动 |
| 周期位置 | **量价齐升、供需缺口持续扩大**。2026H1已完成两轮普涨（英飞凌2月/5月-7月、意法4月/6月、华润微/士兰微2月及7月1日、扬杰/新洁能/斯达等跟进10-25%）；台厂正酝酿10月第三轮10-15%（非合约现货）。主流功率器件交期普遍30周以上，部分高压/碳化硅主驱模块超40-52周，华润微订单能见度达9个月并创新高，出现“按客户重要性分货” |
| 核心驱动力 | **AI数据中心供电重构（400V→800V/48V高压直流，单机功率器件用量提升3-5倍，AI挤占8英寸产能）+ EV 800V平台 + 光伏储能逆变/PCS高压化**三重共振；2026年全球8英寸产能预计再降约2.4%（TrendForce），前五大功率IDM资本开支连续两年下降后仅温和回升11%，新增产能释放需2-3年 |
| 最大变量 | SiC分化：6英寸通用衬底/器件产能充分、价格战后毛利偏薄；8英寸高端衬底/器件紧缺溢价，天岳先进8寸导电型全球市占51.3%（2025富士经济）、8寸产品收入占比已超50%、Q2毛利率25.36%修复；6寸向8寸升级、12寸研发布局为未来三年主线 |
| 国产化率 | Si基IGBT中低压>60%，高压<50%，SiC主驱替代率<20%；华润微、士兰微、比亚迪半导体等五家中国厂商已进全球收入前二十（Yole 2026） |
| 投资主线 | **优选IDM龙头**——本轮已验证：有自有产线企业将涨价直接转化为利润与现金流（华润微Q1 +296.6%、H1 +113%），Fabless/代工依赖型两头受挤压（斯达Q1 -74%、H1 -76%） |

> 行业判断：本轮非2021年疫情式断供复刻，而是AI算力+电网升级+新能源结构性拉动的“供给驱动型上行周期”（摩根士丹利《Power Semis–Supply Driven Upcycle》），持续性优于库存驱动周期，机构普遍预判景气至少延续至2027年H1。

## 四、逐家深度诊断（基于2026H1法定披露更新）

### 4.1 时代电气（688187）— 碾压级体量 + 地板级估值，但功率半导体纯度与新能源拖累凸显

**优势**：
- 287亿营收+41亿净利体量仍碾压板块，毛利率32.81%为板块最高，资产负债率35.25%稳健
- 轨交基本盘稳固：H1轨交板块75.80亿元（+9.67%），牵引变流系统城轨市占率60.92%连续14年第一，海外中标29个项目
- 新兴装备中汽车14.64亿元（+46.50%）、半导体26.99亿元（+11.69%）、海洋5.53亿元（+30.76%）高增，PE 16.2x历史3%分位提供极强安全垫
- 战略加码IGCT：7月31日公告与北京怀柔实验室（国家级）、清华华控、南网研究院等五方合资设立北京中车时代怀实半导体（注册资本2.87亿元，时代半导体现金1.92亿元持股67%并表），以无形资产入股方式绑定源头技术与场景验证，拓展IGCT产品型谱
- 股东回报积极：拟10派4.6元（派现6.12亿元）+ 已回购H股2724.5万股（10.26亿元，1024.56万股已注销）

**隐患**：
- **新兴装备内部严重分化**：新能源3.67亿元同比骤降64.99%（上年同期10.47亿元），工业3.45亿元-3.74%，暴露对光储单一赛道依赖风险
- **增收不增利**：H1营收+7.01%但归母仅+2.44%、利润总额20.55亿元同比-1.59%，销售/管理/研发费用刚性两位数增长，财务费用-0.52亿元较上年同期-1.78亿元收窄1.27亿元（利息收入减少+汇兑损失增加）
- **现金流与资产质量承压**：经营现金流14.81亿元同比-21.18%，应收账款145.75亿元较年初+18.91%（约为H1归母8.5倍），存货97.91亿元较年初+12.47%，下半年回款与去库存压力待观察
- **纯度不足**：新兴装备仅占总营收41.5%（54.28/130.71），半导体26.99亿元仅占20.6%，功率半导体弹性远小于纯IDM标的

### 4.2 士兰微（600460）— 最纯的IDM赌注，但H1扣非与毛利率证伪“量利双增”

**优势**：
- H1营收72.62亿元（+14.62%）延续两位数增长，集成电路29.76亿元（+16.36%，其中32位MCU +36%、MEMS传感器2.1亿元+60%）、分立器件34.44亿元（+14.50%，汽车/光伏用IGBT及SiC模块15.96亿元+11%、IPM模块20.33亿元+9%）均稳步放量
- 6英寸SiC月产1万片接近满载，8英寸5000片/月已投产并计划扩至1万片，厦门8英寸线2025Q4通线后2026H2产能释放预期仍在
- 纯度最高：130亿年营收几乎全部来自功率半导体与分立器件，8英寸SiC与12英寸模拟/汽车半导体、MEMS项目储备丰富
- 两次提价（3月1日起小信号二极管/三极管/TMBS/MOS芯片约10%、7月1日起15%起）显示定价权尝试

**隐患**：
- **盈利质量存疑**：归母+94.84%但扣非仅+0.67%，非经常性2.45亿元占归母47.5%，Q2扣非1.13亿元同比-8.81%反而下滑，主营改善停滞
- **毛利率不升反降**：H1 18.56%同比-1.86pp为板块最低，与华润微、新洁能等Q2环比修复背道而驰，说明涨价尚未覆盖成本或产品结构偏低端
- **财务压力未缓解**：资产负债率53.28%（Q2）为板块最高，自由现金流持续为负区间，Q1经营现金流-9亿后H1仅2.92亿元且同比-12.08%，折旧与扩产摊销压力仍大
- **估值与预期差**：静态PE 109.6x虽处历史1%分位，但若以扣非年化5.4亿元计前瞻PE仍约90x以上，高于华润微拐点后估值，弹性定价需以Q3扣非与毛利率修复为验证锚点

### 4.3 华润微（688396）— 本轮周期中业绩兑现最充分、拐点最坚实的IDM龙头

**优势**：
- **业绩彻底反转**：H1 7.22亿元已超2025全年6.61亿元，终结三年连降，Q2单季3.92亿元（+53.53%）营收32.71亿元（+14.24%）双创单季新高，毛利率27.61%同比+1.67pp环比+2.13pp
- **分部全面改善**：产品与方案板块营收+23.18%（毛利率+1.07pp），制造与服务+11.72%（毛利率+1.22pp，其中晶圆制造+10%、封测+16%），180nm及以下中高端掩模产品收入占比近60%，产品结构向高附加值迁移
- **IDM定价权最强**：年内两轮集中涨价（2月小范围试探、7月大范围落地且客户为锁定产能主动接受），8月25日业绩会明示“订单饱满、产能接近满载，若成本与供需持续紧张不排除第三轮”；Q2综合毛利率环比+2.13pp已验证传导
- **第三代半导体放量**：碳化硅营收同比+148%增速领先于IGBT/MOSFET，GaN外延中心启用，深圳12英寸线（投资200亿+）与重庆12英寸线（6月达2万片/月）下半年加速爬坡
- **现金流与财务最健康**：经营现金流13.91亿元同比+95.13%与归母增速同步，资产负债率17.9%（年报口径）为板块最低，现金86亿元量级，具备逆周期扩产与分红能力（拟10派0.56元）

**隐患**：
- 前期市场份额增长乏力（2023-2025营收99→101→111亿元仅个位数增长）需以持续订单验证，本轮高增基数仍低（2025H1仅3.39亿元）
- 12英寸重资产折旧与SiC/GaN研发投入仍处高位，若Q3涨价不及预期或AI/汽车需求波动，毛利率修复斜率可能放缓
- 估值修复已部分兑现（Q1 PE 122.5x分位46%），需跟踪重庆12寸良率与8寸产能利用率能否维持95%以上

### 4.4 斯达半导（603290）— 产业链分化中唯一量价双弱，继续回避

**优势**：
- IGBT模块国产第一、唯一进入全球前十的中国厂商，车规认证与客户壁垒仍在
- 净利率历史较高（2025年10.1%），Q2后7月1日起对IGBT及SiC MOSFET模块/分立器件提价15%以上，三季度毛利率或有环比修复窗口（参考扬杰、捷捷等Q2已修复而斯达、扬杰Q2未修复与提价时点滞后相关）

**隐患（延续且加重）**：
- **业绩自由落体未止**：H1营收-0.41%但归母-76.40%、扣非-82.29%，已低于2025全年盈利的1/6，TTM 1.95亿元较Q1 3.28亿元再降40%，坠落速度快于Q1（-74.3%）
- **毛利与费用双杀**：毛利率20.58%同比-9.16pp为板块最大跌幅，公司解释主因功率模块原材料成本增加+2025年产品价格下调滞后传导；研发费用同比大增、财务费用由负转正进一步侵蚀
- **资产负债表恶化**：资产负债率43.13%同比+9.53pp、环比+9.85pp，经营现金流2.10亿元同比-42.40%，存货周转率0.93次同比-2.42%
- **业务结构逆风**：新能源10.2亿元同比-16.02%（与时代电气新能源-65%同指向下游阶段性需求波动），虽工控与电源7.1亿元同比+40.17%对冲，但AI数据中心供电等高景气赛道中公司份额与涨价弹性弱于IDM
- **估值陷阱**：PE历史16%分位看似便宜，但盈利持续下修导致PE被动攀升、缺乏锚点，短期无业绩拐点

### 4.5 补充观察：新洁能、芯联集成、天岳先进

**新洁能（605111）— Fabless弹性标的已现Q2拐点**：H1 11.70亿元（+25.57%）中Q2 6.5亿元（+35.3%）显著加速，毛利率Q2 31.06%环比+2.32pp，经营现金流2.12亿元（+32.55%）；按器件SGT MOS 5.45亿元（+28.6%）、Trench MOS 2.75亿元（+10.3%）、IGBT 1.96亿元（+48.1%）增速分化，IGBT受益光储回暖（微逆/户储/工商储）。公司5月中下旬完成对大客户涨价25-30%（6-7月全部落地），管理层指引9月启动新一轮，交期已超9个月且继续拉长，Q3毛利率有望继续改善。风险在于Fabless模式下晶圆代工成本（华虹等上调5-15%）向下游传导的持续性。

**芯联集成（688469）— 扭亏但质量待考**：H1 45.62亿元（+30.53%）中SiC子公司11.82亿元（+105.9%）为核心增量，毛利率12.71%同比+9.17pp环比+7.03pp大幅修复，Q2扣非8646万元已实现单季扭亏（去年同期-3.05亿元）。但归母2.78亿元中92%来自向芯联先进专利及技术授权一次性收益2.56亿元（确认收入2.79亿元），主营仍亏0.65亿元，盈利可持续性依赖“功率业务聚焦高端、收缩低端”与12英寸车规数模混合线（6月启动、总投资约200亿元、规划5万片/月）爬坡。

**天岳先进（688234）— 衬底龙头Q2单季扭亏、8寸放量修复**：H1 9.14亿元（+15.10%）中Q2 5.48亿元（+42.06% YoY, +49.97% QoQ）创单季新高，毛利率Q2 25.36%（+12.72pp YoY, +6.24pp QoQ）显著修复，Q2归母189万元实现单季扭亏（Q1 -0.61亿元），但H1仍亏0.586亿元（去年同期盈利0.109亿元）。8寸产品收入占比已超50%，全球8寸导电型市占51.3%（富士经济2025），6寸仍为主力量产但价格竞争激烈（2025车规级单价-40.84%、非车规-53.10%后企稳）。后续看点为济南/上海工厂产能利用率与良率能否同步提升至稳定盈利。

## 五、投资决策（基于2026H1法定披露更新）

### 首选：华润微（688396）—— 量价双升中确定性与弹性兼具

| 维度 | 判断（更新） |
|------|------|
| **纯度** | MOSFET国内规模第一、功率器件IDM平台最完整（掩模/晶圆/封测/模块），SiC+148%、IGBT/ MOSFET/第三代半导体全布局，AI数据中心与新能源双赛道受益 |
| **弹性** | H1归母已超2025全年、扣非+51.48%验证弹性，Q2毛利率环比+2.13pp、现金流+95%显示涨价已进利润表；重庆12寸2万片/月爬坡+潜在第三轮涨价提供下半年催化 |
| **趋势** | 三年下滑终结、Q1 +296% → H1 +113%连续两期同向显著改善，多源交叉验证通过，趋势确认向上且斜率陡峭 |
| **估值** | 静态PE 122.5x（Q1）随TTM 10.44亿元快速回落，拐点后前瞻PE显著低于士兰微扣非口径，风险收益比更优 |
| **催化剂** | 8月25日业绩会“不排除第三轮涨价”、重庆12寸下半年加速爬坡、SiC/GaN放量、8寸产能紧缺延续至2027H1 |

**核心逻辑**：本轮功率半导体周期本质是“AI挤占+8寸收缩”导致的供给驱动型紧平衡，有产能的IDM才能将涨价转化为利润。华润微是板块中唯一“订单饱满+产能满载+两轮涨价落地+毛利率与现金流同步修复”的标的，财务最健康、催化最明确。

### 次选：士兰微（600460）—— 高纯度SiC期权，但需以Q3扣非与毛利率为观察锚

- 若追求对SiC渗透最直接的押注且能承受盈利质量波动，士兰微仍提供最高功率半导体纯度与产能弹性（6寸满载、8寸5000→10000片/月、厦门8寸2026H2投产、12寸模拟/汽车半导体储备），但需接受当前扣非停滞、毛利率下滑、负债率52.9%+的高Beta
- 配置建议：华润微作底仓（确定性），士兰微作弹性卫星仓，合计功率半导体仓位中华润微权重应高于士兰微，直至Q3财报验证涨价传导

### 底仓：时代电气（688187）—— 深度价值与股东回报，但需警惕新能源与费用拖累

- PE 16.2x历史3%分位、41亿净利安全垫、分红+回购提供防御性
- 适合作为组合中低波动底仓而非进攻标的，功率半导体纯度不足（半导体仅占营收20.6%）制约弹性；若新能源板块Q3未企稳或应收/存货继续攀升，应控制权重

### 回避：斯达半导（603290）—— 趋势未企稳前不抄底

- H1 -76%且毛利率崩塌、负债攀升，7月涨价尚未验证，短期看不到业绩拐点，历史16%分位PE不构成安全边际，可能是价值陷阱

### 风险提示（更新）

1. **需求分化风险**：2026H1新能源（时代-65%、斯达新能源-16%）已显阶段性波动，若AI数据中心800V架构商用节奏慢于预期或车规需求二次去库存，涨价传导可持续性存疑
2. **SiC/衬底价格分化风险**：6寸通用产品价格竞争激烈（天岳2025单价-40%至-53%），8寸放量前可能出现局部价格战，衬底成本占器件47%且生长慢（PVT 0.2-0.3mm/h）导致降本不及预期
3. **产能与成本风险**：8寸产能2026再降2.4%、晶圆代工与封测报价已普涨5-30%（华虹平均利用率106.1%），无自有产线的Fabless与重资产IDM均面临成本与折旧双重挤压
4. **财务与汇率风险**：士兰微负债率53.28%+现金流转弱、斯达负债率9pp攀升、时代电气汇兑损失与财务费用收窄1.27亿元，海外业务多币种结算下汇率波动直接侵蚀利润
5. **地缘与技术风险**：美国出口管制升级可能影响高端产线设备/EDA获取；GaN 650V以下与SiC 1200V以上分界在800V母线下仍存技术与可靠性验证风险
