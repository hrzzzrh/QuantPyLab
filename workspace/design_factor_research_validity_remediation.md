## 1. 修复目标

本计划修复的是研究流程的有效性，不承诺把策略历史收益优化为正。完成后的系统必须能够：

1. 在训练、验证和测试之间保持严格隔离；
2. 对每个训练月份给予相同总权重，避免上市股票数量较多的月份主导拟合；
3. 使用有明确组合含义的非负、和为 1 的权重模型，并通过先验收缩降低无约束归一化导致的零权重和单因子塌缩；
4. 在验证证据不足、权重结构不合格或搜索负担过高时拒绝方案，而不是强制选择一个“最不差”组合；
5. 使用不重叠的 Walk-forward 测试区间，避免把重叠年份重复统计为独立证据；
6. 在报告中分开陈述“研究协议有效”和“策略收益证据充分”，禁止用流程通过替代投资有效性结论。

当前 2016—2025 年测试结果已经被读取。因此，修复后的历史重跑属于回溯性方法开发验证，不是新的盲测证据。真正的确认性结论仍需要未来未见数据或预先封存且未参与本轮设计的数据。

## 3. 训练模型修复

### 3.1 目标变换

未来收益标签改为逐信号日的方向一致百分位排名，再在当日去均值。这样可降低极端个股收益对拟合的支配，并使目标与策略使用的截面因子排名处于可比较尺度。

原始未来收益、标签起止日期仍保留用于审计；目标变换只发生在训练拟合阶段，不改变验证和测试回测收益。

### 3.2 月份等权

每个信号日的全部股票观测使用总和为 1 的样本权重。实现上对当日特征和目标同时乘以 `1 / sqrt(当日有效股票数)`，使 Gram 矩阵和协方差中每个月份贡献相等。

### 3.3 单纯形约束与先验收缩

训练目标改为：

`最小化：加权预测误差 + ridge_alpha × ||w - prior||²`

约束为：

- 每个因子权重不小于 0；
- 全部因子权重和为 1；
- `prior` 取候选策略在训练前声明的完整归一化因子权重；候选没有可用先验时使用等权。

优化器使用确定性的投影梯度法，每步投影到概率单纯形。这样零解不再是可行解，`ridge_alpha` 表示向预先声明策略结构收缩的强度，而不是先拟合任意尺度系数后再归一化。

训练结果继续允许部分因子为零，但必须由研究门禁检查有效因子数和最大单因子权重。

## 4. 研究协议门禁

在现有样本覆盖门禁之外新增以下预先配置的协议门禁：

| 门禁 | 正式配置初始值 | 作用 |
|:---|---:|:---|
| 最少有效因子数 | 2 | 拒绝单因子权重 |
| 最大单因子权重 | 0.80 | 拒绝高度集中权重 |
| 最低验证选择分数 | 0.00 | 验证夏普不为正时不进入测试 |
| 最大失败训练比例 | 0 | 正式有限网格要求全部组合可拟合 |
| 最大组合/验证信号日 | 0.25 | 限制多重比较负担 |
| 最少完成测试窗口 | 3 | 防止仅凭一两个窗口下结论 |
| 测试窗口不得重叠 | true | 确保窗口级汇总不重复统计同一时期 |

未通过模型或验证门禁的组合不回退到默认权重；整个窗口没有合格组合时记录为 `rejected`，不读取也不运行该窗口测试数据。报告必须区分：

- `protocol_passed`：研究协议和隔离要求通过；
- `protocol_failed`：配置、样本、模型或窗口独立性不合格；
- `completed_with_rejections`：协议正常执行，但部分窗口因预设门禁被拒绝；
- 策略证据：只描述完成测试窗口的收益分布，不参与本轮参数回写。

## 5. 正式配置收缩

正式修复配置采用：

- 5 年训练、2 年验证、2 年测试；
- Walk-forward 步长 2 年，确保测试段互不重叠；
- `holding_count = [20, 50]`；
- 缩尾范围固定为 `[0.05, 0.95]`；
- `ridge_alpha = [0.1, 1.0]`；
- 每个窗口最多 4 个外层组合，23 个验证信号日下比较负担约为 0.174；
- 训练最少 48 个有效月末信号日；
- 验证和测试各最少 20 个可执行信号日。

该搜索空间根据参数职责和独立时间样本数预先收缩，不根据修复后测试收益再次扩展或删改。

## 6. 标准报告修复

标准报告新增或明确展示：

1. 标签变换、月份等权、权重先验和单纯形约束；
2. 每个窗口的模型门禁、验证门禁和拒绝原因；
3. 测试区间是否重叠、独立测试窗口数；
4. 实际比较组合数与组合/验证信号日比例；
5. 成功训练比例、有效因子数和最大权重；
6. 协议状态与策略收益证据分离；
7. `retrospective_method_development=true`，明确当前历史测试期已经用于方法诊断；
8. 被拒绝窗口不输出测试指标，证明测试未被读取用于放宽门禁。

## 7. 验收标准

### 7.1 单元和集成行为

- 单纯形投影对任意有限输入输出非负且权重和为 1；
- 全因子负协方差样本不再产生零解；
- 月份股票数量变化不改变月份总权重；
- 使用未来日期数据修改不能改变此前训练特征；
- 验证门禁拒绝时测试执行函数不被调用；
- 测试窗口重叠时正式协议拒绝启动；
- 训练关闭时三个正式策略行为不变。

### 7.2 全量研究运行

- 全部正式训练组合成功拟合；
- 所有进入测试的模型至少 2 个有效因子且最大权重不超过 0.80；
- 每个进入测试的窗口验证分数大于 0；
- 组合/验证信号日不超过 0.25；
- 测试窗口互不重叠，至少 3 个窗口完成测试；
- 报告协议状态通过；若策略证据不足，必须如实结论为“证据不足”，不得继续使用测试数据调参；
- Ruff、格式检查和全量 pytest 通过；
- 完成最终 Code Review 后精准提交。
