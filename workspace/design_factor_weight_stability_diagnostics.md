# 因子权重稳定性诊断设计

**设计日期**：2026-08-20
**状态**：已完成实施
**适用范围**：`evaluate-factor-experiments` 的训练权重审计

## 1. 背景

稳健研究协议扩大了验证和测试时间样本，并移除了重复的 Ridge 搜索值，但最终报告仍显示多个窗口的入选权重为单一因子 1.0。只看入选模型无法判断这是训练器对所有参数组合都产生的结构性塌缩，还是验证集偶然挑中了极端权重组合。

## 2. 目标

- 为每个训练组合输出可机器审计的权重集中度指标。
- 同时比较全部成功组合与最终入选组合，区分“模型普遍塌缩”和“选择放大塌缩”。
- 不改变权重拟合、验证排序、测试隔离和任何策略行为。
- 将诊断数值写入标准报告和独立 CSV，作为后续是否引入权重约束或中性化的证据。

## 3. 指标口径

对训练结果中的归一化非负权重 `w` 计算：

- `factor_count`：训练组合中的因子数量。
- `nonzero_factor_count`：权重大于 `1e-12` 的因子数量。
- `max_factor`、`max_weight`：最大权重因子及其权重。
- `effective_factor_count = 1 / Σ(w²)`：等权因子数量的等效值；单因子为 1，两个等权因子为 2。
- `weight_entropy`：`-Σ(w log w)`；零权重不参与计算。
- `normalized_weight_entropy`：除以 `log(factor_count)` 的归一化熵；只有一个因子时记为 0。
- `collapse_level`：`single_factor`（非零因子不超过 1 或最大权重至少 0.9）、`concentrated`（最大权重至少 0.6）或 `diversified`。
- `selected`：该训练组合是否为当前窗口验证集入选方案。

阈值沿用现有报告的 0.9 高度集中提示，并把 0.6 仅作为分层标签，不作为硬门禁。

## 4. 输出与解释

新增 `factor_weight_diagnostics.csv`，逐训练组合保留上述字段、训练状态、失败原因和窗口/候选/试验身份。标准报告新增汇总表，按窗口列出：成功组合数、单因子组合数、入选是否单因子、平均/最小有效因子数、最大权重范围。

报告风险提示分为两类：

- 若一个窗口全部成功训练组合都为 `single_factor`，说明塌缩是训练/因子数据层面的普遍现象，不能归因于验证选择。
- 若只有入选组合为 `single_factor`，说明验证选择可能放大集中权重，需要检查选择指标和参数空间。

这些提示不自动阻断研究，也不把“多因子权重更均衡”假设成更优；下一阶段再根据诊断决定是否做权重约束、行业/规模中性化或因子去相关。

## 5. 验收标准

- 新 CSV 与 `training_models.csv` 的训练组合一一对应，成功/失败状态不丢失。
- 标准报告能同时展示全部训练组合和入选组合的集中度。
- 单元测试覆盖单因子、等权多因子、集中但非单因子、空权重/失败组合和入选标记。
- 既有五份研究审计 CSV 数值不改变；真实稳健评估只新增诊断产物和风险文字。
- Ruff、全量测试、真实评估和 Review Gate 通过后提交。

## 6. 实施结果

- `factor_weight_diagnostics.csv` 已接入标准评估输出，逐行对应 `training_models.csv`，并保留失败训练组合。
- `summary.md` 已增加全部成功训练组合的按窗口汇总，并明确区分“全部组合普遍塌缩”和“验证选择放大塌缩”。
- 诊断只读取已完成的训练权重，不改变拟合、验证排序、测试隔离或策略行为。
- 真实稳健评估批次 `factor-experiment-robust-walk-forward_20260820_233539` 完成：10 个窗口、180 个训练组合、180 个成功；诊断输出 180 行，其中 156 组为 `single_factor`、24 组为 `concentrated`，10 个窗口各有一个入选标记。
- 与此前批次相比，研究有效性门禁、失败记录、入选试验 ID 和测试指标保持一致；训练权重及训练/验证浮点指标存在历史数据快照差异。对同一进程、同一训练窗口重复拟合得到完全相同的权重，因此本次诊断没有引入评估路径漂移；跨数据快照的可复现性另列为后续任务。
- 单元测试和全量质量门禁已通过；Review Gate 通过后，本设计随实现一并提交。
